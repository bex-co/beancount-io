# MCP agent journeys: baseline, 2026-09-15

This is the first live baseline for `yarn mcp:agent-eval`, and the comparison point for later MCP tool, resource, prompt, and instruction changes. Every result below is a live client session against the hosted endpoint, not a replayed transcript.

## Conditions

- **Endpoint:** `https://beancount.io/api-gateway/mcp`, which reports server `beancount-mcp 1.0.0`. The endpoint does not expose a deployed revision.
- **Credential:** a QA account's API key with `ledger.read` and `ledger.write`, pinned to its dedicated `mcp-agent-eval` ledger. Each attempt started from the fixture in `fixtures/main.bean`.
- **Claude Code:** 2.1.272 with its default model, which reported `claude-opus-5`.
- **Codex:** codex-cli 0.154.0 with its default model, which Codex does not report.
- **Limits:** 3 attempts per journey and client, 300 s and 40 MCP calls per attempt, run on macOS.
- **Command:** `yarn mcp:agent-eval --attempts 3`

## Observations

- **Correct answers and ledger changes:** all 18 attempts passed. Every answer contained the expected figures and names. The two read-only journeys left the ledger byte-for-byte unchanged, and the purchase journey added exactly one matching transaction. The fixture was restored after the run.
- **Claude Code calls and cost:** Claude Code made one non-MCP tool call per attempt, a deferred tool lookup before its first MCP call. Its cost across the nine attempts was about USD 1.78.
- **Codex tool errors:** in one discovery attempt, Codex had a failed MCP call and recovered. Its answer and ledger state still passed.
- **Variation:** Claude Code's MCP call count varied only on the report journey (6 to 8). Codex's varied only on discovery (3 to 4).

## Not measured

- **Claude Code with a user-level MCP configuration, and other clients:** not run. The harness passes the eval server on the command line.
- **Codex cost, turns, and model:** unavailable from `codex exec --json`.
- **Scoring limits:** the answer scorer checks that each expected fact is present. It does not penalize extra claims, such as naming an additional stale account. The state scorer compares `main.bean` text and the file list, so a write to a newly included file would show up as an extra file.
- **Historical audit:** the 2026-09-08 field audit's 11, 21, and 15 turns came from different prompts, one client, and a local stack. They are not comparable to these numbers.
