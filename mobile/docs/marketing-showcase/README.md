# Marketing showcase captures

The tracked WebP files contain the deterministic public demo ledger. They are
safe inputs for documentation and localized App Store creatives; do not replace
them with captures from a contributor's signed-in ledger.

The App Store uses the first three stories—financial overview, plain-text/Git
ownership, and reporting depth—declared with every localized caption and device
size in `../../metadata/screenshots.json`. Rebuild the ignored PNG outputs with
`yarn screenshots:build` and validate them with `yarn screenshots:validate`.
