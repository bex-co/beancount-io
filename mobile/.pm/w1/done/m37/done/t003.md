## Objective

A small persisted store of manual verdicts — `recurring` / `notRecurring` per (ledgerId, payee) — that always beats detection: Monarch's approve/ignore review queue collapsed into a toggle.

## Context

- Pattern: Apollo reactive var + AsyncStorage hydration, like the existing vars in `src/common/vars/` (no Redux/Zustand — house rule). `@react-native-async-storage/async-storage` is already a dependency; **no new deps**.
- Fidelity framing per the milestone README: this is device-local display preference, not ledger data; the ledger-native `custom` directive alternative is inbox `032`.

## Steps

1. `src/common/vars/merchant-recurring-overrides.ts`: var, hydrate-on-launch, `setOverride` / `clearOverride`, storage key namespaced by ledger id.
2. Pure resolution helper `resolveRecurringVerdict(detection, override)` with unit tests (override wins in both directions; absence falls through to detection).
