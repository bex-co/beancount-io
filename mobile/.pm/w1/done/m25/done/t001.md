## Objective

When fuzzy search returns zero matches, render a tappable "Create `<typed query>`" row in place of the bare `accountPickerNoResults` text, gated on the query being plausibly an account name.

## Context

- Zero-results state renders at `src/screens/account-picker-screen/account-picker-screen.tsx:348` (`emptyText`).
- Validation primitives live in `src/screens/open-account-screen/account-name.ts` (`ACCOUNT_ROOT_PREFIXES`, `AccountNameValidation` with reasons like `invalidRoot`, `invalidCharacters`).
- The picker screen is user-facing: theme tokens via `useTheme()`, strings via `useTranslations()`.

## Steps

1. Add a create row component to the empty state showing the typed query verbatim.
2. Gate visibility: show the row whenever the query is non-empty; validate with `account-name.ts` helpers to decide whether the tap can proceed directly (valid full name) or must surface guidance (see t002's prefill contract).
3. Add the English string(s) (e.g. `accountPickerCreate`) to `src/translations/en.ts`.
4. Verify in light and dark.

## Files

- `src/screens/account-picker-screen/account-picker-screen.tsx`
- `src/translations/en.ts`

## Acceptance criteria

- [ ] A no-match query shows the create row with the typed text; an empty query does not.
- [ ] Row renders correctly in light and dark, string comes from the English base.
- [ ] No hard-coded colors.
