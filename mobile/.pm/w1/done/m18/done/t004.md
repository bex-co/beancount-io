## Objective

When fuzzy-search results have equal match scores, order them by frecency so the accounts a user actually books against surface first.

## Context

- `filterAccounts` in `src/common/account-search.ts` (m17 t001) sorts by fuzzy score; add an optional usage-map parameter for the tiebreak, keeping the module pure and alias-free.

## Steps

1. Extend `filterAccounts(pattern, accounts, usage?, now?)` to tiebreak equal scores by frecency.
2. Pass the active ledger's usage map from the picker screen.
3. Unit-test the tiebreak.

## Files

- `src/common/account-search.ts`

## Acceptance criteria

- [ ] Two equal-fuzzy-score matches order by usage frecency (unit-tested)
- [ ] Fuzzy score still dominates: a better match outranks a more-used weaker match

## Out of scope
