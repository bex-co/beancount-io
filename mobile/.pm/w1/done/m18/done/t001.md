## Objective

Create an alias-free pure module that scores accounts by recency-weighted frequency ("frecency") from a usage map shaped `{[account]: {count, lastUsedAt}}`, exposing `topAccounts(usage, now, limit)` and a `frecencyScore(entry, now)` primitive. Reuse or mirror the tested `rankByFrequency` where sensible. Ship with unit tests.

## Context

- Prior art: `src/common/suggestion-utils.ts:289-294` (`rankByFrequency`) — kept `@/`-import-free for the jest-lite runner; follow the same pattern.
- Pass `now` in as a parameter — no `Date.now()` inside scoring — so tests are deterministic.
- jest-lite matchers are limited to `toBe/toEqual/toBeCloseTo/toBeTruthy/toBeFalsy/toThrow` (+ `.not`).
