## Definition of done

`src/screens/journal-screen/`, `src/common/d3/line-chart-d3.tsx`, `src/common/graphql/queries/homeCharts.graphql` and the `onScrubStart`/`onScrubEnd` props are gone, and a repo-wide grep for each returns nothing outside this milestone's own history. `src/generated-graphql/` is regenerated by `yarn codegen`, never hand-edited.

On a cold start the app issues queries for the **first** tab only; visiting each of the other four for the first time renders its skeleton with a background color and no flicker, in light **and** dark. `yarn lint` / `yarn typecheck` / `yarn test:unit` pass.

## Source + Goal linkage

- **Source:** inbox notes `002` (lazy tab mounting), `012` (orphaned `homeCharts.graphql`), `013` (dead chart code) and `025` (unrouted journal screen), all re-verified against the working tree during the 2026-08-16 board triage.
- **Goal linkage:** the cross-cutting quality bar — _"Fast and offline-tolerant where feasible — mobile moments are short."_ Honest accounting: **only `t005` has a direct user-facing effect.** The four deletions are maintenance, justified by the drift they were actively causing rather than by a user outcome — `010` counted a dead search bar as a live copy, `015` filed a dead spinner as a defect, and the deleted `m7/t003` described a card as linking to a tab that no longer exists.
- **Expected outcome:** the app stops issuing four screens' worth of queries before the user has visited them, and the next person reading the tree stops planning work against code that cannot run.
- **Why now:** the triage found all four in one pass and they share a single verification loop (grep + `yarn test`), so batching them costs one review instead of four. `t005` goes last because it is the only behavioral change of the five and the only one that can regress a user-visible surface.

## How it landed

All eight tasks shipped 2026-08-16. Six files and one directory left the tree — `src/screens/journal-screen/` (5 files), `src/common/d3/line-chart-d3.tsx` + its test, `src/common/graphql/queries/homeCharts.graphql`, and `src/__mocks__/` (both files) — along with `generateTicks`, the `onScrubStart`/`onScrubEnd` props, and eight orphaned `journal*` translation keys across 13 locales. `yarn codegen` dropped 61 lines of generated code.

Two things the plan did not anticipate, both handled rather than deferred:

- **The `homeCharts` deletion stranded a mock.** `src/__mocks__/generated-graphql/graphql.ts` re-exported `HomeChartsQuery`, so `tsc` failed. Nothing imports either mock file — the jest-lite runner has no mock resolution — so both went, and `src/__mocks__/` no longer exists.
- **`t003` shipped without the owner confirmation its own steps asked for**, because the milestone was handed over as "implement the README". The reasoning it would have tested is unchanged (nothing calls the operation; Home reads `getLedgerBalanceSheet`), and reverting is `git revert` plus `yarn codegen`.

`t005` was the only user-visible change and the only one that needed judgement: `lazy: false` predated the monorepo move with no recorded rationale, and the `83bddba` flicker fix it might have been protecting turns out to depend on the lifted `SafeAreaView`, not on eager mounting. Verified by cold-starting the dev build in both themes and watching every tab mount for the first time — see `done/t006.md` for the table.

One pre-existing defect surfaced during verification and was filed rather than fixed: an unmatched tabs route renders black instead of `+not-found` (inbox note `w1/026`).
