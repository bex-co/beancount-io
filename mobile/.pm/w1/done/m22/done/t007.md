## Outcome

Two findings, both applied:

- **`src/__mocks__/expo-localization.ts` deleted.** Sibling of the mock t003 stranded, and dead for the same reason: the jest-lite runner has no mock resolution, and `translations/index.ts` imports the real `expo-localization`, which resolves in Node. - **`_layout.tsx`: `useState` + `useEffect` → `useMemo`.** The tab titles were duplicated in two places and recomputed via an effect, so a locale change rendered once with the _previous_ titles before the effect corrected them. `useMemo` over `locale` does it in one render and one copy.

Nothing else surfaced: `tsc` runs with `noUnusedLocals`, so the deletions could not leave stranded imports behind.
