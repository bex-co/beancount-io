## Objective

Make the file editor stop contradicting itself. Its error banner is fetched once at mount and never refetched, so after a save it shows the errors that existed **before** the save — the one place the user is guaranteed to look right after saving. Fire the cheap `errors` scope on every successful save, and the full `file` scope once when leaving the screen.

## Context

- `handleSave` (`src/screens/ledger-file-editor-screen/index.tsx:336`) calls `updateLedgerFile` with no `refetchQueries`, no `update`, no eviction. The only state that changes is a local `shaRef.current`.
- The banner reads `useLedgerErrors()` at `index.tsx:473` (`cache-and-network`, `src/common/hooks/use-ledger-errors.ts:16`) and filters with `filterFileErrors`. Symptom both ways: fix an error → Save → banner still shows it; introduce one → Save → banner still clean.
- Two beats rather than one because users save repeatedly mid-edit; a dozen refetches per keystroke-batch is not affordable. `errors` is a single cheap query.
- There is already a `navigation.addListener("beforeRemove")` handler at `index.tsx:388` for the unsaved-changes guard — the leave hook can hang off the same lifecycle. Note it currently calls `e.preventDefault()`, so the invalidation must fire on the actual departure, not on the intercepted attempt.
- Only invalidate on leave if a save actually succeeded during the session — a read-only visit should cost nothing.
- The editor's own `getLedgerFile` is `network-only` (`index.tsx:259`), so re-entering already gets a fresh sha; it does not need invalidating.

## Steps

1. On successful save (after `shaRef.current = newSha`), call `invalidateLedgerData(client, "errors")` and track that a save happened.
2. On leave, if any save succeeded, fire `invalidateLedgerData(client, "file")`.
3. Verify the banner reflects post-save state: introduce a bad directive, save, confirm the banner appears without leaving the screen; fix it, save, confirm it clears.
4. Confirm the `LedgerDrawerHeader` error badge (`src/components/ledger-drawer/ledger-drawer-header.tsx:95`) tracks the same change.
