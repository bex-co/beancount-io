## Objective

Add one module that owns the list of ledger-derived GraphQL documents and invalidates them by scope, so no screen has to hand-maintain a `refetchQueries` array again. It does two things per call: refetch the matching **active** queries, and evict the corresponding root fields from the cache so unmounted screens and `cache-first` queries do not serve pre-write data.

## Context

- The cache is a bare `new InMemoryCache()` (`src/common/apollo/cache.ts:3`) — no `typePolicies`, so root fields are keyed by field name + args and nothing invalidates them implicitly.
- `client.refetchQueries({ include: [...] })` only reaches **active** observable queries. `app/(app)/(tabs)/_layout.tsx:50` sets `lazy: false`, so all five tabs are active — but account-detail, budget and the reports sub-cards are not, and `use-budget-actuals.ts:63` / `use-budget-groups.ts:44` are `cache-first`. Refetch alone is not sufficient; evict alone loses the immediate repaint.
- Three scopes, by blast radius:
  - `errors` — `GetLedgerErrorsDocument` only. Cheap; safe to fire on every save.
  - `entries` — a single transaction/directive changed: `GetLedgerJournalDocument`, `BalanceSheetDocument`, `TrialBalanceDocument`, `AccountReportDocument`, `AccountJournalDocument`, `IncomeStatementDocument`, `GetLedgerIntervalTotalsDocument`, `LedgerMetaDocument`, `GetLedgerErrorsDocument`, `ListCommitsDocument`.
  - `file` — a whole file changed: everything in `entries`, plus `GetLedgerDirContentDocument`, `GetLedgerNarrationsDocument`, `GetLedgerPayeesDocument`, `GetLedgerPayeeAccountsDocument`.
- Do **not** use `include: "active"` — it would re-run `suggestTransactionCategories` (an LLM call) and `getFeed`, neither ledger-derived.
- `HomeChartsDocument` must not appear in any scope: nothing calls `useHomeChartsQuery`, so it is a silent no-op today. Home's net-worth chart reads `balanceSheet`, which is in `entries`.
- Keep the root-field name for each document derivable in one place — a `[document, rootFieldName]` table beats re-parsing the AST at call time.
- Import the `*Document` constants from `src/generated-graphql/graphql` (read-only; never hand-edit that directory).

## Steps

1. Create `src/common/apollo/invalidate-ledger.ts` exporting `LedgerInvalidationScope = "errors" | "entries" | "file"` and `invalidateLedgerData(client, scope)`.
2. Define the scope → `[document, rootField]` table, with `file` composed from `entries` so the two cannot drift.
3. Implement: `client.refetchQueries({ include })`, then `cache.evict({ fieldName })` per root field, then one `cache.gc()`.
4. Swallow and log failures — the write already committed; an invalidation failure must never be reported to the caller as a write failure (same reasoning as the comment in `use-open-account.ts:36` and `refetchBudgetJournal`).
5. Decide and document the await semantics: callers that navigate away immediately should not block on it.
