## Objective

Meaningful unit tests for the behavior this milestone shipped, green under `yarn test:unit`: the sign-out purge fires (and the test fails when the call is removed), the staleness state machine transitions correctly (cached+refetch-failed → stale; refetch-success → clear; no-cache+failed → error, not stale), and the fetch-policy decisions are pinned so a future edit that silently reverts `use-balance-sheet.ts` to `network-only` fails a test rather than a subway ride.

## Context

- jest-lite constraints: relative imports for value modules; limited matcher set (`toBe`/`toEqual`/`toBeCloseTo`/`toBeTruthy`/`toBeFalsy`/`toThrow` + `.not`).
- The staleness hook should be written as a pure decision function + thin hook so the decision table is testable without renderer machinery.
- Break-each-test-once discipline (m32): every new assertion is seen to fail before it counts.

## Steps

1. Purge test: sign-out path invokes `persistor.purge()` + `clearStore()`.
2. Staleness decision table: all four (cache?, refetch-ok?) combinations.
3. Policy pin: assert the audited hooks export/declare their intended `fetchPolicy`.
4. Break each once; restore; full suite green.
