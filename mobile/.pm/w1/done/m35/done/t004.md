## Objective

The directory renders: one row per payee — brand logo, name, "N transactions", last-transaction date — fed by the t001 query through the t002 selector, with a house-rules skeleton, pull-to-refresh, and empty/error states.

## Context

- Logos are free: `AccountTypeIcon` with `brandText={payee}` already resolves curated brands via `src/common/brand-matcher/` + logo.dev, with per-domain error fallback (m13).
