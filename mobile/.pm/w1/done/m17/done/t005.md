## Objective

Stop showing a skeleton on every picker open: when the ledger-meta query is already in the Apollo cache (Home/Accounts/Reports fetch it), render the list immediately and refresh in the background. Scope the fetch-policy change to the picker so other callers keep their current behavior.

## Context

- `src/common/hooks/use-ledger-meta.ts:13` hardcodes `fetchPolicy: "network-only"`, so the picker refetches (and skeletons) on every mount.
- Apollo cache is a bare `new InMemoryCache()` (`src/common/apollo/cache.ts`) — no type policies needed for this; `cache-and-network` on the picker path suffices.

## Steps

1. Add an options parameter to `useLedgerMeta` (default preserves `network-only`).
2. Pass `cache-and-network` from the account-picker screen.
3. Confirm the skeleton still shows on a cold cache (first open after launch).

## Files

- `src/common/hooks/use-ledger-meta.ts`
- `src/screens/account-picker-screen/account-picker-screen.tsx`

## Acceptance criteria

- [ ] Second open of the picker in a session renders the list with no skeleton
- [ ] Data still refreshes in the background (stale accounts update after fetch)
- [ ] Other `useLedgerMeta` callers' fetch behavior is unchanged
