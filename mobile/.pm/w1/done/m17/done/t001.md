## Objective

Create an alias-free pure module implementing fava-style fuzzy matching for account names — subsequence matching (pattern characters in order, gaps allowed), exact substrings ranked first, a bonus for consecutive-character clusters, lowercase pattern characters matching both cases — plus a segment-start bonus tuned for `:`-separated beancount accounts. Ship it with unit tests.

## Context

- Reference semantics: fava's `frontend/src/lib/fuzzy.ts` — exact substring scores `pattern.length ** 2`; scattered subsequence accumulates a local score that resets on gaps; lowercase pattern chars match case-insensitively, uppercase require exact match. Result: `exfo` matches `Expenses:Food` in fava's editor today — match that muscle memory.
- Must mirror `src/common/suggestion-utils.ts`: no runtime `@/` imports so the jest-lite runner can `require` it (type-only imports are fine — they are erased).
- jest-lite provides only `toBe` / `toEqual` / `toBeCloseTo` / `toBeTruthy` / `toBeFalsy` / `toThrow` (+ `.not`) — write assertions accordingly.

## Steps

1. Add `src/common/account-search.ts` exporting `fuzzyMatch(pattern, text)` (score, 0 = no match) and `filterAccounts(pattern, accounts)` (matches sorted by descending score).
2. Add a segment-start bonus so matches beginning at a `:` boundary (e.g. `fo` against `Expenses:Food`) outrank mid-segment scatter.
3. Add `src/common/__tests__/account-search.test.ts` using relative imports.
