## Objective

Make the picker honor the `selectedItem` route param that callers already pass: visually highlight the caller's current account and scroll it into view on open.

## Context

- Callers pass `selectedItem` (e.g. `src/screens/add-transaction-screen/add-transaction-next-screen.tsx:352`) but the screen reads only `type` (`account-picker-screen.tsx:73`) — the param is currently dead.

## Steps

1. Read `selectedItem` from the route params.
2. Style the matching row as selected (theme tokens, both themes) and scroll the virtualized list to it on first render.

## Files

- `src/screens/account-picker-screen/account-picker-screen.tsx`

## Acceptance criteria

- [ ] Opening the picker with a current value shows that row highlighted and scrolled into view
- [ ] Opening with no `selectedItem` behaves as before (no crash, top of list)

## Out of scope

- Multi-select or checkmark-per-row semantics
