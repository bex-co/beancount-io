## Objective

The merchant view opens with a stats header: transaction count, first/last dates, and totals **bucketed per currency** (never summed across currencies — the `selectTransactionAmount` rule). Data via a second fixed `queryShell` statement filtered to the payee.

## Context

- Payee names are arbitrary user text — quotes, backslashes. Interpolating one into a BQL `WHERE payee = "..."` needs a **tested escaping helper**; a payee named `He said "hi"` must not break or alter the query.
- Statement shape to validate against the backend (adjust to the accepted dialect): per-currency count/sum/min/max grouped by currency for one payee.

## Steps

1. `src/screens/merchant-detail-screen/selectors/escape-bql-string.ts` — pure, relative imports, unit-tested (quotes, backslashes, empty, unicode).
2. Per-payee rollup query + `selectors/merchant-stats.ts` mapping rows → per-currency stat lines.
3. Header UI: name + logo (brand-matcher), count, date span, per-currency totals with fixed `lineHeight`s so the skeleton can mirror it.
