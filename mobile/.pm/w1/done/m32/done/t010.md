## Objective

Meaningful unit tests under `src/__tests__/` for the behavior this milestone shipped — asserting real behavior and failure modes, not snapshots.

## Context

- jest-lite runner constraints (board memory): value modules must use **relative** imports (`@/` resolves for type imports only); matchers limited to `toBe` / `toEqual` / `toBeCloseTo` / `toBeTruthy` / `toBeFalsy` / `toThrow` + `.not`.
- The t001 stream fixture shapes the parsing/rendering assertions.

## Steps

1. Transport construction: headers carry Bearer + `Accept-Language`, body carries `ledgerId`/`sessionId`, `expo/fetch` is the fetch.
2. Approval guard: a message whose last assistant part is `approval-requested` flips the awaiting flag; no approval response is ever produced.
3. Deep-link prefill: `q` lands in input state, send is not called.
4. Session reset: New chat yields a fresh `sessionId` and the reseeded welcome thread.
5. Quota-vs-retryable error classification (t005's split).

## Outcome — done 2026-08-19

`src/__tests__/agent-chat.test.ts` — 43 tests over the transport contract, error classification, the markdown reader, part joining, the deep-link rule, the write-tool refusal, the silent-turn guard, and the preset strings. Suite total 1348 → **1389, all green**, alongside `yarn lint` and `tsc`.

Every unit was **deliberately broken once** to confirm its test bites (the m31/t010 discipline). Ten breaks, ten failures: dropping `credentials: "omit"`, swapping `expo/fetch` for the global, removing the Bearer header, forgetting to stop the stream on New chat, typoing the approval state, letting the silent-turn notice fire mid-stream, auto-submitting the deep link, joining step texts with nothing, and reversing the fence/span order.

**That pass found a real hole rather than confirming a good one.** Deleting `credentials: "omit"` first came back green. The assertion scanned the source for the string — and the paragraph above the code explains the setting by name, so the _comment_ satisfied it. The line could have been deleted and the test would have kept passing, on the milestone's most security-relevant behaviour. `read()` now strips comments before any source assertion.

The fence/span ordering test also caught a genuine bug on first run: code spans were replaced before fences, so ``` left two stray backticks behind.
