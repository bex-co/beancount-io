## Arbitration under real drags — A/B against the pre-change code

`expo-mcp`'s prebuilt XCUITest driver has no swipe (its binary dispatches on five
action strings only: `tapByCoordinates`, `tapByAxId`, `findElementByAxId`, two
screenshots), and synthetic CGEvent input no longer reaches this Simulator.
Rather than install `idb`/Maestro, a throwaway XCUITest bundle was built in the
scratchpad — no change to `ios/`, nothing installed — attaching to the installed
app by bundle id (`XCUIApplication(bundleIdentifier: "io.beancount.ios")`) and
driving `press(forDuration:thenDragTo:)` at coordinates passed through the
`.xctestrun`'s `EnvironmentVariables`. Real HID drags, same pipeline as a finger.

Read by temporarily suppressing the release-reset so a drag _parks_ the cursor at
its end point; where the cursor lands says how far the gesture was tracked. The
same suppression was applied to the stashed pre-change implementation so the two
are read the same way.

| drag (logical pts, y=330) | before (PanResponder)  | after (Gesture.Pan)    |
| ------------------------- | ---------------------- | ---------------------- |
| mid-plot 100 → 320        | parks x≈306, `· NOV`   | parks x≈306, `· NOV`   |
| edge-overlap 20 → 140     | parks index 0, `· JUL` | parks index 0, `· JUL` |

- **Tracking:** the mid-plot drag is followed the whole way — the cursor ends on
  the point nearest x=320, not where the finger landed. Identical before and after.
- **Carousel:** neither implementation pages `SegmentedPages` during a 220pt
  horizontal drag on the plot; the tab stays on Net Worth. The scrub wins the race
  against the paging `ScrollView` exactly as it did before.
- **Drawer:** a drag starting at x=20 — inside the card but inside the drawer's
  8pt-activation edge strip — has its touch-down honoured (cursor appears at index 0) and is then taken by the drawer's pan, which settles back closed. **This is
  pre-existing**: the old PanResponder behaves identically. x=4 is outside the card
  (`contentPadding` = 16) and was never a scrub in either version.
- No regression against drawer or carousel: every observed difference is nil.
