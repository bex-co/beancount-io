## Objective

Give Edit Transaction the same useful symbol and date insertion bar as the mobile ledger file editor, positioned above the keyboard on both platforms.

## Context

- `KeyboardAccessoryBar` provides date, flags, paired quotes, colon, configured currencies, indent, minus, tags, and links.
- CodeEditor's `insertSpec` uses a sequence number, selection replacement, and an optional cursor offset; paired quotes place the cursor inside them.
- The file editor uses keyboard events, safe-area overlap, and editor bottom padding to keep text accessible.

## Steps

1. Reuse `KeyboardAccessoryBar` and `useLedgerMeta` for the current ledger's operating currencies; preserve omission when none are configured.
2. Connect actions to CodeEditor's insertion mechanism, including consecutive identical actions and replacement of selected text.
3. Reuse the keyboard overlap calculation from the file editor. Extract a small shared native helper only where both screens need the same behavior; keep imports inside mobile.
4. Coordinate editor scrolling, keyboard height, and safe-area insets without duplicate keyboard avoidance. Show the bar only when the editor is ready, writable, and the keyboard is visible.
5. Provide accessible action labels through `useTranslations()` where symbols alone do not describe the action.

## Acceptance criteria

- [ ] All existing file-editor shortcuts work in Edit Transaction with the current ledger's currencies.
- [ ] Paired quotes place the caret inside; repeated actions are not lost; selected text is replaced correctly.
- [ ] Actions preserve editing focus and the caret remains above the keyboard/bar on iOS and Android.
- [ ] Hardware-keyboard use, keyboard dismissal, safe areas, light/dark themes, and read-only states have usable layouts.
- [ ] Both screens use the same bar and insertion semantics with no new dependency.

## Out of scope

- Account completion, dedicated Undo/Redo buttons, Add Posting, More menus, or additional syntax shortcuts.
