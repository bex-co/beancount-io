## Objective

Let the big net-worth figure count to its value while the line draws in, so the number and the chart arrive as one gesture rather than the number popping and the chart following.

## Context

- The headline lives in `src/common/d3/interactive-line-chart.tsx:257-267` (styles :73-87), at `fontSizes.display` (28) from `src/common/theme/typography.ts:60`.
- It renders through `src/components/amount-text/index.tsx:29-41` — a plain RN `<Text>` with `fontVariant: ["tabular-nums"]` (`typography.ts:80-81`) and a Dynamic Type cap. Tabular figures mean digits will not jitter while counting.
- Formatting: `formatMoneyWithCurrency` / `formatSignedMoneyWithCurrency` in `src/common/number-utils.ts:104,117`.
- **Critical constraint:** the same headline is what the scrub updates (`interactive-line-chart.tsx:250-268`, scrub label at :248). During a scrub the value must track the finger exactly — a tween there would lag the touch and break the interaction. Animate on first paint and range change only.
- `AmountText` is shared and also renders list rows (`components/account-table/account-table.tsx:251-253`). Do not make it animate globally.

## Steps

1. Add a narrowly-scoped animated variant (e.g. `AnimatedAmount`) rather than changing `AmountText`'s default behavior. Keep the same typography, tabular figures and Dynamic Type cap so nothing shifts.
2. Drive it from a shared value with the same duration/easing token as t002's draw-in so the two finish together.
3. Format on the UI thread via `useAnimatedProps` on a `TextInput` `value`, or via `useAnimatedReaction` + `scheduleOnRN` to set formatted text. If routing to JS, import `scheduleOnRN` from `react-native-worklets` — `runOnJS` is deprecated in worklets 0.10 and `react-native-reanimated` does not re-export the replacement.
4. Count from zero on first paint; on a range change, count from the previous value to the new one.
5. Bypass the tween entirely while `scrubIndex` is non-null — the scrubbed value is set directly.
6. Reuse the existing currency formatter so grouping, sign and currency symbol are identical to the static render at every frame.

## Files

- `src/components/amount-text/index.tsx` (or a sibling animated variant)
- `src/common/d3/interactive-line-chart.tsx`

## Acceptance criteria

- [ ] On first paint the headline counts from zero to its value, finishing with the line draw-in.
- [ ] Scrubbing updates the headline instantly with no tween or lag.
- [ ] The counting value is formatted identically to the static one at every frame (currency symbol, grouping, sign).
- [ ] With reduce-motion on, the final value renders immediately.
- [ ] `AmountText`'s behavior everywhere else (account table rows, breakdowns, budget stats) is unchanged.
- [ ] Digits do not reflow while counting (tabular figures preserved).

- Any other headline in the app (Reports section totals `category-breakdown.tsx:284-286`, budget stat trio `budget-group-card.tsx:217-235`).
