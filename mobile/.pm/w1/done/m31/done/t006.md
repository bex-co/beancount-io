## Objective

The ledger drawer — the app's primary navigation surface since m5 moved Settings into it — is hand-rolled and slides in from the left. Under RTL it must come from the right, including its edge-swipe zone and its shadow, or the main navigation gesture points the wrong way on every screen.

## Context

- `src/components/ledger-drawer/ledger-drawer.tsx` positions the panel with `left: 0` and animates `transform: [{ translateX: progress.value * drawerWidth }]`. Neither mirrors automatically: `left` is physical, and Yoga does not touch `transform`.
- The edge-swipe zone is `.hitSlop(open ? undefined : { left: 0, width: EDGE_HIT_WIDTH })` (around line 300) — also physically left.
- The shadow leans left: `shadowOffset: { width: -4, height: 0 }` (line 76). It should lean away from the panel, so the sign flips with the direction.
- `src/components/ledger-drawer/drawer-motion.ts` is the motion math, deliberately import-free so the gesture worklets and the unit tests share it — `clampProgress`, `settleTarget`, `RELEASE_PROJECTION_SECONDS`. **It works in `progress` units (0 = closed, 1 = open), which are already direction-free.** Do not add direction to it; keep the file import-free and let the caller map progress to a signed translation. Its existing tests in `src/components/ledger-drawer/__tests__/` must keep passing untouched.
- `src/components/ledger-drawer/ledger-drawer-header.tsx` also has absolute positioning (`t004` leaves both drawer files to this task).
- Gesture direction matters too: opening is a swipe from the leading edge inward, so the sign of the horizontal delta the gesture applies to `progress` flips as well. Getting the panel right but not the gesture yields a drawer that closes when you drag it open.

## Steps

1. Read the direction once per render from the `t001` module rather than sampling `I18nManager.isRTL` at several points in the file.
2. Convert `left: 0` to the logical equivalent so the panel is pinned to the leading edge.
3. Make the translation signed: closed sits off the leading edge in both directions, so the `translateX` expression carries a direction factor.
4. Flip the edge hitSlop to the leading edge, and the `shadowOffset.width` sign with it.
5. Flip the sign of the gesture's horizontal delta → `progress` mapping, so dragging inward opens in both directions.
6. Leave `drawer-motion.ts` and its tests alone.
