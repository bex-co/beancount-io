## Objective

Cover the parts of RTL that are logic rather than pixels — the direction predicate, the reload decision, and the icon mapping — with tests that fail when the behavior is wrong, not tests that restate it.

## Context

- Three things here are real logic with real failure modes: (a) `isRtlLocale` over all thirteen locales, (b) `applyLayoutDirection`'s "did the flag actually change" answer, which is what decides whether the app reloads, and (c) `directionalIcon`'s mapping, including the pass-through for vertical chevrons.
- The highest-value assertion is the **negative** one: launching in an LTR locale, and re-launching in Persian when the flag already agrees, must **not** reload. A reload loop at boot is the worst failure this milestone can ship and it is invisible in a single manual launch.
- `t002`'s branch is testable without a simulator: given a previous and a next locale, does the direction change? Twelve-by-thirteen is small enough to assert exhaustively rather than by sample.
- Constraints from this repo's test setup, both already recorded: **jest-lite has no `@/` path alias** — test-reachable modules must use relative imports for values (`@/` works only for type imports) — and it has a **limited matcher set**: `toBe` / `toEqual` / `toBeCloseTo` / `toBeTruthy` / `toBeFalsy` / `toThrow` plus `.not`. No `toHaveLength`, no `toBeNull`.
- `I18nManager` has to be stubbed; assert against the stub's recorded calls rather than against a real native flag.
- The bar m29/m30 set: prove the tests bite. Stub the unit under test to a wrong answer and confirm a specific count of failures, and record that count in the outcome note.

## Steps

1. Add `src/common/__tests__/rtl.test.ts` covering `isRtlLocale` across all thirteen `SUPPORTED_LOCALES` — `fa` true, the other twelve false — so adding a locale without classifying it is caught.
2. Cover `applyLayoutDirection`: flag already correct → returns false and calls no setter; flag wrong → calls `allowRTL(true)` and `forceRTL` with the right value and returns true. Both directions.
3. Cover the direction-change predicate `t002` uses, exhaustively over locale pairs: only pairs crossing the `fa` boundary require a restart.
4. Cover `directionalIcon`: both mirrored pairs in both directions, and pass-through for `chevron-down` / `chevron-up` / an unknown name.
5. Verify the tests bite — break each unit deliberately, record how many tests fail.
