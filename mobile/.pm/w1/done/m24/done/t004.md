## Objective

## Context

- `src/components/time-range-pills/` already has the exact pill shape and accessibility wiring the picker needs.
- Three blockers, all small: its row is a centered non-scrolling `View` (the picker needs horizontal scroll), it fires haptics on every change, and its `T extends string` value cannot carry the picker's `null` "All" sentinel.
- **Land `w1/m20/t011` first** — it fixes the indicator origin in this same file.
- The journal filter pills from the original note are gone with `w1/m22/t001`.

## Steps

1. Add optional `scrollable` and `haptics` props and widen the value type to allow `null`.
2. Adopt in the account picker; delete its local chip implementation.
3. Verify the indicator still lands correctly in the scrollable case — including when the selected chip starts off-screen.
