# Tab icons don't animate on focus, and always use the filled variant

`app/(app)/(tabs)/_layout.tsx:56-114` — each `tabBarIcon` is a static `<Ionicons size={28} color={focused ? theme.primary : color} />`. Two things follow:

- **No motion on focus.** No scale, no bounce, no outline→filled morph. The active tab is a hard color swap.
- **Always the filled variant**, regardless of `focused`, so colour is the only signal distinguishing the active tab. Most iOS tab bars use outline for inactive and filled for active, which reads at a glance and does not depend on hue.
