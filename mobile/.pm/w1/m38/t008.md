## Objective

Produce and visually verify the first three conversion assets for every target App Store localization on both supported display types.

## Context

- Target localizations are `en-US`, `zh-Hans`, `ca`, `de-DE`, `es-ES`, `es-MX`, `fr-FR`, `fr-CA`, `nl-NL`, `pt-BR`, `pt-PT`, `ru`, `sk`, and `uk`.
- Target display types are `APP_IPHONE_65` and `APP_IPAD_PRO_3GEN_129`.
- Bulgarian and Persian users inherit the primary store assets because Apple does not expose matching metadata localizations.

## Steps

1. Capture or prepare the three current demo-ledger source screens on iPhone and iPad without writing to a production ledger.
2. Run the localized screenshot build for all 14 target localizations and both display types.
3. Inspect every output for translation fit, misleading UI/caption mismatch, sensitive data, dimensions, alpha, and intended filename order.
4. Rebuild from clean generated output and confirm the manifest produces the identical set.

## Files

- `mobile/docs/marketing-showcase/`
- `mobile/metadata/screenshots/`
- Manifest and build inputs created by `w1/m38/t007`.

## Acceptance criteria

- [ ] Exactly three ordered assets exist for every target locale and both display types.
- [ ] Each asset is locale-native, legible, dimension-correct, opaque, and backed by deterministic demo data.
- [ ] Clean regeneration produces the same names, count, order, and dimensions.
- [ ] No screenshot contains production user, account, ledger, notification, or credential data.
