## Objective

Create locale-native canonical App Store metadata for Catalan, German, Spanish, French, Dutch, and Portuguese storefronts.

## Context

- Canonical app-level files live at `mobile/metadata/app-info/<locale>.json`.
- Canonical version-level files live at `mobile/metadata/version/<version>/<locale>.json`.
- Spanish, French, and Portuguese require distinct regional metadata files where Apple exposes distinct storefront localizations.

## Steps

1. Add app-info metadata for `ca`, `de-DE`, `es-ES`, `es-MX`, `fr-FR`, `fr-CA`, `nl-NL`, `pt-BR`, and `pt-PT`.
2. Add the matching next-version descriptions, promotional text, support/marketing URLs, and fresh release notes.
3. Adapt accounting terminology and tone for each region rather than copying one machine translation into both regional variants.
4. Check every field's code-point limit and verify URLs resolve without locale-specific dead ends.

## Files

- `mobile/metadata/app-info/{ca,de-DE,es-ES,es-MX,fr-FR,fr-CA,nl-NL,pt-BR,pt-PT}.json`
- `mobile/metadata/version/<next-version>/{ca,de-DE,es-ES,es-MX,fr-FR,fr-CA,nl-NL,pt-BR,pt-PT}.json`

## Acceptance criteria

- [ ] All nine target app-info and version-localization files exist and parse as canonical JSON.
- [ ] Name, subtitle, promotional text, and description stay within Apple's limits.
- [ ] Regional variants use natural, reviewed wording and are not blind duplicates.
- [ ] Copy accurately describes the shipped app and avoids unverifiable superlatives or keyword stuffing.

## Out of scope

- Bulgarian, Persian, Slavic, English, and Chinese listing files handled by other tasks.
