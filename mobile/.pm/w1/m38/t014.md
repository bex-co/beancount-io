## Objective

Add meaningful automated and fixture-level coverage for locale completeness, version scaffolding, keyword rules, screenshot generation, and release-order failure modes.

## Context

- The risky failures are silent omissions, stale localized release notes, invalid field limits, duplicate indexed phrases, leaked user data, wrong screenshot order, and auto-submit before assets are staged.
- Remote ASC writes cannot be a routine unit-test dependency; plan parsing and orchestration should use fixtures while the final workflow is verified against the real editable version.

## Steps

1. Test exact locale-manifest coverage, regional variants, and the explicit Bulgarian/Persian fallback classification.
2. Test `yarn bump` scaffolding, fresh `whatsNew` gating, version parity, and preservation of Android changelog behavior.
3. Test keyword length/separators/title-subtitle overlap and screenshot manifest count/order/dimensions/opacity with representative long and Cyrillic/CJK captions.
4. Test that release orchestration refuses a non-editable target or missing metadata/screenshot plan and cannot apply without confirmation.
5. Run `yarn format:check`, `yarn lint`, `yarn typecheck`, and `yarn test:unit` from `mobile/`, plus the repository guidance and secret checks when applicable.

## Files

- `mobile/src/scripts/**/__tests__/` or the package's established script-test location.
- `mobile/scripts/` validation fixtures/tests.
- Metadata and screenshot fixtures containing demo data only.

## Acceptance criteria

- [ ] Tests fail for a missing/extra locale, stale release note, over-limit field, indexed-phrase overlap, wrong asset order, alpha channel, and premature apply/release.
- [ ] Tests cover Bulgarian/Persian fallback without removing their in-app translations.
- [ ] Remote-operation tests use fixtures or dry-run plans and never require committed credentials.
- [ ] All affected mobile and repository checks pass without hand-editing a lockfile.

## Out of scope

- Tautological snapshots or tests that call production mutation endpoints in routine CI.
