## Objective

Add the Sankey layout engine. **This is a new dependency** (repo rule: ask the user before adding dependencies) — flagged in the 2026-08-19 `/pm-brainstorm` and approved by the owner when handing this milestone to `/pm` the same day. `d3-sankey` is ~10KB of pure JS layout math (no DOM), and `@types/d3-sankey` is required by strict TypeScript.

## Context

- `d3-sankey` is **not** part of the installed d3 bundle (`d3-hierarchy`, `d3-interpolate`, `d3-ease`, `d3-scale-chromatic` are — see `w1/020`); the web reaches Sankey through ECharts, which mobile does not use.
- `mobile/` pins Yarn 1.22.22 — run `yarn add` from inside `mobile/`, never hand-edit `yarn.lock`.
- Memory note: Yarn 1 has an add-invariant quirk on this tree (see the Expo 57 upgrade notes) — if `yarn add` fails on an unrelated invariant, add the entry to `package.json` and run `yarn install`.

## Steps

1. `yarn add d3-sankey` and `yarn add -D @types/d3-sankey` from inside `mobile/`.
2. Confirm `yarn typecheck` resolves `sankey()`, `sankeyLinkHorizontal()` types.
3. Confirm the bundle builds (`npx expo start` boots Metro cleanly).

- `package.json`, `yarn.lock` (via yarn only)
