## Objective

Translate the 175 `en.ts` keys that `src/translations/sk.ts` currently inherits instead of declaring, so Slovak users read the whole app in Slovak, and delete `sk` from the `KNOWN_GAPS` baseline.

## Context

- `src/translations/sk.ts` — declares 143 of the base's 318 top-level keys today, the widest gap on the board.
- `src/translations/en.ts` — the source of truth; translate against the English **value** and use the surrounding `//` group comments to place each key on its screen.
- Missing groups: multi-posting entry, open-account, the journal's directive types, reports/dashboard cards and range chips, transaction edit/delete, AI receipt capture, notifications and commit detail, the ledger file list and editor, and budgets.
- Slovak declension around `{{account}}` / `{{interval}}` in the budget and edit-conflict messages: phrase the carrier sentence so the inserted value stays nominative.
- The m29 gate is live: an unknown key or a dropped `{{token}}` fails `yarn test:unit`.
- The six m29 locales are already complete — read `zh.ts` or `de.ts` for how a group was rendered there before inventing a new phrasing.

## Steps

1. Run the integrity suite to get the exact missing list for `sk`.
2. Translate each key in `en.ts` order, under the same `//` group comments, so the files stay diffable side by side.
3. Preserve every `{{token}}`; keep button and chip labels short enough for their control.
4. Reuse the terminology already in this file for terms it already translates (account types, "ledger", "transaction", "budget").
5. Remove the `sk` entry from `KNOWN_GAPS`.
6. `yarn lint` / `yarn typecheck` / `yarn test:unit`.
