## Objective

Give the app a shared motion vocabulary — named durations, easings and spring presets — plus a reduce-motion hook, so every later task in this milestone (and every future screen) reaches for a token instead of inventing another magic number.

## Context

- There are no motion constants anywhere in `src/common/theme/`. Grep for `duration|easing|Easing|animation|motion|spring` across `src/common/theme/*.ts` returns zero hits.
- Eleven magic durations are scattered across the app today: `loading-tile/index.tsx:49-50` (`300`/`300`), `picker/index.tsx:167,168,172,173` (`300` ×4), `text-input-modal/index.tsx:134-138` (`200` in / `150` out), `progress/index.tsx:26` (`500` default prop), `toast-provider/index.tsx:63,64,88` (`300`/`300`/`2000`), `common/progress-bar.tsx:35` (`200`).
- `src/common/theme/spacing.ts:1-15` carries a doc comment explaining exactly why a shared scale exists ("the hard-coded pixel values that used to live per-file drifted apart"). That argument applies verbatim to motion; follow its shape and tone.
- `src/common/theme/index.ts` re-exports from `./typography` and `./spacing` — `./motion` is the third sibling.
- No `Easing` import exists anywhere in the codebase; every `withTiming` currently runs Reanimated's default easing.
- Reanimated 4.5.1 defaults every animation to `ReduceMotion.System` (`ReduceMotion` is exported from `react-native-reanimated`), so `withTiming`/`withSpring` already land at their end state when the OS setting is on. The hook is for what Reanimated does not own: looping shimmer, staggered reveal scheduling, and anything driven by `useFrameCallback`.
- Reanimated's own `useReducedMotion()` is exported and synchronous, but its JSDoc notes it is an **app-start snapshot** that does not re-render on change. Wrap `AccessibilityInfo` instead so a mid-session toggle takes effect.
- Hook naming/location convention: `src/common/hooks/use-translations.ts`, `use-session.ts`.
- No new dependencies — everything needed is installed.

## Steps

1. Add `src/common/theme/motion.ts` exporting a `durations` scale (roughly: `instant`, `fast` ~150ms, `base` ~250ms, `slow` ~400ms, `chart` ~450ms), an `easings` set built on Reanimated's `Easing` (a standard ease-out for entrances, ease-in-out for morphs), and a `springs` set. Reuse Reanimated's `SnappySpringConfig` where it fits — `components/ledger-drawer/ledger-drawer.tsx:53` already uses it.
2. Keep the whole module free of app imports so it stays worklet-safe and unit-testable, matching `components/ledger-drawer/drawer-motion.ts`.
3. Open with a doc comment in the style of `spacing.ts:1-15`, naming the drift it exists to prevent and stating the motion budget: entrance/transition motion stays under 500ms, direct feedback under 300ms.
4. Re-export from `src/common/theme/index.ts` alongside `./typography` and `./spacing`.
5. Add `src/common/hooks/use-reduce-motion.ts`: seed from `AccessibilityInfo.isReduceMotionEnabled()`, subscribe with `AccessibilityInfo.addEventListener("reduceMotionChanged", cb)`, and `.remove()` on unmount.
6. Do **not** ship `<ReducedMotionConfig mode={ReduceMotion.Never} />` anywhere — it would override the user's accessibility setting app-wide.
