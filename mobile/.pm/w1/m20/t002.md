## Objective

Make the net-worth / assets / liabilities line chart draw itself in when data first lands, instead of appearing fully formed in one frame — the single most visible piece of this milestone, and the behavior the web dashboard already has.

## Context

- `src/common/d3/interactive-line-chart.tsx` — the chart. Geometry is built in one `useMemo` (:147-180): `scaleLinear` for y (:152-154), a hand-rolled linear x map (:155-158), `d3Line(...).curve(curveMonotoneX)` (:161-165), `d3Area().y0(baseline)` (:166-171).
- SVG nodes today: `<Defs><LinearGradient id="netWorthFill">` (:275-280), area `<Path fill="url(#netWorthFill)">` (:282), dashed baseline `<Line strokeDasharray="4,3">` (:285-295), line `<Path strokeWidth={2.5}>` (:297-304), scrub cursor (:307-326), resting end dot `<Circle r=4>` (:329-338).
- Consumers: `src/screens/home-screen/components/account-charts-card.tsx:98` and `src/components/balance-chart-card/index.tsx:68`.
- The file imports no animation API today. Nothing in `src/common/d3/` does.
- Web parity: `dashboard/src/features/reports/balance-sheet/line-chart.tsx:162-164` — 1000ms `cubicOut`. Aim shorter here (chart token from t001, under 500ms) since mobile first paint follows a skeleton.
- The chart is wrapped in `ErrorBoundary fallback={null}` (:356), so a render throw silently collapses it to zero height — be careful not to introduce one.

## Steps

1. Compute the line's total length by summing your own segment lengths (`Σ hypot(dx, dy)`) over the already-computed point array, inside the existing `useMemo`. Do **not** use `getTotalLength()`: react-native-svg's own source flags it experimental, it is a synchronous JS-thread-only TurboModule call, and it has open bugs (svg#1943).
2. Animate the stroke on with `strokeDasharray` / `strokeDashoffset` via `useAnimatedProps` on an `Animated.createAnimatedComponent(Path)`, driven by a single shared value and the `chart` duration/easing tokens from t001.
3. **Render numeric dash values from the very first frame.** Transitioning `strokeDasharray`/`strokeDashoffset` from `undefined` to a number silently fails on iOS (svg#2200).
4. Fade the gradient area `Path` in behind the stroke (opacity only — cheaper than clipping, and one animated prop).
5. Fire the draw-in once per data arrival, not on every re-render. Key it on the series identity so a scrub or a theme change does not replay it.
6. Keep the scrub cursor and resting end dot as the only other animated nodes; do not add new SVG children (whole-`<Svg>` repaint means node count is what costs).
7. Leave the reduce-motion path to Reanimated's `ReduceMotion.System` default — verify the chart simply appears complete with the setting on.
