## Objective

Replace Edit Transaction's plain text input with the existing CodeEditor while retaining lossless source editing and trustworthy transaction saves.

## Context

- `src/screens/edit-transaction-screen/edit-transaction-screen.tsx` currently controls a multiline TextInput through React state.
- CodeEditor owns live text and exposes `requestSave`, document epochs, edit revisions, and a save callback returning success.
- Transaction saves use `updateLedgerEntrySourceSlice`; the file editor's `updateLedgerFile` operation is not appropriate for a source-slice edit.

## Steps

1. Mount CodeEditor in a bounded, flexible editor area after entry context is ready; add a themed loading skeleton and explicit unavailable-context state.
2. Seed the exact slice once for each loaded entry. Keep typing in CodeMirror and prevent query refetches from replacing an active draft.
3. Route the header Save action through the editor's current document snapshot into the existing transaction mutation, write-access flow, and `invalidateLedgerData(client, "entries")` path.
4. Preserve draft/dirty state on errors and edits made during a save. Verify that entry identity/checksum refresh supports a second save; follow the existing schema response without hand-editing generated code.
5. Prevent duplicate submissions, honor read-only access, and guard cancel/back navigation when the draft has changes.

## Acceptance criteria

- [ ] The fetched slice renders highlighted and retains all source text without automatic formatting.
- [ ] Save submits the latest editor snapshot with the correct ledger, entry identity, and checksum.
- [ ] Late loads, refetches, failed saves, and edits during a save preserve the draft and accurate dirty state.
- [ ] Two successive saves work; stale context reports an error without silently overwriting another change.
- [ ] Write access, loading/error states, and explicit dirty-draft discard behavior are covered.

## Out of scope

- Structured transaction forms, full-file writes, mutation/schema redesign, or automatic saving.
