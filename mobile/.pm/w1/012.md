# `homeCharts.graphql` is now orphaned

`src/common/graphql/queries/homeCharts.graphql` has no consumer. `w1/m19` removed its last two references — `HomeChartsDocument` sat in the `edit-transaction-screen` and `transaction-detail-screen` refetch arrays, where it was a silent no-op because nothing ever called `useHomeChartsQuery`. Home's net-worth chart reads `balanceSheet`; the spending card reads `getLedgerJournal`.

What still mentions it:

- `src/generated-graphql/` — `HomeChartsDocument`, `useHomeChartsQuery`, `HomeChartsResponse` (regenerated from the `.graphql` file; the schema-side `homeCharts` field belongs to the server and stays either way).
- `src/screens/home-screen/selectors/select-spending-compare.ts:45` — a comment noting that `homeCharts` returns net profit rather than the gross expense figure the card wants. Worth keeping as rationale even if the query goes.

Deleting the `.graphql` file and re-running `yarn codegen` would drop ~60 lines of generated code. Sub-hour, but it touches `src/generated-graphql/`, so it wants its own diff rather than riding along with unrelated work. Confirm first that nothing plans to use `homeCharts` — it returns a prebuilt chart payload that could suit a future Home card better than assembling one client-side.
