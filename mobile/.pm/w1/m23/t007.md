## Objective

Cover the two pieces of this milestone that are real logic rather than markup: the refresh appearance resolver and the tab icon's focused/unfocused mapping.

## Context

- Test conventions: `src/__tests__/` plus colocated `__tests__/`; the jest-lite runner needs relative imports for value modules (`@/` resolves for types only) and supports a limited matcher set.
- Prior art for theme-resolving tests: `src/__tests__/ledger-drawer-motion.test.ts`, `src/common/__tests__/haptics.test.ts`.

## Steps

1. Test the refresh config against both effective themes, including `themeVar === "system"`.
2. Test the icon mapping: every tab has a distinct outline/filled pair and no tab falls back to the filled variant when unfocused.
3. Run `yarn test:unit`.
