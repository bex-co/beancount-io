## Objective

Make native command capabilities discoverable through bea without a separately installed bean-* executable.

## Context

`bea example --help`, `bea treeify --help`, and enabled `bea price --help` show only help. `bea doctor region --help` hides FILENAME/REGION; `bea ingest archive --help` hides SRC/destination/overwrite/dry-run. Corresponding managed-native help displays those interfaces. Typer eagerly handles help before forwarding ctx.args (cli/src/cli/main.py:209–220 and doctor.py:40).

## Steps

1. Expose upstream usage/options through the existing process boundary while retaining bea-specific targeting and optional-feature instructions.
2. Cover every affected doctor operation/alias, example, treeify, price, and ingest operation; inspect check for the same gap.
3. Keep help usable before optional enablement and never silently install an optional feature merely to show its help; keep command registration/reference generation coherent.
