# Port the CLI off typer's private click so typer 0.29+ can install

**Chore · cli · medium · 1–2h · A2.** [239](./done/239.md) capped `typer<0.29` because typer 0.29.0 dropped its vendored `typer._click.types` and `ParamType`. Five frontend modules import typer's private click: `cli/utils.py` (`ParamType` for `NonEmptyPath`, `RawPath`, `IntoPath`), `native_command.py` and `single_value.py` (`_click.parser._OptionParser`), `main.py` (`_click.exceptions.NoArgsIsHelpError`) and `commands/list.py` (`_click.core.ParameterSource`). The cap keeps installs working but holds every user on an old typer, and the next typer change to the others will break again.

- **Do:** move the three path types to typer 0.29's own parameter types or a callback, and the rest to public typer API or `click` as a declared dependency (adding one needs the owner's approval, per the root `AGENTS.md`). Then lift the cap and relock with `uv`.
- **Acceptance:** `cli/pyproject.toml` allows typer 0.29; `python scripts/test-install.py` passes for the wheel and the sdist on a fresh resolve; `make check-all` passes; `grep -rn "typer\._click" cli/src` finds nothing.
