# Generalize sidebar resize to right-anchored layouts

The drag-to-resize rail in the shared shadcn sidebar primitive
(`dashboard/src/common/components/ui/sidebar.tsx`, `SidebarRail`) assumes a
left-anchored sidebar: it computes width as `clientX - wrapperLeft`. The
primitive still advertises `side="left" | "right"` and ships the matching
`group-data-[side=right]:…` styling, so the resize math is the one place that
silently assumes left. Documented in the rail's JSDoc for now.

Deferred because no `<Sidebar side="right">` exists anywhere in the app today
(every call site uses the default left). Cheap generalization when a right
sidebar is actually introduced: thread `side` through `SidebarContext` (the
provider already owns sidebar state) and compute symmetrically —
`side === "left" ? clientX - rect.left : rect.right - clientX`. ~2 lines + one
context field. Sub-hour; pick up only if/when a right-anchored sidebar lands.

Source: `/simplify` altitude review during w1/m3 (2026-08-16).
