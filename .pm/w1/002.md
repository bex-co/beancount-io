# MCP consent page strands the interaction uid

`dashboard/src/features/oauth/pages/consent.tsx` (`LedgerStep`, zero-ledger
branch) renders `<Link to="/auth/welcome">` — a real navigation off
`/oauth/consent?uid=…` with no way back, so an MCP client whose user has no
ledger yet has to restart the whole authorization. Open the ledger-creation
path in a new tab, or keep the `uid` in a return link so the interaction can
resume. Found during the 2026-08-27 mobile sign-in research; sub-hour.
