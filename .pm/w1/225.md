# Refusals echo caller input unbounded, and one hint names a removed `replace` operation

**Copy/robustness · backend-v2 · minor · ~35m · A1.** From `/qa-find-bugs-mcp`, 2026-11-10, production `beancount-mcp 1.0.0`, following every reachable MCP hint as an agent would (44 traced).

- **Unbounded echoes (MCP, REST and GraphQL):**
  - **Repro:** these refusals return the input in full:
    - `readLedgerFiles` with a 5000-character path gives "file not found: zzz…" (5021 characters).
    - `runBqlQuery` with `"SELECT "+"z"×5000` gives 5061.
    - `listLedgerEntries` with a 5000-character `directiveTypes` value gives 5031.
    - The `social/profile` username refusal is 3025.
    - REST `/query` and GraphQL echo the same.
    - A path containing `\u001b[31m` and `\r\n` comes back with ESC and CRLF intact.
  - **Controls:** the filter refusal (256-character cap) and the ledger-slug refusal do not echo.
  - **Cause:** echoed values are interpolated unbounded (e.g. `NotFoundError` "with ID '${id}'", `domain-errors.ts:90`, and the engine's BQL message). No clamp exists in `mcp-errors.ts` `envelopeFromThrown`, REST `error-middleware` or GraphQL `format-error`.
  - **Fix:** one shared helper clamps each echoed value (about 120 characters plus "…") and escapes C0 controls. Use it at `DomainError` construction or in all three translators, with a test per surface.
- **Stale hint:**
  - **Repro:** `updateLedgerFiles` with an `old_string` that matches many times hints "…or use `replace` to overwrite the whole file". The file item accepts only `{path, old_string, new_string}` or `{path, content, sha?}`.
  - **Cause:** `edit-ledger-files-tool.ts:282` keeps the operation name from before the w1/m38 split.
  - **Fix:** change it to "…or send the whole file as `content` (with its `sha` from `readLedgerFiles`)".
