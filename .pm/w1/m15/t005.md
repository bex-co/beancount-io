## Objective

Clear the polish issues from the review in one pass; each is a few lines.

## Context

- `cli/src/cli/commands/format.py`: the positional defaults to `.` and ignores global `--file`; `bea --file books/main.bean format` formats the working directory tree.

## Steps

2. `add transactions --from -` reads stdin; document it.
3. Shorten the five docstring first lines to under 60 characters; move detail to the second paragraph.
4. `init`: print the absolute path (or `~`-relative when under the home directory) in the "Next:" hint.
5. Pluralize "row was/rows were"; say "matches row N of this import" for in-batch duplicates; print "would format" lines as notes, not error details.
