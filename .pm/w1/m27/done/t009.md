## Objective

Prove exactness as a property, not as a handful of examples.

## Context

- Tests must assert real behavior and failure modes; never tautological or snapshot-everything.
- CLI tests live in `cli/tests/` and run under pytest-xdist, so every test owns its own state.

## Steps

1. Identify the behavior this milestone shipped that is not yet pinned by a test.
2. Add the missing cases, including the failure modes and the exact exit codes or payloads.
3. Confirm each new test fails against the pre-milestone behavior.

## Files

- `cli/tests/` (or the owning package's test directory)

## Acceptance criteria

- [ ] A property test feeds every write path the same set of amount strings and asserts the bytes on disk equal the input's decimal value.
- [ ] A test asserts no written number carries more fractional digits than its input or the display context allows.
- [ ] A round-trip test pipes `add transaction` JSON output into `add transactions` for costed and priced postings.
- [ ] An idempotency test asserts a repeated `add price` and `add balance` leave the ledger unchanged; `cd cli && make check-all` passes.

## Out of scope

- Coverage-percentage targets; the bar is meaningful assertions, not a number.
