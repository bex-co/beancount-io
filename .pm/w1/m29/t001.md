## Objective

PRFAQ002 promises the same `include "https://beancount.io/prices/BTC-USD"` line works locally. ADR 015 has already fixed the hosted contract, so the CLI mirrors a settled design rather than deciding one: an origin allowlist, an exact `/prices/<ALIAS>` path, a bounded fetch, and price-only validation.

## Context

- ADR 015 section 2: origin allowlist (default `https://beancount.io`), path exactly `/prices/<ALIAS>` with `ALIAS` matching `[A-Za-z0-9._-]{1,64}`, no user info, query, or fragment; redirects refused; an empty allowlist disables the feature.
- ADR 015 section 3: five-second timeout, `Accept: text/plain`, `redirect: "error"`, a 1 MiB body cap, at most sixteen distinct managed URLs per load.
- ADR 015 section 4: every non-blank line is a comment, a `YYYY-MM-DD price COMMODITY NUMBER QUOTE` directive, or an indented metadata line keyed `price-source`, `price-kind`, `observed-at`, or `provisional`; one commodity and quote pair throughout; zero directives is a failure.
- `docs/prfaqs/PRFAQ002-include-live-price.md` section 15 states the same bounding and privacy requirements for local resolution.
- This belongs engine-side under `cli/src/bea_engine/`, since the frontend must not load ledger data.

## Steps

1. Implement the origin, path, and alias policy exactly as ADR 015 section 2 states it, with the allowlist configurable and an empty value disabling the feature.
2. Implement the bounded fetch to ADR 015 section 3, including the redirect refusal and the per-load URL cap.
3. Implement price-only validation to ADR 015 section 4, rejecting a whole body on any disallowed directive and treating a zero-directive body as a failure.
4. Reject a body whose header alias disagrees with the requested alias, or whose commodity pair differs from the revision it would replace.
5. Send no ledger credential, ledger name, or private content with a price request.

## Acceptance criteria

- [ ] A URL outside the allowlist, with a query string, or with a non-matching alias is refused with a distinct message saying it is not an allowed managed price source.
- [ ] A redirecting origin reports unavailable rather than being followed.
- [ ] A body containing any non-price directive is rejected whole; a zero-directive body is a failure, not an empty feed.
- [ ] A body whose header alias or commodity pair disagrees is refused.
- [ ] No credential or ledger identifier appears in an outgoing price request.

## Out of scope

- Changing the hosted contract, which ADR 015 owns.
- Supporting arbitrary remote file includes — this is a registered price request, not a general URL include.
