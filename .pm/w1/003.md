# `Query.getFeed` is refused to OAuth sessions

Seen 2026-08-28 while closing w1/m6 on the local stack: the first thing the
native app does after signing in is load Home, and its feed query comes back
`FORBIDDEN` — "reachable only from a browser session" — because
`Query.getFeed` is filed `session-only` in `backend-v2/src/server/api/op-class.ts`.
Same shape as the `Query.userProfile` fix in ADR 0008's amendment: a
`ledger.read` token reading the user's own feed is not lifecycle, billing, or
credential minting. Reclassify to `read` (with the parity pin and ADR counts),
and sweep the rest of the session-only list for anything the native app calls
after sign-in so the next one is not found the same way.
