## Objective

Pin the encoding and normalization matrix, which is exactly the surface that regresses silently.

## Context

- Tests must assert real behavior and failure modes; never tautological or snapshot-everything.
- CLI tests live in `cli/tests/` and run under pytest-xdist, so every test owns its own state.

## Steps

1. Identify the behavior this milestone shipped that is not yet pinned by a test.
2. Add the missing cases, including the failure modes and the exact exit codes or payloads.
3. Confirm each new test fails against the pre-milestone behavior.

## Files

- `cli/tests/` (or the owning package's test directory)

## Acceptance criteria

- [ ] Fixtures cover BOM, CRLF, no-final-newline, non-UTF-8, and NFD-versus-NFC ledgers, each exercised through check, add, import, and format.
- [ ] A round-trip test asserts a BOM plus CRLF ledger survives an append with no mixed endings.
- [ ] An NFC/NFD test asserts one account and one balance.
- [ ] `cd cli && make check-all` passes.
