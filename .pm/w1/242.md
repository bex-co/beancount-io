# Mobile Ask-AI: show the setup hint for an unconfigured AI model

Follow-up to [m48](./done/m48/README.md) (ADR029 D5), whose scope kept mobile to regression fixes. On a stack with no LLM key, `POST /api-gateway/agent` now answers HTTP 503 `{ ok: false, error: { code: "CONFIGURATION_ERROR", message, metadata: { hint } } }` before streaming. `mobile/src/screens/agent-screen/agent-errors.ts` classifies that as `generic`, so the agent screen shows its generic error copy and a retry button that cannot help. Before m48 the same stack failed inside a 200 stream and got the same generic notice, so this is not a regression.

**Done when:** `classifyAgentError` recognises `CONFIGURATION_ERROR`, the agent screen shows the server's message and hint (localized lead-in in every mobile locale) with no retry action, and a unit test covers it. Receipt scans already treat the code as permanent (w21/869).
