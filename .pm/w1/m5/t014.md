## Objective

Add meaningful automated and device-level coverage for the native OAuth flow, especially adversarial audience/scope/resource cases and refresh, redirect, compatibility, and logout failure modes.

## Context

- Backend, dashboard, mobile, and deployment packages own separate checks and lockfiles.
- OAuth success-only tests would miss the boundaries that motivated the migration; negative verification and concurrent lifecycle behavior are required.
- Tests and simulator evidence must never use production credentials, mutate a real user's ledger, or preserve bearer tokens in artifacts.

## Steps

1. Test backend signing configuration, code-only metadata, PKCE, exact clients/redirects, resource allowlisting, audience enforcement, scope enforcement, unpinned consent, and refresh rotation/revocation behavior.
2. Test dashboard mobile login/register/OTP/approve/cancel state while preserving existing MCP and identity consent paths.
3. Unit-test mobile metadata validation, warm/cold redirects, opaque-token handling, secure session hydration, concurrent refresh, rotated-token persistence, offline retry, terminal failure, Apollo replay, logout, and legacy-session routing.
4. Verify iOS and Android external-browser round trips against hosted and local compatible servers using non-production fixtures/accounts.
5. Run each owning package's documented format, lint, typecheck, unit/integration, build, and secret-scan checks from its own directory.

## Files

- `backend-cluster/backend-v2/src/**/__tests__/`
- `dashboard/src/**/__tests__/`
- `mobile/src/**/__tests__/`
- Deployment smoke/integration checks where appropriate.

## Acceptance criteria

- [ ] Tests reject missing/wrong audience, missing scope, arbitrary resource, redirect mismatch, state/issuer mismatch, invalid PKCE, and identity-token API use.
- [ ] Tests cover refresh races, rotation persistence, offline recovery, terminal grant failure, replay limits, logout, and legacy compatibility.
- [ ] Hosted and self-hosted external-browser flows are verified on iOS and Android without leaking secrets or mutating production ledger data.
- [ ] All affected package CI commands and the repository secret scan pass.

## Out of scope

- Tautological snapshots, fabricated coverage-only branches, or third-party authorization-server compatibility certification.
