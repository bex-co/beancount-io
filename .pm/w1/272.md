# `bea cloud ledger delete --help` says "Pass dryRun to preview the destroy summary", but the command has no such option

Found by `/qa-find-bugs-cli w1` on 2026-11-16 (HEAD `8adc7ff65`, `bea 0.3.1`, macOS 26.5, checkout `uv run bea`, stdin closed, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`). Severity: minor. Only `--help` and a refused unknown option were run. No ledger was deleted or previewed. A1: the most destructive hosted command tells an agent or a person to run a preview that the CLI cannot run. Following the hint fails, and the only way left to see what a delete removes is to delete.

**Repro** (no ledger needed; a signed-in token is needed only for the last command, which stops at the confirmation before any request is sent):

```sh
bea cloud ledger delete --help
bea cloud ledger delete alice/books --dry-run     # Error: No such option: --dry-run (exit 2)
bea cloud ledger delete alice/books --dryRun      # Error: No such option: --dryRun (exit 2)
BEA_TOKEN=... bea --no-input cloud ledger delete alice/books   # exit 2: pass --yes to confirm
```

**Actual.** The help body reads: "Delete the repository and perform the existing linked-bank cleanup. Requires current administrative authority and respects the credential pin. Pass dryRun to preview the destroy summary without destroying anything." The only option listed is `-h, --help`. The same text is generated into `cli/docs/REFERENCE.md` (`### bea cloud ledger delete`).

**Expected.** The help describes options the command actually accepts. Since w23/m13 (`09a06ed42`, `035b6b6a3`), REST `DELETE /api-gateway/v1/ledgers/{owner}/{name}` takes a `dryRun` body flag (alias `dry_run`) and answers `{ledgerId, dryRun: true, preview: LedgerDeletePreview}`. GraphQL and MCP `deleteLedger` preview the same way. The CLI is the only client surface that has no preview, so the better fix is to expose the flag, not only to reword the help.

**Root cause.** cli: `cli/scripts/gen_cloud_commands.py` builds each command's help as `summary + "\n\n" + description` from `cli/openapi/v1.json` (around line 150). It builds options only from path and query parameters, so the `deleteLedger` request-body field `dryRun` becomes prose with no option behind it. The generated command is in `cli/src/cli/commands/cloud/generated/ledger.py`, around lines 80–115. It calls `delete_ledger.sync_detailed(owner, name, client=client)` with no `body`, even though the pinned client `cli/src/cli/api/rest_client/api/ledger_v_1/delete_ledger.py` accepts `body: DeleteLedgerBody`.

**Fix.**
1. Add `--dry-run` to `bea cloud ledger delete`, through the generator registry (a body-flag entry on the `deleteLedger` `Command`), not by editing generated files. Send `DeleteLedgerBody(dry_run=True)`. Skip the confirmation prompt: a preview destroys nothing, so `--no-input` without `--yes` is fine. Print the `preview` destroy summary in human output and emit it under `--json`. Exit 0, and do not print "deleted".
2. Then the help sentence describes a real option. Prefer CLI wording such as "Pass --dry-run to …" over the API's `dryRun`. If the generator keeps the spec description verbatim, add a gate that fails generation when a description names a body field that has no CLI option.
3. Run `make codegen` and refresh `cli/docs/REFERENCE.md`. Document the preview in `cli/docs/USAGE.md` next to the existing `cloud ledger delete` examples (about line 2570).
4. Tests in `cli/tests/test_cloud_generation.py` or alongside it: `--dry-run` sends `{"dryRun": true}`, never prompts, and renders the preview. A plain delete still prompts and still sends no `dryRun`. The help names `--dry-run`. Revert the change and these tests should fail.

The server already offers the preview on REST, GraphQL and MCP, so this needs no backend change. Estimate: 40–60 minutes.

**Dedupe.** Searched `.pm/**` (open, `done/` and `blocked/`) for `cloud ledger delete`, `dryRun`/`dry_run` together with delete, and `deleteLedger`. w23/m13 (done) added the lifecycle previews on REST, GraphQL and MCP, and its t006 re-pinned the CLI REST client. It never exposed the flag in `bea`. No open item covers this. `git log -S"Pass dryRun to preview the destroy"` shows only those two m13 commits.
