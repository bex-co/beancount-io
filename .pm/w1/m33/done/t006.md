## Objective

ADR 019's implementation table lists `securitySchemes` derived from each tool's op class in `composition-root.ts`; on 2026-10-06 they appear only in the REST OpenAPI registry. Confirm whether MCP tool descriptors carry them and add them if not, so hosts know which tools need which credential.

## Context

- backend-cluster/backend-v2/src/server/api/composition-root.ts
- backend-cluster/backend-v2/src/server/rest/openapi-registry.ts (where `securitySchemes` exists today)

## Steps

1. Check the `tools/list` output for `securitySchemes`.
2. If absent, derive them from the op class at registration; test a read tool, a write tool, and an admin tool.

## Files

- backend-cluster/backend-v2/src/server/api/composition-root.ts

## Acceptance criteria

- [x] Every tool in `tools/list` carries the scheme its op class requires, with a test.

## Out of scope

- Changing credential policy.

## Result

2026-10-06. Not present before: MCP tool descriptors carried no `securitySchemes` (only the REST OpenAPI registry had any). Now `mcpToolSecuritySchemes(tool)` in `op-class.ts` derives each tool's scheme from `VERB_TABLE` — OAuth 2 with the scope of the tool's most privileged verb (`read` → `ledger.read`, `write` → `ledger.write`, `admin` → `ledger.admin`); session-only → OAuth without a scope; public → `noauth` too. Placement follows OpenAI's Apps SDK reference (checked 2026-10-06): top-level on each `tools/list` entry, mirrored in `_meta.securitySchemes` for clients that read only `_meta`. `_meta` goes through `registerTool`; the top-level field is added by wrapping the SDK's `tools/list` handler as it installs it through the public `setRequestHandler` (the SDK's tool registry is private and its descriptor has no slot). Tests: every tool publishes the derived scheme in both places (raw wire response, since the client SDK strips the top-level field when parsing), scope selection for single, grouped, and mixed-class tools, and the session-only and public branches; removing the wrapper turns the top-level test red. The size gate now measures the raw response: 72 KB (4.1 KB for the two copies across 30 tools).
