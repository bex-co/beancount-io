## Objective

Provide a small shared launcher for native executables and helper commands in the separate engine environment.

## Context

- ADR014 requires subprocess execution, not importing an upstream Python entrypoint into bea.
- Provisioning is owned by t015/t016; all commands use the same reviewed engine location.

## Steps

1. Resolve engine executables and pass argument arrays without shell-generated command strings.
2. Forward cwd, stdin/stdout/stderr, terminal interaction, cancellation/signals, and exit status. Keep --file translation and bea JSON/strict extensions explicit.
3. Exercise absent/conflicting global bean-* commands, paths with spaces, piped input, and an interactive command through real subprocesses.

## Files

- cli/src/cli/main.py; cli/ (shared process launcher)
- cli/tests/

## Acceptance criteria

- [ ] Delegation runs in a distinct process/interpreter and does not import Beancount, Beanquery, or Fava into the frontend.
- [ ] Native output and errors remain observable; the launcher handles provisioned and first-use paths without manual upstream installation.

## Out of scope

- In-process entrypoint loading, upstream command reimplementation, or arbitrary internal-object RPC.
