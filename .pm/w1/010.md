# BQL can report another ledger when a filename contains # or ?

**Major · 45–60 minutes.** QA reference CLI-QA-004.

Create `/absolute/qa/main.bean`:
```beancount
2026-01-01 open Assets:Cash USD
2026-01-01 open Equity:Opening USD
2026-02-01 * "QA"
  Assets:Cash 999 USD
  Equity:Opening -999 USD
```
Copy it to `main.bean#target.bean`, replacing both 999 values with 10.
Run:
```sh
uv run bea --json --file '/absolute/qa/main.bean#target.bean' query "SELECT sum(position) WHERE account = 'Assets:Cash'"
uv run bea --json --file '/absolute/qa/main.bean#target.bean' list transaction
```
Query exits 0 with **999 USD**, but target.file names the requested suffixed
file. Listing correctly shows **10 USD**. Earlier repeated controls reproduce
with `?` too; ordinary filenames work. Neither file is modified.

Cause: `src/cli/commands/query.py` builds `beancount:` + path. Beanquery's
Beancount source applies urlparse().path, discarding query/fragment suffixes.

unquote it. Check the same DSN construction in `ask/agent.py` and query shell;
those paths are source-traced, not live-verified in this run.
