Turn "the directories might object" into a decision per tool, grounded in the policies' own words.

## Result (2026-10-09)

The decision table is in ADR 019's Amendments ("2026-10-09 — The MCP surface is trimmed…"), with every deciding clause quoted from C-rev, C-pol, and O-gl as read that day.

- **Remove:** `manageApiKeys`, `listPublicKeys`, `managePublicKeys`, `deleteAccount`, and the resources `publicKeys`, `publicKey`, `allTierQuotas`, `aiCfoUsage`.
- **Relabel:** `listBankConnections` gets `readOnlyHint: true`, and `manageBankImport` gets `destructiveHint: true`.
- **Reword:** server instructions, tool descriptions, and upsell error text.
- **Keep:** every other tool.

No host-hiding was needed, so ADR 019 D1's single endpoint stands. `renameLedgerFile` stays non-destructive because the workflow refuses an existing target ("file already exists; rename refused…").

Implementation note for t002/t003: `surface-parity`'s `countDeferred` counts an MCP-eligible verb with no MCP binding as a gap whatever its `mcpExempt` says. The removals therefore need an explicit "withheld from MCP by directory policy" set that `isReachableOn` consults, not just exemption prose.
