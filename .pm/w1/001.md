When the AI answers "top expenses" (etc.), the answer should deep-link to the filtered journal/report view, not just state a number — chat as a navigation surface, not a walled garden.

**Blocked on the private backend:** the dashboard already renders chat answers as markdown (`dashboard/src/features/ai-agent/pages/ask-ai/chat-message.tsx`), so links work as soon as the chat API emits dashboard URLs in its answers. That API change belongs on the private backend repo's board, not here (see `.pm/DO_NOT_DO.md`). Once the backend emits links, the frontend remainder (internal-route handling, link styling) is sub-hour — pick this up then.
