## Objective

Implement the rename as one shared workflow that every adapter calls: rewrite the account tokens in every loaded source file, project the result through the new-error gate, and commit all files at once.

## Context

- `src/features/ledger/service/ledger-repo-service.ts` `changeFiles` commits several files atomically.
- `src/features/ledger/utils/file-write-gate.ts` holds the projected new-error gate and `projectedSourceFiles`.
- `src/features/ledger/workflow/ledger-workflow.ts` holds the other ledger write workflows, including the commit-returning ones from w23/m42.

## Steps

1. Read the loaded source files at HEAD. Find account tokens with a scanner that skips quoted strings and `;` comments and matches whole account names only (the old name, or the old name followed by `:`).
2. Build the projected files, run them through the existing new-error gate, and honor `allowInvalid`.
3. On `dry_run`, return the per-file changed lines and counts. Otherwise commit with `changeFiles` against the HEAD that was read, and return `commit`.
4. Refuse per t001's contract before reading files where possible.
5. Unit-test the scanner on prefixes, descendants, strings, comments, metadata and every directive kind.

## Acceptance criteria

- [ ] Scanner tests cover every case in t001's contract, and fail if the scanner is replaced by a plain string replace.
- [ ] A rename across three files makes one commit; a preview makes none.
- [ ] A rename that would add a bean-check error is refused unless `allowInvalid` is set.
