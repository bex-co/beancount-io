# CSV query export doesn't neutralise spreadsheet formulas, and the docs don't say so

**Severity: minor. Owner: cli. Estimate: 30–45m. A1:** bank-sourced payees end up in spreadsheets; exports should be safe or clearly documented. Continuous CLI QA, 2026-10-03 (round 10); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1 (Beancount 3.2.3, beanquery 0.2.0), Python 3.13, macOS 26.5.1 arm64. Fresh process per command with timeouts, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME` (so `~/.config/beanquery/init` below is the isolated home), notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced at least twice with a working control.

With a payee `=HYPERLINK("http://x","y")` (or narration `+cmd|' /C calc'!A0`, `@SUM(1+1)`, `-2+3`): `bea --file /abs/main.bean query "SELECT payee, narration" -f csv -o /abs/out.csv` writes the cells verbatim (correct RFC 4180 quoting), so opening the file in a spreadsheet evaluates them. Native `bean-query` behaves the same — a hardening/documentation gap, not a regression.

Basis: OWASP CSV-injection guidance (neutralise text cells starting with `=`, `+`, `-`, `@`, tab, CR); bea already treats ledger strings as untrusted for terminals (`_inert_cell`, `cli/src/bea_engine/query.py:592`), and payees often come from imported bank CSVs.

Cause: `cli/src/bea_engine/query.py:637–661` (`_render_csv` / `_csv_from_jsonable` for `str`).

Fix/acceptance (decide one): prefix `'` on **string-typed** cells beginning with a trigger character (numeric/Amount/Position cells unchanged so `-5` stays numeric), or document the behaviour in USAGE's query section with an opt-in flag. Either way the choice is tested and documented. Check `.pm/DO_NOT_DO.md` "don't re-implement upstream" if diverging from bean-query output.

---

**Resolved 2026-10-04** — USAGE now documents that CSV query cells are written verbatim and can run as spreadsheet formulas, and a new opt-in `--spreadsheet-safe` prefixes formula-looking text cells with `'` while numbers keep their sign. `tests/test_query_csv_spreadsheet_safe.py` covers it. Shipped in the commit that moved this note (`cli`).
