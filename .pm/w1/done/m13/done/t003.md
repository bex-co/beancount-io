## Objective

Text reports show money at the precision the ledger uses for that currency; JSON keeps the exact decimal string.

## Context

- Converting `4.50 EUR` at `1.09` yields `Decimal("4.9050")`, and `bea report income-statement` prints `Dining 4.9050 USD` and `Net Profit 4,415.6450 USD`.
- Beancount's `DisplayContext` (available from the loaded ledger options as `dcontext`) knows the precision inferred per currency; Fava quantizes on display with it.
- `cli/src/cli/query_render.py` deliberately preserves BQL result precision; that policy is for queries and stays.

## Steps

1. In the report text renderer, quantize each amount with the ledger's display context for its currency before formatting; fall back to the amount's own exponent for commodities the ledger never wrote.
2. Leave JSON untouched: decimal strings keep full precision.
3. Check that inventory-style cells (`10 VTI {250.00 USD}`) still render the cost as the ledger wrote it.
