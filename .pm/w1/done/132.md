# Case-insensitive filters never match Turkish `İ`/`ı` against `i`/`I`, unlike `report -a` and import rules

**Severity: minor. Owner: cli. Estimate: 20–30m. A1:** Turkish-language ledgers must be searchable. Continuous CLI QA, 2026-10-03 (round 8); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command with timeouts, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced twice with a working control.

```beancount
option "operating_currency" "TRY"
2026-01-01 open Assets:Banka TRY
2026-01-01 open Expenses:İzmir TRY
2026-01-02 * "İSTANBUL KEBAP" "AKŞAM YEMEĞİ"
  Expenses:İzmir  10 TRY
  Assets:Banka
```

`bea --file /abs/tr.bean list transaction --search istanbul` → 0 rows; `list transaction -a izmir` → 0 rows; `bea balance izmir` → "No accounts match izmir."; `--search ısparta` misses `ISPARTA GIDA`. Controls: `report income-statement -a izmir` finds `İzmir 10 TRY`; an import rule `match = "istanbul"` matches `İSTANBUL KEBAP`. Same under every locale.

Expected: USAGE documents `--search`, `--account` and `bea balance` as case-insensitive; the same term should match everywhere.

Cause: `str.casefold()` folds `İ` to `i` + U+0307 and leaves `ı` unchanged — `cli/src/bea_engine/ledger/text.py:69` (`fold_account`, 13 callers incl. `report.py:605`), `cli/src/bea_engine/ledger/reader.py:219,233` (search), `cli/src/cli/utils.py:101–110` (frontend `fold_account`, `list.py:132,334,355`); `re.IGNORECASE` (rules, Fava `account_predicate`) treats them as equal.

Fix/acceptance: in both fold helpers map `İ`/`ı` to `i` (dropping U+0307 after `i`) before casefold/NFC. The three commands match the fixture under every locale; NFC/NFD matching unchanged.

---

**Resolved 2026-10-03** — `--search`, `--account` and `bea balance` filters now match Turkish `İ`/`ı` against `i`/`I`, consistent with `report -a` and import rules. `tests/test_turkish_case_fold.py` covers it. Shipped in the commit that moved this note (`cli`).
