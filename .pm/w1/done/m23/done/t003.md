## Objective

`bea format --check` reports `All 1 file(s) are formatted` and exits 0 on split ledgers whose includes are missing, unparseable, or themselves unformatted, because bea treats "bean-format produced no rewrite" as "already formatted". A pre-commit or agent gate built on it passes over ledgers `bea check` rejects.

## Context

- `w3/370`: `format --check` exits 0 for a missing include and for existing children that fail syntax, balance, or assertion checks.
- `w3/332`: `format -i` / `--check` on a split-ledger root leaves included files unformatted but reports green.
- `w3/273`: `format --check` is green for files that are not valid Beancount at all — bean-format echoes garbage unchanged.
- Formatting is forwarded to the engine from `cli/src/cli/commands/format.py`.

## Steps

1. Resolve the include closure of the target before formatting and format every reachable `.bean` file, not just the named root.
2. Treat a file bean-format cannot parse as a failure rather than as already formatted; distinguish 'unchanged because formatted' from 'unchanged because unparseable'.
3. Exit nonzero from `--check` when any file in the closure is unformatted, unparseable, or missing, and name each one.
4. Report the scanned set (files formatted, skipped, failed) so the caller can see the closure that was walked.

## Files

- cli/src/cli/commands/format.py
- cli/src/bea_engine/ledger/text.py
- cli/tests/test_docs_examples.py

## Acceptance criteria

- [ ] `format --check` on a root whose include is missing exits nonzero and names the include.
- [ ] `format --check` on a root with an unformatted child exits nonzero and names the child; `format -i` formats it.
- [ ] `format --check` on a file containing garbage exits nonzero rather than reporting it formatted.
- [ ] A fully formatted split ledger still exits 0 and lists every file it walked.

## Out of scope

- Changing bean-format's alignment algorithm or its width options (`w3/331`, `w3/348` are separate).
- Symlink-following policy in the directory walk (`w3/329` is separate).
