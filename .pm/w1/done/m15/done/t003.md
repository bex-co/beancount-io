## Objective

Let the most common add read like a sentence: what it was, then the postings.

## Context

- `cli/src/cli/commands/add.py::transaction` has no positional argument; `bea add transaction "Coffee" -p …` fails with "Got unexpected extra argument(s) (Coffee)".
- `--narration / -n` defaults to empty text and must keep working for scripts.

## Steps

1. Add an optional positional `NARRATION` argument; when both it and `--narration` are given with different text, exit 2 with a usage error naming both.
2. Update the command docstring example and both docs' transaction examples to the positional form, keeping one `--narration` example for scripts.

## Files

- `cli/src/cli/commands/add.py`
- `cli/README.md`, `cli/docs/USAGE.md`

## Acceptance criteria

- [ ] `bea add transaction "Coffee" -p "Expenses:Dining 12.50" -p Assets:Checking` writes narration `Coffee`.
- [ ] `--narration` alone still works; conflicting values exit 2.
- [ ] JSON `data.directive.narration` reflects the positional value.
