## Objective

Answer "what is in checking" with one command, matching the `bal` habit from ledger-cli and hledger, without adding a new report engine.

## Context

- `bea report trial-balance` renders the full tree; its `--account` filters transactions involving matching accounts and keeps every posting (Fava semantics), so `--account Checking` prints the whole Assets tree.
- The tree data (`account`, `balance`, `balance_children`, `children`) already exists in `cli/src/cli/commands/report.py`; pruning is a walk over it.
- `cli/docs/PRFAQ.md` FAQ 10 asks to keep command count low; this is a read-only alias over an existing report, registered in the local panel in `cli/src/cli/main.py`.

## Steps

1. Register `bea balance [ACCOUNT…]` as a top-level read command that runs trial balance and prunes the tree to nodes whose full name contains any argument (case-insensitive), keeping ancestors for structure.
2. Accept `--conversion`, `--time`, and `--allow-errors` with the same semantics as reports; no `--interval`.
3. With no argument, output equals `bea report trial-balance`.
4. JSON returns the pruned tree with the same field names as trial balance; add the command to both docs' command maps.
