# Ledger-controlled paths and diagnostics reach the terminal raw through bea's error and warning output

**Severity: minor. Owner: cli. Estimate: 45–60m. A1:** a ledger from someone else's repo must not drive the user's terminal or clipboard. Continuous CLI QA, 2026-10-03 (round 8); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command with timeouts, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced twice with a working control.

```python
from pathlib import Path
Path("main.bean").write_text('2024-01-01 open Assets:Cash USD\n2024-01-01 open Expenses:Food USD\n'
  '2024-03-05 document Assets:Cash "r\x1b]52;c;SElKQUNL\x07\x1b]0;PWNED\x07.pdf"\n')
```

On a PTY: `bea --file /abs/main.bean list open` (and `report trial-balance`) exits 0 with stderr `main.bean:3: File does not exist: ".../r\x1b]52;c;SElKQUNL\x07\x1b]0;PWNED\x07.pdf"` — raw ESC/BEL (OSC 52 clipboard write, OSC 0 title). `add note --date 2024-04-01 --account Assets:Cash -m hi` exits 1 with the same raw bytes under "The change would leave the ledger invalid". Raw through pipes too (`print()`, not Click). Same leak via an include glob containing ESC, an included file whose name contains ESC (`list transaction --details` source line), and `bea format --check|-i DIR` on such a file. Ledger unchanged. Controls: table cells (`list document`, `query SELECT`) and `--json` show a visible `\x1b`; import CSV errors escape correctly.

Expected: the invariant in `cli/src/cli/commands/ask.py` — "no control character reaches the screen raw" (`w3/392`); USAGE says untrusted text "cannot drive your terminal".

Cause: raw printing at `cli/src/cli/output.py:538` (`render_ledger_errors`), `:43` (`flush_warnings`), `:115–117` (`_print_failure`), `cli/src/cli/commands/list.py:352` (`--details` source), `cli/src/cli/commands/format.py:224,235,246` (`cannot parse:` lines); engine messages quote paths and document names verbatim.

Fix/acceptance: in text mode only, pass these through `cli.utils.inert_text`/`single_line`; JSON keeps exact values. A PTY regression (like `tests/test_control_character_sanitization.py`) on `list`, `add`, `format --check` shows 0 raw ESC/BEL and a visible `\x1b`; JSON details keep the original; the source file is byte-identical. Native `bea check` passthrough is excluded by design.

Dedupe: `w3/392` (persistence/tables), `w4/173` (BQL cells), `w3/451` (ask), [090](./090.md) (cloud), [097](./097.md) (ask hyperlinks) — none cover diagnostics.
