# `bea report trial-balance` does not balance: its default market valuation leaves a holding's unrealized gain with no line, and without `-t` a priced currency exchange has no `Equity:Conversions`, so the report pack marks correct books NOT RECONCILED

Found by `/qa-find-bugs-cli w1` on 2026-11-18 (HEAD `5f13f574a`, `bea 0.4.1`, macOS 26.5.1, Python 3.12.14, checkout `uv run bea`, stdin closed, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, synthetic ledgers). Severity: major. A1: a trial balance is the one report whose job is to show that debits equal credits, and the customer `beancount-report-pack` skill compares it with the balance sheet; on any ledger holding priced investments or foreign currency, `bea` prints a trial balance that does not sum to zero, with exit 0 and no note, and the pack fails a correct ledger.

**Repro** (synthetic, `main.bean`; `bea check` exits 0):

```beancount
option "operating_currency" "USD"
2024-01-01 open Assets:Wallet USD
2024-01-01 open Assets:Euro EUR
2024-01-01 open Assets:Broker
2024-01-01 open Equity:Opening-Balances
2024-01-02 * "Opening"
  Assets:Wallet 1000.00 USD
  Equity:Opening-Balances
2024-01-10 * "Buy"
  Assets:Broker 5 AAPL {100.00 USD}
  Assets:Wallet -500.00 USD
2024-01-20 * "Exchange"
  Assets:Euro 90.00 EUR @ 1.10 USD
  Assets:Wallet -99.00 USD
2024-01-31 price AAPL 120.00 USD
2024-01-31 price EUR 1.20 USD
```

```sh
bea -f main.bean report trial-balance                  # 1
bea -f main.bean report trial-balance -t 2024-01       # 2
bea -f main.bean report trial-balance -x at_cost       # 3
bea -f main.bean report trial-balance -x at_cost -t 2024-01   # 4
bea -f main.bean report balance-sheet -t 2024-01       # control
python3 skills/beancount-report-pack/scripts/report_pack.py --file main.bean --time 2024-01 --out pack
```

**Actual** (all exit 0; Income and Expenses are `—` throughout):
1. Assets `1,109.00 USD`, Equity `-1,000.00 USD`: the sections sum to **109.00 USD**.
2. Same window with `-t`: Equity `-1,009.00 USD` (`Conversions:Current -9.00 USD`): the sections sum to **100.00 USD**, and the equity root differs from (1) for the same entries.
3. Assets `90.00 EUR 901.00 USD`, Equity `-1,000.00 USD`: sums to **90.00 EUR −99.00 USD**.
4. With `-t`: `Conversions:Current -90.00 EUR 99.00 USD` appears and the sections sum to zero. Only this form balances.
- Control: the balance sheet (with or without `-t`) shows Equity `-1,000.00 USD` and `Valuation/translation adjustment (credit): -109.00 USD`, so its equity reconciles.
- Report pack: `NOT RECONCILED`, exit 3, `FAIL Trial balance agrees with the statements — difference 9.0000 USD` (trial-balance equity -1,009 vs balance-sheet equity -1,000). Every other tie-out passes.

**Expected.** At every valuation but `units` (where lots at cost cannot net by construction), with or without `-t`, the five sections sum to zero: (1) and (2) show an Equity line carrying the 109.00 USD (100.00 unrealized on AAPL, 9.00 translation on EUR), and (3) shows the conversions (`-90.00 EUR 99.00 USD`) that (4) shows. Basis: the balance sheet already derives this figure (`valuation_adjustment`, w5/789 folded the clamp's conversions into it so `-t` and no `-t` agree), and `report.py` treats a trial balance that stops summing to zero as a bug (w5/463).

**Root cause.** `cli/src/bea_engine/report.py:567` (`_trial_balance`) renders `FinancialStatementsModule().trial_balance` (`cli/src/fava/modules/financial_statements.py:130-144`): five converted hierarchies and nothing else. The balance sheet (`:146-185`) computes the residual adjustment; the trial balance never does. Without `-t` there is no period clamp, so Beancount's `Equity:Conversions` booking never exists (`cli/src/fava/ledger.py` / `core/filters.py`); with `-t` the clamp adds it, and only the trial balance keeps it in its tree (w5/501, w5/789).

**Fix** (cli, plus the report pack check in `skills/`). Give the trial balance one adjustment line under Equity, computed as the balance sheet computes `valuation_adjustment` and with the clamp's conversion booking folded into it, so the line and the equity root are the same with and without `-t`; carry it in `--json` (beside the trees) and as a row in `--format csv`. Then `check_trial_balance` in `skills/beancount-report-pack/scripts/report_pack.py:176` compares trial-balance equity with balance-sheet equity plus `valuation_adjustment`. Leave `units` as is and say in USAGE (Reports) that only it can leave a residual. The hosted trial balance (`getLedgerTrialBalance`, `backend-cluster/ledger/src/features/ledger/service/ledger-finance-service.ts`) has no adjustment either: decide in the fix whether REST/GraphQL/MCP get the same line, per the parity rule.

**Regression.** The repro's four commands each sum to zero (text and JSON), with the line equal to the balance sheet's adjustment; the report pack on the repro exits 0 with the trial-balance tie-out passing; each fails with the fix reverted.

**Blast radius.** `bea report trial-balance`, `bea balance` with no account (prints the same trial balance), their CSV and JSON, and the report pack's tie-out. The balance sheet, income statement and overview are unaffected. A ledger with no holdings and no priced exchanges is a working control: its trial balance sums to zero.

**Dedupe.** Searched `.pm/**` for `trial` with `Conversions`, `unrealized`, `valuation`, `sum to zero`. w5/789 (done) fixed the balance sheet's `-t` split and kept the trial balance's conversions row per w5/501; w5/463 (done) fixed unrooted accounts; none makes the trial balance itself balance. Estimate: 45–60 minutes.

---

**Resolved 2026-11-18** — `FinancialStatementsModule.trial_balance` (`cli/src/fava/modules/financial_statements.py`, marked as a Beancount.io change) now returns the five trees' residual as `valuation_adjustment`, derived as the balance sheet's is. At every valuation but `units`, the equity tree leaves out the clamp's `C`-flagged conversion booking, so the line absorbs it. On the repro, all four commands sum to zero with and without `-t`. USD shows Equity -1,000.00 and `Valuation/translation adjustment: -109.00 USD`, equal to the balance sheet's. At cost the line is `-90.00 EUR 99.00 USD`. The line is `valuation_adjustment` in `--json` beside the trees and a `valuation_adjustment` row in `--format csv`. Text prints it after Equity when it is not zero. `bea balance` with no terms prints the same. The line is null under `units`, with `--account` or `balance` terms, with loader errors, and while a balance is unvalued. `units` keeps the conversions row, and USAGE (Reports) says only it can leave a residual. `bea balance` with terms shows the folded trees too, so `tests/test_report_price_notice_cost_currency_route.py` now expects the balance sheet's missing-price notices there. The report pack (`check_trial_balance`) passes on the repro and also compares the trial balance's adjustment with the balance sheet's when the sheet reconciles its equity. The suite version is now 0.4.37. The hosted `getLedgerTrialBalance` is left as it is: it runs on a separate engine shared by REST, GraphQL and MCP, which stay in parity with each other. Regressions: `cli/tests/test_report_trial_balance_nets.py` has 23 tests, all failing with the fix reverted. `scripts/skills/test_report_pack.py` gains a holdings ledger that reconciles and a tampered adjustment that fails, each failing with its half of the fix reverted. `make check-all` passed (12136 tests). Shipped in `10dd0edd4` (`cli`, `skills`).
