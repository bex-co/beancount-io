# The error collapser repeats identical messages for the same line

**Severity: minor. Owner: cli. Estimate: 15–20m. A1:** error output should be readable at a glance. Continuous CLI QA, 2026-10-03 (round 6); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1 (Beancount 3.2.3), Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed unless piping JSON. Reproduced twice with a working control; compared against native `bean-check`/`bean-query`.

On a ledger without `open Assets:Bank`, `bea --file /abs/main.bean add balance --date 2026-02-01 --account Assets:Bank --amount "974.50 USD"` ends with "Same problem on 1 more line: 26." — line 26 is the proposed append itself (upstream reports the unknown-account error twice for one line). `--pad-from Equity:Old` with a closed `Equity:Old` prints the identical inactive-account paragraph twice.

Cause: `cli/src/bea_engine/ledger/write.py:390–413` (`_collapse_repeats`) doesn't dedupe identical `(message, lineno)` records and skips collapsing when `lineno` is None.

Fix/acceptance: merge identical duplicates (including those without a line number); each repro shows the message once.

---

**Resolved 2026-10-03** — an error upstream reports more than once for the same line now prints once with every hint either copy carried, instead of repeating or pointing "same problem" at its own line. Tests in `tests/test_ledger_safety.py` cover it. Shipped in the commit that moved this note (`cli`).
