## Objective

When a ledger has no `sshUrl`, `bea cloud ledger clone` stops with a clear, stable error instead of a Git failure.

## Context

- `cli/src/cli/commands/cloud/ledger/app.py` prints and clones from `ledger.ssh_url` (`manager.check_clone_url(ledger.ssh_url)`).
- CLI failure contract: every failure is a JSON envelope under `--json` (w1/m25); exit status tells the truth (w1/m23).

## Steps

1. Handle a null/absent `ssh_url` in the show and clone paths.
2. Emit a stable error code and a message that this deployment serves no Git over SSH, with a hint to ask the operator.
3. Update the generated reference/docs for the command.

## Files

- `cli/src/cli/commands/cloud/ledger/app.py` and tests
- `cli/` docs for `bea cloud ledger`

## Acceptance criteria

- [x] `bea cloud ledger clone` on a ledger without `sshUrl` exits non-zero, writes nothing to disk, and returns the JSON envelope under `--json` (test).
- [x] A ledger with `sshUrl` clones exactly as before (test).
- [x] `make check-all` passes in `cli/`.

## Out of scope

- Cloning over HTTPS (see the milestone's Out of scope).
