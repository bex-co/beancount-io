# `bea cloud ledger list --json` omits `page` from the envelope

**Severity:** minor  
**Package:** `cli`

## Repro

`bea --json cloud ledger list --page 2 --limit 3` returns `limit` and `truncated` but no `page`. Page 1 vs page 2 rows differ correctly, so paging works; machines cannot echo the requested page from the payload alone.

## Expected

Bounded list envelopes that accept `--page` should include the page that was applied (alongside `limit` / `truncated`), matching how automation reconstructs the next request.

## Actual

`register_ledger_commands` → `ledger_list` calls `output.emit(..., truncated=..., limit=limit)` and never passes `page`.

## Fix

Thread `page=page` through `output.emit` (or an equivalent envelope field) in the generated list command / generator registry; cover with a contract test.

## Estimate

~20–30m
