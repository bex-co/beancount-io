# Investigate verified https redirect URIs for the native client

`beancount-mobile` redirects to `io.beancount.ios:/oauth/callback` and
`io.beancount.android:/oauth/callback` — custom schemes that any app on the
device can claim, so RFC 8252 §8.6 wants end-user interaction before redirecting
to one. Evaluate Universal Links (iOS) and App Links (Android) as the OAuth
redirect instead: they verify the client's identity through an
`apple-app-site-association` / `assetlinks.json` file on the dashboard origin,
which would make a quieter continuation path safe for the hosted origin.
Written recommendation only (~45m): hosting on hosted and self-hosted origins,
the `expo-web-browser` return path, and what a self-hoster would have to
publish. If the answer is "yes", it becomes its own milestone.
