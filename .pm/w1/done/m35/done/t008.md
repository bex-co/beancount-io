## Verdict

**Confirmed, fixed.** Checks 11–16 each re-ran `hostMetadata()`: the 401 pointer, the protected-resource document, and the authorization-server metadata, so 18 requests per run where 3 do. The six checks could also judge different snapshots mid-rollout. `hostMetadataFor` now memoizes per run, keyed by the `Options` object `main` hands every check. It is not keyed by `baseUrl`, so tests that pass fresh options against a mutated stub still get fresh reads. New test "discovers the metadata once for a whole run" asserts exactly three stub hits. With the cache write disabled it fails (1 failed, 27 passed). Every check's verdict is unchanged. backend-v2 `typecheck`, `lint`, and `test` (5075 tests) pass.
