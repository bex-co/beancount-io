## Objective

Make JSON query options produce the requested result rather than succeeding while ignoring them.

## Context

Published 0.2.0 exits 0 for `bea --json --file main.bean query 'SELECT 1' -o result.json` without creating result.json. An existing file retains stale bytes. `--numberify` also leaves Inventory columns unchanged. Text CSV export and text numberification are working controls. Reproduced twice each; stale-file control reproduced separately.

The frontend forwards both options at cli/src/cli/commands/query.py:94–97, but cli/src/bea_engine/main.py:82–83 calls rows_answer without them. The frontend JSON branch always emits to stdout.

## Steps

1. Write the standard JSON envelope to the requested output file; preserve stdout behavior when no destination is supplied or the destination is `-`.
2. Apply requested numberification engine-side using upstream result conversion, retaining decimal-safe JSON serialization.
3. Return a nonzero error for invalid/unwritable destinations; validate before replacing an existing export and preserve it on query/validation failure.
