## Objective

Verify the amount grammar and the write round-trip guarantee are documented where agents and skills will read them.

## Context

- Root `CLAUDE.md` compatibility rules: every `AGENTS.md` is a relative symlink to its `CLAUDE.md`, and root `.claude/skills` links to `../.agents/skills`.
- Customer skill catalog: `skills/CLAUDE.md`; customer skills live in `skills/.claude/skills/beancount-*`.
- `cli/docs/REFERENCE.md` is generated — run `make docs`, never hand-edit.

## Steps

1. Document the amount grammar in `cli/docs/USAGE.md`: accepted spellings, the float refusal, the scientific-notation rule, the cost shapes, and the round-trip guarantee.
2. Document the idempotency rule for `add price` and `add balance` beside the write-safety section.
3. Run `make docs` and confirm `make docs-check` is green.
4. Check the JSON examples in the `beancount-import`, `beancount-reconcile`, and `beancount-migrate` skills against the accepted shapes, then run `python3 skills/scripts/ci-check.py` and `python3 scripts/check-agent-guidance.py`.
