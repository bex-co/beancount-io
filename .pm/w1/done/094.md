# Bulk-added posting metadata is written at posting indentation, so it reads as transaction metadata

**Severity: minor. Owner: cli. Estimate: ~30m. A1:** ledger text written for users must show metadata under the posting it belongs to. Continuous CLI QA, 2026-10-03 (round 4); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced twice from fresh fixtures with a working control.

```sh
cat > rows.json <<'EOF'
[{"date":"2021-01-02","narration":"x","postings":[{"account":"Expenses:Food","amount":"5 USD","meta":{"receipt":"R-1"}},{"account":"Assets:Cash","meta":{"cleared":true}}]}]
EOF
bea --file /abs/main.bean add transactions --from /abs/rows.json
bea format --check /abs/main.bean
```

Actual: the file gets `  Expenses:Food  5 USD` / `  receipt: "R-1"` / `  Assets:Cash` / `  cleared: TRUE`, all at two spaces; `format --check` reports it formatted, so it is never corrected. Beancount still attaches the metadata to the right posting (list/query agree); whether other parsers (e.g. the hosted ledger service) treat it the same is unverified.

Expected: posting metadata nested under its posting, as upstream `printer.format_entry` writes it (deeper than the posting line).

Cause: `cli/src/bea_engine/ledger/write.py:734–735` (`_indent_block`) flattens every indented line to the file's posting indent (from `ff47e5c6`, `aa5bd335`).

Fix/acceptance: preserve relative depth (map the printer's nested lines to twice the destination indent). Posting metadata comes out deeper than its posting; list/query unchanged; `format --check` clean.

---

**Resolved 2026-10-04** — appended posting metadata is now nested under its posting at twice the file's indent, so it no longer reads as transaction metadata. `tests/test_bulk_posting_meta_indent.py` covers two- and four-space ledgers. Shipped in the commit that moved this note (`cli`).
