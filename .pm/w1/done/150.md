# A `sign=ledger` preview followed by the documented flag-free `--apply` writes the opposite sign

**Severity: minor. Owner: cli. Estimate: 30–45m. A1:** what the preview shows must be what apply writes. Continuous CLI QA, 2026-10-03 (round 11); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command with timeouts, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, stdin closed. Reproduced twice from fresh fixtures with a working control.

Base ledger: `option "operating_currency" "USD"`, `2026-01-01 open Assets:Checking USD`, `2026-01-01 open Expenses:Uncategorized USD`.

`cc.csv`:

```csv
Date,Description,Amount
2026-08-02,GROCERY,25.00
```

```sh
bea --file /abs/main.bean import /abs/cc.csv --account Assets:Checking --csv date=Date,amount=Amount,narration=Description,sign=ledger
bea --file /abs/main.bean import /abs/cc.csv --apply
```

Actual: the preview shows `Assets:Checking -25.00 USD`; the apply prints "Using remembered settings … --csv date=Date,amount=Amount,narration=Description …", writes `+25.00 USD`, exit 0, with no mention that `sign` was dropped.

Expected: IMPORTING.md says "`--apply` re-runs flag-free" (and that `sign=` is never remembered); `w1/done/m24/t007` asked to ask or refuse rather than apply when remembered settings may not fit.

Cause: `cli/src/cli/commands/import_.py:539–542` strips `sign` before saving; recall (`:401–408`) can't tell the remembered run used `sign=ledger`. Introduced by the `w3/279` fix (`77eb123f`).

Fix/acceptance: remember a "used sign=ledger" marker (or scope it to the source file's content hash) and on recall re-apply it for the identical file or refuse with "pass sign=ledger or sign=bank explicitly". The repro's apply writes −25.00 or exits 2; the `w3/279` regression (a different file with the same header must not inherit the sign) still holds.

---

**Resolved 2026-10-04** — after a `sign=ledger` preview, a flag-free `--apply` of the same file now keeps `sign=ledger` (remembered by file hash), while other files with the same header still import bank-signed with a note. Tests in `tests/test_import.py` cover it. Shipped in the commit that moved this note (`cli`).
