## Objective

Create a `cloud` Typer sub-app and move every hosted command under it: `bea auth login|logout|status` becomes `bea cloud login|logout|status` (the `auth` level is flattened — the cloud surface is too small for two levels), and `bea ledger …` becomes `bea cloud ledger …`. Local verbs stay untouched at the top level. No back-compat aliases: the CLI is unreleased.

## Context

- Registration lives in `cli/src/cli/main.py` (`app.add_typer(auth_app, name="auth")`, `app.add_typer(ledger_app, name="ledger")`).
- Hosted commands today: `cli/src/cli/commands/auth.py` (login/logout/status) and `cli/src/cli/commands/ledger/` (create/delete/list/clone).
- Design rule fixed in the milestone source: `cloud` holds commands *about the cloud* (account, resources, sync); task verbs never move in.

## Steps

1. Create `cli/src/cli/commands/cloud/` with a `cloud_app` Typer; register `login`, `logout`, `status` directly on it (moved from `auth.py`) and mount the existing ledger app as `cloud ledger`.
2. Move `cli/src/cli/commands/ledger/` under `cli/src/cli/commands/cloud/`, mirroring the command tree in the package layout.
3. In `main.py`, replace the `auth` and `ledger` registrations with a single `app.add_typer(cloud_app, name="cloud")`.
4. Fix imports and run `make check-all` from `cli/`.

## Files

- `cli/src/cli/main.py`
- `cli/src/cli/commands/auth.py` (removed/absorbed)
- `cli/src/cli/commands/ledger/` → `cli/src/cli/commands/cloud/ledger/`
- `cli/src/cli/commands/cloud/` (new)

## Acceptance criteria

- [ ] `bea cloud login|logout|status` and `bea cloud ledger list|create|delete|clone` run (reaching at least the credential check without a server).
- [ ] `bea auth` and top-level `bea ledger` exit with "no such command".
- [ ] `make check-all` passes.
