# A rules pattern that matches empty text (e.g. trailing `|`) silently becomes a catch-all and books rows cleared

**Severity: minor. Owner: cli. Estimate: 15–25m. A1:** rule mistakes must not silently categorize every bank row. Continuous CLI QA, 2026-10-02 (round 2); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed unless a PTY is stated. Reproduced at least twice from pristine fixtures.

CSV `s.csv`:

```csv
Date,Description,Amount
2026-01-05,WHOLE FOODS,-20.00
2026-01-08,Employer payroll,2500.00
```

`r.toml`:

```toml
[[rule]]
match = "whole foods|trader joe|"
account = "Expenses:Groceries"
```

```sh
bea --file /abs/main.bean import /abs/s.csv --account Assets:Checking --rules /abs/r.toml --csv date=Date,narration=Description,amount=Amount --apply
```

Actual: the payroll deposit is booked to `Expenses:Groceries` with flag `*`, exit 0, `check` clean, the `!` review queue empty. Control: without the trailing `|`, payroll is `unmatched`.

Expected: `w1/done/m24/t006` required "an explicit catch-all spelling if one is wanted"; the docs name `.*`.

Cause: only blank pattern text is refused (`cli/src/bea_engine/csv_mapper.py:274–277`, mirrored at `cli/src/cli/csv_mapper.py:67–70`); a pattern for which `expression.search("")` succeeds matches every row.

Fix/acceptance: refuse at load time, naming the rule (exit 2), any pattern that matches the empty string unless it is the documented explicit catch-all (`.*`). The repro exits 2 naming rule 1; `.*` still works.

Dedupe: incomplete fix of `w3/done/342` / `w1/done/m24/t006`; no open item.

---

**Resolved 2026-10-03** — import rules whose pattern matches empty text (for example a trailing `|`) are now refused at load time naming the rule, with exit 2; only `.*`-style spellings are accepted as an explicit catch-all. Tests in `tests/test_import.py` (`TestCsvRulesMatching`) cover the frontend and engine copies. Shipped in the commit that moved this note (`cli`).
