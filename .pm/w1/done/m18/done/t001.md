## Objective

One starter ledger for the whole repository, produced by the CLI when it is present and by the skill's own template when it is not.

## Context

- `skills/.claude/skills/beancount-init/SKILL.md` writes `main.bean` with `Assets:Cash`, `Liabilities:CreditCard`, `Income:Salary`, `Expenses:Food`, and `Equity:Opening-Balances`, then `uv init --bare`, `uv add fava beancount`, a Makefile with a random Fava port, and a `.gitignore`.
- `bea init` (`cli/src/cli/commands/init.py`) writes thirteen accounts, `option "title"`, `operating_currency`, an opening-balance transaction, and `Equity:OpeningBalances`, with `--currency`, `--date`, and `--opening-balance`.
- The root `CLAUDE.md` requires skills to behave identically under Claude Code and Codex.
