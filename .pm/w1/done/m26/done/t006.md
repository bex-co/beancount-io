## Objective

Verify a Windows newcomer's first ledger works as the install and tutorial pages promise, and document the file conventions this milestone pins.

## Context

- Root `CLAUDE.md` compatibility rules: every `AGENTS.md` is a relative symlink to its `CLAUDE.md`, and root `.claude/skills` links to `../.agents/skills`.
- Customer skill catalog: `skills/CLAUDE.md`; customer skills live in `skills/.claude/skills/beancount-*`.
- `cli/docs/REFERENCE.md` is generated — run `make docs`, never hand-edit.

## Steps

1. Document the file conventions in `cli/docs/USAGE.md`: BOM handling, line-ending preservation, final-newline repair, NFC normalization, and the CR/LF rule for string fields.
2. Walk `cli/docs/TUTORIAL.md` with a BOM plus CRLF ledger and confirm every step works as written.
3. Run `make docs` and confirm `make docs-check` is green.
4. Re-check the `beancount-init` and `beancount-import` skill text for anything that assumes LF-only UTF-8, then run `python3 skills/scripts/ci-check.py` and `python3 scripts/check-agent-guidance.py`.
