# Ledger writes keep only mode bits: group, ACLs, extended attributes and file flags are dropped

**Severity: major. Owner: cli. Estimate: 1–1.5h (may warrant promotion). A1:** shared ledgers must keep who can read and write them. Continuous CLI QA, 2026-10-03 (round 5); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced at least twice with a working control.

Group (on a volume with ownership enabled, e.g. `/private/tmp`, in a directory whose group is `wheel`):

```sh
printf 'option "operating_currency" "USD"\n\n2026-01-01 open Assets:Checking USD\n2026-01-01 open Expenses:Food USD\n' > main.bean
chgrp admin main.bean && chmod 660 main.bean
bea --file /abs/main.bean add transaction --date 2026-01-05 --narration Lunch --posting "Expenses:Food 10 USD" --posting Assets:Checking
stat -f '%Sp %Sg' main.bean      # -rw-rw---- wheel
```

ACL / xattrs / flags: `chmod +a 'user:nobody deny read' main.bean; xattr -w user.tag keep main.bean; chflags nodump main.bean`, then `bea add …` or `bea format -i` → `ls -leO` shows no ACL entry and no `nodump`; `xattr` keeps only `com.apple.provenance` (`com.apple.quarantine` is also dropped).

Actual: exit 0; the group silently changes to the directory's, so group members lose access; a deny ACL disappears (widening read access); xattrs and flags are lost. Mode bits including setgid and executable are preserved (0755, 0664, 0640, 02664 checked). Control: without a different group/ACL/xattr, nothing changes.

Expected: USAGE — "Subsequent add/import/format writes preserve the file's permissions" and "Writes respect the destination file's permissions".

Cause: `cli/src/bea_engine/ledger/write.py:842–843` (`replace_checked`) only `chmod`s the fresh staging file (`candidate_file`, `write.py:273`) before `os.replace`; `format -i` uses the same path (`formatting.py:75`). From `ff47e5c6`.

Fix/acceptance: before replacing, `os.chown(candidate, -1, original_stat.st_gid)` (refuse with exit 3 if that fails rather than change the group), copy flags (`os.chflags`), and copy ACLs/xattrs (macOS `copyfile(3)` with `COPYFILE_ACL|COPYFILE_XATTR`; `shutil.copystat` copies xattrs only on Linux). After add/import/`format -i`, a ledger with a non-default group, an ACL entry, a user xattr and `nodump` keeps all four. Check the export writers that copy only mode (`cli/src/cli/utils.py:195`, `bea_engine/query.py:211`; read, not tested). Promote if over an hour.

Blast radius: every staged write — `add *`, `add transactions`, `import --apply`, `ask` append, `format -i`; group loss also on Linux.

Dedupe: no `.pm` hit for xattr / ACL / quarantine / chgrp / gid / ownership.

---

**Resolved 2026-10-04** — ledger writes (add, import, `format -i`, ask) now keep the file's group, ACL entries, extended attributes and nodump/hidden flags, refusing with exit 3 when the group cannot be kept; the file owner is unchanged by design. `tests/test_write_keeps_file_metadata.py` covers it. Shipped in the commit that moved this note (`cli`).
