# A failed assertion on a parent account offers a ready-to-run opening adjustment despite subaccount activity

**Severity: minor. Owner: cli. Estimate: 20–30m. A1:** suggested commands must not paper over real discrepancies. Continuous CLI QA, 2026-10-03 (round 6); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1 (Beancount 3.2.3), Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed unless piping JSON. Reproduced twice with a working control; compared against native `bean-check`/`bean-query`.

```beancount
2026-01-01 open Assets:Bank
2026-01-01 open Assets:Bank:Checking USD
2026-01-01 open Equity:OpeningBalances
2026-01-01 open Income:Salary
2026-01-05 * "Pay"
  Assets:Bank:Checking  1000.00 USD
  Income:Salary
```

`bea --file /abs/par.bean add balance --date 2026-02-01 --account Assets:Bank --amount "900 USD"`

Actual (exit 1, file unchanged): "Review missing transactions first. The following command creates an intentional opening adjustment." plus a filled-in `… --account Assets:Bank --amount '900 USD' --pad-from Equity:OpeningBalances`, which would post −100 USD to the parent from equity, hiding a discrepancy in Checking. Control: `--account Assets:Bank:Checking` gets only the date/review hint.

Expected: the leaf-with-activity hints (USAGE: review missing transactions before choosing an adjustment).

Cause: `cli/src/bea_engine/ledger/write.py:318–324` counts only `posting.account == balance.account` as activity.

Fix/acceptance: count postings to descendants (`balance.account + ":"`); the parent case returns only the date hint.

---

**Resolved 2026-10-03** — a failed balance assertion on a parent account whose subaccounts have activity no longer suggests a ready-to-run opening adjustment; it gets the date/review hint only. A test in `tests/test_workflow_guidance.py` covers it. Shipped in the commit that moved this note (`cli`).
