# `docs/mcp.md` contradicts the served contract in eight places

**Docs · backend-v2 · minor · ~30m · A1.** From `/qa-find-bugs-mcp` doc replay, 2026-11-09, production `beancount-mcp 1.0.0` (44 tools, 67 templates). The server is right in every case except 4, where the doc contradicts itself. Each line went stale when a shipped milestone did not carry its change through to it.

1. **`:790`** says "update and delete offer no preview", but `updateLedger` and `deleteLedger` publish `dry_run` and return previews. Stale since w23/m13.
2. **`:840`** says `deleteLedger` "accepts only `ledger`". It also takes `dry_run`, and a preview returns `{ledgerId, preview}`.
3. **`:875`** says the collaborator tools have no preview and that `dry_run` is rejected. `setLedgerCollaborator`, `removeLedgerCollaborator` and `leaveLedger` publish `dryRun` / `dry_run`.
4. **`:413-416`** says file writes "take no errors flag". `create`/`update`/`deleteLedgerFiles` publish `allow_invalid` (bf8487414, w23/m15), and `:527` of the same doc says to pass it.
5. **`:347-356`** describes MCP key creation (`ledgerScope`, `key_prefix`), and **`:227`** lists key management under `ledger.admin`. MCP has had no key tool since be2a7b44b (w1/m36/t003, ADR 019).
6. **`:1006`** says `?conversion=EUR` on a USD-only ledger answers in USD with `missingPrices`. A currency the ledger never names is refused with `BAD_USER_INPUT` "Unsupported conversion" (67c3ed0b9, w23/156). `:991` holds only for a currency the ledger names but cannot price.
7. **`:1333`** says "forty-three" tools; `tools/list` serves 44.
8. **Tools table `:322`:** the unescaped `|` in the `updateLedgerFiles` row splits it into an extra column. The table also omits nine served tools without pointing to the sections that cover them: `createLedger`, `previewLedgerSetup`, `createPullRequest`, `mergePullRequest`, `rejectPullRequest`, `parseFile`, `parseReceipt`, `generateTempAssetUploadUrl` and `insertReceiptTransaction`.

- **Fix:** correct items 1–8, escape the `|`, and add the nine rows or links to their sections. The neighbouring doc errors at `:379` and `:990` are already filed as w1/187 and w1/193.

**Addendum 2026-11-09 (commit replay), two more stale lines:**
- `:639` says a file edit commits with message `AI edit: {description}`. The description is used verbatim; w2/010 and 893294ef0 dropped the prefix.
- `:560` says entry writes compose `Added N …`. The served messages are:
  - `Add <date> "<payee>"` for one `addLedgerEntries` entry
  - `Add N directives to <file>` for `appendLedgerText`
  - `Update …` / `Delete <date> "<payee>"` for the entry-source edits
  - `Delete entries` for `deleteEntrySources`
- `:1296` tells the caller to "use `runBqlQueryStructured` to see the rest" of a truncated BQL result. `runBqlQueryStructured` also stops at 1000 rows (`truncated: true`, no total), so it cannot show the rest. The tool's own truncation line (`bql-query-tool.ts:107`) is accurate.
- `:1920` says "Postings also take `tags`, `links`, and string-valued `meta`, written onto the posting line". Posting tags and links have been refused since 503934b1e (w23/171).
