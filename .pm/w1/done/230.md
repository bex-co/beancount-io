# spending-report prompt still says "use cost(position) for currency totals"

**Copy · backend-v2 (MCP prompts) · minor · ~10m · A1.** From `/qa-find-bugs-mcp`, 2026-11-10, production `beancount-mcp 1.0.0`.

- **Repro:** `prompts/get spending-report {ledger, period:"2026"}`. Step 3 reads "Select `^Expenses:` to mean spending, and use `cost(position)` for currency totals."
  - With an `80.00 EUR @ 1.09 USD` charge in the ledger, `SELECT sum(cost(position)) WHERE account ~ '^Expenses:' AND year = 2026` returns `{USD:4091.49, EUR:80.00}`.
  - `sum(weight)` returns 4178.69 USD, which local `bea` agrees with.
  - Following the playbook, "what did I spend this year" comes out as two currencies instead of one total.
- **Cause:** `src/features/ai-agent/api/mcp-prompts.ts:343`. w5/358 corrected the skill this prompt was ported from to `sum(weight)` (`skills/beancount-ask/SKILL.md:88`), but the hosted prompt was never updated.
- **Fix:** "use `sum(weight)` for an operating-currency total (an `@`-priced foreign charge counts at the amount paid); `cost(position)` only reduces lots held at `{cost}`". Pin the wording in the prompt-list test.

**Resolved 2026-11-10.** Step 3 of the `spending-report` prompt now reads: "use `sum(weight)` for an operating-currency total: it counts an `@`-priced foreign charge at the amount paid, where `cost(position)` leaves it in the foreign currency (it reduces only lots held at a cost)". That is the wording w5/358 gave the `beancount-ask` skill this prompt was ported from.
- **Test:** `mcp-prompt-list.test.ts` pins the new wording and the absence of the old "use `cost(position)` for currency totals". It fails with the old prompt.
