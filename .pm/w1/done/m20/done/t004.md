## Objective

Prove optional enablement preserves the one-install experience and the reviewed process/license boundaries.

## Context

- m19 supplies clean-artifact and frontend-import checks; reuse them for optional profiles.

## Steps

1. Install the base and each supported optional profile without global upstream tools; test explicit enablement, repeat use, missing-feature guidance, upgrades, and recovery.
2. Assert no unselected dependencies appear in the base engine or frontend. Run real ingest/archive and quote commands with import isolation checks.
3. Inspect exact profile artifacts, notices, licenses, and required corresponding source. Verify that optional resolution does not reintroduce the base compatibility conflict.

## Files

- cli/scripts/smoke-installed.py; cli/tests/test_release.py; CLI optional-profile tests
- CLI release scripts and manifests

## Acceptance criteria

- [ ] Base commands work without extras; optional commands work after one bea-level feature choice and reuse installed components offline where their data permits.
- [ ] All supported channels preserve frontend isolation and satisfy the recorded optional artifact requirements.

## Out of scope

- Silent feature downloads, unreviewed optional dependency upgrades, or a separate release pipeline.
