# Served tool and template descriptions make three false claims

**Copy · backend-v2 · minor · ~25m · A1.** From `/qa-find-bugs-mcp`, 2026-11-10, production `beancount-mcp 1.0.0`. About 48 of the roughly 70 concrete claims in the live descriptions were checked; these are false both in production and on `main`. Each one costs an agent a failed call or a misread result. Every refusal behind them is clean.

1. **`runBqlQuery` lists a column that doesn't exist.**
   - The description's column list includes `change`. `SELECT change LIMIT 1` is refused "column 'change' not found", on the structured twin too.
   - All the other listed columns run.
   - **Where:** `src/features/ai-agent/tools/bql-query-tool.ts:15`, also copied in `docs/marketplace-submissions/lobehub/lhm.plugin.json:21`.
   - **Fix:** drop `change`, or name the engine's real column (e.g. `weight`) after checking that it runs.
2. **Trial balance promises "Every account's debit and credit totals — the statement that proves the books balance."**
   - The resource and REST return only the five `*_hierarchy_data` trees of signed per-currency balances. They contain no debit or credit field and no total or "balances" verdict.
   - **Where:** `src/features/ledger/api/rest/v1/analysis-handler.ts:135`, which feeds the MCP template and the OpenAPI spec (`docs/openapi/v1.json:15324`).
   - **Fix:** describe what is returned ("each account's signed balance per currency under the five roots; debits positive, credits negative"). Alternatively, add per-currency debit/credit totals and a sums-to-zero check on every surface.
3. **`addLedgerEntries` says "custom, query, option, and plugin are excluded, add them as raw text."**
   - `appendLedgerText` accepts `custom` and `query`, but refuses `option` and `plugin`. Its hint correctly points to `updateLedgerFiles`.
   - **Where:** `src/features/ai-agent/api/mcp-tools.ts:403`. The GraphQL and REST descriptions already say "via file writes".
   - **Fix:** "custom and query: add them with `appendLedgerText`; option and plugin: edit the main file with `updateLedgerFiles`."
- **Same pass:**
  - The `mergePullRequest`/`rejectPullRequest` outputSchema says `baseBranch`/`headBranch` is "The created PR's actual … ref", copied from `createPullRequest`.
  - The `deleteEntrySources` dry-run `message` reads "Would delete 1 entries".
- **Dedupe:** w1/200 covered `docs/mcp.md`, and w3/192 covered the dashboard trial-balance copy. These are the served descriptions. No tool names change, so the website's `mcp.json` sync is unaffected.

**Resolved 2026-11-10.** All three claims, and the two from the same pass, now match what is served.

1. **BQL columns:** `runBqlQuery`'s list names `weight` in place of `change`. Every listed column was run against `@rustledger/wasm` 0.24: `change` is "column 'change' not found", and `weight` answers the posting's weight.
2. **Trial balance:** the read (REST, the MCP template, OpenAPI) now says "Each account's balance per currency, as signed trees under the five roots …: debits positive, credits negative. No debit or credit totals are returned."
3. **`addLedgerEntries`:** it now says that custom and query are added with `appendLedgerText`, and option and plugin by editing the main file with `updateLedgerFiles`.
- **Same pass:**
  - The pull-request result's `baseBranch`/`headBranch` read "The pull request's … branch, read back from the repository — never a default" on REST, GraphQL and MCP; the word "created" is gone from the merge and reject outputs.
  - The batch delete's message counts "1 entry", in both preview and commit, in the ledger's service and route (`entryCount`).
- **Contract:** the OpenAPI snapshot changes in descriptions only. The CLI's pinned spec is re-synced and its client regenerated. The LobeHub submission record (`docs/marketplace-submissions/lobehub/lhm.plugin.json`) keeps the text as submitted; it is refreshed from the deployed metadata by its own process.
- **Tests:**
  - `served-description-claims.test.ts` reads `tools/list` and `resources/templates/list` through an SDK client and pins each fix. Reverting fails all four cases.
  - `entry-count.test.ts` and `source-slice-dry-run.test.ts` pin the count. (`backend-v2`, `ledger`, `cli` generated client)
