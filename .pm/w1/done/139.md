# Close and ask skills detect recurring charges by `payee`, which `bea import` leaves empty for one-description CSVs

**Severity: minor. Owner: skills. Estimate: ~30m. A1:** month-end close must catch a missing subscription. Continuous CLI QA (skill-driven workflow), 2026-10-03 (round 9); report and filing only, no fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command with timeouts, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced twice with a working control.

```sh
bea --json --no-input init "$PWD" --currency USD --date 2026-01-01
# bank.csv: Date,Description,Amount — NETFLIX.COM -15.49 on 2026-01-12 and 2026-02-12; SAFEWAY on 01-20, 02-20, 03-20
bea --file $PWD/main.bean --json --no-input import bank.csv --csv auto --account Assets:Checking --duplicates review --apply
```

Then run the close checklist's recurring query (`SELECT payee, year(date), month(date), sum(cost(position)) … WHERE account ~ '^Expenses:' GROUP BY payee, year, month`).

Actual: only `None 2026 1`, `None 2026 2`, `None 2026 3` — every imported row groups under an empty payee, so the missing March NETFLIX charge is never reported ("Recurring gaps: 0"). The ask skill's subscription recipe returns one `null` group of 9 rows.

Expected: `skills/.claude/skills/beancount-close/SKILL.md:46` and `references/close-checklist.md:30–37` — a recurring gap is reported.

Cause: `bea import` maps a single description column to `narration` by design (`cli/docs/IMPORTING.md:70`); the skill queries group only by `payee` — `beancount-close/references/close-checklist.md:33–34`, `beancount-ask/references/bql-recipes.md:55–56`, `:62–63`.

Fix/acceptance: group by `coalesce(payee, narration) AS merchant` (verified to list NETFLIX.COM for Jan and Feb and not Mar) and filter on it in the per-merchant recipe; a skills behaviour test imports a payee-less CSV and finds the gap.

Dedupe: no `.pm` hit (incl. `w2/done/m5`); query from `b2d49003`.

---

**Resolved 2026-10-04** — the close and ask skills now detect recurring charges by merchant — `coalesce(payee, narration)` — so gaps in payee-less imported bank CSVs are reported; the queries are executable recipes covered by a behaviour test in `skills/scripts/test_beancount_skills.py`.
