# A `currency=` mapping that differs from the header only by case silently becomes a constant commodity

**Severity: minor. Owner: cli. Estimate: 20–30m. A1:** a mapping typo must not relabel every row's currency. Continuous CLI QA, 2026-10-02 (round 2); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed unless a PTY is stated. Reproduced at least twice from pristine fixtures.

CSV header `Date,Description,Amount,Currency`, row `2026-01-05,Hotel Paris,-120.00,EUR`; accounts opened without currency constraints (multi-currency).

```sh
bea --file /abs/main.bean import /abs/x.csv --account Assets:Checking --csv date=Date,narration=Description,amount=Amount,currency=CURRENCY --apply
```

Actual: writes `-120.00 CURRENCY`, exit 0, `check` clean — every per-row EUR/GBP is relabelled. Controls: `currency=Currency` writes `-120.00 EUR`; the same case typo in `amount=AMOUNT` is refused ("names column 'AMOUNT' … which x.csv lacks").

Cause: `cli/src/bea_engine/csv_mapper.py:777–780` treats any value that matches no header exactly and looks like a commodity as a constant; the preview never says a constant was assumed.

Fix/acceptance: if the value matches a header case-insensitively, refuse with "did you mean 'Currency'?"; otherwise accept a constant only when the ledger knows it (declared commodity, open currency, operating currency) and print a note that a constant currency is in force. Repro exits 2 naming `Currency`; `currency=EUR` still works.

Dedupe: the constant form came from `w3/421` / `w3/m49/t004` without a typo guard. [060](./060.md) covers cell injection, not this.

---

**Resolved 2026-10-03** — a mapped CSV column that differs from a header only by case is now refused with the header it probably meant, a constant `currency=` must be a commodity the ledger already knows (declared, opened, used, or operating), and the preview notes when a constant currency is in force. `tests/test_import.py` (`TestCsvRowCurrency`) covers the typo, the unknown constant and the declared-commodity control. Shipped in the commit that moved this note (`cli`).
