# `bea balance ACCOUNT` hides closed accounts that still hold money, so totals disagree with the trial balance

**Severity: major. Owner: cli. Estimate: 30–45m. A1:** agents checking balances must not get silently understated totals. Continuous CLI QA, 2026-10-02 (round 2); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed unless a PTY is stated. Reproduced at least twice from pristine fixtures.

```beancount
option "operating_currency" "USD"
2024-01-01 open Assets:Bank USD
2024-01-01 open Assets:Old USD
2024-01-01 open Equity:Opening
2024-01-02 * "fund"
  Assets:Bank  100 USD
  Assets:Old    50 USD
  Equity:Opening
2024-12-31 close Assets:Old
```

```sh
bea --file /abs/closed.bean balance Assets
bea --file /abs/closed.bean balance Old
```

Actual (exit 0): `Assets 100 USD` with only Bank listed (JSON `balance_children {"USD":"100"}`); `bea balance Old` prints "No accounts match Old." on stderr. With `-t 2024-01` the 50 USD reappears.

Expected: `Assets 150 USD` (Bank 100, Old 50) — `bean-query "SELECT account, sum(position) WHERE account ~ '^Assets' GROUP BY account"`, `bea report trial-balance -a Assets` and plain `bea balance` all agree. `bea check` passes; Beancount allows closing a non-empty account.

Cause: `cli/src/bea_engine/report.py:110–115` (`_balances`) collects every `Close` regardless of date or balance; `_prune_tree` (`report.py:661–662`) drops those accounts from the tree and parent totals; message at `cli/src/cli/commands/report.py:382–383`.

Fix/acceptance: exclude only accounts closed on/before the as-of date **and** with an empty balance. On the fixture `balance Assets` reads 150 (Old 50) and `balance Old` shows 50 USD; `test_filtered_views_exclude_closed_accounts` (zero-balance closed account hidden) still passes. Qualify the USAGE line "Closed accounts are excluded from filtered views".

Blast radius: `bea balance` with arguments only; `report * -a` is the working control.

Dedupe: exclusion added in `79553f2c` (`w1/done/m15`) for zero-balance accounts only; nearby `w3/294`, `322`, `379`, `396` don't cover it.

---

**Resolved 2026-10-03** — filtered `bea balance` views now keep closed accounts that still hold a balance (only empty closed accounts are hidden), so totals agree with the trial balance. A test in `tests/test_customer_workflows.py` covers it. Shipped in the commit that moved this note (`cli`).
