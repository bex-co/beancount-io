# Any `.output` line in the beanquery init file breaks every managed `bea query` with a raw AttributeError

**Severity: minor. Owner: cli. Estimate: 20–30m. A1:** a harmless user config line must not break queries. Continuous CLI QA, 2026-10-03 (round 10); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1 (Beancount 3.2.3, beanquery 0.2.0), Python 3.13, macOS 26.5.1 arm64. Fresh process per command with timeouts, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME` (so `~/.config/beanquery/init` below is the isolated home), notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced at least twice with a working control.

```sh
printf '.output /abs/other.txt\n' > ~/.config/beanquery/init     # or .output main.bean
bea --file /abs/main.bean query 'SELECT count(*)'
```

Actual: exit 1 `Error: 'PreciseShell' object has no attribute 'context'` (ledger preserved). Control: an init file with `.set format csv` works (output becomes CSV).

Cause: `cli/src/bea_engine/query.py:564` constructs `PreciseShell(LEDGER_DSN, stream, interactive, True, …)` (`runinit=True`); upstream replays init inside `DispatchingShell.__init__`, before `self.context` exists, and the guarded `do_output` → `_redirect_output` reads `shell.context` (`query.py:271`). Introduced by the shared refactor in `a048d307` (`w1/done/038`).

Fix/acceptance: construct with `runinit=False` and replay init after loading, as `native_interactive` does (`query.py:314–323`). With init `.output X`, `bea query` works (or refuses clearly); with init `.output <ledger>` it refuses. Fix together with [142](./142.md).

---

**Resolved 2026-10-03** — a `.output` line in `~/.config/beanquery/init` no longer breaks `bea query` with a raw AttributeError: the init file is replayed once the ledger is loaded on every path, it redirects normally, is refused when it names a ledger file, and an explicit `--output` takes priority. `tests/test_query_init_file.py` covers each case. Shipped in the commit that moved this note (`cli`).
