## Objective

Protect the shared theme contract and the user-visible behavior of all three templates with focused tests that catch brand, fallback, responsive, dark-mode, content-parity, and security regressions.

## Context

- Existing tests cover structure, key copy, URL validation, escaping, and several old hard-coded blue values.
- Tests should assert semantic style roles and required output behavior, not snapshot entire HTML documents or freeze harmless whitespace.
- backend-v2 package checks are the release gate for this code because there is no package-wide GitHub Actions workflow.

## Steps

1. Replace obsolete color-specific assertions with stable checks for the shared dashboard-aligned theme roles and generated output.
2. Add coverage for light inline fallbacks, dark-mode selectors/metadata, narrow-layout rules, all-template preview inclusion, and long-content safety.
3. Retain and extend tests for escaping, URL rejection, plain-text parity, CTA targets, OTP visibility, and expiration guidance.
4. Run focused Jest tests, then backend-v2 lint, typecheck, and build from the package directory.

## Acceptance criteria

- [ ] Tests fail when shared brand roles, safe fallbacks, dark-mode support, template inclusion, or required CTA/content behavior regresses.
- [ ] Existing URL/XSS protection and plain-text behavior remain covered.
- [ ] Tests avoid full-document snapshots and tautological assertions.
- [ ] Focused tests plus `yarn lint`, `yarn typecheck`, and `yarn build` pass from `backend-cluster/backend-v2/`.

## Out of scope

- Artificial coverage targets or tests for unrelated backend-v2 features.
