## Objective

Keep bea ask's AI work in the frontend and perform ledger operations only through engine commands.

## Context

- ask/agent.py currently mixes AI SDK use with Beancount parsing and query/write helpers.
- The optional AI packages must not become engine/helper dependencies.

## Steps

1. Replace direct query, validation, and write library calls with the existing native/helper command contracts.
2. Use BQL, ledger text, and business results; preserve tool errors, exact amounts, write confirmation, and credential handling.
3. Exercise tool calls with deterministic AI/provider fixtures and real engine subprocesses.

## Files

- cli/src/cli/ask/agent.py; CLI ask tools; cli/pyproject.toml
- engine helper contracts; cli/tests/

## Acceptance criteria

- [ ] Ask queries and validated writes work without Beancount/Beanquery/Fava loading in the AI process.
- [ ] The engine imports no AI SDK, and the base install remains free of optional AI dependencies.

## Out of scope

- New AI capabilities, live credentials/provider calls in tests, or private-object RPC.
