# `doctor roundtrip` through a symlinked ledger overwrites and deletes a file beside the real ledger

**Severity: major. Owner: cli. Estimate: ~20m. A1:** a diagnostic command must never delete ledger files. Continuous CLI QA, 2026-10-03 (round 12); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command with timeouts, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced at least twice with before/after hashes and a working control. Found by a regression hunt over shipped fixes.

`books/main.bean` contains `include "main.roundtrip1.bean"` plus one transaction; `books/main.roundtrip1.bean` holds the `open` directives; `link.bean` is a symlink to `books/main.bean`.

```sh
bea doctor roundtrip link.bean
bea --file books/main.bean check
```

Actual: exit 0 "Entries are the same. Congratulations."; `books/main.roundtrip1.bean` is **deleted**; afterwards `check` exits 1 (include matches no files, unknown accounts). Control: `bea doctor roundtrip books/main.bean` exits 4 with the collision refusal and leaves the file intact.

Expected: the `w3/done/409` collision guard holds for symlinked paths (its note listed symlink aliases as unverified).

Cause: `cli/src/cli/commands/doctor.py:197–205,223` derive scratch names from the path as typed (`link.roundtrip1.bean`), while upstream `ledger_path = click.Path(resolve_path=True, …)` (`beancount/scripts/doctor.py:37`) resolves the link and writes/unlinks `books/main.roundtrip1.bean`. Gap in `d00a9aea`.

Fix/acceptance: `os.path.realpath(ledger)` before `splitext` in `_roundtrip_artifacts` (optionally assert upstream's `resolve_path=True` in the existing upstream-source test). The symlink repro exits 4 with the file byte-identical; a symlinked ledger with free scratch names runs and leaves no artifacts.

---

**Resolved 2026-10-04** — `doctor roundtrip` now derives its scratch names beside a symlinked ledger's real file, as upstream does, so it refuses instead of overwriting and deleting an include there. Tests in `tests/test_doctor_roundtrip_collisions.py` cover it. Shipped in the commit that moved this note (`cli`).
