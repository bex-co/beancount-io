## Steps

2. Create a billing portal configuration that allows payment-method updates, invoice history, billing address and tax ID, and disables subscription update and cancellation. Set its ID in production through the variable t003 adds, then redeploy.

   - add `invoice.paid` to the live webhook endpoint's events;
