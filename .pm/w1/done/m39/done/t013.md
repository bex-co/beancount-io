## Objective

Add tests that fail if the shipped behaviour breaks, using synthetic fixtures and mocked Stripe responses only.

## Context

- Same constraint as m37: no live charge, coupon redemption or subscription mutation, and no real customer data in fixtures.

## Steps

1. Backend:
   - classification over every configured price pair;
   - proration time passed through;
   - `ACTIVE`, `REQUIRES_ACTION` and `FAILED` mapping;
   - refusal of scheduled kinds and legacy targets;
   - per-session return URLs;
   - portal configuration;
   - authorization denial for API-key and OAuth credentials;
   - the edge cases: a legacy price choosing the same tier and cycle, two active subscriptions, double confirms, and Checkout for an existing subscriber.
2. Pricing-page contract (milestone README):
   - `createSubscriptionSession` accepts the pricing page's client and every price it sells, and returns a session URL;
   - `subscriptionStatus.hasActiveSubscription` keeps its meaning on both the verified-cache path and the live Stripe path;
   - `/settings/general` still links to Billing;
   - the sign-up `next=/pricing?billing=yearly` round trip still lands back on the pricing page.
3. Dashboard:
   - summary card and "Pay yearly" visibility;
   - plan row defaults;
   - sheet amounts and failure states;
   - the authentication fallback;
   - confirmation polling and timeout;
   - deep-link validation;
   - each prompt's recommended plan.

## Files

- Tests next to the changed modules in `backend-cluster/backend-v2/src/features/stripe/` and `dashboard/src/features/user-settings/`

## Acceptance criteria

- [x] Each test fails when its behaviour is reverted.
- [ ] The pricing-page contract test fails if any price the pricing page sells is refused.
- [ ] No snapshot-everything or tautological tests.
- [ ] Both packages' full gates pass.

## Out of scope

- Browser end-to-end runs against live Stripe.

## Outcome — 2026-10-18

The task's list was mapped against the tests already shipped by t001–t010 and m40. The mapping covers classification over every price pair, proration pass-through, outcome mapping, the edge cases, the confirmation polling, deep-link validation, sheet failures and the authentication fallback. Only the gaps were filled. Every new test was mutation-checked: break the code it covers, see it fail, then restore.

**Backend:**
- **Credentials:** API-key and OAuth are now denied for every `user.billing.*` action. `authorization-service.test.ts` builds its list from the registry, with a floor of nine, so the three plan-change actions are no longer missing. `subscription-service-authorization.test.ts` runs every billing case for both credential types.
- **Pricing-page contract:** `createSubscriptionSession` is exercised through the real GraphQL schema for each of the six prices the pricing page sells. Each case checks the session URL, the line-item price and promotion codes.
- **Immediate-only refusals:** they now cover TO_MONTHLY and SPLIT as well as DOWNGRADE.
- **Retired targets:** a preview of a retired target fails validation before any Stripe call.

**Dashboard:**
- **Sign-up round trip:** the `next=/pricing?billing=yearly` round trip is tested through the real routes, using the URL the pricing page builds. A signed-in visitor gets a document redirect, an unsafe `next` falls back, and a finished sign-up does a document navigation back to pricing.
- **Billing summary card:** the price, the legacy label, the card, the renewal date and the "Pay yearly" offer.
- **`BillingSummaryLink`:** it names each tier and links to Billing.
- **Collaborators-limit prompt:** it recommends the next tier up.

**Bug found and fixed:** "Pay yearly" compared against the list price rather than what the subscriber pays. A $9.99 legacy monthly subscriber was told they would "save $36.00" by moving to $143.88, when it would cost them $24 more a year. The offer now compares against twelve of the subscriber's own payments, and it is hidden when yearly saves nothing.

**Also shipped here:** [w1/176](../../../done/176.md). Checkout now refuses the retired prices, because the pricing page sells $143.88 in production.
