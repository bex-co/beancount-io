## Objective

Prove the milestone works where customers pay: in production, against the deployed revision, with real Checkout and real subscription changes, at no cost. This is the user's requirement of 2026-10-18. Automated tests and read-only checks are not enough evidence on their own.

- **Credentials:** `QA_EMAIL` and `QA_PASSWORD` in `beancount-io/.env`, which is gitignored. Read them at run time. Never print, log, commit or paste them anywhere, including this board.
- **Coupons:** two production coupons, each with:
  - `percent_off: 100` and `duration: forever`, so prorated change invoices are $0 too, not only the first one;
  - one single-redemption promotion code;
  - an expiry within a few days.
  t004 created them on 2026-10-18 through the worker's live Stripe CLI access, restricted to the three Beancount products. The promotion codes expire on 2026-10-25; after that, mint a fresh single-use code on the same coupon from the CLI. Codes never enter the board, a commit or a log.

- **Pricing-page contract:** see the milestone README. Flow A starts on `beancount.io/pricing`, so the test also proves that page still sells.
- Run this only after the milestone's code is deployed. Record the backend and dashboard revisions.

## Steps

1. Sign in as the QA account. It must start on Free with no subscription; if it does not, end its existing subscription first (see step 5).
2. **Flow A — coupon 1, yearly from the pricing page:**
   - Choose Premium · Yearly on `beancount.io/pricing`, enter the promotion code in Checkout, and pay $0.
   - Expect the dashboard confirmation, then Billing showing Premium · Yearly renewing in a year at $143.88.
   - Expect quotas and `bea --json cloud status` to say PREMIUM.
   - Then upgrade to Growth · Yearly in the change sheet: the preview shows $0 due, the change applies at once, and Growth limits and the Growth badge appear.
3. **Flow B — coupon 2, monthly from the dashboard, then switch to yearly:**
   - End the Flow A subscription immediately (step 5).
   - Check out Premium · Monthly from the Billing tab with the second code.
   - Use **Switch to yearly**: the renewal date moves one year out, the cycle reads Yearly, and the tier stays Premium on every surface.
4. **Edge cases without a coupon:**
   - Cancel a Checkout once: you return to the pricing page with the plan and cycle, and nothing is charged.
   - Open a mistyped and an unsafe deep link: Billing renders.
   - Open `/settings/general`: one click reaches Billing.
   - Switch the language to Chinese once and check the Billing copy.
   - Analytics: in GA4 DebugView or Realtime, see `plan_change_previewed`, `plan_change_confirmed` and `checkout_started` from Flows A and B. A $0 purchase deliberately sends no server-side `purchase` (t010), so confirm only that the webhook acknowledged `invoice.paid`.
5. **Cleanup:** end both QA subscriptions immediately, using live access or the operator (the product's own cancel only ends at period end). Deactivate any unused code. Confirm the QA account reads Free again.
6. Record public-safe evidence in the milestone README: date, revisions, each step's pass or fail, and what was cleaned up. No codes, emails, or customer or subscription identifiers.
