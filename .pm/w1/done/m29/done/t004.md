## Objective

A managed price is only trustworthy if its freshness is inspectable. ADR 015 already defines the vocabulary; the CLI should speak it in both human and JSON output.

## Context

- ADR 015 section 8: per-source url, alias, commodity, quote, source, revision, ETag, observed-at, fetched-at, next-refresh-at, freshness (`recent`, `stale`, `unavailable`), last error, and the shadowed count. Freshness is computed at read time, never stored: recent within ten minutes, stale beyond it, unavailable when no validated revision exists.
- ADR 015 section 5: a manual refresh is a head update that sets the next refresh time to zero.
- `bea price` already exists as the Beanprice forward, so the new subcommands must not collide with it — `cli/src/cli/commands/price.py`.
- ADR 015 section 10: when a managed URL has no validated revision, the missing-file report names the include as written, its file and line, and says the source is unavailable; the cause travels in the status record.

## Steps

1. Add a status view listing every managed source in the loaded ledger with the ADR 015 fields, in human and `--json` form.
2. Add a refresh action that zeroes the next-refresh time and re-resolves, reporting what changed.
3. Make the unavailable-source error name the include as written with its file and line, and point at the status view for the cause.
4. Keep the existing `bea price` Beanprice forward working unchanged, and make the command tree unambiguous.

## Acceptance criteria

- [ ] The status view lists every managed source with its freshness, revision, observed-at, next refresh, shadowed count, and last error, in human and JSON form.
- [ ] Freshness is computed at read time: a source unchanged for more than ten minutes reads stale.
- [ ] The refresh action re-resolves immediately and reports what changed.
- [ ] An unavailable source produces an error naming the include, its file and line, with the cause available in the status view.
- [ ] The existing `bea price` Beanprice forward is unchanged.

## Out of scope

- A price catalog browser or instrument search.
- Alerting on staleness.
