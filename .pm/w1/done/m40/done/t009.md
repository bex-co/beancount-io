## Objective

While a subscription is `past_due`, every dashboard page shows a banner: "We couldn't charge <card> for <plan>. Update it by <date> to keep <plan>." It has an **Update payment method** action that opens the billing portal with m39's pinned configuration.

## Context

- t003's status fields supply the card, the plan and the next attempt date. Copy: PRFAQ005 question 15 (Failed renewal).

## Steps

1. Read the past-due state from the shared subscription status query without adding a request per page.
2. Render the banner in the app shell, with a dismiss that returns on the next session.
3. Add every string to every locale catalog.

## Files

- The dashboard app shell, `dashboard/src/features/user-settings/hooks/`, locales

## Acceptance criteria

- [x] The banner appears only while `past_due`, shows the next attempt date, and opens the portal.
- [x] It adds no extra status request per page.

## Out of scope

- Payment collection inside the dashboard.

## Implementation notes

- `FailedRenewalBanner` (`dashboard/src/common/components/billing/`) sits under the header in the three signed-in shells: the ledger layout, the dashboard home and settings.
- It reads the shared `GetSubscriptionStatus` query, which Apollo caches. One request serves the session, and the Billing page reuses the same entry, so a page adds no request.
  - A past-due subscription keeps its paid tier, so the profile tier the root route already loads gates the query. A Free or signed-out user never sends it, which matters for churned users, whose status lists their whole subscription history.
  - The query is also skipped in the native app's web view and once dismissed. The dismissal is read from session storage only after hydration, so server and client render the same markup.
- It shows only for a `past_due` subscription with a `nextPaymentAttempt` (t003's bounded grace): "We couldn't charge <card> for <plan>. Update it by <date> to keep <plan>."
  - The plan is the profile tier's localized name, so legacy prices are named too.
  - The date is the next retry, in the app locale (`useBillingDateFormat`). The final retry date waits on t006's retry settings.
  - **Update payment method** opens the pinned billing portal through `useSubscriptionPortal`, using the subscription's own client ID.
  - The dismiss button hides the banner for the browser session.
  - It is a `role="status"` region, so remounting it across shells does not re-announce it assertively.
- Four new strings in the common catalog, in 15 locales. Shell tests stub the banner next to their other mocks; it has its own tests, including the Free and signed-out skip.
