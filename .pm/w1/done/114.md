# A flag or keyword written without a following space marks a real directive `generated`, and `--on-disk` hides it

**Severity: minor. Owner: cli. Estimate: 20–30m. A1:** valid Beancount spelling must not change what bea reports as written. Continuous CLI QA, 2026-10-03 (round 6); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1 (Beancount 3.2.3), Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed unless piping JSON. Reproduced twice with a working control; compared against native `bean-check`/`bean-query`.

```sh
printf '2024-01-01 open Assets:Cash USD\n2024-01-01 open Expenses:Food USD\n2024-01-05 *"Payee" "nospace"\n  Expenses:Food  1 USD\n  Assets:Cash\n2024-01-06 txn"T" "txnglued"\n  Expenses:Food  1 USD\n  Assets:Cash\n2024-01-07*"P" "dateglued"\n  Expenses:Food  1 USD\n  Assets:Cash\n2024-01-08 * "ok" "control"\n  Expenses:Food  1 USD\n  Assets:Cash\n' > main.bean
bea --file /abs/main.bean list transaction
bea --file /abs/main.bean list transaction --on-disk
```

Actual: `bean-check` exits 0 (the lexer splits these tokens without whitespace); `list` shows the first three rows `generated`; `--on-disk` returns only the control row; `bean-query` reports correct `main.bean:3/6/9`. `2024-01-01open Assets:Cash USD` likewise vanishes from `list open --on-disk`.

Expected: USAGE — `generated` marks only plugin rows; `--on-disk` is what grep finds.

Cause: `cli/src/bea_engine/ledger/reader.py:78` (`_DATE_TOKEN = …\s+(\S+)`) requires whitespace after the date and captures to the next whitespace; `:123` needs `_TXN_TOKEN` to match that whole token and `:124` needs it to equal the directive word (from `c2041585`).

Fix/acceptance: mirror the lexer — optional whitespace after the date, then the directive word or flag at the token start (`txn|[*!&#?%]` glued is fine, `[A-Z](?=\s)` for capital flags, `\b<keyword>` otherwise). No fixture row is `generated`; `--on-disk` returns all 4.

Dedupe: distinct from `w3/394` (slash dates) and [049](./049.md) (U+2028 drift).

---

**Resolved 2026-10-03** — a flag or directive keyword written without a following space (`*"Payee"`, `txn"T"`, `2024-01-07*`, `2024-01-09open`) now counts as written, so those rows are no longer marked `generated` and stay in `--on-disk`; a capital-letter flag must still stand alone, as Beancount's lexer requires. `tests/test_on_disk_glued_tokens.py` covers each spelling. Shipped in the commit that moved this note (`cli`).
