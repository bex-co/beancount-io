## Objective

Define the preset-question pool for the Ask page as translation keys in the ai-agent feature locales, covering every supported language, so t003 can render localized suggestion chips. Questions must be ones the AI can only answer with the user's own ledger data — not generic "what is double-entry" prompts.

## Context

- Feature locales: `dashboard/src/features/ai-agent/locales/` (currently 15 languages: en, bg, ca, de, es, fa, fr, ja, ko, nl, pt, ru, sk, uk, zh).
- Translation pipeline: `dashboard/scripts/prepare-translations.ts` and `dashboard/scripts/translate-todos.ts`; aggregation via `dashboard/src/locales/index.ts`.
- Starting pool (English): "How much did I spend on dining last month?", "What's my current net worth?", "Show my top 5 expense categories this year", "Any transactions I haven't categorized?", "Compare this month's spending to last month", "What's my largest single expense this quarter?"

## Steps

1. Add a namespaced key set (e.g. `aiAgent.suggestions.*`) with the pool to `locales/en.ts`.
2. Run the existing translation pipeline to fill the other languages; spot-check output.
3. Verify keys resolve through the `src/locales` aggregation layer.

## Files

- `dashboard/src/features/ai-agent/locales/*.ts`
- possibly `dashboard/scripts/translate-todos.ts` config/lists if new keys need registration

## Acceptance criteria

- [ ] All preset questions resolve via `t("aiAgent.suggestions.*")` in every supported language.
- [ ] No hardcoded question strings in components.
- [ ] `yarn typecheck` passes in `dashboard/`.

## Out of scope

- The chip UI and rotation logic (t003).
- Personalizing the pool based on user history.
