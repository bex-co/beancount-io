## Objective

Render 3–4 randomly rotated preset questions as clickable chips above the chat input in the empty state; clicking one submits it immediately by reusing the existing `?q=` auto-submit mechanism. Chips disappear once the conversation starts.

## Context

- Auto-submit already exists: `dashboard/src/features/ai-agent/pages/ask-ai/index.tsx` reads `searchParams.q` and dispatches a form submit (lines ~87–108). A chip can set the input and trigger the same path — no new submission plumbing.
- Question pool comes from t002 (`aiAgent.suggestions.*`).
- Rotation: pick 3–4 per mount (stable for the session is fine); biasing by user history is explicitly later work.

## Steps

1. Build a small suggestion-chips component in the ask-ai page folder that samples 3–4 keys from the pool on mount.
2. Render it between the message list and the input form only while `messages.length === 1` (welcome only).
3. Wire chip click to the same submit path as `?q=` (set input + dispatch submit, or navigate with `?q=`).

## Files

- `dashboard/src/features/ai-agent/pages/ask-ai/index.tsx`
- new component under `dashboard/src/features/ai-agent/pages/ask-ai/`

## Acceptance criteria

- [ ] Empty state shows 3–4 chips in the active locale.
- [ ] Clicking a chip submits that question and the chips vanish as the conversation starts.
- [ ] Chips never render once there are user/assistant messages beyond the welcome.
- [ ] No chip renders while a stream is in flight.

## Out of scope

- Contextual follow-up suggestions after each answer (P1).
- Analytics on chip CTR (needs the analytics review separately).
