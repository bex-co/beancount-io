# Tags, links, flags and currencies are not validated as tokens, so one value splits or injects directives

**Severity: major. Owner: cli. Estimate: 45–60m. A1:** agent-written values must produce exactly the one entry requested. Continuous CLI QA, 2026-10-02; report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command, stdin closed, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`, synthetic fixtures. Reproduced twice from pristine fixtures.

Use a synthetic root with `option "operating_currency" "USD"`, `2026-01-01 open Assets:Cash`, `2026-01-01 open Equity:Opening`, and `2026-01-01 open Expenses:Food USD` (each on its own line). The previous reference to 045 collided with the typed-metadata note; related CSV currency injection is now tracked in [060](./060.md).

```sh
printf '%s\n' '[{"date":"2026-02-01","narration":"x","tags":["trip\n2026-01-01 open Assets:Evil\n2026-02-01 * \"y\""],"postings":[{"account":"Expenses:Food","amount":"1 USD"},{"account":"Assets:Cash"}]}]' > tx.json
bea --json --file /abs/main.bean add transactions --from /abs/tx.json
touch r.pdf; bea --json --file /abs/main.bean add document --date 2026-02-01 -a Assets:Cash --filename r.pdf --tag 'a#b' --link $'q\n2026-01-01 open Assets:Evil'
bea --json --file /abs/main.bean add open --date 2026-02-01 -a Assets:New -c $'USD\n2026-01-01 open Assets:Evil'
bea --file /abs/main.bean add open --date 2026-02-01 -a Assets:New2 -c 'EUR,GBP'
```

Actual (all exit **0**): bulk reports `"written": 1` but writes a posting-less `* "x" #trip`, an `open Assets:Evil`, and `* "y"` carrying the postings (bulk `"flag": "*\n…"` does the same). `add document` echoes `tags:["a#b"]` but the file holds `#a#b ^q` plus an injected `open`. `add open -c` and `add commodity -c` inject an `open`; `-c 'EUR,GBP'` opens with two currencies. `--tag 'a ^b'` silently becomes tag `a` + link `b`, and `--link 'x^y'` two links, including on single `add transaction`.

Working control: single `add transaction` re-parses its header and requires exactly one entry (`adding.py:484`), so it refuses the newline cases — but still accepts the sigil splits.

Expected: each `--tag`/`--link`/`--flag`/`-c` value (and the bulk JSON fields) is exactly one Beancount token, otherwise exit 2 and the file unchanged — matching how `--tag 'a b'` is already refused and USAGE's "additions never modify existing lines" / one-entry contract.

Cause: `cli/src/bea_engine/ledger/models.py:29–30` (`Tag`/`Link` only strip a sigil), `models.py:198` (`flag: str` unconstrained), `ledger/adding.py:91–92` and `:126` (currencies only stripped/non-empty), `writer.py:209–243` (`normalize_entry_strings` flattens quoted strings only), `write.append` (`write.py:846`) no re-parse check.

Fix/acceptance: validate in the models — tag/link `[A-Za-z0-9\-_/.]+` after the sigil, flag a single valid flag char or `txn`, currency `_CURRENCY_CODE`. Defence in depth: `write.append` re-parses the appended text and refuses when the entry count differs. All five commands exit 2 with the file byte-identical; `--tag trip`, `--tag '#trip'`, `--link '^inv-001'`, `-c USD -c EUR` keep working. Run `make check-all`.

Dedupe: `w3/done/223` covers only the header-error headline (residual: newline-in-`--tag` on single add still blames `--posting 1`; fold into this fix). Commits `2111cec5`, `95c2e7e6` strip sigils without validating. No `.pm` hit for inject / sigil split / tag newline.

---

**Resolved 2026-10-03** — tag, link, flag and commodity values in `bea add` (single and bulk) must each be one Beancount token, otherwise exit 2 with the file unchanged, and every append checks that each rendered directive reads back as exactly one directive; the token rules apply to write input only, so `bea list` still shows plugin-generated entries. `tests/test_add_token_injection.py` covers each option, bulk rows, the read-back check and plugin entries. Shipped in the commit that moved this note (`cli`).
