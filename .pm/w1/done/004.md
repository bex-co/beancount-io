# `bea cloud login` help hardcodes `~/.config/bea/credentials.json`

**Severity:** minor  
**Package:** `cli`

## Repro

`bea cloud login --help` says the session is stored in `~/.config/bea/credentials.json`. With `BEA_CONFIG_DIR` set, credentials actually land under that directory (`cli/src/cli/config.py` → `credentials_path()`).

## Expected

Help / docstring should mention `$BEA_CONFIG_DIR/credentials.json` (defaulting to `~/.config/bea`), consistent with `USAGE.md`’s env table.

## Actual

Docstring in `cli/src/cli/commands/cloud/app.py` and generated `docs/REFERENCE.md` hardcode the default path only.

## Fix

Rephrase the login command help; regenerate reference docs.

## Estimate

~15m
