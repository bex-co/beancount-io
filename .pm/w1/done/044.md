# Portable price export loses document paths reached through symlinks

**Severity: minor. Owner: cli. Estimate: 40–55m. A1/A2:** a valid ledger's successful portable export must remain usable when moved to another machine. Continuous CLI QA, 2026-10-02; follow-up to completed `w4/180`.

Environment: clean `main` at `97dab6b04c6e40e4cf47e0c1d668731d36c7ec41`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13.0, Darwin 25.5.0 arm64. Synthetic local files, absolute ledger/output paths, isolated child config/cache/data, notifier disabled, inherited target/token removed. Closed stdin, no TTY; each subprocess bounded to 15 seconds. No network feed is needed.

Create `books/receipt.pdf` with any synthetic bytes, a relative symlink `books/alias.pdf -> receipt.pdf`, and `books/main.bean`:

```beancount
2025-01-01 open Assets:Cash USD
2025-01-02 document Assets:Cash "alias.pdf"
```

Run:

```sh
bea --json --file /absolute/books/main.bean check
bea --json --file /absolute/books/main.bean price export --output /absolute/export
bea --json --file /absolute/export/main.bean check
```

Actual: source check exits **0**. Export exits **0**, empty stderr, manifest lists only `export/main.bean` and `export/receipt.pdf`. The copied ledger still refers to `alias.pdf`, which is absent. Export check exits **1** with `File does not exist: "/absolute/export/alias.pdf"`. Reproduced twice with fresh source and destination directories. Source text is unchanged.

Also reproduced: a symlinked parent directory `linked -> real` makes `document ... "linked/receipt.pdf"` fail in the export, which copies `real/receipt.pdf`; two aliases of the same receipt are collapsed to one canonical attachment, leaving both literal paths missing. Working controls: directly referencing `receipt.pdf`, or a hard link `hard.pdf` with a matching directive, exports and checks successfully.

Expected basis: `cli/docs/USAGE.md` promises a self-contained snapshot and documents beneath the root copied to the same relative place. Either preserve every relative reference and produce a checkable export, or refuse the unsupported alias before writing anything with an actionable message. Do not report portable success while leaving missing attachments.

Cause: `cli/src/bea_engine/managed_load.py:689` resolves `entry.filename` before allocating its destination at line 691. `_export_attachments` compares only canonical source/destination relative paths at line 701, losing the literal spelling the directive uses. Its dictionary is keyed by the resolved document, so multiple aliases collapse. `export_portable` copies that canonical file at lines 639–642; `_rewrite_export_includes` rewrites includes only, never document filenames. Caller search finds the sole production entry at `cli/src/bea_engine/main.py:674`, called through `cli/src/cli/commands/price.py:122`.

Fix/acceptance: preserve the lexical attachment path while using resolved identity for containment and alias protection, or explicitly refuse unpreservable references before the export plan writes files. Cover a file symlink, a directory symlink, two references to one target, and regular/hard-link controls. A successful export must pass the normal ledger check after relocation independently of the source directory. Keep outside-tree/absolute-document refusal and destination collision protection. Run meaningful regression coverage and `make check-all` in `cli/`; no new dependency or backend change.

Dedupe: searched all `.pm` states and open milestone READMEs for export documents, attachments, symlinks and `export_portable`. `w4/180` shipped attachment preservation in `d6d801e9`; its existing regular/nested-document acceptance still works. This alias case is residual scope in that implementation. `w4/171`, `w4/172`, `w3/412`, `w3/413` and `w3/436` address include placement/destination aliasing/collisions, not lexical attachment references. No overlapping open item found.

Evidence: `cli/tmp/qa-20261002-loop/captures.jsonl`, `export_docs.py` (two full repeats), `export_controls.py` (four adjacent cases), and retained synthetic source/export trees. Public reproduction above does not rely on ignored captures. Other OSes, managed feeds combined with attachments and auto-discovered `documents` option aliases remain unverified. No real ledgers, credentials, hosted resources, fixes or shipping.

---

**Resolved 2026-10-03** — portable `price export` now copies each document under the exact path its directive uses, so symlinked files and folders become plain copies and each alias gets its own copy; the moved export passes the ledger check, and the outside-tree and absolute-path refusals are unchanged. `tests/test_price_export_documents.py` covers file, folder, double-alias and hard-link cases. Shipped in the commit that moved this note (`cli`).
