## Objective

Scope the Home screen's currency to the selected ledger so Net Worth renders in the ledger's own operating currency (e.g. `$` for `open_ledger/airbnb`, which declares `operating_currency "USD"`), not a default ledger's currency.

## Context

- `mobile/src/screens/home-screen/home-screen.tsx:46` already has `const ledgerId = useLedgerGuard();`.
- Line 47 calls `useLedgerMeta(userId)` — no `ledgerId` — while line 58 correctly uses `useBalanceSheet(ledgerId)`. This mismatch makes the values come from airbnb but the `€` symbol come from the backend's default ledger.
- `useLedgerMeta(userId: string, ledgerId?: string)` already accepts and forwards `ledgerId` (`mobile/src/common/hooks/use-ledger-meta.ts:10-14`); sibling screens (`accounts-screen`, `add-transaction-next-screen`) pass it.

## Steps

1. Change `useLedgerMeta(userId)` to `useLedgerMeta(userId, ledgerId)` at `home-screen.tsx:47` (the `ledgerId` at line 46 is already in scope above the call).
2. Verify in the running app against `open_ledger/airbnb`: Home Net Worth shows `$`, matching the `$` amounts in Recent Transactions.

- `mobile/src/screens/home-screen/home-screen.tsx`
