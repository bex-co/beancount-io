# `doctor roundtrip` and `doctor print-options` ignore syntax errors in included files and exit 0

**Severity: minor. Owner: cli. Estimate: 30–45m. A1:** doctor's exit contract is what agents use to gate a ledger. Continuous CLI QA, 2026-10-02 (round 2); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed unless a PTY is stated. Reproduced at least twice from pristine fixtures.

`main.bean`:

```beancount
option "operating_currency" "USD"
include "sub/bad.bean"
2026-01-01 open Assets:Bank USD
2026-01-01 open Expenses:Food USD
```

`sub/bad.bean` (unterminated string):

```beancount
2026-01-11 * "Cafe" "Broken
  Expenses:Food  4.50 USD
  Assets:Bank
2026-01-12 * "X" "Y"
  Expenses:Food  1.00 USD
  Assets:Bank
```

Actual: `bea --file /abs/main.bean check` exits 1 (`sub/bad.bean:4: Invalid token: 'X"'`); `bea doctor roundtrip /abs/main.bean` prints the same error, then `Entries are the same. Congratulations.`, exit **0**; `bea doctor print-options /abs/main.bean` prints defaults with no error, exit **0**. Control: the same broken text in the root file makes roundtrip exit 1.

Expected: `cli/docs/USAGE.md` "`bea doctor` exit contract" — `print-options` and `roundtrip` exit 1 when the ledger does not parse.

Cause: `cli/src/cli/commands/doctor.py:121–134` (`_syntax_errors_of`) calls the engine `syntax` command, which does not follow includes (`cli/src/bea_engine/ledger/text.py:100–113`); used at `doctor.py:190` and `:243`.

Fix/acceptance: check syntax over the include closure for these two operations (`lex`/`parse` stay single-file like upstream). Both commands exit 1 naming the include's error, with no congratulations line.

Dedupe: `w3/409`, `w3/403`, `w1/m23/t004` cover other doctor issues, not includes.

---

**Resolved 2026-10-03** — `doctor print-options` and `doctor roundtrip` now check syntax across the ledger's whole include closure and exit 1 naming an error anywhere in it, with no congratulations line. `tests/test_doctor_include_syntax_errors.py` covers it. Shipped in the commit that moved this note (`cli`).
