## Objective

Remembered import settings are invisible and can silently corrupt a later import: a remembered `sign=ledger` flips amounts on a different export with the same header, a remembered explicit `--date-format` poisons a later file with a different convention, a missing remembered `--rules` path hard-fails, and a bare `--csv` refresh wipes the remembered rules and default account without saying so.

## Context

- `w3/279` (major): remembered `sign=ledger` silently flips later same-header exports.
- `w3/308` (major): remembered `--date-format` poisons a later same-header CSV with a different convention.
- `w3/310`: a missing or corrupt remembered `--rules` path hard-fails the import.
- `w3/311` (major): sticky `--rules` / `--default-account` are silent, and a bare `--csv` refresh wipes them.
- Sticky settings are persisted per ledger by the import command; the convention is documented in `cli/docs/IMPORTING.md`.

## Steps

1. Print the remembered settings that are being applied at the top of every preview, with the source file they came from.
2. Key remembered settings on more than the header row, or re-validate them against the file, so a different export cannot inherit a wrong sign or date convention; when validation fails, ask or refuse rather than applying.
3. Degrade a missing or unreadable remembered `--rules` path to a warning plus an unruled import, not a hard failure.
4. Never drop remembered settings silently: a refresh that discards them says which ones it discarded.

## Files

- cli/src/cli/commands/import_.py

## Acceptance criteria

- [ ] Every preview lists the remembered settings in force, or states that there are none.
- [ ] A second export with the same header but a different date convention is not silently parsed with the remembered format; the mismatch is detected and surfaced.
- [ ] A remembered `--rules` path that no longer exists produces a warning and an unruled import, exit 0, with the stale setting named.
- [ ] A bare `--csv` refresh reports which remembered settings it discarded.

## Out of scope

- Redesigning where sticky state is stored.
- Per-ledger configuration beyond the import settings.
