# `add document` accepts a `../` path outside the ledger directory that the next `bea check` rejects (as "absolute")

**Severity: minor. Owner: cli. Estimate: 25–35m. A1:** a write that succeeds must not leave a ledger that fails check. Continuous CLI QA, 2026-10-03 (round 14); report and filing only, no product fix applied.

Environment: `main` HEAD `97dab6b0`, checkout `cli/.venv/bin/bea` 0.3.1, Python 3.13, macOS 26.5.1 arm64. Fresh process per command with timeouts, isolated `HOME`/`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled, no inherited `BEA_FILE`/`BEA_TOKEN`/`CI`, synthetic fixtures, stdin closed. Reproduced at least twice with a working control. Found by a regression hunt over shipped fixes.

From `d/copy` (ledger `d/copy/main.bean`, file `d/orig/docs/inv.pdf` exists):

```sh
bea --file main.bean add document --date 2026-01-03 -a Assets:Cash --path ../orig/docs/inv.pdf     # exit 0, writes "../orig/docs/inv.pdf"
bea --file main.bean check                                                                        # exit 1
```

Actual: `check` (also `--json`, `-v`, `-C`) fails with `Document path '/…/d/orig/docs/inv.pdf' is absolute and outside the ledger directory`, though the user wrote a relative path; later adds keep succeeding on a ledger `check` fails. Inversely, `add` rejects an absolute path inside the tree that `check` would accept.

Cause: `add` checks only `Path(filename).is_absolute()` (`cli/src/bea_engine/ledger/adding.py:131`); `check` resolves and tests containment (`cli/src/bea_engine/main.py:747–764`), and Beancount makes every document path absolute on load, so the message always says "absolute". Gap in `56601140` (`w3/351`).

Fix/acceptance: one shared predicate — the resolved path lies inside the destination ledger's directory — for `add document` and `check`. `--path ../x.pdf` exits 2 with nothing written; an absolute in-tree path is treated identically by both; the check message quotes the path as written.

---

**Resolved 2026-10-04** — `add document` now refuses a path that climbs out of the ledger directory with `..`, using the same containment rule as `check`, whose message now quotes the path as written instead of calling it absolute. `tests/test_document_path_containment.py` covers it. Shipped in the commit that moved this note (`cli`).
