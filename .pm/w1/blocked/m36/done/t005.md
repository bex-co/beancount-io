## Objective

Remove text a reviewer could read as prompt injection or an upsell.

## Context

- Server instructions in the MCP route ("Start with `listLedgers`…", "Prefer resources…").
- `src/features/ai-agent/api/mcp-errors.ts` ("upgrade the plan").
- Tool descriptions and prompt text in `mcp-prompts.ts`.

## Steps

1. Rewrite each item as neutral description of behavior, per t001's quoted rules.
2. Keep `mcp-prompt-list.test.ts` and the error-code contract intact.

## Files

- backend-cluster/backend-v2/src/features/ai-agent/api/mcp-errors.ts
- backend-cluster/backend-v2/src/features/ai-agent/api/mcp-tools.ts

## Acceptance criteria

- [x] No instruction, description, or error text directs model behavior or mentions upgrading a plan. Error codes are unchanged.

## Out of scope

- Changing error codes or quota behavior.

## Result (2026-10-10)

- **Server instructions** (`buildInstructions`): every line now states what the server provides. Gone: "Start with…", "Prefer resources…", "After any write, check…", "branch on error.code and follow error.hint", and "wait, do not retry now". The facts stay: ledger defaults, the URI grammar, playbooks, `validation.newErrors`, the BQL posting caveat, the result envelope, and the budgets.
- **Tool descriptions:**
  - `appendLedgerText` no longer says "Use this, not editLedgerFiles"; it says it adds directives without rewriting files.
  - `checkLedger` drops "Call after any write…".
  - `getEntryContext` drops "what to read before editing it" and names the hash `editEntrySource` takes.
  - `listLedgers` drops "must call this first".
  - `refreshManagedPrices` drops "Use when a source is stale…".
- **Upsell:** the `RESOURCE_LIMIT_REACHED` and `PREMIUM_REQUIRED` hints are neutral. MCP also drops any sentence that names a plan, upgrade, premium, subscription, pricing, or paid from those two categories' messages and throw-site hints. "Ledger limit reached. Maximum: 1, Current: 1." keeps its numbers and loses "Upgrade to Premium…". Error codes, and GraphQL and REST messages, are unchanged.
- **Error hints:** hints that name the next call (`listLedgers` and the like) stay. Claude's checklist requires actionable errors, and its prompt-injection rules apply to descriptions.
- **Tests:** `mcp-instructions.test.ts` checks the instructions for steering and plan wording. `mcp-errors.test.ts` covers four plan-wording cases. `mcp-tool-list.test.ts` checks every served tool and prompt description. Restoring the old `appendLedgerText` wording, or removing the strip, fails them.
- **Gates:** backend-v2 `yarn typecheck`, `yarn lint`, and `yarn test` (5067 passed).
