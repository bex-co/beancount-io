# Decision needed: should `bea add close` refuse to close a used Income or Expenses account?

**Source:** routine cli-qa, 2026-11-15 (follow-up the run surfaced but did not file).

`bea add close` refuses to close any Income or Expenses account that has postings, saying it "still holds" its lifetime total:

```
bea add close -a Expenses:Food --date 2024-12-31
# → refuses: account still holds 45.50 USD (exit 1)
```

Its hint tells the user to post a transaction that moves the amount out. For a flow account that would distort the income statement, since an expense account's running total is history, not a balance to drain.
