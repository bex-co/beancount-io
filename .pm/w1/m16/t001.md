## Objective

Turn a CSV into preview-ready transactions from a column mapping given on the command line, reusing the whole existing import pipeline.

## Context

- `cli/src/cli/commands/import_.py` runs configured importers through `identify`, `account`, `extract`, then preview, duplicate matching, validation, diff, and `--apply`. It selects the configuration via `--config`, a remembered path, or `importers.py` beside the root.
- `cli/docs/examples/csv_importers.py` is a 50-line standard-library importer with the same shape this task generalizes.
- beangulp is not a dependency and must not become one here (see the milestone README).

## Steps

1. Add `--csv MAPPING` where MAPPING is `field=Column[,field=Column…]` with required `date`, `amount`, `payee`; optional `narration`, `id`, `currency` (else the operating currency), `debit`/`credit` as an alternative to `amount`, and `sign=bank|ledger` (default: negative means money leaving the source account).
2. Add `--account ACCOUNT` (required with `--csv`) as the source account; `--date-format` defaulting to ISO with `%m/%d/%Y` and `%d/%m/%Y` accepted explicitly.
3. Implement the mapper as an in-package importer class (`name = "csv"`) built from the mapping, so `--csv` and `--config` are mutually exclusive and everything downstream is unchanged.
4. On a row that fails to parse, exit 2 naming the CSV line, the column, and the value.
5. Expose the mapping in JSON preview (`importer`, `config_source: "--csv"`).

## Files

- `cli/src/cli/commands/import_.py`
- `cli/src/cli/directives/` (shared amount and date parsing helpers, if reused)

## Acceptance criteria

- [ ] The IMPORTING.md sample CSV imports with `--csv date=Date,amount=Amount,payee=Payee,narration=Narration,id=BankID --account Assets:Checking` and produces the same preview rows as the Python example.
- [ ] A debit/credit two-column export imports with `debit=Debit,credit=Credit`.
- [ ] A bad date exits 2 with line, column, and value.
- [ ] `--csv` with `--config` exits 2.

## Out of scope

- OFX and QIF (use a Python importer).
- Categorization (t002).
