## Objective

Implement the move as one shared workflow: remove each entry's slice from its file, append the slices to the target, add the `include` when asked, gate the whole projection, and commit once.

## Context

- `deleteEntrySources` already resolves and removes several slices in one commit (`backend-cluster/backend-v2/src/features/ai-agent/api/mcp-source-slices.ts`; batch resolution in `backend-cluster/ledger/src/foundation/rustledger/source-slice-resolver.ts`).
- `src/features/ledger/service/ledger-repo-service.ts` `changeFiles` commits several files atomically; `src/features/ledger/utils/file-write-gate.ts` projects and gates a multi-file change and lists `notLoaded` files.

## Steps

1. Resolve every listed entry's slice in one batch and check each `sha256sum`.
2. Build the projected files: each source file minus its slices; the target plus the slices in source order; `includeFrom` plus the `include` line when the target is not already reached.
3. Refuse an unreachable target without `includeFrom`. Gate the projection and honor `allowInvalid`.
4. On `dry_run`, return the diff; otherwise commit with `changeFiles` and return `commit`.
