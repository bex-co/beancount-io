Bank Sync has no way to give every selected staged row the same target account. The review table (`dashboard/src/features/plaid/components/transaction-review-table.tsx`) offers Select all, AI Fill (LLM suggestions limited to open accounts, which can leave rows blank) and per-row pickers. Submit refuses the whole selection while any row lacks a target ("{count} selected transactions need target accounts."). A user clearing a backlog to `Expenses:Uncategorized` has to set each row by hand. A user reported exactly this on 2026-11-08 and said doing it row by row is not a realistic workaround.

Add a "Set target account for selected" control that fills the target for every selected row, including rows the filters hide (submit already acts on those), and leaves per-row overrides editable afterwards. Translate it into every dashboard locale. The API needs no change: `importStagedBankTransactions` and REST `POST …/bank-transactions/submit` already take one target per row, so an agent can do the same through MCP. If the work runs past an hour with the locales and tests, promote this note to a milestone.
