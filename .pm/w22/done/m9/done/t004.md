## Objective

Deploy through the button into a scratch workspace and walk the same browser checklist as the canary, then tear it down.

## Context

- The browser steps are w22/m7 section 5: sign-up form, signed-in landing, cookie, refresh, a fresh-browser login, first ledger.
- Teardown by resource id, with a 404 proof for each, so the scratch workspace stops billing.
- Record anything the bex wizard does that surprises a first-time user and send it to the platform's own board; do not work around it here.

## Steps

1. Deploy via the badge into a non-canary workspace with the minimal prompts.
2. Run the browser flow against the new host.
3. Delete every resource and confirm 404s.

## Done 2026-11-09

- **Deploy:** a Blueprint made from `main` with the same body the badge sends (no inputs) into a workspace whose names were taken. Hostnames carried suffixes (`beancount-dashboard-1cjo`, `beancount-api-igu0`). Builds queued, then all four services went live in about 35 minutes.
- **Gitea:** `bex-entrypoint: schema gitea ensured` in its log, and it passed bex's readiness check on the first rollout.
- **Browser:** `dashboard/scripts/qa/run-self-host-sign-up.mjs --require-self-host` passed every check on the suffixed host: form renders, sign-up lands signed in, no verification page, HttpOnly + Secure host-only cookie, reload keeps the session, first ledger created, second ledger allowed, no console errors, account deleted. `/_internal/public-url` and `/.well-known/*` answered on the dashboard host.
- **Not covered by this run:** a separate fresh-browser sign-in and sign-out (the smoke test signs up and reloads, it does not sign out and back in). Same-origin cookie behavior is the same code path the canary exercises.
- **Teardown:** 4 services, Postgres, Key Value and the Blueprint deleted by id; each answered 404 afterwards, and the dashboard host answered 404.
- **Surprise for the platform's board:** a Blueprint made this way builds one image at a time, so the first rollout takes tens of minutes; reported there, not worked around here.
