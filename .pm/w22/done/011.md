# In Persian the Files list's file-type icon touches the file name; the 8pt gap English has moves to the screen edge

**Trivial · mobile · 10–15m · A3.** Native mobile QA, 2026-11-10, repository HEAD `6183533d9`, development build `io.beancount.ios` 1.20261002.50 on iPhone 17e / iOS 27.0, light, app language Persian after the layout restart, signed in as the QA account on an authenticated ledger. Read-only pass.

## Repro (reproduced twice, once per Persian session)

1. Switch the app to **فارسی** (Settings → Language → Restart now), open the **Files** tab.
2. The `</>` icon is drawn at the right edge, as it should be, but it sits directly against the file name: `main.bean</>`, `README.md</>`. The last letter of the name and the icon have no space between them. On the 3× capture the gap is about 1pt.
3. Switch back to English: the same row has the icon at the left edge and an 8pt gap before `main.bean`. In Persian the icon is also about 22pt from the screen edge, against the 16pt gutter in English, so the 8pt the row reserves for the gap has moved outside the icon.

**Expected:** the row mirrors as a whole, with the same 8pt between icon and name and the icon at the gutter, as the Settings and Accounts rows do in Persian.
**Actual:** icon flush against the name, extra space at the screen edge.

Local evidence: `.tmp/qa-20261110/fa2/files-full.png`, `row-zoom.png` (3× crop of the first row).

## Root cause (inferred from the geometry, not traced in the native layout)

`mobile/src/screens/ledger-file-browser-screen/index.tsx:153-155`: `rowIcon: { width: 28 }` is a fixed-width box around a 20pt Ionicons glyph (`:308-313`, `size={20}`). The icon sits at the box's physical left in both directions: in English that is its start edge, leaving the 8pt remainder toward the name; in Persian that is the edge facing the name, leaving the remainder at the outer side. An icon-font glyph has no right-to-left letters, so the stretched `Text` aligns it left regardless of the layout direction. No other style in the file uses a physical side (`marginStart` is the only margin, `:182`).

## Fix

Target: in Persian the icon sits at the start edge of its box (right) and keeps the same 8pt before the name, matching English mirrored. Keep the 28pt column so folders and files line up. Either align the icon to the box's start edge (`alignItems: "flex-start"` on `rowIcon`, which Yoga flips with the layout direction) or drop the fixed width and give the icon a `marginEnd` of 8; then check the dimmed (non-text file) row and the folder row, which share the style. Mobile only; no API surface.

## Blast radius

Settings, Accounts, Transactions and Merchants rows in Persian have correct spacing (captured in the same session), so this is that one row. The Example ledger's file browser (`/examples/(tabs)/ledger`) shares the screen. A folder row and the dimmed non-text-file row were not on screen in this ledger.

**Resolved 2026-11-10** — the Files row's icon box now mirrors with the layout, so in Persian the file-type icon sits at the gutter with the same 8 pt before the name as English has.
