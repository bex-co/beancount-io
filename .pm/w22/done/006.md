**Resolved 2026-11-08** — a committed, repeatable browser smoke test for a deployed self-hosted stack, shipped in `40feaa231` (`dashboard`, `deploy`). `dashboard/scripts/qa/run-self-host-sign-up.mjs --url <address>` signs up a throwaway account with a random address and password (nothing hard-coded), then checks: it lands signed in with no verification page, the browser keeps an HttpOnly, Secure cookie for that host, a reload keeps the session, a ledger is created (so the ledger service and Gitea work), a second ledger is allowed (no plan limit) and the page logged no errors; then it deletes the account unless `--keep`. On a stack that verifies email it reports "skipped" (exit 0), or fails with `--require-self-host`. It needs Playwright only where it is run, and says how to install it if missing. Verified against the bex canary (all ten checks pass, account deleted), unit-tested through a fake page (13 tests), and each check was broken on purpose to confirm a test fails.
