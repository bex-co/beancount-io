# After a live text-size change nearly all text on Notifications and on Commit detail is cut to its top half

**Minor · mobile · 40–50m (two screens) · A2.** Native mobile QA, 2026-11-10, repository HEAD `59f13b939`, development build `io.beancount.ios` 1.20261002.50 on iPhone 17e / iOS 27.0, light, English, signed in as the QA account on its synthetic `example` ledger. Read-only pass. The local captures show the QA account's commit authors and messages and are not for quoting.

## Repro (each screen reproduced twice, the second from a fresh relaunch)

1. Terminate the app, `xcrun simctl ui <udid> content_size large`, relaunch, dismiss the dev toast.
2. **Notifications:** the bell on Home. **Commit detail:** the same screen, then the first *Recent changes* row.
3. With the screen open, `xcrun simctl ui <udid> content_size accessibility-large` (AX2, the supported ceiling in `.pm/DO_NOT_DO.md`).

**Expected:** every line reads whole and the rows grow, as they do from a cold AX2 launch.
**Actual, Notifications:** the `LEDGER ERRORS` and `RECENT CHANGES` section titles, `Ledger is healthy — no errors.` and every commit row's message and its author/date/SHA line show only their upper halves, in the old row heights. **Actual, Commit detail:** the subject, the `Author:` line, `STATS` (its `+1 −1` is a single green pixel), `FILES`, the file row and the `DIFF` header and every diff line are cut to their tops.

**Control (cold):** terminate, set AX2 first, launch, open the same screens: both render whole, the messages wrap onto two lines and the metadata onto two.

Evidence is local only (`.tmp/qa-20261110/w22b/`): `30-notifications-live-ax2.png`, `33-notifications-live-ax2-repeat.png`, `35-commit-live-ax2.png`, `38-commit-live-ax2-repeat.png` against `31-notifications-cold-ax2.png` and `36-commit-cold-ax2.png`.

## Root cause

Neither file reads `fontScale` (`grep -c fontScale` is 0 in both). `mobile/src/screens/notifications-screen/notifications-screen.tsx`: the section titles `sectionHeader` (`:417`, `:473`), the empty and healthy lines, the error rows (`:237-244`), the commit rows' `changeMessage` (`:516`), `changeMeta` (`:519`) and `changeSha` (`:527`), `olderText` (`:564`). `mobile/src/screens/commit-detail-screen/commit-detail-screen.tsx`: `messageLine` (`:289`), `messageBody` (`:293`), `metaLine` (`:295`), the `sectionLabel`s (`:308`, `:380`), `additions` and `deletions` (`:322-325`), the file rows (`:355-367`) and the diff's `diffText` (`:221`).

## Fix

Key those Texts on `fontScale` (distinct key per sibling), never the list or the diff scroller, so paging, the expanded list and the horizontal diff scroll survive. Add both files to the `KEYED_TEXTS` table in `mobile/src/__tests__/live-font-scale-remeasure.test.ts`, then verify default → AX2 → default natively against cold AX2 launches. Mind `w22/010`: the author line is isolated in Persian, and the keyed Text must keep that content as it is. Mobile only.

## Blast radius

Notifications' ledger-error rows (not on screen in this run), its Show older and Show more controls, and every commit. Filed beside `w22/017`–`019`, `021`–`029`, `030`.

Nothing covers live size changes here.
