# After a live text-size change Browse ledgers cuts its three tab labels and every ledger row's visibility and description lines

**Minor · mobile · 20–30m · A2.** Native mobile QA, 2026-11-10, repository HEAD `59f13b939`, development build `io.beancount.ios` 1.20261002.50 on iPhone 17e / iOS 27.0, light, English, signed in as the QA account. Read-only pass: no star was toggled and no ledger was opened or switched. The local captures list the QA account's ledgers and are not for quoting. This is the same mechanism as `w22/017`–`025`.

## Repro (reproduced twice, the second from a fresh relaunch)

1. Terminate the app, `xcrun simctl ui <udid> content_size large`, relaunch, dismiss the dev toast.
2. Open the drawer, then **Browse ledgers** (`automation_tap` on testID `drawer-discovery-row`).
3. With it open on *Your ledgers*, `xcrun simctl ui <udid> content_size accessibility-large` (AX2, the supported ceiling in `.pm/DO_NOT_DO.md`).

**Expected:** the three tabs (`Your ledgers`, `Starred`, `Explore`) read whole, and each row shows its owner, name, and its `Private · Current` or description line in full, as they do from a cold AX2 launch.
**Actual:** the tab labels are cut to their tops (`Your l…`, `Star…`, `Exp…`, in a single-line row that keeps its old height); in every row the `Private · Current` line and the description (`Synthetic ledger for MC…`) and its `Private` line show only their upper halves. The owner prefix, the ledger name and the star re-lay out correctly (the name text wraps, the star keeps its 48 pt target).

**Control (cold):** terminate, set AX2 first, launch and open the same screen: the tabs read `Your ledgers` (two lines) / `Starred` / `Explore`, and every row's visibility and description lines are whole.

Evidence is local only (`.tmp/qa-20261110/w22c/`): `51-discovery-live-ax2.png`, `54-discovery-live-ax2-repeat.png` (and `-crop`) against `52-discovery-cold-ax2.png`. The Explore tab (public ledgers; row second line `Public`) shows the same on a second data set: `.tmp/qa-20261110/w22e/21-explore-live-ax2.png` (and `-crop`); and the Starred empty state `.tmp/qa-20261110/w22f/12-starred-live-ax2.png` (and `-crop`), cold-large reference `11-starred.png`. No cold-AX2 control was captured for the Starred empty state; the other two tabs' controls rendered whole.

## Root cause

`mobile/src/screens/ledger-selection/index.tsx` reads `fontScale` (`:133-134`) only to choose the stacked row layout. Its Texts are not keyed: the tab label `styles.text` (`:249`, testID `discovery-tab-<value>` at `:241`), the row's `muted` lines (`:353`, `:357`), and the empty, error and link Texts (`:415`, `:434`, `:444`, `:456`, `:469`). The owner and the name (`:340-348`) re-lay out because they sit in the stacked branch that remounts.

## Fix

Key those Texts on `fontScale` (a distinct key per sibling, `mobile/src/__tests__/font-scale-key-collisions.test.ts`), never the list, the tab strip's selection or the search field, so the selected tab, the typed query and the scroll position survive. Add the file to the `KEYED_TEXTS` table in `mobile/src/__tests__/live-font-scale-remeasure.test.ts`, then verify default → AX2 → default natively against a cold AX2 launch. Mobile only; no API surface.

## Blast radius

The one Browse ledgers screen. *Your ledgers* and *Explore* were reproduced (the tab labels cut, the rows' second line cut) and the **Starred** tab's empty state too (`Star a ledger to save it here for next time.` and its `Explore` link cut to slivers, in an account with nothing starred). The error and *Load more* states were not exercised. The `+ New` drawer action and the drawer's own ledger list were not exercised. Filed beside `w22/017`–`025`, `027`–`029`, `030`.

## Dedupe

Searched `.pm/**` (including `done/`) for `ledger-selection`, `discovery`, "Browse ledgers", `fontScale`, live text size. `w2/done/059` (Home chart tabs), `w3/done/180` (search fields at extra-large sizes), `w3/done/183` (report category names) and `w21/done/247` (the drawer's double-scaled line heights) are cold-size layout fixes. None covers a live change here.
