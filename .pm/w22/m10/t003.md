## Objective

Every new message from t002 exists in all 15 dashboard languages (en, bg, ca, de, es, fa, fr, ja, ko, nl, pt, ru, sk, uk, zh), translated for that language with its own plural forms, so no reader sees English or a `[TODO]` in the panel.

## Context

- Rules are in `dashboard/AGENTS.md`, Internationalization: translations live in `src/features/plaid/locales/<lang>.ts`; counts are plural messages (`{ one, other }` in English; `{ one, few, many, other }` in Russian, Ukrainian and Slovak; `{ other }` only in Chinese, Japanese and Korean); never paste English into another catalog.
- `yarn i18n:prepare` syncs every catalog (missing keys appear as `[TODO]`); `yarn i18n:check` must report nothing. `src/test/translations.test.ts` and `src/test/locale-stray-english.test.ts` guard shape and stray English; a message that is genuinely identical in a language goes in that test's `IDENTICAL_BY_DESIGN` list with the reason.
- Persian (`fa`) is right-to-left: check the panel and the header button in RTL so neither the label nor the popover alignment is mirrored wrongly (recent Persian layout fixes in this package are the reference).

## Steps

1. Run `yarn i18n:prepare`, then translate every `[TODO]` the new keys produced.
2. Run `yarn i18n:check`, `yarn test` (locale tests), and `yarn lint` from `dashboard/`.
3. Render the panel with `fa` active (component test or the browser check in t004) and confirm the layout.

- [ ] The `fa` panel is laid out correctly in RTL.
