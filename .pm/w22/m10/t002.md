## Objective

Add a "Set for selected" control in the Target account column header, beside AI Fill, that opens a small panel: pick one account, see how many rows it will set, and apply it with the t001 helper. A user who has selected a backlog can give every selected row the same target in one action and still edit any row afterwards.

## Context

- File: `dashboard/src/features/plaid/components/transaction-review-table.tsx`. Targets live in `targetAccounts`, selection in `selectedIds`; `hiddenSelectedCount` already counts selected rows a filter hides, and `hiddenSelectedNotice` already tells the reader that hidden selections are still submitted. Reuse that wording and do not change what Submit, Delete, or AI Fill do.
- Use the shared `Popover` (`src/common/components/ui/popover.tsx`) and the existing `AccountCombobox` (open accounts only). Keep the panel inside the feature; do not add a shared primitive for one use.
- The panel shows: the number of selected rows, how many of them are hidden by filters, the account picker, a switch "Replace existing targets" (default off = `fill-blank`) with the number of rows that already have a target, and Apply. Apply is disabled until an account is chosen. The control itself is disabled, with its reason in a tooltip or `aria-describedby`, when no row is selected.
- After Apply: one toast with the number of rows set, the panel closes, focus returns to the control, and the missing-accounts alert recomputes from the new map.
- State stays in memory exactly as today; nothing is persisted.

## Steps

1. Add the control and panel using the t001 helper; compute the "will set" and "will replace" counts from the same helper so the panel and the result cannot disagree.
2. Add English strings (message and description, plural forms with `{count}`) to `src/features/plaid/locales/en.ts`; t003 translates them.
3. Add component tests in `src/features/plaid/components/__tests__/`: select several rows, apply to a blank set and see every selected target set and the alert count drop; a row hidden by a filter is set too; `fill-blank` keeps an existing target, the switch replaces it; a row stays individually editable afterwards; the control is disabled with nothing selected; unselected rows are never touched.
4. Run `yarn format:check`, `yarn lint`, `yarn test`, `yarn build` from `dashboard/`.
