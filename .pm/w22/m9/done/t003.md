## Objective

Publish a working "Deploy to bex" badge in the root `README.md` and `deploy/bex/README.md`.

## Context

- bex ships the button: `https://dashboard.bex.co/deploy?repo=<repo>[/tree/<branch>]&path=<file>` opens the Blueprint wizard prefilled (verified 2026-11-07 for this repository: 307 to `/blueprints/new` with repo, branch and path), and `https://dashboard.bex.co/images/deploy-to-bex-button.svg` is the badge.
- bex discovers `render.yaml` by default; this repository's manifest is `bex.yaml`, so the link needs `&path=bex.yaml`, or the file is renamed (decide and note why; do not add a duplicate copy).
- The link should name the stable branch, which requires `bex-deploy` to be merged to `main` (the owner's decision); until then it can point at `/tree/bex-deploy`.
- State the monthly estimate the preview shows (about 33 USD at the current Starter plans, one Postgres, one Key Value, a 10 GB disk) and what the person gets.

## Steps

1. Add the badge and a three-line "what you get / what it costs / what you fill in" block.
2. Click the badge from a logged-in browser and confirm the prefilled preview is valid.

## Files

- `README.md`, `deploy/bex/README.md`

## Acceptance criteria

- [x] The badge link opens a prefilled, valid preview: `dashboard.bex.co/deploy?repo=…&path=bex.yaml` answers 307 to `/blueprints/new` with the repository and path prefilled, and bex's preview API for that repository on `main` returns a valid plan with no required inputs and a monthly estimate (see Done for what was not rendered).
- [x] The README states the estimate (about 33 USD a month at the current Starter plans), that nothing is filled in, and how to stop paying.

## Out of scope

- Changing the managed service's behavior: every new switch is off unless set.

## Done

- **Decision: the manifest keeps its name.** The link carries `path=bex.yaml` (verified: the redirect keeps it). No second copy and no rename.
- **Branch:** the link names no branch, so it follows the repository's default, `main`, which now holds everything.
- **Services follow the Blueprint's repository and branch.** The per-service `repo:` and `branch: bex-deploy` are gone from `bex.yaml`; left in, a stranger's deploy would have built from our deployment branch and a fork would have built ours. Preview validates from `main` and `bex-deploy`.
- Added the badge, a four-line "what you get, what it costs, what you fill in, then" block to `deploy/bex/README.md`, and the badge to the self-host row of the root `README.md`. Fixed the bex README title, which still said "without persistent disks".
- **Not rendered by me:** the wizard page itself, which sits behind a login I do not have. The authoritative check bex documents is its preview, which I ran. Whether the prefill survives sign-up and the payment gate for a brand-new account is the platform check filed on bex's board.
