## Done

`/simplify` over the milestone's diff with four reviewers (reuse, simplification, efficiency, altitude).

- **Applied, the main one (altitude):** the OAuth signing key was derived by a separate start-time script, duplicating the contract of `getJwks`, the one place that decides where the key comes from, with its own copy of the curve order, salt and JWK shape, plus an extra `eval` and node start. It is now `deriveSigningJwks` in `src/config/jwks`, behind `getJwks`'s existing parameters, still off unless `OAUTH_JWKS_FROM_AUTH_SECRET=true`. It produces the **same key** as the script for the same secret (checked key for key on four secrets, including Unicode and 200 characters), and a known-answer test pins the derivation constants so a later change cannot silently sign every OAuth client out. The script, its test and the start-command step are gone. Mutations are caught: changing a constant fails the pin; deriving without being asked fails six tests.
- **Applied (efficiency):** each attempt to learn the public address now has a 3-second timeout; one connection the dashboard accepts but never answers could otherwise hold the container for minutes and defeat the 5-minute cap.
- **Applied (reuse, simplification):** the address resolver quotes what it prints for the shell (round-trip tested through `sh`, including `$(…)` and backticks) and refuses a query or fragment, as the backend's `getOAuthPublicUrl` does; stale comments fixed (Gitea "second database", the manual `bex ssh` migration, the `SERVER_URL` note); the proxy handler's two stacked doc blocks merged. `OAUTH_JWKS_FROM_AUTH_SECRET` is documented in the backend README and `.env.example`.
- **Skipped on purpose:** merging the two node start-ups into one (about 50 ms, couples unrelated steps); registering `public-url` as a plain route instead of global middleware (a routed handler fails to register in this nitro build); moving URL composition out of the start command into the apps (their consumers read the value at import, and the managed service must not change); the Gitea wrapper creating its own schema (bex has no init job, so the wrapper is the only hook, and the Dockerfile says so); small `ensure_schema` tidying and re-parsing a parsed URL (negligible).
