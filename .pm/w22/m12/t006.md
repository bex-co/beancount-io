## Objective

Prove the whole flow on a real self-hosted stack, from a profile with no Git or `bea` state, then delete the stack.

## Context

- Create the stack from the root Blueprint; it takes about half an hour. Delete every resource afterwards and confirm each answers 404.
- Isolate the client: an empty `BEA_CONFIG_DIR`, and `GIT_CONFIG_GLOBAL` pointing at an empty file, so no Keychain entry or old helper answers instead.

## Steps

1. Sign up, create a ledger, `bea cloud login`, `bea cloud git setup`.
2. `git clone`, commit, `git push`, `git pull`: no prompt at any step.
3. Check the token in Settings → Personal access tokens (if t001 chose one).
4. `bea cloud logout`; the next `git fetch` is refused.
5. Against the managed service, `bea cloud git setup` refuses and writes nothing.
6. Delete the stack.
