## Objective

Implement the helper Git calls: `bea cloud git credential get|store|erase`, speaking Git's credential protocol on stdin and stdout.

## Context

- Git sends `key=value` lines (`protocol`, `host`, `path`, …) and a blank line; for `get` the helper answers `username=…` and `password=…`, or nothing to let Git fall back to its next helper or prompt.
- Answer only for the host `setup` registered; print nothing for anything else.
- Keep stdout to the protocol alone. A short hint on stderr is fine (Git shows it), for example when the login has expired.

## Steps

1. Hide the command from normal help; it is for Git.
2. `get`: return the credential from t001, minting a fresh one if it lapsed while the login is still valid.
3. `store`: no-op. `erase`: forget the stored credential so the next `get` mints one.

## Files

- `cli/src/cli/commands/cloud/` (the `git` group)
- `cli/tests/`

## Acceptance criteria

- [ ] `printf 'protocol=https\nhost=<git host>\n\n' | bea cloud git credential get` prints a username and a password Git accepts for clone and push.
- [ ] For any other host it prints nothing and exits 0.
- [ ] Signed out, it prints nothing on stdout and Git prompts as usual.

## Out of scope

- Hosts other than the one `setup` registered.
