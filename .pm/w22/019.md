# After a live text-size change the merchant detail header loses its name, its totals and its Recurring text

**Minor · mobile · 20–30m · A2.** Native mobile QA, 2026-11-10, repository HEAD `59f13b939`, development build `io.beancount.ios` 1.20261002.50 on iPhone 17e / iOS 27.0, light, English, signed in as the QA account on its synthetic `example` ledger. Read-only pass; the Recurring switch was not touched.

## Repro (reproduced twice, the second from a fresh relaunch)

1. Terminate the app, `xcrun simctl ui <udid> content_size large`, relaunch, dismiss the dev toast.
2. Drawer (testID `drawer-merchants-row`) → **Merchants** → the first merchant (testID `merchant-row-<payee>`).
3. With the detail open, `xcrun simctl ui <udid> content_size accessibility-large` (AX2, the supported ceiling in `.pm/DO_NOT_DO.md`).

**Expected:** the header shows the merchant name, the transaction count, one signed total per currency, the date range, and the Recurring title with its description, as the transactions below it do.
**Actual:** the name and `71 transactions` show only their upper halves; the three currency totals are gone, leaving a blank band; the date range and the `Recurring` title are cut, and its description ends after `Whether this merchant i`. The transaction rows below re-lay out correctly.

**Control (cold):** terminate, set AX2 first, launch and open the same merchant: the name, count, three totals, date range and the five-line Recurring description are all whole.

Evidence is local only (`.tmp/qa-20261110/w22b/`): `23-merchant-detail-live-ax2.png`, `27-merchant-detail-live-ax2-repeat.png` (and `-crop`) against `25-merchant-detail-cold-ax2.png`.

## Root cause

`mobile/src/screens/merchant-detail-screen/merchant-detail-screen.tsx` has **no** `fontScale` at all. The list header (`listHeader`, `:598-690`, testID `merchant-stats-header`) is plain Texts: `payeeName` (`:608`), `count` (`:612`), each total row, the date range, `toggleTitle` (`:671`) and its description. The rows below remount because the entry row switches to its stacked layout at large sizes; the header has no such switch.

## Fix

Key each header Text on `useWindowDimensions().fontScale` with a distinct key per sibling (`font-scale-key-collisions.test.ts`), or key the header container (`merchant-stats-header`) alone: it is the list's header, not the list or the screen, so scroll and the Recurring switch's stored value survive (check that the switch keeps its position). Add the file to the `KEYED_TEXTS` table in `mobile/src/__tests__/live-font-scale-remeasure.test.ts`, then verify default → AX2 → default natively against a cold AX2 launch. Mobile only.

## Blast radius

The one merchant detail screen, for every merchant. Filed beside `w22/017`, `018`, `020`–`030`, the same mechanism at other sites.

## Dedupe

Searched `.pm/**` including `done/` for `merchant-detail`, `merchant-stats-header`, `payeeName`, `fontScale`, live text size. `w4/done/013`, `014` and `w3/done/181` concern the header's content, not text size; `w22/012` its digits. Nothing covers live size changes on it.

## Unverified

A merchant with one currency or a long name, the Recurring detection card on a merchant that has one, the shrink direction here (observed on Settings, `w22/021`), dark mode, Android.
