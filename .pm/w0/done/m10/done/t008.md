## Result (2026-11-25)

Definition of done, item by item:

- **Signing key, both targets.** `deploy/docker` (t002) and `deploy/docker-single-psql` (run the same way after t007, project `m10-psql`, Caddy in front, `.env` from its `.env.example`): with only the required values, `https://<APP_DOMAIN>/.well-known/oauth-authorization-server` answered 200 and its `jwks_uri` served one ES256 key, with `OAUTH_JWKS` empty; the app's protected-resource document named `https://<APP_DOMAIN>`; `/api-gateway/mcp` answered 401 pointing at the protected-resource document. With the `.env` line removed, both answered `503 oauth_not_configured`. A supplied `OAUTH_JWKS` was served instead of the derived key, and the derived `kid` held across restarts (t002).
- **Compose.** `docker compose --env-file .env.example config --quiet` and the SSH-overlay variant pass in both directories, and the rendered backend environment carries `OAUTH_JWKS_FROM_AUTH_SECRET: "true"` (empty for an `.env` without it). `scripts/check-docker-targets.py` now guards this in `CI (deploy)` (t007).
- **README.** Neither Docker README asks for a keyset made offline: the key is derived from `AUTH_SECRET` by default, a command prints one of your own, a supplied key wins, and rotating `AUTH_SECRET` signs OAuth clients out. Both name `https://<APP_DOMAIN>` for the app and `https://<APP_DOMAIN>/api-gateway/mcp` for MCP (t003).
- **Bring books in.** The steps are in `deploy/docker/README.md` and linked from `docker-single-psql`: create a ledger, merge, push; a forced push is refused. On both stacks a ledger with three commits of its own went into a new ledger, the forced push was refused, a fresh clone showed the earlier commits under the merge, and `checkLedger` reported no errors (t004, and the `m10-psql` run). The hosted export goes through `bea cloud ledger clone` with an SSH key.

Beyond the task text: both targets now set `GIT_PUBLIC_URL=https://${API_DOMAIN}/git`, because Gitea's own address, which ledgers named before, takes neither a token nor a password (t004).
