# A case-twin folder below the first path level is still accepted in the New File dialog, and the server's refusal names a folder as a "file"

**Severity:** minor. **Estimate:** 30 minutes. Owner: mobile.

**Root cause (A3).** `checkLedgerFileName` checks only `segments[0]` (`mobile/src/screens/ledger-file-browser-screen/utils.ts:132-141`); the w21/825 resolution itself records that only the first folder is checked. The dialog lists only `parentDirectory(filePath)` (`index.tsx`, about `:516`), and that folder doesn't exist when the case differs, so it returns NOT_FOUND and the create goes ahead.

On the server, `portable-twin.ts:46-56` does walk every depth and throws `"<path> already exists as <twin.path>"`. `clashingFileName` (`utils.ts`, about `:160`) returns the full repository path, so the toast reads "A file named 2024/q1 already exists" for a folder, and `knownExisting` gets a repository-root path that never matches a name in the current folder.

Not run natively in this pass. `tsx` proof: `checkLedgerFileName("a/B/x", ["a"])` and `checkLedgerFileName("2024/Q1/jan", ["2024"])` both return `ok`.

**Native steps** (a `qa-` ledger): create `qa-2024/q1/a.bean` through the API, then type `qa-2024/Q1/b`. Expect the dialog to close and a toast naming `qa-2024/q1`.

## Fix

Before creating, list each ancestor of the target folder, or let the server's twin error name the kind. Show `ledgerFolderNameExists` for a folder twin.

**Acceptance:** `a/B/x` with `a/b` present is refused inline, or with folder wording, and the typed text is kept.

## Dedupe

w21/825 records the residual gap explicitly. Related: w21/770 and w21/787.
