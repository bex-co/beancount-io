# Files can't open an included file whose extension isn't on a fixed list (`include "prices"`, `prices.inc`); the row is dimmed with no reason

**Severity:** minor (users with extensionless or `.inc` includes can't edit them in the app). **Estimate:** 15 minutes. Owner: mobile. A3: `common/ledger-file-types.ts:68` (`isEditableTextFile`) allows a fixed list of extensions. Other rows are dimmed and untappable with no explanation (`ledger-file-browser-screen/index.tsx:243-244`), though Delete is still offered. The hosted engine loads such includes (`backend-cluster/ledger/src/foundation/rustledger/file-map-loader.ts:43`; test at `__tests__/file-map-loader.test.ts:285-295`).

Not run natively (the files must be created via the dashboard or MCP, since New File only makes .bean/.beancount names). Under `tsx` (the agent's proof), `isEditableTextFile` returns false for `qa20261020-prices` and `qa20261020-prices.inc`, and true for `.txt` and `.ledger`.

## Fix

Treat any file the ledger includes as an editable text file (or sniff for text content), and explain why a row can't be opened when it really can't.

**Acceptance:** an included `prices` file opens in the editor. Binary files stay disabled, with a reason. A unit case is added.

## Dedupe

Searched `.pm/**` for isEditableTextFile and include together with extension.
