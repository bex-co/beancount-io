# A misspelled built-in plugin reads "Python plugin "beancount.plugins.auto_acounts" requires the python-plugins feature" instead of naming the typo

**Severity:** minor. **Estimate:** 15 minutes. Owner: ledger. A3: the engine's E8005 text passes through unchanged; w21/773 fixed only its location (`url-include-errors.ts:99`).

Not run natively. Under `main`'s engine (the agent's proof), `plugin "beancount.plugins.auto_acounts"` gives `main.bean:3 E8005 Python plugin "beancount.plugins.auto_acounts" requires the python-plugins feature`. Beancount would say "No module named …".

## Fix

Rewrite E8005 as "Unknown plugin \"X\": Beancount.io can't run this plugin", and add a "did you mean auto_accounts?" hint when the name is close to a built-in.

**Acceptance:** this fixture names the plugin as unknown and suggests auto_accounts. A unit case is added.
