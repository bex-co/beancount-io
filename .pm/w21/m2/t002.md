## Objective

Spread `...contentColumn` over the scroll content of every bespoke detail,
form, and settings screen, so cards and forms cap at 640 pt centered on iPad.

## Context

- Same shared styles and test pattern as t001 (w21/1005).
- The agent chat's message bubbles are already `%`-capped; capping the message list keeps them readable relative to the column.

## Steps

1. For each screen, find its scroll content style and spread `...contentColumn` into it (import from `@/common/content-column`).
2. Check each screen for full-bleed children (sticky headers, horizontal scrollers, edge-to-edge rows, negative margins) and keep those full width where the design needs it.
3. Add a consumer check per touched screen to `content-column.test.ts`.
4. Run the mobile gates: `yarn format:check`, `yarn lint`, `yarn typecheck`, `yarn test:unit` (from `mobile/`).
