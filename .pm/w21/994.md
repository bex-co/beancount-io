# Budget: the current period's target is prorated to today on mobile and the full period on the dashboard, so one ledger gets opposite on-target verdicts

**Severity:** major if unreconciled, and it needs a product decision. **Estimate:** 1 hour once decided. **Owner:** product call, then the package that changes (I lean towards the dashboard).

**Root cause (A3).** The two apps implement different rules for the period in progress:
- Mobile: `budgetForIntervalExact` in `mobile/src/screens/budget-screen/selectors/budget-selectors.ts` budgets only up to `asOf` (today), clipping to the window start. The Home budget panel follows it (`select-budget-panel.ts:76`; w21/076, w21/102, w21/377).
- Dashboard: `budgetHeadlinePeriod` in `dashboard/src/features/ledger-data/budget/budget-utils.ts` and `budget-chart-card.tsx:233-247` call `calculateBudgetForInterval(headline.end, …)` with `headline.end` set to the last day of the period containing today. Its documentation says "never a window edge that clips the period and so prorates its target" (w0/027).

Not reproduced in the app or browser; only the mobile side ran under `tsx`, and the dashboard side is read from source (`date-fns` isn't installed in `dashboard/`). Example: a monthly 310 USD budget on 2026-01-01, today 2026-10-24, period ending 2026-10-31.
- Mobile gives a target of `240.00` (310 × 24/31).
- The dashboard's target is the whole month, `310.00`.

The pair documented in w21/076: with 250 spent against a 300 monthly budget on Oct 21, mobile shows "Budget $203.23, Variance +$46.77, Above target" (red); the dashboard headline compares the same 250 with 300, giving −50, "Below target" (green).

w0/027 asked the dashboard for a "to date" qualifier when comparing partial-period actuals, and I found no record that the two platforms were reconciled.

## Fix

Pick one rule and apply it to both. If mobile's is kept, pass `today` as an end clamp in `calculateBudgetForInterval` for the headline period only, and label it "to date"; keep the chart bars as they are.

**Acceptance:** for a monthly 310 budget, today 2026-10-24 and 200 spent, both packages produce the same target and the same verdict, with a table-driven case using the same fixture in each package's tests.
