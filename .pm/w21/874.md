# The dashboard's entry page offers Save and Delete on a plugin copy, and Delete removes the whole series (dashboard half of w21/840)

**Severity:** major. **Estimate:** 45 minutes. Owner: dashboard. A3: `dashboard/src/features/journal/pages/entry-page.tsx` always renders `EntryContextPanel`, whose `editable = canWrite && managedSource === null` never looks at `generated_from`; the GraphQL context query the panel reads does not request the field, and nothing in `dashboard/src` references it. On the server, `deleteSourceSlice` resolves a plugin copy's ID to its source and deletes the source text, so Delete on a copy of an `amortize_over` entry removes the entry that all its copies come from. w21/840's mobile half withholds Share and Copy link on plugin copies; a link to a copy can still be reached from a journal row or typed.

## Fix

Add `generated_from` to the entry-context operation (and regenerate the types), and have `EntryContextPanel` go read-only for an entry that has it, with a link to the source entry (w21/508's read-only rule).

**Acceptance:** a plugin copy's entry page shows no Save and no Delete, and links to its source; an ordinary entry is unchanged. Unit cases are added.
