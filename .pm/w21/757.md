# `nounused` ignores plugin order, so a child closed by `close_tree` counts as used (w21/739 variant)

**Severity:** trivial. **Estimate:** 15 minutes. Owner: ledger. A3: `nounused.ts:27` reads the final directives, which include the closes `close_tree` generates, so an idle child looks used.

Proven with the real engine under ts-node (as `yarn verify:rustledger` runs it) against Beancount 3.2.3 `bean-check`, also at the commit before the fix (the agent's run). Not on production: the ledger service hasn't been redeployed with the fix. `plugin "beancount.plugins.nounused"` then `plugin "beancount.plugins.close_tree"`; open `Assets:Qa20261020Broker`, `…Broker:Idle` and `…Cash`; one Broker/Cash transaction; `2024-04-01 close Assets:Qa20261020Broker`. bean-check reports "Unused account 'Assets:Qa20261020Broker:Idle'"; the engine reports no `nounused` error, only a hidden E1004 warning.

## Fix

Evaluate `nounused` on the directives at its plugin position (before later plugins' generated entries).

**Acceptance:** this fixture matches bean-check, and the reversed order matches too. A unit case is added.
