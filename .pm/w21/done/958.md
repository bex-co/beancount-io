# A foreign-currency card or bank account has a grey chart with no percent, while its journal rows are red and green

**Severity:** minor. The screen contradicts itself. **Estimate:** 20 minutes. Owner: mobile. This is a gap in w21/713 and w21/783.

**Root cause (A3).** w21/713's fix for stock splits reaches too far.
- `mobile/src/screens/account-detail-screen/account-detail-screen.tsx:548` sets `neutral={unitsCurrency !== undefined}`, so every account shown in units gets a neutral chart, not just commodities held at cost.
- A cost-less EUR balance stays in EUR under `at_value`. `selectBalanceDisplay` (`common/balance-display.ts`) then returns `kind: "units"` with `value: null`, which sets `unitsCurrency` (`:222`).
- With `neutral` set, `interactive-line-chart.tsx:455` drops the percent, and `:703` makes the line and change text grey.
- The rows don't get the same treatment: `journalChangeTone` (`select-change-tone.ts`, used at `account-entry-row.tsx:194`) goes flat only when a cost is present, and `postingsCost` returns null with no `{cost}`.

**Effect.** A EUR card on a USD ledger going from −500 EUR to −300 EUR shows a grey "+200.00 EUR" with no "(+40.00%)", and a grey line. The same move on a USD card reads "+$200.00 (+40.00%)" in green. In the rows below the chart, the payment is green and the charge red. Overdrawn foreign-currency bank accounts and vacation-hours accounts are affected the same way.

Not run natively in this pass. `tsx` proof with the real helpers:
- `selectBalanceDisplay({EUR:"-300.00"},{EUR:"-300.00"},"USD")` gives `{"kind":"units","units":{"currency":"EUR","number":-300,"scale":2},"value":null}`.
- The split case (QANVDA at cost) gives a non-null `value`, so the two cases can be told apart.
- `journalChangeTone(200, 1, null, 2)` gives `"up"`, so the row is green.
- `describeChange(200, null, fmt)` gives `{amount:"+200.00 EUR", flat:false}` with no percent, although `changePercent(-500,-300)` is 40.

## Fix

Make the chart neutral only when the units are lots held at cost, which is the case w21/713 was about. For example, `neutral={unitsCurrency !== undefined && display.kind === "units" && display.value !== null}`, or check for a cost on the account's postings.

**Acceptance:**
- A units display with `value: null` (EUR card −500 → −300) isn't neutral: it shows "(+40.00%)" and a favourable color.
- The QANVDA split (`value` non-null) stays neutral.
- Add a matching `chartPointText` case, since w21/783 also uses `neutral`.

## Dedupe

No match for "neutral" with EUR, foreign or units, `unitsCurrency`, `neutral={`, or "foreign currency" with chart. It's a gap in done w21/713 and w21/783.
