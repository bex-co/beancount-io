# A Latest Updates row with no action is announced as "dimmed"

**Severity:** low (edge case). **Estimate:** 10 minutes. Owner: mobile. A3: `feed-card.tsx:117-120` renders `<Pressable disabled={!action} accessibilityRole={action ? "button" : undefined}>`. A Pressable is accessible by default, and `disabled` adds the not-enabled trait, so an informational row reads "<title>, <source · date>, dimmed". `feedRowAction` returns null for an empty or unresolvable link (`feed-logic.test.ts:79-82`), and the backend sends "/" when an activity has no repo owner (`activity-transformer.ts:167-169`).

Not run natively (VoiceOver). This is a code-level trace (the agent's).

## Fix

Render a non-pressable `View` when there's no action, or guard inside `onPress` without `disabled`, as w21/428 did.

**Acceptance:** an action-less row is read without "dimmed". A source case is added.

## Dedupe

Same class as w21/287 and w21/428 (other screens). w21/481 touched feed-card for contrast only. Searched `.pm/**` for feed-card and dimmed.

---

**Resolved 2026-10-24** — the feed row no longer sets `disabled` for an action-less row; no press handler and no button role are enough, so it is read as informational text, not "dimmed". Source cases in `feed-logic.test.ts` (`mobile`). Not run with VoiceOver.
