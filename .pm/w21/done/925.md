# Add Budget's empty Account row reads to VoiceOver as if "Expenses:Groceries" were selected, and its placeholder is nearly invisible in light mode

**Severity:** moderate. A VoiceOver user hears "Account, Expenses:Groceries, button", thinks an account is already chosen, and then finds Done disabled. **Estimate:** 20 minutes. Owner: mobile. A3: `mobile/src/screens/add-budget-screen/add-budget-screen.tsx:390` passes `account || t("budgetAccountPlaceholder")` as `value`. `FormRow` speaks that value through `accessibilityValue={{ text: value }}` (`:170`) and paints the muted text in `theme.black60` (`:109-111`).

Not run natively in this pass. Proof with `tsx`, against the real styles:
- In light mode, `#c2c3b6` on the card's `#ffffff` is **1.78:1**. Dark mode is 6.29:1.
- Open Account already gives its empty currency row a separate spoken value (`open-account-screen.tsx:552-554`).
- Other placeholders use `controlPlaceholder`, which is 4.74:1.

**Native steps:** in light mode, go to Budget → +. The Account row shows a faint "Expenses:Groceries". With VoiceOver on, focus the row: it is read as the row's value.

## Fix

- When no account is chosen, pass a translated "Not selected" as the spoken value, or mark the row as a placeholder.
- Use `theme.controlPlaceholder` for `valueMuted`.

**Acceptance:**
- A unit case checks that, with no account, the row's spoken value isn't the example account.
- `text-style-contrast.test.ts` gets a `valueMuted` on `card` case at 4.5:1 or better in both themes.

## Dedupe

Only unrelated hits. Searched for "budgetAccountPlaceholder", "Expenses:Groceries", "valueMuted" and "accessibilityValue placeholder".

**Resolved 2026-10-24** — Add Budget's empty Account row speaks a translated "No account chosen" (`budgetAccountNotSelected`, all 13 locales; `FormRow` takes a `spokenValue`) instead of the example account, and its muted value uses `controlPlaceholder` (4.74:1) instead of `black60` (1.78:1 in light). Cases: the `valueMuted` contrast case in `text-style-contrast.test.ts` and `add-budget-account-row-spoken.test.ts` (`mobile`). Not run natively.
