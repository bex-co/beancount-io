# Entry Context's balance rows drop the account name when an account holds a lot: "4.0000 QAETF {101.2500 USD, 2026-10-21}" with no account, at the default text size

**Severity:** moderate. You can't tell whose balance a row is. **Estimate:** 15 minutes. Owner: mobile. A3: `transactions-screen/entry-context/balance-section.tsx:58-62`. The amounts column is `flexShrink: 0` and the account is `flex: 1`, so a long lot string takes the whole row. Rows only stack when `prefersStackedLayout` (AX sizes) is true (`:81`, `:102`).

Reproduced natively on the iPhone 17e simulator, English UI at the default text size, Metro `--clear` at `045715ae1`, on the disposable QA ledger, which was restored byte-for-byte to `f1a0b83c`. Fixture: `open Assets:Qa20261020Broker "FIFO"`, a 2026-10-21 buy of `4.0000 QAETF {101.2500 USD}`, and a 2026-10-22 sale of `-1.0000 QAETF {} @ 110.00 USD`. Transactions ▸ Qa20261020 Sell ▸ Entry Context (expanded) ▸ Balances Before Entry: after the Gains and Bank rows comes a row reading only **"4.0000 QAETF {101.2500 USD, 2026-10-21}"**, wrapped, with no account name.

## Fix

When an amount contains a lot (`{`) or is wider than about half the row, stack the row as the AX layout does. Alternatively, let the amounts shrink and wrap.

**Acceptance:** this row shows `Assets:Qa20261020Broker` and its lot, both readable. A layout or unit case is added.

## Dedupe

Not w21/092 (currency lines), w21/684 (AX sizes only) or w4/058. Searched `.pm/**` for balance-section, flexShrink and lot together with Entry Context.

---

**Resolved 2026-10-24** — a balance row whose amount carries a lot stacks its amounts under the account at any text size (`stacksBalanceRow`), so `Assets:Qa20261020Broker` and its lot are both readable. Cases in `balance-section-layout.test.ts` (`mobile`). Not run natively.
