# Share/Copy link on a plugin copy hands out the copy's /entry/ URL; the dashboard's entry page offers Save and Delete there, and Delete removes the whole series

**Severity:** major. The app hides Delete on plugin copies (w21/443, 508) but shares a link that offers it. **Estimate:** 30 minutes. Owners: mobile and dashboard. A3:
- **Mobile:** `selectTransactionMenuActions` (`transaction-detail-screen/selectors/select-transaction-detail.ts`) checks only `isGenerated`, so a plugin copy keeps Share and Copy link, built from the copy's own ID.
- **Dashboard:** `dashboard/src/features/journal/pages/entry-page.tsx` always renders `EntryContextPanel`, and its `editable = canWrite && managedSource === null` never looks at `generated_from` (no reference anywhere in `dashboard/src`).
- **Server:** `deleteSourceSlice` resolves the copy's ID to its source (`ledger-journal-service.ts:84`, `:527-535`) and deletes the source text.

Mobile half reproduced natively on the iPhone 17e simulator, English UI, Metro `--clear` at `045715ae1`, on the disposable QA ledger, which was restored byte-for-byte to `f1a0b83c`. Fixture: `plugin "fava.plugins.amortize_over"` and `2026-10-20 * "Qa20261020 Insurer" "Qa20261020 car insurance"` with `amortize_months: 3` (300.00 USD). Tapping "Qa20261020 Insurer · car insurance (1/3) · −$100.00" shows the plugin-copy notice and no pencil. ⋯ offers **Share link / Copy link**, and Copy link puts `https://beancount.io/ledger/<owner>/mcp-agent-eval/entry/c0d24cb1c47671ad54376da2128742be` on the clipboard: the copy's ID, not the source's. The dashboard half is from the agent's code trace; the page wasn't opened, and Delete wasn't exercised.

## Fix

Make the dashboard entry page read `generated_from` and go read-only, with a link to the source entry. On mobile, either link to `generatedFrom` or withhold Share and Copy link on copies. Both should match w21/508's read-only rule.

**Acceptance:** a plugin copy's shared link never opens an editable or deletable page for the template. Unit cases are added on both sides.
