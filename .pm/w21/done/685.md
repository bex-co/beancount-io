# At AX2, Home's budget panel cuts both "Housing:Rent" and "Housing:Utilities" to "Housing…", so budgets look the same

**Severity:** minor (accessibility; AX2). **Estimate:** 15 minutes. Owner: mobile. A3: `home-screen/components/budget-card.tsx:44-60, 150-163`. Each row's header is a row that never stacks: `row.shortAccount` (`fontSizes.md`, `flex: 1`, `numberOfLines={1}`, cut at the end) sits beside the "actual / budget" `AmountText`. At AX2 the account is about 30pt, and the card's inner width is 325pt. w21/027 fixed the Budget screen's cards this way, but not Home's panel. VoiceOver is fine, because the label is the full account.

Measured, not shown natively. The agent laid out the real fonts with AppKit at React Native's AX2 multiplier (2.143): beside "$1,234.56 / $2,000.00" (≈188pt), both `Housing:Rent` and `Housing:Utilities` render as **"Housing…"**. Beside "$412.50 / $500.00", `Food:Groceries` renders as "Food:Groc…". On iPhone 17e at AX2 (`d731eb32a`, disposable ledger with monthly budgets on Expenses:Housing:Rent and Expenses:Housing:Qa20261020Utilities, then restored byte-for-byte), `automation_find_view` places the panel's first row at y≈2158pt, below the fold. The automation tools can't scroll, so it wasn't screenshotted.

## Fix

Stack the account above the amounts when text is enlarged (as w21/027 did for Budget cards), or let the account wrap to two lines.

**Acceptance:** at AX2, two budgets that share a parent are told apart on Home. The default size is unchanged.

Home counterpart of w21/027 (done; Budget screen cards). w21/015 (done) is about re-measuring after a size change. Searched `.pm/**` for budget-card.tsx, "budget panel" together with AX2, and shortAccount.
