# Merchants shows "Search 0 merchants…" and a sort button above its load-error and empty states

**Severity:** low (cosmetic). **Estimate:** 5 minutes. Owner: mobile. A3: `merchants-screen/merchants-screen.tsx:399` renders the search row whenever `!isInitialLoading`, which includes the error and blank states. The placeholder count is `merchants.length` (0) (`:277-279`).

Not run natively (the error state needs the device offline, and the QA ledger has payees). Code path (the agent's): with `rollupError` and no data, the header renders "Search 0 merchants…" and the sort button above "Failed to load merchants / Retry". The same text shows above "No merchants yet" on a ledger with no payees, and typing does nothing in either state.

## Fix

Render the search and sort row only when `merchants.length > 0`.

**Acceptance:** neither state shows the search row. A source case is added.
