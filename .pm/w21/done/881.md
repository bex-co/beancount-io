# On a ledger with renamed roots (`option "name_assets" "Activos"`), the Accounts tab's top rows show "Assets", while the page they open is titled "Activos"

**Severity:** low. **Estimate:** 10 minutes. Owner: mobile. A3: the category row label is a translation key (`flatten-rows.ts:152`), rendered with `t(item.label)` (`account-table.tsx:545-546`). The ledger's own root name (`category.account`) is never shown. Open Account already shows renamed roots as the ledger names them (w21/073, 629).

Not run natively: renaming roots on the disposable ledger would make all its existing accounts invalid. Under `tsx` (the agent's proof), with `option "name_assets" "Activos"`, the first row has `label: "assets"` and `account: "Activos"` and renders "Assets", while the rows under it read `Qa20261020Banco` under `Activos:`.

## Fix

When `category.account` differs from the default root, use it as the label (and in the accessibility label). Otherwise keep `t(key)`.

**Acceptance:** with renamed roots, the top rows read the ledger's names. A unit case is added.
