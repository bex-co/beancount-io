# The Return key does nothing in the New File dialog

**Severity:** trivial. **Estimate:** 10 minutes. Owner: mobile.

**Root cause (A3).** The `TextInput` in `mobile/src/components/text-input-modal/index.tsx` (about `:222-232`) has no `onSubmitEditing` and no `returnKeyType`. The dialog is shared with Open Account's budget and Delete Account.

**Native (iPhone 17e, 2026-10-23).** Files → + → paste `qa-ret`. "Create file" becomes enabled. Pressing Return closes the keyboard only: the dialog stays open and nothing is created. The key's label is the plain "return" arrow, not "Done". I cancelled the dialog without creating anything.

## Fix

Set `returnKeyType="done"` and `onSubmitEditing={handleConfirm}`. The handler already guards against a disabled confirm.

**Acceptance:** Return with a valid name creates the file; with an invalid name it does nothing.

No hit for this dialog. `onSubmitEditing` appears only in `agent-screen` and `open-account-screen`. Searched for "Return key", "onSubmitEditing" and "text-input-modal".
