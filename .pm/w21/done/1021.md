# `bea init` writes AGENTS.md for coding agents

The `beancount-init` skill writes `AGENTS.md` (and `CLAUDE.md` -> `@AGENTS.md`) from `skills/beancount-init/references/agents-template.md`, but a user who only installed `bea` gets neither. Add an opt-in or default option to `bea init` that writes `AGENTS.md` from the same template, never overwriting an existing file; test that an existing file is untouched. Update `cli/README.md` and the REFERENCE (`make docs`). A1/A2, ~45m, too small for a milestone. Source: `/pm-brainstorm for w21` 2026-11-05, candidate 6.

---

**Resolved 2026-11-06** — `bea init --agent-files` writes `AGENTS.md` and a one-line `CLAUDE.md` (`@AGENTS.md`) from the `beancount-init` skill's template, created exclusively so an existing file is never replaced (an existing `AGENTS.md` also leaves `CLAUDE.md` unwritten); a test fails if the embedded text drifts from the skill's template. Opt-in, so default `init` output is unchanged. Skill template lists all sixteen skills; suite version 0.4.25. Shipped in the commit that closes this note (`cli`, `skills`).
