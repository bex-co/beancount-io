# Entry Context's Source Code block draws Persian/Arabic lines in the wrong order: an amount lands inside the account path (gap in w21/780)

**Severity:** minor. **Estimate:** 5 minutes. Owner: mobile. A3: `transactions-screen/entry-context/index.tsx:321-323` renders `entryContext.slice` as raw text. `isolateSourceLine` is used only in `commit-detail-screen.tsx:221`. w21/780's resolution noted that this view "could use the same helper", but nothing was filed for it.

Not run natively: the Source Code block is below the fold once Entry Context is expanded.
