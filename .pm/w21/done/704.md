# Since w21/675, any unused pad in a ledger with an amortize or forecast plugin adds a false "Balance failed" (the pad recheck skips plugins)

**Severity:** major (false reconciliation errors in ledgers that use Fava plugins). **Estimate:** 30 minutes. Owner: ledger. A3: w21/675's recheck re-parses the files with the unused pads blanked out, through `withLedger(blanked, …)` (`backend-cluster/ledger/src/foundation/rustledger/engine.ts:726-737`, especially `:736`). That path skips the TS plugin layer (`amortize_over`, forecast), while the main pass checks balances against the plugin-transformed entries. Every balance on an account a plugin touches is then re-checked against untransformed postings, and fails.

Proven with the real engine under ts-node (as `yarn verify:rustledger` runs it), with Beancount 3.2 `bean-check` as the reference:

```
plugin "fava.plugins.amortize_over"
2026-01-01 open Assets:Prepaid
2026-01-01 open Assets:Cash
2026-01-01 open Expenses:Insurance
2026-01-01 open Equity:Open
2026-01-01 * "Insurance"
  amortize_months: 3
  Expenses:Insurance  300.00 USD
  Assets:Prepaid  -300.00 USD
2026-02-15 balance Assets:Prepaid  -200.00 USD
2026-01-02 * "dep"
  Assets:Cash  100.00 USD
  Equity:Open  -100.00 USD
2026-03-01 pad Assets:Cash Equity:Open
2026-03-02 balance Assets:Cash  100.00 USD
```

Expected: only E2003 "Unused Pad entry". Actual: E2003 plus E2001 "Balance failed for Assets:Prepaid: expected -200.00 USD, got -300.00 USD". With the pad line removed, the engine reports no errors at all. Not on production yet: the ledger service hasn't been redeployed since w21/675.

## Fix

Run the recheck through the same plugin pipeline as the main pass (apply the TS plugins to the blanked parse), or reuse the main pass's transformed entries with the unused pads dropped.

**Acceptance:** this fixture reports only "Unused Pad entry". w21/675's and w21/676's fixtures still report their hidden failures. A unit case with amortize_over is added.

## Dedupe

Regression of w21/675 (done). Searched `.pm/**` for pad-recheck, withLedger and amortize together with pad.
