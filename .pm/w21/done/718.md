# Home's Latest Updates ledger rows ("Committed to …") are English in every language

**Severity:** trivial (i18n). **Estimate:** 30 minutes. Owner: backend-v2 (or mobile). A3: feed titles for ledger activity come from `activity-transformer.ts`'s `titleTemplates` in English, and mobile shows `item.title` as is (`feed-card.tsx:117`). w21/136 localized the blog and release rows only; its recheck noted the ledger rows but nothing was filed.

Read-only production: `getFeed(locale: "de")` for the QA account returns `"title":"Committed to mcp-agent-eval"`, while the card heading and the rest of Home are German. Not captured natively, because the card is below the fold.

## Fix

Return a structured type (for example `{kind: "commit", ledger}`) and localize the title on the client, or localize `titleTemplates` by the `locale` argument the query already takes.

**Acceptance:** in German, a ledger commit row reads in German. The same goes for other supported languages. A unit case is added.
