# Portuguese (pt-BR) shows European words that mean something else in Brazil: Last name reads "Apelido" (nickname), and links read "ligação" (phone call)

**Severity:** minor. The labels state the wrong thing to the Brazilian readers the file is written for (it otherwise uses arquivo, salvar, tela and Excluir; w21/584 confirmed pt-BR). **Estimate:** 10 minutes. Owner: mobile. Keys in `mobile/src/translations/pt.ts`:
- `profileLastName` "Apelido" (line 862). In Brazil, apelido means nickname.
- `shareLink` "Partilhar ligação" and `copyLink` "Copiar ligação" (lines 72–73). In Brazil, ligação means a phone call.
- `testConnection` "Testar ligação" (line 186), with the same problem.

Not run natively (it needs a language switch). The agent's catalog check compared these with en "Last name", "Share link", "Copy link" and "Test connection". They render on Profile's last-name field (`profile-screen.tsx:416`), transaction detail's ⋯ menu (`transaction-detail-screen.tsx:735,740`) and Server settings (`server-settings-screen.tsx:340`).

## Fix

"Sobrenome", "Compartilhar link", "Copiar link" and "Testar conexão". While there, review the other European forms (utilizador, aplicação, "tem de").

**Acceptance:** the four keys read as pt-BR. The locale-integrity test still passes.
