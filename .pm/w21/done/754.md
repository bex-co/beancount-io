# w21/739 regression: `pedantic` (or `unique_prices` before `implicit_prices`) now raises a false "Disagreeing price entries" and refuses a buy

**Severity:** major once deployed (an ordinary buy at cost is refused). **Estimate:** 20 minutes. Owner: ledger. A3: `unique-prices.ts:144` and `:198` now judge every day against the final directives, including `implicit_prices`' generated prices, regardless of plugin order. Beancount's `unique_prices` sees implicit prices only when `implicit_prices` is declared before it, and under `pedantic` it never does.

Proven with the real engine under ts-node (as `yarn verify:rustledger` runs it) against Beancount 3.2.3 `bean-check`, also at the commit before the fix (the agent's run). Not on production: the ledger service hasn't been redeployed with the fix. `plugin "beancount.plugins.pedantic"` then `plugin "beancount.plugins.implicit_prices"`; commodities USD and QAVTI; `Assets:Qa20261020Broker QAVTI` and `Assets:Qa20261020Cash USD`; `2026-10-20 price QAVTI 101.00 USD`. Then `addEntries` with `2026-10-20 * "Qa20261020 Buy"` (Broker 1 QAVTI {100.00 USD} / Cash −100.00). bean-check accepts it. The engine refuses it with "Disagreeing price entries". The same happens with `unique_prices` declared before `implicit_prices`. Before w21/739: 0 errors.

## Fix

Respect plugin order: run the uniqueness check on the directives as they stand at that plugin's position. Implicit prices count only when `implicit_prices` comes first.

**Acceptance:** both orders match bean-check. A unit case is added.

## Dedupe

Regression from w21/739 (done), related to w21/735 (done). Searched `.pm/**` for "Disagreeing price" and plugin order.

---

**Resolved 2026-10-23**. `reconcileUniquePriceErrors` (`backend-cluster/ledger/src/foundation/rustledger/unique-prices.ts`) now respects plugin order. Beancount runs plugins in the order declared, so its `unique_prices` sees `implicit_prices`' prices only when that plugin comes first. `pedantic` carries none of its own.

- When `implicit_prices` is declared but runs after `unique_prices` (or `pedantic`), each day is judged on the prices the source writes. The locator then ignores priced postings.
- When it runs first, or isn't declared at all, the booked stream is used, as before.

The three orders now match bean-check 3.2.3 with the note's fixture: pedantic then implicit_prices and unique_prices then implicit_prices raise nothing, so the buy is accepted. implicit_prices then unique_prices raises "Disagreeing price entries" on line 7.

Unit cases in `unique-prices.test.ts`; live engine cases in `scripts/verify-rustledger.ts` (fail at the previous HEAD with the note's false error). Needs a ledger-service deploy. Shipped in the commit that moves this note.
