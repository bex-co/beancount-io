# A currency exchange booked through an Equity conversions account reads as spending: "−$100.00" with the grey Equity icon (and as green income in a EUR ledger)

**Severity:** major. A transfer between your own accounts reads as money spent. **Estimate:** 25 minutes. Owner: mobile. A3: `transactions-screen/utils/transaction-display-utils.ts:350-353` (`selectTransactionAmount`) treats an exchange as neutral only when `postings.every(isBalanceSheet)`. In the standard Beancount trading-account pattern, the two Equity legs cancel within each currency, but they fail that test. The code then falls to the operating-currency bucket (`:379`, or failing that the largest bucket, `:392`) and signs it. `pickPrimaryAccount` (`common/tx-category`) treats Equity as a category leg, so the icon is the Equity glyph rather than the transfer glyph. The detail hero uses the same function.

Reproduced natively on the iPhone 17e simulator, English UI, Metro `--clear` at `e332baeb2`, on the disposable QA ledger, which was restored byte-for-byte to `f1a0b83c`. Fixture: `2026-10-21 * "Qa20261020 FX" "conversion via equity"` with `Assets:Qa20261020USD -100.00 USD`, `Equity:Qa20261020Conversions 100.00 USD`, `Assets:Qa20261020EUR 92.00 EUR` and `Equity:Qa20261020Conversions -92.00 EUR`. Transactions shows **"Qa20261020 FX · conversion via equity · −$100.00"** with the grey building icon. Under `tsx` (the agent's proof), a EUR ledger gives a green "+92.00 EUR". The same exchange written with `@` reads a neutral "$100.00".

## Fix

Treat the entry as an own-accounts exchange when every non-balance-sheet posting is Equity and those Equity legs exactly offset the balance-sheet legs in each currency. Show it neutral, sized by the operating-currency leg, and have `pickPrimaryAccount` return the transfer category for this shape.

**Acceptance:** this row reads a neutral "$100.00" with the transfer icon in a USD ledger, and "92.00 EUR" neutral in a EUR ledger. Unit cases are added.

## Dedupe

w21/057 and w21/570 (done) cover only exchanges written with `@`. w21/710 is the server's balance-sheet cap. Searched `.pm/**` for Conversions, "trading account", Equity:Trading and Equity:FX.

---

**Resolved 2026-10-23** — An exchange booked through Equity conversion legs now reads as a move between your own accounts. The new `isEquityConversion` (`mobile/src/common/tx-category/index.ts`) recognises the shape: only balance-sheet and Equity legs, in two or more currencies, each netting to zero, with money leaving in one currency and arriving in another. `selectTransactionAmount` (`transaction-display-utils.ts`) treats such an entry, when it has no cost or price, like the all-balance-sheet exchange: neutral, sized by the operating currency's leg. `pickPrimaryAccount` returns the transfer category for it, so it gets the transfer icon instead of Equity's. The detail hero uses the same function.

The fixture reads a neutral "$100.00" in a USD ledger, and a neutral 92.00 EUR in a EUR ledger. A two-currency opening balance, all of it arriving, is unchanged.

Unit cases are in `transaction-display-utils.test.ts` and `tx-category/__tests__/tx-category.test.ts`; three fail at the previous HEAD. One full-suite run failed `settleWithin` once (a real-timer race of 5 ms, which this change doesn't touch); it passed on every rerun. Not checked natively. Shipped in the commit that moves this note.

Native recheck (iPhone 17e, fresh Metro `--clear` at `dca83bb03`, second launch; disposable ledger with the note's Equity-conversions fixture, restored byte-for-byte to `f1a0b83c`): Transactions now shows "Qa20261020 FX · conversion via equity · **$100.00**", neutral and unsigned, with the **transfer** (⇄) icon instead of "−$100.00" with the Equity glyph. Fixed for a USD ledger. The EUR-ledger case was not exercised. (Trip and Miles in the same fixture are w21/819, still open.)
