# A long emoji payee cut at the 60-character limit puts a "�" in the commit subject

**Severity:** trivial. **Estimate:** 5 minutes. Owner: ledger.

**Root cause (A3).** `backend-cluster/ledger/src/features/ledger/utils/commit-message.ts:43` cuts with `label.slice(0, MAX_LABEL - 1)`. That counts UTF-16 units, so it can split a surrogate pair.

Not run natively in this pass (it needs the ledger deploy that carries w21/903). `tsx` proof: with a `🍕` straddling index 59, the subject is `Update 2026-10-22 "xxxx…xx�…"`. The same text round-tripped through UTF-8 also shows `�…`.

**Native steps** (after the deploy): add a transaction whose payee is about 46 characters followed by an emoji, then open Recent changes. The row subject ends in `�…`.

## Fix

Cut by code points, for example `Array.from(label).slice(0, 59).join("")`.

**Acceptance:** a payee of 46 `x` characters followed by `🍕` yields a subject with no `�` and no lone surrogate.
