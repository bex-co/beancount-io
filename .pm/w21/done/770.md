# New File accepts a name that differs from an existing file only by letter case or Unicode form ("Main" beside main.bean)

**Severity:** minor (a clone on macOS or Windows keeps only one of the pair; w23/054 exists to keep ledgers portable). **Estimate:** 15 minutes. Owner: mobile and backend-v2. A3: the client's existence check is an exact, case-sensitive match (`ledger-file-browser-screen/utils.ts:105`), and the server's `assertPortableRepoPath` (`backend-cluster/backend-v2/src/features/ledger/utils/safe-repo-path.ts:45-66`) has no case or NFC check either.

Native (iPhone 17e, Metro `--clear` at `2f2eac40f`; probe file deleted afterwards through `deleteLedgerFile`, `main.bean` untouched): Files ▸ + ▸ paste `Main` enables **Create file** with no error, beside the existing `main.bean` (cancelled without creating). Under `tsx` (the agent's proof), `checkLedgerFileName` accepts "Main" → `Main.bean`, "QA20261020-Notes" beside `qa20261020-notes.bean`, a decomposed "qa20261020-café" beside the composed one, and a trailing zero-width space. "main" is correctly refused.

## Fix

Compare names case-insensitively and NFC-normalized (and strip invisible characters) on both client and server.

**Acceptance:** "Main", "QA20261020-Notes" and the NFD variant are refused as existing. Unit cases on both sides are added.
