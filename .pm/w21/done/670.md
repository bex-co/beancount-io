# Budget ALL skips every period between the account's last posting and today (w21/010 regression via w21/332)

**Severity:** minor (Budget). **Estimate:** 20 minutes. Owner: mobile. A3: w21/332 made `allTimeThroughToday` (`budget-screen/selectors/budget-selectors.ts:316`) append the current period's row, so the series' last date is now today. `use-budget-actuals.ts:97,128-130` then calls `periodsThrough(today)` to fill in the periods after the last row, finds nothing left to add, and the empty periods between the last posting and the current one never appear. That is w21/010's bug again. Daily and weekly budgets lose every day or week in the gap.

## Fix

Fill the gap before appending the current period, or have `periodsThrough` work from the last *posting* period rather than the series' last row.

**Acceptance:** with this fixture, ALL shows September at $0, as YTD does (w21/010's acceptance). w21/332's acceptance still holds. Daily and weekly unit cases are added.
