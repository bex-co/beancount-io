# VoiceOver reads an income budget row on Home as "111% used, Above target"

**Severity:** low (accessibility). Income is reached, not used up. **Estimate:** 15 minutes. Owner: mobile. A3: `home-screen/selectors/select-budget-panel.ts:283-295` (`budgetPanelRowAccessibilityValue`) always uses `budgetPanelRowValue` ("{{actual}} of {{budget}}, {{percent}}% used, {{status}}", `translations/en.ts:699-700`), ignoring the `row.income` flag the row already carries (`:59`).

Not run natively: VoiceOver can't be driven here, and the Budget card is below the fold. Under `tsx` with the real `en` strings (the agent's proof):
- `Income:Qa20261020Salary`, target −5000, actual −5500 → "$5,500.00 of $5,000.00, 111% used, Above target".
- `Income:Qa20261020Bonus`, target −1000, actual −400 → "$400.00 of $1,000.00, 40% used, Below target".

Fixture: `2026-01-01 custom "budget" Income:Qa20261020Salary "monthly" -5000.00 USD`, plus a 5,500.00 USD salary on 2026-10-15.

## Fix

Add an income key, for example "{{actual}} of {{budget}} target, {{percent}}% reached, {{status}}", in all 13 locales, and use it when `row.income`.

**Acceptance:** an income row's spoken value has no "used". Expense rows are unchanged. A unit case is added.
