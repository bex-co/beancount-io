# A padding entry says "A plugin generated this entry", and its "source" opens titled "Transaction" with an "Edit Transaction" link under a `pad` line

**Severity:** low (wrong text). **Estimate:** 15 minutes. Owner: mobile. A3: the ledger marks padding as generated, with `generated_from` set to the pad directive (`engine.ts:270-271`), so `isPluginCopy` is true and `pluginCopyNotice` (`en.ts:409`) says "plugin". "Open the source entry" pushes the pad directive, which isn't a transaction. `selectSourceSlice` then shows it under the title "Transaction" with "Edit Transaction" (`transaction-detail-screen.tsx:670-685`).

Reproduced natively with w21/840's build. Fixture: `2026-10-21 pad Assets:Qa20261020Cash Equity:Qa20261020Opening` and `2026-10-22 balance Assets:Qa20261020Cash 500.00 USD`. Transactions ▸ "(Padding inserted for Balance of 500.00 USD …) · Pad · +$500.00" reads **"A plugin generated this entry from another one, so it can't be edited or deleted here."** "Open the source entry" opens a screen titled **"Transaction"** showing `2026-10-21 pad Assets:Qa20261020Cash Equity:Qa20261020Opening` with **"Edit Transaction"** beneath it.

## Fix

Use pad-specific wording when the flag is `P` (for example "Beancount inserted this padding for a balance check"). Title and label a non-transaction source by its directive type (Pad · Edit entry).

**Acceptance:** this padding entry and its source read as padding and pad, not as plugin output and a transaction. A unit case is added.
