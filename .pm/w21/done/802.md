# When the ledger list fails or is still loading, the drawer shows only the current ledger, with no error, retry or skeleton

**Severity:** minor. On the first launch after sign-in, a failed or slow list looks like a one-ledger account. **Estimate:** 15 minutes. Owner: mobile. A3: in `ledger-drawer.tsx`, the error/retry state renders only when the list is empty, and the footer retry bar only when at least one ledger loaded. The synthesized "Current ledger" section (`drawer-ledgers.ts:74-88`) makes the list non-empty, so neither shows, and the same section replaces the loading skeleton.

Not run natively: it needs the list request to fail. Under `tsx` (the agent's proof), no loaded ledgers, `error: true` and a selected `qa/disposable` give one section, `[Current ledger · qa] disposable`, and both the error state and the retry bar evaluate to false.

## Fix

Show the retry bar when `error && sections.every(s => s.current)`, and the skeleton under the current section while loading.

**Acceptance:** with the list failed, the drawer shows the current ledger plus a retry, and while loading it shows a skeleton. A unit case is added.

Not w21/066, w21/382, w21/391 or w21/295 (cached list, contrast, offline cached list, guard). Searched `.pm/**` for drawer together with retry, error and "Current ledger".

---

**Resolved 2026-10-23** — The drawer's list footer now covers the out-of-directory "Current ledger" row. A new `drawerListFooter` (`components/ledger-drawer/drawer-ledgers.ts`) picks it from the error and loading flags and from how many ledgers loaded and sections are shown:
- **Retry:** when the list failed and anything is shown, the current-ledger section included.
- **Skeleton:** while the list loads with nothing of it loaded yet but the current row shown.
- **Nothing:** for a loaded list, or an empty one, whose own empty state already speaks.

`ledger-drawer.tsx` draws the footer from it. With the list failed, the drawer shows the current ledger plus "Couldn't load ledgers" and Retry. While loading, it shows the skeleton rows under it.

Unit and source cases are in `__tests__/drawer-ledgers.test.ts`; four fail at the previous HEAD. A failed list request can't be forced here, so this was not checked natively. Shipped in the commit that moves this note.
