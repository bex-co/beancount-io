# The Cash flow Sankey leaves every node under about 6% of the flow unlabeled, so small categories and "Other" can't be identified

**Severity:** medium. **Estimate:** 45 minutes. Owner: mobile.

**Root cause (A3).** `mobile/src/screens/reports-screen/components/cash-flow-sankey.tsx`, in the labels `graph?.nodes.map` block (about `:360`): `if (box.y1 - box.y0 < fontSizes.xs) return null`. The node rectangle is still drawn, but the colour is per role only (`sankeyColorForRole`), so every expense node is the same red. The Sankey has no values or tooltip (a tap only dims ribbons), and the chart's spoken summary (`cashFlowChartSummary`) gives totals only.

Not run natively in this pass. `tsx` proof (the agent's): `selectRangedAccountTree` then `transformToSankeyData` on a fixture, then d3-sankey with the component's own parameters (width 370, height 280, extent `[78,8]`–`[292,272]`, `nodePadding(10)`, `iterations(0)`). Income is Salary 6000; expenses are Rent 2000, Food 600, Transport 250, Health 200, Fun 150, Phone 60, Gifts 40, Fees 12.

| Node | Height (px) |
|---|---|
| Rent | 68.0 |
| Food | 20.4 |
| Transport | 8.5 |
| Health | 6.8 |
| Fun | 5.1 |
| Other (Phone + Gifts + Fees) | 3.8 |
| Savings | 91.4 |

With `fontSizes.xs = 12`, Transport, Health, Fun and Other get no label: four of six expense nodes are unnamed red slivers. Any category under about $350 on $6,000 of income is unlabeled, and more savings makes it worse.

**Native steps:** on a disposable ledger, add `Income:Salary` -6000 and those eight expenses, all dated this month. Open Reports, tap 1M, and scroll to the Cash flow card. Only "Rent" and "Food" are labelled.

## Fix

- Draw the label of a too-short node outside the node, with a leader line or de-collided in a column. Or add a tap-to-reveal caption that shows the pressed node's name and value (the press state already exists).
- Add each node's name and amount to the spoken summary.

**Acceptance:** a pure helper such as `sankeyLabelPlacements(nodes)` returns a label for every non-hub node whose height is above 0 on the fixture above; a native check can name each of the six expense nodes, by label or by tap.

## Dedupe

w21/540, 749, 768 and 774 cover label text and fit, not omission. Searched for "sankey label hidden", "node shorter than one line" and "unlabeled node".

---

**Resolved 2026-10-24** — the nodes too short for a label (under one line of text) are now named and valued: `unlabeledNodeNotes` lists them ("Transport $250.00 · Health $200.00 · Fun $150.00 · Other $112.00" on the note's fixture, the hub and empty nodes left out), shown as a caption under the Sankey and appended to the chart's spoken summary, so every expense category can be identified by reading or by VoiceOver. This is the note's caption-and-summary option rather than leader lines or a tap-to-reveal. Cases in `sankey-data.test.ts` (the fixture and the wiring; the wiring case fails without the component change; `mobile`). Not run natively.
