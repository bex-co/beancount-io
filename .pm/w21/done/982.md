# A commodity with no cost or price loses its neutral chart colour again (w21/958), so a transfer-in reads as a large gain

**Severity:** minor to moderate. The w21/713 symptom (a split or transfer-in reading as a 900% gain) returns for unpriced commodities. **Estimate:** 30 minutes. Owner: mobile. This is a regression of w21/958 (`97741f943`).

**Root cause (A3).** `isUnitsHeldAtCost` (`mobile/src/common/balance-display.ts`) is `kind === "units" && value !== null`, used for the account detail chart's `neutral` flag (`account-detail-screen.tsx`, about `:548`). `selectBalanceDisplay` sets `value: null` whenever the converted value is 0. That is true for a foreign-currency card, which w21/958 meant to colour, and equally for a commodity with no cost or price, such as RSU grants, an airdrop or a transfer-in.

Not run natively in this pass. `tsx` proof (the agent's, with the real `selectBalanceDisplay`):

| Input | Display | `isUnitsHeldAtCost` |
|---|---|---|
| BTC held with no price or cost | units, value null | `false` (neutral before the change) |
| JPY card | units, value null | `false` (the intended target) |
| VOO at cost | units, value 4000 | `true` |

The first two cannot be told apart by this predicate.

## Fix

Distinguish a currency from a commodity, for example by whether the ledger declares a `commodity` or `price` for it, or by the operating currencies, rather than by `value === null`.

**Acceptance:** an unpriced `2 BTC` account whose units series rises 2 → 10 stays neutral, while a `JPY` account keeps its percent and colour (w21/958's native case).

**Resolved 2026-10-24** — `isUnitsHeldAtCost` is true for units with a value in the ledger's currency, or for any commodity that is not a national currency, and false only for a national currency with no value (a foreign-currency card or bank account), so an unpriced `2 BTC` or an RSU grant rising in units stays neutral while a JPY or EUR card keeps its percent and colour (w21/958). `isFiatCurrency` separates them (BTC, ETH and tickers are not, JPY and EUR are).
