# Picking a parent account in the Transactions filters also returns other accounts that merely contain its name

**Severity:** low to moderate. The filtered list includes transactions from an unrelated account, such as `Assets:Reimbursable:Expenses:Travel` when `Expenses:Travel` is picked. **Estimate:** 30 minutes. Owner: mobile.

**Root cause (A3).**
- The filter sheet sends the bare account name as `query.account` (`mobile/src/screens/transaction-filters-screen/.../select-filter-query.ts`, about `:147`).
- The server treats a plain name as a run of `:` components found anywhere in an account name (`makeComponentRunMatcher`, `backend-cluster/ledger/src/foundation/rustledger/directive-filter.ts:321`), which w21/113 made deliberate for `?account=Food`-style links.
- The picker offers only parents of two or more components (`withParentAccounts`, `picker-sections.ts:233`), so a full path from a root is always meant.

Not run natively in this pass. `tsx` proof with the real `makeAccountNameMatcher`:

| Filter | Account name | Matches |
|---|---|---|
| `Expenses:Travel` | `Assets:Reimbursable:Expenses:Travel` | yes (wrong) |
| `Assets:Bank` | `Liabilities:Assets:Bank` | yes (wrong) |
| `Assets:Bank` | `Assets:Bank-Old` | no (w21/113 works) |

An anchored `^Expenses:Travel(:|$)` matches `Expenses:Travel` and `Expenses:Travel:Air`, and rejects the other two.

**Native steps:**
1. On a disposable ledger, add `Expenses:Travel:Air` and `Assets:Reimbursable:Expenses:Travel`, each with a transaction.
2. Transactions → sliders icon → the account row → pick `Expenses:Travel` → Apply.

The list also contains the Reimbursable transaction.

## Fix

Have the filter sheet send `^<escaped account>(:|$)`, which the server's regex path accepts. Leave `?account=` links alone, since w21/113 made a bare component deliberate there. Alternatively, the server could anchor on a leading root when the value starts with a root.

**Acceptance:**
- A unit test on `toFilterQuery` builds that pattern.
- A ledger test shows the Reimbursable entry excluded and `Expenses:Travel:Air` kept.
