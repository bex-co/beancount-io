# A plain "file already exists" refusal in a subfolder is toasted as "A folder named … already exists" (w21/989 regression)

**Severity:** moderate. The message is wrong, and the name is no longer remembered. **Estimate:** 20 minutes. Owner: mobile. This is a regression of w21/989 (`0577807c2`).

**Root cause (A3).** `clashIsFolder(twin, sentPath)` (`mobile/src/screens/ledger-file-browser-screen/utils.ts:186-190`) says a clash is a folder when the twin's path is shallower than the sent path. In `handleCreate` (`index.tsx`, about `:641`), `sentPath` is the full path (`buildLedgerFilePath(currentPath, filename)`), but when the server's refusal is a plain conflict ("... already exists", with no "as"), `clashingFileName(error, filename)` falls back to the relative `filename`. In any non-root folder the relative name is always shallower than the full path, so the fallback is classed as a folder. The early return then also skips `setKnownExisting`, so the name is no longer remembered, as it was before.

At the root the depths are equal, so it works there, which is why the 989 tests pass. The test only calls `clashIsFolder` with server-style full paths.

Not run natively in this pass (it needs a stale listing inside a subfolder). `tsx` proof (run by me with the real helpers): `clashingFileName({graphQLErrors:[{message:"File already exists"}]}, "notes.bean")` gives `notes.bean`; then `clashIsFolder("notes.bean", "notes.bean")` is `false` (root), but `clashIsFolder("notes.bean", "2024/notes.bean")` is `true`. The user sees "A folder named notes.bean already exists" for a file.

**Native steps:** in a `qa-` folder, with a file created elsewhere so the list is stale, create the same name again.

## Fix

Compare like with like: strip `currentPath` from `filePath`, or call `clashIsFolder(existing, filename)` when the twin is relative. Better, have `clashingFileName` report whether the twin came from the server's "as" message, and treat only an "as" twin shorter than `filePath` as a folder. Keep `setKnownExisting` for the fallback.

**Acceptance:** `clashIsFolder` is false for `("notes.bean", "2024/notes.bean")` when the twin is the fallback; run the handler with a mocked plain conflict from a non-root `currentPath` and expect `ledgerFileNameExists` plus a remembered name.
