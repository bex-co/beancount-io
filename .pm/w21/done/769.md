# New File creates "qa20261020.bean.bean" from "qa20261020.bean." (a trailing dot adds the extension a second time)

**Severity:** trivial. **Estimate:** 10 minutes. Owner: mobile. A3: `ledger-file-browser-screen/utils.ts:38` appends `bean` to a name ending in a dot without checking whether the part before the dot already ends in `.bean`, `.beancount` or a refused extension. The dialog's own rule says a part ending in a dot is refused.

Native (iPhone 17e, Metro `--clear` at `2f2eac40f`; probe file deleted afterwards through `deleteLedgerFile`, `main.bean` untouched): Files ▸ + ▸ paste `qa20261020.bean.` enables **Create file** with no error. Create opens the editor titled "**qa20261020.bean.bean**". Under `tsx` (the agent's proof), "qa20261020.beancount." → `qa20261020.beancount.bean`, and "qa20261020.txt." → `qa20261020.txt.bean`, though "qa20261020.txt" is refused.

## Fix

Strip a trailing dot before checking or adding the extension, or refuse names ending in a dot.

**Acceptance:** "qa20261020.bean." creates `qa20261020.bean` (or is refused), and the .txt variant is refused. Unit cases are added.

## Dedupe

Searched `.pm/**` for "trailing dot" together with file name, and checkLedgerFileName.
