# Transactions rows mark only "!", so forecast (#) entries look booked and can fill the whole first screen

**Severity:** minor (a forecast plugin turns the Transactions tab into a list of future, unmarked "spending"). **Estimate:** 20 minutes. Owner: mobile. A3: `transactions-screen/entry-row/index.tsx:197` badges only `entry.flag === "!"`, and the tab passes no `dateToday`, so there's no "Upcoming" label (Home has one since w21/261). Padding (`P`) entries carry no marker either. The dashboard shows a flag column and a distinct style for these.

Native (iPhone 17e, Metro `--clear` at `3263cb449`; disposable ledger restored byte-for-byte; today 2026-10-23): the QA ledger plus `plugin "fava.plugins.forecast"` and `2026-10-20 # "Qa20261020 Groceries [WEEKLY]"` (Rent 1500.00 / Checking). The Transactions tab opens on "December 29, 2026 · **Qa20261020 Groceries −$1,500.00**", then Dec 22, 15, 8, 1, Nov 24, 17, 10… The whole first screen is projected entries, none badged or labelled upcoming.

## Fix

Badge non-`*` flags (forecast `#` as "Forecast", `P` as "Padding"), and label future-dated rows "Upcoming" on this tab as Home does.

**Acceptance:** with this fixture, forecast rows are visibly marked and today's real entries are easy to find. Cleared rows are unchanged. A unit case is added.

## Dedupe

Not w21/161 or w21/537 (the "!" badge) or w21/261 (Upcoming on Home only). Searched `.pm/**` for "isPending", forecast together with Transactions, and "Upcoming" together with Transactions.
