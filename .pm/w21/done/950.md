# A Preset ledger name pasted with a tab or line break passes the form, then Review shows raw English about a "Title" and Create stays disabled

**Severity:** minor. Names pasted from a spreadsheet cell or a note often carry a tab or a trailing newline, and the form never mentions a "Title". **Estimate:** 15 minutes. Owner: mobile.

**Root cause (A3).**
- `slugifyLedgerName` drops the control character, so `isNewLedgerName("Family\tBudget")` is true and the hint reads "Will be created as familybudget" (`ledger-name.ts:7-29, 39`).
- `buildSetup` sends the raw name as the setup title (`mobile/src/screens/create-ledger-screen/create-ledger-screen.tsx:409`, `title: values.name`).
- The backend's `previewLedgerSetup` refuses any title containing a control character (`build-ledger.ts:150`, from w23/049), with VALIDATION_FAILED.
- `previewFailureKind` treats that as `"refused"`, so `:942` prints the server's English text, and `previewBlocked` keeps Create disabled.

Starter and Sample are unaffected, because they send no title.

Not run natively in this pass. Proof with `tsx` against the mobile helpers and the backend setup builder:

| Name | Mobile form | `previewLedgerSetup` |
|---|---|---|
| `"Family\tBudget"` | valid, slug `familybudget` | refused: "Validation failed for setup: Title must not contain line breaks or other control characters" |
| `"Household\n"` | valid | refused, same message |
| `"  Family  "` | — | accepted, but written untrimmed into `option "title"` |

**Native steps** (the preview is a read-only query; nothing is created):
1. Copy `Family<tab>Budget`.
2. Drawer ▸ New ledger ▸ Preset ▸ Personal ledger ▸ Next.
3. Paste the name, then tap Next.

Review shows "Validation failed for setup: Title must not contain…", and Create is greyed out.

## Fix

Send `title: values.name.replace(/\p{Cc}+/gu, " ").replace(/\s+/g, " ").trim()`. Alternatively, refuse control characters in the name schema with a translated message.

**Acceptance:**
- `buildSetup` turns `"Family\tBudget"` into `"Family Budget"`, and `"Household\n"` into `"Household"`.
- The previews for those names succeed.
- A unit test asserts that the title never contains a control character and has no leading or trailing spaces.
