# Transaction detail never shows the brand logo that its list row shows (Amazon, Whole Foods…)

**Severity:** trivial (visual consistency). **Estimate:** 5 minutes. Owner: mobile. A3: every row that shows a payee passes it to `AccountTypeIcon`, so a known brand shows its logo. That covers `transactions-screen/entry-row/index.tsx:207`, `account-detail-screen/components/account-entry-row.tsx:193`, `merchants-screen/merchant-row.tsx:174` and `merchant-detail-screen.tsx:512`. The transaction detail hero (`transaction-detail-screen.tsx:783`) passes only `postings={iconPostings}`, so the same entry falls back to the category glyph once it's opened.

Native (iPhone 17e at `f746d69ef`; disposable ledger restored byte-for-byte): Home's Recent Transactions shows the orange Amazon logo for "QA AMAZON MKTPLACE" and the Whole Foods logo for WHOLE FOODS. Opening either one shows the fork-and-knife category glyph in the detail hero.

## Fix

Pass the same brand text the list row uses (payee, falling back to narration) to the hero's `AccountTypeIcon`.

**Acceptance:** an entry shows the same icon in its row and in its detail. Unit or render case added.
