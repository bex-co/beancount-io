# New File accepts a folder that differs from an existing one only by letter case ("qa20261020docs/b" beside Qa20261020Docs) (gap in w21/770)

**Severity:** minor. Before backend-v2's portable-twin check deploys, this creates a case-twin folder, the portability break w21/770 closed for file names. Once it deploys, the dialog closes and the toast misnames the folder: "A file named Qa20261020Docs already exists". **Estimate:** 15 minutes. Owner: mobile. A3: `checkLedgerFileName` (`ledger-file-browser-screen/utils.ts:85-115`) compares the typed path's key only against names in the current folder. The folder lookup (`index.tsx:516`) asks for `qa20261020docs` case-sensitively, gets NOT_FOUND, and the create goes ahead.

Reproduced natively with w21/824's build. In the disposable ledger, `Qa20261020Docs/a.bean` was created through the API and deleted afterwards. Files ▸ + ▸ paste **qa20261020docs/b**: no error shows, and **Create file** is enabled. Create wasn't tapped, to avoid writing a twin folder. ## Fix

**Acceptance:** this input shows that error, Create is disabled, and an exact folder match still works. A unit case is added.
