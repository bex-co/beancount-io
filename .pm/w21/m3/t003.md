## Objective

Add a script that extracts each recipe, runs it through `bea query` on the declared fixture, and fails when a query errors, returns zero rows, or names a missing fixture.

## Context

- Existing checker: `scripts/skills/ci-check.py` and its unit tests
- Run `bea` through the repo's installed path used by the existing fixture checks

## Steps

1. Parse recipes (fixture declaration + fenced query).
2. Execute with a timeout; classify error, empty, missing fixture.
3. Print one line per recipe and exit non-zero on any failure.

## Files

- scripts/skills/ (new runner, or an extension of ci-check.py)
- scripts/skills/tests/ (runner tests)

## Acceptance criteria

- [ ] A broken query, an empty result, and a missing fixture each fail the runner in a test
- [ ] The committed cookbook passes

## Out of scope

- Changing which queries the recipes use
