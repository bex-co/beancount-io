# The ledger filter in the drawer and Browse ledgers is literal about quotes, Unicode form, Turkish İ, width and Arabic script, unlike every other search in the app

**Severity:** low. It is a sibling of w21/466, 257, 519, 569, 785 and 912, none of which touched this function. **Estimate:** 20 minutes. Owner: mobile.

**Root cause (A3).** `searchWords` in `mobile/src/common/ledger-search.ts:8-13` does only `toLocaleLowerCase().split(/[\s\-_/.]+/)`, then a raw `includes`. The drawer filter (`drawer-ledgers.ts:162`) and Browse ledgers (`discovery-store.ts:23`) both use it. The description is free text typed at Create Ledger or on the dashboard.

Not run natively in this pass. `tsx` proof: `ledgerMatchesQuery` returns false for each of these.

| Description | Query |
|---|---|
| `Mom’s household` | `Mom's` |
| `Café budget` (NFD) | `café` |
| `İstanbul expenses` | `istanbul` |
| `ＦＸ trades` | `fx` |
| `كافي شاپ` | `کافی` |

**Native steps:**
1. Give a ledger the description "Mom's household" (for example from the dashboard).
2. On the iPhone, open Browse ledgers → Yours, and type `Mom` to confirm the baseline.
3. Paste `Mom’s` with a curly apostrophe, or type with Smart Punctuation on.

The ledger vanishes from the results.

## Fix

Extract the fold used in `match-suggestions.ts` (quotes, NFC, width, Arabic script, İ, whitespace) into one shared function, and apply it in `searchWords` to both the query and the haystack.

**Acceptance:** each row above returns true, and the existing w21/244 cases still pass.
