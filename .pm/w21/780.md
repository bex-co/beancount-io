# A commit diff draws an RTL account's amount inside the account path: "-  Assets:Qa20261020Bank:100.00      ملی:بانک USD"

**Severity:** low. In the change history, a posting's amount reads as part of its account, and the account's segments run child-first. **Estimate:** 20 minutes. Owner: mobile. A3: `DiffLineView` (`commit-detail-screen/commit-detail-screen.tsx:206-217`) renders `line.content` raw. Under the Unicode bidi rules (W2/N1), the "100.00" after an Arabic segment resolves as an Arabic number, and the spaces between join the right-to-left run. That run is drawn reversed, so the amount lands between "Bank:" and the Arabic segments. w21/743/766's `isolateAccountPath` (`common/bidi.ts`) isn't applied to source lines.

Reproduced natively on the iPhone 17e simulator, English UI, Metro `--clear` at `2dffe6ff5`, on the disposable QA ledger, which was restored byte-for-byte to `f1a0b83c`. Fixture: `2026-01-01 open Assets:Qa20261020Bank:بانک:ملی USD`, and `2026-10-21 * "Qa20261020 RTL deposit"` with `Assets:Qa20261020Bank:بانک:ملی      100.00 USD` / `Liabilities:Qa20261020Card -100.00 USD`. Home ▸ bell ▸ Recent changes ▸ the restore commit that removed it ▸ Diff:
- The posting line reads **"-  Assets:Qa20261020Bank:100.00      ملی:بانک USD"**.
- The open line reads "-2026-01-01 open Assets:Qa20261020Bank:ملی:بانک USD", with the child first, as on Accounts before w21/743.

## Fix

Before rendering, isolate each whitespace-delimited token of a source line that contains RTL letters. For an account token, use `isolateAccountPath`; for any other token, use a first-strong isolate. Keep the line left-to-right. Then the amount stays in its column, and the path reads root first. The same helper could serve any other raw-source view, such as Entry Context's source.

**Acceptance:** this fixture's diff lines read "Assets:Qa20261020Bank:بانک:ملی      100.00 USD", root first with the amount after the account. Lines without RTL text are unchanged. A unit case is added.
