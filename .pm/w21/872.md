# A read-only or cold-error guard inside Scan Receipt has no way back on iOS: the full-screen modal has no header, Cancel or swipe

**Severity:** minor. **Estimate:** 10 minutes. Owner: mobile. A3: the route is `fullScreenModal` with `headerShown: false` (`app/(app)/_layout.tsx:77-80`). `LedgerWriteGuard` (`src/components/ledger-write-guard.tsx:16-58`) shows only "Ledgers", which replaces the modal. Other guarded routes keep their header back button.

Not run natively: reaching the route on a read-only ledger needs a deep link, and deep links are blocked on this simulator (w4/blocked/001). Home's + is hidden for readers. Code path (the agent's): a read-only ledger plus `beancount:///(app)/receipt-capture` shows "This ledger is read-only…" with no close control.

## Fix

Add a Close or Back action to the guard, or show the header when the guard blocks.

**Acceptance:** the blocked receipt route can be dismissed back to where the user came from. A source case is added.
