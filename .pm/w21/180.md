# Budget actuals match accounts by raw text prefix, so a budget on `Expenses:Transport` also counts `Expenses:Transportation`, unlike Reports and account detail

**Severity:** moderate. A budget reads over target from a sibling account's spending, and the same month shows different Transport figures on Budget and on Reports. **Estimate:** 1 hour, plus an owner decision. Owner: ledger (or mobile). A3: the budget card's `getLedgerIntervalTotals` matches with a plain `startsWith`, deliberately copying Fava's `str.startswith`. Reports builds its tree on `:` boundaries, and the account report uses component matching (`matchesAccountOrChild`), so the two screens disagree. An earlier reviewer this run noted the Fava parity and held the issue back. This item asks the owner to decide, because mobile users see the inconsistency now.

Verified live through read-only GraphQL on `open_ledger/example` at `main` `f518cd365`: `getLedgerIntervalTotals(accountName: "Expenses:Food:Groc", time: "2017-08")` returns **USD 147.58**, the full Groceries total for a name that doesn't exist, while `getLedgerAccountReport` for the same name returns no points.

## Scenario

`Expenses:Transport` budget 100 monthly. October: Transport 40, `Expenses:Transportation` 60.
- Budget and Home's panel show Transport at $100 actual, 100% used.
- Reports 1M shows Transport $40 and a separate Transportation $60.
- Account detail for Transport shows +$40.

## Where

- `mobile/src/screens/budget-screen/hooks/use-budget-actuals.ts:37`
- `backend-cluster/ledger/src/foundation/rustledger/interval-series.ts:237, 323` (`matchesPrefix`)

## Fix (choose one)

1. Switch `intervalTotals` to component matching, a deliberate break from Fava like the CLI's w5/292, so REST, GraphQL and MCP agree.
2. Keep the server as it is, and have mobile request per-account `accountBalances` and sum only the budget account and its `:` children.

**Acceptance:** with the scenario, Budget shows $40 actual for Transport, matching Reports and account detail.

## Dedupe

w21/113 is the journal account filter; w5/292 and w5/921 are CLI. Searched `.pm/**` for startswith, matchesPrefix, "prefix sibling", Transportation and getLedgerIntervalTotals together with budget.
