# At AX2, Entry Context's balance rows cut account names to "Asset…king" and "Expen…eries"

**Severity:** minor (accessibility; AX2). **Estimate:** 20 minutes. Owner: mobile. A3: `transactions-screen/entry-context/balance-section.tsx:26-50, 88-95`. Each Balances Before/After row is a row that never stacks: the account (`fonts.mono`, `fontSizes.sm` with no scale cap, `numberOfLines={1}`, `ellipsizeMode="middle"`) sits beside `balanceAmounts`, which is `flexShrink: 0`. At AX2 the account is about 27.9pt Menlo. On a 390pt screen the amount ("4910.00 USD" ≈ 120.5pt in `AmountText`, capped at 1.4×) leaves about 173pt after the gutters, card padding and the 12pt margin. That fits about 5 characters on each side of the ellipsis.

Measured, not shown natively. The agent laid out the real fonts with AppKit at React Native's AX2 multiplier (2.143, `RCTAccessibilityManager.mm:268`): `Assets:Bank:Checking` beside "4910.00 USD" renders as **"Asset…king"**, and `Expenses:Food:Groceries` beside "85.40 USD" as **"Expen…eries"**. On iPhone 17e at AX2 (`d731eb32a`), the transaction detail pushes Entry Context below the fold, and the automation tools here can't scroll, so the expanded card wasn't screenshotted. At the default size, Money flow above it already shows "Expenses:…Utilities" at AX2.

## Fix

Stack the row (account above, amounts below, trailing) when `prefersStackedLayout` holds, as Money flow's posting row does.

**Acceptance:** at AX2 on iPhone 17e, both accounts are readable (wrapped, or truncated only to the same degree as Money flow), and amounts stay right-aligned. The default size is unchanged.
