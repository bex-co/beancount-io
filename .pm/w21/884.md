# In Persian, chart labels mix Persian and Latin digits, even within one label ("۱۲/۲۸ 25", "· اوت 2026" beside "۳۱ اوت ۲۰۲۶")

**Severity:** minor (fa). **Estimate:** 20 minutes. Owner: mobile. A3: dates format with Persian digits (`date-format.ts`), but raw Latin slices are appended:
- `common/d3/axis-year-marks.ts:21` (`year.slice(2)`)
- `common/series-util.ts:355` (`selectedPeriodLabel`, `period.slice(0,4)`)
- `budget-labels.ts:57-58` (yearly budgets, `date.slice(0,4)`)

Not run natively (it needs Persian). Under `tsx` in fa (the agent's proof):
- A weekly Budget axis across New Year reads `۱۲/۲۸ 25 , ۱/۴ , ۱/۱۱ 26`.
- Account detail's scrub label reads `· اوت 2026`, while its journal headers read `۳۱ اوت ۲۰۲۶`.
- The spoken budget span reads `۱۲/۲۸ 2025–۱/۱۱ 2026`.

## Fix

Format the year marks and the selected-month label with the same locale formatter, or pin Latin digits in `gregorian()` (`-u-nu-latn`) for fa if that becomes the rule (see w21/885).

**Acceptance:** each label uses one digit system in fa. Unit cases are added.
