# Server settings shows the "older server" result in red, with an advisory saying the server isn't available

**Severity:** trivial (self-hosted users only). **Estimate:** 10 minutes. Owner: mobile. A3: `welcome/server-settings-screen.tsx:254-255, 304, 322-323` treat only `connected` as success. The `older` result added by w21/593 therefore gets the error style, and the "You can still save this URL and try signing in when the server is available." advisory appears under it, although the server answered.

Not run natively: it needs a signed-out session and a self-hosted server older than 2026-10-21. Proven under `tsx`: the real `testServerConnection("https://beancount.io/")`, with only the schema probe answered as an old schema, returns `{"kind":"older"}`, and the screen's predicates select the red style and the unavailable-server advisory.

## Fix

Give `older` a neutral or warning style and drop the unavailable advisory for it, keeping w21/593's message.

**Acceptance:** an older server reads as a warning ("older than the app. You can connect…") without the "when the server is available" text. A unit or render case is added.
