# The AVERAGE error has no file or line when the sale posting carries a flag (`! Assets:…`) (w21/721 variant)

**Severity:** trivial. **Estimate:** 10 minutes. Owner: ledger. A3: `backend-cluster/ledger/src/foundation/rustledger/average-booking.ts:9`'s `POSTING` regex expects the account first, so a flagged posting (`  ! Assets:Qa20261020Broker -5 VTI {} @ 120 USD`) reads "!" as the account. The fallback locator then gives up when a same-day twin shares the narration, and the notification row can't be tapped.

Proven with the real engine under ts-node, against `bean-check` 3.2.3 (the agent's proof): `option "booking_method" "AVERAGE"`, a buy, a flagged sale `2024-06-01 * "Vanguard" "Rebalance"`, and a same-day twin narration. bean-check reports `main.beancount:8 AVERAGE method is not supported`; the engine reports `BOOK null:null`. Not on production: the ledger service hasn't been redeployed since w21/708.

## Fix

Allow an optional posting flag before the account in `POSTING`, or better, take the location from the posting itself (as suggested in w21/721).

**Acceptance:** this fixture reports the sale's file and line. A unit case is added.
