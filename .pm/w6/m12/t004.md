## Objective

Verify Beancount.io in Gemini Apps' real preview/native workflow and obtain one
accepted Connected Apps review submission.

## Steps

1. Follow [the current registration flow](https://developers.google.com/connected-apps/gpc/perform-the-steps)
   on the same app. Complete accurate public details, Gemini Apps availability,
   tool snapshot/permissions and required private synthetic reviewer instructions.
2. Use the authorized tester identity and actual
   [Gemini Developer Mode](https://gemini.google.com/devmode). Verify OAuth,
   actual schemas/annotations, a known accounting answer and one supported
   dry-run preview with independent unchanged commit/file/counts/balance/errors.
   Preserve existing grants and avoid unrelated data/context permissions.
3. Fix actual owned integration failures with regression coverage and API parity.
   A generic MCP client or per-user manual URL connection is supplementary,
   not proof that this registered preview works.
4. Finish all authorized preparation, then use the real review action once;
   record the app/version, accepted receipt, manage URL and UTC review status.
   Keep preview, test success and accepted review as separate observations.
5. Park genuine preview/account/mandatory confirmation gates with exact owners;
   t005 handles approval, publishing and public availability independently.

## Acceptance criteria

- [ ] The registered Gemini preview passes actual native authentication,
  discovery, accounting read and one dry-run/unchanged-state journey.
- [ ] One actual accepted review submission is retained with its exact app/version.
- [ ] Public evidence is redacted, stage/check/owner/next trigger are current,
  and no tester-only availability or preview is called a public listing.

## Out of scope

Production-ledger writes, a second deployment, public credentials/account data,
new dependencies without required approval, duplicate applications, unrelated
outreach or paid placement. Keep the hosted MCP connector distinct from local
customer-skill distribution.
