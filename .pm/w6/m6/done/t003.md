## Objective

When a skill hands off to a sibling, such as `beancount-close` → `beancount-reconcile` or `beancount-migrate` → `beancount-init`, and that sibling is not installed, the agent tells the user which skill is missing and how to install it. It must not improvise the missing workflow or fail silently.

## Context

- Sibling hand-offs today: `beancount-close` → ask, import, init, reconcile; `beancount-import` → importer-author, init, migrate, options, reconcile; `beancount-migrate` → import, init, reconcile; `beancount-reconcile` → import, init; `beancount-importer-author` → import, init; `beancount-ask` → init, reconcile; `beancount-options` → init; `beancount-init` → import, importer-author, migrate. Some are *see-also* pointers rather than hand-offs, so separate the two before editing.
- The Git checkout installs all eight at once. A registry installs one folder at a time.

## Steps

1. For each real hand-off, add one short line where the hand-off happens. It names the sibling and says how to install it from ClawHub, from Hermes, or with the link installer, by pointing at `skills/docs/installation.md` rather than repeating its commands.
2. Keep `SKILL.md` under the ~500-line guideline, and keep the wording host-neutral (no Claude Code-only or Codex-only tool names).

## Files

- `skills/.claude/skills/beancount-*/SKILL.md`

## Acceptance criteria

- [ ] With only `beancount-close` installed, a close run names `beancount-reconcile` as missing and how to get it, instead of reconciling ad hoc.
- [ ] `python3 skills/scripts/ci-check.py` passes, and `verify` on the full suite is unchanged.

## Out of scope

- Merging skills, or a ClawHub dependency mechanism (none is documented).

## Evidence

- 2026-10-16: Claude Code in plan mode, with only the `beancount-close` bundle in a workspace's `.claude/skills/`, a synthetic ledger, and a request to close June 2026 with a checking statement. It reported "0 tied, 3 unverified … the reconcile skill is missing", linked the installation guide to add `beancount-reconcile`, and did not reconcile ad hoc.
- Real hand-offs edited: `beancount-close` → `beancount-reconcile` (and `beancount-ask`'s recipes for extra figures), `beancount-migrate` → `beancount-init`. The other sibling mentions are routing or see-also pointers and were left as they were.
