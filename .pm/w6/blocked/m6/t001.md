## Objective

Get two decisions from the repository owner and record them before anything is published. First, whether the `beancount-*` skills may be published under ClawHub's `MIT-0` terms. Second, which ClawHub handle publishes them, and so which scope users type (`@<handle>/beancount-init`).

## Context

- ClawHub's skill-format page says every published skill is licensed `MIT-0`, with no per-skill override, and that `SKILL.md` must not add conflicting terms.
- The repository `LICENSE` is MIT ("Copyright (c) 2019-2026 Beancount.io"). MIT-0 drops the requirement to keep the copyright and permission notice, so the published copies would carry weaker terms than the repository.
- A package scope must match the publisher's ClawHub handle exactly. ClawHub sign-in is with GitHub, so the handle should belong to an account the project controls, not to one person.

## Steps

1. Put both questions to the owner with the facts above. Do not decide on their behalf.
2. Record the answers in the milestone `README.md` under a `## Decisions` section, with the date.
3. If the owner declines MIT-0, block the milestone with `/pm block w6/m6 …` and state that as the reason. Hermes's direct GitHub install (t008) stays available without ClawHub, so file that as a smaller inbox note instead.
