## Audit map (main, 2026-10-26)

No lifecycle mutation takes a preview flag on any surface; workflows take no preview param either.

| op | REST input | GraphQL | MCP tool input | result contract |
| --- | --- | --- | --- | --- |
| updateLedger | `ledgerUpdateInput`: name/description/private (`.strict()`) | `UpdateLedgerInput`: name/description/private | REST input + `ledger` target | `LedgerData` |
| deleteLedger | no body (`ledgerDeleteInput` `{}` unused by route); description states "Applies immediately; no preview." | `ledgerId` arg only | REST input + `ledger` target | `{ ledgerId }` |
| setLedgerCollaborator | `collaboratorUpdateInput` minus path `collaborator` (permission only) | `AddCollaboratorArgs`: ledgerId/collaborator/permission? | `COLLABORATOR_OPERATION_SCHEMAS.update` + target | collaborator result |
| removeLedgerCollaborator | path `collaborator` only (`collaboratorDeleteInput`) | `DeleteCollaboratorArgs`: ledgerId/collaborator | `COLLABORATOR_OPERATION_SCHEMAS.delete` + target | collaborator result |
| leaveLedger | `{}` body (`collaboratorLeaveInput`) | `LeaveLedgerArgs`: ledgerId only | `COLLABORATOR_OPERATION_SCHEMAS.leave` + target | collaborator result |
| setLedgerStar | no body (PUT star / DELETE unstar); description states "No preview." | `starLedger`/`unstarLedger`: ledgerId only | `ledgerStarInput` (starred bool + target) | star result |

Paths: REST `src/features/ledger/api/rest/v1/{lifecycle,collaborators,star}-handler.ts`; workflows `updateLedger`/`deleteLedger` in `src/features/ledger/workflow/ledger-workflow.ts`, collaborators in `ledger-collaborators-workflow.ts`; GraphQL `src/features/ledger/api/resolvers/ledger-resolver.mutation.ts` (+`.types.ts`), `ledger-collaborators-resolver.mutation.ts`; MCP `src/features/ai-agent/api/mcp-lifecycle.ts`, collaborators/star tools in `mcp-tools.ts` + `mcp-collaborators.ts`/`mcp-ledger-star.ts`.

Preview renderings for t002–t003: update = current→new diff with the privacy flip unmissable (fetch current, no PUT); delete = destroy summary (ledger identity + file/entry/collaborator counts or equivalent, no DELETE). Flag shape follows m7; delete may instead grow a separate preview tool following the `previewLedgerSetup` precedent (t003 decides with rationale).

t004 verdict: implement set/remove/leave (access-affecting; remove + leave already carry the DESTRUCTIVE annotation), exclude setLedgerStar with a documented rationale (IDEMPOTENT_WRITE personal toggle, instantly reversible; REST already states "No preview").
