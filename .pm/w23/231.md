# Probe `resources/read` template query keys and percent-encoding

Sibling of `w1/201` (invalid percent-encoding in a resource query value is accepted and answers an empty success). m12 made REST GETs refuse unknown keys; check whether MCP resource templates do the same.

- Probe with the in-process route tests: an unknown key, `?account=%ZZ`, a duplicated key, on three templates.
- If any is accepted silently, refuse it with `BAD_USER_INPUT` and a hint, with a test; if all refuse, record the evidence and close.
