## Objective

Make the deployed-server QA fail when a tool's text block carries less than its `structuredContent`. That is the gap that let the summary-only text ship.

## Context

- `.agents/skills/qa-shared/scripts/qa-contract-replay.mjs` replays the documented contracts against the hosted endpoint, and `.agents/skills/qa-shared/scripts/qa-mcp.mjs` prints parsed JSON-RPC messages.
- `.agents/skills/qa-find-bugs-mcp/SKILL.md` drives MCP QA. It never compares the two result channels.
- The rule is in `backend-cluster/backend-v2/docs/mcp.md` § The result envelope: every text block except `runBqlQuery`'s ends with `structuredContent` as compact JSON on its last line. `runBqlQuery`'s text is the table, equal to `structuredContent.result` after the row-count line.
- The in-process gate is `backend-cluster/backend-v2/src/features/ai-agent/api/__tests__/mcp-text-carries-data.test.ts`.

## Steps

1. In the contract replay, for every `tools/call` it makes (successes and refusals), parse the text block's last line and compare it with `structuredContent`. Apply the `runBqlQuery` rule to that tool.
2. Report a mismatch as a failing row naming the tool.
3. Add the channel check to the qa-find-bugs-mcp skill's surface table, and note that Claude Code shows `structuredContent`, so it cannot be the client used to judge text.
4. Cover the comparison with the helper's Node tests.
