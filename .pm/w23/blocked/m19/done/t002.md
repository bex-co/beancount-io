## Objective

For a plain projection that selects `discrepancy`, run the engine query with `date`, `account` and `amount` appended as hidden columns, look up each row's failed-assertion diff by those keys (the validator figure the journal path already uses, `failedBalanceDiffs`), fill the `discrepancy` cell as an Amount (null for a passing assertion, as stock), and drop the hidden columns from the result and its column list.

## Context

- `ledger-journal-service.ts` `failedBalanceDiffs`, `ledger-legacy-journal.ts` (`diff_amount`).
- Hidden columns must not change row count, order, LIMIT or the visible column names/dtypes.

## Steps

1. Append the keys and map them to diffs
2. Fill the cells and strip the hidden columns
3. Keep results byte-identical for queries that do not select discrepancy
