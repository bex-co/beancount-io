## Objective

Record every intentional difference between the engine and stock beanquery in one allowlist, in the corpus README, with a reference for each entry, so a new difference is never silently tolerated.

## Context

- Candidate references: blocked `w6` items (for example `w6/blocked/023`, the engine's FROM evaluation, and `w6/m2`, which needs a published `@rustledger/wasm` release), ADRs, and documented engine limitations.
- The allowlist is keyed by query id and the difference class; the replayer (t003) refuses entries without a reference.

## Steps

1. Run the replayer and list every difference the first corpus shows.
2. For each, either fix it as a separate inbox note or allowlist it with a reference.
3. Write the allowlist and a short README (how to regenerate, how to add a query, what an entry must cite).

## Files

- `backend-cluster/ledger/scripts/bql-oracle/README.md` (new)
- The allowlist file read by the replayer

## Acceptance criteria

- [ ] Every allowlist entry has a reference that resolves in the repository.
- [ ] The replayer fails on an allowlist entry with no reference.
- [ ] The README documents the regeneration command and the offline-fixture rule.

## Out of scope

- Fixing the engine differences the allowlist records.
