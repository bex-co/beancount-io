## Objective

Make `yarn verify:rustledger` replay every oracle query through the current ledger engine, compare rows, columns, dtypes, and error category with the stock result, and print a per-query diff for any unexpected difference.

## Context

- `backend-cluster/ledger/scripts/verify-rustledger.ts` already runs live engine checks (and already cites stock beanquery results in comments); `package.json` exposes it as `verify:rustledger`.
- The jest harness cannot host the `@rustledger/wasm` loader, which is why this gate runs under `NODE_OPTIONS=--experimental-vm-modules` as a script.
- Deviations that are intentional are listed in an allowlist (t004); the replayer must read it and skip only exact, referenced entries.

## Steps

1. Load `bql-oracle.json` and the allowlist in `verify-rustledger.ts` (or a module it imports).
2. Run each query against the engine on the same fixture and compare using the normalization from t001.
3. Print, per failing query: the query, the oracle result, the engine result, and the first differing cell or column.
4. Fail the script when any unallowlisted difference exists.

## Files

- `backend-cluster/ledger/scripts/verify-rustledger.ts` (or a new module under `backend-cluster/ledger/scripts/bql-oracle/`)

## Acceptance criteria

- [ ] `yarn verify:rustledger` replays the whole corpus and exits nonzero on an unallowlisted difference.
- [ ] The failure output names the query and shows both results.
