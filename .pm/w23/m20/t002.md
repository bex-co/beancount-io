## Objective

Pick about 60 queries from the done w23 BQL findings and add the checked-in fixture ledgers they run against, then generate `bql-oracle.json` with t001. The set covers FROM shapes, expressions, date arithmetic, NULL handling, and empty results.

## Context

- Sources: done notes `w23/016`, `116`–`171`, and the open `w23/212` (`FROM year > 2026`, `FROM account ~ 'Cash'`, `FROM payee LIMIT 1`, `FROM has_account(...)`).
- **Offline constraint:** the oracle must be reproducible offline. Fixtures use literal `price` directives only; never `include "https://beancount.io/prices/..."` or any other network source. Stock beanquery reads a local loaded ledger and has no data source of its own; the managed price feed is resolved by the `bea` CLI outside beanquery. Price-related queries (`convert`, `getprice`, conversions) must therefore run against literal `price` directives.
- Reuse the existing multi-file fixtures under `backend-cluster/ledger/scripts/rustledger-shadow/fixtures` where they fit instead of copying them.

## Steps

1. Group candidate queries by finding class and keep a few per class rather than every probe.
2. Add or reuse fixture ledgers; write only literal `price` directives.
3. Record, per query, which done note it comes from.
4. Generate `bql-oracle.json` and review the stock results by hand for the classes the notes describe.

## Files

- `backend-cluster/ledger/scripts/bql-oracle/queries.json` (new, query list with provenance)
- `backend-cluster/ledger/scripts/bql-oracle/fixtures/` (new or reused)
- `backend-cluster/ledger/scripts/bql-oracle/bql-oracle.json` (regenerated)

## Acceptance criteria

- [ ] About 60 queries, each citing its source note, covering FROM shapes, expressions, date arithmetic, NULL, and empty results.
- [ ] `grep -r "https://" ` over the fixtures finds no `include` of a remote URL.
- [ ] Regenerating the oracle on a machine without network access gives identical output.

## Out of scope

- Fixing any engine deviation the corpus reveals; those are recorded in the allowlist (t004) or filed as inbox notes.
