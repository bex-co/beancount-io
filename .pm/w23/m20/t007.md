## Objective

Add meaningful tests for the gate itself: assert real behavior and failure modes, not trivial or snapshot-everything checks.

## Context

- The gate's value is that it fails when it should; the tests must prove that.
- The package's jest suite cannot load `@rustledger/wasm`, so tests cover the pure parts (diffing, normalization, allowlist and hash checks) with synthetic inputs.

## Steps

1. Unit-test the comparison: a differing cell, a differing dtype, a missing column, and an error-vs-rows mismatch each produce the expected diff text.
2. Unit-test the allowlist: an entry without a reference is refused, and an entry matches only its exact query and difference class.
3. Unit-test the staleness hash: changing a query changes the hash and yields the regeneration message.
4. Run the manual sabotage check once: reintroduce the w23/212 wrap in `bql-from-fold.ts`, confirm `yarn verify:rustledger` fails naming the affected queries, then revert.

## Files

- `backend-cluster/ledger/scripts/bql-oracle/` tests, or `backend-cluster/ledger/src/**/__tests__/` for the pure helpers

## Acceptance criteria

- [ ] Each tested failure mode fails before the behavior exists and passes after.
- [ ] The sabotage check was run and the result is recorded in the closeout.

## Out of scope

- Testing beanquery itself.
