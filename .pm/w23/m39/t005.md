## Objective

A file that nothing includes is not part of the ledger, so its entries are not validated. Say so in the verdict instead of "No new bean-check errors", without refusing the create-then-include flow.

## Context

- `w1/227`: `createLedgerFiles` on an orphan `.bean` file with an unopened account reports `valid:true`
- `appendLedgerText` with a path nothing includes is refused (control)
- Creating a file before including it is the documented way to split a ledger, so refusing would break it

## Steps

1. Decide the verdict shape (for example `included:false` and a note that entries are not validated)
2. Apply it to preview and commit on REST, GraphQL and MCP
