# 200 — date_diff silently NULLs when DATE() meets non-column args in 3 cells

## Summary
`date_diff` agrees with stock wherever a column is involved (w23/022 it.514-515,
w23/165's workaround), but silently returns NULL — no error — in exactly three
non-column cells, all involving the `DATE()` constructor, while stock returns
day counts:
- `date_diff(DATE('2026-02-01'), DATE('2026-01-01'))` → MCP blank, stock `31`.
- `date_diff(today(), DATE('2026-01-01'))` → MCP blank, stock `300`.
- `date_diff(DATE('2026-02-01'), 2026-01-01)` (bare-date second arg) → MCP
  blank, stock `31`.

The full 4×4 arg-kind matrix (column / `today()` / `DATE()` / bare date) is
otherwise clean: `(col,·)` and `(·,col)` all agree, `(today,today)` → 0 both,
`(DATE,today)` → −269, `(bare,DATE)` → 31, `(bare,bare)` → 31, `(today,bare)` →
300. Only the three cells above blank — asymmetrically (`(bare,DATE)` works
but `(DATE,bare)` blanks; `(DATE,today)` works but `(today,DATE)` blanks), so
no simple "DATE() unsupported" rule explains it. `DATE()` itself is sound
(dtype `date`, correct value) and works inside `date_add(DATE,7)` → 2026-01-08
and `year(DATE)` → 2026 — the NULL comes from `date_diff`'s own argument
handling. Blanks are stable across reruns (deterministic, not flaky).

## Repro
- `call runBqlQuery {"ledger":"puncsky/mcp-agent-eval","query":"SELECT date_diff(DATE('2026-02-01'), DATE('2026-01-01')) FROM entries LIMIT 1;"}` → `1 row`, blank cell. GraphQL `queryShellText` twin blanks identically (engine-level, all surfaces). Stock CSV: `31`.
- `… date_diff(today(), DATE('2026-01-01')) …` → blank; stock `300`.
- `… date_diff(DATE('2026-02-01'), 2026-01-01) …` → blank; stock `31`.
- Controls: `(col,DATE)` → −31, `(DATE,col)` → 31, `(DATE,today)` → −269,
  `(bare,DATE)` → 31 — all match stock.

## Expected
Return the day count in the three blank cells like stock (and like the
neighboring cells). A wrong-but-quiet NULL inside a documented workaround
function (w23/165 names `date_diff` the day-count workaround) is worse than a
refusal: agents cannot detect it. Owner: rustledger engine (`date_diff`
overload resolution / argument evaluation); upstream report if the WASM
can't see it.
