# 200 — Text rendering blanks correct date_diff values in 3 DATE()-arg cells

## Summary
`date_diff` COMPUTES correctly everywhere, but the text renderer blanks the
cell in exactly three non-column `DATE()`-involving cells, while stock's text
and every structured surface show the value:
- `date_diff(DATE('2026-02-01'), DATE('2026-01-01'))` → MCP text blank;
  structured `[[31]]` (dtype int), REST `[[31]]`, stock `31`.
- `date_diff(today(), DATE('2026-01-01'))` → MCP text blank; structured
  `[[300]]`, stock `300`.
- `date_diff(DATE('2026-02-01'), 2026-01-01)` (bare-date second arg) → MCP
  text blank; structured `[[31]]`, stock `31`.

Proof the value (not just the type) is right: `WHERE date_diff(DATE,DATE) > 0`
keeps all 29 rows on MCP (a NULL would filter everything), and `SELECT
date_diff(DATE,DATE) > 0` renders `TRUE`. But `SELECT date_diff(DATE,DATE) + 0`
renders blank — arithmetic propagates whatever makes the cell unrenderable,
while comparison coerces through it. The full 4×4 arg-kind matrix (column /
`today()` / `DATE()` / bare date) is otherwise text-clean, asymmetrically so
(`(bare,DATE)` renders 31 but `(DATE,bare)` blanks; `(DATE,today)` renders
−269 but `(today,DATE)` blanks). GraphQL `queryShellText` blanks identically
(shared text renderer); MCP structured, REST, and (by shape) `queryShell` are
correct — text-only, not engine-level. (First version of this note filed it as
an engine NULL; the WHERE/structured controls corrected the mechanism.)

## Repro
- `call runBqlQuery {"ledger":"puncsky/mcp-agent-eval","query":"SELECT date_diff(DATE('2026-02-01'), DATE('2026-01-01')) FROM entries LIMIT 1;"}` → `1 row`, blank cell. Same query via `runBqlQueryStructured` → `[[31]]`; REST `POST …/query` → `[[31]]`; stock CSV → `31`.
- `… date_diff(today(), DATE('2026-01-01')) …` → text blank, structured `[[300]]`, stock `300`.
- `… date_diff(DATE('2026-02-01'), 2026-01-01) …` → text blank, structured `[[31]]`, stock `31`.
- Controls: `WHERE … > 0` → 29 rows (value present); `SELECT … > 0` → TRUE; `SELECT … + 0` → blank (arithmetic propagates the unrenderable cell).

## Expected
Render the computed value as text in the three cells (the renderer already
has the int — structured proves it). Owner: ledger shell text renderer /
`toShellCell` text path (`ledger-shell-mappers.ts` family): find what cell
shape these three arg combinations produce that stringifies to `""` while
JSON-serializing to the number, and normalize it. Until fixed, text and
structured disagree on the same query — agents reading text see missing data.
