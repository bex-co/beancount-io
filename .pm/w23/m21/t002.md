## Objective

Turn the t001 table into a generated test that runs each tool through each available surface using the existing in-memory parity fixtures and asserts the preview/commit rule.

## Context

- Reuse the fixtures in `structured-entry-parity.test.ts`, `file-write-gate-parity.test.ts` and `source-slice-parity.test.ts`.

## Steps

1. Write the generator over the t001 fixture.
2. Per case assert: preview succeeds, `valid:false`, `newErrors` non-empty, nothing written; commit refuses with the same code on every surface.
3. Fail the run when `MCP_TOOLS` has a preview-capable write tool missing from the fixture.
