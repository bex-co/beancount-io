# 183 — `AND`/`OR` coerce NULL to FALSE instead of propagating NULL (stock + SQL say NULL)

## Summary
The engine coerces NULL to FALSE inside `AND`/`OR` (two-valued logic over the coercion), while stock propagates NULL (NULL result whenever a NULL side survives short-circuit). Seven legs split: `NULL AND TRUE`, `TRUE AND NULL`, `NULL OR FALSE`, `FALSE OR NULL`, `NULL AND NULL`, `NULL OR NULL` (MCP FALSE, stock NULL), plus `NULL AND FALSE` (MCP FALSE, stock NULL — the one leg where MCP is SQL-correct and stock quirks). Agreement legs pin the rule on both sides: `FALSE AND NULL`→FALSE, `TRUE OR NULL`→TRUE, `NULL OR TRUE`→TRUE, `NOT NULL`→TRUE (both coerce there; SQL would say NULL, out of scope).
