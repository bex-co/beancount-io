# MCP endpoint accepts an empty JSON-RPC batch `[]` with `202` instead of `-32600 Invalid Request`

**Severity:** minor (transport edge case; no data effect). **Owner:** `backend-cluster/backend-v2` (`mcp-route.ts`). **Estimate:** 15–30m. **Pillar:** A1. **Parity:** MCP-only — REST and GraphQL have no JSON-RPC batch envelope, so no other surface changes.

## Repro (production 2026-11-05, `beancount-mcp` 1.0.0, API key, Node helper `qa-mcp.mjs`)

`POST https://beancount.io/api-gateway/mcp` with `Accept: application/json, text/event-stream`, `Content-Type: application/json`, a valid bearer, and body:

| Body | Status | Result |
| --- | --- | --- |
| `[]` | `202` | empty body, accepted as if it were notifications |
| `[{"bad":1}]` | `400` | `-32600 Invalid Request: the body must contain valid JSON-RPC messages` |
| `{"bad":1}` | `400` | same `-32600` |
| `"x"` | `400` | `-32600 Invalid Request: the body must be a JSON-RPC request object` |
| `[{"jsonrpc":"2.0","id":1,"method":"tools/list"}]` | `200` | normal batch result |

## Expected

JSON-RPC 2.0 §6 makes an empty array an Invalid Request: `400` with `-32600` and `id: null`, the same envelope the other malformed bodies already get.

## Root cause

`backend-cluster/backend-v2/src/features/ai-agent/api/mcp-route.ts:134` validates a batch with `body.every((message) => JSONRPCMessageSchema.safeParse(message).success)`. `[].every(...)` is vacuously `true`, so the envelope check passes and the SDK transport answers `202`, as for a body of only notifications. The check was added by `62bc5b6fe` ("distinguish invalid MCP envelopes from parse errors").

## Fix

Treat an empty array as invalid in that predicate (`body.length > 0 && body.every(...)`) and add a `mcp-route` test next to the existing invalid-envelope case asserting `400` / `-32600` for `[]`. Add a `docs/mcp.md` line only if the transport section lists the invalid-body cases.

## Dedupe

Searched `.pm/**` (including `done/`) for empty batch / JSON-RPC envelope terms: no match. `yarn mcp:conformance` checks 1–16 do not cover it.
