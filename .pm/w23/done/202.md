# 202 — listLedgerEntries tool lacks the journal subtype filters every sibling surface has

## Summary
`listLedgerEntries` refuses `transactionSubtypes`/`documentSubtypes`/
`customSubtypes` as `Unrecognized key`, while the same filters work on the
MCP `journal` resource, REST `GET …/journal`, and (per w23/006) GraphQL
`getLedgerJournal` — all backed by the shared `getJournal` service that
already normalizes them. The tool is the lone surface without them:
- `call listLedgerEntries {"ledger":"…","transactionSubtypes":["cleared"]}`
  → `BAD_USER_INPUT: Unrecognized key: "transactionSubtypes"`.
- `read beancount://…/journal?transactionSubtypes=["cleared"]` → rows.
- REST `GET …/journal?transactionSubtypes=["cleared"]&limit=2` → `total: 29`
  (16 cleared + 13 family-passthrough, the documented w23/150 scoping).
- Live tool schema: `account, filter, time, directiveTypes, limit, offset,
  ledger` only; description promises narrowing "by account, filter, time,
  and directiveTypes" — no subtype mention.

Worse, w23/006 (done) claims the opposite: its resolution says "mixed-case
kinds and subtypes forwarded canonically on REST, the MCP resource, the MCP
tool and GraphQL". `git log -S transactionSubtypes` on
`backend-cluster/backend-v2/src/features/ai-agent/api/mcp-list-tools.ts` is
empty — the tool NEVER had the params, so the done-note over-claims and its
"journal-parity" pins cannot cover tool subtypes. An agent working
tool-first (the primary agentic path) has no subtype filtering without
dropping to resources/REST.

## Repro
- `call listLedgerEntries {"ledger":"puncsky/mcp-agent-eval","transactionSubtypes":["cleared"]}` → `Unrecognized key` (same for the other two subtype keys).
- `call listLedgerEntries {"ledger":"puncsky/mcp-agent-eval","directiveTypes":["Transaction"]}` → `total: 16` (tool works; only subtypes missing).

## Expected
Add the three subtype arrays to the tool input (same case-insensitive
normalization + unknown-value refusal as the siblings, reusing
`normalizeJournalKinds`), extend the description, and either extend 006's
parity pins to the tool or correct the done-note's claim. Owner:
backend-v2 MCP tools (`mcp-list-tools.ts` + service passthrough).
