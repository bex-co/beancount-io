## Objective

Generate the stock results for the mapped statements into the checked-in corpus with the same source-hash staleness check as the BQL oracle.

## Context

- `backend-cluster/ledger/scripts/bql-oracle/bql-oracle.json`, `bql-oracle-source-hash.ts`
- No fixture may read a network source

## Steps

1. Add the report statements to the generator
2. Regenerate the corpus
3. Keep the stale-corpus message naming the regeneration command

## Files

- backend-cluster/ledger/scripts/bql-oracle/

## Acceptance criteria

- [x] The corpus regenerates offline and a stale corpus fails with the command to run

## Out of scope

- Adjacent work not named above

## Result

Reused the BQL oracle's machinery instead of a second generator: the 24 `report-*` statements (2 ledgers x 3 reports x 4 modes) are appended to `queries.json`, so `generate-bql-oracle.py` captures stock's answers into `bql-oracle.json` offline and the existing source hash covers them. `"replay": false` marks them so the BQL replay, whose question is the engine's BQL, skips them; `report-cases.json` maps each to a report and mode. Regeneration is the existing command.
