## Result

Each report is defined by a stock BQL statement over the summed inventory: `SELECT account, <fn>(sum(position)) [WHERE …] GROUP BY account ORDER BY account`, with `units`, `cost`, `value` and `convert(…, 'USD')` for the conversion modes `units`, `at_cost`, `at_value` and `usd`, scoped to all accounts (trial balance), the balance-sheet roots, or `year = 2026` and the income roots (income statement). Two fixtures cover the price paths: `reports.bean` has no `price` directives, only the `@` annotations of a lot sale and a EUR charge (the `w1/229` shape, plus a pad and a balance assertion), and `reports-priced.bean` is the same ledger with literal directives; both load clean in stock beancount. Written up in the oracle README ("Report oracle").
