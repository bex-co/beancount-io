## Result

`replay-report-oracle.ts` runs each case through `LedgerFinanceService` (the same in-memory repository the live checks use), flattens the account tree to the balance each account holds, and compares it with stock's rows as exact decimals; the pure flatten and compare logic is `report-oracle-compare.ts` with unit tests. `yarn verify:rustledger` calls it after the oracle replay. First run against an empty allowlist: 12 cases differed. With price directives the reports agree with stock (only `96` against `96.00` formatting, which the exact comparison ignores). Without them the reports also agree for `units`, `at_cost` and `usd`, leaving the EUR and QAX figures unconverted as stock does. The real differences: the balance sheet's synthetic equity accounts (Fava's design, ignored by name) and the reports' `at_value`, which values a lot with no price directive at cost where stock BQL `value()` leaves the units (Fava's `get_market_value`, documented in `cost-valuation.ts`).
