## Objective

Add a helper that, given the requested conversion target(s) and the currency-keyed balances a report returned, lists the from/to legs that stayed in another currency (non-zero only), including the case where the requested target does not appear in the data at all (a USD-only ledger asked for EUR).

## Context

- Promoted from `w23/180` (owner decision 2026-10-30: disclose holdings-style, not refuse).
- Design change, 2026-10-30: a first cut collected the unreachable legs inside the ledger's lot valuation (`19b758623`, reverted in `f31482e2c`). A converted payload already keys every balance by the currency it ended in, so any non-zero currency that is not the conversion target IS a leg without a price path; deriving it in backend-v2 gives the same answer with no ledger endpoint or client change. The silent cases are the summary shapes, which state one `currency` and gave no hint that the requested conversion was not honored.
- Holdings already returns `missing_prices` (a list of from/to legs); reuse the leg shape.

- [x] Mixed data with a priced and an unpriced currency yields only the unpriced one
- [x] units, at_cost, at_value and a missing target yield no legs; multi-target lists name the whole target string
