# w23/118 — `initialize` validation failures answer `-32603` with a raw zod dump instead of `-32602` + shaped error

Status: inbox
Opened: 2026-10-26 (loop it.2710–2711)
Surface: MCP (`initialize`)
Severity: minor (error-shape consistency; `-32603` misleads clients into treating a bad request as a server fault)

## Summary

Every other MCP method shapes invalid params the same way: JSON-RPC `-32602`
with `data: {code: "BAD_USER_INPUT", message, hint}`. `initialize` alone answers
`-32603` (JSON-RPC "Internal error") whose `message` is a raw zod issue array and
which carries no `data` at all:

| call | result |
|---|---|
| `tools/call` (params omitted) | `-32602`, `data.code BAD_USER_INPUT`, hint (it.2698) |
| `resources/read {}` | `-32602`, `data.code BAD_USER_INPUT`, hint (it.2703) |
| `prompts/get` mistyped arg | `-32602`, `data.code BAD_USER_INPUT`, hint (it.2694) |
| `initialize` (clientInfo omitted) | `-32603`, message = `[\n {\n "expected": "object",\n "code": "invalid_type",\n "path": [\n "params",\n "clientInfo"\n ], …`, NO `data` |
| `initialize` (`capabilities: 5`) | `-32603`, same raw-zod shape naming `params.capabilities`, NO `data` |

## Why it matters

- `-32603` means "the server failed while handling a valid request". A client (or
  retry layer) that trusts the code will treat its own malformed `initialize` as a
  server outage — retries, backoff, pages — instead of fixing the request.
- The raw zod dump leaks validator internals (`expected`/`code`/`path` frames) in
  a shape no other method emits, so clients cannot share one error parser.
- `initialize` is the first call every client makes; it is the worst method to
  shape differently.

## Suggested fix

Route `initialize` params through the same validation-error mapper as the other
methods: `-32602` + `data: {code: "BAD_USER_INPUT", message, hint}`.

## Repro

```bash
node .agents/skills/qa-shared/scripts/qa-mcp.mjs rpc initialize \
  '{"protocolVersion":"2025-11-25","capabilities":{}}'
# → {"code":-32603,"message":"[\n  {\n    \"expected\": \"object\", …","path":["params","clientInfo"] …}
node .agents/skills/qa-shared/scripts/qa-mcp.mjs rpc tools/call
# → {"code":-32602,…,"data":{"code":"BAD_USER_INPUT",…}}  (the shape initialize should match)
```
