## Audit map (live engine, synthetic ledger, 2026-10-27)

Reproduced via `backend-cluster/ledger/tmp/probe-122-nulls.ts` (scratch, live `@rustledger/wasm` + `queryResultToShellResult`). Every 122 probe confirmed:

| probe | raw engine cell | mapped value | mapped dtype | owner |
| --- | --- | --- | --- | --- |
| `sum`/`min`/`first`/`last` over empty filter | `null` | `""` | `str` (name fallback) | shell |
| `count(*)` over empty filter | `0` | `0` | `int` | — (correct) |
| GROUP BY null group key | `null` (it.3193 shape; fixture lacks null payees, mapper path identical) | `""` | column fallback | shell |
| `int`/`decimal`/`bool`/`str(NULL)` | `null` | `""` | `str` (name is `int(NULL)` etc., matches no table) | shell |
| `year`/`month`/`day`/`quarter(NULL)` | `null` | `""` | `str` | shell |
| `date(NULL)` | engine error `type error: DATE: argument must be a string or date` | error | — | engine |
| `weekday(NULL)` | engine error `type error: WEEKDAY expects a date` | error | — | engine |
| `substr`/`subst(NULL)` | engine error (it.2054/2277 probes) | error | — | engine |

The `""` is 100% the shell: `toShellCell` coerces null (`ledger-shell-mappers.ts:185`), a documented contract pinned by the w23/075 test. The `str` dtype is 100% the shell: `classifyColumnDtype` filters nulls, then falls back by column name. The engine is honest throughout the lenient camp — it returns `null` and lets us mistype it.

Target contract: value rendering awaits the w23/075 owner decision — (b1) null on REST+MCP with `""` kept on GraphQL, (b2) null everywhere, or (b3) keep `""`. Dtype is independent of that decision: numeric/string/date nulls should report their natural dtype under any option. t002 blocks on 075; t003's inference work (expression/cast/name shape — the engine exposes no cursor schema) is designed here and waits behind it.

Strict-camp triage (for t004): `date` vs `int`/`decimal`/`bool`/`str`, and `weekday` vs `year`/`month`/`day`/`quarter`, are engine-internal inconsistencies — no shell code is involved (errors arrive with severity error, no hint). `substr`/`subst` likewise. Verdict: upstream-file each cluster (casts, date-parts, substr family) with the sibling comparison as evidence; shell-side, add ENGINE_GAPS hint entries (`ledger-shell-service.ts` precedent) so the refusal names the coercion the siblings perform. No silent inconsistency left untriaged either way.

Out of scope, confirmed: empty aggregates return one engine row (`[null, 0]`) where stock returns zero — the w23/blocked/022 split, untouched by this milestone.
