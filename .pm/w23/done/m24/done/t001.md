A Node script that reads the QA credentials from the environment, connects to the hosted MCP endpoint, records the deployed server revision, and works only on a synthetic ledger it creates.

- Hosted endpoint: `https://beancount.io/api-gateway/mcp`. `.pm/DO_NOT_DO.md` forbids a second stack for MCP testing.
- The `qa-find-bugs-mcp` skill already names `QA_EMAIL`/`QA_PASSWORD` as the credential source; they live in gitignored env files only.

## Steps

1. Create `scripts/` entry under the backend package with a clear usage header.
2. Fail fast with a plain message when the credentials are missing.
3. Create the synthetic ledger and delete only what the script created.
