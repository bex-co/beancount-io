## Result

`id-handoff-matrix.test.ts` lists every identifier-shaped argument `tools/list` publishes (16 primary spellings) with the tool that produces it. A new one fails until registered, a producer that is renamed or removed fails, the argument's own text or its tool's text has to name a producer, and each flow marked as a journey has to be driven in `tools-only-journey.test.ts`, which walks the flows with each id taken from the previous call's output. Its first run found three real gaps the text-only reviews had missed: `insertReceiptTransaction.receiptObjectKey`, `parseReceipt.objectKey` and `parseFile.s3ObjectKey` never said where the key comes from, which hosts that cannot read resources need (ADR 019 D7); the three tool descriptions now name `generateTempAssetUploadUrl`. Nested arguments (`deleteEntrySources` entries, `deleteLedgerFiles` files) are not scanned.
