## Result

The rule is `src/shared/page-info.ts` (`PageInfo`, `offsetPage`, `numberedPage`) and the `Pagination` section of `docs/mcp.md`: the signal rides beside the result, never inside it. Offset reads are exact (`total` or `truncated`); page-and-limit reads report `hasMore` when the page came back full, so an exact-multiple last page reads `hasMore: true` and the next is empty. A catalog page past the first with no `limit` carries no signal.
