## Result — audit (2026-11-07)

Envelopes: REST v1 success has **no envelope** (`server/rest/v1-route.ts` sends the handler's value bare); MCP tools wrap in `{ok,result}` (`features/ai-agent/utils/run-tool.ts`); MCP resources return the bare JSON; GraphQL list fields return bare `[Type]` arrays and `extensions` is used only for error codes. The only existing page metadata is the legacy journal's `PageInfo`.

| Read | Params | Max | Result | total / more |
| ---- | ------ | --- | ------ | ------------ |
| `listLedgers` / catalog `accessibleLedgers` | page+limit | 100 (omitting both returns all) | bare array | none |
| catalog `owned`, `search` | page+limit | search 100; owned unverified | bare array | none |
| `listLedgerEntries` / journal | limit+offset | 1000, default 20 | `{total,data,is_empty}` | `total` = whole filtered count; no more-flag |
| plaintext-journal | limit+offset | 1000 | `{content,total,truncated}` | `total` whole count; `truncated` = more remain |
| account-journal | limit+offset | 1000, default 20 | `{items,total,...}` | `total`, no more-flag |
| collaborators | page+limit | 50, default 10 | REST shape unverified; GraphQL bare array | none verified |
| commits | page+limit | 50, default 30 | bare array | none |
| public keys (REST/GraphQL only) | page+limit | 50 | bare array | none |
| social followers/following/starred | page+limit | 50, default 20 | `{users|repositories,total}` | `total` = **returned page size**; no more-flag |
| feed | offset+limit | 100, default 10 | `{items,total,hasMore}` | complete: whole count and `hasMore` |
| staged bank transactions, ledger source files | none | none | arrays | none; the 100-file resource cap is silent |

Spellings: limit+offset only on the journal reads and feed; page+limit everywhere else; no cursor anywhere. Only the feed and plaintext journal tell a caller whether more remains.

Consequence for the plan: an "additive-only" in-body envelope exists for the object-shaped results (journal, account journal, social) but not for the bare arrays (ledgers, catalog, commits, collaborators, keys), where a has-more field would change the top-level type. See the milestone's Blocked section.
