# 143 — Temp-asset `NOT_FOUND` carries the generic ledgers/files/entries hint, which names three lookups that cannot contain the key

## Summary
Every temp-asset miss answers `NOT_FOUND: Temporary asset not found` with the fallback hint "Confirm the target exists: `listLedgers` for ledgers, `listLedgerFiles` … for files, `listLedgerEntries` for entry hashes" — none of which can ever surface a `tmp/…` object key. An agent holding a stale or mistyped key is sent to page through ledgers, files, and entries instead of re-checking the key against `generateTempAssetUploadUrl` output or re-uploading. Same hint-quality family as w23/047 (done, which added entries to the fallback) and w23/137 (open, lying permission pointer) — this is the temp-asset remainder: the fallback improved, but this family needs its own hint.

## Repro (prod, puncsky/mcp-agent-eval, read-only)
- `read beancount://temp-assets/download-url?objectKey=not-a-valid-key` → `-32002 NOT_FOUND: Temporary asset not found` + the generic hint.
- `call parseReceipt {"objectKey":"tmp/bogus-qa-key-12345"}` → `isError: true`, same code/message/hint. No quota spent (fails before parsing).
- Uniform message across foreign/malformed/missing keys is correct (w23/066) — only the hint is wrong.

## Root cause (main)
`TEMP_ASSET_NOT_FOUND` concealment (`backend-cluster/backend-v2/src/server/api/authorization/authorization-service.ts`) deliberately unifies foreign/missing/malformed denials as `NOT_FOUND` but carries no tailored hint, so MCP falls back to `CATEGORY_HINTS[NOT_FOUND]` (`src/features/ai-agent/api/mcp-errors.ts`). Contrast the file read, which throws its `NotFoundError` with a tailored "List what exists first" hint (`mcp-resources.ts`).

## Expected
A temp-asset-specific hint on the concealed denial — re-check the `objectKey` from `generateTempAssetUploadUrl` (or the completed upload), keys expire and are user-bound — without distinguishing foreign from missing (w23/066 constraint). The concealment is shared, so REST/GraphQL surfaces need the parity check per the backend workflow.
