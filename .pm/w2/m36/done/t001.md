## Objective

Commit `backend-cluster/backend-v2/server.json` describing the hosted MCP endpoint for the official MCP Registry, and a backend test that keeps the listing aligned with what `/.well-known/mcp.json` advertises.

## Context

- Schema: `https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json`. `name` matches `^[a-zA-Z0-9.-]+/[a-zA-Z0-9._-]+$`; `description` ≤ 100 characters; remotes are `streamable-http` or `sse` with an HTTPS, non-localhost URL; `repository` takes `url`, `source`, `id`, `subfolder`; `icons[]` take an HTTPS `src`, `mimeType`, `sizes`.
- Draft values validated on 2026-10-03: name `io.beancount/beancount`, title `Beancount.io`, description "Query, edit, and reconcile a hosted Beancount ledger: BQL, reports, files, and bank imports." (93 chars), version `1.0.0`, `websiteUrl` the MCP guide in this repository, repository `https://github.com/bex-co/beancount-io` (`source: github`, `id: "300529232"`, `subfolder: backend-cluster/backend-v2`), icon `https://beancount.io/lgasset/logo.png` (256×256 PNG, served today), one remote at `https://beancount.io/api-gateway/mcp`.
- `mcpManifest` in `backend-cluster/backend-v2/src/features/well-known/api/well-known-route.ts` names `endpoint` and `version: "1.0.0"`; the test config in `__tests__/well-known-route.test.ts` uses `dashboard.url: https://beancount.io`, so the manifest's `endpoint` there is the production URL the listing must match.
- `mcp-publisher` installs with `brew install mcp-publisher` or from the latest release tarball (`mcp-publisher_darwin_arm64.tar.gz`); run it from `tmp/` if not installing.

## Steps

1. Write `server.json` with the draft values; keep `remotes` to the one `streamable-http` entry and add no `headers` or `packages`.
2. Run `mcp-publisher validate server.json` from `backend-cluster/backend-v2/`.
3. In `well-known-route.test.ts`, read `server.json` from the package root and assert: `$schema` on `static.modelcontextprotocol.io`; `name` is `io.beancount/beancount`; `description.length <= 100`; `version` is semantic and equals the manifest's `version`; `remotes[0]` is `streamable-http` at the manifest's `endpoint`; `icons[0].src` is on the production origin.
4. Mutate the URL once locally to confirm the test fails, then restore it and run the focused suite.
