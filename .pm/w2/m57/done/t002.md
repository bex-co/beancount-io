## Objective

Book a payroll run exactly as the provider's summary prints it: gross wages and employer taxes to expense, each withholding and employer tax to its liability, net pay out of the bank.

## Context

- Same discipline as `beancount-property`'s mortgage split: figures are read as printed, never computed.

## Steps

1. Write the inputs list and gates: printed gross minus printed withholdings equals printed net; employer taxes as printed.
2. Write the proposal shape and the confirmed write.

## Files

- The owning skill's text and references

## Acceptance criteria

- [x] A summary that ties produces a balanced, check-passing entry; one that does not tie stops with both figures shown.
- [x] A summary missing a figure produces a question, never a computed amount.

## Out of scope

- Calculating wages, withholdings, or employer taxes.
- Contractor payments (ordinary entries through `beancount-add`).

## Result

`beancount-add` gains Recording payroll: inputs only as the provider's summary prints them (a missing figure is asked for, never computed), the `payroll-tie` gate (printed gross − withholdings = printed net, by engine arithmetic, a nonzero gap stops the proposal), the entry shape per ADR025 (wages and employer taxes to expense, one `Liabilities:Payroll:<Item>` per printed line, net from the paying account, `payroll:` metadata), a duplicate-run check, and the batch write; paychecks received and contractor payments stay ordinary entries. Verified by `test_payroll_run_ties_printed_figures_and_books_liabilities` (a tying summary reads gap 0.00, a misread net reads -4.00, the run writes with its `payroll:` key and the root check passes; fails when the gap ignores withholdings). Full skills suite: 160 tests pass. The add description is unchanged, since the routing probe already sends payroll runs here.
