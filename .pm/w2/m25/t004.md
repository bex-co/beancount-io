## Objective

Give people one command to update that does the right thing for their install channel and never replaces files itself.

## Context

- The sibling bex CLI's `bex upgrade` self-replaces only raw-binary installs and refuses when a package manager owns the file; `bea` has no raw-binary channel, so `bea upgrade` only dispatches.
- Channel detection from `sys.executable` / the console script path: Homebrew (`/Cellar/` or `/opt/homebrew/`, `/home/linuxbrew/`) → `brew upgrade bea`; uv tool (`uv tool dir` prefix) → `uv tool upgrade beancount-io`; pipx (`pipx environment` venv dir) → `pipx upgrade beancount-io`; editable or checkout install → print `git pull` and `uv sync` guidance and exit 0.
- `--check` prints the current and latest versions and the command it would run, without running it.

## Steps

1. Add `cli/src/cli/commands/upgrade.py` with the detection table and a `--check` flag; run the chosen command with the user's PATH, stream its output, and return its exit code.
2. Unknown channel: exit 2 with the two manual commands.
3. Document in `docs/USAGE.md` and `README.md`.
