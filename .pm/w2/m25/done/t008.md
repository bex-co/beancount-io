## Context

- Notifier and upgrade code are pure Python with injectable clock, environment, HTTP, and paths; the formula renderer and tag check are shell scripts testable with fixtures.

## Steps

3. Formula: rendering a fixture version/sha produces a formula that `ruby -c` parses and that contains the sha exactly once; bad version input fails.
4. Release: `make release-check` rejects a mismatched tag (shell test).
