# Tell clients which entries are managed prices instead of making them parse the path

w2/m32/t005 hides Edit/Delete on managed price entries in the dashboard journal panel. It recognizes them by regex on the entry's file name (`managedPriceSourceUrl` in `dashboard/src/features/journal/lib/entry-source-location.ts`), which copies how the ledger builds virtual keys (URL resolved against the including file, `//` collapsed by POSIX normalization).

The ledger already holds the exact list, `managedPricePaths`, and its write guard uses it. Have the ledger's entry-context/source-slice read return `managedSource: string | null` from that list, carry it through backend-v2 (GraphQL `getLedgerEntryContext`, REST, MCP entry-context), and let the dashboard read the field. Then drop the regex. Mobile and any other client get the same answer without copying the key rule.

About an hour across ledger, backend-v2 and dashboard. Found by the m32 simplify pass (altitude review).
