## Cause and repair

`mobile/src/screens/home-screen/components/account-charts-card.tsx:130–142` stores lifetime maxima for `captionHeight` and `headerHeight`. At235–246 its caption wrapper always uses `minHeight: captionHeight`, including when the current caption is undefined; the caption layout callback only applies `Math.max(previous, height)`. Neither ledger identity nor layout changes reset that measurement. `home-screen.tsx:111–140` correctly produces optional current-ledger captions, but its persistent card at241–251 receives no ledger/layout measurement scope. The pure `chartPageHeight` helper can shrink when given a smaller header; the owning state never supplies one.

Scope the card's measurements to its current ledger and layout inputs, allowing obsolete measurements to shrink/reset. Preserve the deliberate maximum across the three pages **within the current context**, so ordinary tab changes remain stable and every page retains the full170-point plot. Do not replace this with the last active page's height, erase range selection as an incidental remount, disable text enlargement, truncate amounts or remove valid valuation information. Account for font/width/locale and loaded-content changes in the same local measurement contract. No backend, query, dependency or shared AmountText change is needed.

Add a meaningful mounted-card lifecycle regression: caption-bearing ledger → caption-free ledger, and a measured larger layout → smaller layout. It must fail with the lifetime maximum retained; the existing numeric helper tests alone miss it. Native acceptance: repeat the default and maximum→large journeys in both themes, with current values unchanged, no obsolete caption gap, accessible ranges and complete plots; switching current tabs still has stable height. Preserve loading/error/empty and permission behavior.

One production `AccountChartsCard` caller exists, HomeScreen, shared by app and example tab aliases. The app route was exercised; signed-out aliases remain source-traced. Account-detail `BalanceChartCard` uses the shared chart outside this pager and is not independently reproduced as affected.
