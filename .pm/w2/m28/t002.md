## Objective

Trial balance, income statement, balance sheet, overview, and interval totals return Fava's chart payloads (`*_hierarchy_data`, `linechart_data`, every zero-balance account). Give agents a summary shape and keep the chart shape behind a query switch.

## Context

- Every audit agent computed net worth and spending by account with BQL instead of the statements, because the statement payloads are shaped for the dashboard's charts.
- The services already compute totals; the summary is a projection, not a new report.

## Steps

1. Define summary shapes: balance sheet → `{asOf, currency, assets, liabilities, equity, netWorth, byAccount: [{account, balance}]}` (non-zero only); income statement → `{period, income, expenses, net, byAccount}`; overview → `{netWorth, series: [{date, netWorth}]}`; interval totals → `[{period, total, byAccount}]`.
2. Make the summary the default for the MCP resources and the m27 tools; accept `?shape=fava` for the current payload.
3. Report amounts in the ledger's operating currency with `conversion` honored; state the currency once at the top.
