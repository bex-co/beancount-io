# Monaco color scheme for markdown (and other non-beancount) files

Ledger file blob view (e.g. `/ledger/<name>/files/blob/main/README.md`) renders markdown with no syntax colorization.

Cause: `dashboard/src/features/ledger-editor/file-editor/components/ledger-file-view/text-editor.tsx:47` passes the raw file extension as the Monaco language id (`md`), but Monaco's markdown language id is `markdown` — unknown ids fall back to plaintext. `@monaco-editor/react` already ships all basic-language tokenizers, so no new deps needed.

Fix: add an extension → Monaco-language-id mapping (`md`/`markdown` → `markdown`; while there, cover other mismatched common extensions: `yml` → `yaml`, `py` → `python`, `sh` → `shell`, `js`/`ts` → `javascript`/`typescript`) with a unit test, keeping the existing `beancount`/`bean` → `beancount` case. Verify colors render in both light and dark themes on a `.md` blob.
