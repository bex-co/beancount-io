## Objective

Add one small TypeScript authorization module that can decide only the canonical `user.delete` action.

## Context

- `authz/model.fga` defines `user#can_write_lifecycle` as an exact-self relationship derived from `owner`.
- ADR 0010 does not call for an OpenFGA deployment yet, so runtime evaluation remains local and replaceable.
- The module must not grow into a grant framework, a second DSL, or a migration of unrelated operations.

## Steps

1. Define the canonical action, user resource constructor, typed input/decision, and structured denial error.
2. Permit browser-session and OAuth user credentials, deny API keys, and check the exact-self relationship through a narrow evaluator.
3. Fail closed for unknown actions, wrong resources, relationship denial, and evaluator failure.

## Files

- `backend-cluster/backend-v2/src/server/api/authorization/**`

## Acceptance criteria

- [x] The module implements only `user.delete` and has no dependency beyond existing backend code.
- [x] The allow decision requires the current subject and resource to be the same stable user ID.
- [x] API keys and every unknown or unavailable path deny with structured metadata.

## Out of scope

- Step-up, grants, Redis, OAuth changes, OpenFGA deployment, or other actions.
