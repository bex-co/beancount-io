## Objective

Make every indexable page emit exactly one self-referencing `rel=canonical` by wiring `getSelfCanonicalUrl` into the shared SEO components, while reconciling with the routes that already emit canonicals (commit detail, blob, ask) so no page ends up with two canonical tags.

## Context

- `dashboard/src/common/components/seo/ledger-seo.tsx` and `page-seo.tsx` emit title/description/OG/hreflang via React 19 head hoisting but no canonical today.
- `hreflang-links.tsx` shows the SSR-safe location pattern (`useLocation()` from TanStack Router + constant production origin).
- Commit-detail (`routes/ledger.$ledgerOwner.$ledgerName.commit.$commitSha.tsx`, m9), blob, and ask routes set canonicals at the route level (m8) — these must remain the single canonical for those pages.
- `noIndex` pages skip hreflang already (m8); they must not gain a canonical either.

## Steps

1. Add canonical emission to `LedgerSEO` and `PageSEO`: default to `getSelfCanonicalUrl` on the current location; skip entirely when `noIndex`.
2. Add an optional `canonicalUrl` prop so routes with bespoke canonicals (commit/blob/ask) pass theirs through instead of double-emitting; remove or delegate the route-level `<link rel=canonical>` where needed so each page has exactly one.
3. Spot-check rendered heads (SSR + client) for: overview, journal, an account page with `?lang=uk`, an account page with `?editMode=`-style params, commit detail, blob, ask, login.

## Files

- `dashboard/src/common/components/seo/ledger-seo.tsx`
- `dashboard/src/common/components/seo/page-seo.tsx`
- `dashboard/src/common/components/seo/ledger-page-seo.tsx` (prop pass-through if needed)
- Routes currently emitting their own canonical (commit detail, blob, ask) — reconcile only

## Acceptance criteria

- [ ] Indexable pages emit exactly one `rel=canonical`; `noIndex` pages emit none.
- [ ] Account page visited with `?lang=uk` canonicalizes to `...?lang=uk`; with UI-state params they are stripped.
- [ ] Commit-detail/blob/ask pages keep their existing canonical URLs with no duplicate tag.
- [ ] `yarn lint && yarn test` pass in `dashboard/`.

## Out of scope

- Changing the hreflang alternate scheme.
- Sitemap coverage (backend-owned).
