# Surface managed price status to clients (follow-up to w2/m31, ADR 015)

The ledger service now returns per-source status for managed price includes (`managedPrices` on every cached load: url, alias, commodity pair, source, revision, ETag, observed-at, next refresh, `recent` / `stale` / `unavailable`, last error). Nothing above the ledger reads it yet. Expose it through backend-v2 on REST, GraphQL, and MCP with the same shape and credential policy (parity workflow), then show the freshness label and timestamps in the dashboard's price and balance views, and hide the edit action on managed price entries (the ledger already refuses the write with `OPERATION_NOT_ALLOWED`). A "Refresh prices" action is a head update that zeroes `nextRefreshAt` (ADR 015 section 5); ship it with this surface. More than an hour across three packages: size before promoting.
