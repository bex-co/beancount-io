## Objective

Show which prices come from a managed source, how fresh each source is, and let a writer refresh them.

## Context

- Price view: `dashboard/src/features/ledger-data/commodities/`. Data comes through Apollo/GraphQL codegen (`yarn codegen`).
- New locale keys go in `en` first, then every locale (`src/test/translations.test.ts`).

## Steps

1. Add the managed-price query and refresh mutation `.graphql` documents, then run codegen.
2. Render a managed sources panel on the commodities page. Each source shows alias/pair, a freshness label (`recent`/`stale`/`unavailable`), observed and next-refresh times, and the last error. Add a Refresh prices button for writers that refetches on success.

## Files

- `dashboard/src/features/ledger-data/commodities/**`, `dashboard/src/graphql/**`, locale files

## Acceptance criteria

- [x] Ledgers with no managed include see no new UI.
- [x] Each freshness state has a distinct, translated label.
- [x] Refresh is hidden for read-only viewers and shows a pending state.

## Out of scope

- Balance sheet annotations beyond the price view; the instrument catalog.

## Result

`ManagedPriceSources` sits above the charts on the commodities page. Each source shows its pair, a freshness badge (any unknown value reads as unavailable), its feed source, observed and next-refresh times, and the last error. Writers also get Refresh prices, which refetches both the status and the commodity charts. Covered by `managed-price-sources.test.tsx` (9 cases). Codegen ran against an SDL printed from backend-v2 source, because the deployed gateway does not serve the new fields yet. Not checked in a running browser in this session.
