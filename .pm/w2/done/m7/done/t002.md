## Objective

Extensionless and dotfile text files are classified as `text` so `FileContentView` routes them to `TextFileView`.

## Context

- `getFileExtension` returns `""` for `LICENSE`, `Makefile`, `.gitignore` (`dashboard/src/features/ledger-editor/shared/lib/utils.ts:32`)
- `isTextFile:50` and `getFileType:95` control routing in `dashboard/src/features/ledger-editor/file-editor/components/ledger-file-view/file-content-view.tsx:67`

## Steps

1. Add `TEXT_BASENAMES` set in `utils.ts` (lowercased, without leading `.`): `license`, `licence`, `copying`, `copyright`, `readme`, `contributing`, `code_of_conduct`, `changelog`, `history`, `authors`, `makefile`, `gnumakefile`, `dockerfile`, `containerfile`, `gemfile`, `rakefile`, `vagrantfile`, `procfile`, `gitignore`, `gitattributes`, `editorconfig`, `env.example` (and plain `env`).
2. Update `isTextFile(filename)` to return `true` if `getFilename(filename).toLowerCase().replace(/^\./, "")` is in the set, or if extension is in `textExtensions`.
3. Ensure `getFileType` inherits the fix (it already delegates to `isTextFile`).
4. Keep case-insensitive; handle paths (`a/b/LICENSE` → `LICENSE`).
