## Context

- The ledger is the rules database: learning from history every run avoids a parallel rules file that drifts. No separate rules file in v1.
- Low confidence routes to `Expenses:Uncategorized` (or a clarifying question when the batch is small), never to a plausible-sounding guess.

## Steps

3. Define the per-row output shown at review: target account, confidence, one-line reasoning.
