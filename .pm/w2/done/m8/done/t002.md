## Objective

SEO helpers can emit a `robots` meta tag (`noindex, follow` or equivalent) from one shared API used by ledger and page SEO components.

## Context

- `dashboard/src/common/lib/seo/seo-helpers.ts` — `getSEOMetadata` / `createHeadMeta`
- `dashboard/src/common/components/seo/ledger-seo.tsx`, `ledger-page-seo.tsx`, `page-seo.tsx`
- Today: title, description, OG, Twitter, hreflang only — no robots control

## Steps

1. Extend head-meta builders with an optional `robots` / `noIndex` flag.
2. Thread the option through `LedgerSEO` / `LedgerPageSEO` / `PageSEO` (and route `head()` helpers if needed).
3. Default remains indexable when the flag is unset (overview pages unchanged).

## Files

- `dashboard/src/common/lib/seo/seo-helpers.ts`
- `dashboard/src/common/components/seo/ledger-seo.tsx`
- `dashboard/src/common/components/seo/ledger-page-seo.tsx`
- `dashboard/src/common/components/seo/page-seo.tsx`
- Matching `__tests__` under those folders

## Acceptance criteria

- [ ] Call sites can request `noindex` and the rendered `<head>` includes a robots meta tag.
- [ ] Existing pages with no flag keep previous indexable behavior.
- [ ] Unit tests cover both modes.

## Out of scope

- Applying noindex to every deep route (t003).
- Hreflang gating (t004).
