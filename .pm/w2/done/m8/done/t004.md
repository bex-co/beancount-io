## Objective

Do not emit 15-locale hreflang alternates on pages marked `noindex`, which currently multiply crawlable `?lang=` URLs (GSC showed Fees pages for `lang=uk` / `lang=ca`).

## Context

- `dashboard/src/common/components/seo/hreflang-links.tsx` is included from `LedgerSEO` for every ledger page.
- Hreflang on noindex pages wastes crawl budget and creates low-CTR locale duplicates.

## Steps

1. Gate `HreflangLinks` behind the same noindex flag (or omit when robots is noindex).
2. Ensure indexable overview pages still emit hreflang as today.
3. Add/adjust a component test for the gate.

## Files

- `dashboard/src/common/components/seo/ledger-seo.tsx`
- `dashboard/src/common/components/seo/hreflang-links.tsx`
- `dashboard/src/common/components/seo/__tests__/*`

## Acceptance criteria

- [ ] noindex pages render zero hreflang `link rel="alternate"` tags.
- [ ] Indexable overview pages still render the full language set + x-default.

## Out of scope

- Changing how `?lang=` works for signed-in users.
- CMS locale URL strategy (`/zh/blog`, etc.).
