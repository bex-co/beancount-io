## Objective

Keep an enforceable indexability policy aligned with Beancount.io as a **social accounting** app with searchable acquisition pages.

## Final policy (outcome)

Canonical copy: `dashboard/src/common/lib/seo/indexability.ts`.

**Indexable (default):**
- Public user profiles + useful public ledger read/social surfaces
- Base Ask / agent landing page (prefilled-question deep links are noindex)
- Acquisition pages: login, sign-up, forgot password
- Read-only ledger file (`blob`) pages, with stable canonical URLs

**noIndex:**
- Transactional auth: reset-password token URLs, sign-up OTP, authenticated welcome
- Ephemeral auth: logout, OAuth callback/consent, device auth
- Auth-gated shells (`/ledger` home, `/ledger-gallery` while requireAuth)
- User + ledger settings; file directory (`tree`), edit/create/upload; import;
  plaid/link; receipt
- Parameterized/internal views: BQL query and ledger errors
- Error / not-found pages

## Acceptance criteria

- [x] Policy documents useful social reads + acquisition pages as indexable.
- [x] Transactional/private/write/thin/parameterized surfaces remain noIndex.
