## Objective

Transactional, private, write, thin, and parameterized routes emit `noindex`; useful public social/read routes remain indexable.

## Context

- GSC showed that route ownership alone is not enough to decide indexability.
- Social/read value is intentional for public journals, reports, accounts, documents, events, holdings, statistics, and commits.
- Token/session flows, internal tools, and write screens are not useful search destinations.

## Steps

1. Apply `noIndex` via `LedgerPageSEO` / route `head()` to the denylist in t001.
2. Keep useful public social/read and acquisition pages indexable.
3. Canonicalize Ask URLs and noindex prefilled-question deep links.

## Files

- `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.*.tsx` (deep children)
- Feature pages that render `LedgerPageSEO` / `LedgerSEO`
