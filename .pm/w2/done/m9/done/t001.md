## Objective

Give `GET /ledger/$owner/$name/commit/$sha` a route-level `head` that emits a specific title/description containing the short hash (7 chars) plus `rel=canonical` to the stable commit URL, and stop reusing the list key `ledgerCommits` for the detail page.

## Context

- Route lives at `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.commit.$commitSha.tsx` — currently `component: CommitDetailPage` with no `head`. Detail page at `dashboard/src/features/git/commits/pages/commit-detail-page.tsx` uses `<LedgerPageSEO seoKey="ledgerCommits" />` (generic "Commits - {ledgerName}").
- Read-only `blob` route already shows the pattern: `getSEOMetadata` + `createHeadMeta` + `links: [{rel:"canonical", href: getLedgerFileCanonicalUrl(...)}]` at `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.files.blob.$branch.$.tsx:17`.
- Commit URL is public and indexable per `dashboard/src/common/lib/seo/indexability.ts`; canonical must strip UI query params.
- SEO key `seo.ledgerCommits` exists; detail needs `seo.ledgerCommit` (singular) with `{ledgerName}` and `{shortSha}` interpolation.

## Steps

1. Add `head: ({params}) => ({...createHeadMeta(getSEOMetadata("seo.ledgerCommit.title","seo.ledgerCommit.description",{ledgerName: params.ledgerName, shortSha: params.commitSha.slice(0,7)})), links:[{rel:"canonical", href:"https://beancount.io/ledger/"+encodeURIComponent(params.ledgerOwner)+"/"+encodeURIComponent(params.ledgerName)+"/commit/"+encodeURIComponent(params.commitSha)}]})` to the commit route (or equivalent via helpers).
2. Update `dashboard/src/features/git/commits/pages/commit-detail-page.tsx` to use `seoKey="ledgerCommit"` with `params={{shortSha: commitSha.slice(0,7)}}` so SSR + CSR via `LedgerPageSEO` also emit the short hash (keep `LedgerPageSEO` path for client hoisting; route head is canonical for SSR).
3. Keep list page `w2/m8` behavior for `/commits` (still `ledgerCommits`).
