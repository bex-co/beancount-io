## Objective

Make every loader caller see managed prices by overlaying validated virtual files onto the file map after the SHA-keyed cache returns, with ledger-authored prices winning and per-source status attached.

## Context

- ADR 015 sections 1, 6, 7, 8, 10.
- `loadCachedFileMapForRepo` in `src/foundation/clients/load-cached-ledger-file-map.ts` is the single choke point every service and route uses; `loadLedgerFileMap` is its uncached fallback.
- `url-include-errors.ts` rewrites the engine's missing-file report for URL includes; the message must now distinguish "not an allowed managed source" from "managed source unavailable: <cause>".

## Steps

1. Create `managed-price-overlay.ts` with `overlayManagedPrices(files, entryPoint, deps)` that: walks the include closure, collects URL targets with their including path, applies the policy, dedupes by URL, resolves each through the feed cache (bounded by `maxFeedsPerLedger`), computes the engine key per including file, materializes the first key with the effective text and later keys with a placeholder comment, and returns `{ files, managedPrices }`.
2. Implement precedence: collect `(date, base, quote)` from the customer's own files; replace shadowed managed price lines and their metadata with `; shadowed by ledger price` comment lines, preserving line numbers.
3. Compute `freshness` from the latest `observed-at` and the clock; attach `ManagedPriceSource[]` to `LoadedLedger.managedPrices`.
4. Call the overlay from both `loadCachedFileMapForRepo` (after `getOrSet`) and `loadLedgerFileMap`, passing the process cache helper and config.
5. Extend `reportUrlIncludes` to take the resolution outcomes and emit the three message classes (not allowed, unavailable with cause, unchanged for non-managed URLs); keep file and line pointing at the customer's include.

## Acceptance criteria

- [x] With the BTC-USD fixture, the returned file map contains the feed under `https:/beancount.io/prices/BTC-USD` and `managedPrices[0].freshness` is `recent` under a clock inside ten minutes of the latest observation.
- [x] A same-date `2026-09-15 price BTC 1 USD` or `price USD 0.00001 BTC` in `main.bean` comments out the managed 2026-09-15 line in the virtual file.
- [x] The same URL included from `main.bean` and `sub/x.bean` yields one feed body and one placeholder.
- [x] A disallowed URL and an unavailable managed URL produce the two distinct error messages at the customer's file and line.
