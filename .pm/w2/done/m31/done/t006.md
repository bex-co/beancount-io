## Objective

Guarantee that virtual price files are never counted, offered, edited, deleted, or committed.

## Context

- ADR 015 section 9.
- `src/core/directive-limit.ts` counts directives over `files`; `ledger-journal-service.ts` locates source slices over `files` and commits by file path; `ledger-data-service.ts` `checkProjectedErrors` overlays projected files onto `files`.
- `assertSafeRepoPath` would accept `https:/host/prices/BTC-USD` as a path, so an edit today would attempt a real Gitea write.

## Steps

1. Export `isManagedPricePath(path)` from the overlay module and `stripManagedPriceFiles(files)`.
2. In `directive-limit.ts`, count and project over the stripped map.
3. In the journal service, reject `updateSourceSlice`, `deleteSourceSlice`, and `deleteMultiSourceSlices` when the located file is a managed price path with `OperationNotAllowedError("edit managed price source", ...)` before any commit.
4. In `checkProjectedErrors`, reject a projected overlay whose path is a managed price path with `BadUserInputError`.
5. Confirm `collectSourceFiles` and `includeTraversalOrder` skip URL targets (already true) and add regression tests.

## Acceptance criteria

- [x] A ledger with 5 directives plus an 87-price feed counts as 5 for the directive limit.
- [x] Editing or deleting a managed price entry returns `OPERATION_NOT_ALLOWED` and no Gitea write is attempted.
- [x] `sourceFiles` never contains a managed price path.

## Out of scope

- Hiding the edit action in the dashboard.

## Evidence
