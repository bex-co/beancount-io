## Objective

Write the Report + Commit phases in SKILL.md: generate the month's income statement and balance sheet summary via `bean-query` (reuse `beancount-ask` recipes where they exist), assemble the close report (checklist statuses + statements), and — only after confirmation — commit with a documented message convention (e.g. `close: 2026-06 — N accounts reconciled, P&L attached`).

## Context

- The commit is the audit artifact: the close report goes in the commit body so `git log` reads as a close history.
- Confirm gate covers both any fix entries made during the close and the commit itself.

## Steps

1. Define the P&L/BS summary queries and the report format.
2. Define the commit message convention and what gets staged.
3. Confirm-gate the commit; on no, leave the working tree for the user.
