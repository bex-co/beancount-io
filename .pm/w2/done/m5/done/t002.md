## Objective

Write `references/close-checklist.md`: the full month-end procedure — enumerate active accounts for the period, reconcile each (delegating to the `beancount-reconcile` skill where statements exist, flagging accounts without statements), verify period-end balance assertions, check recurring-entry completeness (expected rent/salary/subscription entries present), and sweep flagged (`!`) entries.

## Context

- Recurring completeness is a query over prior months' payee patterns: what appeared in each of the last N months but not this one?
- Accounts without statements can't be reconciled — they are listed as "unverified", never skipped silently.

## Steps

1. Define active-account enumeration (postings in period or nonzero balance).
2. Define per-account reconciliation delegation and the unverified path.
3. Define the recurring-completeness check and the flag sweep.
