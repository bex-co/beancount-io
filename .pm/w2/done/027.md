# `bea` resolves managed price includes locally (follow-up to w2/m31, ADR 015)

PRFAQ002 promises the same `include "https://…/prices/BTC-USD"` line works in the CLI. The hosted contract is now fixed by ADR 015 (origin allowlist, `/prices/<ALIAS>`, price-only validation, ledger-price precedence, immutable revision plus a mutable head with time-stamped refresh, failure keeps the last good revision). Mirror it in `cli/` with a cache directory of `<hash>/<revision>.beancount` plus `head.json`, an offline mode that reads the head only, and strict mode that fails on stale or unavailable sources, across check, list, query, report, import, and write validation. Multi-task; size before promoting.
