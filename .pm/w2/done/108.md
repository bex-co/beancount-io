# Account searches find nothing when the text has a leading or trailing space

**Minor · dashboard · 20–30 minutes.** A2: an account name pasted from a statement, a spreadsheet cell or a copied journal line often carries a trailing space. Both account searches then report no matches for an account that exists.

Production https://beancount.io, 2026-11-10, English, isolated headless Chromium 156 at 1440×1000, signed in as the owner of the designated synthetic ledger. Read-only. Local main `c7d2ab05c`.

## Reproduce

| Surface | Input | Actual | Control |
| --- | --- | --- | --- |
| Accounts page search (`/ledger/<o>/<l>/accounts`) | `  cash  ` | **0 / 12**, empty table; the URL keeps `search=++cash++`, so a reload repeats it | `cash` → `Assets:Cash` |
| Sidebar **Search accounts…** (Go to account) | `  cash  ` | no options | `cash` → `Assets:Cash` |

The other list searches already trim: Budget (`features/ledger-data/budget/index.tsx:220`, `search.trim()`) and Ledger Gallery (`features/ledger-list/pages/gallery-page/index.tsx:88`).

## Root cause

- `dashboard/src/features/ledger-data/accounts/index.tsx:455-460` compares `a.account.toLowerCase().includes(search.toLowerCase())` against the raw input. `hasActiveFilters` (line 468) also counts a whitespace-only search as an active filter.
- `dashboard/src/common/components/ledger-layout/go-to-account.tsx:72` relies on cmdk's default filter, which scores the untrimmed input.

## Fix

Trim before matching in both places. On the Accounts page, use `const query = search.trim().toLowerCase()` and base `hasActiveFilters` on the trimmed value. Keep the raw text in the input and URL so typing is not disturbed. For Go to account, pass cmdk a `filter` that trims the search (or trims the controlled search value) and otherwise keeps cmdk's ranking. Add one test per surface that types `"  cash  "` and expects `Assets:Cash`.

## Blast radius

These are the two account-name searches in `dashboard/src`. The journal's Account filter is sent to the ledger service and is not covered here.
