## Objective

Mirror the EN title/description intent across all 13 locale `seo/*.ts` files so `hreflang` alternates each have a native-language snippet with brand + keyword, not English leftovers.

## Context

- Locale files at `dashboard/src/i18n/locales/seo/bg.ts, ca.ts, de.ts, es.ts, fa.ts, fr.ts, ja.ts, ko.ts, nl.ts, pt.ts, ru.ts, sk.ts, uk.ts, zh.ts` (plus `it` supported in `search-console-report-core.ts:60`) currently carry direct translations of the generic titles (`Anmelden`, `Se connecter`, etc.) with same boilerplate descriptions.
- `dashboard/src/locales/index.ts` aggregates these via `extractMessages`; `scripts/prepare-translations.ts` and `flatten-translation-keys.ts` enforce key parity. After EN rewrite, every locale must update the same 6 keys (`seo.login.*`, `seo.signUp.*`, `seo.forgotPassword.*`) so no locale's `hreflang` alternate serves a generic snippet.

## Steps

1. For each locale file, rewrite the 3 titles/descriptions to the native equivalent of the EN intent (brand `Beancount` stays Latin, add native words for `free`, `plain-text accounting`, `Git-backed`/`Fava` where idiomatic — not machine-literal).
2. Run `yarn prepare-translations` and `yarn lint` from `dashboard/`; fix any key drift or formatting.
