## Objective

Add the missing `bea add` recipes to the shared contract and have the behavioral tests execute them, so the skill's commands are tested, not just written.

## Context

- `bea-cli.md` has marked recipes for `open`, `open-staged`, `batch`, `option-expiry`, and `balance`. `skills/scripts/test_beancount_skills.py` executes marked recipes against isolated ledgers.
- A single native transaction already appears as `add transaction --posting` in the options section; give it a general recipe.

## Steps

1. Add `<!-- recipe: -->` blocks for a single `add transaction`, `add close`, `add price`, and `add note`, each with `--file` and `--into`.
2. Add tests: each recipe writes the expected directive to the included destination; a close on an account with a nonzero balance behaves as the skill text says; a price for an undeclared commodity behaves as `bea` documents.

## Files

- `skills/.claude/skills/beancount-init/references/bea-cli.md`, `skills/scripts/test_beancount_skills.py`

## Acceptance criteria

## Out of scope

## Result

New `## One-off entries` section in `beancount-init/references/bea-cli.md` with executable `transaction` (native `--posting` legs, one may omit its amount), `close` (into `open_target`, with the note that `bea add close` writes over a balance), `price` (exact repeat writes nothing; a different same-day quote needs the user's say-so and `--force`), and `note` recipes. `test_beancount_skills.py` now also reads recipes from `beancount-add/SKILL.md` and adds four tests: a one-off transaction lands in the included destination and the add skill's `already-recorded` read finds it within the window but not at another amount or outside it, and `entry-destination` names the included file; `open-accounts` lists unused accounts and drops a closed one; `balance-before-close` reports the remaining balance, `close` writes anyway, a posting on the close date is allowed and a later one is refused without writing; `price` repeat writes nothing, a different same-day quote is refused, and `note` lands in the destination. Breaking each write recipe (dropping `--into` from `transaction` or `note`, hard-coding the `close` account, adding `--force` to `price`) turns a test red. Full suite 107/107 with `bea` 0.3.1.
