## Objective

Rename `chat` to `ask` (matching the dashboard's Ask-AI and the `beancount-ask` skill) and move its AI dependencies out of the default install so a first `bea check` never installs or imports an LLM client.

## Context

- `cli/pyproject.toml` lists `openai>=1.0` and `pydantic-ai>=0.3` as mandatory dependencies.
- `cli/src/cli/main.py` imports `cli.commands.chat` at module import time, which pulls `pydantic_ai` and `openai` into every command, including `--help`.
- `prompt-toolkit` stays in the core dependencies: the REPL uses it, and terminal pickers/confirmations elsewhere will too.
- PRFAQ FAQ 15 sets a warm `--help` p95 under 500 ms that makes no network calls and initializes no AI integration.

## Steps

1. Add `[project.optional-dependencies] ask = ["openai>=1.0", "pydantic-ai>=0.3"]` and drop both from `dependencies`; run `uv lock`; make the dev group include the extra so tests still run.
2. Rename the command to `ask` (`bea ask "question"` one-shot with `--print` semantics preserved, `bea ask` opens the REPL); rename `cli/src/cli/commands/chat.py` → `ask.py` and the `cli/src/cli/chat/` package → `cli/src/cli/ask/`.
3. Import `pydantic_ai`/`openai` only inside the command body; on `ImportError`, exit 2 with: `bea ask needs the ask extra: uv tool install 'beancount-io[ask]'`.
4. Register the command in `main.py` through a thin wrapper so `main.py` no longer imports the ask package at load time.
5. Measure: `python -X importtime -m cli.main --help` shows neither `openai` nor `pydantic_ai`.
