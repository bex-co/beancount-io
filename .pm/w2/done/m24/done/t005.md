## Objective

Define and implement the exit-code table and the error contract once, in the shared output helper, so every command fails the same way and a failed write can never look like success.

## Context

- `cli/src/cli/output.py` prints `Error: …` to stderr and exits 1 for everything; argument parsing exits 2; there is no error category.
- PRFAQ FAQ 3/16: bulk `write transactions --from` appends the successful rows, reports failures, and still exits 0; readers discard loader errors; reports do not print the loader errors they receive.
- Agreed exit codes: 0 success; 1 ledger or validation error; 2 usage error (bad arguments, missing target, missing extra, input needed under `--no-input`); 3 authentication or permission; 4 conflict or unknown write outcome.
- In `--json` mode the error goes to stderr as one JSON object: `{"error": {"category": "validation", "message": "…", "exit_code": 1, "request_id": "…"}}` when a backend request id exists.

## Steps

1. Add an error type per category in `cli/src/cli/errors.py` carrying the exit code; make `output.error()` accept it and render text or JSON per the run context.
2. Map `httpx` 401/403 to category `auth` (exit 3), GraphQL errors with the backend request id preserved.
3. `add transactions --from`: validate every row before appending any; if any row is invalid, write nothing and exit 1 listing the rejected rows; keep a `--partial` flag that appends the valid rows but still exits 1.
4. `list` and `report`: print loader errors to stderr and exit 1 unless `--allow-errors` is passed, in which case print them and still return data.
5. Put the exit-code table in `docs/USAGE.md`.

## Acceptance criteria

- [ ] A JSON file with one invalid row leaves the ledger untouched and exits 1; with `--partial` the valid rows land and the exit code is still 1
- [ ] `bea --json check` on an invalid ledger prints a JSON error object on stderr and nothing on stdout
- [ ] An expired credential on `bea ledger list` exits 3
- [ ] The exit-code table in USAGE.md matches a test that exercises each code
