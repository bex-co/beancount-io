## Objective

Add tests that pin the automation contract this milestone shipped, asserting real behavior and failure modes through Typer's `CliRunner`.

## Context

- Existing tests cover credentials/device flow, writer serialization, output helpers, ask/skills, Fava imports, and forecast logic; none cover the command contract end to end.
- Fixtures: a small valid ledger and an invalid ledger under `cli/tests/fixtures/`.

## Steps

1. Target resolution: flag beats env beats cwd; missing file exits 2 naming the sources.
2. Exit codes: one test per code (0, 1, 2, 3 via a mocked 401, 4 via a mocked timeout on a write).
3. `add transactions --from`: invalid row leaves the file byte-identical and exits 1; `--partial` appends valid rows and exits 1.
4. `--json`: envelope shape, decimal strings, `truncated` flag on `list --limit`; stderr JSON error object with empty stdout on failure.
5. `--no-input`: `ledger delete` without `--yes` exits 2; `--json` implies no prompts (assert no `typer.confirm` call).
6. `ask` without the extra: exit 2 with the install hint (simulate by blocking the import).
