## Objective

Move `skills/docs/*` to `docs/skills/`: the installation, first-query, first-month, migration, and importer-graduation guides, the rehearsal records, and `examples/`. Also move `m21-rehearsal-evidence.md`, which t002 left behind, beside the other rehearsal records. Then fix every link and every command a customer copies, so each guide works exactly as written from the new location.

## Context

- The guides tell customers to copy paths inside the checkout, such as `$SKILLS_SRC/skills/docs/examples/migration/…`, `$SKILLS_SRC/skills/scripts/verify-migration.py`, and `$SKILLS_SRC/skills/.claude/skills/beancount-ask/evals/files/eval1_ledger.beancount` (`first-query.md`). Each becomes `docs/skills/…`, `scripts/skills/…`, or `skills/<name>/…`.
- The sparse checkout must now carry all three directories: `git -C "$SKILLS_SRC" sparse-checkout set skills scripts/skills docs/skills`. Every guide that clones or sparse-checks-out repeats that line, and so do `skills/README.md` and the root `README.md`. t004 adds the upgrade path for older checkouts.
- Absolute links: `skills/beancount-close/SKILL.md` and `skills/beancount-migrate/SKILL.md` send a single-skill registry install to `https://github.com/bex-co/beancount-io/blob/main/skills/docs/installation.md`. `cli/README.md`, which ships to PyPI, links `skills/docs/installation.md` and `skills/docs/first-query.md`. These change here. PyPI shows the new links from the next `bea` release on.
- The verifiers' `FIXTURES` constants and their tests point at `docs/examples/…`.
- `ci-check.py`'s one-install check scans `CUSTOMER_DOCS` only `if CUSTOMER_DOCS.is_dir()`. A stale path therefore skips the guides silently instead of failing. Repoint it to `docs/skills/`, and make a missing directory a failure.

## Steps

1. `git mv skills/docs docs/skills`, then move `scripts/skills/m21-rehearsal-evidence.md` beside the other rehearsal records.
2. Update relative links between the guides, `skills/README.md`, `skills/AGENTS.md`, and the root `README.md`; the absolute GitHub URLs in skill text and `cli/README.md`; and every copyable command path.
3. Repoint the verifiers' fixture paths and `CUSTOMER_DOCS`. Run the three verifier test files and `ci-check.py`. Confirm its output lists `OK one-install guidance` for each guide.
