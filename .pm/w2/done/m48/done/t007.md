## Objective

Add deterministic tests for the recipes this milestone shipped, asserting real behavior and failure modes. The client evals in t004 cover the agent's judgment; these tests cover the numbers it quotes.

## Context

- `scripts/skills/test_beancount_skills.py` executes the `<!-- recipe: … -->` blocks in `beancount-reconcile/SKILL.md`, `references/statement-formats.md`, and `beancount-close/references/close-checklist.md` against isolated synthetic ledgers.

## Steps

1. For `coverage-ledger-side`, assert:
   - The count and signed total for postings inside the window.
   - A posting dated on the statement's last day is included, and one dated the next day is not.
   - Postings in two currencies produce two rows.
   - A posting to another account is excluded.
   - An empty window returns no row, which the skill must report rather than read as zero.
2. If t001 added a statement-arithmetic recipe, assert that it reports a nonzero difference for rows that do not reach the printed ending balance, and that it keeps more than two decimals.
3. Confirm each new test fails with its recipe reverted.
