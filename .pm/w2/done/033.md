# Tell clients which entries are managed prices instead of making them parse the path

w2/m32/t005 hides Edit/Delete on managed price entries in the dashboard journal panel. It recognizes them by regex on the entry's file name (`managedPriceSourceUrl` in `dashboard/src/features/journal/lib/entry-source-location.ts`), which copies how the ledger builds virtual keys (URL resolved against the including file, `//` collapsed by POSIX normalization).

The ledger already holds the exact list, `managedPricePaths`, and its write guard uses it. Have the ledger's entry-context/source-slice read return `managedSource: string | null` from that list, carry it through backend-v2 (GraphQL `getLedgerEntryContext`, REST, MCP entry-context), and let the dashboard read the field. Then drop the regex. Mobile and any other client get the same answer without copying the key rule.

About an hour across ledger, backend-v2 and dashboard. Found by the m32 simplify pass (altitude review).

---

**Resolved 2026-09-23** — The ledger's entry context now returns `managed_source`: the feed URL when the entry's source path is a managed include's virtual key, else null. It comes from `managedPriceSourceFor`, which rebuilds each include's key exactly as the overlay wrote it. The field is described in the IDL, mapped by backend-v2 (`?? null` for an older ledger service), and exposed on the GraphQL `EntryContext`. REST and MCP entry-context pass it through unchanged. The dashboard journal panel reads it, and the path regex (`managedPriceSourceUrl`) and its tests are gone.

Tests:
- ledger `managed-price-read-only.test.ts`: managed, nested-include and repository cases;
- backend-v2 `ledger-journal-service.test.ts`: pass-through and null default;
- dashboard `entry-context-panel.test.tsx`: a URL-looking path without `managed_source` stays editable, and ignoring the field fails the gate case.

All three package gates pass. **Deploy order:** the dashboard query selects `EntryContext.managed_source`, so backend-v2 and the ledger service must be deployed before the dashboard. Shipped in `ledger`, `idl`, `backend-v2` and `dashboard`.
