## Objective

Let every tracked deployment target pass `MCP_REGISTRY_AUTH_PROOF` through to backend-v2, and record the new well-known path where ADR 0009 says every one of them is indexed.

## Context

- `APP_LINKS_APPLE_TEAM_ID` / `APP_LINKS_ANDROID_SHA256` are the model: `deploy/docker/docker-compose.yml`, `deploy/docker-single-psql/docker-compose.yml`, and `deploy/docker-mac/docker-compose.yml` pass them with an empty default, and each target's `.env.example` carries a commented block. `bex.yaml` and `deploy/dev-sandbox` do not carry them.
- ADR 0009 (`docs/adrs/ADR009-backend-v2-well-known-paths.md`) is the index of `/.well-known/*` paths and lists the touchpoints a new path must visit: route, census, rate limiter (automatic here), dev proxy (wildcard, automatic), README.
- `backend-cluster/backend-v2/README.md` has a "Native app links" section describing the optional env-gated well-known routes.
- Which target serves `beancount.io` is not established in this repository (see `w2/blocked/m35/t013.md`); do not guess — t006 establishes it before setting the production value.

## Steps

1. Add `MCP_REGISTRY_AUTH_PROOF: ${MCP_REGISTRY_AUTH_PROOF:-}` beside the app-link lines in the three compose files, with a one-line comment.
2. Add a commented `MCP_REGISTRY_AUTH_PROOF=` block to the three deploy `.env.example` files mirroring the app-links wording: unset → 404, production-only, never on a self-host.
3. Add the path to ADR 0009's table (RFC/contract column: official MCP Registry HTTP domain proof; registered by `well-known-route.ts`; served only when the variable is set) and note the addition in its status line.
4. Add an "MCP Registry domain proof" section after "Native app links" in the backend README: what the record is, where it comes from, why a self-host leaves it unset, and a pointer to `docs/mcp.md` for the listing.

## Files

- `deploy/docker/docker-compose.yml`, `deploy/docker/.env.example`
- `deploy/docker-single-psql/docker-compose.yml`, `deploy/docker-single-psql/.env.example`

## Acceptance criteria

- [x] Each compose file still renders (`docker compose config` with the target's example env) and passes the variable with an empty default.
- [x] ADR 0009's table has the new row and the README section exists; neither contains a key value.

## Out of scope

- Setting the production value (t006); `bex.yaml` and `dev-sandbox`, unless t006 finds the hosted target is one of them.
