# In Persian, a truncated English commit message or payee loses its beginning: "Add 2026-10-30 custom budget …" reads "…stom budget Expenses:Food:Restaurant"

**Minor · dashboard · 20–30 minutes.** A2: a commit's first words (the verb, the date) and a payee's first word are what tell rows apart. The page is right-to-left in Persian, so a one-line `truncate` puts its ellipsis at the inline end, which is the left. An English (left-to-right) string inside that element is then cut at its *start*, not its end. Rows that differ only at the start look identical.

Production https://beancount.io, 2026-11-12, `main-CuYafm8C.js`, signed out, isolated headless Chromium, public `open_ledger/example`. Read only. Local main `0599445ab`.

## Reproduce

The visible part of each truncated string, read from per-character positions:

| Surface (viewport) | Full text | `?lang=en` shows | `?lang=fa` shows |
| --- | --- | --- | --- |
| Commits list (1440×1000) | `Add 2026-10-30 custom budget Expenses:Food:Restaurant` | `Add 2026-10-30 custom budget Expens…` | `…stom budget Expenses:Food:Restaurant` |
| Commits list (1440×1000) | `chore: verify the git control plane over ssh` | `chore: verify the git control plane over s…` | `…ore: verify the git control plane over ssh` |
| Journal payee (390×844) | `Metro Transport Authority` | `Metro Transport Autho…` | `…tro Transport Authority` |

The commit detail page's sidebar list is the same component, so it reads the same way. Messages short enough to fit are unaffected.

## Root cause

- `dashboard/src/features/git/commits/components/commit-list-item.tsx:71–73`: `<p className="truncate …">{commit.message.split("\n")[0]}</p>`. The author name at `:75` is the same.
- `features/journal/components/journal-description/transaction-description.tsx:14`: `<strong className="payee truncate …">{directive.payee}</strong>`.

The text takes the page's direction because nothing gives these elements their own. Only `exact-amount-input.tsx:175` uses `dir="auto"` in the dashboard.

## Fix

Add `dir="auto"` to text the ledger or git supplies and the page truncates: commit message and author, payee, and narration if it is truncated too. A Latin message then truncates at its end in Persian, and a Persian message at its own end in English. Grep the other `truncate` elements that render ledger strings (file names, ledger names, tags) and apply the same.

**Acceptance:** in `fa`, the Commits list shows `Add 2026-10-30 custom budget Expens…` and the 390 px Journal shows `Metro Transport Autho…`, the same leading text as in English. English is unchanged. A render test under `dir="rtl"` checks for `dir="auto"` on the commit message.
