## Objective

After minting a key, the dashboard shows the plaintext and a copy button and nothing else. Show the exact client setup with the new key filled in: the Claude Code command, the JSON block for Cursor and Claude Desktop, and a link to the guide.

## Context

- `dashboard/src/features/user-settings/pages/api-keys/api-key-create-dialog.tsx` renders the success state; the key is only ever visible here.
- Claude Code: `claude mcp add --transport http beancount <issuer>/api-gateway/mcp --header "Authorization: Bearer <key>"`. Cursor/Claude Desktop: the `mcpServers` JSON in the guide.
- The issuer/endpoint must come from the deployment's public configuration (`/.well-known/mcp.json` after t002), not a hard-coded production URL, so self-hosts show their own address.

## Steps

1. Add a tabbed "Use this key" panel (Claude Code / Cursor / Claude Desktop / curl) with copy buttons; fill the endpoint from the public configuration and the key from the mint response.
2. Add the same panel, without the key, to the API-keys page header so returning users can find the setup again.
3. Localize the labels through the existing `userSettings` locale files.
