## Objective

A CLI user who has already run `bea cloud login` should get their MCP client configured without visiting the dashboard: one command prints (or writes) the Claude Code / Cursor / Claude Desktop configuration for the logged-in server.

## Context

- The `bea cloud` namespace is generated from the v1 OpenAPI spec (w1/m12) with curated commands for multi-step flows; this is a curated command.
- The CLI cannot mint a key with a key (server rule), so the command takes an existing key via `--key`/env or reads it from the login session when the session can mint one, and otherwise prints the dashboard URL to mint at.
- The endpoint comes from the server's `/.well-known/mcp.json` (t002).

## Steps

1. Add `bea cloud mcp config [--client claude-code|cursor|claude-desktop|json] [--key …] [--write]` under the curated commands; `--write` edits the client's config file only after showing the diff and confirming, honoring `--no-input`.
2. Never print a key the user did not supply; redact in `--json` output unless `--show-key`.
3. Document it in `cli/docs/USAGE.md` and the MCP guide's quickstart.
