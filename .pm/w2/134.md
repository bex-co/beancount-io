# Create Ledger, Open Account, and the SSH and API key dialogs still close on Escape and throw away what was typed

**Minor · dashboard · 45–60 minutes.** A2: w2/123 made New Entry and Add Budget ask "Discard what you typed?" before Close, Escape, an outside click or Cancel throws a draft away. `dashboard/AGENTS.md` now states that as the rule for every idle dialog holding typed input. Its closing note says Open Account was left out. These form dialogs still close silently:

| Dialog | Entry point | Typed input lost | Pending write |
| --- | --- | --- | --- |
| Create New Ledger | ledger switcher → **Create Ledger** (`common/components/ledger-layout/ledger-switcher.tsx:398–412`); `/ledger` sidebar (`features/ledger-list/pages/dashboard-page/components/dashboard-sidebar.tsx:486–498`) | name, template, description | `DialogContent` has no `busy`, so Escape closes it while `CreateLedger` is still running |
| Open Account | Accounts → **Open Account** (`features/ledger-data/accounts/open-account-dialog.tsx`) | date, account | holds the write (`busy={pending}`) ✓ |
| New SSH key | Settings → SSH keys (`features/user-settings/pages/ssh-keys/key-create-dialog.tsx:116–201`) | title and a pasted public key | no `busy` |
| New API key | Settings → API keys (`features/user-settings/pages/api-keys/api-key-create-dialog.tsx:232`) | the key's name and options | holds the write (`busy={loading}`) ✓ |

Production https://beancount.io, 2026-11-12, after the deploy that shipped w2/123 (`main-CuYafm8C.js`). English, isolated headless Chromium at 1440×1000, signed in as the QA account, on the disposable ledger. A request guard aborted every mutation, and nothing was created: the ledger count is still 6 / 20 and no account was opened. Local main `ed59fa5bb`.

- **New Entry (control):** after typing an amount, Escape opens "Discard what you typed? Your input hasn't been saved." with **Keep editing** / **Discard** ✓.
- **Create Ledger:** typing name `qa-draft-guard` and a description and pressing Escape once closes the dialog with no question.
- **Open Account:** typing `Expenses:QaDraftGuard`: the first Escape closes the account suggestions, and the second closes the dialog with no question.
- **SSH and API keys:** from the code; not opened here, since the account's credentials are out of scope.

## Fix

- Route each dialog's dismissals through `useDiscardDraftGuard` (`common/components/discard-draft-guard.tsx`) with react-hook-form's `formState.isDirty`, read during render, as w2/123 did for Add Budget. A successful write still closes directly.
- Pass `busy` to the Create Ledger (`createLoading`) and SSH key (`createKeyLoading`) `DialogContent`s, so a late completion can't land after the dialog is gone. Better still, start them through `usePendingSubmit` per the AGENTS rule.

**Acceptance:** in each dialog, typed input followed by Escape, Close, an outside click or Cancel asks first; **Keep editing** keeps the values and focus; an untouched dialog closes directly. Escape during Create Ledger's or a new SSH key's pending write does nothing. Tests mirror `discard-draft.test.tsx`.
