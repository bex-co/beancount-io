## Findings

Applied:

- **Page cap bypass (high).** GraphQL `Float` arguments and the owned-ledgers REST query accept numbers past 2^53. There `page++` stops changing the number, and the ledger service reads the exponent form as page 1, so `{ page: 1e12, limit: 1e12 }` looped without bound. The loop now counts reads. A window whose offset is not a safe integer keeps the single call such input always made. Regression tests added.
- The two identical owned-ledger closures became one private `listUserOwnedLedgersCatalog`. The page reader now takes a query object, which also removes a `number | undefined` signature that GraphQL's `null` contradicted.
- Comments:
  - dropped a docblock that was wrong on the window path, and one that repeated `catalogWindow`'s;
  - the normalization comment now says what the ledger service actually does.
- `count: Infinity` replaces an optional count. The cap warning now logs how many ledgers were read and says the result may be truncated.
- Tests:
  - unpaged reads assert call counts instead of exact call arrays;
  - removed a `limit: 100` test over 91 ledgers, which could not notice an ignored limit;
  - the owned-ledger adapter is shared.

Declined:

- Dropping `(w2/m34)` from the page-size comment. Code in this repository cites board ids (`(w3/m9)`, `(w2/m28:t001)`), and this one points at the public record of why the constant exists.
- Bounding GraphQL `ListLedgersArgs` and the owned-ledgers query with `int().min(1).max(100)`. That is an input-contract change on two surfaces and in the OpenAPI snapshot the CLI pins, and the loop is already bounded without it.
- A cheaper pinned `listUserOwnedLedgers` (owner check plus a direct ledger read). It saves at most two calls for a rare caller, at the cost of a second code path.
- Parallel or total-count paging. The ledger service drops Gitea's `X-Total-Count`, and a speculative second page doubles Gitea's work for the common catalog of under 50.
- Reuse. No existing pager fits: `fetchAllByDirectiveType` needs a total that the catalog response does not carry.

Out of scope and filed as [w2/034](../../034.md): create-ledger's tier check, `ledgersUsed` and the activity feed each read one capped page.
