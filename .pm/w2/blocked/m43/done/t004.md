## Objective

## Context

- The guide today: Prerequisites, then 1. Get the skills (sparse checkout), 2. Link them into your agents (`beancount-skills.py install`), 3. Confirm the agents see them, Update, Local edits, Existing copies and name conflicts, Remove.
- The suite must be installed whole, because skills hand off to siblings and share `beancount-init/references/bea-cli.md` (`skills/README.md`, Install).
- `npx skills add https://github.com/bex-co/beancount-io/tree/main/skills` lists only the customer suite (research run, 2026-10-18), and `npx skills update` refreshes installs ([vercel-labs/skills](https://github.com/vercel-labs/skills)). `gh skill install` reads `skills/*/SKILL.md` and skips hidden folders. Hermes installs from a repository path (`hermes skills install owner/repo/path`), and its taps skip folders starting with `.`. Confirm each command against the tool's current `--help` before writing it down.
- `beancount-skills.py install` refuses any name already taken by a copy, and `verify` runs from the checkout. A channel install without a checkout is confirmed through the clients' skill listing and the first-query answer instead.
