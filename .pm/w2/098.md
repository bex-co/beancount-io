# `business@1`'s acceptance scenario expects an account the preset never opens

`backend-cluster/backend-v2/src/features/ledger/setup/catalog.json`: `business@1`'s acceptance scenario records a 1,000 capital contribution and a 500 loan and expects `Liabilities:Loan: 500`. Neither the preset's accounts nor its optional questions (invoices-bills, fixed-assets) open `Liabilities:Loan`. The `business@1-acceptance` entry in `fixtures.json` carries the scenario as data without executing it, and `setup-catalog.test.ts` only checks the expected map is non-empty, so [w3/m53](../w3/done/m53/README.md) closed with the gap in place.

Fix it by opening the loan account (required, or through a funding question) or by changing the scenario, and add a test that executes each acceptance scenario against the preset's accounts. Whether the scenario's unsigned figures (`Liabilities:Loan: 500`, `Equity:Capital: 1000`) mean ledger signs or presentation signs needs settling at the same time. A shipped preset version changes only through a new version, so check whether `business@1` is already listed before correcting it in place.
