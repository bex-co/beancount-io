# Error and warning alert text is below 4.5:1 contrast in dark mode

**Minor (accessibility, dark mode) · dashboard · 15–25 minutes.** A2: every load error, filter error and destructive warning is written in the one style that fails contrast in dark mode.

Production https://beancount.io, 2026-11-10, isolated headless Chromium 156 at 1440×1000, theme **System** with `prefers-color-scheme: dark` emulated, English. Computed colours were read from the live page and converted to sRGB through canvas, with alpha composited onto the alert's own background. Local main `db3cd8cca`.

## Reproduce

1. With the dark theme, open `/ledger/<owner>/<ledger>/journal?filter=%23` (measured on the synthetic ledger; any ledger shows the same error state).
2. Measure the alert description, "Error loading journal entries: The filter expression can't be read…": `oklch(0.65 0.22 25 / 0.9)` on the alert's `bg-card` `oklch(0.198 0.009 145)`.

**Actual:** **4.30:1** for 14px normal-weight text. WCAG 1.4.3 requires 4.5:1. The ledger Settings warning "Deleting a ledger is permanent and cannot be undone…" measures the same 4.30:1.

**Expected:** at least 4.5:1. Controls: the same text at full opacity measures 5.06:1 in dark mode. Light mode passes at 4.94:1 (90%) and 5.23:1 (100%). An automated sweep of 14 ledger routes in both schemes found no other text below its threshold.

## Root cause

`dashboard/src/common/components/ui/alert.tsx:12` (destructive variant): `*:data-[slot=alert-description]:text-destructive/90`. The 10% transparency takes the dark `--destructive` (`style.css:187`, `oklch(0.65 0.22 25)`) from 5.06:1 down to 4.30:1 on `bg-card`. This is unchanged since the dashboard import (`af5339de0`).

## Fix

Use full-opacity `text-destructive` for the description in the destructive variant (5.06:1 dark, 5.23:1 light). Do not lighten the token: that would also change destructive buttons and borders. Add a test that pins the variant's description class so the opacity cannot return unnoticed.

## Blast radius

47 non-test dashboard files render `variant="destructive"` with an `AlertDescription`, including the journal, report, budget, settings and import error states. Every one changes together through the shared variant.

Searched `.pm/**` for `destructive/90`, and for contrast items mentioning dark mode with alerts. w21/702 is mobile Files light mode; w4/1086 is import translation. No existing item.
