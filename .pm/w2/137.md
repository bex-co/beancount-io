# The account page's Units, Change and Balance columns print the raw ledger decimal ("2550.60 USD") under a period table that writes the reader's way ("4.844,07 USD")

**Minor · dashboard · 20–30 minutes.** A2: one page should write an amount one way. [w2/119](./done/119.md) moved the Accounts directory, Statistics, the account page's period table, Journal postings and Entry Context to `<LedgerAmount>`. Since then they use the reader's separators and the ledger's `render_commas` grouping, with every source digit kept. The account page's own journal (the **Units**, **Change** and **Balance** columns of the shared `JournalTable`) was not on that list and still prints the bare decimal string.

Production https://beancount.io, 2026-11-12, `main-CuYafm8C.js` (includes the w2/119 fix), signed out, isolated headless Chromium at 1440×1000, public `open_ledger/example`, `/account/Assets:US:BofA:Checking`. Read only. Local main `bd4d4373e`.

## Reproduce

The first row of each table on the same page:

| `?lang=` | Period table (`<LedgerAmount>`) | Journal: Units · Change · Balance |
| --- | --- | --- |
| `en` | `4,844.07 USD` | `2550.60 USD` · `2550.60 USD` · `2754.06 USD` |
| `de` | `4.844,07 USD` | `2550.60 USD` · `2550.60 USD` · `2754.06 USD` |
| `fa` | `۴٬۸۴۴٫۰۷ USD` | `2550.60 USD` · `2550.60 USD` · `2754.06 USD` |

In German, `.` is the thousands separator, so `2550.60` can read as 255,060. In Persian the digits and separators don't match the table above them.

## Root cause

`dashboard/src/features/journal/components/journal-table.tsx:58–69` (`JournalAmounts`) renders each amount with `formatAmountWithCurrency` (`journal-description/utils.ts:3–8`). That calls `formatAmount` (`common/lib/format/format-amount.ts:12`), which only strips commas. The Units column (`deriveAccountUnits`) goes through the same path.

## Fix

Render these amounts with `<LedgerAmount number={amount} currency={currency} />`, as w2/119 did for Journal postings, keeping the `<Amount>` bidi isolate.

**Acceptance:** on the account page in `en`, `de` and `fa`, Units, Change and Balance are written exactly as the period table writes them (`2,550.60` / `2.550,60` / `۲٬۵۵۰٫۶۰ USD` with `render_commas` on). Every source digit is kept. A render test covers one locale.
