# In Persian, the Overview's share-of-total column writes Persian digits with a Latin %, and two chart tooltips write Latin digits and %

**Trivial · dashboard · 15–20 minutes.** A2: a Persian reader sees one way of writing a percentage, the one the Statistics page already uses (`Intl.NumberFormat(fa, { style: "percent" })` → `۳۴٫۲۲٪`). This is the dashboard counterpart of mobile [w22/042](../w22/042.md). [w2/125](./done/125.md) (`dcf6b014c`) moved counts to the language's digits but did not cover these percentages.

Production https://beancount.io, 2026-11-12, signed out, `?lang=fa`, isolated headless Chromium at 1440×1000, public example ledger `open_ledger/example`. Read only. Local main `48c785130`; the lines below are unchanged at HEAD.

## Reproduce

Overview → the distribution card → **نمایش جدول** (Show table). The "سهم از کل" (share of total) column reads:

| Account | Amount | Share |
| --- | --- | --- |
| Assets:US:Vanguard:VBMPX | ۴۱٬۱۷۹٫۹۳ USD | **۳۴٫۲۲%** |
| Assets:US:Vanguard:RGAGX | ۴۸٬۴۷۱٫۳۹ USD | **۴۰٫۲۷%** |

The digits are Persian, but the sign is the Latin `%`, not `٪` (U+066A).

Two more percentages, from the code (the tooltips weren't captured here):

- Overview distribution pie tooltip: `features/reports/overview/components/distribution-chart/distribution-pie.tsx:47`: `` `… (${percent}%)` `` writes ECharts' raw `percent` in Latin digits, next to an amount `formatNum` writes in Persian digits.
- Balance Sheet tree map tooltip: `features/reports/balance-sheet/hierarchy-tree-map.tsx:178–187`: `toFixed(1)` + `%`, Latin digits.

## Root cause

- `features/reports/overview/components/distribution-chart/distribution-data-table.tsx:70–74`: `formatNum(Number(….toFixed(2)))` followed by a literal `%`.
- The two tooltip formatters above.

## Fix

Format all three with one percent formatter (`Intl.NumberFormat(language, { style: "percent", minimumFractionDigits, maximumFractionDigits })`, as `entries-count-by-type.tsx:83` does), passing the ratio instead of the percentage.

**Acceptance:** in `fa` the table cell reads `۳۴٫۲۲٪` and both tooltips write Persian digits and `٪`. English stays `34.22%`. A unit test covers the formatter for `fa` and `en`.
