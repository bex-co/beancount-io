## Objective

`renameLedgerFile` (MCP, REST `POST …/rename-file`, and GraphQL) currently commits an empty file at `newPath` and deletes `oldPath`, so the file's content is lost. Make rename preserve content, refuse when the ledger still includes the old path, and produce a commit message that says what happened.

## Context

- `ledger-workflow.ts` builds a single Gitea change-files op `{operation: "create", path: newPath, from_path: oldPath}` with no content (~L683). Gitea's contents API needs `update`/`rename` semantics with `from_path`, or an explicit read-then-create+delete in one change set.
- Reproduced 2026-09-08: commit diff showed `2026/09-probe.bean … index 0000000..e69de29` (empty) and the old file with `deletions: 3`; the commit message was "Add 2026/09-probe.bean".
- After the rename, `beancount://{owner}/{name}/errors` reported `failed to read file 2026/probe.bean` because `main.bean` still included the old path.

## Steps

1. Write the regression test first: rename a file with content and assert the new path holds the same bytes and the old path is gone.
2. Change the workflow to a content-preserving rename (Gitea rename/update op with `from_path`, or read the blob and submit create+delete atomically in one `changeFiles` call).
3. Before renaming, scan the ledger's source files for `include` lines that reference `oldPath`; refuse with an actionable message listing them unless the caller passes `updateIncludes: true`, in which case rewrite them in the same commit.
4. Default the commit message to `Rename <oldPath> → <newPath>`; keep the caller's `message` when given.
5. Return `{oldPath, newPath, updatedIncludes: [...]}` so the agent knows what else moved.

## Acceptance criteria

- [ ] Renaming a non-empty file yields identical content at the new path on all three surfaces.
- [ ] A rename whose old path is still `include`d is refused with the including files named, unless `updateIncludes` is set, in which case those lines are rewritten in the same commit.
- [ ] The commit message reads `Rename a → b` by default.
- [ ] The regression test fails against the current code.

## Out of scope

- Directory renames.
- Rewriting `document`/`option` paths other than `include`.
