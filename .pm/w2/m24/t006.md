## Objective

Give every read-side command a documented `--json` shape so agents consume data instead of scraping tables: check, query, list, report, auth status, ledger list.

## Context

- Text tables are the only output today; `read transaction --json` exits 2 (PRFAQ FAQ 3).
- Contract (PRFAQ FAQ 10): data on stdout only; money as decimal strings with a currency field; dates as ISO `YYYY-MM-DD`; an envelope with `bea` version, resolved target (`file` path), and `truncated` plus `limit` for bounded lists.
- `query` returns Beanquery typed rows: emit column names, column types, and rows; `report` emits the same tree/interval structure the text renderer consumes, not a rendering.
- Rename `auth whoami` to `auth status` and include credential source, expiry, and email/username/tier.

## Steps

1. Add a `Envelope` helper in `output.py`: `{"bea": version, "target": {...}, "data": ..., "truncated": bool}`; commands pass plain dicts/lists built from the Pydantic directive models (`model_dump(mode="json")`).
2. Implement `--json` for `check` (errors list), `query`, all `list <type>`, all four `report` commands, `auth status`, and `ledger list`.
3. Disable prompts, spinners, and ANSI whenever `--json` is on (already implied by t004).
4. Document each command's JSON shape in `docs/USAGE.md` with one example per family.
