## Objective

Rename the Python distribution to `beancount-io` and expose exactly one console script, `bea`. The old `beancount-cli` script disappears (the CLI is unreleased; there is nobody to stay compatible with), and `beancount-cli` on PyPI is an unrelated third-party project, so the old name can never be published anyway.

## Context

- `cli/pyproject.toml` declares `name = "beancount-cli"` and `[project.scripts] beancount-cli = "cli.main:app"`.
- `cli/src/cli/main.py` builds `typer.Typer(name="beancount-cli", help="Beancount.io CLI — …")`; the name shows in every `--help` usage line.
- `cli/Makefile` target runs `uv run beancount-cli --help`; `cli/CLAUDE.md` and `cli/README.md` document the same command.
- The device-login request reports `client.name` to the backend (`cli/src/cli/auth/device_flow.py`); that string is shown on the consent screen and must become `bea`.
- Naming decision (TPM discussion 2026-09-06): product "Beancount.io CLI", package `beancount-io`, command `bea`.

## Steps

1. Change `[project] name` to `beancount-io`, `[project.scripts]` to `bea = "cli.main:app"`, and description to "Beancount.io CLI"; run `uv lock` from `cli/` (never hand-edit `uv.lock`).
2. Set the Typer app `name="bea"` and shorten the help to one line naming the product.
3. Report `client.name = "bea"` in the device-login mutation; update `tests/test_device_flow.py` fixtures.
4. Update `Makefile`, `CLAUDE.md`, and `README.md` in `cli/` to invoke `uv run bea`.
5. Run `make check-all`.
