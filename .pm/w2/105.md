# Import preview names fields in English in every language

**Minor · dashboard · 20–30 minutes.** A2: a newcomer importing a bank CSV in their own language sees mixed-language error lines.

Production https://beancount.io, 2026-11-10, isolated headless Chromium 156 at 1440×1000, signed in as the owner of the designated synthetic ledger. Preview only: no import, AI call or write. Local main `78b4cb37f`.

## Reproduce

1. Open `/ledger/<owner>/<ledger>/import?lang=zh`.
2. Choose this CSV:

   ```csv
   Date,Payee,Description,Amount
   2026-09-06,qa-f,blank amount,
   2026-02-30,qa-g,bad date,-1.00
   ```

**Actual:** each invalid row's diagnostic line reads `Amount: 金额为必填项` and `Date: 日期格式无效。预计年-月-日`. The messages are translated, but the field names are English. The same happens in all 14 non-English locales.

**Expected:** `金额：…` / `日期：…`, using the column labels the table header already shows in that language.

## Root cause

`dashboard/src/features/importer/components/steps/preview/editable-preview-row.tsx:~277` renders `<strong className="capitalize">{field}:</strong>`. `field` is the react-hook-form key (`date`, `payee`, `description`, `amount`), and CSS `capitalize` turns it into "Date"/"Amount". This is unchanged since the dashboard import (`af5339de0`). Localized labels already exist for every field (`importer.preview.date`, `.payee`, `.description`, `.amount`; for example `zh.ts:216-230`) and the same row already passes them to `EditableCell` as `label`.

## Fix

Map each field to its `importer.preview.<field>` label and render `t(label)` followed by the locale's separator. Add a localized `"{field}: {message}"` key if languages differ on punctuation (the fullwidth `：` in zh/ja), and drop `capitalize`. Add a regression in `components/steps/preview/__tests__/` that renders an invalid row under a non-English locale and asserts the localized label.

## Blast radius

The only `{field}:` prefix in `features/importer`. Cell-level errors, `aria-label`s and the table header are already localized.

## Dedupe

Searched `.pm/**` for `{field}:`, `capitalize`, `Amount:`, and import preview diagnostics. w3/142 and w4/972 cover diagnostic visibility and row-shape guards, not the label language. No existing item.
