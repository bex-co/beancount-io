# Locale-aware plurals on both clients, then natural count sentences in m27

Filed 2026-09-26 from [m27](./m27/README.md)'s recorded deviation. Neither client can pluralise a count by locale, so the strings are worked around.

- **Web:** the overview reads `Prices not updated since Sep 8, 2017: 6` and `Not in total: 1`.
- **Mobile:** it reads `6 prices not updated since …`, but with only `one` and `other` forms, so Russian, Ukrainian and Slovak are ungrammatical for 2–4.

**Dashboard.** i18next (`react-i18next`) already resolves `key_one`, `key_few`, `key_many` and `key_other` from `{ count }` through `Intl.PluralRules`. Our wrapper blocks it in three places:

- `src/common/hooks/use-translations.ts` types `t(key: keyof typeof en)`, so a base key with only `_one`/`_other` variants fails the type-check, and the dev-mode `i18n.exists(key)` warns. Derive the base keys by stripping plural suffixes, require `count` for them, and check existence with `{ count }`.
- Module catalogs such as `features/reports/overview/dashboard-translations.ts` type every language as the same `Record<Key, string>`. Plural keys need per-language category sets: en one/other, ru and uk one/few/many/other, zh, ja and ko other only.
- The locale parity checks should require exactly `new Intl.PluralRules(lang).resolvedOptions().pluralCategories` for each plural key, and keep strict parity for every other key.

**Mobile.** Register `i18n-js` pluralization per locale from `Intl.PluralRules` (`i18n.pluralization.register`). Give ru, uk and sk their few/many forms, and extend the locale-integrity suite to check the categories each locale needs.

**Then** rewrite m27's count strings as natural sentences on both clients (`{count} prices not updated since {date}`, `{count} not in total`, `{count} at cost (no price)`) in all 15 dashboard and 13 mobile languages.

**Size:** likely over an hour across two packages. Promote to a milestone when it is picked up (dashboard infrastructure, mobile infrastructure, string rewrite, then the closing tasks). **Pillar:** A2, because non-English newcomers read grammatical counts. **Depends on:** m27 closing first, so its strings are final.
