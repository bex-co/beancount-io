# Make the dashboard type-check require `count` for plural translation keys

Follow-up from [m28](./m28/README.md). Plural keys now resolve through `Intl.PluralRules` on both clients. On the dashboard, though, a plural base key called without `{ count }` is caught only by `useTranslations`' dev-mode check (`dashboard/src/common/hooks/use-translations.ts`). The compiler cannot catch it, because the key type comes from `en: Record<string, string>`.

To fix it, give the English resources literal key types, derive the plural base keys (those with a `_other` variant), and overload `t` so those keys require `{ count: number }`. Size is roughly 45–60 minutes, most of it keeping the existing `keyof typeof en` callers compiling. Pillar: A2, catching missing counts before they reach users.
