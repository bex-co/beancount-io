## Objective

Give users an outbound path whose links round-trip into the app: **Share link** and **Copy link** on the ledger drawer for the current ledger and on transaction detail for the entry.

## Context

- Sharing today exists only on the referral screen (`Share.share`); `expo-clipboard` is already a dependency.
- The canonical URL is the selected server's origin plus the dashboard path; build it with the inverse of the resolver's table so the two cannot drift.
- Entry links use the entry hash the detail screen already holds after the w4/m4-era hash changes.

## Steps

1. Add `buildLedgerUrl` beside the resolver and unit-test the round trip `resolveAppLink(buildLedgerUrl(x)) == x`.
2. Add the two actions to the ledger drawer and to transaction detail, using `Share.share` and `expo-clipboard`, with `accessibilityLabel`s and translated strings in all 13 locales.
3. Show a brief confirmation on copy; never block on the share sheet result.
