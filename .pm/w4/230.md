# Keep inline ledger-header actions inside the available width

Severity: **minor**, dashboard. Estimate: **35–50 minutes**. A2 — readers should see and reach header actions without horizontal page scrolling when desktop filters appear beside an expanded sidebar.

Production `https://beancount.io`, 2026-10-09 Pacific time, authenticated QA reader, public synthetic `open_ledger/crypto-example`, English/German, isolated headless Chromium 149.0.7827.55. Source initially checked on **cf2bce76**, then rechecked on **f7460cac**; the header, inline controls, Combobox and Sidebar sources are unchanged across that pull. Exact deployed SHA is unverified.

## Reproduce

1. In a fresh 1024×1000 context with the normal expanded sidebar, open `/ledger/open_ledger/crypto-example/statistics?time=2026&lang=de`. Wait for populated Statistics rows, then another 800ms. No table horizontal scrolling or focus action is required.
2. The page already has **scrollWidth=1050** against a **1024px** viewport, with `scrollX=0`. The header is x=256–1024, width 768, but its own scrollWidth is **794**. Its right-hand action group runs x=296–1049.9375.
3. The 32px account-menu button begins at **x=1017.9375** and ends at **1049.9375**: only about 6px lies inside the viewport. The header crop was visually inspected and confirms its clipped right edge. Measurements remain unchanged after another 700ms.
4. Press the actual Cmd+B sidebar shortcut. With the sidebar collapsed, the document fits at scrollWidth1024 and the header actions fit. Press Cmd+B again: the same 1050px overflow returns while `time=2026` is retained.
5. An independent fresh German1024 context repeats the initial, settled, collapsed and restored measurements. Native Tab from the preceding help-menu trigger reaches the account-menu button; Enter still opens its menu and Escape returns focus. This is a clipped presentation, not failed activation or authentication. Menu/profile contents were neither logged nor captured.

Controls: English at1024 has scrollWidth1024 and its account-menu button ends at1023.359375. German at1100 and1440 fits with the sidebar expanded. All four cases retain their period through sidebar collapse/restore. The Statistics table's own horizontal overflow is separately keyboard-scrollable; it does not explain the header's out-of-viewport button or this initial document overflow.

All fresh contexts were closed. No ledger/account writes, clipboard actions, injected CSS, fabricated data or component callback invocations occurred.

## Cause and bounded repair

`dashboard/src/common/components/ledger-layout/layout-header.tsx` chooses inline filters through viewport-based `hidden lg:block` / `lg:hidden`, without accounting for the expanded sidebar's remaining header width. Its nonwrapping flex action group retains intrinsic width. `ledger-search-controls/index.tsx` supplies inline minimum widths160/180/180px plus Clear all; German's longer action label pushes the complete header past the available width. The current native button and disclosure behavior remains functional.

Make the header choose a fitting presentation based on its available space, or use an appropriate responsive fallback to the existing filter sheet. Keep the sidebar toggle, localized Clear all, all filter fields, help and account actions visible and keyboard-accessible. Preserve active values, period/query semantics, sidebar shortcuts, filter-sheet close/focus behavior, normal wide-screen inline controls and the completed narrow anonymous-header repair. Do not merely hide overflow, globally shrink shared Buttons, or discard controls/values. No API/dependency change is needed.

Acceptance: German1024 with the expanded sidebar has no document-wide overflow and every header action fits; collapsing and restoring the sidebar retains that property and the active period. Repeat English1024, German1100/1440, narrow filter-sheet behavior and the existing anonymous320px controls. Add a real layout regression at the inline-filter breakpoint with translated labels and the actual sidebar width; presence-only component assertions miss this failure. Run dashboard gates when implementing.
