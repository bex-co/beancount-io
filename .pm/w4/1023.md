## Cause and repair

`dashboard/src/features/importer/components/steps/preview/editable-preview-row.tsx:165–175` omits `multiline` from Payee's `EditableCell`; the Description binding passes it. `editable-cell.tsx` therefore chooses its existing single-line Input branch. The browser strips line breaks from that input's DOM value. On actual typing, `handleChange:147–150` replaces the retained `localValue` with this flattened value, which commit/row rebuilding propagates. Unchanged Enter and Escape keep the original state, explaining why those controls pass.

Enable the existing multiline editor for Payee. Preserve the shared newline-insertion hint, Enter commit, blur commit, Escape cancellation, composition-key guard and focus restoration; Date and Amount stay single-line. Cover the actual Payee binding with a meaningful typed-edit regression, including embedded quoted CSV text, appended content through commit and Configure, and cancellation.
