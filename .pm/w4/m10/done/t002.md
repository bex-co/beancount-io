## Objective

Give contributors a pull request template that restates the three rules every PR is judged by: one package per change, the package's own checks green, and no secrets.

## Context

- `CONTRIBUTING.md` "Pull requests" section already states Conventional Commits, one-package scope, and lockfile rules; the template should reference, not duplicate, and add a checklist.
- Root `README.md` "Quality bar" has the per-package check commands; link it.
- `.github/workflows/secret-scan.yml` gates every push; mention the local `gitleaks` command.

## Steps

1. Create `.github/pull_request_template.md` with: summary, package(s) touched, checks run (checkbox per package with the command), screenshots for UI changes, and the secret-scan checkbox.
2. Keep it short enough that contributors fill it rather than delete it.
