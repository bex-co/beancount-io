## Objective

Give report grouping the same page-scoped lifetime as the validated chart-view preference, without adding a global preference store.

## Context

See [FINDINGS.md](./FINDINGS.md) for the natural production reproductions, source matches and prior-work boundaries.

## Steps

1. Reuse existing enum/search and replace-navigation conventions for the five ChartInterval values. Keep the route output optional, Monthly as the absent/typo fallback, and default URLs clean.
2. Preserve view/mode/offset and shared time/account/filter fields when changing only interval. Keep route/ledger isolation and explicit shared-link/reload behavior.
3. Expose one reusable selection contract to the four report owners and SSR loader dependencies; do not create separate client and server normalization rules.

## Files

- dashboard/src/common/lib/navigation/
- dashboard/src/common/hooks/
- dashboard/src/common/types/chart.ts
- The four report search schemas and route loaderDeps contracts

## Acceptance criteria

- [ ] An explicit Weekly selection survives a shared-scope search patch and a fresh parse of that URL.
- [ ] Default Monthly and a mistyped value fall back without an error or requiring every existing Link to name an interval.
- [ ] No dependency, API, cookie or localStorage preference is added.

## Out of scope

New interval types, report arithmetic/API changes, global preferences and unrelated dashboard repairs.
