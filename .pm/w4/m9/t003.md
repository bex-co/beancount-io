## Objective

Remove the setup cliff behind t002: a user who does not know bean-price's metadata grammar runs `bea price sources` and sees every commodity in the ledger, whether it has a declared source, and the exact `commodity` directive lines to add for the ones that do not.

## Context

- Commodities come from `commodity` directives and from the currencies used in postings; use the loaded ledger rather than parsing text.
- bean-price's source names and ticker shapes differ per source (`coinbase/BTC-USD`, `yahoo/EURUSD=X`); print the grammar and the example shape, never a guessed ticker for a specific commodity.
- Output must follow the `--json` contract so an agent can act on it: one row per commodity with `declared_source` (string or null) and `suggestion` (the directive text).

## Steps

1. Add `sources` to `price_app` in `cli/src/cli/commands/price.py`.
2. Collect commodities, join with any `price:` metadata, and mark the operating currency as `base` so it is not flagged as missing a source.
3. Render a table (commodity, source, last price date if any) and, below it, the ready-to-paste `commodity` directives for the unsourced ones, with a one-line pointer to bean-price's source list.
4. Regenerate `REFERENCE.md`.

## Files

- `cli/src/cli/commands/price.py`
- `cli/docs/REFERENCE.md` (generated)

## Acceptance criteria

- [ ] On the sample ledger, the output lists every commodity once and flags the unsourced ones with a pasteable directive.
- [ ] `--json` rows carry `commodity`, `declared_source`, `last_price_date`, `suggestion`.
- [ ] The verb works without the extra (it reads the ledger only) or exits `2` with the hint if the team decides it should require it; the decision is stated in USAGE.
