## Cause and bounded repair

`dashboard/src/features/ledger-data/events/event-type-label.ts:18–24` returns ordinary-looking authored strings unchanged before reaching its quote/backslash escaping at:26–38. A literal authored string containing quotes around `All Types` therefore bypasses escaping and reads exactly like the generated quoted label for unquoted `All Types`. The same bypass admits the synthetic empty-label and whitespace-escape spellings above. The menu items and selected trigger in `events/index.tsx` correctly share this helper and preserve exact values; they inherit the same ambiguous display.

Make the helper's escaped presentation distinguishable from authored strings containing its quote/backslash notation. Keep ordinary readable names, localized global/empty labels, whitespace/control/format-character spelling, exact keys/filtering, focus restoration and global reset. No event normalization, generic menu redesign, dependency, API or serializer change is needed. Do not fix one literal spelling with another finite special-case list.

Acceptance: the real Events page presents distinct visible and native accessible names for all three supplied pairs; selecting either member identifies that member on the focused trigger and filters to its exact record. Preserve empty, one/two spaces, tab, reserved-label, ordinary/global controls and live localization. Cover the helper and real menu/trigger callers, repeat native checks at both widths, and run dashboard gates on implementation. Report only; no product fix or formal regression test.
