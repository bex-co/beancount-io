The shared Monaco wrapper intentionally waits for actual runtime/style readiness (`common/components/monaco-editor/index.tsx`), while query execution/results can settle earlier. That caller-owned focus action explains the later focus transfer; the shared readiness gate remains necessary.

Only this bookmarked-query/result route is independently reproduced; other controls, navigation/unmount during initialization and other Monaco consumers remain compatibility scope.

Acceptance: native Tab to the ready result before delayed editor readiness remains on that same result after release, and the next End reaches its final row at both widths.
