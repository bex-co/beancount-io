**Severity:** minor misleading copy. **Estimate:** 25–40 minutes, dashboard. **A2:** the selected amount-filter label should describe the rows a reader is reviewing.

## Cause and bounded repair

`dashboard/src/features/importer/components/steps/configure/account-mapping-table.tsx:154–157` matches the internal positive group with **txn.amount >= 0**, while the negative group uses <0. `features/importer/locales/en.ts:413–416` names the former **Positive only** and describes it as positive amounts. Zero satisfies the implemented predicate but not that wording.

Keep the existing nonnegative grouping and rename its visible option/selected value to plain wording such as **Zero or positive**, with equivalent supported-language messages and accurate translator metadata. The internal positive enum and existing translation key can stay. Do not silently change the numeric predicate, reject zero rows, alter selection or row validation, or change import posting semantics to make the old label true. Preserve All amounts, Negative only, search composition, disabled/pending states, [319](./done/319.md)'s stable Filter by amount identity/table naming, and [322](./done/322.md)'s separate required-field feedback repair.

Acceptance: the zero-only and mixed files retain the observed3/4 nonnegative rows and0/1 negative rows, but both the closed selector and open option accurately name the zero-inclusive group. Check the longer label at390/1440 and update all fifteen catalogs through the normal translation checks. Keep the working Preview/Configure/Back/reset and hidden-selection controls. Run dashboard gates when implementing; no assertion-only test is needed just to repeat the chosen copy. No dependency, backend or API change is required.
