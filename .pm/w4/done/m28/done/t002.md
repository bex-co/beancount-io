## Objective

Register a pluralizer per shipped locale that picks the key from `Intl.PluralRules`, and extend the locale-integrity suite to require each plural key's categories per locale.

## Acceptance criteria

- [ ] Meets the parts of the [definition of done](../README.md#definition-of-done) this task covers.

## Result

- **Pluralizer:** `mobile/src/common/plural.ts` picks the category through `Intl.PluralRules`, falling back to the English rule when the runtime lacks the locale. `src/translations/index.ts` registers it with i18n-js for all 13 locales.
- **Catalog typing:** a `Translations` type (`src/common/translation-types.ts`) lets each locale carry its own plural categories.
- **Checks:** `src/translations/__tests__/plural.test.ts` requires exactly each locale's categories, with the same failure cases as the dashboard check.
- **Keys rewritten:** all seven plural keys were rewritten per language, including the merchants, ledger-editor and budget counts. Russian and Ukrainian error counts now read as sentences.
- **Not observed:** `Intl.PluralRules` on Hermes was not observed on a device; the English-rule fallback covers its absence.
