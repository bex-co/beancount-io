# Keep localized public-ledger header actions inside narrow viewports

Severity: minor. Estimate: 40m, dashboard. A2: newcomers should be able to read and use sign-in and filter actions on narrow public-ledger pages.

Environment: production https://beancount.io, anonymous synthetic open_ledger/example, isolated headless Chromium 149.0.7827.55, German/light, 320×740. Local main 26d54a9db7d33c31a549bd12a0454a1c01f3f038; deployed main-BIr0jJni.js, exact deployed commit unverified.

Repro: load `/ledger/open_ledger/example/journal?lang=de` at 320px, wait for Results 1–60 / 1044, and inspect the header. Repeat with a fresh reload. Sign-in “Anmelden / Registrieren” is clipped at the right edge: its rectangle runs x131.56–341.53 while the header/viewport end at320; document scrollWidth342. Sidebar occupies x12–40 and Filters x40–123.56. Expected: all three actions fit and remain readable/operable without horizontal page scrolling. Actual: the final sign-in text and right button border are outside the screen. This is a presentation failure, not failed authentication.

Controls: German at390px has scrollWidth390 and sign-in right374; English at320px has scrollWidth320 and sign-in right304. The German Filters button at320 still opens the report-filter sheet and Escape dismisses it. API Journal data loads normally; no data or auth mutation was performed.

Root: `dashboard/src/common/components/ledger-layout/layout-header.tsx:88–93,101–122,142–150` places Sidebar and the Filters/sign-in group in one fixed-height nonwrapping flex row with horizontal padding. Shared `ui/button.tsx:8` applies whitespace-nowrap and shrink-0. The combined German intrinsic widths exceed the remaining header space. Fix the header's constrained-width action presentation, retaining localized accessible names, visible focus and all actions; use a compact accessible action or suitable reflow with matching header height. Do not globally weaken Button sizing or simply hide overflow. No dependency/API change needed.

Blast radius: sole production LayoutHeader caller is ledger-layout/index.tsx:102. Its filter route policy covers Overview, Journal, Income Statement, Balance Sheet, Trial Balance, Account, Events, Statistics and Cash Flow. Only German Journal was reproduced here; authenticated menus and other locales/routes are unverified. Preserve desktop inline filters and unrelated routes. The observed failure occurs settled and does not depend on a network error or empty ledger.

Dedupe/history: all-board searches for header overflow/clipping, narrow sign-in and 320px localized headers found no matching issue. Completed w3/m20 introduced the narrow filter trigger in e0e5cc8b and required 390/768px usability; those controls still work. This extends responsive coverage to320px with longer translated anonymous actions. Existing header tests assert control presence, not browser geometry. Current source retains the implicated layout, so no known later fix/deployment lag. Native header issues and CLI table-header truncation are separate implementations.

Acceptance: German at320px and390px and English at320px keep all header actions within the viewport; keyboard activation and filter close/focus return still work; desktop controls remain usable. Verify browser geometry with the real German catalog and run normal dashboard gates for the eventual fix. Actual screen-reader speech, authenticated actions and patched behavior remain unverified.

**Resolved 2026-09-19** — below a new `xs` breakpoint (22rem, smaller than
Tailwind's smallest default) the filters and sign-in actions show their icon
alone. Nothing is hidden from assistive technology: the filters button already
carried an `aria-label`, and the sign-in link gains one with the same localized
phrase its text used to supply. The threshold is 352px so 390px is entirely
unchanged, and neither Button sizing nor overflow clipping was touched — both
were ruled out by this note. Verified live: at 320px in German, French and
Russian all three actions fit with document `scrollWidth` equal to the viewport
(it was 342 against 320 before), at 390px every language still renders its
labels, and each action keeps its full localized accessible name — 16/16 across
four languages and both widths. Shipped in `4010db77` (`dashboard`).
