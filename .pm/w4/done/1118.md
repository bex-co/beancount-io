# Keep private ledger names out of GA4 page titles

**Major (private-identifier confidentiality) · dashboard · ~45m · A2/A3.** Found 2026-10-31 while re-verifying [265](./265.md) after its closeout; that closeout checked full ledger paths, not the bare ledger name in the page title.

Production https://beancount.io, fresh QA-owner context at 390×844, the account's own private synthetic ledger, every analytics collector request blocked locally before transmission. Opening Files on that ledger sets `document.title` to `Files - <ledger name>`, and the generated collector requests carry that title in `dt` on every event (page_view, route_view, scroll, bql_query_executed). Page locations (`dl`) were correctly origin-only or route patterns; only the title leaks the identifier. Retained evidence shows the field and the title shape with the name redacted.

**Cause:** `dashboard/src/common/analytics/analytics-provider.tsx:31` passes `page_title: document.title` to `trackPageView`, and the Google tag also reports the document title as `dt` by default on every event. `track.ts` documents that ledger names must never reach GA4 through the raw URL, and §4 of `dashboard/docs/event-taxonomy.md` treats ledger names as PII, but the title channel is not covered.

**Fix:** send a non-identifying title for analytics — for example the route pattern or a static per-route label — through both the explicit `page_view` and the tag-level `page_title` setting, so `dt` no longer reflects `document.title` on ledger/user routes. Keep the visible browser tab title unchanged. Update the taxonomy's page_view params and privacy notes.

**Acceptance:** with collector requests blocked locally, owner private-ledger and guest public-ledger navigation (Overview, Query, Files tree → blob) emit no ledger or owner name in `dt` or any other field; the tab title still shows the ledger name; tests assert the title sent to gtag on a ledger route. Run dashboard gates.

**Dedupe:** searched all `.pm` states for page_title, page title and `dt`; w0/053 and 265 covered locations, referrers and search terms, not titles.
