**Resolved 2026-10-23** — When the current search fails, Gallery (`ledger-list/pages/gallery-page/index.tsx`) shows its alert with a Try Again in place of the listbox, so the action is never a listbox child. Try Again re-runs the same search through the lazy query's `refetch` and `useQueryRetry`: same `q` and `limit` 50, with no clearing, retyping or reload. The error and a busy Try Again stay mounted, so a second press sends nothing, and another failure returns focus to Try Again.

The failure is shown only while its search is still the live one. Clear, Escape or a new query during a retry never bring the old error back, reopen the popup or move focus (212 intact). A retry that lands for the still-open search hands focus to the field, so Arrow Down and Enter pick a real result. Raw input and URL, the 300 ms debounce, the two-character minimum, result-ownership guards, option IDs and active descendant, announcements, IME handling and 976's Arrow Down reopening are unchanged. No new strings.
