## Outcome

code: 18/18 at 1440 and 390.

- 12/12 public continuations — Star from a ledger carrying a query and a
  fragment, Follow from a profile carrying a fragment only, plus the plain-path
  and query-only controls — each emitted target coming back exactly as entered
  with one `#`, and each one replayed to confirm it loads the intended page
  rather than the "Error loading data / invalid information" the malformed
  target produced.
- 6/6 guard checks — an in-app navigation to a guarded route keeps its
  fragment; a fresh full page load keeps path and query only, because the
  browser never transmits a fragment; a plain guarded path is unchanged.

Definition of done, clause by clause:

- Star, Follow and both eligible guarded producers serialize the available
  path, query and fragment correctly, including query-plus-fragment and
  fragment-only destinations;
- the reported corruption is gone: `?time=2016#overview` no longer arrives as
  `?time=2016overview`, and `/ledger/open_ledger#collection` no longer arrives
  as `/ledger/open_ledgercollection`;
- unsafe-continuation rejection, plain-path behaviour and the server fragment
  limitation are intact, each with a test of its own;
- `yarn format:check`, `yarn lint`, `yarn test` (378 files, 4264 passed, 1
  pre-existing skip) and `yarn build` pass, and public browser replay confirms
  the emitted targets.

**Not claimed:** authenticated completion. The DoD requires an authorized QA
session before claiming end-to-end coverage, and this run had none. What is
verified is that the correct continuation is emitted and that the emitted URL
loads when replayed — the same boundary FINDINGS drew. Signing in and landing
back on the fragment is untested here, and nothing in this milestone's record
asserts otherwise.

Other limits: the ledger UNAUTHENTICATED guard fires only for a ledger that
exists but is unreadable by the caller, which an anonymous session cannot reach
on the public instance, so it rests on source and shared-helper coverage; a
fresh page load cannot carry a fragment at all, so the guard's full-load
behaviour is path-plus-query by nature; and the narrow width is an emulated
viewport.
