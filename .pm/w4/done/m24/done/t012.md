## Objective

Repair the six half-translated Ukrainian messages in the two catalogs that the
milestone's original survey never reached, because they do not sit at a path
ending in `locales/uk.ts`.

## Context

- Found while building the all-locale guard for t010, which enumerates catalogs
  through the compiled `@/i18n/locales` barrel rather than a file glob, and so
  saw keys the file survey had not.
- The milestone was planned from `rglob("locales/uk.ts")`. Two of the 47
  Ukrainian catalog files live one directory deeper —
  `src/i18n/locales/common/uk.ts` and `src/i18n/locales/seo/uk.ts` — so the
  pattern matched neither. These hold the shared `common.*`, `component.*` and
  `seo.*` keys, which appear on every screen.
- The damage, against `en.ts`:
  - `common.balanceSheet` — `Баланс Sheet`
  - `component.intervalSelect.daily` — `Вaily`
  - `component.errorState.title` — `Помилка loading data`
  - `component.accountCombobox.placeholder` — `Пошук accounts...`
  - `component.combobox.placeholder` — `Тип to search...`
  - `seo.welcome.description` — `Ласкаво Просимо to Beancount! Get started with plain-text accounting and financial management.`
- `component.errorState.title` and the two combobox placeholders are reachable
  anonymously, so unlike t003's surfaces these can be checked on screen.

## Steps

1. Translate the six, using `bg.ts` for phrasing and keeping `Beancount` as the brand name.
2. Re-run the scan over all 47 Ukrainian catalog files, enumerated with `find src -name uk.ts` rather than the glob that missed these.
3. Check the account combobox and an error state on screen at `?lang=uk`.
4. Run `yarn format:check`, `yarn lint`, `yarn test`, `yarn build` from `dashboard/`.

## Files

- `dashboard/src/i18n/locales/common/uk.ts`
- `dashboard/src/i18n/locales/seo/uk.ts`

## Acceptance criteria

- [ ] None of the six carries a stray English word.
- [ ] All 47 Ukrainian catalog files scan clean, not just the 45 the original glob matched.
- [ ] The account combobox placeholder reads Ukrainian on screen.
- [ ] Key counts and `{placeholder}` interpolations are unchanged; English and the other thirteen locales are untouched.
