The API already supplies the required inputs and outcomes. Coordinate [1084](./1084.md)'s separate pending-date snapshot and [1083](./1083.md)'s initial preview-read retry.

Acceptance: real Accounts and both dialogs hold A, attempt each dismissal, and settle failure/success without changing a later B confirmation.
