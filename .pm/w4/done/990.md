# Keep newer filter drafts when earlier changes finish

**Severity:** minor. **Estimate:** 45–60 minutes. **Owner:** dashboard. **A2:** a reader correcting a period or account while its prior selection loads should retain the new text until deliberately applying it.

## Cause and bounded repair

`dashboard/src/common/components/ui/combobox.tsx:187–189` copies every changed value prop into inputValue, including completion of this control's own earlier choice. `handleInputChange` at:110–122 has already stored the newer text; the committedRef marker only prevents duplicate blur submission and is cleared on editing. It supplies no protection against this later prop copy.

`common/components/ledger-search-controls/index.tsx:68–76` passes the resolved selected router value to Combobox. The Time adapter at:189–198 uses `triggerOn="blur"`, so the newer September draft is intentionally independent of the older applied August value. Root route beforeLoad awaits its ordinary profile read before that earlier navigation finishes. The shared Combobox effect then mistakes that completion for a fresh external replacement.

Retain the newer uncommitted draft when a previous local selection finishes. Track submission/draft ownership at the appropriate shared primitive or filter adapter boundary, while retaining deliberate external value changes, Clear all, Back/Forward and reload restoration. Keep ordinary Enter/blur application, Escape draft preservation, option selection, composition handling and focus behavior. The applied URL and result should continue to describe August until the reader explicitly commits September. Include meaningful delayed-parent-update and explicit-reset regressions; a blanket refusal to synchronize props would break the working reset behavior. No API, dependency or backend change is needed.

Acceptance: using the real filter control/router, commit August, type complete September while the previous navigation read is held, then release it; September remains exact, focused and uncommitted. Its next explicit commit sends September once. Test normal settled commits, external restoration/reset, failed navigation, Escape, blur and change-mode consumers, then repeat both widths and run dashboard gates when implementing.
