# Offer Try Again on the remaining QueryView read failures

**Severity:** minor, follow-up to [m50](./m50/README.md). **Estimate:** 45–60 minutes, dashboard. **A2:** any failed read should be recoverable where its error appears, without a reload.

After m50, `QueryView` runs its own in-place retry whenever a caller passes `onRetry={refetch}`. While that retry is pending the error stays, with a busy Try Again, and focus returns to Try Again if the retry fails. Commodities and Budget pass `onRetry`. Five callers still show a read error with no Try Again:
- `dashboard/src/features/ledger-data/settings/index.tsx`
- `dashboard/src/features/ledger-data/accounts/index.tsx`
- `dashboard/src/features/ledger-data/errors/index.tsx`
- `dashboard/src/features/ledger-data/documents/index.tsx`
- `dashboard/src/features/ledger-data/events/index.tsx`

The m50 simplify review found these by reading the code. Subsequent live QA below reproduces Accounts, Documents, Events and Errors at both widths. Settings remains unverified in a browser.

Three older screens hand-roll the same retry without the single-flight guard or focus handback. Each could switch to `useQueryRetry` (`common/hooks/use-query-retry.ts`):
- General Settings' w4/257 retry (`features/user-settings/pages/general/index.tsx`);
- Billing's w4/312 AI usage retry (`subscription-section.tsx`, whose focus handback in `subscription-usage-overview.tsx` would then come from the shared hook);
- the reset-password token check (`features/auth/pages/reset-password-page/index.tsx`).

Budget's `useBudgetEntries` retry returns nothing. If it returned its first-page `refetch()`, its error would stay busy instead of flashing to the skeleton.

Acceptance:
- Each of the five pages offers a keyboard Try Again that re-reads only its own query, keeping its filters.
- The migrated screens keep their current behavior, plus the busy state and focus handback.
- Real-Apollo regressions cover a failed read, a rejected retry and a successful retry.
- Verify natively at both widths.
- Dashboard format:check, lint, test and build pass.

Source: the w4/m50 `/simplify` reuse and altitude reviews (see [m50 t004](./m50/done/t004.md)).
