## Cause and bounded repair

`dashboard/src/features/ledger-data/commodities/format-commodity-price.ts:15–30` derives a precision from the series but caps it at six decimal places in both the constant and varying branches. `formatCommodityAxisTick` at:37 always calls `toFixed` with that cap. For the1e−9–3e−9 series, every displayed tick therefore rounds to zero. `build-commodity-chart-labels.ts:36–37` wires that formatter directly into CommodityChart's actual y-axis. Its fixed-decimal tooltip control above passes. In the same file, `formatCommodityPriceLabel` at:7–8 tests only whether the raw string contains a dot and then removes every trailing zero with `/0+$/`. For `2.5e-10`, that deletes the exponent’s final zero and returns `2.5e-1`; the no-dot `5e-10` bypasses the trimming branch. The actual chart-label wiring calls this helper, so the native tooltip exhibits the changed value.

Use an appropriate significant-digit/scientific fallback when fixed precision cannot distinguish tiny nonzero ticks. Normalize harmless mantissa trailing zeros without changing an exponent or the quote’s numeric value. Keep source text/value rather than round-tripping through Number, and retain readable ordinary quotes and genuine zero. Keep the fix within commodity axis formatting and its chart wiring. Preserve source tooltip/history strings, numeric plotting, dates, existing confinement, narrow bounds and the ordinary BTC/CUSDC behavior. Do not round the price data, invent nonzero values, add dependencies or import this feature into common chart utilities.

Acceptance: the real commodity chart for the supplied three points has distinct nonzero y-axis labels at desktop/narrow widths; its exact fixed-decimal tooltip/history remain unchanged. Scientific-notation tooltips must retain the values of `1.25e-10` and `2.5e-10`, with `5e-10` still correct. Cover very small varying and constant series, exponents ending in zero, true zero and ordinary prices through the actual chart formatter wiring, then run dashboard gates when implementing. No product change or formal regression test was authored in QA.
