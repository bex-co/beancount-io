Preserve each valid source decimal through the amount model and the Net Worth headline/monthly table, applying only the intended currency/display rounding. Keep approximate numbers available to existing chart consumers without using them as the source for financial text. Use the existing decimal/string helpers and compatible shared formatter support; coordinate with W4/1001 and add no dependency.

## Verification

**Exact text.**
- `formatNumber`, `formatQuantity` and `useFormatNumber` accept a decimal string as well as a number. `Intl.NumberFormat` formats the string digit for digit (ECMA-402 2023), under the same ISO minor units, grouping, locale and no-`-0.00` rules. An ungrouped string keeps the `.` separator, as the number path does.
- Overview's `CurrencyAmount` carries the ledger's decimal (`exact`, from `parseDecimalNumber`, inverted exactly) beside its numeric `value`, which stays for sorting and chart coordinates.
- `FormattedAmounts` formats `exact` when present, so the Net Worth headline and table, account balances and money movement totals show the recorded amount.
- Number formatting output is unchanged. Malformed values are still skipped.

**Regressions:**
- `format-number.test.ts` has exact-string cases: 2^53+1 grouped, ungrouped and de-locale; commodity source digits; ordinary parity; no negative zero.
- `overview-utils.test.ts` expects the decimal on its amounts.
