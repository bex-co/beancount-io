## Objective

Add `plan-play` and `apply-play` steps beside the App Store release script so the listing is reviewed as a diff and applied deliberately, and document the choreography so `/mobile-release` can follow it.

## Context

- `mobile/scripts/app-store-release.sh` has the plan → approve → apply shape; mirror it for Play through the Developer API edit lifecycle (insert edit, update listings and images, validate, commit).
- `docs/app-store-localization.md` describes the Apple flow; add the Play section there.
- The `mobile-release` skill must reference the new steps so a release does not leave Play half-updated.

## Steps

1. Implement the two steps with a dry-run default that prints per-locale diffs and never prints credentials.
2. Apply against Play with the user's confirmation; verify the localized listing renders in the console for a sampled locale.
3. Update the localization doc and the `mobile-release` skill.

## Files

- mobile/scripts/app-store-release.sh (or a sibling `play-release.sh`)
