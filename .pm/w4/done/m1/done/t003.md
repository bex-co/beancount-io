## Objective

Render the shared statement model as a clean financial statement that users can print or save as PDF from the browser without exporting dashboard charts or navigation.

## Context

- The deliverable is accurately labeled `Print / Save as PDF`; direct PDF generation is not promised.
- A Balance Sheet is an as-of view and a Profit & Loss covers the active time filter; when only the raw filter is available, display it faithfully rather than inventing resolved dates.
- The export is an unaudited management report and must not claim GAAP, IFRS, audit, or tax compliance.
- Semantic headings and table headers are required for assistive technology and readable print output.

## Steps

1. Build a renderer for ledger name, statement title, report context, hierarchical rows, currencies, section totals, and generation time.
2. Add print styles that hide application chrome and charts, repeat table headings where supported, avoid splitting short row groups, and handle long account names.
3. Support Letter and A4, light output regardless of dashboard theme, and sensible behavior for multiple currencies and empty sections.
4. Trigger the browser print flow from an isolated printable surface without introducing a PDF library.

## Acceptance criteria

- [x] Print output contains no dashboard navigation, interactive controls, or charts.
- [x] Ledger, statement kind, active time/account/advanced filters, conversion, currency labels, hierarchy, totals, and generation time are visible.
- [x] The document uses semantic headings and associated row/column headers.
- [x] Long account names, multiple currencies, empty sections, Letter, and A4 do not clip critical values.

## Out of scope

- Direct binary PDF generation, branding, signatures, audit opinions, published snapshots, email, or mobile share sheets.

## Completion

- Added a semantic portal-rendered statement with ledger/title headings, active report context, generation time, section tables, scoped headers, hierarchy indentation, currencies, and exact totals.
- Print CSS isolates the body-level statement portal from all dashboard chrome and charts, forces light output, repeats table headers, avoids row splitting, wraps long labels, and uses the browser's selected Letter/A4 paper size.
- The action uses same-window `window.print()` and the exact label **Print / Save as PDF**; it does not claim to generate a PDF binary or certified financial statement.
- Component tests cover semantic headings and tables, long labels, multiple currencies, active context, and empty sections.
