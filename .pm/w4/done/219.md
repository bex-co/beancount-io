# Name the Income Statement chart-mode selector

**Minor · 20–35m · dashboard · A2.** Accessibility users should be able to identify the chart-mode setting independently of its selected value.

Production October9,2026, authenticated QA reader of public Example, fresh headless Chromium149 at1440×1000 and390×844, English. Research7f019d98; pulled1f641d1c adds only unrelated board work. Exact deployed revision unverified.

2. Inspect native Chromium accessibility nodes: the chart-mode combobox has name="" and value="Stacked Bars". Neighboring controls have name="Select time period"/value="Monthly" and name="Select conversion"/value="At Cost".
