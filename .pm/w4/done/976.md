# Reopen Gallery's available results with Arrow Down after Escape

**Severity:** minor. **Estimate:** 35–45 minutes. **Owner:** dashboard. **A2:** a keyboard user should be able to return to the available ledger results without editing the query or blurring/refocusing the search field.

## Reproduction and controls

Production `https://beancount.io`,2026-10-22; owned isolated headless Chromium155.0.8059.85, authenticated QA using read-only public ledger search, English/light/UTC. Fresh390×844 and1440×1000 contexts independently reproduce the failure. No mocked search response or mutation is used.

1. Open `/ledger-gallery`, type **shopify** and wait for the actual `shopify / open_ledger/shopify` result. Ordinary ArrowDown selects `ledger-search-option-0` while the input retains DOM focus.
2. Press Escape: the list closes, the query/focus remain and the active descendant clears, correctly preserving the repaired dismissal contract.
3. Press ArrowDown again. At both widths, `aria-expanded` stays false, there are zero option nodes, no active descendant and the input remains focused. Enter still leaves the Gallery URL/query unchanged.
4. Native Tab followed by Shift+Tab refocuses the same input: the unchanged query immediately reopens that same real Shopify result. ArrowDown then selects it normally. The result was available; the closed-list keyboard branch could not expose it.

The retained narrow event observer records trusted, non-composing ArrowDown/Escape/ArrowDown/Enter. A separate fresh390 positive control waits for completed ArrowDown/Enter navigation: URL `/ledger/open_ledger/shopify`, title **Shopify Inc. Financial Statements FY2021-FY2026Q2**, visible Net Worth and actual ledger reads. Browser Back restores `?q=shopify`, its input and the real result. An earlier URL-only navigation sample preceded destination readiness and is superseded by this completed control.

The real debounce control also passes: from selected Airbnb, change input to Shopify and press Enter immediately. Old options/active descendant disappear and no stale ledger opens; after settlement the correct Shopify result appears. Preserve this working ownership guard.

The expected available-popup Down Arrow behavior follows the [WAI combobox keyboard pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/#keyboardinteraction). The defect is the missing keyboard reopen action for settled matching results, not Escape dismissal or result availability.

## Source and bounded repair

`dashboard/src/features/ledger-list/pages/gallery-page/index.tsx:189–225` handles Escape, then returns at **if (!isDropdownOpen || searchResults.length === 0) return**. Its ArrowDown logic is below that guard, so it can move an already open list but never reopen the closed one. `handleInputFocus` independently reopens current-query results, explaining the Tab/refocus workaround. The current `searchResults` computation already withholds stale, pending, failed and ineligible data.

For a non-composing ArrowDown with settled, eligible, nonempty current results, open the list and make its first option active while retaining input DOM focus and correct aria-activedescendant. Preserve ordinary open-list movement and Enter acceptance. Escape followed by Enter alone must still leave the list closed and perform no navigation. Keep the minimum length, debounce/current-variable checks, pending/empty/error behavior, Clear, pointer handling, IME guard, URL/history and actual selection/reset policy. No blur/refocus workaround, timeout, shared Input/Combobox redesign, dependency or API change is needed.

Acceptance: fresh desktop/narrow search→Escape→ArrowDown reopens current results with a valid first active option; subsequent Enter opens that exact ledger. Escape→Enter alone, composing keys and stale/pending/empty/failed searches cannot activate hidden or obsolete results. Cover the actual Gallery keyboard/state path and retain completed selection/Back and Clear controls; run dashboard gates when implementing. Physical IME, other engines and assistive-technology speech remain unverified.
