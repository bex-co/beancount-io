# Include the first account in stacked Income Statement tooltips

**Minor · 25–40m · dashboard · A2.** Readers should be able to identify every account segment in a stacked bar, including the first one.

Production October9,2026; authenticated QA reader, public freelancer-invoicing, isolated headless Chromium149, fresh1440×1000 and390×844. English, source main7b6398db; exact deployed revision unverified. No production writes.

1. Open https://beancount.io/ledger/open_ledger/freelancer-invoicing/income-statement?time=2026&view=income&lang=en. This is the supported Income chart view; its default mode is stacked.
2. Hover January's first account segment using the native browser pointer. The popup contains only 2026-01 and -6,000 USD, omitting Income:Consulting.
3. Hover the other January segment: its popup includes Income:Development and -9,500 USD.
4. Repeat from fresh desktop and narrow contexts; the first account is consistently absent while the second account is named.

Expected: both tooltips identify their actual account, month, currency and amount. Actual: series index0 loses its account name; the next series works. Series names/legend are currencies, so the omitted account cannot be recovered from the popup's USD text. Real GetLedgerIncomeStatement(at_cost/monthly,time2026) HTTP200 supplies January account balances Income:Consulting=-6000 and Income:Development=-9500. Actual GetLedger.favaOptions.invertIncomeLiabilitiesEquity is false, so the negative bars are correct. The initial harness assumed inverted signs; corrected fresh controls verify model/API equality and reproduce the name defect. No arithmetic/sign or API error is claimed.

Root: dashboard/src/features/reports/income-statement/date-balance-chart/stack-date-balance-chart.tsx:139–148 derives account identity from the currency/account series index but guards it with accountList.length>0 && param.seriesIndex. Valid index0 is falsy and renders the empty account div. Accounts are sorted and series constructed in currency/account order earlier in the same component; the consulting bar is the first USD/account pair.

Fix: accept series index0 explicitly while retaining the existing account mapping and handling genuinely absent/invalid indexes safely. Preserve series currency names, grouping/stack keys, amount formatting/signs, dates, colors and legend behavior. Add meaningful tooltip regressions using realistic item params for index0 and later indexes across multiple account/currency pairs; verify native first/second account hovers on both widths after implementation. Run normal dashboard checks. No new dependency, API or schema change is needed.

Dedupe/blast radius: searched all board states for seriesIndex, zero/first-series tooltip/account omission and stacked chart formatter terms, and reviewed open milestone scopes.
