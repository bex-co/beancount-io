# Give Cash Flow statement charts readable period data

**Severity:** minor accessibility defect. **Estimate:** 45–60 minutes. **Owner:** dashboard. **A2:** readers using a keyboard or text alternative must be able to read the monthly values shown in the Cash Flow statement's charts.

## Reproduction and controls

Production `https://beancount.io`, 2026-10-22; owned isolated headless Chromium 155.0.8059.85, anonymous public `open_ledger/example`, English/light, fresh 1440×1000 and 390×844 contexts. Time **2016**, interval **Monthly**, conversion **At Cost**. Genuine public data, no response fixtures or hosted writes.

1. Open `/ledger/open_ledger/example/cash-flow?time=2016`. **Net Cash Flow** draws twelve monthly points, in three unit series. A native pointer hover on November displays **2016-11 / USD: -1,611.76**.
2. Select **By Activity** using the desktop tab or narrow View selector. This draws twelve periods across nine activity/unit series. A native hover on November's operating bar displays **2016-11 / Operating Activities / +1,520.87 USD**. Both views repeat at both widths.
3. Move the pointer outside the chart and wait for the tooltip to disappear. There are **zero Period data/other native disclosures, zero chart images with a data description, and no monthly dates in the main text**. The four readable tables are Operating Activities List, Net change in cash & equivalents, Investing Activities List and Financing Activities List, all Account/USD/Other tables of whole-period figures.
4. Focus **Select conversion** and use native Tab. Focus enters the chart tabpanel; ArrowRight exposes no tooltip or period value. The next Tab reaches the aggregate account-list region. The chart supplies no keyboard route to its twelve values. This is a browser DOM/keyboard observation; actual screen-reader speech is unverified.

The pointer amounts are independently corroborated: Decimal sums November's real Assets interval totals for the report's three listed cash accounts to **-1,611.76 USD**; the independent November Income Statement net-profit control gives operating **+1,520.87 USD**. No arithmetic defect is claimed. Both actual Cash Flow CSV downloads have 54 data rows and only January 1–December 31, 2016 reporting context, so they do not supply the chart's monthly rows. Their whole-period export contract should remain intact.

Passing control: follow the actual Related Pages → Income Statement link at each width. Time 2016 is retained, and native Enter on its **Period data** opens a named 13-row table with Period/USD/IRAUSD/VACHR columns, keeping summary focus. That existing pattern makes chart values readable without pointer movement.

## Cause and bounded repair

`dashboard/src/features/reports/cash-flow/cash-flow-charts.tsx:132–140,274–282` returns only ReactECharts for NetCashFlowChart and ActivityBreakdownChart. Their tooltips contain the values, but neither renderer includes the existing chart-data disclosure/table pattern or an equivalent readable alternative. `cash-flow-content.tsx:259–294` passes the already-built `statement.intervals` to those two renderers. It is their sole production owner; the lower statement tables aggregate the entire selected period and cannot substitute for interval data.

Add a named native period-data disclosure to each Cash Flow chart, using the existing ChartDataTable/ChartPeriodTable pattern and existing period/activity labels where suitable. Net Cash Flow must identify period, unit and net amount; By Activity must identify period, activity, unit and amount. Derive the alternative from the same final model/series as its chart, preserve signs, plotted zeros, units and meaningful decimal text, and update it with the selected interval, conversion and shared scope. Give it an unambiguous chart name, retain native keyboard open/close and focus, and keep collapsed charts out of the tab order. Preserve chart/legend behavior, declarations and inference notices, statement tables and exports. No API, dependency, backend or new chart abstraction is needed.

Acceptance: real rendered regressions exercise both actual chart renderers with multiple periods, currencies, negative/zero amounts, empty data and a settled scope/interval replacement. Native desktop/narrow disclosures expose each plotted quantity with its activity/unit identity; the existing Income Statement alternative remains healthy. Run dashboard gates when implementing. Other engines/locales, empty/failed reads and repaired behavior remain unverified here.
