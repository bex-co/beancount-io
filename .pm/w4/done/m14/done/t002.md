## Implementation and verification

Completed 2026-09-19. The Catalan Journal namespace carried the same defect shape as the common catalog: one contiguous run of keys, `journal.linked` through `journal.unknownDirectiveType`, where each key held the Catalan written for a neighbouring concept while its `description` still matched its own key. The run also contained values for keys that no longer exist in the English source, which is why the tail of the run drifted further than one position. 31 messages were reassigned to the concepts their keys name.

The controls named in FINDINGS now read as themselves: Open is "Obrir" rather than "El contingut de la nota és obligatori"; Note is "Nota" rather than "No s'han trobat beneficiaris"; Metadata is "Metadades" rather than "Carregant el context de l'entrada..."; Payee/Narration is "Beneficiari/Descripció" rather than "Emplenar"; Pending keeps its literal "!" label and now carries "Transaccions pendents" as its accessible name rather than "El beneficiari és obligatori". Other and Linked keep their literal "x" and "V" flags with "Altres transaccions" and "Documents vinculats" as their names, matching how the other locales treat single-character flags. The rest of the run — linked documents, loading entry context, narration placeholder, new entry, the four not-found messages, note content and its validation message, pad, payee placeholder, postings, price, the four select placeholders, the metadata and postings toggles, the units header and the unknown-directive message — was repaired in the same pass.

Literal flags were kept separate from explanatory accessible names as the milestone requires, and wording was grounded in the sibling es, fr and pt catalogs rather than invented. `journal.linked` is "V" for Vinculat, which matches how pt localizes the same flag; es and fr keep "L".

Only the catalog changed. `features/journal/components/journal-filters.tsx` already maps each control to the right `labelKey`/`titleKey`, and `journal-table.tsx:273,275` already reads the header keys, so directive filtering, subtype behaviour, permissions and API inputs are untouched. English is unaffected.

Gates from `dashboard/`: `yarn format:check`, `yarn lint` (tsc, ESLint, Knip), `yarn test` (374 files, 4,190 passed, 1 pre-existing skip) and `yarn build` all pass. gitleaks reports no leaks in the changed tree.
