## Objective

Close the second blind spot: `knip.jsonc` makes every `src/**/*.test.{ts,tsx}` an entry point, which the test runner needs, so a module kept alive only by its own test is never reported. Add a companion check that fails when a non-test module's importers are all tests.

## Context

- Entry points that are legitimately unimported: `app/**` routes (Expo Router), `src/scripts/**` and `scripts/**` (standalone scripts), and `babel.config.js`, as listed in `knip.jsonc`.
- The one known legitimate script case is `src/scripts/play-release.ts`, reached through `scripts/play-release.sh` with `npx tsx`; no import graph can see that.
- Re-exports through an `index.ts` count as production importers only when the barrel itself has a production importer.

## Steps

1. Write the check beside t003's, reusing its allowlist mechanism, and chain it into `lint:deadcode`.
2. Allowlist `src/scripts/play-release.ts` with its reason.
3. Update the `yarn lint:deadcode` row in `mobile/CLAUDE.md` to name what the gate now covers.

## Files

- `mobile/scripts/` (new check)

## Acceptance criteria

- [ ] Adding a module imported only by a test makes `yarn lint:deadcode` fail with the module named; removing it makes it pass.
