## Objective

Put **New ledger** where users look for it and replace the two dead ends: the drawer's "No entries" empty state and the ledger guard's untranslated fallback.

## Context

- `src/components/ledger-drawer/ledger-drawer.tsx` renders `t("noEntries")` when the account has no ledgers and offers only a website link.
- `src/components/ledger-guard/ledger-guard.tsx` renders three hard-coded English strings ("No Ledger Selected", "Please select a ledger to continue", "Select Ledger"), the only UI text in the app that bypasses `useTranslations()`.
- Discovery (w4/m4) lives at `/(app)/ledger-selection`.

## Steps

1. Add a **New ledger** row to the drawer beneath the ledger list.
2. Replace the drawer empty state with a short message plus **Create** and **Discover** actions.
3. Localize the guard fallback and give it the same two actions.
4. Add `accessibilityLabel`s to the new controls.

## Files

- mobile/src/components/ledger-drawer/ledger-drawer.tsx
- mobile/src/components/ledger-guard/ledger-guard.tsx
- mobile/src/translations/en.ts

## Acceptance criteria

- [ ] An account with zero ledgers sees Create and Discover in the drawer and in the guard, in the active locale.
- [ ] The drawer row opens the create screen; existing drawer tests still pass.
