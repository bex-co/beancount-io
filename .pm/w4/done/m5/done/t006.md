## Objective

Add the iOS `apple-itunes-app` meta tag to public dashboard ledger routes so mobile Safari visitors from README, Telegram, and gallery links see the install banner, and confirm the tag stays off private and auth pages.

## Context

- App Store id `1527950512`; use `app-argument` with the current page URL so the banner opens the app on the same ledger.
- The dashboard ledger layout route is `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.tsx`; head management already handles canonical tags (w2/m10).

## Steps

1. Emit the meta tag from the ledger layout's head only when the ledger is public.
2. Add a route test asserting presence on a public ledger and absence on a private ledger and on auth routes.

## Files

- dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.tsx
- dashboard/src/routes/__tests__/

## Acceptance criteria

- [ ] Public ledger pages carry the tag with the page URL as `app-argument`; private and auth pages do not.
- [ ] Dashboard `yarn lint`, `yarn test`, and `yarn build` pass.

## Out of scope

- An Android install prompt; there is no meta-tag equivalent.
