## Objective

Add meaningful tests for the behavior this milestone shipped, asserting real outcomes and failure modes.

## Context

- Mobile unit tests run through `yarn test:unit` (the jest-lite runner in `mobile/scripts/`); dashboard tests through `yarn test`; backend-v2 through `yarn test`.
- Tests must fail when the covered behavior is broken; no snapshot-everything or tautological tests.

## Steps

1. List the behaviors and failure modes shipped by the implementation tasks.
2. Write one focused test per behavior; sabotage the implementation once to confirm each test fails.
3. Run the owning package's full check gate.
