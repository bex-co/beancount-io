# Name collapsed sidebar group flyouts

**Severity:** minor accessibility. **Estimate:** 25–40 minutes. **Owner:** dashboard, `common/components/ledger-layout/ledger-group-flyout.tsx`. **A2:** readers navigating an icon sidebar should be able to identify the popup containing its report or advanced destinations.

Production `https://beancount.io`,2026-10-22 America/Los_Angeles; independent owned isolated headless Chromium155.0.8059.85 contexts, English/light, signed out, public synthetic `open_ledger/example`,1440×1000 and1024×1000. No response substitutions, mutations or hosted writes.

## Reproduction and controls

1. Open Journal with `time=2016-08`. Use the native Cmd+B sidebar shortcut to collapse it to the icon rail. Focus **Reports** and press Enter.
2. Chromium Accessibility.getFullAXTree exposes an unignored **dialog with name:""**. Its visible title is Reports; the trigger is correctly named Reports. PopoverContent has neither aria-label nor aria-labelledby, so neither the trigger nor the plain title names this separate node.
3. Repeat for **Advanced**: its visible title and trigger say Advanced, while its dialog name is again empty. Both fresh widths reproduce both groups.
4. Passing controls: Escape closes each flyout and returns focus to its own Reports/Advanced trigger in all four cases. The Reports popup exposes six correctly named report links; Advanced exposes Query, Commodities and Documents. Reopen Reports, keyboard-activate **Income Statement**, and the flyout closes at the correct `/income-statement?time=2016-08` destination. The actual href and resulting URL agree at both widths; selected time is preserved.

## Cause and bounded repair

`ledger-group-flyout.tsx:109–120` renders bare PopoverContent, then the visible `label` inside an unassociated div. The translated label is already passed to the component and used on its trigger. Give the popup that same appropriate group name, either with aria-label={label} or a stable association to its visible title. Keep the primitive and caller structure; do not assign one global name to every Popover.

`ledger-sidebar.tsx:355–366` selects this component only for **collapsed, nonmobile** groups. The shared renderMenuGroup path serves Reports, Import, Advanced and the conditional multi-destination Status group. Reports/Advanced were live exercised; the other two are source-traced scope. Expanded groups and the narrow drawer use a different inline submenu path. Preserve that distinction, translated labels, active destinations, keyboard/pointer/touch opening, hover gap/delay, Escape and navigation/filter retention. No API, dependency or new translation is needed.

Acceptance: open the actual flyout component by keyboard and pointer with two different localized group labels and assert the dialog's role/name, independently of the trigger. Keep the named links, Escape focus return and real destination action. Preserve existing touch-event ordering and mouse-delay regressions; repeat native collapsed-sidebar checks at desktop/tablet widths and run dashboard gates when implementing. Actual screen-reader speech, physical touch/pen, the two conditional groups and repaired behavior remain unverified.
