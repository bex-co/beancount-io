**Resolved 2026-09-19** — The legacy route now dispatches in `beforeLoad`: `type=file` with a path is handed to the canonical blob route (`/files/blob/main/<path>`) carrying `lineNumber` and `editMode`, with `replace: true` so the alias leaves history. A leading slash in `path` is trimmed so the blob URL stays well formed. `type=dir`, the default (no `type`), and `type=file` with an empty path are untouched and still render the directory browser. The note's repro was confirmed first on the pre-fix code — the compatibility URL for `transactions/sales.bean` showed the breadcrumb and then "Failed to load directory contents" with Try Again — and the fix was verified live at 390×844 and 1440×1000 against the public read-only API: the same URL now opens the 4.33 KB read-only source that its canonical counterpart serves, `lineNumber=42` survives dispatch, the `transactions` directory URL still lists its six files, Back from the redirected file lands on the directory page rather than bouncing, and a missing file now gets the canonical "File not found: transactions/nope.bean" with a parent-directory link instead of the generic directory error. Permission handling is unchanged and was checked signed out: `editMode=true` is forwarded, and the canonical view's existing `effectiveEditMode = requestedEditMode && canWrite` gate in `text-file-view.tsx` strips it, leaving a read-only editor with no save action — the alias does not decide permission itself. `routes/__tests__/files-content-alias-route.test.ts` adds eight cases that drive the route module's own `validateSearch` and `beforeLoad` (rather than re-implementing them, as the older `redirect-routes.test.ts` does) and assert the thrown value is a genuine router redirect; all eight fail when the dispatch is removed. Not covered: `?lang=` is not carried onto the blob route, matching what every other in-app file navigation already does (`use-file-navigate`, the directory view's links) since the canonical route's search schema is `{editMode, lineNumber}`; authenticated editing through the alias was not exercised. Dashboard gates all pass (`yarn format:check`, `yarn lint`, `yarn test` — 404 files, 4560 passed, 1 pre-existing skip — and `yarn build`). Shipped in `d9330b50` (`dashboard`).
