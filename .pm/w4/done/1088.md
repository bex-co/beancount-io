# Keep language changes inside the current file draft

**Severity:** minor. **Estimate:** 45–60 minutes. **Owner:** dashboard. **A2:** changing the dashboard language while editing a file should preserve the draft without asking the user to leave it.

## Reproduction and controls

Production `https://beancount.io`, owned isolated headless Chromium156.0.8078.47, authenticated QA owner in its designated disposable synthetic ledger, UTC. Start English/light. Nine fresh contexts exercise Create File five times and existing-file Edit four times. Seven are dirty; the empty new form and unchanged existing buffer are controls. Seven contexts stay1440×1000. Two start390×844, widen only to access the actual desktop User menu, then return narrow: responsive crossover, not a phone-native language menu.

1. Open `/ledger/<qa-owner>/<disposable-ledger>/files/new/main?lang=en`. Enter `qa-20261025-language-draft.txt` and the local text `qa-20261025 unsaved language-change draft`. Do not save.
2. User menu → Theme → Dark changes appearance in place without a warning and retains both values.
3. User menu → Language → Deutsch. The URL changes only `lang=en` to `lang=de`; the same editor, filename node and draft remain. German has already applied, but **Nicht gespeicherte Änderungen** opens and warns that leaving will lose changes.
4. Escape or **Bleiben** dismisses it and retains both values, the same new-file route and `lang=de`. A separate **Ohne Speichern verlassen** run also keeps that route and draft: no departure happens.

Repeat on an existing text file at `/files/blob/main/main.bean?editMode=true&lang=en`, appending the unsaved comment `; qa-20261025 unsaved existing-file language change`. Dark remains safe; Deutsch opens the same departure decision despite retaining the file and `editMode=true`. Escape preserves the marker. In the separate explicit Leave run the marker is discarded, yet the same file remains in edit mode with German applied. This is an unnecessary destructive decision during a preference change; no silent loss before confirmation is claimed.

Working controls: empty Create File and unchanged existing-file Edit switch to German without a dialog. In separate dirty runs, the actual **Cancel/Abbrechen** action still opens the guard, and Escape preserves the filename/visible draft or existing-file marker. Existing-file Cancel removes editMode when allowed: exempting every same-path query change would weaken real protection.

All nine contexts complete and close. Zero mutation attempts, hosted writes, page exceptions or console errors. Existing-file API controls independently retain exact content, SHA, size and file commit before/after every run. Save is never activated. Assertions concern the exact filename and normalized visible draft/marker, not a claim that every Monaco model byte was read. The narrow dialog screenshot was visually inspected.

## Cause and bounded repair

`dashboard/src/common/hooks/use-change-language.ts:30–35` changes and persists the locale, then synchronizes `lang` with `history.replaceState` and a synthetic popstate at:13–16. `buildUrlWithLanguage` deliberately preserves the pathname, other search values and fragment. This is an in-place preference transition.

Both file guards ignore the transition supplied to `shouldBlockFn`: Create File `index.tsx:116–125` returns hasDraft; existing-file `file-edit-mode.tsx:73–77` checks only dirty/saved-exit state. Installed TanStack Router `src/useBlocker.tsx:175–215` supplies current/next route, path, params and search, so these consumers can distinguish context changes. The existing-file dialog's confirmed Leave calls onDiscard at:232; TextFileView's handler restores saved contents at:195. Create File's Leave only proceeds, so its mounted local draft survives this same-context transition.

Exempt a language-only transition that keeps the same file/new-file context and all other relevant state. Preserve the exact draft and edit mode, update the visible language and URL coherently, and open no departure choice. Keep guards for actual file/branch/ledger navigation, Cancel/editMode exit, Back and unload, as well as pending/failed saves, successful-save exits, and the repaired Stay focus handoffs. Do not disable all query-parameter guards or suppress locale synchronization globally. No API, translation, dependency or draft-persistence feature is needed.

Acceptance: real editor/router interactions repeat both language journeys with dirty and clean buffers, plus theme controls, with no dialog or draft reset. Actual Cancel, sidebar departure and Back must still require the existing choice; Stay/Escape retain content and useful focus, and confirmed departure reaches its destination once. Preserve successful/failed-save behavior and repeat desktop/responsive controls before dashboard gates.
