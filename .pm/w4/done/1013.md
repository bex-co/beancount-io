## Cause and bounded repair

`monaco-beancount-actions.ts:19–40` applies ALIGN_RE independently to each physical line. Its prefix excludes quotes/semicolons **on that line**, but it carries no open-string context from preceding lines. The continuation has no quote, so it is padded as an amount-bearing line. `file-edit-mode.tsx` calls this helper through its re-export; `registerEditorShortcuts` calls the same helper for Cmd/Ctrl+D. Only the menu action was independently exercised in this pass.

Preserve quoted-string context across lines, respecting escapes and comment boundaries, and exclude string contents from layout edits. Use reliable existing lexical handling where available; a current-line quote check cannot protect this continuation. Keep the implementation within dashboard, retain ordinary posting alignment/currency-column behavior and single-line strings, and preserve [969](./969.md)'s actual-change/no-op Undo boundaries. No new dependency, full ledger parser, backend change or cross-package import is required.

Acceptance: real helper input/output regressions preserve the multiline narration exactly while still aligning the real postings. Include escaped quotes/backslashes, quotes inside comments, closing-line transitions, ordinary single-line strings and string-only no-op/Undo controls. Exercise both menu and Cmd/Ctrl+D with native before/after models at desktop/narrow, retaining exact draft/discard behavior, and run dashboard gates when implementing. QA authored no product fix or formal tests.
