## Result

`/simplify` ran four passes (reuse, simplification, efficiency, altitude) over m27's code.

**Applied:**

- **Mobile `valuation.ts`:** price dates are indexed once per price array and currency (a `WeakMap`), instead of a full scan and sort per holding per Accounts row. One pair matcher serves both the price and the managed-source lookups.
- **Mobile hooks:** the managed-price read folds into `useLedgerPrices`, and `use-ledger-managed-prices.ts` is removed.
- **`SegmentedPages`:** `header` is a render function of the active page. The card no longer mirrors the active index, which also stops the caption lagging the tab highlight.
- **`ValuationSheet`:** it derives visibility from `valuation`, so nothing is built while it is closed.
- **`AccountChartsCard`:** `onCaptionPress` is required, and the stale "date of its prices" doc is gone.
- **Web popover:** units now use the ledger-precision `useFormatQuantity`, so `0.00012 BTC` is no longer shown as `0`.

**Skipped:**

- **Shared `median` and `parseLedgerDay` helpers:** moving them from `screens/` into `common/` is a refactor outside m27.
- **Merging the two mobile price documents:** it needs codegen churn.
- **A shared sheet component:** it would be the third `Modal` sheet in the app, which calls for its own change.
- **Making the Accounts and account-detail status lines tappable:** that is new scope. m27's rule 2 names Home's status line.

Gates afterwards: mobile `format:check`, `lint`, `typecheck` and `test:unit` (1930) pass; dashboard `format:check`, `lint`, `test` (4901, 1 skip) and `build` pass.
