## Objective

Render the existing Home, Accounts, and Reports screens for an authorized public example without requiring an account.

## Context

- All three target screens currently call `useSession()`.
- Public-ledger access and write-permission checks already exist in `useLedgerAccess()` and `canWriteLedger()`.
- m26–m28 define the current valuation and localization behavior; guest views must use those same implementations.

## Steps

1. Separate the screens' public read inputs from account-specific preferences and queries, using explicit optional identity where needed.
2. Reuse the existing screen components and selectors; skip authenticated-only reads and controls for guests.
3. Scope guest preferences and cached reads to the selected deployment and ledger, and surface unavailable or denied data without stale private content.

## Files

- `mobile/src/screens/home-screen/`
- `mobile/src/screens/accounts-screen/`
- `mobile/src/screens/reports-screen/`
- `mobile/src/common/hooks/` and associated query definitions as needed.

## Acceptance criteria

- [x] All three screens load an available public example with no session and no authenticated-only query.
- [x] Cash-only and investment figures and valuation disclosures agree with the existing signed-in public-reader behavior.
- [x] Changing examples cannot leave the previous ledger's figures or preferences presented as the new selection.
- [x] Authenticated callers retain their existing strict session and permission behavior.

## Out of scope

Copying the screens into a demo implementation, changing accounting semantics, expanding API permissions, and changing the generated GraphQL files by hand.

## Completion evidence — 2026-09-27

Home, Accounts and Reports reuse their existing components and accounting selectors. LedgerReadContext reads public getLedger metadata instead of authenticated ledgerMeta; generated hooks were regenerated with yarn codegen. Native public-example checks covered everyday, company and crypto data, balances and market-value disclosures. Company report axis labels now retain the full MUSD amounts.
