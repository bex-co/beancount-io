## Objective

Give signed-out visitors a visible Welcome action and a small example chooser that leads to Home, Accounts, and Reports on the selected server.

## Context

- Welcome currently offers Sign In, Sign Up, and server settings.
- `mobile/src/screens/ledger-selection/use-discovery.ts` depends on an authenticated session and calls authenticated search/account APIs.
- Known public examples include `open_ledger/example`, `open_ledger/minimax`, and `open_ledger/crypto-example`; availability must be checked against the selected deployment.

## Steps

1. Add a translated, accessible example action on Welcome and a curated example chooser using individual public-ledger reads.
2. Connect selection to the guest shell and supported views, reusing existing navigation components where appropriate.
3. Provide a clear return to Welcome and server settings. When no curated example exists on the selected server, show an actionable empty state without switching origins.

## Files

- `mobile/src/screens/welcome/index.tsx`
- `mobile/src/screens/` — example chooser as needed.
- `mobile/app/` — chooser route and guest navigation.
- `mobile/src/components/ledger-drawer/` and related shared navigation only if needed.

## Acceptance criteria

- [x] A signed-out visitor can choose an available example from Welcome and navigate among the three supported views.
- [x] The chooser calls no authenticated search, account-list, or starring endpoint.
- [x] Missing examples and a self-hosted server without examples have a usable empty state; every request stays on the selected deployment.
- [x] Navigation labels and targets remain usable at enlarged text sizes and in both themes.

## Out of scope

General anonymous ledger search, starring, creating example ledgers, a new demo backend, and hosted Universal Links deployment.

## Completion evidence — 2026-09-27

Welcome exposes Try an example. The chooser probes the three curated IDs on the selected deployment and the guest tabs render the existing views. Real Apollo tests prove that authenticated operations, mutations, other ledgers and cross-server cache reuse are blocked. A missing example cannot cause a switch to the managed service.
