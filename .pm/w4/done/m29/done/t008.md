## Objective

Prove the guest access and authentication transitions through real state and rendered component behavior, and complete the package verification gate.

## Context

- The new behavior crosses route guards, screen queries, selected-server state, and OAuth continuation.
- Existing mobile tests use the package's Jest-lite runner; rendered-component tests already cover shared navigation contracts.
- Native verification is required in addition to unit checks.

## Steps

1. Cover Welcome-to-example selection and each supported guest view, including the absence of authenticated-only requests and mutation actions.
2. Exercise unavailable/private examples, server changes, logout, late responses, sign-in cancellation/failure/success, and existing pending-link behavior using controlled dependencies around the production code.
3. Include signed-in controls and representative cash-only/investment data to detect regressions in ordinary navigation and financial presentation.
4. Run `yarn format:check`, `yarn lint`, `yarn typecheck`, and `yarn test:unit` from `mobile/`; verify any fixes on the affected native paths and retain the walkthrough evidence from t005.

## Files

- Tests beside the guest state, routes, screen integrations, and authentication continuation in `mobile/src/`.
- Existing related tests under `mobile/src/common/`, `mobile/src/components/`, and `mobile/src/screens/`.

## Acceptance criteria

- [x] Behavioral tests fail if guest selection crosses servers, protected actions become available, or sign-in continuation restores the wrong context.
- [x] Tests exercise the production state transitions and rendered integrations rather than asserting strings or reimplementing their logic.
- [x] All four mobile gates pass, and native evidence covers both themes, enlarged text, and the supported guest views.
- [x] Test evidence uses synthetic or public data and introduces no production ledger mutation or analytics.

## Out of scope

Snapshot-only proof, new test dependencies, new backend stacks, and tests of unrelated package behavior.
