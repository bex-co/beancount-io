## Objective

Provide a guest context for the three approved read screens while preserving the authenticated route boundary for every protected destination.

## Context

- `mobile/app/(app)/_layout.tsx` currently redirects every missing session to Welcome.
- `mobile/src/common/hooks/use-session.ts` is a strict authenticated accessor; guest browsing must not fabricate an identity to satisfy it.
- Selected-ledger persistence, server selection, and Apollo teardown already live in `mobile/src/common/`.

## Steps

1. Add the smallest guest state needed for the selected server, example, and supported view; make its transition to and from authenticated state explicit.
2. Mount a read-only guest route shell using the existing providers and screen architecture. Keep route files thin and screen logic under `src/screens/`.
3. Clear or invalidate guest state on server changes and session teardown, and reject results that arrive for an obsolete context.

## Files

- `mobile/app/` — guest routes and root integration as needed.
- `mobile/src/common/vars/` — guest state and selected-server integration.
- `mobile/src/common/apollo/session-teardown.ts` and relevant provider integration.

## Acceptance criteria

- [x] Guest reads have no authenticated user ID, token, or synthetic session.
- [x] Only the approved guest views are reachable through the new shell; authenticated routes retain their guard.
- [x] Switching server or ending a session clears obsolete selections and prevents prior private data or late responses from appearing.

## Out of scope

Backend authentication changes, anonymous search, export shortcuts, new state-management dependencies, and broad routing refactors.

## Completion evidence — 2026-09-27

Added the separate /examples route, in-memory guest selection and per-example Apollo cache. Server changes and session teardown clear the visit and invalidate pending authorization. guest-access.test.ts executes the production ledger guard, permission hook and protected AppLayout; a guest selection never supplies a session or a cached write grant.
