## Cause and bounded repair

`dashboard/src/features/ledger-editor/upload-files/index.tsx:280–282` opens the hidden input solely through fileInputRef.current.click. At:351–357 that input has no readiness gate. At:368–374 the visible Choose your files button is disabled only while isUploading. This server-rendered enabled button cannot open the chooser before its React handler attaches, and its early activation is not replayed.

Apply the existing TanStack useHydrated convention from the repaired Import/Receipt pickers to this control group. Keep the chooser and hidden input unavailable until hydrated, then retain normal pointer/Enter/Space activation and existing upload-busy behavior. Audit the drop area's readiness presentation consistently; early drag/drop was not independently exercised here. Preserve readable SSR instructions, write-permission checks, folder-name checks, maximum sizes, replacement staging, partial-batch recovery and late-completion ownership. Scope the change to this uploader; no API, dependency or global Button change is needed.

Acceptance: real server-render-to-hydrate coverage proves the initial unavailable state and subsequent enabled chooser, including actual native picker activation at both widths and harmless cancellation. Keep the settled file upload/selection controls working. Run dashboard gates when implementing; client-only mocks cannot prove the initial state.
