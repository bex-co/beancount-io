# Keep unselected chart legend labels readable in light mode

**Severity:** minor. **Estimate:** 60 minutes. **Owner:** dashboard. **A2:** readers must be able to identify and enable additional commodity series in financial reports.

Environment: production `https://beancount.io`, signed out, English, isolated headless Chromium 149.0.7827.55. Local HEAD `26d54a9d`, fetched main `bd5d1d31` (only newer dashboard change is importer test mocks), deployed asset `main-BIr0jJni.js`; exact deployed SHA unknown.

## Reproduction

1. Fresh-load `/ledger/open_ledger/example/income-statement?time=2016-02&lang=en` in light mode. Keep Net Profit / Monthly / At Cost.
2. USD is selected. IRAUSD and VACHR are unselected but available legend controls. Their actual rendered ZRender text spans use `#cfd2d7`, normal 12px sans-serif, over a transparent canvas and white page background: contrast **1.515919725:1**. Fresh 390×844 and 1440×1000 documents agree.
3. Click IRAUSD with the browser pointer. Its legend selection becomes true and its label changes to `#54555a` (**7.436259432:1**). This proves that the faint label is usable, not a disabled control. VACHR stays faint and unselected.
4. At 1440×1000, `/ledger/open_ledger/example/balance-sheet?time=2016&lang=en` also renders unselected IRAUSD/VACHR labels with the same failing color.

Expected: selected and unselected labels remain readable while their states are distinguishable. Normal-size text requires 4.5:1; the inactive-control exception concerns controls unavailable for interaction, which this pointer control disproves. [W3C contrast guidance](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

Working dark control: a fresh 1440×1000 Income Statement with `theme=dark` renders the same unselected color against the actual page background `#0b0e0b`, giving **12.804575366:1**. Selected text uses `#B9B8CE`. Preserve this working appearance. Measurements use rendered text fill/font and computed background colors, not anti-aliased screenshot pixels.

Real `GetLedgerIncomeStatement` HTTP 200 for February 2016 / monthly / at_cost returns one February 29 net-profit bucket: USD `-3055.88`, IRAUSD `2400`, VACHR `-10`. These match the chart's series. There is no missing data or arithmetic defect.

## Cause and fix

`dashboard/src/common/components/react-echarts/client.tsx:25–36` uses the upstream default theme in light mode. `runtime.ts:42–63` registers only the app's dark theme. The installed ECharts 6.0.0 `lib/component/legend/LegendModel.js:262` supplies the disabled palette color as `inactiveColor`; `LegendView.js:328–333` uses it for every unselected legend label, even when `selectedMode:true` permits interaction.

The app's `single-date-balance-chart.tsx:105–128` deliberately starts non-primary series unselected and supplies no contrast override. Balance Sheet's `line-chart.tsx:71–117` does likewise. This is an app-theme integration repair using supported ECharts options, not a dependency fork or a reason to remove the legend.

Set a readable unselected-legend foreground for the shared managed light appearance, using a narrowly scoped light theme or equivalent shared option default. Keep the dark appearance's passing colors, caller-supplied theme precedence, transparent backgrounds, selected/unselected state, pointer toggles, series colors and financial values. Avoid a blanket text or palette replacement and do not edit node_modules.

Callers surveyed: the shared runtime serves the single/stacked Income Statement charts; Balance Sheet and Account line charts; Cash Flow's two legend-bearing chart builders; Overview's income/expense and optional net-worth legends; Budget. The hidden Distribution pie legend is not a user-visible reproduction. Only Income Statement and Balance Sheet are independently reproduced here; other callers need regression checks when applying the shared default.

Acceptance: rendered 12px labels in both reproduced light-mode reports meet at least 4.5:1 before and after selection at both widths; a pointer can still toggle the same series without changing amounts or dates. Preserve dark mode and explicit theme overrides. Extend the existing real-runtime SVG/theme checks to cover an unselected operable legend, then verify the browser color pair; a test of a configuration string alone is insufficient.
