# Price export escapes its output directory for parent-relative includes

Severity: **major**. Package: **cli**. Estimate: **45–60m** for canonical
source mapping, containment validation and targeted regression coverage.
Source: continuous CLI QA for w4. **A1/A2:** a portable export must contain its
files and must not overwrite unrelated files beside the chosen directory.

Environment: 2026-09-21, main `390568c220bfbdb0df1c9decb8436c64dfa3c9ca`,
checkout `cli/.venv/bin/bea` 0.3.0, Python 3.13.3, Darwin arm64. Synthetic
fixtures and all outputs stayed beneath `cli/tmp/qa-20260921-cli-loop/`.
Fresh processes used child-only config/cache/data directories there,
`BEA_NO_UPDATE_NOTIFIER=1`, no inherited BEA_FILE/BEA_TOKEN, and bounded
25-second captures. No hosted account, live price fetch, or real ledger.

## Reproducer and observed result

In a disposable directory create this tree:

```text
input/books/main.bean        include "../shared/accounts.bean"
input/shared/accounts.bean   2024-01-01 open Assets:Cash USD
out/shared/accounts.bean     UNRELATED SENTINEL
```

Each file ends in a newline. `bea --json --file /absolute/input/books/main.bean
check` succeeds. Run:

```sh
bea --json --file /absolute/input/books/main.bean price export   --output /absolute/out/copy
```

Exit 0, stderr empty. The JSON manifest includes
`/absolute/out/copy/../shared/accounts.bean` and `/absolute/out/copy/main.bean`.
The **pre-existing `out/shared/accounts.bean` is overwritten** with the account
open from the source, although it is outside `out/copy`. The exported root
still says `include "../shared/accounts.bean"`. Its source remains unchanged.

Copy only `out/copy` to a fresh `relocated/copied` directory. Both fresh
`bea check` and the installed upstream `bean-check` exit 1:
`File glob "../shared/accounts.bean" does not match any files`.
Two pristine repetitions had the same overwrite and failed relocation.
Captures retain the sentinel's before/after hashes and exact written contents.

Working control: use an absolute include path pointing to the same external
accounts file. Export places it at `_shared/01-accounts.bean`; copying that
export alone to another directory passes both CLI and upstream check.
Ordinary includes under the root directory also export and query correctly.

Expected: map every external source into the exported tree (as the absolute
control already does), rewrite includes to those internal destinations, and
leave every file outside the chosen export untouched. `docs/USAGE.md` calls
`price export` a self-contained snapshot; export portability is the completed
w1/m29/t005 acceptance contract.

## Cause, scope, and repair

`cli/src/bea_engine/ledger/write.py:69–72` collects glob matches with
`Path.absolute()`, retaining lexical `..` segments. In
`managed_load.py:545–552`, `path.relative_to(snapshot.root.parent)` consequently
succeeds with `../shared/accounts.bean`; the `_shared` fallback is skipped.
The destination becomes `target / '..' / 'shared/accounts.bean'`, and
`:560–563` writes it with no containment check. `_rewrite_export_includes`
then preserves the same escaping relative spelling.

Canonicalize source identity for destination classification, maintain a mapping
compatible with include rewriting, and validate the complete destination plan
is inside the intended export before any write. Do not change shared snapshot
semantics casually: capture also supports atomic add/import validation. Caller
search finds `export_portable` only in engine `main.py:597`, reached through
frontend `commands/price.py:_export`; the export fix can remain local to this path.

- [ ] The exact parent-relative fixture exports all files beneath `out/copy`,
      preserves the neighboring sentinel and source files, and survives relocation.
- [ ] Absolute external includes and ordinary local/glob includes still work;
      the manifest names actual contained files.
- [ ] A real CLI regression checks outside bytes and runs the relocated export
      through upstream `bean-check`; run CLI gates when fixing.

Dedupe: all queues, completed/blocked records and open milestones searched for
price export, containment, parent includes and portable snapshots. No open
match. Read full completed w1/m29/t005/DoD and exporter tests: they cover managed
feeds and direct-root output, not lexical parent traversal. Introduced by
`109fef1d`; later exporter history leaves the mapping unchanged. This is separate
from existing destination aliases overwriting a source, which needs inode checks.

Verified evidence: `captures/cycle6-*-escape-export-*.json`, relocated checks,
absolute controls and `cycle6-native-oracle-*.json` beneath the run directory,
plus `cycle6.py` and both sets of fixtures. Unverified: Windows path semantics,
managed feeds in this fixture, and concurrent filesystem changes. No product fix
or shipping; only sanitized local resources remain.
