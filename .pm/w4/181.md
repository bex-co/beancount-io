# Protect the source ledger when native query exports use --source

Severity: **major — source data loss**. Package: **cli**. Estimate: **40–55m** for the local-source destination guard and regressions. Source: continuous CLI QA. **A1/A2**: a read/export command must not silently replace the books it reads.

Checkout main `390568c2`, `cli/.venv/bin/bea` 0.3.0, Python 3.13.3, macOS arm64. Isolated config/cache, notifier disabled, inherited `BEA_FILE`/`BEA_TOKEN` removed, closed stdin, captured non-TTY stdout/stderr. Synthetic files only.

Create `/scratch/main.bean`:

```beancount
2024-01-01 open Assets:Cash USD
2024-01-01 open Equity:OpeningBalances USD
2024-01-02 * "Start"
  Assets:Cash 1000 USD
  Equity:OpeningBalances
```

```sh
bea query --source /scratch/main.bean --output /scratch/main.bean 'SELECT account, number LIMIT 2'
bea --json --file /scratch/main.bean check
```

Actual: first command exits 0, stdout/stderr empty; the ledger bytes become an ASCII table headed `account number` containing the two query rows. The second command exits 1 with invalid-token/indent errors. All original directives are gone. Reproduced twice with pristine fixtures, recorded before/after SHA256 and inspected bytes. Reproduced separately with `--source beancount:/scratch/main.bean`, a symlink destination, a hard-link destination, and `--output child.bean` where the root includes that child. Each exits 0 and corrupts the relevant source; fresh-process checks confirm failure.

Working controls: the same query with `--file` instead of `--source` refuses with exit 2 and preserves the ledger, repeated twice. Native `--source` with a distinct output file succeeds and leaves a valid, unchanged ledger. Ordinary CSV/text/Beancount and JSON exports to distinct files passed in the same cycle.

Expected: apply the documented USAGE alias refusal to local ledger sources before launching the native writer. The contract says root/include aliases under any spelling, symlink or hard link are refused before writing. Native output formatting does not justify bypassing this explicit safety guarantee.

Root: `cli/src/cli/commands/query.py:186–195` forwards `--source` plus `--output` through `launch.run_native("bean-query", ...)` and exits before `output.refuse_ledger_alias` at lines 198–202. The earlier `check_output_destination` checks directory/parent shape only. Native dispatch (`src/cli/engine/launch.py:75`) consequently lets upstream Beanquery write the source path. The existing guard in `src/cli/output.py:235` already compares closure members with inode-aware identity; it is simply unreachable on this branch. The managed query/shell guards cannot protect a subprocess routed directly to native Beanquery.

Repair: resolve supported local Beancount source forms (bare path and `beancount:` URI) to their ledger input and run the existing closure/alias refusal before native launch. Preserve source URI parsing semantics and normal native output. Add a regression for each reproduced spelling/alias and a distinct-destination control; do not infer safety from `--json`, which intentionally rejects `--source`. Cover local CSV inputs too if the same native write path is retained, without treating `memory:`/`test:` as filesystem ledgers. Interactive native `.output` was not exercised and should be assessed separately rather than claimed fixed by an argv-only guard.

Acceptance: reproduced one-shot variants exit 2 with a path-specific diagnostic and identical source hashes; unrelated output still works. Run the CLI checks. No server/API or new dependency is involved.

Dedupe: full completed w3/300 and w1/m23/t001 were read. `285b6d90` closed the original `--file`/managed-shell alias defect; those controls still pass. This is an uncovered native `--source` branch, not a claim the original reproduction still fails. Targeted history through `4ce341a6`, `0e04c47b`, and `2860c09b` retains the early native return. No open item owns this path; w4/172 is a different price-export writer.

Evidence: `cli/tmp/qa-20260921-cli-loop/cycle10.py`, `cycle10b.py`, and captured `cycle10-*-source-alias-*.json` / `cycle10b-*.json`, including exact argv, output streams, exit statuses and before/after hashes.
