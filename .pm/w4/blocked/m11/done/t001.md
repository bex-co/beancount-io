## Objective

Give the account screens the data and the single pure decision the [display rule](../README.md#display-rule) needs. For any account or total, the selector returns the primary figure, an optional secondary cost figure with its basis, and the commodities that could not be expressed in the operating currency. It must tell an empty balance apart from one that is not expressible.

## Context

- Evidence: [w4/016](../../016.md), [w4/027](../../027.md).
- `mobile/src/common/balance-util.ts` sets `BALANCE_CONVERSION = "at_cost"`. Under `at_cost`, a commodity with no cost currency stays under its own key, and `resolveCurrencyBalance` ignores it — that is how `-8 VACHR` becomes `$0.00`.
- A commodity held at cost (RGAGX) comes back already converted under `at_cost`, so its units need the `units` conversion keyword. `src/common/graphql/queries/accountReport.graphql` and the trial-balance query behind `src/screens/accounts-screen/hooks/use-trial-balance.ts` already take `$conversion`.
- Per-currency precedent: `src/screens/merchant-detail-screen/selectors/merchant-stats.ts` (`totalsByCurrency`).

## Steps

1. Capture which keys an `at_cost` response returns for a commodity held at cost and for a commodity with no cost currency.
2. Add a `units` read only where the rule needs it (commodity accounts and their journal), reusing the existing hooks and cache policy. Do not change `BALANCE_CONVERSION`.
3. Write the selector beside the existing balance utilities, keeping the totals of `resolveCurrencyBalance`'s current callers unchanged.

## Files

- `mobile/src/common/balance-util.ts`
- `mobile/src/screens/accounts-screen/hooks/use-trial-balance.ts`, `use-account-report.ts`
- `mobile/src/common/graphql/queries/*.graphql`, only if a query needs a new field. Regenerate with `yarn codegen`; never hand-edit `src/generated-graphql/`.

## Acceptance criteria

- [ ] RGAGX-shaped data yields units as primary and the cost amount as secondary; `-8 VACHR` yields units, not zero; `{}` yields empty; a USD account yields exactly what it shows today.
- [ ] Operating-currency totals computed through the selector equal the current `resolveCurrencyBalance` totals.

## Out of scope

- Rendering (t002–t004), a valuation toggle (w4/068), and backend changes.
