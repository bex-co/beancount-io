## Objective

Ship `bea price fetch`, which reads bean-price's own convention (`price: "USD:coinbase/BTC-USD"` metadata on `commodity` directives), fetches each quote through `beanprice`'s source modules, and appends the result through the same exact-match dedup that `bea add price` already implements, honoring the `--json` / `--no-input` automation contract.

## Context

- `cli/src/cli/commands/add.py::add_price` appends a `Price` directive and reports `written: 0, duplicate: true` on an exact date/commodity/amount match anywhere in the root file (see `cli/docs/USAGE.md`, "Adding directives"). Reuse its writer path; do not duplicate the dedup.
- bean-price's metadata grammar: comma-separated `CURRENCY:SOURCE/TICKER` entries, `^` prefix inverts the quote. Follow it exactly so a ledger works with both `bean-price` and `bea`.
- `beanprice`'s public functions for building jobs from directives and fetching at a date are the integration point; verify the exact names against the installed version at task time and pin what the code relies on in a comment.
- Commands register in `cli/src/cli/main.py` under `_LOCAL_PANEL`; a `price` Typer sub-app with `fetch` (and later `sources`) matches the `add` / `list` layout.
- Exit-code contract in `cli/docs/USAGE.md`: `0` success, `1` validation, `2` usage. A run where some sources fail still writes the successes, reports each failure, and exits `1`; nothing written on network failure is not a `4`.

## Steps

1. Create `cli/src/cli/commands/price.py` with `price_app` and `fetch`; options `--date` (default today), `--commodity/-c` (repeatable filter), `--dry-run`, plus the global `--file` / `--json` / `--no-input` behavior.
2. Load the ledger, collect `commodity` directives with `price:` metadata, build fetch jobs through `beanprice`, fetch with a bounded timeout, and route each successful quote through the existing add-price writer.
3. Emit a per-commodity result (`fetched` with amount and source, `duplicate`, or `failed` with the reason) as a table in human mode and one JSON object in `--json` mode; `--dry-run` prints the would-be directives and writes nothing.
4. Register `price_app` in `main.py`; run `make docs` so `REFERENCE.md` picks it up.
