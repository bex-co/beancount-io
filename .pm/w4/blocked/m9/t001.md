## Objective

Make upstream `beanprice` available to `bea` as an optional extra named `price`, mirroring how the `ask` extra keeps LLM clients out of the default install, so the price verbs can import it and fail with a clear `usage` error when it is absent.

## Context

- `cli/pyproject.toml` already has `[project.optional-dependencies] ask = [...]`; the dev dependency group installs `beancount-io[ask]` so tests can import it.
- `cli/src/cli/commands/ask.py` catches `ImportError` and raises `UsageError(_MISSING_EXTRA)`; that is the pattern to reuse (exit code 2, `usage`).
- `docs/adrs/ADR012-cli-beangulp-not-a-hard-dependency.md` records why heavy or native dependencies stay out of the default install. `beanprice` is pure Python (requests, python-dateutil, beancount); confirm its runtime dependency list at task time and record it in the same ADR style if anything native appears.
- Never hand-edit `cli/uv.lock`; run `uv lock` / `uv sync --all-groups` from inside `cli/`.

## Steps

1. Add `price = ["beanprice>=<current release>"]` under `[project.optional-dependencies]` and `beancount-io[price]` to the dev group.
2. Add a small probe helper (for example `cli/src/cli/prices.py`) that imports `beanprice` lazily and raises `UsageError` with the install hint `uv tool install "beancount-io[price]"` / `brew` note, using the same wording style as `ask`.
3. Run `uv lock` and `uv sync --all-groups` inside `cli/`; commit the lockfile diff.
4. Verify a default install (`uv pip install .` without extras in a scratch venv under `cli/tmp/`) does not pull `beanprice`.

## Files

- `cli/pyproject.toml`, `cli/uv.lock`
- `cli/src/cli/prices.py` (new) or the module the team prefers for optional-dependency probes

## Acceptance criteria

- [ ] `uv run python -c "import beanprice"` succeeds with `--all-groups`; a no-extras install has no `beanprice` package.
- [ ] Calling the probe without the extra raises `UsageError` whose message names the extra and the install command.
- [ ] `make check-all` passes.

## Out of scope

- Any fetching behavior (t002).
- Making `beanprice` a hard dependency.
