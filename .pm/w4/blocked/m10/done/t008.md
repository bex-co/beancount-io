## Objective

Add a path-filtered CI check that keeps the issue forms valid and the community files' internal links resolving, so a later edit cannot silently break the front door.

## Context

- `.github/workflows/ci-agent-guidance.yml` and `scripts/check-agent-guidance.py` show the pattern for a small Python validator behind a path filter.
- GitHub issue forms need `name`, `description`, `body` with at least one non-markdown element, and every `id` unique; validate those keys and that each `labels:` entry exists in the repository label list committed alongside the check.

## Steps

1. Write `scripts/check-github-community.py`: parse every `.github/ISSUE_TEMPLATE/*.yml`, check the required keys and unique ids, and resolve relative links in `SECURITY.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and `.github/pull_request_template.md`.
2. Add `.github/workflows/ci-community-files.yml` filtered to those paths.
3. Prove the check fails on a form with a duplicate id and on a broken link, then restore.

## Files

- `scripts/check-github-community.py` (new), `.github/workflows/ci-community-files.yml` (new)

## Acceptance criteria

- [ ] The check fails on a deliberately broken form and link, and passes on `main`.
- [ ] The workflow runs only when the covered paths change.

## Out of scope

- Validating the rendered GitHub UI.

## Validation evidence

- Shipped in `dbb1e763`: `scripts/check-github-community.py` validates every issue form (required keys, supported field types, unique ids, markdown values, dropdown options, known labels), the chooser `config.yml` (boolean `blank_issues_enabled`, https contact links), and relative links in `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, and the PR template. YAML is parsed with Ruby's standard library, so no dependency was added.
- Passes on the tree (`GitHub community files OK (4 issue forms).`, exit 0). With a duplicate `id` in `bug.yml` and a broken relative link in the PR template it exits 1 naming both (`body[5] repeats id \`reproduction\``, `broken link \`../docs/does-not-exist.md\``); restored, it passes again.
- `.github/workflows/ci-community-files.yml` runs only on changes to the issue forms, PR template, community guides, the script, or the workflow. `CI (community files)` passed on `dbb1e763`: https://github.com/bex-co/beancount-io/actions/runs/34912164333.
