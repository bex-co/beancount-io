## Objective

Add meaningful tests using the actual router hash shape for query-plus-fragment and fragment-only paths, encoded fragments, empty fragments and unsafe continuations. Exercise emitted Star/Follow targets and guard results.

## Context

See [FINDINGS.md](./FINDINGS.md) for reproduction, source and evidence limits.

## Acceptance criteria

- [x] Tests fail against the current malformed targets, pass the repair, and retain unsafe-next rejection; run dashboard native checks.

## Out of scope

Backend/API changes, authentication policy changes, new dependencies and unrelated login defects.

## Outcome

Added `login-continuation.test.tsx`: nine cases driving an **actual** TanStack
router — memory history, real route tree, real parser — because the defect was
never in validating a `next` string but in building one. Handing a ready-made
string to the producer cannot see a delimiter that was dropped while
assembling it, so each case navigates to a URL and reads the `next` that
reached `/auth/login`, through both routes a visitor can take: a guest action
on a public page calling `useLoginNextPath`, and a guarded route whose
`beforeLoad` is `requireAuth`.

Cases: query plus fragment; fragment with no query; plain path; query only; an
encoded fragment, asserted by parsing the emitted URL back and requiring its
`&` to stay in the fragment rather than leak into the query; an empty fragment,
which must not invent a trailing `#`; a guarded route's query and fragment; a
guarded plain path; and a signed-in visitor passing straight through.

Proved load-bearing by restoring the original
`pathname + searchStr + hash` concatenation: **4 of the 9 fail** — precisely
the four fragment-bearing cases — while the five controls keep passing, which
is what makes them controls. Restoring the repair passes 9/9.

Also extended `auth.test.ts` (now 23 cases) at the guard's new entry point:

- an unsafe continuation is dropped whole and the configured fallback is used
  instead, across protocol-relative, absolute, backslash and control-character
  forms — the w3/170 rejection contract, re-asserted through `getSafeReturnPath`
  rather than only through `getSafeRedirectPath`;
- a fragment survives into the guard's continuation, which the previous fixtures
  never covered because they all passed `hash: ""`.

Gates from `dashboard/`: `yarn format:check`, `yarn lint`, `yarn test` (378
files, 4264 passed, 1 pre-existing skip) and `yarn build` all pass. `gitleaks`
reports no leaks in `dashboard/src`.
