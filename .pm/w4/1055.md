## Cause and bounded repair

`dashboard/src/features/ledger-data/commodities/commodity-price-history.tsx:72–80` puts raw price.value directly in its right-aligned TableCell. It inherits the Persian paragraph direction, which reorders the weak leading minus. The sole production caller is Commodities at index.tsx:230; the history table is a sibling of CommodityChart. Therefore1018's existing LTR chart-container repair cannot fix this table, and it should remain closed.

Wrap the exact price text in the existing `common/components/amount.tsx` Amount component, or the same bounded LTR isolated numeric run. Keep the raw source decimal text and its trailing zeros, monospaced/tabular styling, localized date/price headings, RTL page/card layout, table identity and keyboard disclosure. Do not change formatting precision, transpose columns, force the whole card/page LTR, change API results or add a dependency.

Acceptance: the real rendered history table in fa/en retains a leading sign for both negative fixture values at narrow/desktop widths, with exact positive/zero/trailing-zero controls and working show/hide focus. Cover the actual history numeric cell meaningfully; preserve the existing history table/identity tests and run dashboard format, lint, test and build when implementing. The parent QueryView's loading/empty/error behavior is unchanged and was not fault-tested in this cycle. QA authored no product fix or formal tests.
