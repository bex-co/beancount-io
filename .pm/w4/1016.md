## Cause and bounded repair

`dashboard/src/features/ledger-data/events/index.tsx:117` defines `typeLabel = type => type || t("page.events.emptyType")`. A nonempty whitespace string is truthy, so it bypasses the empty-type label and renders only whitespace in the trigger and menu item. Those are its two callers; neither supplies another accessible name. CSS whitespace handling and accessible-name normalization leave the controls unnamed.

The same helper returns printable authored strings unchanged. English `page.accounts.allTypes` is `All Types` and `page.events.emptyType` is `(no type)`, so the two authored strings above share the global and synthetic-empty labels despite having different underlying values.

Provide visible and accessible presentations in both callers that distinguish authored types from the global action and synthetic empty/whitespace representations, preserving the original string for keys and exact filtering. Keep empty, one-space and other whitespace identities distinguishable if they coexist; an escaped/code-point representation with appropriate localized context is one bounded option. Merely choosing another magic display label moves the collision to another valid authored string. Do not trim/rename stored event types, merge options, reject valid ledger data or replace null with an authored-string sentinel. Preserve 271's working `all`, empty-string and ordinary-type filtering, search composition, sorting/counts, shared-filter reset and current read retry. No API, dependency, cross-package import or global menu change is needed. Add any new user-facing message in all supported locales.

Acceptance: real Events/menu regressions with ordinary, empty, single-space, tab, literal `All Types` and literal `(no type)` types expose meaningful distinct option/selected-button names and retain exact row filtering. Native desktop/narrow selection of the single-space type remains usable and named. With the four-record collision fixture, each authored choice returns its corresponding single row and the distinct global action returns all four; their presentations identify those different scopes/identities. Preserve the existing table and request/error behavior, and run dashboard gates when implementing. Tabs/other whitespace are regression scope, not additional live reproductions. QA authored no product fix or formal tests.
