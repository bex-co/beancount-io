## Producer and source

The ledger producer `backend-cluster/ledger/src/foundation/rustledger/account-tree.ts:111–122` explicitly stores direct postings in balance and rolls them into balanceChildren at every ancestor. The response already contains the necessary correct units and amounts; no backend/REST/GraphQL/MCP repair is indicated.

`dashboard/src/features/reports/overview/lib/sankey-data-transformer.ts:34–46` picks USD or the first arbitrary unit and discards the unit identity. `aggregateHierarchyBalance:52–63` only reads a node's own balance when it has no children; otherwise it sums children starting from zero. This drops valid parent postings, even with an empty child. `extractNodesAtDepth:103–118` also traverses only children above the target depth, so repairing only the aggregation base case is insufficient for all supported depths. Downstream totals, link widths and Savings use the scalar values. `components/cash-flow-sankey.tsx:111–114` appends literal USD to every edge tooltip. These lines originate at af5339de;47672769 added shared cash-flow-role resolution without repairing them. The existing nested aggregation test has no node with both a direct balance and descendants.
