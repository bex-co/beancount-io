# Half-translated messages remain in the Bulgarian, Persian, Korean and Chinese catalogs

Severity: minor localization defect. Estimate: ~40m, dashboard. A2/A3: four
more locales show labels that are words in neither language.

Found by the all-locale guard shipped for `w4/m24/t010`
(`dashboard/src/test/locale-stray-english.test.ts`), which scans every locale
whose script is not Latin for a message written in its own script that still
carries an English word. The guard lists each of these as a named deviation
pointing at this note, so repairing them shortens that list.

Thirteen messages, by locale:

- **zh (9)** — `page.accountReport.accountBalance` = `账户 Balance`,
  `accountJournal` = `账户 Journal`, `title` = `账户 Report`,
  `noJournalEntriesForAccount` = `未找到日记账条目 for this account.`,
  `page.holdings.noDataReturnedFromQuery` and `page.bql.noDataReturnedFromQuery`
  = `无数据 returned from query`, `page.statistics.noDataAvailableForQuery` =
  `无数据 available`, and both `page.overview.starButton` messages, which begin
  with an untranslated `Ledger`.
- **bg (2)** — `seo.welcome.description`, English after its first two words;
  `page.overview.starButton.unstarSuccess` = `Ledger премахна успешно звездата`.
- **ko (1)** — `page.overview.starButton.starSuccess` = `Ledger가 성공적으로 주연을
  맡았습니다.` The English `Ledger` is the visible defect; the Korean also reads as
  "took the starring role", which is a separate mistranslation of "starred".
- **fa (1)** — `seo.welcome.description`, same shape as Bulgarian.

Two keys are damaged in several locales at once — `seo.welcome.description` in
bg, fa and ru, and the `page.overview.starButton` pair in bg, ko, ru and zh —
so they are worth fixing together across all of them rather than locale by
locale.

Repro: run `yarn vitest run src/test/locale-stray-english.test.ts` from
`dashboard/` after deleting the relevant entry from `KNOWN_DEVIATIONS`; the
suite names the offending key and the stranded words.

Acceptance: these thirteen are translated, their entries are removed from
`KNOWN_DEVIATIONS`, and the guard still passes — its "keeps every known
deviation real" case fails if a key is left listed after being fixed, so the
list cannot go stale. English and the other locales are unchanged. Run the
dashboard gates.

Not in scope: the thirty Russian ones, which are `w4/153`, and the Latin-script
locales (ca, de, es, fr, nl, pt, sk), which this technique cannot check at all —
a stray English word there is indistinguishable from the target language by
script.
