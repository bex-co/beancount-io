**Minor · 25–40m · dashboard · A2/A3.** Rare accepted-date arithmetic error; residual of [277](./done/277.md)'s `Date.UTC` year-remapping class in a different helper. A quote dated **0099-12-30** is incorrectly fresh at **0100-01-31** because its calculated age is **−693,928 days**, rather than32. Amounts and displayed dates are correct.

## Cause and bounded repair

`dashboard/src/features/reports/overview/lib/net-worth-valuation.ts:87–92` parses the four-digit date, then calls `Date.UTC(Number(year), …)`. JavaScript remaps years0–99 to1900–1999. The valid quote0099-12-30 therefore becomes1999-12-30 internally, but reference date0100-01-31 stays in year100; their subtraction is−693928days. The native label is separately formatted correctly, which is why the stale status contradicts the date shown beside it.

The private helper is used only by this valuation module: `priceCadenceDays` at141–142, reference day at248 and quote day at262. Overview is the production owner of the exported selector. Both authored cadence and managed-age comparisons must preserve calendar years; native managed feeds were not exercised.

The actual native contexts loaded `ledger._ledgerOwner._ledgerName.index-Dt5Wt5tH.js`. Its complete `dayNumber` block equals current main `4462dad68`, working source and fetched main (SHA-256 `a797f1fb9949da8f5980d081b83c80dbaa409dd087c1d5e1442fe2cc6ff87c72`). Whole modules differ due to other fixes; no whole-build match is claimed. Direct execution of the complete current module reproduces the classification and negative age. Targeted history dates this constructor to `be8e9eba2`.

Build the UTC day count without the0–99 remapping, for example using `setUTCFullYear` on a UTC-backed date. Preserve the ISO-string input/fallback behavior, cadence median/window, thresholds, historical point reference and future-period cap at today. Do not change prices, amounts, timezone preferences, freshness policy or display labels. No API, backend, dependency or translation change is required.

Acceptance: both early-century native layouts show the January stale count/date and holding status, while December and the1999/2000 control keep their existing behavior. Meaningful selector regressions cover the0099→0100 age, cadence across that boundary, valid early leap dates and ordinary/managed thresholds; they fail on the old constructor. Run dashboard gates and distinguish a local repair from deployed behavior.
