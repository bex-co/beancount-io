## Objective

Replay public Budget, Commodities, Statistics and Settings at narrow and desktop widths; inspect native accessibility trees. Check owning documentation and root package tables for drift; no new feature documentation or skill is required.

## Context

See [FINDINGS.md](./FINDINGS.md) for reproductions, source, controls and evidence limits.

## Acceptance criteria

- [x] Names identify the visible data in all four public journeys; unchanged documented workflows remain accurate.
- [x] Record any actual screen-reader coverage separately from DOM/native-AX inspection.

## Out of scope

API/data changes, global Table defaults, new dependencies, unrelated control labels and a broad accessibility redesign.

## Outcome

Replayed all four public journeys at 1440x1000 and 390x844 against a production
build, reading Chromium's accessibility tree over CDP. 32/32 naming checks plus
14/14 journey-control checks.

Names identify the visible data in every journey:

- Budget — seven distinct names, and they survive a real filter change: after
  narrowing the interval filter to **Monthly**, all seven tables are still
  present, still named and still distinct. (A first version of this check never
  actually clicked the filter — the page uses buttons, not a select — so it was
  only re-reading the same state; it now presses the real control.)
- Commodities — `ACME/USD` and `BMKT/USD` open by keyboard (`Enter` on the
  disclosure, the deliberate alternative from w3/051), and the names are still
  correct and distinct after closing and reopening one.
- Statistics — three distinct names, with 41 account links still reachable
  inside the tables.
- Settings — `Beancount Options` and `Fava Options`.

FINDINGS' controls all still hold: no Delete control is exposed to the public
budget reader, the Insurance card and its 600 figure are present, commodity
price precision is unchanged (`2024-01-01 / 61.40 / 2024-04-01 / 64.90`), and
the Settings page exposes zero inputs, textareas or selects to an anonymous
reader, with only the two intended sections rendered.

Documentation checked for drift: the root `README.md` package table,
`dashboard/README.md` (its only Budget/Settings mention is the signed-in API
credentials flow, unaffected), `dashboard/docs/` and the skill catalogs. No
documented workflow changed, and no new feature documentation or skill was
needed.

One doc change was warranted rather than skipped: `features/ledger-data/AGENTS.md`
had no table-naming contract, while `features/reports/AGENTS.md` documents
exactly this for its hierarchy tables. Added a **Table Names** section recording
the convention, why the currency belongs in a budget name, and the trap this
milestone actually hit — that a component's loading and empty branches render
their own copies of the heading, so the id belongs on the one beside the table.
`python3 scripts/check-agent-guidance.py` passes (17 canonical scopes).

Screen-reader coverage, recorded separately as the acceptance requires: **none
was exercised.** Every result above is native accessibility-tree metadata and
DOM association. No assistive-technology speech or shortcut behaviour is
claimed.
