## Objective

Add a `units_by_cost` conversion keyword that reduces each lot inventory to units keyed by commodity and cost currency.

## Context

- `backend-cluster/ledger/src/foundation/rustledger/lot-inventory.ts`: lots carry `currency`, `costNumber`, `costCurrency`; `valueLot` maps a lot to `[key, amount]` and `reduceScaled` sums by key, so the new case returns `[`${currency} {${costCurrency ?? ""}}`, units]` at the units' written scale.
- `parseConversion` and `cost-valuation.ts` `resolveConversion` list the reserved keywords; the refusal message names them.
- Consumers: `account-tree.ts` and `interval-series.ts` (balance sheet, income statement, trial balance, interval totals, account report). The journal running balance has its own conversion handling and is out of scope.

## Steps

1. Add the keyword to `Conversion`, `parseConversion`, `resolveConversion` and its error text.
2. Implement the `valueLot` case with the written scale.
3. Unit tests for the m58 fixtures, mixed-cost lots of one commodity, cash sharing a cost currency, time scoping and filters.

## Files

- `backend-cluster/ledger/src/foundation/rustledger/lot-inventory.ts`, `cost-valuation.ts`, tests
