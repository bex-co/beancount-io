## Cause and repair

`dashboard/src/features/ledger-data/budget/delete-budget-dialog.tsx:107–112` passes `target.interval.toLowerCase()` into the translated `page.budget.budgetDeleteDescription`. This lowercases the stored English protocol cadence; it never translates it. All15 Budget locale catalogs interpolate `{interval}`. All15 already have localized cadence labels used by `budget-history-table.tsx:49–57`, explaining why the correct row label changes back to English inside its confirmation. The14 non-English catalogs share this source path; only German and Persian were asserted natively here.

Supply a cadence phrase translated for each confirmation's grammar, through per-cadence messages or dedicated localized adjective keys. Do not blindly lowercase picker labels: grammatical agreement can differ. Keep locale-key parity, existing English text, exact amount/account/date identity and the selected directive hash. Use a safe readable fallback if an unknown cadence reaches the existing dialog. No stored directive, API enum, financial calculation, dependency or other package needs changing.

Acceptance: real DeleteBudgetDialog descriptions for all five cadences use appropriate localized language in German and Persian, with locale parity across the supported catalogs and an unchanged English control. Repeat native opening/cancellation at both widths and keep1080's focus repair separate. Run dashboard gates on implementation. Native review of the other12 non-English locales, expert translation review, other engines and actual deletion remain unverified.
