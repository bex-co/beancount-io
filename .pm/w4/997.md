# Select an available unit when stacked charts lack the operating unit

**Severity:** minor. **Estimate:** 30–45 minutes. **Owner:** dashboard. **A2:** a populated report must not initially hide every series merely because the current scope contains no operating-currency amounts.

## Reproduction and controls

Production `https://beancount.io`, 2026-10-22; owned isolated headless Chromium 155.0.8059.85, anonymous public `open_ledger/example`, English/light, fresh 1440×1000 and 390×844 contexts. Genuine reads only; no response fixtures, mutations or hosted writes.

The ledger declares operating currency **USD**. Its real BQL control returns `2016-11-29 / Expenses:Vacation / 104 / VACHR`. Scope both the date and account: using only the date also includes unrelated USD purchases, and using only the account over the full year includes USD payroll. Those broader scopes do not demonstrate the defect.

1. Open `/ledger/open_ledger/example/cash-flow?time=2016-11-29&account=Expenses%3AVacation&view=byActivity`. The chart is blank with a grey **VACHR** legend, although its three real series contain operating **-104**, investing **+104**, financing **0 VACHR**. Both the input option and mounted ECharts legend are `{VACHR:false}`.
2. Click the native canvas legend's VACHR item. Its state becomes `{VACHR:true}` and both activity bars appear. Every series value remains identical and no new GetLedgerCashFlow is sent. This is initially hidden data, not an empty report or failed read.
3. Open `/ledger/open_ledger/example/income-statement?time=2016-11-29&account=Expenses%3AVacation&view=expenses`. The default **Stacked Bars** likewise hides its sole **104 VACHR** series with `{VACHR:false}`.
4. Select **Single Bars** without first enabling that legend. The same 104 VACHR is selected and shown automatically. Return to Stacked Bars: it starts hidden again. A native VACHR legend click restores the stacked bar without changing its data or sending another Income Statement read. Both fresh widths reproduce both chart failures and controls.

Separate normal 1440px controls with Time 2016 and no account restriction contain USD/IRAUSD/VACHR. Both stacked views correctly start with USD selected and the other units unselected, with twelve periods of nonzero USD data. Preserve that useful preferred-unit default and the reader's ability to toggle units manually.

## Cause and bounded repair

`dashboard/src/features/reports/cash-flow/cash-flow-charts.tsx:250–264` and `income-statement/date-balance-chart/stack-date-balance-chart.tsx:174–182` build the initial legend selection with `unit === primarySeries`. When the only available unit is VACHR and primarySeries is USD, every entry becomes false.

The adjacent NetCashFlowChart, SingleDateBalanceChart and Balance Sheet LineChart already use the intended fallback: prefer the operating unit when present, otherwise select the first available unit. The Single Bars browser control demonstrates that fallback on this exact dataset. Apply the same initial-selection behavior in the two stacked builders. Do not invent a USD series, relabel or convert VACHR amounts, select no unit by default, force every unit on, or re-enable units after the reader deliberately turns them off.

ActivityBreakdownChart has one production owner, CashFlowContent. StackDateBalanceChart is selected through DateBalanceChart for both Income Statement Income and Expenses modes; Expenses is live-reproduced, while the Income caller is source-traced only. Preserve activity/account stacking, series order and colors, signs, plotted zeros, filters, interval/conversion controls, readable period alternatives and exports. Coordinate the same Cash Flow file with [996](./done/996.md), which supplies missing text alternatives; a table does not repair this blank default chart. No API, dependency or backend behavior change is needed.

Acceptance: meaningful rendered builder regressions cover a declared USD operating unit absent from nonzero VACHR/EUR data, an available operating unit, multiple available fallback units, empty input and manual legend toggling. Exercise both actual stacked builders and their Income/Expenses callers, preserve working Single/Net/Balance Sheet behavior, repeat desktop/narrow and run dashboard gates when implementing.
