# Revealing a statement row's extra units also collapses its account branch

Severity: **minor**. Estimate: **30–45 minutes**, dashboard only. A2 — readers inspecting a multi-unit example should keep the account hierarchy they are reading when revealing hidden amounts.

## Live reproduction

Production `https://beancount.io`, public synthetic `open_ledger/example`, authenticated QA with read-only access, English/System, owned headless Chromium **149.0.7827.55**. Fresh 1440×1000 and 390×1000 loads reproduce. Local main **1f56c700** retains the cause; deployed full SHA/bundle identity is unverified.

1. Open `/ledger/open_ledger/example/balance-sheet?time=2017-09`. Select **Units** through Select conversion and wait for the report to settle.
2. In **Assets List**, expand `Assets` and `Assets:US` if needed. The table has **19 header-inclusive rows**, including Checking. The `Toggle children of Assets:US` control is expanded; its `All amounts for Assets:US` control is compact (`+4 more`).
3. Activate **All amounts for Assets:US** by keyboard Enter. The amount control becomes expanded and displays all seven non-primary commodities, but the independent account expander becomes **false**, Checking disappears, and the table drops to **3 rows**.
4. Click the same amount control again (visibly Show less, with the same accessible name). It becomes compact while the account branch unexpectedly reopens, restoring **19 rows**.

Both viewports repeat the exact `19 → 3 → 19` result on fresh loads. The action produces no new browser exception. The totals remain correct: 3,609.87 USD and the seven other units; this is unintended hierarchy toggling, not a financial-calculation defect or missing API data. No production writes were performed.

Working control: after the page has settled, use the dedicated account expander alone. It correctly collapses/reopens the branch while preserving both amount cells. The amount disclosure should likewise change only its own expanded state.

## Cause and repair

`dashboard/src/features/reports/balance-sheet/hierarchy-list.tsx:141` toggles `OtherBalancesColumn` through a button whose click does not stop propagation. The enclosing tree row at **line 218** handles every bubbled click by toggling its account. The existing dedicated account expander at **lines 234–237** and account link at **line 258** already stop propagation, demonstrating the correct local event boundary. Summary rows have no row-level toggle, so that caller lacks the interfering handler.

Stop the extra-unit button's click from reaching the tree-row handler while keeping pointer and keyboard activation, accessible name/state, inline amounts, focus, compact threshold, ordinary row clicks, dedicated expanders, and account navigation. Do not remove the row-click behavior or change totals, exports, API payloads, currencies or layout to mask this interaction.

Acceptance: with a real expandable parent and visible descendant, revealing and hiding extra units keeps `aria-expanded` on the account expander true and leaves descendants visible. Pointer click and keyboard Enter work; all formerly hidden amounts remain reachable. Dedicated row/expander collapse still works, and a summary-row disclosure remains usable. Add a meaningful regression that asserts the child stays visible through both activations; a leaf-only or amount-only test cannot catch this bubbling. Run dashboard format/lint, tests and build when implementing.

The shared HierarchyList is used by Balance Sheet, Income Statement and Cash Flow through `balance-sheet/hierarchy-list-card.tsx`, and directly by Trial Balance. Only the Balance Sheet parent-row case is live-reproduced here; the sibling routes are source-traced scope.
