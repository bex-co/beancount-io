Typing no longer reaches the editor; native Tab restarts at **Skip to main content** instead of continuing in the entry workspace. The draft itself remains intact.

This composition has no trigger, so it focuses nothing. The retained editor and BODY → Skip-link native trace agree with that missing caller-owned return target.
