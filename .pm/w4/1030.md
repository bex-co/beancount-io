# Keep parent accounts' own balances in Overview cards and distributions

**Minor · 45–60m · dashboard · A2.** Residual of [m21](./done/m21/README.md): the shared leaf-only traversal drops direct balances on any account with children. Accounts can falsely say **“No accounts found”**, and both distributions can falsely say **“No Data Available”**, beside a correct nonzero Net Worth. Populated children then receive100% of a distribution that omits their parents.

1. Open Overview, set Time **2026-05**, and inspect Financial position and the Balance Sheet distributions.
2. Set Time **2026-06**, then open both native Breakdown disclosures.
3. Return Time to **2026-05**.

Net Worth correctly reads20.00USD, but Accounts says **No accounts found** and both distributions say **No Data Available**. Returning from June repeats the same false empty state.

The correct direct-account composition is Wallet100 + Savings25, and Card80 + Fees5 after the distribution's existing liability inversion. No account should contribute its rolled-up subtree a second time.

## Cause and bounded repair

`dashboard/src/features/reports/overview/lib/overview-utils.ts:211–229` defines `flattenHierarchy`: if a node has children, it traverses them and never retains that node. Its only two production callers are `buildAccountBalanceRows` at232–281 and `buildDistributionData` at523–560. Both subsequently read **own `balance`**, so dropping an internal node discards real holdings even when all its children are zero. AccountBalancesCard sorts/slices the resulting rows to seven; DistributionChart builds pie/bar data and Breakdown from the resulting slices. Both asset and liability paths are affected.

The complete served traversal and both caller blocks in `ledger._ledgerOwner._ledgerName.index-Dt5Wt5tH.js` equal current main `a4b97052f` and working source. Traversal SHA-256 `7a7804666a4cb2532e3344e054be10d932b9eb4125298bba3604732a3b88f328`; the two caller hashes and source maps are retained locally. Whole utility modules differ due to other fixes; no whole-build match is claimed. The traversal dates to `af5339de0` and is unchanged in the m21-era `73829285a` version and fetched main.

Traverse every real node and retain each nonzero **own balance** exactly once, including internal nodes and roots with direct postings. Do not substitute `balanceChildren`, which would double-count descendants. Preserve the top-seven ordering, real account identities/navigation, existing liability sign policy, per-unit model/disclosure and operating-unit choice, negative-value bar fallback, Other grouping, exact amount text and genuine empty states.
