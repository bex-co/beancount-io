# Dismiss combobox suggestions with Escape without submitting the filter draft

Severity: minor keyboard interaction defect; dismissal can replace a valid report with an invalid-input error. Estimate: 50m, dashboard. A2: readers should be able to dismiss suggestions and continue editing without accidentally applying an unfinished filter.

Environment: production https://beancount.io, anonymous synthetic open_ledger/example, isolated headless Chromium149.0.7827.55, English/light390×844 and fresh1440×1000. Local/fetched main26d54a9db7d33c31a549bd12a0454a1c01f3f038; deployed main-BIr0jJni.js, exact deployed SHA unverified.

Repro: start Overview with Time2016. Narrow: open Filters; desktop: use the header Time combobox. Replace its text with `2026-02-30`, then press Escape while its suggestions popup is open. The draft is committed to `?time=2026-02-30`, focus becomes BODY, and the report shows Error loading data with the invalid-information explanation. Both widths independently reproduce. An earlier narrow blank→2016 draft also committed on Escape, so the behavior is not restricted to invalid text. No Enter or suggestion activation occurred.

Expected: Escape dismisses the open popup and leaves editing focus in the combobox, without invoking its apply callback or changing the report URL/data. Keep the draft available for continued editing; do not make this an arbitrary global rollback of already-applied values. The [WAI-ARIA combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) describes Escape as popup dismissal and focus retention/return, distinct from Enter accepting a suggestion.

Root: `dashboard/src/common/components/ui/combobox.tsx:132–137` explicitly calls inputRef.current.blur() in its Escape branch after closing the popup/resetting the highlight. handleInputBlur at120–127 applies inputValue when triggerOn=blur. All three LedgerSearchControls fields select that mode at188/199/210. Thus keyboard dismissal is converted to a normal blur commit. Unlike explicit selection/Enter, Escape does not set skipBlurCommitRef; simply adding a skip flag while still discarding input focus would leave half the defect. Keep the repair in the shared combobox's dismissal/focus behavior and preserve popup layering inside the filter sheet.
