## Adoption verification

Completed 2026-09-19. The repaired Catalan journey was exercised live rather than inferred from the catalogs: a local production build served the dashboard while anonymous read-only reads of the public `open_ledger/example` ledger came from the public Beancount.io API on one origin. 30 checks ran in fresh isolated headless Chromium contexts at 1440x1000 and 390x844; all 30 passed.

Direct `lang=ca` links land on a usable Journal at both widths. Every control the QA run reported now names its own concept: Obrir, Nota, Metadades, Apunts, the Beneficiari/Descripció column header, and the accessible names Transaccions pendents, Altres transaccions and Documents vinculats behind the literal !, x and V flags. Clear all reads "Esborrar tot", the shared payee/tag placeholder reads "Filtrar per etiqueta, beneficiari, ...", and the sidebar Overview destination reads "Resum general". None of the seven reported unrelated validation or loading sentences appears on any label, title or placeholder. At 390px the sidebar and the Filtres sheet both open and carry the same repaired strings.

The controls still perform their own actions. Selecting Obrir and deselecting Transacció sends `directiveTypes: ["Open"]` with `time: "2016"` and returns 53 entries, matching the recorded fixture exactly. Clicking Esborrar tot drops `time` from the URL and restores 1,044 transactions with Transaction selected. An English control at both widths still shows Open, Note, Metadata, Postings and Overview, so the repair did not touch English. Persisted directive selections still survive a reload, which is why the Clear all journey runs in its own fresh context.

Documentation was reviewed for drift with no change required. `dashboard/AGENTS.md:100-104` describes where feature and aggregate locales live, how to add keys and that `src/test/translations.test.ts` checks locale *shape*; all of that remains accurate, and this milestone changed values rather than structure, keys or tooling. `dashboard/README.md` mentions locale splitting and the supported-language count, both unaffected. No root README/AGENTS package table, skill catalog or guidance symlink changes, because no package, skill or setup variable changed. One accurate gap is worth recording rather than editing around: the existing shape checks cover structure, interpolation, cross-language key parity and namespaces, but nothing asserts that a value means what its key names — which is exactly why this defect shipped. Closing that gap is t005's regression work.

Follow-up recorded rather than silently expanded: `common.directivesLimitApproaching` and `common.directivesLimitReached` are still untranslated English in Catalan. That is a translation gap, not a wrong key-to-meaning association, so it stays outside this milestone.
