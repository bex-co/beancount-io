## Implementation and verification

Completed 2026-09-19. Auditing the whole namespace against the keyed English source, as FINDINGS asks, showed the reported keys are part of one contiguous run of misassigned values in `dashboard/src/i18n/locales/common/ca.ts`: each key in the run carries the Catalan written for a neighbouring concept, while every `description` still matches its own key. 24 messages were reassigned to the concepts their keys name.

Overview is now "Resum general" instead of a missing trial-balance sentence; the payee/tag placeholder is the instructional "Filtrar per etiqueta, beneficiari, ..." instead of an overview load-error; and Clear all is "Esborrar tot". The same run also held At Cost, At Market Value, Balance Sheet, Converted to, Daily, Quarterly, Error loading data, Failed to load filter options, Income Statement, Net Profit, Net Worth, No accounts found, No Data Available, No matches found, Please try again later, Search accounts..., Select conversion, Select time period, Time, Trial Balance and Type to search..., all repaired in the same pass.

Wording was grounded in the sibling es, fr and pt catalogs for every key rather than invented. Two candidates were deliberately left alone after checking those siblings: `common.actions` reads "Transaccions" in Catalan, but es, fr and pt all use their own word for Transactions on that key, so it is a shared product choice rather than Catalan damage; and `common.directivesLimitApproaching` and `common.directivesLimitReached` are untranslated English in Catalan, which is a translation gap rather than a wrong key-to-meaning association, so they are recorded here as follow-up rather than swept into this repair.

Only the catalog changed. The consumers named in FINDINGS already pass the right keys — `common/components/ledger-search-controls/index.tsx:171,206` and `common/components/ledger-layout/ledger-sidebar.tsx:128` — so no route, filter, permission or API behaviour changed. A placeholder-parity check across all fifteen locales in both catalogs reports no interpolation drift, and the other fourteen locales show no misassignment of this kind.

Gates from `dashboard/`: `yarn format:check`, `yarn lint` (tsc, ESLint, Knip), `yarn test` (374 files, 4,190 passed, 1 pre-existing skip) and `yarn build` all pass. gitleaks reports no leaks in the changed tree.
