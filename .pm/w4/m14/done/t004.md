## Simplify review

Completed 2026-09-19. Ran `/simplify` over the milestone's changed code — `dashboard/src/i18n/locales/common/ca.ts` and `dashboard/src/features/journal/locales/ca.ts` as changed by bb4dd35d and 7ac03105 — across the four standing angles. Three came back clean; one found a real regression this repair introduced, which is now fixed.

**Fixed.** `common.netWorth` had been given "Patrimoni net", the string `common.equity` already carries, collapsing two distinct concepts into one label. This is not cosmetic: `features/reports/balance-sheet/balance-sheet-content.tsx:83,86` builds a single tab selector containing both, so a Catalan reader saw two identical entries and could not tell which tab they were choosing, and lines 225 and 280 then render both as sibling `<h2>` headings. Every locale except a pre-existing ja collision keeps them apart (en Equity/Net Worth, es Patrimonio/Patrimonio Neto, fr Capitaux propres/Patrimoine net, de Eigenkapital/Nettowert, nl Eigen vermogen/Netto vermogen, sk Vlastné imanie/Čisté imanie). `common.equity` now reads "Fons propis", the standard Catalan accounting term, and `common.netWorth` keeps "Patrimoni net". This is the one key touched that was not part of the original corruption; it is changed here because the collision was introduced by t001, not inherited.

**Clean, with evidence.** Reuse: no translation helper, framework, dependency or runtime mechanism was added — the diff is string literals only, and the six other newly-identical pairs (page name vs related-links nav, narration placeholder vs narration) are identical in en, fr and pt too. Simplification: no stranded values from the original corruption remain, key order is byte-identical, key sets still match en exactly (107 journal, 210 common), and literal flags stayed literal — "x" and "!" match every locale, and "V" follows the localized-initial convention pt, nl, bg and uk use. Efficiency: data only, no runtime work; the two files shrank by 612 raw / 150 gzip bytes, and Catalan is lazily imported (`src/i18n/init.ts:13`) so it contributes nothing to the tracked initial-JS budget, which `scripts/check-locale-budget.mjs` reports at 348,647 of 370,000 gzip bytes with no failures.

**Skipped, deliberately.** Three residual Catalan strings are shared by two keys each: "Diari" (Daily / Journal), "Error en carregar les dades" (Error loading data / Failed to Load Data) and "Pàgines relacionades" (Related Pages / Related pages). None renders as a competing choice inside one control the way Equity and Net Worth do, es and pt carry the first two collisions identically, and the third differs in English only by capitalization. Churning them would be wording preference, not simplification.

**Recorded, not acted on.** Two observations belong outside this milestone: English `description` metadata ships inside every locale chunk and is discarded at runtime by `extractMessages` (`src/i18n/utils.ts`), which is a property of the catalog format across all fifteen languages rather than anything this diff introduced; and es, fr and pt carry half-translated values such as "Limpiar all" and "Otro transactions", which is exactly the scope w4/083 already owns.

Gates from `dashboard/` after the fix: `yarn format:check`, `yarn lint`, `yarn build` and `yarn test` (374 files, 4,190 passed, 1 pre-existing skip) all pass.
