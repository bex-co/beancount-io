# Preserve Cash Flow chart units when regrouping periods

**Minor · 45–60m · dashboard · A2.** Cash Flow silently switches the plotted unit back to USD after the reader selects VACHR and changes interval. Both Net Cash Flow and By Activity lose the selection on an uncached read and on a cached update. The amounts and available units are correct; the chosen view is discarded.

QA October 23, 2026 UTC, production `https://beancount.io`, owned isolated headless Chromium 156.0.8078.47, English/light/UTC, anonymous public example ledger. Four fresh contexts cover both views at 1440×1000 and 390×844. Genuine reads and native canvas legend/interval clicks throughout; chart references are read only to observe selection, instance IDs, plotted values and actual legend coordinates. No response modeling or chart-state injection.

## Reproducer and controls

1. Open `/ledger/open_ledger/example/cash-flow?time=2016-12&view=byActivity&lang=en`, Monthly, At Cost.
2. Click VACHR in the rendered legend to enable it, then USD to disable it. The actual map is **`USD:false, VACHR:true`**. By Activity shows vacation-hour activity **+15 / −15**, rather than USD operating **4802.68** and financing **240.68**.
3. Choose Quarterly. Its genuine `GetLedgerCashFlow` request returns HTTP 200 without GraphQL errors, for the same ledger, December filter and At Cost conversion. After settling, the new chart defaults to **`USD:true, VACHR:false`**. Available units remain USD/VACHR and all six plotted amounts are identical; only grouping and the unexpected selection change.
4. Reselect VACHR alone. Choose Monthly, whose result is cached. There is **no new finance read**, the chart instance remains the same, and selection nevertheless resets to **`USD:true, VACHR:false`**.
5. Repeat at the other width and in Net Cash Flow (`view=netCashFlow`, also the default view). All four cases reproduce both paths. Net Cash Flow retains its correct values, **5043.36 USD / 0 VACHR**, while likewise replacing the reader's unit choice.

Expected: interval changes preserve **`USD:false, VACHR:true`** when both units remain available. The chosen chart view, ledger, time filter, conversion and amounts remain coherent.

Working controls in every case: native re-selection works after each reset; merely opening the interval menu preserves the selection; selecting Monthly again while already Monthly preserves it. This distinguishes interval regrouping from a broken legend or ordinary focus change. The uncached path creates a new instance, while cached Monthly reuses the Quarterly instance. Both lifecycle failures are independently observed.

## Cause and bounded repair

`dashboard/src/features/reports/cash-flow/cash-flow-charts.tsx:110,290` calls `legendSelectionFor(currencyList, primarySeries)` without its existing chosen-selection argument. Both renderer bindings at `:143,306` pass only options/style/class and never capture `onLegendSelectChanged`. Each new option therefore supplies initial primary-unit defaults over the native choice. `cash-flow-content.tsx:275,297` passes no saved selection, and `cash-flow/index.tsx:166` replaces content while an uncached query is pending, discarding chart-local state as well.

Use the existing legend event/selection helpers and retain each Cash Flow view's reader choice at the page level across loading. Pass it through CashFlowContent to both renderers; reconcile it with available units through `legendSelectionFor`. Preserve initial defaults, completed 997's missing-primary fallback, deliberate all-off choices and legitimate unit-availability changes. Keep pending/error/empty guards truthful; retaining an old interactive report under new scope is not the repair. No global preference store, dependency or backend/API change is needed.

Acceptance: native Net Cash Flow and By Activity at desktop/narrow widths preserve the chosen units through both Monthly→Quarterly's read and cached Quarterly→Monthly. Meaningful regressions must exercise actual legend events, retained-option updates and pending child remounts, so fixing only one lifecycle cannot pass. Keep view/period/conversion, exact values and current report guards intact, and run dashboard gates. All-off, removed-unit and theme transitions are regression scope here, not new live failures claimed by this report.
