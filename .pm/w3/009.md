# Files Version History button loses its accessible name at narrow width

**Severity:** minor. **Estimate:** 15–25m for a translated accessible label and
responsive verification. **Pillar:** A2 — users of assistive technology must
be able to identify the source-history action.

Reproduced 2026-09-07 on production, Chrome 152, English/light, authenticated
public-example reader; source/fetched main `57fc1c27`, deployed SHA unverified.

1. At 390×844, fresh-load
   `/ledger/open_ledger/example/files/tree/main`.
2. Inspect the file toolbar's accessibility tree: Files is followed by an
   unnamed button. No button named **Version History** exists.
3. Focus Files and press Tab. The unnamed history button receives focus.
   Press Enter: it successfully opens the ledger's commit-history view.
4. Repeat after a fresh narrow load. At 1440×1000 the same button is correctly
   named **Version History** because its visible label is present.

Expected: the button retains its translated name when its visible text is
hidden. Actual: only the icon remains accessible, so the action has no name.
Its navigation works; this is separate from the unreachable file rows in
`w3/008`.

Root cause: `dashboard/src/features/ledger-editor/directory-browse/components/ledger-directory-view.tsx:184–194`
places the only label in a `hidden md:inline` span and supplies no aria-label
or screen-reader-only text. Give the button a permanent localized accessible
name using the existing `commits.versionHistory` translation. Preserve its
current keyboard activation and responsive layout.

Blast radius: the directory tree and `/files/content` callers share this
toolbar. The content alias is traced only. Create/upload/back buttons in the
same file use the same hidden-label pattern, but their owner/subdirectory
states were not exercised for this finding; check those adjacent controls
without invoking any writes. Git Clone is intentionally hidden at this width
and is not part of this finding.

Acceptance: a role/name lookup finds Version History at desktop and narrow
widths, Tab reaches it, Enter opens history, and other toolbar labels remain
correct. Confirm the active locale supplies the name.

Dedupe: searched open/completed board records for file toolbar, Version History
and accessible labels; no overlap. Completed sidebar/gallery accessibility
work `w5/done/m2` does not cover this toolbar. Source history `af5339de` and
`aeec496b` contains no repair, nor does fetched main. Other locales, screen
readers and patched behavior remain unverified.

Local evidence: `dashboard/tmp/qa-20260907-w3-loop/file-navigation-evidence.json`
and `file-tree-keyboard-390.png`. No production ledger changes were made.
