## Objective

Replace the dashboard's `navigator.language`-only default with ADR026's resolution and source labels, and save the preference by its write rule.

## Context

- Today: `dashboard/src/features/ledger-list/lib/setup-presets.ts` `suggestCurrency(locale)` with a hand-kept region table.
- ADR026 order: flow selection → saved `defaultCurrency` → browser region → `USD`; the browser time zone's country may add a one-tap candidate, never preselected.
- The region table and supported list should come from the canonical `currencies.json`, as a generated copy with a drift test (mobile already holds one).

## Steps

1. Generated currency tables plus an IANA time-zone→country map.
2. A pure resolver returning `{ currency, source, candidate? }`, with tests for each source and the conflict case.
3. Read `defaultCurrency` from `GetCurrentUser`; after a successful create, save a changed currency, or an accepted one when none is stored.

## Files

- `dashboard/src/features/ledger-list/lib/`
- `dashboard/src/graphql/query/auth.graphql`

## Acceptance criteria

- [ ] Each source and the time-zone candidate are covered by unit tests, including `en` without region.
- [ ] The write rule never overwrites a stored preference with an unchanged suggestion.

## Out of scope

- The flow layout (t003).

## Evidence (2026-11-01)

- `dashboard/src/features/ledger-list/lib/currency-suggestion.ts`: saved `defaultCurrency` → browser region (canonical region table, now a generated copy `setup-currencies.json` with a drift test) → `USD`; the browser time zone (`time-zone-regions.json`, generated from the IANA `zone.tab` plus legacy aliases) adds a one-tap candidate when its currency differs, never preselected, and never beside a saved preference. `currencyToSave` implements the write rule. 12 unit tests cover each source, `en` without region, the conflict case, legacy zone names, and the write rule.
- `LedgerForm` preselects the suggestion until the customer types or taps a candidate (the draft remembers the choice), shows the source label (`CurrencySuggestionHint`, translated in all 15 locales), and after a successful preset create saves the preference through `UpdateDefaultCurrency`; a failed save changes nothing created. The old `navigator.language`-only helper and its hand-kept tables were removed.
- Gates: `yarn lint` (deadcode, i18n), `yarn test` 7592 passed, `yarn build`.
