# `bea balance ''` matches every account (`'' in account` is always true)

**Severity:** minor. **Estimate:** 10–20 minutes. **Owner:** cli. **A1:** an
agent that passes an empty positional account filter (template hole, shell
`""`) gets the full trial balance — JSON even records `"account_filter": ""`
while the trees equal an unfiltered run; human mode labels it `account: all`.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `a7d16cde`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
bea --json --file main.bean balance
# account_filter: null — full Assets/Equity/Income/Expenses trees

bea --json --file main.bean balance ''
# exit 0 — account_filter: "" — SAME full trees (e.g. Assets:Cash 2950 USD)

bea --file main.bean balance ''
# "Valuation: USD; account: all"  ← looks intentional

# Controls
bea --json --file main.bean balance Nomatch
# assets/liabilities/… null — no match

bea --json --file main.bean balance '   '
# no match (spaces are not a substring of account names)
```

## Expected

Empty positional account terms are a usage error (exit 2) or match nothing —
same policy as w3/286 (`--search ''`) / w3/287 (`list --account ''`). Must not
equal omitting the argument.

## Actual

`balance ''` builds `terms = ['']`. Pruning keeps every node because
`'' in account.casefold()` is always true. Human output even says `account: all`.

## Root cause

`cli/src/bea_engine/report.py` (~75–83, ~447):

```python
terms = [(term or "").casefold() for term in accounts]
...
matches = ... any(term in node.account.casefold() for term in terms)
```

An empty string is kept as a real term; substring membership then matches all
accounts.

## Fix

Reject blank account terms (after strip) with a usage error, or drop blanks and
error if none remain. Align with w3/286–287. Regression: `balance ''` exits 2
(or empty trees); `balance Cash` / unfiltered / `Nomatch` unchanged.

## Dedupe

Same empty-substring class as w3/286 (list `--search`) and w3/287 (list
`--account` / `--currency` — different mechanism: falsy skip). Not w3/292
(report period collapse; uses `balance Nomatch` only as a control). No open
note covers `bea balance` positional `''`.
