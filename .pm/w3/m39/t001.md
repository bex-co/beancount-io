## Objective

Expose each primary sidebar as a `navigation` landmark with a distinct, localized accessible name, so landmark navigation reaches the ledger menu by name. Add the landmark at the composing sidebar level, not inside the shared primitive, unless every consumer of that primitive is genuinely a navigation region.

## Context

- `dashboard/src/common/components/ui/sidebar.tsx:686-690` (`SidebarMenu`, a bare `<ul>`) and `:603` (`SidebarContent`, a bare `<div>`) emit no navigation semantics.
- Composing shells: `dashboard/src/common/components/ledger-layout/ledger-sidebar.tsx` (ledger routes) and `dashboard/src/features/ledger-list/pages/dashboard-page/components/dashboard-sidebar.tsx` (`/ledger`).
- Each page already has up to two `navigation` landmarks (`Related pages`, `pagination`), so the new names must be distinct — an unnamed or duplicate landmark makes the list worse.
- New strings need an English key plus matching keys in the other 14 locales; `src/test/translations.test.ts` checks shape.
- Preserve the focus fallback documented at `sidebar.tsx:43` and the narrow-viewport sheet behavior.

## Steps

1. Add the landmark and its localized label to the ledger sidebar.
2. Do the same for the dashboard sidebar with its own distinct label.
3. Add both label keys to all 15 locale files.
4. Re-run the landmark sweep on `/ledger`, a ledger overview, a journal and a public balance sheet.
