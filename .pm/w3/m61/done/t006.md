## Done 2026-11-03

`/simplify` ran over m61's source (`4f6ea03eb`, `fcf984b59`, `5e805402e`, `e88183272`) with reuse, simplification, efficiency, and altitude reviewers. All applied changes preserve behavior.

**Backend**
- One `requestIdBody` schema (`rest/v1/request-id-body.ts`) replaces four drifting REST copies; the OpenAPI output is byte-identical.
- One `@RequestIdArg()` decorator replaces three GraphQL `@Arg` blocks.
- `mcpRequestId` moved beside `ledgerSelection` instead of being borrowed from a sibling tool.
- The Redis store has one fail-open `run()` helper.
- `runIdempotentEntryWrite` takes an explicit `committed` predicate from each service instead of peeking at `success`.
- The in-progress `CONFLICT` carries a machine-readable `requestInProgress: true`, which both clients match instead of the resource label.

**Dashboard**
- `newRequestId` (secure-context fallback) moved from `ledger-form` to `common/lib/entry-write` and is shared by ledger creation and entry writes.
- The hook returns a memoized `{ withRequestId, send }`; the unused `requestIdFor`/`reset` are dropped.
- `getErrorMessageKey` uses `instanceof`.
- Smart Import builds its batch and id once rather than per retry.

**Mobile**
- `common/request-id.ts` (`fnv1a32`, `newRequestId`) is shared with ledger creation; its base-36 draft fingerprints are unchanged.
- The hook is memoized and drops the unused `reset`.
- `ledger-refusal` keeps a commented name match, so the module does not pull in Apollo.

**Skipped**
- An options bag for `addBulkEntries`'s positional flags: existing debt across many callers.
- Moving ledger creation onto the new runner: its store deliberately fails closed.
- Trimming stored results: a replay must return the first result.
- Plain `SET`/`DEL`: the bounded client exposes only `eval`.
- A narrower dashboard refetch: it runs only after about 7 s of retries.
- One-line call-site helpers: the current nesting is readable.

**Gates**
- Backend: typecheck, `yarn test` (8168), the Redis integration test (6), ESLint, Prettier, and Knip (only the existing oauth finding).
- Dashboard: format, lint, and test (7688).
- Mobile: format, lint, typecheck, and `test:unit` (5070).
