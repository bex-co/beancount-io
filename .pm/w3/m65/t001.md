## Objective

Add a review procedure to the report-pack workflow that checks an existing pack against the ledger and returns findings.

## Context

- ADR020 P2 `beancount-report-review`: start as a review reference inside report-pack; split into its own skill only once users review artifacts they did not generate.
- Findings carry sheet/cell (or file/row) addresses and source tie-outs; performed and skipped checks are disclosed; the original is unchanged; the result is never called a statutory audit.
- Preserve commodity precision and choose tolerances per commodity and policy; report excluded or below-threshold differences (ADR020).

## Steps

1. Write `skills/beancount-report-pack/references/review.md`: inputs, tie-out checks against `bea` queries, finding format, review recommendation.
2. Link it from `skills/beancount-report-pack/SKILL.md` with a trigger for reviewing an existing pack.
