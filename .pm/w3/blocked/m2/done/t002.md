## Objective

The budget creation form: Date, Account, Interval, Amount + Currency, submitting via `useBulkEntriesMutation` and refetching the budget journal query.

## Context

- Route: `mobile/app/(app)/add-budget.tsx` → `src/screens/add-budget-screen/`.
- Field components: `DatePickerModal` (default today), account via the account-picker screen + `globalFnFactory` callback (see `SelectedPostingAccount` usage), `Picker` for interval — **chronological order Daily→Yearly** (the dashboard's alphabetical order is a codegen accident; don't port it), default Monthly; currency defaults to the ledger's operating currency (`useLedgerMeta` + `getPrimaryCurrency`).
- Forms: react-hook-form + zod are installed; validation parity with dashboard (required-only; amount stays a free string).
- Entry points: /budget header ＋ and empty-state CTA (enable what t008/m1 stubbed).
- Track `budget_add_submitted`; success haptic + `router.back()`.

## Steps

1. Route + screen with the four fields and validation.
2. Submit → t001 builder → `useBulkEntriesMutation` → check `bulkEntries.success`, surface `message` on failure → refetch journal query (`awaitRefetchQueries`).
3. Wire /budget's ＋ and empty-state CTA to push `/add-budget`.
