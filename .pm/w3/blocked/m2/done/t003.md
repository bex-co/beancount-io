## Objective

Reuse the add-budget screen as "Update Budget" from a group card: account locked, interval and currency prefilled — dashboard-parity semantics where an update is a newer-dated directive superseding on its effective date.

## Context

- Dashboard reference: `add-budget-dialog.tsx` props `lockedAccount` / `defaultInterval` / `defaultCurrency`; button label "Update Budget".
- Pass params via `router.push({ pathname: "/add-budget", params })`; read with `useLocalSearchParams`.
- Card entry point on `budget-group-card.tsx` (m1), write-gated if mobile has a permission concept for the ledger.

## Steps

1. Accept `account` / `interval` / `currency` params; lock the account field, prefill the rest; switch screen title to the update copy.
2. Add the Update entry point to the group card.
3. Update-mode help text: newer directive for the same account+currency takes effect on its date.

## Files

- `mobile/src/screens/add-budget-screen/` (mode handling)
- `mobile/src/screens/budget-screen/components/budget-group-card.tsx`

## Acceptance criteria

- [ ] From a card, the form opens locked+prefilled; submitting adds a new history entry and the card's current amount updates after refetch.
- [ ] Add mode is unaffected.

## Out of scope

- Editing an existing directive in place (no such API — by design).
