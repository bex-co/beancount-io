## Objective

Add the one GraphQL operation mobile lacks for budget: `getLedgerIntervalTotals` (per-interval actuals for an account, sub-accounts rolled up server-side), and regenerate typed hooks.

## Context

- Schema already has it: `mobile/src/generated-graphql/schema.graphql` — `getLedgerIntervalTotals(accountName!, ledgerId!, interval!, conversion!, time, filter, account): [IntervalTotalItem!]!`.
- Dashboard reference query: `dashboard/src/features/ledger-data/budget/graphql/budget.graphql`.
- Mobile convention: `.graphql` files in `mobile/src/common/graphql/queries/`, then `yarn codegen` (never hand-edit `src/generated-graphql/`).
- Budget uses `conversion: "units"` and `interval` = the budget's own cadence, lowercase.

## Steps

1. Create `intervalTotals.graphql` selecting `date`, `balance`, `accountBalances`.
2. `cd mobile && yarn codegen`; confirm `useGetLedgerIntervalTotalsQuery` (or lazy variant) is generated.
