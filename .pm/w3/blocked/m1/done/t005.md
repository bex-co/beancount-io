## Objective

Build the budget-vs-actual chart primitive: vertical bars for actual per-interval spending with a dashed budget line overlaid — a step line when the budget history has more than one entry, flat otherwise (dashboard parity).

## Context

- Home for D3 charts: `mobile/src/common/d3/` (d3 + react-native-svg, no chart library).
- Closest analog to copy from: `income-expense-bar-chart.tsx` (grouped bars + overlaid line + legend).
- Dashboard behavior to mirror: `budget-chart-card.tsx` — dashed line, `step: "end"` staircase when history > 1, "No Data Available" empty state.

## Steps

1. Create `budget-bar-chart-d3.tsx` with props `{ labels, actuals, budgets, currencySymbol, height? }`.
2. Bars for actuals; dashed step path for budgets; small legend matching existing chart styling; theme colors via `ColorTheme` tokens.
3. Empty-state rendering when all values are absent.
