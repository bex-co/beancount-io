## Objective

Add the Budget panel to the Home screen: top 3 budget groups by current-period utilization (most at-risk first), each a progress-bar row, with "See all ›" navigating to /budget. No budgets → a one-row CTA state for discoverability.

## Context

- Pattern: `DashboardCard` with `onSeeAll` (see `recent-transactions-card.tsx`); place **after `SpendingCard`** in `home-screen.tsx`; honor the `refreshing`/`refreshSignal` refetch contract.
- Data source per t001's spike decision: `homeCharts.budgets` if sufficient, else journal query + up to 3 current-period `getLedgerIntervalTotals` calls (`time` = current-period date range of each budget's own cadence).
- Row: shortened account, progress bar (error color when over), `spent / budget CUR`; utilization sign-flipped for income budgets (t002 selector).
- Track `budget_panel_see_all` on the See-all tap.

## Steps

1. Create `budget-card.tsx` in `src/screens/home-screen/components/` + a ranking selector (pure, in `selectors/` with tests).
2. Wire into `home-screen.tsx` after SpendingCard; rows and See-all push `/budget`.
3. Empty state: single CTA row using t006 copy, navigating to /budget's empty state.
4. Skeleton via `LoadingTile` while loading.

- [ ] Panel shows ≤3 rows sorted by utilization desc; over-budget rows use the error color.
- [ ] Tapping the panel or See-all lands on /budget; event fires.
- [ ] Zero-budget ledgers see the CTA row; panel refetches on pull-to-refresh; Home render time not visibly regressed.
