## Objective

Assemble the dedicated budget page: expo-router stack route, time-span pills, a lazy FlatList of BudgetGroupCards, and the no-budgets empty state.

## Context

- Route pattern: one-liner `mobile/app/(app)/budget.tsx` → `src/screens/budget-screen/` (mirror `open-account.tsx`); no `_layout.tsx` change needed; title via `<Stack.Screen options>`.
- Guard: wrap in `LedgerGuard`, `useLedgerGuard()` for `ledgerId`.
- Read query: `useGetLedgerJournalQuery` with `{ directiveTypes: ["Custom"], customSubtypes: ["budget"], limit: 200 }` — **explicit limit**; server default 20 silently truncates (dashboard bug, don't port it). Check `total` against the cap.
- Pills: reuse `mobile/src/components/time-range-pills/` (haptic) with All time / This year / Last year / Last 12 months mapping to the Fava `time` filter values (`undefined` / `year` / `year-1` / date range).
- Page view: `usePageView("budget")`.

## Steps

1. Route file + screen scaffold with header (title, right-side ＋ placeholder disabled until m2).
2. Journal query → `groupBudgetEntries` → FlatList of cards keyed `${account}::${currency}` so per-card actuals queries fire as cards mount.
3. Time-span pill state passed down as `time` to cards.
4. Empty state: icon + "No budgets found" copy + CTA (navigates nowhere until m2 — render CTA copy pointing to the web dashboard for now, or hide the button; pick one and note it).
5. Pull-to-refresh refetches the journal query.
