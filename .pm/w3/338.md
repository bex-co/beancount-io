# `bea treeify` exits 0 when it treeifies nothing (WARNING only)

**Severity:** minor. **Estimate:** 15–25 minutes. **Owner:** cli. **A1:** a
pipeline `bea balance | bea treeify` (or any input with no hierarchical column)
gets exit **0** and unchanged stdout, so automation treats a failed transform
as success.

Found 2026-09-16 by continuous CLI QA ([c800 hunt](71c38bb9-d65c-40c5-9054-10dcecbbff3c)),
HEAD `57e5877a`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Confirmed
`cli/tmp/qa-20260915/c801/`. Evidence: `c800/`.

## Repro

```sh
printf 'plain text\nno hierarchy\n' | bea treeify
# exit 0 — stderr WARNING: Could not find any valid column in input
# stdout unchanged

printf 'Assets:Cash 100\n' | bea treeify
# exit 0 — tree output (control)
```

## Expected

No-column / no-transform cases exit nonzero (usage/validation) so `$?`
distinguishes success from passthrough.

## Actual

Upstream `treeify` warns and exits 0; `treeify.py` forwards the exit unchanged.

## Fix

Map the no-column WARNING to UsageError / exit 2 (or document as intentional).
Regression: plain-text stdin exits nonzero; valid account columns still exit 0.
