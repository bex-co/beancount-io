# Lot reductions replace current market prices (blocked on upstream engine)

**Major · backend-cluster/ledger · blocked.** A1/A3. Carries forward the finding
from **m18**, which was abandoned as a milestone on 2026-09-10 because its
prerequisite does not exist. The full reproduction, source trace, fixtures and
controls are archived at [`done/m18/README.md`](./done/m18/README.md).

## The defect, in one line

A cost-only reduction of an existing lot is treated as new quote information, so
selling half a position reprices every remaining unit at the historical lot cost.
On the public `open_ledger/crypto-example`, BTC shows **42500** instead of the
declared **98000** quote, and all BTC holdings total **13897.50 USD** instead of
**32046 USD**. Every BQL transport (dashboard, GraphQL, REST, MCP) shares it.

## Why this is not workable in this repo today

The producer is upstream: rustledger's `extract_per_unit_price` returns a cost
fallback without knowing whether the posting reduces an existing position, and
the query price database has no lot-reduction/booking gate. Python Beancount
3.2.3's `implicit_prices` plugin excludes cost-only `MatchResult.REDUCED`
postings and keeps the correct quote — that is the contract to match.

Verified 2026-09-10 against the npm registry:

- `@rustledger/wasm` latest release is **0.24.0** (2026-09-06). m18 proved both
  0.21.0 and 0.24.0 fail the reduction fixture.
- The `1.0.0-rc.*` line is **not** newer: rc.18 was published 2026-01-14 and npm
  marks it deprecated ("Use @rustledger/wasm@0.1.0 or later"). It is an older,
  abandoned line, not a corrected artifact.

So no released or supported engine artifact fixes this. The current WASM query
interface exposes no price-policy option, and `backend-cluster/ledger/CLAUDE.md`
forbids vendoring rustledger source or WASM bytes into this public repo. The
remaining in-repo options — fabricated Price directives, a parallel valuation
engine, a blanket `units < 0` filter, or client-side compensation — were all
ruled out in m18 as either wrong accounting or leaving other surfaces incorrect.

## What unblocks it

An upstream rustledger release whose implicit-price inference is booking-aware,
or a supported engine interface for price policy. When one lands, re-promote
this note: m18's task breakdown (pin the contract in live fixtures → verify the
artifact → integrate at the engine boundary) is still the right plan, and its
`probe-reduction-prices.mjs` fixture still reproduces the failure in one run.

Publishing the upstream issue/patch is outside this repo's scope and was not
done by the QA run that found this.
