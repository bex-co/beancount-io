## Objective

Give the native create screen the same stages, defaults, and review as the dashboard flow.

## Context

- `mobile/src/screens/create-ledger-screen/create-ledger-screen.tsx` has the same four fields and a Create header action today.
- `expo-localization` is already a dependency, read for language only in `mobile/src/translations/index.ts`; its currency and region fields supply the native hint. Language alone never selects a currency.

## Steps

1. Stage the native screen to match t001's steps and defaults, reusing m53's preview and `requestId`.
2. Apply the same title-to-address slug fallback for non-Latin titles.
3. Keep the simple path as short as today's single screen for a defaults-only user.

## Files

- `mobile/src/screens/create-ledger-screen/create-ledger-screen.tsx`
- `mobile/src/translations/`

## Acceptance criteria

- [ ] The defaults-only path and the reviewed preset path both create the ledger m53's preview promised.
- [ ] Changing interface language never rewrites a selected currency or an existing ledger.

## Out of scope

- Mobile billing or any ADR001-mobile-billing scope (deferred by owner decision).

## Evidence (2026-10-20)

- Mobile creation is staged like the dashboard's (start -> details -> review) in `create-ledger-screen.tsx`: preset choice with the same eight catalog presets, currency suggested from the device region via `expo-localization` (region only, never language), history date, optional first opening account/amount, and a review step rendering the server preview (`PreviewLedgerSetup` query). The GraphQL client was regenerated with `yarn codegen` against an SDL emitted from backend source (served locally, since production does not carry the new fields yet); generated files were not hand-edited. Every create sends a `requestId`, and the draft (step, values, requestId) persists in AsyncStorage so leaving and returning resumes.
- Gates in `mobile/`: `yarn format:check`, `yarn lint` (incl. Knip deadcode and the GraphQL operations check), `yarn typecheck`, and `yarn test:unit` (2,340 passed) all pass. New keys were added to English and translated in all 12 other locales (locale-integrity suite); the creation-refresh harness mocks cover the new dependencies and the "no duplicate creation" contract still holds.
