## Objective

Return Close/Delete Account confirmations to the correct row action or a connected fallback.

## Context

- The menu passes only an account target; its persistent More actions button is not passed into the controlled page-level dialogs.
- The menu's own Escape return works, but settled confirmation dismissal focuses BODY at both widths.
- A successful close can remove the action button and deletion removes the row, requiring an explicit fallback.

## Steps

1. Capture the actual row More actions element when selecting Close/Delete; do not retain the menu item that unmounts.
2. Restore that connected target through the dialog's existing close-autofocus extension point.
3. When the original action disappears, focus the persistent Search accounts input without triggering another action.
4. Preserve account eligibility, context/hash reads, loading/error states, confirmation, mutation results and cache refresh.

## Files

- dashboard/src/features/ledger-data/accounts/index.tsx
- dashboard/src/features/ledger-data/accounts/close-account-dialog.tsx
- dashboard/src/features/ledger-data/accounts/delete-account-dialog.tsx

## Acceptance criteria

- [ ] After opening and menu transitions settle, Escape, Cancel and Close return to the exact row button at both widths.
- [ ] Successful local-fixture completion with a removed trigger focuses Search accounts; failures keep focus inside the open dialog.
- [ ] No detached target, timer workaround, automatic mutation or global focus override is introduced.

## Out of scope

Production account closure/deletion, accounting policy changes and other dialogs.
