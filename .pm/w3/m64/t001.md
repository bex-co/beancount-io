## Objective

Choose which `bea` reads become resources and which hosted playbooks become read-only local prompts.

## Context

- `cli/docs/MCP.md`: the server "advertises tools only (no resources or prompts)" and refuses every write.
- The hosted endpoint serves resources (errors, accounts, payees, metadata) and the close-month, reconcile-account, categorize-imports, and spending-report prompts (`backend-cluster/backend-v2/docs/mcp.md`).

## Steps

1. Map candidate resources to existing `bea --json` commands (for example `check`, `list account`, `list payee`).
2. Pick a local URI scheme that cannot be mistaken for a hosted `beancount://` URI.
3. Adapt close-month, reconcile-account, and spending-report as read-only prompts; record why categorize-imports is excluded (it writes).
4. Write the design into `cli/docs/MCP.md` as the intended surface.

## Files

- `cli/docs/MCP.md`

## Acceptance criteria

- [ ] Every resource maps to one existing `bea --json` command.
- [ ] No prompt instructs the agent to write through MCP.

## Out of scope

- Local writes over MCP (a separate owner decision).
