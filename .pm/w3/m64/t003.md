## Objective

Implement `prompts/list` and `prompts/get` with arguments and advertise the `prompts` capability.

## Context

- Prompts are instructions the agent follows with the server's read tools; they must stay inside the server's read-only contract.

## Steps

1. Add the capability.
2. Implement the prompts chosen in t001 with typed arguments (for example period, account).
3. Reject missing or malformed arguments with a JSON-RPC error.

## Files

- `cli/src/cli/commands/mcp.py`

## Acceptance criteria

- [ ] `prompts/get` returns each prompt with its arguments substituted.
- [ ] A missing required argument is an error, not a prompt with a blank.
