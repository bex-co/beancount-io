# `bea list pad --account` ignores the SOURCE column (silent empty result)

**Severity:** minor. **Estimate:** 15–25 minutes. **Owner:** cli. **A1:** an
agent filtering pads by the equity/source side (`--account Equity`) is told
there are no pads even though the table’s SOURCE column clearly matches —
same substring contract that works for `list transaction` posting accounts.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `3b647660`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
cat > main.bean <<'EOF'
option "operating_currency" "USD"
2024-01-01 open Assets:Cash USD
2024-01-01 open Equity:Opening USD
2024-01-02 pad Assets:Cash Equity:Opening
2024-01-03 balance Assets:Cash 100 USD
EOF

bea --file main.bean list pad
# DATE 2024-01-02  ACCOUNT Assets:Cash  SOURCE Equity:Opening

bea --file main.bean list pad --account Cash
# same row (padded account matches)

bea --file main.bean list pad --account Equity
# exit 0 — "No pad directives found."

bea --json --file main.bean list pad --account Equity
# {"data": [], "truncated": false, ...} — empty, not an error
```

## Expected

`--account` on `list pad` is a case-insensitive substring over **either** the
padded ACCOUNT or the SOURCE account (USAGE: generic account filter for
`pad`; the human table always shows both columns). `--account Equity` must
return the pad whose SOURCE is `Equity:Opening`.

## Actual

`list_pads` only checks `entry.account`. A filter that matches only
`source_account` yields an empty list / “No pad directives found.”

## Root cause

`cli/src/bea_engine/ledger/reader.py` `list_pads` (~395–396):

```python
if account and account.casefold() not in entry.account.casefold():
    continue
```

Never inspects `entry.source_account`. Contrast `list_transactions`, which
matches `--account` against any posting account.

## Fix

Match when the substring appears in `entry.account` **or**
`entry.source_account`. Regression: the Equity filter above returns the pad;
Cash still works; unrelated substrings stay empty. Document if SOURCE is
intentionally excluded (prefer matching SOURCE — the column is already shown).
