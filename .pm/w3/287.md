# `bea list … --account ''` matches every row (empty substring is always true)

**Severity:** minor. **Estimate:** 10–20 minutes. **Owner:** cli. **A1:** same
class as w3/286 for `--search`: an empty `--account` filter (template hole,
shell `""`, JSON→CLI bridge) silently returns the full unfiltered list for
every account-filtered `list` subcommand instead of zero hits or a usage
error.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `6cbb6a92`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
# Any ledger with several opens / transactions

bea --json --file main.bean list open
# data length N (e.g. 4)

bea --json --file main.bean list open --account ''
# exit 0 — data length N (same as unfiltered)

bea --json --file main.bean list open --account Cash
# exit 0 — only opens whose account contains “Cash”

bea --json --file main.bean list transaction --account ''
# exit 0 — every transaction (same as omitting --account)
```

Same empty-string match-all on `list transaction|note|balance|close|document|pad`
wherever `--account` is implemented via `account.casefold() not in …`.

## Expected

Empty `--account` is a usage error (exit 2: account filter required) or matches
nothing. It must not disable filtering. Align with the fix chosen for w3/286
(`--search ''`).

## Actual

`list_opens` / `list_transactions` / … use
`account.casefold() not in entry.account.casefold()` (or posting accounts).
In Python, `'' in any_string` is always `True`, so the filter never excludes a
row.

## Root cause

`cli/src/bea_engine/ledger/reader.py` account filters (e.g. `list_opens`
~249, `list_transactions` ~152, `list_pads` ~395): no non-empty guard before
substring membership. Typer accepts `--account ''`.

## Fix

Reject blank `--account` (after strip) with a usage error, or treat blank as
“match nothing”. Share the guard with w3/286’s `--search` fix. Regression:
`--account ''` exits 2 (or `[]`); `--account Cash` unchanged.

## Dedupe

Twin of w3/286 (empty `--search` only). Not w3/285 (`list pad` SOURCE column).
Not w3/275 (Unicode). No open note covers empty-string `--account` match-all.
