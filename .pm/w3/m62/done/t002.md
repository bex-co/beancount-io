## Objective

Add one **Currency** field to today's single creation form, prefilled for the user, and send it for Starter ledgers only.

## Context

- Form: `dashboard/src/features/ledger-list/components/ledger-form.tsx`. It sends `name`, `description`, `private`, `template` (only when Sample), and `requestId`.
- Starting point from before the revert: `336b3cf4d^:dashboard/src/features/ledger-list/lib/currency-suggestion.ts and setup-currencies.json`. Keep only the order below; drop the time-zone candidate, the source label, and the setup flow.
- The current-user query does not read `defaultCurrency` today; the GraphQL `User` type exposes it.

## Steps

1. Read `defaultCurrency` in the current-user query and regenerate types with `CODEGEN_SCHEMA_FILE` codegen.
2. Prefill: saved `defaultCurrency` → the supported currency of the browser locale (`navigator.languages`) → `USD`. Offer the supported list for editing.
3. Show the field under the template choice while Starter is selected; hide it for Sample.
4. Send `currency` only for Starter. Keep the submit label "Create ledger".
5. Add the field's label and hint to every shipped locale.

## Files

- `dashboard/src/features/ledger-list/components/ledger-form.tsx` and its tests
- the package's current-user GraphQL document and generated types, locale files

## Acceptance criteria

- [x] With `defaultCurrency: "JPY"` the field opens as JPY; with none and a supported region it opens as that region's currency; otherwise USD.
- [x] Creating a Starter ledger sends the selected currency; a Sample ledger sends no `currency`.
- [x] The rest of the form (fields, order, validation, requestId retry behavior) is unchanged.
- [x] `yarn format:check`, `yarn lint`, `yarn test`, `yarn build` pass.

## Out of scope

- Saving the chosen currency back to the profile.
- Any other ADR026 change.

## Implementation notes

- A server validates the whole GraphQL document, so one that declares `currency` is refused by a server older than the argument even when no currency is sent (the w21/592 lesson). The form therefore omits USD, and `useCreateLedger` (`features/ledger-list/hooks/use-create-ledger.ts`) sends `CreateLedger` unchanged unless a Starter has another currency, which goes out as the separate `CreateLedgerInCurrency` document. The sidebar, ledger switcher, and welcome page all create through it.
- The picker is the shared `Combobox` over a copy of backend-v2's `currencies.json`, labelled with `Intl.DisplayNames`; the browser region comes from `navigator.languages`, read after mount.
- Validation applies only while Starter is selected, so a cleared currency never holds back a Sample.
- The create submit reads "Create Ledger" again (the w3/648 label lost in the 2026-11-07 revert); editing keeps "Save".
