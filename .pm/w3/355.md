# `bea doctor context` resolves relative `include:lineno` against cwd, not the root ledger dir

**Severity:** minor. **Estimate:** 20–35 minutes. **Owner:** cli. **A1:** with
an absolute root ledger path, `doctor context … txns/jan.bean:4` fails from
any cwd other than the books tree — location resolves under the process cwd.

Found 2026-09-16 by continuous CLI QA ([c970 hunt](fff724fd-bfe7-4361-90e5-40c43f9d8c43)),
HEAD `f4585c00`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Confirmed
`cli/tmp/qa-20260915/c971/`. Evidence: `c970/`.

## Repro

```sh
# from a foreign cwd:
bea doctor context /abs/books/main.bean txns/jan.bean:4
# exit 1 — No entry … /foreign/cwd/txns/jan.bean:4

bea doctor context /abs/books/main.bean /abs/books/txns/jan.bean:4
# exit 0
```

## Expected

Relative include locations resolve against the root `FILENAME` directory.

## Actual

`doctor.py` forwards to bean-doctor unchanged; relative paths use process cwd.

## Fix

Rewrite relative `file:lineno` against the ledger directory before launch (or
chdir for the native call). Regression: foreign-cwd repro exits 0.

## Dedupe

Not w3/352 (region display). Not w3/345 (parse exit). No open note covers
cwd-sensitive `doctor context` include locations.
