## Objective

Delete a single budget history entry from an expanded card: native confirm → optimistic-lock fetch → source-slice delete → refetch. Every failure path surfaces a visible error.

## Context

- Two-step (dashboard `delete-budget-dialog.tsx`): `GetLedgerEntryContext(entryHash, ledgerId)` for `sha256sum`, then `deleteLedgerEntrySourceSlice({ entryHash, sha256sum })` — both operations already codegen'd in mobile.
- **Fix, don't port:** the dashboard silently no-ops when `sha256sum` is missing — mobile must show an error toast/alert.
- Confirm via `Alert.alert` interpolating interval, amount, account, and effective date ("removes a single budget entry and cannot be undone").
- After success: refetch the budget journal query (prefer targeted refetch over the dashboard's full cache clear); track `budget_deleted`.

## Steps

1. Trash affordance on history rows → confirm alert.
2. Context fetch; missing `sha256sum` or mutation error → visible error, row intact.
3. Success → refetch; card updates (group disappears when its last entry is deleted).
