# `bea list open` human table leaves unrestricted opens with a blank CURRENCIES cell

**Severity:** minor. **Estimate:** 10–20 minutes. **Owner:** cli. **A1:** human
`list open` shows whitespace for currency-unrestricted opens while JSON has
`"currencies": []` — agents cannot tell “any currency” from a render failure.

Found 2026-09-16 by continuous CLI QA ([c1030 hunt](a1ee44a3-6aeb-4e07-b2a6-2fa0c3441289)),
HEAD `82a68a0b`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Confirmed
`cli/tmp/qa-20260915/c1033/`. Evidence: `c1030/`.

## Repro

```sh
# Assets:Broker and Equity:Opening-Balances have no currency list
bea --file main.bean list open
# CURRENCIES blank for those rows; Assets:Cash shows USD

bea --json --file main.bean list open
# "currencies": [] vs ["USD"]
```

## Expected

Empty currencies render an explicit sentinel (`—` / `(any)`), matching report
empty-amount convention.

## Actual

`", ".join(o["currencies"])` yields `""` for unrestricted opens.

## Fix

Render a documented sentinel when currencies is empty; keep JSON `[]`.
Regression: unrestricted rows show the sentinel; restricted rows unchanged.

## Dedupe

Not w3/290 / 341 / 287. No open note covers blank human CURRENCIES for
legitimate unrestricted opens.
