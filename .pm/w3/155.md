Root cause: dashboard/src/common/components/ledger-search-controls/index.tsx:146–150 builds suggestions by interpolating each raw payee between double quotes, without escaping regex metacharacters. At203–205 the chosen string becomes the shared advanced filter unchanged. Quoting only makes it a lexical string; it does not make it a literal regex. The ledger's existing Fava-compatible parser in backend-cluster/ledger/src/foundation/rustledger/directive-filter.ts:299 accepts quoted strings, strips only the surrounding quotes at349–352, and key predicates at483–486 pass the contents to makeMatcher, whose regex compilation is at187–189. The production0→6 controls prove the same interpretation. Do not change the backend's deliberate advanced-regex semantics.
