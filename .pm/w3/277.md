# One-shot `bea query '.output PATH'` exits 0 after creating an empty file (no query runs)

**Severity:** minor. **Estimate:** 20–30 minutes. **Owner:** cli. **A1:** an
agent that mirrors the interactive `.output FILE` / query / `.output` pattern
as a one-shot `bea query '.output /tmp/out.txt'` thinks redirection succeeded,
gets exit 0, and finds a **0-byte** file with no table — then may assume the
ledger was empty.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `66eccd1b`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
bea --file main.bean query ".output /tmp/bea-out.txt"
echo exit=$?
ls -la /tmp/bea-out.txt
# exit 0
# -rw-r--r-- … 0 … /tmp/bea-out.txt

bea --file main.bean query ".output /tmp/missing-dir/out.txt"
# exit 1
# Error: [Errno 2] No such file or directory: '…/missing-dir/out.txt'
# (same raw errno class as w3/270)
```

Non-interactive stdin cannot recover the interactive two-step either: the
whole stdin is one `query_string`, so

```sh
printf '.output /tmp/out.txt\nSELECT account LIMIT 1\n' | bea --file main.bean query
# exit 0, stdout empty, /tmp/out.txt often absent
```

Working controls:

```sh
bea --file main.bean query --output /tmp/out.txt 'SELECT account LIMIT 1'
# exit 0; file has the text table; stdout empty

# interactive PTY: .output FILE then SELECT writes the table to FILE
```

## Expected

One-shot / non-TTY `.output` should either:

1. refuse with usage (“use `bea query --output FILE 'SELECT …'`”), or
2. require a query in the same invocation and write that result,

and must not report success with an empty artifact that looks like a completed
export.

## Actual

`.output` is forwarded to beanquery’s shell command, which opens/truncates the
path and returns success with no result rows. Bea’s one-shot path runs a single
`onecmd` on the entire string, so no later SELECT is attached.

## Fix

Detect `.output` / `.output` reset in the non-interactive one-shot path and map
to `UsageError` pointing at `--output FILE` + query argument (keep interactive
PTY behavior). Soften missing-parent errno like w3/270. Regression: the empty
`.output /tmp/…` repro exits 2 with guidance; `--output` + SELECT unchanged.

## Dedupe

w3/234 (`--json` shell utilities). No open note covers one-shot `.output`
