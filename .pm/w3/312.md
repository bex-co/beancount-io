# `--json` on enabled `price` / `ingest` still breaks the JSON contract

**Severity:** minor. **Estimate:** 25–40 minutes. **Owner:** cli. **A1:** an
agent that wraps every `bea` call in `--json` cannot parse success or failure
for optional native forwards once `beanprice` / `beangulp` are enabled — stdout
is bean-price / Beangulp text, and upstream argparse/tracebacks stay on stderr
— while `doctor` / `example` / `treeify` / `ask` already refuse JSON cleanly.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `bc798cc6`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Optional
features enabled in the managed engine. Evidence:
`cli/tmp/qa-20260915/c504/evidence/json-price-ingest/`, `c516/`.

## Repro

```sh
bea engine enable beanprice   # if not already present
bea engine enable beangulp

bea --json price -n -e USD:yahoo/AAPL
# exit 0; stdout is bean-price text (not envelope); stderr empty

bea --json price -e 'NOTASOURCE:zzz'
# exit 2; stderr is upstream argparse help — not a JSON error

# ingest.py: from beangulp import Ingest; Ingest([])()
bea --json ingest identify --config ingest.py bank.csv
# exit 0; stdout: "* …/bank.csv" (not envelope)
```

Working control:

```sh
bea --json doctor lex main.bean
# exit 2 + parseable refuse_json usage error
```

## Expected

Same gate as doctor/example/treeify/ask — exit 2, empty stdout, JSON usage
error naming `price` / `ingest`.

## Actual

`cli/commands/price.py` and `cli/commands/ingest.py` call
`run_optional_native` / `run_optional_script` without `refuse_json` after the
feature is enabled. Tests in `tests/test_native_json_refusal.py` cover only
doctor/example/treeify. Pre-enable / missing-script paths may already error;
the post-enable success and upstream-failure paths do not.

## Fix

Call `refuse_json` in both commands; document beside the other JSON exceptions
in `USAGE.md`; extend `test_native_json_refusal.py`. Regression: the four
commands above exit 2 with a JSON usage envelope and empty stdout.

## Dedupe

Incomplete follow-through of **w3/done/221** (doctor/example/treeify only;
done/221’s price/ingest control is the pre-enable path). Not w3/295 (`engine
enable` double message). No open note for post-enable `--json price|ingest`.
