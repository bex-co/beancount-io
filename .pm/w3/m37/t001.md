## Objective

Move the `{currency: number}` inventory cell formatting that currently lives inside the Holdings feature into `dashboard/src/common/`, so the BQL result renderer can use it without one feature importing another feature's private helper (`dashboard/CLAUDE.md` organization rules). Provide one display form (an ordered list of `<number> <currency>` entries suitable for React rendering) and one plain-text form (the same entries for CSV), both preserving the lossless decimal handling of `formatDecimalCell`. Repoint Holdings at the shared module and delete the feature-local copies. This task changes no output.

## Context

- Source of truth today: `dashboard/src/features/ledger-data/holdings/holdings-table.tsx:31-42` (`renderObject`) and `dashboard/src/features/ledger-data/holdings/utils.ts:1-8` (`csvObjectToString`), plus `formatDecimalCell` in the same `utils.ts`.
- Destination: `dashboard/src/common/lib/` alongside the existing `common/lib/format/` and `common/lib/export/` modules, which already own generic escaping and download lifecycle code.
- Read the parent README for the reproduction, the API payload shape, and the deliberate fava zero-net `{}` serialization that must not be changed.

## Steps
