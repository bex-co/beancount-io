# Unbalanced stock/commodity reduction gets a FX “price annotation” hint (wrong recovery)

**Severity:** minor. **Estimate:** 20–30 minutes. **Owner:** cli. **A1:** an
agent selling shares without a cost lot (`Assets:Broker -1 HOOL` vs cash) is told
to fix a “currency exchange” with `@` FX syntax, not to attach `{cost}` / reduce
an existing lot — so it retries the wrong annotation class.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `f6e0c3ec`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
# Assets:Broker already holds 1 HOOL {100 USD}; Cash in USD
bea --file main.bean add transaction --date 2020-07-03 --narration sell2 \
  --posting 'Assets:Broker -1 HOOL' --posting 'Assets:Cash 100 USD'
# exit 1
# Transaction does not balance: (100 USD, -1 HOOL)
# For a currency exchange, use a price annotation with the actual exchange rate:
# for example, '100 EUR @ 1.08 USD' balances against '-108 USD'.
```

Working controls:

```sh
# True FX — hint is appropriate:
#   Expenses:Travel 100 EUR   +   Assets:Cash -108 USD  (no @) → same hint OK

# Correct stock reduction — succeeds:
bea --file main.bean add transaction --date 2020-07-03 --narration sell \
  --posting 'Assets:Broker -1 HOOL {100 USD}' --posting 'Assets:Cash 100 USD'
```

## Expected

When the residual mixes operating currency with a commodity that already has
inventory lots (or when a posting reduces a non-currency commodity without
cost/price), prefer a cost-lot / `@` market-price recovery message — e.g. use
`{100 USD}` or `1 HOOL @ 100 USD` — instead of (or before) the EUR/USD FX
example.

## Actual

`bea_engine/ledger/write.py` appends the FX hint for every balancing error whose
residual has `len(currencies()) > 1`, with no check that both sides are cash
currencies vs. a lot reduction.

## Fix

Gate the FX hint on residuals that look like cash↔cash (both in
`operating_currency` / known currencies without open lots), and add a separate
hint when a residual includes a held commodity unit. Regression: the stock
repro’s detail mentions cost/`{…}` (not EUR `@`); a true EUR/USD imbalance still
gets the FX example.

## Dedupe

Not w3/268 (bare `@`/`@@` → MISSING tokens). Not w3/272 (bulk JSON amount
shorthand vs lots). No open note covers the FX hint misfiring on commodity lot
reductions.
