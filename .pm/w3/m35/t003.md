## Objective

Prevent CSV, Markdown and printable statements from exporting financial values under metadata from an unfinished request.

## Context

Read this milestone README and ../129.md for the concrete browser reproductions and API controls. Report mode has not implemented the fix.

## Steps

1. Propagate request readiness and coherent completed context through the three statement-content components into StatementExportMenu and the print document.
2. Disable pending export actions until a coherent current result is available. The browser-print portal must also remain truthful: retain a fully labeled completed snapshot or show a pending state, never old values with new basis metadata. Merely disabling menu buttons is insufficient.
3. Keep generation timestamps, filenames, unit labels and normal post-success downloads correct; preserve export failure feedback and cleanup.

## Acceptance criteria

- [ ] The reproduced pending Units state cannot download a units-labeled At Cost CSV.
- [ ] Markdown and headless print content cannot mix the new basis with old balances, including browser-print behavior outside the menu.
- [ ] After completion, actual downloaded CSV Assets rows exactly match the Units API response and filenames/context agree.

## Out of scope
