## Objective

Prevent retained Apollo data from acquiring a new conversion, interval or filter label before its corresponding response completes.

## Context

Read this milestone README and ../129.md for the concrete browser reproductions and API controls. Report mode has not implemented the fix.

## Steps

1. Trace the Balance Sheet data/previousData fallback and current conversion props; audit the same pattern in Income Statement, Cash Flow and Trial Balance.
2. Represent retained results together with the inputs that produced them, or withhold financial results while replacement data is pending. Do not pass old balances beside newly selected calculation metadata.
3. Handle cached results, overlapping requests, failure and ledger changes without accepting an obsolete response as the latest selection. Keep correct date parsing and financial signs.
