# Sticky `--rules` / `--default-account` are silent; a bare `--csv` refresh wipes them

**Severity:** major. **Estimate:** 30–45 minutes. **Owner:** cli. **A1:** after
seeding import memory with `--rules` and `--default-account Expenses:Misc`, a
flag-free re-import silently keeps applying them (human note only names column
mapping + date-format; JSON has no `rules` / `default_account` fields). Re-passing
`--csv` alone then clears rules and resets the default to
`Expenses:Uncategorized` with no warning — agents lose categorization without
knowing memory changed.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `ea146087`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only. Evidence: `cli/tmp/qa-20260915/c515/`.

## Repro

```sh
# fresh BEA_CONFIG_DIR; opens Checking / Groceries / Misc / Uncategorized
printf 'Date,Description,Amount\n2024-04-01,WHOLE FOODS,-10.00\n2024-04-02,Other,-5.00\n' \
  > bank.csv
cat > rules.toml <<'EOF'
[[rule]]
match = "whole foods"
account = "Expenses:Groceries"
EOF

bea --file main.bean import bank.csv \
  --csv date=Date,amount=Amount,narration=Description \
  --account Assets:Bank:Checking --rules rules.toml \
  --default-account Expenses:Misc
# remembers mapping + rules + Misc

bea --file main.bean import bank.csv --account Assets:Bank:Checking
# stderr: only "Using remembered column mapping … (--date-format …)."
# WHOLE FOODS → Groceries; Other → Misc — rules/default applied, never named

bea --json --file main.bean import bank.csv --account Assets:Bank:Checking
# config_source=remembered --csv; config is columns only — no rules / default_account

# refresh mapping without re-passing sticky knobs:
bea --json --file main.bean import bank.csv \
  --csv date=Date,amount=Amount,narration=Description \
  --account Assets:Bank:Checking
bea --json --file main.bean import bank.csv --account Assets:Bank:Checking
# both rows → Expenses:Uncategorized; rules gone
```

## Expected

Human + JSON disclose sticky `--rules` and `--default-account` the same way the
note already names `--date-format`. Re-passing `--csv` alone should keep prior
sticky categorization (or warn before clearing).

## Actual

`cli/commands/import_.py` recall restores `rules` / `default_account` but the
remembered note (~column mapping + date-format only) and JSON envelope omit
them. Any new `--csv` run re-remembers `rules=None` and
`default_account or "Expenses:Uncategorized"`, wiping prior sticky values.

## Fix

Emit `rules` + `default_account` in the remembered note and JSON. On `--csv`
without those flags, preserve prior sticky values (or warn before clearing).
Regression: after the seed above, flag-free JSON exposes the rules path and
`Expenses:Misc`; bare `--csv` refresh does not silently uncategorize.
