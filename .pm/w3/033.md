# Related Files links navigate to a missing route

Severity: **minor**. Owning package: **dashboard**. Estimate: **20–30 minutes**.

Production `https://beancount.io`, 2026-09-08, Chrome152, English, System/light;
authenticated QA reader of public `open_ledger/walmart`, no write permission.
Desktop1440×1000 and fresh narrow390×844. Deployed SHA unverified; local
`a315c273` and fetched `origin/main cc3f4c2f` have the same implicated files.

1. Open `/ledger/open_ledger/walmart/documents?lang=en`. Wait for **No documents
   found in this ledger.**
2. Under **Related Pages**, activate **Files**. Its href is
   `/ledger/open_ledger/walmart/files`. The app leaves the ledger layout and
   displays **404 / Page not found** with **Go Home** and **Go Back**.
3. Repeat from a fresh390px page: same result. The Files links on `/events`,
   `/errors` and `/import` also reach this missing route at desktop width.
4. Working controls: **Go Back** returns to Documents. The sidebar's **Files**
   link reaches `/ledger/open_ledger/walmart/files/tree/main`, which loads the
   public folder list, including FY2027.

Expected: every advertised Files link opens the current ledger's root file
browser. This journey needs no write permission or production mutation.

The missing route displays the app's404 screen, but a direct HTTP read returns
200, as does the working file-browser route. Do not report an HTTP404 or a
backend outage. No console errors were captured. There is no failing GraphQL
operation behind the broken link: the client selected a nonexistent route.
The source page's empty state is valid; `getLedgerErrors` also returns200 and
zero errors for Walmart and all four tested personal example ledgers.

Root cause: six RelatedLinks callers supply the incomplete URL:

- `features/ledger-data/documents/index.tsx:238`
- `features/ledger-data/events/index.tsx:264`
- `features/ledger-data/errors/index.tsx:170`
- `features/importer/pages/import-page.tsx:54`
- `features/ledger-editor/create-file/index.tsx:209`
- `features/ledger-editor/upload-files/index.tsx:368`

All paths above are inside `dashboard/src/`. The first four callers are
independently reproduced; create/upload pages are source-traced only.

passes it straight to TanStack Link. The registered directory route is
`routes/ledger.$ledgerOwner.$ledgerName.files.tree.$branch.$.tsx:5–8`; there is
no base `/files` route or redirect. The sidebar at
`common/components/ledger-layout/ledger-sidebar.tsx:437` and
`common/hooks/use-file-navigate.ts:48–58` use the working tree/main contract.
