# `bea format a.bean b.bean` (multi-file, not `-i`) exits 2 with raw bean-format Click help instead of a bea usage error

**Severity:** minor. **Estimate:** 15–25 minutes. **Owner:** cli. **A2:** a
newcomer (or agent) formatting two paths to stdout gets upstream
`bean-format` usage text (“Output option can only be used with a single
FILENAME”) rather than a clear bea message to use `-i` or one file.

Found 2026-09-15 by continuous CLI QA against `main`, HEAD `74b59632`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
bea format a.bean b.bean
echo exit=$?
# exit 2
# Usage: bean-format [OPTIONS] [FILENAMES]...
# Error: Output option can only be used with a single FILENAME.
#        Try in-place option instead.
```

Working controls:

```sh
bea format a.bean              # formatted text on stdout, exit 0
bea format -i a.bean b.bean    # rewrites both, exit 0
bea --json format -i a.bean b.bean
# envelope scanned/formatted lists both paths
```

`--json format a.bean b.bean` (no destination) already has a clear bea usage
error about needing `-i`/`-o`/`--check`/`--dry-run`.

## Expected

Refuse multi-file stdout (and multi-file `-o`) with a bea `usage` error naming
`-i` or a single path — same clarity as the JSON destination check. Do not
surface raw `bean-format` Click help as the primary message.

## Actual

`format.py` forwards every path to `bean-format` without `-i`; upstream rejects
multiple filenames when writing to stdout. `launch.run_native` returns exit 2
and the frontend exits with that status, leaking the child help text.

## Root cause

```text
cli/src/cli/commands/format.py:93-98
  status = launch.run_native("bean-format", [..., *files])
  if status != 0: raise typer.Exit(status)
# no preflight when len(files) > 1 and not in_place and output_file is None
```

## Fix

Before calling `bean-format`, if `len(files) > 1` and not `--in-place` (and not
`--check`/`--dry-run`), raise `UsageError` such as: “Formatting multiple files
to stdout is unsupported; pass --in-place, or format one file.” Keep single-file
stdout and multi-file `-i` green. Regression: two-file stdout exits 2 with that
message; `bea format -i a b` still formats both.
