## Objective

Resolve the active application's date-fns locale once through shared dashboard formatting infrastructure while preserving per-request localization and lazy loading.

## Context

- The seven callers and pinned date-fns fallback are documented in this milestone README.
- src/i18n/config.ts owns fifteen supported languages; src/i18n/init.ts owns isolated localization and language transitions.
- Completed w2/m21 forbids eager unused-language downloads and shared mutable SSR language state.

## Steps

1. Use the installed date-fns locale option, with explicit mappings for supported language codes. Reuse its duration rules and suffixes; do not reimplement them.
2. Integrate locale availability with the existing localization transition so loading, superseded changes and failed loads keep a coherent current language and retry path.
3. Expose the smallest common formatter or hook needed by the callers, including the calendar's locale object. The pinned react-day-picker/locale/* modules extend compatible date-fns locales with accessibility translations; retain those labels and use explicit lazy imports or an equally small shared arrangement. Avoid global setDefaultOptions and eager all-locale imports.

## Files

- dashboard/src/common/lib/format/ and an owning common hook if needed
- dashboard/src/i18n/init.ts and src/i18n/config.ts

## Acceptance criteria

- [ ] The formatter selects the active app language, even when the browser preference differs.
- [ ] English/Chinese controls use the same dates and duration semantics.
- [ ] Concurrent requests cannot overwrite each other's locale, and unused languages are not eagerly loaded.
- [ ] The calendar can reuse the selected locale with upstream label extensions; the relative formatter accepts the same language without a duplicate per-feature mapping.

## Out of scope

Typed-date formatting/parsing policy, API timestamp changes, auth gates, manual
language/URL precedence repair027, social pagination, avatar delivery, new
dependencies, private data and real bank/ledger mutations.
