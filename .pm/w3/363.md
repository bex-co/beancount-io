# `bea doctor linked` / `doctor region` exit 0 on empty scope (missing link or no entries)

**Severity:** minor. **Estimate:** 20–40 minutes. **Owner:** cli. **A1:** an
agent that runs `doctor linked main.bean ^typo` (or `doctor region main.bean
999:999`) gets exit **0** and only `Net Income: ()` — no tree and no “not
found” — while `list transaction --link typo` at least says nothing matched.

Found 2026-09-16 by continuous CLI QA ([c1060 hunt](7f217543-571e-4dd1-a404-64964a834a89)),
HEAD `0ec10e36`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Confirmed
`cli/tmp/qa-20260915/c1060/`. Evidence: `c1060/`.

## Repro

```sh
# ledger has ^coffee-jan only
bea doctor linked linked.bean ^does-not-exist
# exit 0 — blank tree; "Net Income: ()"

bea doctor region linked.bean 999:999
# exit 0 — same empty success shape

# control
bea doctor linked linked.bean ^coffee-jan
# exit 0 — Cash / Food tree; Net Income: (-5 USD)
```

## Expected

Nonzero exit or an explicit empty-scope diagnostic — not silent success that
looks like a balanced empty ledger.

## Actual

Wrappers forward to `bean-doctor`; empty link/region prints `Net Income: ()`
with exit **0**.

## Fix

Detect empty scoped output and raise a clear error, or patch upstream to exit
nonzero. Regression: missing-link exits nonzero with a message; valid-link
unchanged.

## Dedupe

Not w3/352 (fraction tree when rows exist). Not w3/355 / 345. No open note on
empty-scope false-success for `linked` / `region`.
