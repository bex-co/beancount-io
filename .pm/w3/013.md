# Public-ledger Sharing and Git Clone copy buttons have no accessible names

**Severity:** minor — assistive-technology users encounter two indistinguishable
unnamed buttons. **Estimate:** 30–45m, including both callers, localized labels and focused
accessibility coverage. **Pillar:** A3 — sharing a public example is usable
through the keyboard and accessibility tree.

Reproduced 2026-09-08 on production, Chrome 152, English/light, authenticated
QA reader of synthetic public `open_ledger/example`, source `a315c273`;
deployed SHA unverified. Fresh desktop 1440×1000 and narrow 390×844 repeats.

1. Open `/ledger/open_ledger/example/settings` and locate Public Sharing.
2. Focus the named **Shareable URL** field, then press Tab. Focus reaches a
   native button with empty text and no accessible name.
3. Focus **Embed Code**, then Tab. Focus reaches a second unnamed button.
4. Fresh desktop/narrow accessibility snapshots expose each simply as `button`;
   neither identifies its copy action or the content it copies.

Expected: distinct localized names such as **Copy shareable URL** and **Copy
embed code**, retained when the Copy icon changes to Check. The visible fields
already have correct accessible names and both buttons are keyboard-focusable.
The read-only URL and generated embed iframe/link correctly target the public
example; inert HTML parsing confirms the code is not malformed. Clipboard
writes and actual cross-site iframe rendering were not exercised.

Root cause: `dashboard/src/features/ledger-data/settings/visibility-section/index.tsx:214–227,241–252`
renders icon-only Buttons without text, `aria-label` or `aria-labelledby`.
The associated Labels name the input/textarea, not their sibling buttons.
One `VisibilitySection` production caller exists, in Settings at 75. The
share controls appear for public ledgers; no API change is needed.

Fix in **dashboard**: give each button a persistent distinct localized name
that describes its action and target. Keep the name available through the
copied/check state and error recovery. Preserve existing focus order, copy
handlers and feedback; use the existing locale conventions across supported
languages. The names must not depend on hover-only tooltips.

Additional reproduced caller: on public
`/ledger/open_ledger/budgeting-envelopes/files/tree/main`, open Git Clone.
Both SSH and HTTP tabs contain an unnamed icon-only copy button. Tab from the
URL field reaches it, but its accessibility snapshot only says `button`; text,
aria-label and title are all absent. A fresh desktop reload reproduces this.
An already-open popover resized to 390×844 still exposes the unnamed control;
the Git Clone trigger is intentionally hidden on fresh narrow pages.

`dashboard/src/features/ledger-editor/directory-browse/components/ledger-clone-url-menu.tsx:70–88`
renders both protocol copies through `CloneUrlInput`, with no accessible name
in either Copy or Check state. Its sole production caller is
`ledger-directory-view.tsx:182`. Extend this same naming repair to the clone
control with a localized action/target name such as Copy SSH clone URL and
Copy HTTP clone URL. Pass the protocol context into its input component;
preserve the existing URL, copy logic and feedback. No shared API or cross-feature
import is needed. History af5339de → aeec496b → aa0cbd3e leaves this omission
unchanged; the latest change concerns the Download ZIP cursor.
