# Remembered CSV `sign=ledger` silently flips later same-header bank exports

**Severity:** major. **Estimate:** 30–45 minutes. **Owner:** cli. **A1:** after one
`--csv …,sign=ledger` import, any later flag-free import of a different file that
shares the same header + `--account` reuses `sign=ledger` and inverts every
amount (Coffee `-4.50` becomes `+4.50` on the asset), while
`IMPORTING.md` already refuses to sticky-remember inferred `--date-format`
because “two exports can share a header row without sharing a date convention.”

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `0ab6cf85`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated `BEA_CONFIG_DIR` /
`XDG_CACHE_HOME`. Synthetic fixtures only.

## Repro

```sh
# fresh config dir; ledger with Assets:Bank:Checking + Expenses:Uncategorized open
printf 'Date,Description,Amount\n2024-03-01,Coffee,-4.50\n2024-03-02,Paycheck,1000.00\n' \
  > bank.csv
printf 'Date,Description,Amount\n2024-04-01,Cafe,4.50\n' > ledger-sign.csv

bea --json --file main.bean import bank.csv --csv auto --account Assets:Bank:Checking
# Coffee → Assets:Bank:Checking -4.50 USD (bank sign, correct)

bea --json --file main.bean import ledger-sign.csv \
  --csv date=Date,amount=Amount,narration=Description,sign=ledger \
  --account Assets:Bank:Checking
# updates remembered mapping for this header+account to include sign=ledger

bea --json --file main.bean import bank.csv --account Assets:Bank:Checking
# config_source: remembered --csv
# config: …,sign=ledger
# Coffee → Assets:Bank:Checking +4.50 USD  ← inverted vs first preview
```

Working controls:

- Same `bank.csv` with an explicit `--csv auto` again restores bank sign.
- A changed header row does not hit the poisoned memory (documented).

## Expected

Sign convention should follow the same safety rule as date format: either do not
remember `sign=` across files, or remember it only when the caller passes it on
that invocation, and never apply a sticky `sign=ledger` to a later flag-free
import of a different export that merely shares headers. Prefer matching the
documented date-format policy.

## Actual

Memory is keyed by root ledger + header row + source account. An explicit
`sign=ledger` becomes part of that blob, so any later same-header bank export
imported without `--csv` silently negates amounts.

## Fix

Stop persisting `sign=` in the remembered mapping (like inferred date-format),
or persist it but require an explicit `--csv` / `--sign` to reuse and print a
loud human+JSON warning when a remembered sign is applied. Regression: the
three-step repro above keeps Coffee at `-4.50` on the third preview; an
intentional same-file reimport with `sign=ledger` still works when passed
explicitly.

## Dedupe

Not w3/256 (parse of `$` / thousands / parentheses). Not w3/226 (delimiter /
EU decimal). No open note covers sticky remembered `sign=` flipping amounts.
