# `bea list open` drops the booking method (`"FIFO"` / `"STRICT"` / …)

**Severity:** minor. **Estimate:** 15–25 minutes. **Owner:** cli. **A1:** an
agent that opens a brokerage account with an explicit booking method and later
`list open` / JSON-inspects the books cannot recover `"FIFO"` / `"STRICT"` /
`"NONE"` / `"AVERAGE"` — only date, account, and currencies — so lot-matching
policy is invisible on the read path.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `f0783e97`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
cat > main.bean <<'EOF'
option "operating_currency" "USD"
2020-01-01 open Assets:Brokerage HOOL "FIFO"
2020-01-01 open Assets:Cash USD
EOF

bea --file main.bean list open
# DATE / ACCOUNT / CURRENCIES only — no booking column

bea --json --file main.bean list open
# [{"date":"2020-01-01","account":"Assets:Brokerage","currencies":["HOOL"]},
#  …]  ← no "booking": "FIFO"
```

Working control — the directive is valid and check-clean:

```sh
bea --file main.bean check   # exit 0
grep FIFO main.bean          # still on the open line
```

## Expected

`list open` (human + JSON) exposes the optional booking method when present,
e.g. JSON `"booking": "FIFO"` or `null` when omitted. Human table can add a
BOOKING column or show it beside currencies.

## Actual

`OpenDirective` has only `date`, `account`, `currencies`. `list_opens` never
reads `entry.booking`.

## Root cause

`cli/src/bea_engine/ledger/models.py` `OpenDirective` omits `booking`;
`cli/src/bea_engine/ledger/reader.py` `list_opens` (~254) constructs without
`entry.booking`.

## Fix

Add optional `booking: str | None` to `OpenDirective`, populate from
`entry.booking` (stringify the Beancount booking enum), and render it in the
list table / JSON. Regression: the FIFO fixture above returns `"booking":
"FIFO"`; opens without a method return `null` / empty.

## Dedupe

Not w3/289 (user metadata on list types — booking is a first-class Open field,
not `meta`). Not w3/241 (report conversion of `@`-priced inventory). No open
note covers `list open` dropping booking.
