## Objective

Publish complete row values and validity together after every committed edit, preserving unrelated errors and pending edits.

## Context

Read the parent milestone for exact production evidence, source trace, working
controls and limits. Follow dashboard and importer guidance. This is the sole
implementation queue for promoted038 and its reproduced error-loss extension.

## Steps

1. Validate the entire current candidate, including preserved parser diagnostics, rather than treating trigger(field)'s partial error state as whole-row validity. Use the validation result directly instead of assuming a form-state snapshot contains all current errors.

2. Keep preview counts and workflow rows synchronized with that result. Editing a payee alone in either rejected fixture row must retain the date/amount error; correcting the actual field must clear only the resolved diagnostics.

3. Make Enter/blur, Escape cancellation and Continue transitions coherent with pending validation. Preserve committed values during fast successive edits and retain037's row-identity contract without duplicating its deletion fix.
