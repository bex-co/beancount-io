## Objective

Correct three exemption strings that were true when written and stopped being true with nothing to notice. Each is a one-line edit; the value is that ADR 0008's decisions exist because of them, so the record and the table should agree before anything is built on either.

## Context

- `src/server/api/op-class.ts` — `VERB_TABLE` and the `M` / `R` exemption category constants.
- **`Mutation.bulkEntries`** (class `write`) carries the `runBqlQuery` escape hatch. BQL is a query language and cannot append a directive. 29 of the 30 rows carrying that category are reads; this is the one write. The verb *is* reachable from MCP — through `editLedgerFiles`, by writing the directive text — so the conclusion survives while the argument for it does not.
- **`Query.listLedgers`** carries `notAgentShaped`. That held only because ADR 0007 D3 pinned every credential to one ledger: with one reachable ledger, listing them returns what the agent already knows. ADR 0007 D11 inverts it.
- **`M.notAgentShaped` itself** argues about "selection accuracy for the four that matter". `MCP_TOOLS` has seven entries — ADR 0006 D6 added the three API-key tools afterwards.

## Steps

1. Give `bulkEntries` an exemption naming `editLedgerFiles`, or add a category for it if one row does not justify a new constant.
2. Add the ADR 0007 D3 dependency citation to `listLedgers`. Do **not** reverse it here — that belongs with D11's implementation.
3. Fix the count in `M.notAgentShaped`, or reword so no count appears.
