# Bulk JSON `amount` shorthand rejects lot/cost strings with a misleading “must be a string” error

**Severity:** minor. **Estimate:** 15–25 minutes. **Owner:** cli. **A1:** an
agent that ports a working CLI posting (`1 AAPL {100 USD}`) into bulk JSON as
`"amount": "1 AAPL {100 USD}"` is told the amount must be a string (it already
is) instead of being pointed at `units` + `cost`.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `a5019de4`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
printf '%s\n' '[{"date":"2020-02-01","narration":"x","postings":[
  {"account":"Assets:Broker","amount":"1 AAPL {100 USD}"},
  {"account":"Assets:Cash","amount":"-100 USD"}]}]' > lots.json

bea --file main.bean add transactions --from lots.json
# exit 1
# Row 1, postings.0: Value error, amount must be a string such as '-30 USD'.
```

Working controls:

```sh
# CLI posting string (same lot syntax) works:
bea --file main.bean add transaction --date 2020-02-01 --narration z \
  --posting 'Assets:Broker 1 AAPL {100 USD}' --posting 'Assets:Cash -100 USD'

# JSON units+cost works:
# {"account":"Assets:Broker","units":{"number":"1","currency":"AAPL"},
#  "cost":{"number":"100","currency":"USD"}}
```

## Expected

Either accept inventory/cost in the `amount` shorthand (parity with `--posting`),
or reject with a message that names the two-token limit and points to
`units`/`cost` — not “must be a string” when the value is already a string.

## Actual

`Posting.amount_shorthand` in `bea_engine/ledger/models.py` requires
`isinstance(amount, str) and len(amount.split()) == 2`. Lot strings fail the
length check and raise the same ValueError used for non-strings.

## Fix

Split the errors: non-string → type message; string with ≠2 tokens → “amount
shorthand is 'NUMBER CURRENCY' only; for costs/prices use units and cost/price
objects” (and show the example). Optionally later parse full posting text.
Regression: the lot `amount` repro gets the clearer message (or succeeds if
parsing is added); `"-30 USD"` unchanged.

## Dedupe

Not w3/260 (JSON float amounts). Not w3/261 (empty postings). No open note
covers amount-shorthand vs lot/cost CLI/JSON asymmetry.
