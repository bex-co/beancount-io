## Objective

Close the milestone once its definition of done actually holds — not merely once the code is written.

## Context

The DoD in `w3/m44/README.md` is a behavioral matrix, and the check is that it is real: the three-kind live/revoked matrix passes, the indistinguishability holds, an unauthenticated caller is refused, `lastUsedAt` is untouched, the parity gate is green with no ceiling raised, and ADR017 exists. If any of it does not hold, this task does not run — the milestone is blocked or gains a task.

## Steps

1. Verify the DoD against the repository, not against the task list.
2. Set every remaining task's `status: done`; move each `tNNN.md` to `w3/m44/done/`.
3. Mark every row `— **DONE**` and set `**Status:** done` in `w3/m44/README.md`.
4. Add a closeout note to the milestone README recording what was decided in ADR017 and whether the GraphQL/MCP twins were built or exempted — those two decisions are what a later reader will want.
5. Move `w3/m44/` to `w3/done/m44/` and check `- [x]` in `w3/README.md`.

## Acceptance criteria

- [ ] The DoD holds, verified against the repository.
- [ ] The milestone exists only at `w3/done/m44/`, its README says `**Status:** done`, and the workstream checkbox is checked.
- [ ] The closeout note records the ADR017 decisions and the parity outcome.
