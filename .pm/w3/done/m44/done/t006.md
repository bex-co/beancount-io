## Objective

The repo rule is that every customer-facing capability reaches REST, GraphQL and MCP wherever protocol and credential policy permit, and the surface-parity gate keeps eligible gaps at zero. Introspection is REST-native. Decide honestly whether the GraphQL and MCP twins should exist, build what should, and write a real argument for what should not.

## Context

- `src/server/api/op-class.ts` holds the verb registry, the `restExempt`/`mcpExempt` reason vocabulary (`R.*`, `M.*`), and `isInParityScope`, which decides whether an absence counts as debt or is settled as out of reach.
- Existing reasons worth reading before writing a new one: `R.credentialMinting` / `M.credentialMinting` ("credential minting is deliberately unreachable by a token credential (ADR 0006 D6) … an agent minting its own successor credential is precisely the loop that rule closes") and `M.notAgentShaped` (deferred on tool budget, explicitly not permanent).
- Introspection is not minting — it reads a credential's status. Whether it is *agent-shaped* is a genuine question: an agent runtime brokering tokens has a use for it; an agent doing ledger work does not, and ADR 0008 D5 makes the tool list a budget.
- The caller-authentication policy from ADR017 constrains this. If only a full signed-in session may introspect, a GraphQL twin is natural and an MCP tool is close to unusable by the clients that would want it — that is a credential-policy argument, which the parity rule accepts, and it must be written as one.
- ADR 0008's recurring failure mode is a category outrunning its argument: reusing an existing exemption reason because it is nearby, when its actual claim is false for this verb. Do not do that here.

## Acceptance criteria

- [ ] The verb has an `op-class.ts` entry.
- [ ] Each surface either carries it or has an exemption whose stated reason is true of *this* verb specifically — no reused category that does not fit.
- [ ] The surface-parity zero-debt gate and op-class coverage test are green, with no ceiling raised and no eligibility weakened to get there.
- [ ] If a twin is built, it calls the same handler logic as REST so the two cannot drift.

## Out of scope

Porting any other verb. Changing the parity ratchet's counting rules.
