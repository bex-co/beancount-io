# `bea add open --currency` keeps padded/blank tokens on disk; list shows trimmed

**Severity:** minor. **Estimate:** 15–25 minutes. **Owner:** cli. **A1:** an
agent that passes `-c ' USD '` or blank `-c '   '` beside a real symbol gets
exit **0**; disk keeps padding/empty slots while `list open` returns trimmed
symbols only.

Found 2026-09-16 by continuous CLI QA ([c830 hunt](ac51785a-b31c-4bf5-934b-d020fad42816)),
HEAD `265de8b7`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Confirmed
`cli/tmp/qa-20260915/c831/`. Evidence: `c830/`.

## Repro

```sh
bea --file main.bean add open --date 2024-02-01 --account Assets:Spaced \
  --currency ' USD ' --currency EUR
# disk: open Assets:Spaced  USD ,EUR

bea --json --file main.bean list open --account Spaced
# currencies: ["USD","EUR"]

bea --file main.bean add open --date 2024-02-02 --account Assets:Mixed \
  --currency '   ' --currency USD
# disk: open Assets:Mixed    ,USD
# list: ["USD"]
```

## Expected

Strip/reject blank currency tokens before write so disk, add JSON, and list
agree.

## Actual

Add forwards argv unchanged; reader normalizes on load — views diverge.

## Fix

Strip each `-c`, drop blanks, reject if none remain. Regression: repro writes
clean `USD,EUR` / `USD`; list matches disk.

## Dedupe

Not w3/287 (list empty `--currency`). Not w3/255 (other empty add strings).
No open note covers padded/blank `-c` on **add open**.
