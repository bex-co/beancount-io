# `bea report * -i weekly -t YYYY-MM` appends a spurious month-end period when the last ISO week already closes the month

**Severity:** minor. **Estimate:** 30–60 minutes. **Owner:** cli. **A1:** an agent
running `report income-statement -t 2020-03 -i weekly` gets a sixth weekly row
dated **2020-03-31** with **zero P&L** even though all March activity is in
buckets through **2020-03-29**.

Found 2026-09-16 by continuous CLI QA ([c1200 hunt](b051fc5b-aacd-443f-a19c-0ce8562afaa1)),
HEAD `1cf56931`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Confirmed
`cli/tmp/qa-20260915/c1200/`. Evidence: `c1200/`.

## Repro

```sh
bea --file main.bean report income-statement -t 2020-03 -i weekly
# Weekly breakdown ends with 2020-03-31  0.00 USD …

# control: -t "2020-03-02 - 2020-03-29" -i weekly ends at 2020-03-29
# contrast: -t 2020-12 -i weekly keeps 2020-12-31 when a txn falls that day
```

## Expected

Weekly buckets for a calendar-month filter stop at the last ISO week that
intersects the month unless later-dated activity needs a month-end bucket.

## Actual

Calendar `-t YYYY-MM` unconditionally adds a month-end weekly anchor; quiet
stubs look like an extra inactive week / duplicate cumulative snapshot.

## Fix

Suppress the stub when the last ISO week already covers the filter and no
entries follow. Keep December-style padding when needed. Regression: March
ends 2020-03-29; December 2020-12-31 unchanged.

## Dedupe

Not w3/349 (series stops early vs as_of). Not w3/373 / 374. No open note on
spurious month-end weekly padding for calendar-month filters.

---

**Resolved 2026-09-17** — A `--time` filter that ends partway through an
interval leaves the last bucket a fragment of it (`-t 2020-03 -i weekly` ends on
the Mon–Tue tail of an ISO week running into April). Flow series — income
statement periods and the overview's income/expense series — now drop that
fragment when no entries fall in it (`fava.modules.chart._flow_ranges`), so
March ends on 2020-03-29; a fragment holding entries keeps its bucket, so
December still reports 2020-12-31, and a short filter keeps its only bucket.
Balance series (net worth, assets, liabilities, equity) keep every bucket so
they still reach the as-of date, and the overview table now joins on the union
of valuation dates instead of the flow spine, so its as-of row survives.
Documented in `cli/docs/USAGE.md`; covered by
`cli/tests/test_report_weekly_month_end_fragment.py`. Shipped with this board
close.
