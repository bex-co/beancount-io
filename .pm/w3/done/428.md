# `bea ask -p '   '` sends a whitespace-only question to the hosted AI (empty is refused)

**Severity:** minor. **Estimate:** 10 minutes. **Owner:** cli. **A1:** an
agent filling a template hole with spaces spends a hosted request (and quota)
instead of getting the usage error an empty question gets.

Found 2026-09-26 by CLI QA (`qa-find-bugs-cli`) against `main` HEAD
`8cd9732b`, `uv run bea` 0.3.0, Darwin 26.5.1 arm64. Simulated with a
placeholder `BEA_TOKEN` and `BEA_API_URL=http://127.0.0.1:9` (nothing
listening), so no real request left the machine.

## Repro

```sh
BEA_TOKEN=placeholder BEA_API_URL=http://127.0.0.1:9 bea --file main.bean ask -p ''    </dev/null
BEA_TOKEN=placeholder BEA_API_URL=http://127.0.0.1:9 bea --file main.bean ask -p '   ' </dev/null
```

The first exits 2: `A question is required without a terminal (or with
--print).` The second attempts the network call (`Error: Connection error.`,
exit 1); against a real server it would send the ledger context with a blank
prompt.

## Root cause / fix

`cli/src/cli/commands/ask.py:71` tests `if not question`. Use
`if not (question or "").strip()` (same blank policy as `refuse_blank_filter`
in `cli/src/cli/utils.py:65`), and in the interactive path treat a blank
`default_input` as absent.

## Acceptance

- `ask -p '   '` exits 2 with the same message and makes no request; a test
  asserts the agent is never invoked.

## Dedupe

No `.pm` item mentions a blank `bea ask` question (w3/195 is the dashboard
`q` parameter).

---

**Resolved 2026-10-02** — Empty and whitespace-only questions now receive usage exit 2 before AI imports, credential lookup, or agent construction in print and noninteractive modes. A blank interactive starting question leaves the prompt empty; nonblank question text is preserved. Shipped in `7cd0c012` (`cli`). Triage reproduced the reported empty-versus-spaces distinction against a closed localhost port. Eight regression cases failed before the fix, covering ordinary and Unicode whitespace, a local model server receiving the unwanted request, and the interactive default; the nonblank request control passed. All 50 focused ask tests passed. `make check-all` passed with 2,386 tests and one skip, and the public-tree secret scan passed. Documentation records the blank-input policy; all model traffic in tests stayed on localhost and all ledgers were synthetic.
