## Objective

The `ask` section promised that interactive writes are confirmed and that
`--into` chooses an included destination, but said nothing about which file the
confirmation names, what the panel does with untrusted bytes, or what a Ctrl-C
and a failed turn cost. State the contract the code now keeps.

## Context

- `cli/docs/USAGE.md`, the `bea ask` section.
- `docs/REFERENCE.md` is generated from the option surface, which did not change,
  so no regeneration is needed (`make docs-check` passes).

## Steps

1. Say that the confirmation names the file the write will change — the `--into`
   destination, not the root — and that the directive is shown with control
   characters escaped, and that raw text carrying one is refused.
2. Say that one turn is the unit of failure: Ctrl-C clears the line or abandons
   the turn, Ctrl-D exits, a failed turn returns to the prompt with the history,
   a rejected credential ends the session with exit 3, and each question has a
   fixed budget of requests and ledger queries.
