## Objective

`KeyboardInterrupt` and `EOFError` shared one handler, so Ctrl-C — advertised by
the session's own help as "cancel current input" — exited and discarded the
conversation; and nothing caught what the turn itself could raise, so one
transient failure ended the process. Make one turn the unit of failure.

## Context

- `cli/src/cli/ask/repl.py` — the read loop and the `agent.run_sync` call.
- `cli/src/cli/output.py` — `error()` is `NoReturn`; a session needs the same
  rendering without the exit.

## Steps

1. Split the prompt handlers: Ctrl-C continues the loop, Ctrl-D keeps `Goodbye.`.
2. Stop the spinner before any arm prints, then map a mid-turn Ctrl-C to a
   `(cancelled)` line and anything else to `output.failure`, leaving `messages`
   untouched in both arms so the next question still carries the history.
3. Re-raise `AuthError` deliberately: every later turn would fail the same way,
   and exit 3 stays the documented answer for a rejected credential.
4. Add `output.failure` beside `error`, sharing one `_print_failure` renderer.

## Files

- `cli/src/cli/ask/repl.py`
- `cli/src/cli/output.py`

## Acceptance criteria

- [x] Ctrl-C at the prompt keeps the session; a following question still answers
      and still carries the earlier turn.
- [x] A mid-turn Ctrl-C prints `(cancelled)` and leaves the history unchanged.
- [x] A failed turn prints `Error: …` on stderr and the session answers the next
      question.
- [x] Ctrl-D exits 0; a rejected credential ends the session with exit 3.
