## Steps

1. Express `single_line()` and the new `inert_text()` through one
   `_escape_controls()` helper, so the control-character → `\xNN` mapping exists
   once on the frontend side.
2. Reuse the engine's existing `CONTROL_CHARACTERS` for the write-path refusal
   instead of adding a second pattern; tab is the single documented exception.
3. Share one text renderer (`_print_failure`) between `output.error` (fatal) and

4. Build the usage budget in one `usage_limits()` used by both call sites.
