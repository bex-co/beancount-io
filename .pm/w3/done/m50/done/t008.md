## Objective

Pin every rule this milestone shipped, on the surface where it can actually fail.
A piped capture strips control sequences and the session's prompt never appears
without a terminal, so the rendering and interrupt rules need a real PTY and
assertions on emitted bytes.

## Context

- `cli/tests/conftest.py` gains a local OpenAI-protocol stub model server and a
  PTY runner for `bea ask`, so no test needs hosted AI quota.
- Existing patterns: `cli/tests/test_control_character_sanitization.py` (byte
  assertions on a PTY), `cli/tests/test_interrupt_contract.py` (keystrokes).

## Steps

1. `cli/tests/test_ask_consent_surface.py` — the refusal (unit, per payload
   class), the panel's destination and escaping (unit, recorded Rich console),
   and three PTY cases: an armed directive reaches neither the ledger nor the
   screen raw, an approved `--into` write lands in the named file, and the
   `--print` answer channel is neutralized.
2. `cli/tests/test_ask_session_resilience.py` — the budget is set and spent, SDK
   failures are retold without their vocabulary, the HTTP table still wins, plus
   a scripted `run_repl` covering Ctrl-C at the prompt, Ctrl-C mid-turn, a failed
   turn and the deliberate auth exit; and two PTY cases (Ctrl-C keeps the session
   and its history, a tool loop stops at the CLI's ceiling).
3. Update `test_feedback_regressions.py` for the widened confirm callback.
