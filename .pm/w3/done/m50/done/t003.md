## Objective

The panel was titled with the root ledger even under `--into`, which appends to
an included file, and Rich trimmed that path to the frame width without an
ellipsis. The engine's pre-approval dry run already returns the true `target`;
the frontend threw it away.

## Context

- `cli/src/cli/ask/agent.py` — `write_directive` used only `preview["token"]`.
- `cli/src/cli/ask/repl.py` — `make_confirm_fn` bound `deps.file` once, so the
  title could never reflect `--into`.

## Steps

1. Widen the confirm callback to take the directive, the resolved target and the
   dry run's warnings; pass `preview["target"]` and `preview["warnings"]`.
2. Move the destination into the panel body (`File: …`) and give the panel a
   fixed title, so a long absolute path wraps instead of being silently cut.
3. Show the dry run's warnings on the panel too — they are part of what is being
   consented to.

## Files

- `cli/src/cli/ask/agent.py`
- `cli/src/cli/ask/repl.py`

## Acceptance criteria

- [x] With `--into side.bean`, the callback receives the resolved `side.bean`
      path and the panel prints it in full at 100 columns.
- [x] The approved write lands in that file and leaves the root byte-identical.
- [x] Declining still returns `Write cancelled by user.` and writes nothing.

## Out of scope

- Changing where `--into` resolves to; the engine already decides that.
