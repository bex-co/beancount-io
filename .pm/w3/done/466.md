# Make public-ledger settings read-only for viewers without admin rights

Source: continuous dashboard QA, 2026-10-04.
Pillar: A2 — a visitor opening a public ledger's settings must not be handed editable controls that silently go nowhere.

On a public ledger the signed-in viewer does not administer, the General settings name/description inputs are focusable and editable, yet no Save control exists for them — typing changes local state that can never persist. The section copy also addresses the viewer as the owner ("Update your ledger name", "Control who can access your ledger").

Root cause: `dashboard/src/features/ledger-data/settings/index.tsx:69` gates the General and Visibility sections on bare `<Authenticated>` instead of a write/admin permission, and `general-settings-section/index.tsx` leaves the inputs ungated while only the Save button sits inside `<LedgerAdminPermission>` (lines 160-179). Working control on the same page: the Visibility private/public switch is admin-gated.

Repro: as a signed-in non-admin, open `/ledger/open_ledger/example/settings`, type in Ledger Name — the edit sticks locally with no save path and no permission notice.

Acceptance: viewers without settings-write permission get read-only (or disabled-with-notice) name/description fields and viewer-accurate copy; admins keep the current edit-and-save flow. Add a permission-matrix render test, run the dashboard checks, and ship.

Scope: dashboard ledger-data settings only; no API change (the server already refuses unauthorized saves). Estimated under one hour.

---

**Resolved 2026-10-04** — `GeneralSettingsSection` and `VisibilitySection` now read `useLedgerPermission().isAdmin`. Non-admins get `readOnly` name and description fields with no edit placeholders, and viewer-accurate copy (`*ReadOnly` keys, "Only ledger admins can change them") in all 15 locales. The admin-only public warning styling is no longer shown to viewers. Admins keep the edit-and-save flow and the visibility switch. `settings-read-only.test.tsx` covers the viewer/admin matrix (the viewer cases fail on the old components). Dashboard format, lint, 4,965 tests and build passed. Shipped in `d8bd5112` (`dashboard`).
