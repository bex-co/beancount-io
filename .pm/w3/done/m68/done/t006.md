## Objective

Add tests that assert real behavior and failure modes for token Git auth and for every `gitHttp.passwordAuth` value. No trivial or tautological tests.

## Acceptance criteria

- [ ] Each `info/refs` service and each pack endpoint has a test, crossed with each scope and with a ledger-restricted key.
- [ ] Revoked, expired, and unknown keys get identical 401 responses.
- [ ] A token request does not spend the failed-password budget.
- [ ] Each of `allow`, `warn`, and `deny` is tested on both password paths, with the `warn` log and counter observed.
- [ ] At least one test uses a real `git` client against the proxy and a stub origin, so the hint and the 401 are checked as git presents them.

## Evidence

Added `git-proxy-credentials.test.ts` (4 endpoints x 3 scopes, pinned keys per endpoint, identical 401s, untouched password budget, allow/warn/deny x email/gitea with the warn log and counter, injector chunking at every split) and `git-proxy-real-git.test.ts` (a real `git` client against the proxy and `git http-backend`: token clone/push, scope and pin refusals, revoked key, warn hint on clone and push, deny 401 text). Mutations of the scope check, pin check, counter, injector band-1 rule, and content-length drop each fail tests.
