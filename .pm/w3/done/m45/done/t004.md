Run /simplify over this milestone’s implementation and documentation. Consolidate reusable identity normalization where it improves clarity while preserving the explicit separation between native IDs, generated IDs and legacy lookup.

## Resolution

`/simplify` run with four review agents. Applied: replaced the `(normalized, exact)` boolean product with two named historical formats (which also removed a digest for a format that never existed); compute the postings, description and NFC forms once per row instead of four times; single pass over `hits` carrying the fingerprint instead of computing it twice; dropped a pointless `set`+`sorted` round-trip; narrowed `legacy_ids` to its branch; and pointed `_fingerprint` at `_exact_amount` so the module has one answer to "is this the same amount". Skipped as beyond this diff: threading a `Candidate(key, lossy)` carrier through `answer()` and extracting `_resolve_hits` — noted in the closeout.
