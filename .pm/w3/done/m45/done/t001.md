## Objective

Define a deterministic amount/currency representation for generated IDs and implement it in cli/src/bea_engine/importing.py. Preserve exact Decimal values without context rounding, normalized equivalent spellings, source-account scope, NFC rules and occurrence handling for truly identical rows. Record the chosen compatibility/version strategy for t002.

## Context

See [the milestone](./README.md) for exact reproduction, scope and compatibility requirements.

## Acceptance criteria

- [x] Distinct sub-cent amounts and commodities have distinct generated bases.
- [x] Equivalent decimal spellings and NFC variants have stable identities.
- [x] No native-ID or accounting amount semantics change.

## Out of scope

Backend/API changes, new dependencies, edits to real ledgers and unrelated import behavior.

## Resolution

Generated ids now hash the exact amount with its commodity. `_exact_amount` renders `number.normalize()` with `:f`, so the spellings of one value agree (`-54.20`, `-54.2`, `-54.200` all become `-54.2 USD`) while distinct sub-cent amounts and distinct commodities stay distinct, and `100` never becomes `1E+2`. Source-account scope, NFC rules and occurrence numbering are unchanged.
