## Objective

A debit is money leaving the source account whatever sign the bank printed on
it, and a zero-filled companion column is an empty column. Make the
debit/credit pair branch decide the sign from the magnitude, and refuse a
column that mixes signs instead of guessing.

## Context

- `cli/src/bea_engine/csv_mapper.py:797-804` tests `bool(debit) == bool(credit)`
  on raw strings, so `"0.00"` counts as filled, then negates a debit
  unconditionally — a cell that already carries a minus is negated twice.
- Keep the exact-negation helper `_negated` (`copy_negate`) from `w3/408`: no
  digit may change.
- The frontend twin `cli/src/cli/importing.py` only infers headers; the sign
  logic lives engine-side.

## Steps

1. Parse the filled cell, then take `-abs(n)` for a debit and `abs(n)` for a
   credit, using an exact sign flip.
2. Refuse a debit or credit column that mixes non-zero signs, naming the column
   and the disagreeing rows, rather than guessing a convention.
3. Treat a cell parsing to zero as empty for the "exactly one" rule; keep
   refusing two non-zero cells and handle two zeros like the amount path.
4. Leave `sign=ledger` flipping the resolved number as today.
