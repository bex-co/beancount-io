# Partial-conversion balance sheet says “Net Worth: Unavailable USD” but monthly net-worth series prints per-unit totals

**Severity:** minor. **Estimate:** 20–40 minutes. **Owner:** cli. **A1:** an agent
running `report balance-sheet --allow-errors` on a multi-currency ledger with
missing FX prices reads “Net Worth: Unavailable USD”, then sees **Monthly net
worth** filled with `0.50 BTC  50.00 EUR  100.00 USD` — contradictory signals
on the same screen and in JSON.

Found 2026-09-16 by continuous CLI QA ([c1190 hunt](a8e7be8f-7d1c-494b-991e-b6dea42066ce)),
HEAD `bb84ef00`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Evidence:
`cli/tmp/qa-20260915/c1190/`.

## Repro

```sh
# Cash 100 USD, Wallet 50 EUR, Crypto 0.5 BTC; no EUR/BTC prices
bea --file multi-unit.bean report balance-sheet --allow-errors
# Net Worth: Unavailable USD
# Monthly net worth → 0.50 BTC  50.00 EUR  100.00 USD

bea --json … report balance-sheet --allow-errors
# net_worth {"USD": null}; net_worth_series[0].balance has USD/EUR/BTC
```

## Expected

Headline and interval series agree under partial valuation (both unavailable,
or both per-unit).

## Actual

`_amounts()` renders `null` as `Unavailable USD` for `net_worth`, but series
rows still carry per-unit balances.

## Fix

Align series with partial-valuation policy. Regression: no “Unavailable USD”
paired with populated series; `-x units` unchanged.

## Dedupe

Not w3/313, 304, 241. No open note on net-worth headline vs series under
partial multi-unit conversion.

---

**Resolved 2026-09-17** — The net-worth series now follows the same
partial-valuation policy as the headline it sits under: a row whose balance
still holds a commodity the report could not value reads `null` / `Unavailable
USD` instead of falling back to per-unit amounts, while a row that did convert
keeps its number (January's USD-only `100.00 USD` survives; February and March
go unavailable). The policy has one definition now, `_unvalued()`, shared with
the income statement's per-period net profit, which already behaved this way.
`-x units` and fully priced ledgers are unchanged. Documented in
`cli/docs/USAGE.md`; covered by `cli/tests/test_partial_valuation_series.py`.
Shipped with this board close.
