# Stop repeating account names twice in overview Recent activity rows

Source: continuous dashboard QA, 2026-10-04.
Pillar: A2 — newcomers scanning Recent activity should read each account once, not twice on the same row.

On desktop-width overview rows, the account summary appears twice: once inside the subtitle line ("Eating out with Julie · Slate · Restaurant") and again in the dedicated accounts column ("Slate · Restaurant"). The duplication is in the render, not the data.

Root cause: `dashboard/src/features/reports/overview/components/recent-activity-card.tsx` joins `accountSummary` into the subtitle (lines 269-273) and renders the same `accountSummary` again as its own column (lines 278-282), both visible at `sm:` and up. The column exists so narrow layouts — where it hides — still show accounts via the subtitle.

Repro: open `/ledger/open_ledger/example`, scroll to Recent activity at desktop width; every row names its accounts in both the subtitle and the trailing accounts column.

Acceptance: desktop rows show each account once (subtitle or column, not both) while narrow rows keep the subtitle copy; transfer rows keep their distinct label. Add a render test asserting a single occurrence per row at desktop width, run the dashboard checks, and ship.

Scope: dashboard overview only. Estimated under one hour.

---

**Resolved 2026-10-04** — In `recent-activity-card.tsx` the subtitle's account part is now `sm:hidden` for non-transfer rows, so desktop rows name their accounts once (in the accounts column) while narrow rows, where that column hides, keep them in the subtitle; transfer rows keep accounts in the subtitle beside their Transfer label. `recent-activity-card-accounts.test.tsx` resolves the responsive classes and asserts one visible copy per breakpoint (the desktop case fails on the old render).
