**Resolved 2026-09-11** — fixed and shipped in `4d701a91` (`dashboard`), with the package's full check gate green (format, lint, 3879 tests, build). Triage confirmed the reported root cause against current code before the fix.

Beyond the reported defect, the fix closed a latent crash: TanStack Router surfaces raw URL values through `useSearch` for keys a route's `validateSearch` omits, so `?search=["x"]` reached the Accounts page and threw. Each view now re-coerces at the use site, with a hostile-input regression per suite.
