## Objective

Publish the output contract every MCP tool already has. All seven tools return `structuredContent` and none declares an `outputSchema`, so a client receives structured data it has no contract to validate and the SDK's own output validation is skipped (ADR 0007 D8). Each tool already defines the schema — it is just never registered.

## Context

- `src/features/ai-agent/api/mcp-tools.ts` — the `McpToolDescriptor` interface and the `MCP_TOOLS` fragment; descriptors carry `inputSchema` and no output counterpart.
- `src/server/api/composition-root.ts` — `assembleMcpRegistry` passes each descriptor to `registerTool`.
- `src/features/ai-agent/tools/types.ts` — `toolOutputSchema()` builds the uniform shape as a discriminated union on `ok`: `{ ok: true, result }` or `{ ok: false, error }`. That union is the contract worth publishing — a client can branch on `ok` instead of string-matching.
- Each tool module already exports its own (`bqlQueryOutputSchema`, `listApiKeysOutputSchema`, …).
- Composes with ADR 0007 D6 rather than conflicting: the SDK skips output validation for an `isError` result, which is exactly what a `{ ok: false }` payload now produces.

## Steps

1. Add an `outputSchema` member to `McpToolDescriptor` and populate it from each tool's existing export.
2. Pass it through `registerTool` in `assembleMcpRegistry`.
3. Confirm the SDK normalizes a discriminated union for both the published JSON Schema and its own validation; if it does not, publish the union in whatever form it accepts rather than flattening the tool payloads.
4. Verify a success result validates and an `isError` result still passes through.

## Files

- `src/features/ai-agent/api/mcp-tools.ts`
- `src/server/api/composition-root.ts`
- the seven tool modules under `src/features/ai-agent/tools/` (exports only)

## Acceptance criteria

- [ ] `tools/list` returns 7 tools, each with a non-empty `outputSchema`.
- [ ] A successful tool result validates against its published schema; an `isError` result is unaffected.
- [ ] `src/features/ai-agent/**` and `src/server/api/**` suites stay green.

## Out of scope

- Changing any tool's payload shape — this publishes the existing contract, it does not renegotiate it.
