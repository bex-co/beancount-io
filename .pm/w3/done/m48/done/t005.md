## Objective

Cover the refusals and the working paths so neither regression can return
unnoticed, including the link and spelling variants that make this easy to get
half-right.

## Context

- The reproducers are fully synthetic and need no credentials: `w3/431` uses a
  small ledger with an include plus an inspected synthetic Beangulp importer;
  `w3/436` reproduces signed out with `--allow-errors`.
- Existing controls worth asserting alongside: `query -o` / `format -o` exit 2,
  `example -o` exit 4.

## Steps

1. Table-drive the alias refusal over `-o X`, `-oX`, `--output X`,
   `--output=X`, a symlink and a hard link, for both `ingest extract` (with and
   without `-e`) and `treeify`.
2. Assert the positive paths: `ingest extract -o <new file>` writes,
   `ingest archive -o DIR` archives, `treeify -o <new file>` writes.
3. For the export: a pre-existing foreign file causes exit 2 with the directory
   byte-identical; `--force` overwrites and marks the paths in the JSON answer;
   an empty directory exports as before.
4. Assert the file list of the destination tree is unchanged after every
   refusal — not just the file contents.
5. Confirm each test fails against the pre-fix code.
