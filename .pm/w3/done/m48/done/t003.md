## Objective

State the single output-destination rule once, in the place users and agents
read, and make every command's documented behavior agree with it.

## Context

- `cli/docs/USAGE.md` (~l.358–362) already promises the refusal for
  `ingest extract`; it was not implemented, which is how `w3/431` happened.
- Exit codes are part of the contract: 2 for a refused destination, with
  `example`'s existing-destination 4 documented as its own case.
- The commands with an output destination today: `query -o`, `format -o`,
  `ingest extract -o`, `ingest archive -o`, `treeify -o`, `price export
  --output`, `example -o`.

## Steps

1. Write the rule once in `USAGE.md` — a destination is refused with exit 2 when
   it is the ledger under read (root or any include, any spelling or link) or
   when it would replace a file the command was not given; `--force` where
   offered is the only way past it — and list the per-command exceptions
   (`archive`'s directory, `example`'s exit 4).
2. Update each command's section to point at the rule rather than restating it.
3. Verify every documented example runs as written against a synthetic ledger.
4. Check `cli/README.md`, the root `README.md`/`AGENTS.md` package tables and the
   skill catalogs for statements this change makes false; check the `AGENTS.md`
   symlinks and `.claude/skills` link still resolve. Confirm the text reads the
   same for Claude Code and Codex.

## Files

- `cli/docs/USAGE.md`
- `cli/README.md` (only where a statement is now inaccurate)

- [ ] `USAGE.md` states one rule with its exceptions, and each sentence is true
