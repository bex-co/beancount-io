2. Preserve the existing valid file/line navigation and replace invalid/loading location affordances with truthful states.
3. Verify the public payroll entry from journal and overview after reload; check the account-report caller.

- [ ] Missing filename or a nonpositive/invalid line cannot navigate to the directory as an apparent entry location.
