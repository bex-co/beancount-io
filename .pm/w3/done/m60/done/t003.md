## Objective

Rebuild `LedgerForm`'s creation path as purpose → details with the module list, the shared "balances as of" date, the summary beside Create ledger, and the public warning; remove the review page and "Books begin".

## Context

- `dashboard/src/features/ledger-list/components/ledger-form.tsx` (three steps today), hosts in the welcome page and the sidebar dialog.
- Draft in sessionStorage with `requestId`; preview through `PreviewLedgerSetup`.
- Regression checks to keep: no create before the final action (W4/314), local-date defaults (W4/317), a failed create keeps draft and `requestId` (W4/320), a Template-choice hint that explains the choice (W4/321).

## Steps

1. Purpose step with modules (live account preview from `previewLedgerSetup`) and the separate-ledger note.
2. Details step with title, currency suggestion, first accounts, one "balances as of" date, summary, and the public warning.
3. Send `setup.modules` (with property name); update translations and tests.

## Files

- `dashboard/src/features/ledger-list/`

## Acceptance criteria

- [ ] Two steps on both hosts; no review page; no Books begin.
- [ ] Modules reach `setup.modules`; the summary's account count equals the preview's.
- [ ] The carried regression tests pass.
- [ ] `yarn format:check`, `yarn lint`, `yarn test`, `yarn build` pass.

## Out of scope

## Evidence (2026-11-01)

- `LedgerForm` creation is two steps on both hosts (welcome page and the sidebar dialog share it): **purpose** — the eight catalog presets with personal preselected, the separate-ledger note, under personal the **Also track in this ledger** modules (off by default, each with its account preview and, for the rental, a property name validated by the catalog pattern), and the example ledger — then **details** — title, description, currency with its ADR026 source, the opening account and amount, and a **Balance as of** date only once a balance is known, then privacy with its inline public warning. A summary (visibility · currency · account count from `previewLedgerSetup`) sits beside **Create ledger** and expands to the account list. No review page, no Books begin, and the retired Starter template card is gone (its w3/648 copy test went with it).
- `setup.modules` carries the selected modules (rental with `propertyName` when given); another purpose sends none. `historyStart` is the as-of date with a known balance, else the browser's own day. The draft keeps step, purpose, modules, currency choice, and `requestId`, and never the opening amount (ADR021).
- Regression checks kept as tests: create only from Create ledger by pointer or Enter, with distinct Next/submit nodes (W4/314); the summary names the chosen start (W4/315); opening accounts follow the preset (W4/316); local-day defaults in three zones (W4/317); a failed create keeps draft and `requestId` across close and reopen (W4/320, sidebar test). New: `ledger-form-two-step.test.tsx`, `ledger-form-balance-as-of.test.tsx`, `setup-modules.test.ts` (catalog drift).
- Gates: `yarn lint`, `yarn format:check`, `yarn test` 7620 passed, `yarn build`. Not exercised in a live browser: no deployed backend serves `setup.modules` yet.
