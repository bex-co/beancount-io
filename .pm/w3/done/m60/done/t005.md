## Objective

Rebuild the native creation screen as purpose → details with the module list, the shared "balances as of" date, the summary beside Create ledger, and the public warning; remove the review step and "Books begin".

## Context

- `mobile/src/screens/create-ledger-screen/create-ledger-screen.tsx` (three steps), AsyncStorage draft with `requestId` and fingerprint, older-server `createLedgerBasic` fallback.
- Native already carries the W21 fixes for local dates and the Template hint; keep them.

## Steps

1. Purpose step with modules and live account preview; separate-ledger note.
2. Details step with title, currency suggestion, first accounts, one "balances as of" date, summary, public warning.
3. Send `setup.modules`; update strings and tests.

## Files

- `mobile/src/screens/create-ledger-screen/`
- `mobile/src/common/create-ledger-draft.ts`

## Acceptance criteria

- [ ] Two steps; no review step; no Books begin; modules reach `setup.modules`.
- [ ] A failed create keeps its draft and `requestId`; nothing is created before the final action.
- [ ] `yarn format:check`, `yarn lint`, `yarn typecheck`, `yarn test:unit` pass.
