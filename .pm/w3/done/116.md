# Journal truncates nonzero units and precise quotes to two decimals

Severity: **major**. Package: **dashboard**. Estimate: **45–60m**, scoped to the
shared journal amount formatter and rendered regression coverage.

Production https://beancount.io, September 11, 2026, headless Chrome
152.0.7977.83, English/light, 1440×1000 and 390×844. Dedicated QA GROWTH account;
public synthetic `open_ledger/crypto-example`, pull:true, push:false, admin:false.
Local main f943005d; checked fetched main fa63fb97 has the same implicated files.
Live entry module main-z45iacYQ.js; exact deployed commit is unverified.

## Reproduce

1. Open `/ledger/open_ledger/crypto-example/journal?lang=en&time=2024-12`.
   Keep Transaction selected and click **Postings**.
2. December 31's Ethereum 2.0 posting displays **0.00 ETH**; its real quantity
   is **0.004 ETH**. Lido displays **0.00 STETH** instead of **0.005 STETH**.
   Desktop also displays Compound's cost as **0.02 USD**, losing its **0.0230 USD**
   unit cost. The associated income remains -13.40, -16.75 and -52.90 USD.
3. Fresh desktop and narrow contexts reproduce. In two more fresh contexts,
   expand only Ethereum's **Toggle postings** button: the same 0.00 ETH appears.
4. Open that transaction's **Entry Context**. The source editor visibly retains
   `0.004 ETH {3,350.00 USD, 2024-12-31}`. The missing digits are available to the
   client; this is numeric truncation, not clipping or an empty posting.

Additional shared consumers: in a desktop Journal, deselect Transaction and
select **Price**. December 31's CUSDC price reads **0.02 USD/CUSDC**, while its
GetLedgerJournal response contains amount.number="0.0230". On the Ethereum
account page with time=2024-12, choose **Units** and expand Postings: Change is
**0.00 ETH**, although GetLedgerAccountJournal returns change.ETH="0.004".
Its balance.ETH="1.040" displays 1.04, which is value-preserving normalization.
The At Cost control correctly shows 13.40 USD change and 2471.00 USD balance.

## API controls and cause

GraphQL and REST `GET /api-gateway/v1/ledgers/open_ledger/crypto-example/journal`
with time=2024-12, directiveTypes=["Transaction"], limit=50, offset=0 both return
HTTP200, total=4 and identical entry arrays. Ethereum hash
a2880e3ebb69187903bf71fda168e234 contains units.number="0.004"; Lido contains
"0.005" and Compound cost.number="0.0230". Existing 2300.00 CUSDC, -13.40 USD,
2.64 USD and 0.88 USD values remain correct in the same UI and source probe.

`dashboard/src/common/lib/format/format-amount.ts:18–29` splits a decimal string
and unconditionally keeps only its first two fractional characters. This
truncates rather than rounds: even 0.005 becomes 0.00.
`features/journal/components/journal-description/utils.ts:3–7` delegates to it.
`journal-postings.tsx:45–58` uses this wrapper for narrow/desktop units and
desktop costs/prices; `journal-table.tsx:38–49` uses it for account changes and
balances. `journal-description/price-description.tsx:12` formats price directives.
Executing the actual TypeScript helper with the captured API values reproduces
all three losses exactly.

Backend `ledger-journal-service.ts:154–185` forwards the query and copies the
ledger response items without numeric formatting. GraphQL
`api/resolvers/ledger-journal-resolver.query.ts:170` delegates to this service;
REST `api/rest/v1/journal-reads.ts:99–107` and the registered ledgerJournal MCP
resource share it. The data contract is correct; no API change is proposed.
Live MCP was not exercised.

## Bounded repair

Remove the two-decimal cap from the shared amount formatter while retaining
decimal-string precision, comma handling, signs, units and zero. Do not convert
through Number/toFixed, apply a cents cap to unit prices, or import another
feature's private formatter. The generic report-number and Holdings formatters
are separate contracts and need no change for this defect.

Caller search finds five production consumers of formatAmountWithCurrency:
JournalPostings, JournalAmounts, PriceDescription, BalanceDescription's
diff_amount, and the budget branch of CustomDescription. JournalTable is used
by Journal and AccountJournalTable; JournalDescription is dispatched by that
table. formatAmount has no other production caller beyond this wrapper and an
unused-in-production barrel export. Plaid's same-named local function is separate.
Balance/custom-budget descriptions are source-traced, not newly live-verified.

- [ ] Fresh desktop/narrow global and per-row disclosures preserve 0.004 ETH,
      0.005 STETH and precise costs; ordinary currency amounts retain their values.
- [ ] CUSDC Price and account Units Change preserve the same source precision.
- [ ] Meaningful rendered tests cover posting units/cost/price, an account change
      and a price directive, plus negative small values, exact zero and existing
      two-decimal controls. Update tests that currently bless truncation in
      common/lib/format/__tests__/format.test.ts and journal-description's tests.
- [ ] Keep disclosure, account links, entry context, pending/error/empty guards
      and readonly behavior intact; run the dashboard's normal checks.
