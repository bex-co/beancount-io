# `bea ingest extract -o` (and `treeify -o`) overwrite the root ledger or an included file

**Severity:** major (source data loss, exit 0). **Owner:** cli. **Estimate:**
30–45 minutes. **A1:** "extract into my ledger" is a natural agent reading of
`ingest extract -e main.bean -o main.bean`; it replaces the whole ledger with
the extract output and reports success.

Found by continuous CLI QA 2026-09-26, `uv run bea` 0.3.0 at HEAD `8cd9732b`,
Darwin 25.5.0, isolated config/cache and an isolated managed engine
(`BEA_ENGINE_DIR`) with `bea engine enable beangulp`; synthetic ledger and an
inspected synthetic Beangulp importer.

## Repro

```sh
# main.bean: 19-line valid ledger that includes sub/extra.bean
# ingest.py: minimal beangulp.Importer for files named qa-bank-*.csv; ends with beangulp.Ingest([...])()
# in/qa-bank-x.csv: 2024-03-01,-5.00,Coffee
bea --file main.bean ingest extract -e main.bean -o main.bean in
# exit 0; main.bean now holds only ";; -*- mode: beancount -*-" + one extracted txn.
#   All opens/options/transactions are gone (hash changed; reproduced twice).
bea --file main.bean ingest extract -o sub/extra.bean in
# exit 0; the included file is replaced; `bea check` now fails (unbalanced extract).
printf 'account\nAssets:A\n' | bea --file main.bean treeify -o main.bean
# exit 0; main.bean replaced by an ASCII tree.
```

Working controls: `query -o main.bean`, `format -o main.bean` refuse with exit 2;
`example -o main.bean` refuses an existing file without `--force` (exit 4);
`ingest extract -o out.bean` to a distinct file works.

## Expected

`docs/USAGE.md` (~l.358–362) promises an `-o` destination that is the ledger
under read — root or any include, any spelling/symlink/hard link — is refused
with exit 2 before anything is written. Apply the same guard before launching
the native writer: for `ingest extract`, refuse `-o/--output` (all spellings:
`-o X`, `-oX`, `--output X`, `--output=X`) when it aliases the resolved ledger
closure or the `-e/--existing` ledger's closure; for `treeify`, refuse when it
aliases the resolved ledger closure if one resolves (or at minimum refuse an
existing `.bean`/`.beancount` without `--force`, matching `example`).

## Root cause

`cli/src/cli/commands/ingest.py` `_forward` passes `ctx.args` straight to
`launch.run_optional_script`; `cli/src/cli/commands/treeify.py` likewise
forwards `-o` to native treeify. Neither calls `output.refuse_ledger_alias`
(`cli/src/cli/output.py:235`), which `query.py` and `format.py` use. Commit
`4ce341a6` added safe `-o` destinations for query/format only; `e168b0aa`
(w4/181) covered `query --source`.

## Out of scope

`ingest archive -o DIR` moves source documents into a directory tree; not a
ledger write. Beangulp's own truncation semantics are upstream.

Dedupe: `.pm/**` searched for ingest/treeify + output/overwrite/clobber; only
w4/181 (query --source, done) and w1/m23/t006 (no-op exits) are related.

**Re-verified 2026-09-26** (CLI QA consolidation round, run11) — reproduced
again from a pristine synthetic fixture in fresh processes on the same HEAD
`8cd9732b`, `bea` 0.3.0, macOS 26.5.1 arm64, isolated
`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, stdin closed.
All three cases still hold — `ingest extract -e main.bean -o main.bean` replaced
the root ledger (exit 0), `-o sub/extra.bean` replaced the included file and
left `bea check` failing (exit 1), and `treeify -o main.bean` replaced the
ledger with a tree (exit 0). The controls still refuse: `query -o` and
`format -o` exit 2, `example -o` exits 4, and the ledger stayed byte-identical
through all three.

**Resolved 2026-09-26** — Fixed. `bea ingest extract -o` and `bea treeify -o` now apply the shared output-destination guard (`cli/src/cli/output.py` `guard_forwarded_output`) before the native writer is launched: a destination that aliases the ledger closure — root, any include, the `-e/--existing` ledger, in every spelling and through symlinks and hard links — is refused with exit 2 and the ledger stays byte-identical, and `treeify -o` also refuses an existing `.bean`/`.beancount` file without `--force`. `ingest archive -o DIR` is deliberately outside the guard.
