## Objective

Make a commit's file link reveal its requested diff even when react-window has
not mounted that file's header row.

## Context

- The milestone records desktop/narrow Walmart failures and a manual-scroll
  control proving the requested FY2027 file is available.
- Native anchors cannot scroll to DOM elements that do not exist yet.

## Steps

1. Connect explicit file selection to the parsed diff's file identity and
   flattened header index, reusing `getDiffFileId` and the pinned List API.
2. Scroll the virtual List to the requested row and reveal the viewer in the
   commit pane. Keep ordinary links and small-diff navigation usable.
3. Handle repeated selections and unknown IDs without stale indices or forced
   jumps during normal scrolling. Preserve pull-request viewer compatibility.

## Files

- `dashboard/src/features/git/commits/components/commit-file-list.tsx`
- `dashboard/src/features/git/commits/components/commit-detail.tsx`
- `dashboard/src/common/components/diff-viewer/`

## Acceptance criteria

- [ ] Selecting FY2027 by click or Enter reveals its actual diff at both widths.
- [ ] Virtualization remains enabled and the URL retains a usable file fragment.
- [ ] A small diff, repeated same-file click and missing target remain usable.

## Out of scope

- Backend/API changes, new dependencies or replacing the diff renderer.
