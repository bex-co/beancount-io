## Objective

Prove the selected file becomes visible across actual asynchronous and virtual
rendering boundaries.

## Steps

1. Cover a non-first file outside a real virtual range and assert its rendered
   content/visibility after selection; an href assertion alone cannot catch this.
2. Cover a delayed small-diff result, fresh fragment, reload/history, same-fragment
   reselection and explicit large-diff load. Verify unrelated rerenders do not jump.
3. Cover commit replacement, unknown/malformed fragments and shared pull-request
   rendering compatibility without fabricating a live PR regression.
4. Run dashboard format, lint, tests and build; repeat the public desktop/narrow
   repros against the fixed client with its API origin explicitly recorded.

## Files

- `dashboard/src/features/git/commits/components/__tests__/`
- `dashboard/src/common/components/diff-viewer/__tests__/`
- Existing dashboard browser-check infrastructure as appropriate

## Acceptance criteria

- [ ] Checks fail on the old navigation behavior and pass on visible destinations.
- [ ] Small, virtual and gated diffs preserve their existing rendering controls.
- [ ] Required dashboard checks pass; any platform limits are stated accurately.

## Out of scope

- Snapshot-only or mock-only substitutes for the scroll/visibility behavior.
