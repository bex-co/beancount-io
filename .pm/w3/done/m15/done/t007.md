## Objective

The detailed statement or account journal opened from a monthly Money movement
card describes the same period as the card.

## Steps

1. Give both MovementCard View all links an explicit destination time selection
   derived from the selected interval. Preserve applicable account/filter context.
2. Give category account navigation the same explicit period. Keep the generic
   Account balances card's existing scope; its shared navigation helper has no
   month of its own. An optional explicit search override may be appropriate.
3. For a partial monthly interval, preserve the source's actual date boundaries
   instead of widening a narrower global time filter to a full month. Reuse the
   repository's date/filter semantics and avoid an independent incompatible parser.
4. Let the router-owned state from t001 update the destination UI and requests;
   setting only a query string while leaving the old provider snapshot is insufficient.

## Files

- `dashboard/src/features/reports/overview/components/money-movement-section.tsx`
- `dashboard/src/features/reports/overview/index.tsx` and its existing period utilities as needed
- `dashboard/src/common/providers/ledger-provider/use-ledger-navigate-to-account.ts` if an explicit override is shared

## Acceptance criteria

- [ ] On public real-estate-example, select October 2025. Both View all links
      produce a statement with -2500 USD raw income and 3007.42 USD expenses,
      rather than the lifetime -68894 / 105748.23 totals.
- [ ] The Rent category opens only October's one rent transaction, rather than
      19 monthly rents; the destination URL records the period and reload agrees.
- [ ] A selected partial interval and non-time filters keep the source scope;
      ordinary Account balances navigation is unchanged.

## Out of scope

New report calculations, API fields, or changing the card's displayed sign conventions.
