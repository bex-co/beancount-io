# Report trees omit zero-net parent totals for cost-lot children under `at_cost`

**Severity:** minor. **Estimate:** 30–60 minutes. **Owner:** cli. **A1:** under
`--conversion at_cost`, a parent whose cost-lot children net to zero shows
`balance_children: {}` / human `—` while funded children display amounts —
JSON consumers read “no balance” incorrectly.

Found 2026-09-16 by continuous CLI QA ([c990 hunt](9d33cfdb-8e4c-46ef-9da4-917dbadc3190)),
HEAD `84a4407a`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Confirmed
`cli/tmp/qa-20260915/c991/`. Evidence: `c990/`.

## Repro

```sh
# FundA +10k USD at cost, FundB -10k USD at cost under Assets:Investments
bea --file main.bean report balance-sheet -x at_cost
# Investments — ; FundA 10,000; FundB -10,000

bea --json … | # Investments balance_children == {}
```

Single-child control rolls up correctly.

## Expected

Parent rollup includes converted net (`{"USD":"0.00"}` / `0.00 USD`), not
empty / `—`.

## Actual

Fava `at_cost` hierarchy leaves empty `balance_children` when children net to
zero; human `_amounts` renders that as `—`.

## Fix

Emit explicit zero parent totals from child sums. Regression: offsetting
funds show Investments `0.00 USD`.

## Dedupe

Not w3/313 / 304 / 322. No open note covers zero-net cost-lot parent rollup.

---

**Resolved 2026-09-17** — An inventory drops a position the moment it nets to
zero, which is right for an inventory but wrong for a report tree: a parent whose
children cancel under the conversion rendered exactly like an account with no
balance. Tree serialisation now reports an explicit zero in every currency the
conversion produced when the node holds positions but they cancel — `0.00 USD` /
`{"USD": "0"}` for offsetting cost bases under `at_cost`. The same cancellation
happens under `units` when two children hold opposite quantities of one
commodity, so the fix sits in `fava.core.tree` and covers every conversion rather
than `at_cost` alone. An account that genuinely holds nothing still reads `—` /
`{}`. Documented in `cli/docs/USAGE.md`; covered by
`cli/tests/test_report_tree_zero_net_rollup.py`. Shipped with this board close.
