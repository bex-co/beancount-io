# `bea query` scalar subquery in SELECT list crashes with raw Python AttributeError

**Severity:** minor. **Estimate:** 30–60 minutes. **Owner:** cli. **A1:**
`SELECT account, (SELECT payee FROM postings LIMIT 1) FROM accounts` exits **1**
with `'EvalQuery' object has no attribute 'childnodes'`, while `IN (SELECT …)`
in WHERE works.

Found 2026-09-16 by continuous CLI QA ([c1020 hunt](6773a7c7-f74e-4dc9-b213-007e28f57f68)),
HEAD `26a9cb88`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64. Confirmed
`cli/tmp/qa-20260915/c1022/`. Evidence: `c1020/`.

## Repro

```sh
bea --file main.bean query \
  'SELECT account, (SELECT payee FROM postings LIMIT 1) FROM accounts'
# exit 1 — EvalQuery … has no attribute 'childnodes'

bea --file main.bean query \
  'SELECT account FROM accounts WHERE account IN (SELECT account FROM postings)'
# exit 0
```

## Expected

Evaluate scalar subqueries or refuse with a clear BQL usage error — not a
Python AttributeError.

## Fix

Handle `EvalQuery` in scalar evaluation (or compile-time reject). Regression:
repro exits 2 with guidance or returns rows; IN-subquery control unchanged.
