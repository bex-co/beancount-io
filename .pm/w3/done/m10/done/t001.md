## Objective

Give the Dashboard a typed client seam for listing, creating, and revoking the API keys already exposed by backend-v2, including the one-time plaintext returned only by creation.

## Context

- `backend-cluster/backend-v2/src/features/apikeys/api/api-key-resolver.ts` exposes `apiKeys`, `createApiKey`, and `revokeApiKey`.
- `createApiKey` accepts a name, non-empty scopes, optional `ledgerScope`, and optional `expiresAt`; it returns plaintext once.
- Generated GraphQL output is owned by `yarn codegen`, never hand-edited.

## Steps

1. Add feature-owned GraphQL documents for list, create, and revoke.
2. Request every lifecycle field needed by the UI while keeping plaintext confined to the create-mutation result.
3. Run Dashboard code generation and review the generated diff.
