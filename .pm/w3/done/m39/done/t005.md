## Objective

Pin the shipped behavior with tests that assert real accessibility output and real keyboard interaction — not that a prop was passed.

## Context

- Existing neighbours: `dashboard/src/common/components/ledger-layout/__tests__/ledger-sidebar.test.tsx` and `dashboard/src/common/components/ui/__tests__/sidebar.test.tsx`.
- Query by role, as a screen reader would: `getByRole("navigation", { name })`, not by class or test id.
- The skip link's value is the **focus move**, so assert focus, not just the hash.

## Steps

1. Assert each shell renders a `navigation` landmark with its expected accessible name, and that names stay distinct alongside `Related pages`.
2. Assert the skip link is the first focusable element, is hidden until focused, and moves focus into the main region when activated.
3. Assert the sidebar's existing collapse/expand and post-navigation focus fallback still behave.
4. Confirm each test fails when its fix is reverted.

## Files

- `dashboard/src/common/components/ledger-layout/__tests__/ledger-sidebar.test.tsx`
- tests adjacent to the dashboard sidebar and the shared shell

## Acceptance criteria

- [ ] Removing a landmark or the skip link makes a test fail.
- [ ] The skip-link test asserts `document.activeElement` after activation, not the URL.
- [ ] Landmark assertions use role + accessible name.
- [ ] `yarn test` passes in `dashboard/`.
