## Objective

Give every dashboard route a skip link as its first focusable element, so a keyboard user can pass 11–15 repeated sidebar links in one keystroke. It must be visually hidden until focused, clearly visible and operable when focused, and must move **focus** — not merely the URL hash — to the main content region.

## Context

- No dashboard route currently renders an in-page anchor; measured across `/ledger`, a ledger overview, a journal and a public balance sheet.
- The `main` landmark already exists on every route; it needs a stable id and a programmatically focusable target (`tabindex="-1"` on the target is the usual approach).
- The app shell lives under `dashboard/src/routes/__root.tsx` and the ledger layout in `dashboard/src/common/components/ledger-layout/`; place the link once, in the shell both sidebars share, rather than per route.
- Reuse the existing visually-hidden and focus-ring primitives in `src/common/components/ui/` before adding new styles.
- The link text is a new localized string in all 15 locale files.

## Steps

1. Add the skip link as the first focusable element of the shared shell, targeting the main region.
2. Give the main region a stable id and make it focusable as a target.
3. Add the link text to all 15 locale files.
4. Verify with real keyboard interaction: Tab from a fresh load, confirm the link is visible when focused, activate it, then confirm focus lands in the main content and the next Tab continues inside it.

## Files

- `dashboard/src/routes/__root.tsx` and/or the shared layout under `dashboard/src/common/components/ledger-layout/`
- `dashboard/src/**/locales/*.ts` (all 15)

## Acceptance criteria

- [ ] Tab from a fresh load reaches the skip link first, and it is visible while focused.
- [ ] Activating it moves focus into the main content; the following Tab continues inside the content, not back at the top of the sidebar.
- [ ] The link is not visible or focus-trapping when unfocused, and it does not shift layout.
- [ ] Behavior holds at 1440 and 390, and with the sidebar both expanded and collapsed.
- [ ] `src/test/translations.test.ts` passes.

## Out of scope

Landmarks (t001), reordering any other focusable element, and changing the sidebar's own tab order.
