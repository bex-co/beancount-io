# `docs/USAGE.md` says `format` ignores `--file`; it honors it — and accepts a directory there that every other command refuses

**Severity:** minor. **Owner:** cli (docs + one guard). **Estimate:** 20–30
minutes. **A1:** the usage guide is the contract agents read. It says
`bea --file X format -i` cannot touch `X`; in fact that command rewrites `X`,
and `bea --file DIR format -i` rewrites every `.bean`/`.beancount` file under
`DIR` — while `bea --file DIR check` exits 2 for the same argument.

Found by continuous CLI QA 2026-09-26, `uv run bea` 0.3.0 at HEAD `8cd9732b`,
Darwin 26.5.1 arm64, isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, closed stdin,
synthetic ledgers only, no network or account.

## Repro

```sh
mkdir -p cwd tree/sub
printf 'option "operating_currency" "USD"\n2024-01-01 open Assets:Bank USD\n' > cwd/main.bean
printf '2024-01-02 * "x"\n    Assets:Bank   1.00 USD\n    Equity:Opening\n' > tree/a.bean
cp tree/a.bean tree/sub/b.bean
cd cwd     # a different main.bean is discoverable here

# 1. --file is honored, not ignored: this file is rewritten
md5 -q ../tree/a.bean
bea --file ../tree/a.bean format -i     # "formatted: …/tree/a.bean"  exit 0
md5 -q ../tree/a.bean                   # changed

# 2. --file accepts a directory and walks it
bea --file ../tree format -i
# formatted: …/tree/a.bean
# formatted: …/tree/sub/b.bean
# 2/2 file(s) formatted.   exit 0

# 3. control — the same --file value on every other command
bea --file ../tree check
# Error: Ledger path '…/tree' (from --file) is a directory; expected a ledger file.  exit 2

# 4. BEA_FILE really is ignored, as documented
BEA_FILE=../tree/a.bean bea format --check
# Error: Name the files to format: reading stdin has nothing to compare or rewrite.  exit 2
```

A positional path still wins over `--file` when both are given.

## Expected

Pick one story and make docs and code agree. `docs/USAGE.md` § "Choosing the
ledger" currently says:

> `init` creates its target from its own argument or global `--file` and ignores
> `BEA_FILE`; `format` uses its own positional path and likewise **ignores
> both**.

The code deliberately does the opposite for `--file`
(`cli/src/cli/commands/format.py:76` passes `ctx.file`, and its docstring at
`:403` says "An explicit path wins; otherwise the global `--file` names the
ledger"), and `tests/test_customer_workflows.py:442` asserts
`["--file", book, "format", "--in-place"]` works. So the documentation is the
defect: say that `format` takes its target from a positional path, else global
`--file`, and ignores `BEA_FILE`.

Separately, `format` should apply the same directory guard as the rest of the
CLI to a `--file` value: `--file` is documented as "Ledger entry file", and
letting it name a directory means the one global option users point at a single
file can silently rewrite a whole tree. A directory belongs in the positional
argument (`bea format -i .`), which is already the documented spelling.

## Root cause

`cli/src/cli/commands/format.py:76` — `_targets(paths, ctx.file, …)` uses the
raw `--file` value instead of `context.entry_file()`, so it bypasses the
directory/existence validation at `cli/src/cli/context.py:111-119` that produces
the exit-2 message every other command gives. `BEA_FILE` is absent from
`ctx.file`, which is why only the environment half of the documented sentence
holds.

## Fix

1. Correct the `format` sentence in `cli/docs/USAGE.md` § "Choosing the ledger"
   (and re-check the `format` section's "uses its own positional path" wording).
2. Reject a directory passed through `--file` to `format` with the shared
   exit-2 directory message, pointing at `bea format -i DIR`.
3. Regression coverage: `--file FILE format --check` scans that file;
   `--file DIR format -i` exits 2 and writes nothing; `BEA_FILE=FILE format`
   still exits 2 with the stdin message.

## Dedupe

`.pm/**` searched for `format` + `BEA_FILE`/`--file`/"ignores both"; the hits are
w2/done/019 (a different USAGE.md `format` promise, syntax-error contract) and
