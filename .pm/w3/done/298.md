# `bea treeify` / `bea example` dump upstream Python tracebacks on common misuse

**Severity:** minor. **Estimate:** 20–30 minutes. **Owner:** cli. **A1:** a
missing treeify path or an inverted `example --date-begin`/`--date-end` prints a
multi-line managed-engine traceback instead of a one-line usage/validation
error — same class as w3/274 for `query --source`, but still open for these
native wrappers.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `7b792ea5`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache.

## Repro

```sh
bea treeify /no/such/file.txt
# exit 1
# Traceback (most recent call last):
#   File ".../bin/treeify", ...
# FileNotFoundError: [Errno 2] No such file or directory: '/no/such/file.txt'

bea example --date-begin 2020-12-01 --date-end 2020-01-01 -o /tmp/ex.bean
# exit 1
# Traceback ... IndexError: list index out of range
# (inside beancount.scripts.example.delay_dates)
```

Working controls:

```sh
bea --json treeify /no/such/file.txt
# exit 2 — clean JSON refusal (done/221); human path still leaks traceback

printf 'Assets:Cash 1\n' | bea treeify
# exit 0 — ASCII tree
```

## Expected

Missing input → usage/validation error naming the path (exit 2 or 1) with no
traceback. Inverted example date range → usage error (“begin must be on or
before end”) before generation starts.

## Actual

`launch.run_native` forwards stderr/exit unchanged. Upstream `treeify` and
`bean-example` print full tracebacks for these cases.

## Root cause

`cli/src/cli/commands/treeify.py` / `example.py` → `run_native` with no capture
or mapping of known failure modes (contrast helper_json / refuse_json paths).

## Fix

Pre-validate example date ordering in the frontend; for treeify, check the
input path exists (when not stdin) before launch, or capture native stderr and
rewrite FileNotFoundError / IndexError into UsageError. Regression: the two
repros above exit nonzero with a single clear message and no `Traceback`;
valid treeify/example still succeed.

## Dedupe

Not w3/274 (`query --source` traceback). Not done/221 (`--json` refusal for
these commands). Not w5/004 (`format -i` RO traceback). No open note covers
human-mode `treeify` / `example` traceback wrapping for missing path / bad
date range.
