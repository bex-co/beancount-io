# An unreadable ledger found via `BEA_FILE` or cwd leaks the helper's usage text and exits 1

**Severity:** minor. **Estimate:** 20–30 minutes. **Owner:** cli. **A1:** the
same permission problem gets three different answers depending on how the
ledger was named; the discovery paths print internal `python -m bea_engine`
usage and "engine did not answer", which points at a broken install.

Found 2026-09-25 by CLI QA against `main` HEAD `8cd9732b`, `uv run bea` 0.3.0,
Darwin 25.5.0 arm64, isolated config/cache.

## Repro

```sh
bea --no-input init d --currency USD --date 2026-01-01 && chmod 000 d/main.bean
bea --json --file "$PWD/d/main.bean" check; echo exit=$?
# exit=2 usage: "Invalid value for '--file' / '-f': Path '…' is not readable."   (control)
BEA_FILE="$PWD/d/main.bean" bea --json list open; echo exit=$?
# exit=1 validation: "The Beancount engine did not answer 'bea-engine list …' (exit 2)."
#   details: ["Usage: python -m bea_engine list [OPTIONS]", "Try 'python -m bea_engine list --help' …", …]
(cd d && bea check; echo exit=$?)
# exit=2 with upstream "Usage: bean-check [OPTIONS] FILENAME … is not readable."
chmod 600 d/main.bean
```

`check`, `list`, `report`, `query` and `add` all show the leak under
`BEA_FILE`/cwd discovery.

## Root cause

`cli/src/cli/context.py` `RunContext.entry_file` checks existence, directory
and regular-file status but not readability; only the global `--file` option
in `cli/src/cli/main.py` is declared `readable=True`. The engine's own click
option then rejects the path and the frontend reports its usage text as a
failed helper.

## Fix

In `entry_file`, refuse an unreadable candidate for every source with the
same message shape as the other checks (naming the source, e.g. `(from
$BEA_FILE)`), exit 2 — or exit 3 if the table's permission category is
preferred, consistently for all three sources.

## Acceptance

All three repro lines give the same category/exit and a message naming the
path and its source; no `python -m bea_engine` text reaches the user; test.

## Dedupe

Searched `.pm/**` for not readable, unreadable, permission denied, chmod 000.
No existing item.
