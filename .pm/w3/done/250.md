# `bea --json … -o <directory>` fails with a raw or errno message instead of a clear usage error

**Severity:** minor. **Estimate:** 30–45 minutes. **Owner:** cli. **A1:** scripts
that pass `-o` to a path that turned out to be a directory get either a broken
JSON contract (`format`) or an opaque `Errno 21` rename error that names a
temp file (`query`).

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `88f4cb5e`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache.

## Repro

```sh
mkdir outdir

bea --json --file main.bean format -o outdir
echo exit=$?
# exit 1
# stderr (NOT JSON): Error: Could not open file '…/outdir': Is a directory
# stdout empty

bea --json --file main.bean query "SELECT account LIMIT 1" -o outdir
echo exit=$?
# exit 1
# stderr JSON:
# {"error":{"category":"validation",
#   "message":"[Errno 21] Is a directory: '…/.bea-….tmp' -> '…/outdir'",
#   "exit_code":1}}
```

Human `query -o outdir` similarly prints `Error: [Errno 21] Is a directory: …`.

Working control: `-o` to a normal file path succeeds (format writes the file and
emits a JSON envelope; query writes CSV/text).

## Expected

Preflight: if the `-o` path exists and is a directory (or its final component
cannot be a file), exit **2** with a usage error such as “`--output` must be a
file path, not a directory”. Under `--json`, that must be a JSON error object
(same for `format` and `query`).

## Actual

- `format -o DIR` forwards to `bean-format`, which prints a raw Click/IO error;
  under `--json` the envelope contract is broken.
- `query -o DIR` writes a temp file then `os.replace` fails with Errno 21;
  the message leaks the temp name and uses category `validation`.

## Fix

Before opening/replacing, `Path(output).exists() and Path(output).is_dir()` (and
parent-not-a-directory checks as needed) → `UsageError`. Keep successful file
`-o` paths unchanged. Regression: both commands under `--json -o <dir>` return
JSON usage errors without temp paths or upstream Click text.

## Dedupe

Not w3/249 (empty-dir `-i` silence). Not w5/004 (RO in-place traceback). No
open note covers `-o` directory preflight.

---

**Resolved 2026-09-16** — `format`/`query` `--output` to an existing directory is a usage error (exit 2, JSON-safe) instead of Click/Errno 21 noise. Covered by `cli/tests/test_output_dir_usage.py`. Shipped with this board close.
