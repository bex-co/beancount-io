## Objective

Add a `head:` property to the Accounts and Budget route files using the same `createHeadMeta` + `getSEOMetadata` call the sibling routes use, passing the t001 keys and `{ ledgerName: params.ledgerName }`. Keep the existing `component` and, for Accounts, its `validateSearch`.

## Context

- Target files: `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.accounts.tsx` and `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.budget.tsx`.
- Exact pattern to copy: `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.holdings.tsx:11-20`.
- Route files must stay thin (`dashboard/CLAUDE.md`); the head config belongs in the route, not in the feature page.

## Steps

1. Import `createHeadMeta` and `getSEOMetadata` from `@/common/lib/seo/seo-helpers` in both routes.
2. Add the `head:` property mirroring the holdings route.
3. Load both routes and confirm the title, description, `og:title` and canonical.

## Files

- `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.accounts.tsx`
- `dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.budget.tsx`

## Acceptance criteria

- [ ] Both routes emit a localized title naming the page and the ledger, plus a description, an `og:title` and a canonical URL.
- [ ] Accounts keeps its `validateSearch` behavior; the `?action=` search params still work.
- [ ] Switching the app language changes both titles.
- [ ] `yarn typecheck` and `yarn lint` pass.

## Out of scope

Adding or changing locale strings (t001), the robots/indexability decision (t003), and any other route.
