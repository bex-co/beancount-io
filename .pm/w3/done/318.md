# `bea list price` presents `implicit_prices` plugin quotes as if they were on disk

**Severity:** minor. **Estimate:** 25–40 minutes. **Owner:** cli. **A1:** an
agent that enables `beancount.plugins.implicit_prices`, books a cost lot, then
trusts `list price` / JSON as the source of truth believes a `price HOOL …`
directive exists on disk (and may skip `add price`) — while `rg '^.*price'` /
the ledger file only contain the real EUR price.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `2eecd8a6`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only. Evidence: `cli/tmp/qa-20260915/c630/`.

## Repro

```sh
# main.bean opens Assets:Cash / Expenses:Food / … and has one real price:
# 2020-04-01 price EUR 1.10 USD

bea --file main.bean add open --date 2020-01-01 --account Assets:Broker --currency HOOL
bea --file main.bean add transaction --date 2020-05-01 --narration buy \
  --posting 'Assets:Broker 10 HOOL {100 USD}' --posting 'Assets:Cash -1000 USD'
printf '\nplugin "beancount.plugins.implicit_prices"\n' >> main.bean

grep -n price main.bean
# only the EUR line (+ the plugin line) — no HOOL price directive

bea --file main.bean list price
# DATE / CURRENCY / AMOUNT includes:
# 2020-05-01  HOOL  100 USD

bea --json --file main.bean list price
# data[] includes {"date":"2020-05-01","currency":"HOOL","amount":{"number":"100","currency":"USD"}}
# (no source filename to mark it synthetic)
```

Working control — same ledger without the plugin:

```sh
# list price → only EUR 1.10 USD
```

## Expected

`list price` (human + JSON) either:

1. omits plugin-synthesized prices and shows only on-disk `price` directives, or
2. labels them with a non-ledger source (e.g. `<implicit_prices>`), matching
   what is actually on disk.

Same class of “loader view ≠ file” footgun as w3/301 (`auto_accounts` →
`list open`).

## Actual

`bea_engine/ledger/reader.py` `list_prices` walks post-plugin loaded `Price`
entries and maps them to `PriceDirective` with no source filter. JSON has no
`source` field for prices.

## Fix

Filter to entries whose `meta['filename']` is a real ledger path (or expose
source and teach human list to show it). Regression: the repro’s `list price`
has no HOOL row (or clearly marks it synthetic); EUR on-disk row unchanged;
control without the plugin unchanged.

## Dedupe

Not w3/301 (`list open` + `auto_accounts`). Not w3/290 (booking on open). No
open note covers `implicit_prices` leaking into `list price`.
