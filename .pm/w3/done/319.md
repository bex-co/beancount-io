# `bea list open` presents `currency_accounts` plugin opens as if they were on disk

**Severity:** minor. **Estimate:** 25–40 minutes. **Owner:** cli. **A1:** an
agent that enables `beancount.plugins.currency_accounts`, posts an FX
transaction, then trusts `list open --account Currency` / JSON as the chart of
accounts believes `Equity:Currency:EUR` / `:USD` were opened in the ledger —
while the file only has the plugin line and the real asset opens.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `378679ef`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only. Evidence: `cli/tmp/qa-20260915/c632/`.

## Repro

```sh
# main.bean has ordinary Assets:Cash / Expenses:Food / … opens

printf '\nplugin "beancount.plugins.currency_accounts" "Equity:Currency"\n' \
  >> main.bean
bea --file main.bean add open --date 2020-01-01 --account Assets:EUR --currency EUR
bea --file main.bean add transaction --date 2020-05-01 --narration fx \
  --posting 'Assets:EUR 100 EUR @ 1.10 USD' --posting 'Assets:Cash -110 USD'

grep -n 'open Equity:Currency' main.bean
# no matches — only the plugin line and Assets:EUR open exist on disk

bea --file main.bean list open --account Currency
# Equity:Currency:EUR and Equity:Currency:USD appear

bea --json --file main.bean list open --account Currency
# data[] includes both accounts; no source to mark them synthetic
```

## Expected

`list open` (human + JSON) either omits plugin-synthesized opens or labels
them with a non-ledger source (e.g. `<currency_accounts>`), matching w3/301’s
expectation for `auto_accounts`.

## Actual

`list_opens` walks post-plugin loaded `Open` entries. Same loader-view≠file
class as w3/301 (`auto_accounts`) and w3/318 (`implicit_prices` → `list price`).

## Fix

Share the on-disk / labeled-source filter with the auto_accounts fix. Regression:
the repro’s `list open --account Currency` is empty (or clearly synthetic);
real `Assets:EUR` still lists; control without the plugin unchanged.

## Dedupe

Not w3/301 (auto_accounts → list open). Not w3/318 (implicit_prices → list
price). No open note covers `currency_accounts` opens in `list open`.
