# `bea format --check|-i DIR` follows symlinks and rewrites `.bean` files outside `DIR`

**Severity:** minor. **Estimate:** 20–30 minutes. **Owner:** cli. **A1:** a
pre-commit or agent that runs `bea format -i books/txns/` can rewrite a ledger
one directory up via an outbound symlink, mutating files outside the scoped
tree.

Found 2026-09-16 by continuous CLI QA ([c700 hunt](262ddd64-ccdb-4c8e-aa2c-4689ed96d3b8)),
HEAD `b85e2621`, `uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache.
Synthetic fixtures only. Evidence: `cli/tmp/qa-20260915/c700/`, `c750/` (confirm).

## Repro

```sh
mkdir -p books/inner
cat > books/external.bean <<'EOF'
2020-01-01 open Assets:Cash USD
2020-01-01 open Expenses:Food USD
2020-01-02 * "T"
  Expenses:Food 5 USD
  Assets:Cash
EOF
ln -sf ../external.bean books/inner/link.bean

bea format --check books/inner
# exit 1 — would format: …/books/external.bean

bea format -i books/inner
# exit 0 — formatted: …/books/external.bean
# external.bean rewritten; inner/link.bean stays a symlink
```

## Expected

Directory-scoped format stays inside the requested tree (skip or refuse
outbound symlinks). Do not rewrite targets outside `DIR`.

## Actual

`format.py` `_targets()` `rglob`s then `Path.resolve()`s every match, so
`inner/link.bean -> ../external.bean` becomes the external path in the format
set.

## Fix

When expanding a directory, keep only resolved paths that remain under the
requested root (or operate on the symlink path without escaping). Regression:
the repro’s `--check` / `-i` on `inner/` neither names nor rewrites
`external.bean`.
