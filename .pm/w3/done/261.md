# `bea add transactions` accepts `postings: []` and writes a posting-less transaction

**Severity:** minor. **Estimate:** 15–25 minutes. **Owner:** cli. **A1:** an
agent that emits a bulk row with an empty `postings` array (schema typo or
incomplete builder) gets `written: 1` and a ledger line `YYYY-MM-DD * "…"`,
while `add transaction` refuses the same mistake (`Missing option '--posting'`).

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `f129dd8c`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
printf '%s\n' '[{"date":"2024-09-04","narration":"empty","postings":[]}]' \
  > empty.json

bea --json --file main.bean add transactions --from empty.json
# exit 0 — data.written == 1

grep -A2 empty main.bean
# 2024-09-04 * "empty"
# (no postings)

bea --file main.bean check
# exit 0

bea --json --file main.bean list transaction --search empty --details
# postings: []
```

Working control — single-add:

```sh
bea --json --file main.bean add transaction --date 2024-09-06 --narration nopost
# exit 2 — Missing option '--posting' / '-p'.
```

## Expected

Bulk rows require at least one posting (matching single-add), or document that
empty transactions are intentional and reject only when that is not the case.
Prefer refusing `postings: []` with a field-path usage/validation error before
write.

## Actual

`TransactionDirective` allows an empty postings list; Beancount’s loader
accepts posting-less transactions, so validation passes and the row is
appended. Single-add Typer marks `--posting` required, so the two entry points
disagree.

## Fix

Add a schema/min-length check (`len(postings) >= 1`) on bulk transaction rows
(and any shared model). Regression: the empty JSON exits 1 with nothing
written; a one-posting inferred-balance row and a normal two-posting row still
work; single-add unchanged.

## Dedupe

Not w3/231 (partial-count advice with mixed failures). Not w3/230 (bare meta
numbers). No open note covers empty `postings` arrays on bulk add.

---

**Resolved 2026-09-16** — `TransactionDirective.postings` requires `min_length=1`, so bulk `postings: []` is rejected before write. Covered by `cli/tests/test_bulk_empty_postings.py`. Shipped with this board close.
