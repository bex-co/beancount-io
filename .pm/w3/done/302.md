# `bea` surfaces `noduplicates` hits as a raw `Transaction(...)` repr (~1.5KB), not a readable duplicate message

**Severity:** minor. **Estimate:** 25–40 minutes. **Owner:** cli. **A1:** an
agent (or human) that enables `beancount.plugins.noduplicates` and accidentally
re-adds the same txn gets a validation error whose detail is a full Python
`Transaction(meta={...}, postings=[Posting(...)])` dump — hard to parse, easy to
misfire on in logs, and unlike the clear “Duplicate open directive for …” line
neighbouring checks already emit.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `73c25851`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
cat > main.bean <<'EOF'
option "operating_currency" "USD"
2020-01-01 open Assets:Cash USD
2020-01-01 open Expenses:Food USD
2020-01-01 open Equity:Opening-Balances
plugin "beancount.plugins.noduplicates"
EOF

bea --file main.bean add transaction --date 2020-07-01 --narration dup \
  --posting 'Expenses:Food 1 USD' --posting 'Assets:Cash'

bea --json --file main.bean add transaction --date 2020-07-01 --narration dup \
  --posting 'Expenses:Food 1 USD' --posting 'Assets:Cash'
# exit 1; error.details[0] starts with:
#   … Duplicate entry: Transaction(meta={'filename': '…', …
# and is ~1400+ characters of Python repr (two full Transaction objects)
```

Working control — ordinary duplicate open:

```sh
bea --json --file main.bean add open --date 2020-01-01 --account Assets:Cash
# details: ["… Duplicate open directive for Assets:Cash"]  (~60 chars)
```

## Expected

A short, stable message naming the conflict (date, narration/payee, accounts, or
source locations of both entries), similar to duplicate-open wording. Keep the
Python repr behind `--debug` if needed for developers.

## Actual

Beancount’s noduplicates plugin formats the error with `str`/`repr` of the
entries; `bea` forwards loader errors verbatim into human stderr and JSON
`details` without normalizing this class.

## Fix

Detect duplicate-entry / noduplicates messages (or post-process loader errors
whose text embeds `Transaction(`) and rewrite to a concise summary with file
locations. Regression: the repro’s JSON detail is a short string without a full
`Posting(` dump; duplicate-open and other validation messages stay unchanged.
