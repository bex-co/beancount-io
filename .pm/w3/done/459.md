# Rewrite non-public avatar URLs in the ledger activity feed

Source: continuous dashboard QA, 2026-10-04.
Pillar: A2 — a newcomer inspecting API responses or any client rendering avatars must not receive broken localhost URLs.

The production `getFeed(source: "LEDGER_RSS")` response returns `authorAvatar: "http://localhost:3000/avatars/..."` on every item. The dashboard's `FeedCard` never renders the field, so nothing visibly breaks there today, but every API consumer (REST feed route, GraphQL, future clients) receives an origin that cannot load outside the server's own loopback — and it leaks an internal dev origin into public responses.

Root cause: `backend-cluster/backend-v2/src/features/gitea/feed/service/activity-transformer.ts:190` passes Gitea's `act_user.avatar_url` through unmodified, and the production Gitea instance builds it from a localhost app URL.

Repro: authenticated `POST /api-gateway/` with `GetFeed(source: "LEDGER_RSS")`; inspect any item's `authorAvatar`.

Acceptance: feed items carry either a publicly reachable avatar URL (rewritten to the deployment's public origin) or no `authorAvatar` when none can be built; no `localhost` or other non-public host appears in production feed responses. Cover the rewrite/omit rule with a unit test on the transformer, run the backend-v2 checks, and ship.

Scope: backend-v2 feed service only; no dashboard or mobile changes required (dashboard already ignores the field; mobile only carries it in generated schema). Estimated under one hour.

---

**Resolved 2026-10-04** — `transformActivityToFeedItem` now keeps `authorAvatar` only when Gitea's `avatar_url` is an absolute http(s) URL on a public host, and omits it for loopback, single-label (compose service), `.local`/`.internal`/`.localhost`, and RFC 1918/link-local hosts. A rewrite was not used: the hosted Gitea's public origin serves `/avatars/` behind basic auth, so a rewritten URL would still not load; self-hosted `https://<GIT_DOMAIN>/avatars/…` and Gravatar URLs pass through. Transformer tests cover keep and omit cases (11 fail with the filter disabled); backend-v2 typecheck, lint, 5,006 tests and the OpenAPI drift check passed. Shipped in `6037e4a3` (`backend-cluster/backend-v2`).
