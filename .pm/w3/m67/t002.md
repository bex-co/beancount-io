## Objective

Re-implement `NonEmptyPath`, `RawPath`, `IntoPath` and the app-wide empty-path refusal on typer 0.29's coercion.

- 0.29 removes `click_type=`, `typer.models.TyperPath`, and `typer._click.types`; `main.py` `_refuse_empty_paths` swaps each `TyperPath`'s class and fails at import under 0.29.
- The 0.29 `parser=` runs as a pydantic before-validator that sees only the value, so refusals that name the option (w5/738) need another design.

## Steps

1. Rebuild the three types and the refusal so each error still names the option.
2. Port the eight `click_type=` options.
