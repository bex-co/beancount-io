# File-upload removal buttons have no accessible names

Severity: **minor**. Package: **dashboard**. Estimate: **25–40m**.
A2: users choosing existing files can identify which staged file a button removes.

Production `https://beancount.io`, 2026-09-08, Chrome 152, English/light.
Fresh 1440×1000 and 390×844 contexts with the QA session. Public
`open_ledger/minimax` grants pull/push, not admin; it is not a disposable ledger.
Local HEAD `a315c273`, fetched main `853a4942`, implicated sources unchanged;
deployed SHA unverified.

1. Open `/ledger/open_ledger/minimax/files/upload/main/` and focus
   **Choose your files**. Enter correctly opens the file chooser.
2. Stage two tiny synthetic CSVs, `qa-20260908-first.csv` and
   `qa-20260908-second.csv`. Do not click Upload Files.
3. Inspect the two X buttons beside the filenames. Both accessibility-tree
   entries are unnamed **button** nodes. Each has empty text, no aria-label,
   aria-labelledby or title, and an aria-hidden SVG. Neither the removal action
   nor the target filename is part of its name.
4. Focus the second button and press Space. It correctly removes the second
   staged file and leaves the first; one unnamed button remains. Upload Files
   stays enabled. Repeat from a fresh page at both widths: same result.

Expected: each button identifies its action and target, such as
**Remove qa-20260908-second.csv**. A filename elsewhere in the row is not an
accessible name for its button. Choose your files, Upload Files and Cancel
already have names and native keyboard behavior. All documents return HTTP 200,
with no console/page errors. Preinstalled mutation guards record zero attempts;
no file was sent or repository commit created. Temporary contexts were closed.

Root: `dashboard/src/features/ledger-editor/upload-files/index.tsx:282–315`
renders each row with an icon-only Button and omits a name. The native Button
wrapper at `common/components/ui/button.tsx:39–64` already forwards attributes;
this is a missing caller label, not065's dropped input props. Selection appends
File objects at lines152–156; removal filters their row index at198–200. The
observed removal handler works. No server/schema change is needed.

Fix: add a localized action-plus-filename aria-label to this Button, using the
existing interpolation convention and all fifteen modules in
`features/ledger-editor/upload-files/locales/`. Preserve keyboard activation,
disabled uploading state, size validation and staged file contents. The
[ARIA button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/)
requires an accessible label for the action. Verify real accessibility names
for two different files and correct keyboard removal at both widths; check
locale shape and the owning package gates when implementing.

Blast radius: the one UploadFilesPage implementation serves
`/files/upload/$branch/$`, reached by the directory toolbar for root/nested
paths. There is no separate upload-row component or other caller to repair.
The selected-file state is local; server upload/retry behavior, duplicate
filenames and drag/drop were not exercised in this finding. No production
receipt parsing, storage upload or ledger mutation is required to verify it.
