# `bea query --output` on a directory or missing parent surfaces raw `[Errno …]` instead of usage guidance

**Severity:** minor. **Estimate:** 15–20 minutes. **Owner:** cli. **A1:** a
mistyped `--output` path (directory, or missing parent folder) returns
`[Errno 21] Is a directory` / `[Errno 2] No such file or directory` with exit 1,
including under `--json` as `category: validation` — no hint to pass a file path
or create the parent.

Found 2026-09-16 by continuous CLI QA against `main`, HEAD `891f54bb`,
`uv run bea` 0.2.0, Darwin 25.5.0 arm64, isolated config/cache. Synthetic
fixtures only.

## Repro

```sh
bea --file main.bean query --output /tmp/some-existing-dir 'SELECT 1'
# exit 1
# Error: [Errno 21] Is a directory: '…tmp…' -> '/tmp/some-existing-dir'

bea --json --file main.bean query --output /tmp/some-existing-dir 'SELECT 1'
# exit 1 — error.message is the same Errno 21 string; category validation

bea --file main.bean query --output /tmp/nope/out.txt 'SELECT 1'
# exit 1
# Error: [Errno 2] No such file or directory: '/tmp/nope/out.txt'
```

Working control: `--output /tmp/out.txt` (writable new file) writes the table
and exits 0.

## Expected

Usage/validation errors that name `--output` and say the path must be a
writable file (create parent directories or refuse clearly), without leaking
OS errno / tempfile rename internals in the primary message.

## Actual

The helper opens/replaces the output path and lets `OSError` propagate into the
CLI error envelope unchanged (including a tempfile `->` destination in the
directory case).

## Fix

Before writing, validate `--output`: reject directories and missing parents with
`UsageError` naming `--output`. Keep successful file writes unchanged.
Regression: the two repros exit 2 (or 1) with a clear `--output` message and no
`[Errno`; JSON `error.category` is `usage`.

## Dedupe

Not w3/249 (format on empty dir). No open note covers query `--output` path
errno leakage.
