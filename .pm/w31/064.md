# `normalizeAgentDirPath` strips `"./"` to `""` and `"./."` to `"."`, so MCP `listLedgerFiles` refuses shell-style current-directory spellings while `"."` succeeds

**Minor · backend-v2 (`normalizeAgentDirPath` in `src/features/ai-agent/tools/agent-repo-path.ts`) · 15–20m · A1.** `listLedgerFiles` (`src/features/ai-agent/tools/list-ledger-files-tool.ts:18,49`) explicitly accepts `"."` as a shell-style spelling for the repository root and calls `normalizeAgentDirPath` (`src/features/ai-agent/tools/agent-repo-path.ts:19-24`) to canonicalize shell paths before `LedgerRepoService.listDirContent` runs `assertSafeRepoPath`. However, `normalizeAgentDirPath` checks `path === "."` *before* stripping leading `"./"` prefixes. As a result, `"./"` and `"././"` strip down to `""` and fail with `BAD_USER_INPUT: File path must not be empty`, and `"./."` strips down to `"."` and fails with `BAD_USER_INPUT: Invalid file path` — even though `"."` and `"./<subdir>"` succeed. Found by `/loopx w31` routine `mcp-qa` (`/qa-find-bugs-mcp w31 SHIP=1`) on 2026-11-23 against `https://beancount.io` (`beancount-mcp 1.0.0`, protocol `2025-11-25`, verified at HEAD `40e22400b`). Credential: unpinned read/write/admin `bcio_` key on the QA account. Synthetic ledger: `<qa-owner>/mcp-agent-eval` (read-only for this finding).

## Repro (live)

Call `listLedgerFiles` on `<qa-owner>/mcp-agent-eval` with `"./"`, `"./."`, and `"././"` vs `"."`:

```sh
node .agents/skills/qa-shared/scripts/qa-mcp.mjs call listLedgerFiles '{"ledger":"<qa-owner>/mcp-agent-eval","dir_path":"./"}'
node .agents/skills/qa-shared/scripts/qa-mcp.mjs call listLedgerFiles '{"ledger":"<qa-owner>/mcp-agent-eval","dir_path":"./."}'
node .agents/skills/qa-shared/scripts/qa-mcp.mjs call listLedgerFiles '{"ledger":"<qa-owner>/mcp-agent-eval","dir_path":"././"}'
```

- Actual:
  - `dir_path: "./"` → `isError: true`, `BAD_USER_INPUT`: `"File path must not be empty"`
  - `dir_path: "./."` → `isError: true`, `BAD_USER_INPUT`: `"Invalid file path"`
  - `dir_path: "././"` → `isError: true`, `BAD_USER_INPUT`: `"File path must not be empty"`
- Controls:
  - `dir_path: "."` → `200 OK`, returns root listing (`[{"path":"main.bean",...}]`).
  - omitted `dir_path` → `200 OK`, returns root listing.
  - `dir_path: ""` → `isError: true`, `BAD_USER_INPUT`: `"File path must not be empty"` (intentional: explicit empty string is not canonicalized to root).
  - REST (`GET /api-gateway/v1/ledgers/{owner}/{name}/files?dirPath=.`) and GraphQL (`getLedgerDirContent(dirPath: ".")`) stay intentionally strict behind `assertSafeRepoPath` (same MCP-only shell-path normalization rule as `w23/done/084`).

Expected:

- `listLedgerFiles` treats `"./"`, `"./."`, and `"././"` identically to `"."` and omitted `dir_path` (lists the repository root).
- Explicit `""`, `"/"`, `".."`, `"../"`, and backslashes continue to pass through unchanged and be refused with `BAD_USER_INPUT`.

## Root cause

Not deployment lag — present at HEAD `40e22400b`:

`backend-cluster/backend-v2/src/features/ai-agent/tools/agent-repo-path.ts:11-24`:

```ts
export function normalizeAgentRepoPath(path: string): string {
  let normalized = path;
  while (normalized.startsWith("./")) {
    normalized = normalized.slice(2);
  }
  return normalized;
}

export function normalizeAgentDirPath(
  path: string | undefined,
): string | undefined {
  if (path === undefined || path === ".") return undefined;
  return normalizeAgentRepoPath(path);
}
```

Checking `path === "."` before stripping `"./"` leaves `"./"` → `""` and `"./."` → `"."`, both of which are then rejected by `assertSafeRepoPath` in `LedgerRepoService.listDirContent` (`src/features/ledger/service/ledger-repo-service.ts:260`).

## Fix

In `backend-cluster/backend-v2`:

1. In `normalizeAgentDirPath` (`src/features/ai-agent/tools/agent-repo-path.ts:19-24`):
   ```ts
   export function normalizeAgentDirPath(
     path: string | undefined,
   ): string | undefined {
     if (path === undefined || path === ".") return undefined;
     if (path === "") return "";
     const normalized = normalizeAgentRepoPath(path);
     return normalized === "" || normalized === "." ? undefined : normalized;
   }
   ```
   Explicit `""` still returns `""` (refused by `assertSafeRepoPath`), while `"."`, `"./"`, `"./."`, `"././"`, and `"././."` normalize to `undefined` (root), and `"./subdir"` still normalizes to `"subdir"`.
2. Add unit tests for `normalizeAgentDirPath` (and `normalizeAgentRepoPath`) plus MCP tool tests for `listLedgerFiles` covering `"."`, `"./"`, `"./."`, `"././"`, `"./subdir"`, `""`, `"/"`, and `"../"`.
