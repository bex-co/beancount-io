# `bea -x <currency>` and hosted print a netted-to-zero trial-balance adjustment differently

Source: split from `w31/031` (`9e549301f`), from the `mcp-qa` routine's run 98, 2026-11-19.

- On a ledger whose books net to zero, `bea report trial-balance -x USD --json` prints the valuation adjustment line as `{"USD":"0"}`.
- The hosted trial balance (`w1/291`) prints the same line as `{}` on MCP, REST and GraphQL.
- This is separate from the `at_value` rule question in `w31/031`, which waits on the owner. This one is only how an empty, zero-valued adjustment is shown.
