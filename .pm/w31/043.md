# `generateTempAssetUploadUrl` signs CRLF/blank/invalid `mimeType` into `uploadHeaders` and embeds raw `path.extname(filename)` (newlines, `#`, `?`, spaces, >1024-byte keys) into `objectKey` across MCP, REST, and GraphQL

**Major · backend-v2 (`AssetStorageService.generateUploadUrl`) · 30–45m · A1.** `AssetStorageService.generateUploadUrl` accepts arbitrary `mimeType` strings (including HTTP header-injection `\r\n`, whitespace-only `"   "`, and non-MIME text) — signing `Content-Type` into the presigned AWS SigV4 URL and returning it verbatim in `uploadHeaders` — and concatenates raw `path.extname(params.filename ?? "")` into the S3 `objectKey`, embedding raw newlines (`\n`), `#`, `?`, spaces, or >1,024-byte extensions that exceed S3's object-key limit. Found by `/loopx w31` routine `mcp-qa` (`/qa-find-bugs-mcp w31 SHIP=1`) on 2026-11-23 against `https://beancount.io` (`beancount-mcp 1.0.0`, protocol `2025-11-25`, checked against HEAD `d5b789be4`). Credential: unpinned read/write/admin `bcio_` key on the QA account. No files were uploaded to object storage.

## Repro (live)

Reproduced in fresh requests across MCP, REST, and GraphQL:

1. **MCP `generateTempAssetUploadUrl` with CRLF `mimeType`:**
   ```sh
   node .agents/skills/qa-shared/scripts/qa-mcp.mjs call generateTempAssetUploadUrl '{"filename":"a.pdf","mimeType":"application/pdf\r\nX-Bad: 1"}'
   ```
   Actual: HTTP `200`, `ok: true`, `X-Amz-SignedHeaders=content-type%3Bhost`, `uploadHeaders: {"Content-Type": "application/pdf\r\nX-Bad: 1"}` (untransmittable by any HTTP client).
   Same with `{"filename":"a.pdf","mimeType":"   "}` -> `ok: true`, `uploadHeaders: {"Content-Type": "   "}` (while `mimeType: ""` omits `uploadHeaders`).
   Same with `{"filename":"a.pdf","mimeType":"not-a-mime"}` -> `ok: true`, `uploadHeaders: {"Content-Type": "not-a-mime"}`.
2. **MCP `generateTempAssetUploadUrl` with newline / special chars / overlong extension in `filename`:**
   ```sh
   node .agents/skills/qa-shared/scripts/qa-mcp.mjs call generateTempAssetUploadUrl '{"filename":"receipt.pdf\nX-Inject: 1"}'
   ```
   Actual: HTTP `200`, `ok: true`, `objectKey: "tmp/<owner-id>/2026-11-23-<id>.pdf\nX-Inject: 1"`.
   Same with `"receipt.pdf "` -> `objectKey` ends in `".pdf "`; `"receipt.pdf#frag"` -> ends in `".pdf#frag"`; `"receipt.pdf?a=1"` -> ends in `".pdf?a=1"`.
   Same with `"a." + "x".repeat(1200)` -> HTTP `200`, `objectKey` length `1249` bytes (past S3's 1,024-byte key ceiling).
3. **REST `POST /api-gateway/v1/temp-assets/upload-url`** with the same three payloads:
   Actual: HTTP `200` on all three (`uploadHeaders: {"Content-Type":"application/pdf\r\nX-Bad: 1"}`, `objectKey` containing `\nX-Inject: 1`, and 1,249-byte `objectKey`).
4. **GraphQL `Mutation.generateTempAssetUploadUrl`**:
   Actual: HTTP `200` on both `mimeType: "application/pdf\r\nX-Bad: 1"` (returns CRLF in `uploadHeaders`) and `filename: "a.pdf\nX-Inject: 1"` (returns `\n` in `objectKey`).

Expected: invalid `mimeType` (blank, containing control characters or whitespace-only, or not matching a valid `type/subtype` media type) is refused with `BAD_USER_INPUT` (`field: "mimeType"`), and `filename` containing control characters or producing an unsafe/overlong extension is refused with `BAD_USER_INPUT` (`field: "filename"`) before presigning, identically on MCP, REST, and GraphQL.

## Working controls

- `generateTempAssetUploadUrl` with `{"filename":"receipt.pdf","mimeType":"application/pdf"}` or `{}` returns a clean `objectKey` and valid `uploadHeaders`.
- `generateTempAssetUploadUrl` with `filename: "../../etc/passwd"` yields `extname(...) === ""` (no path traversal into `objectKey`), and `ownerId` is validated by `OWNER_ID_RE = /^[A-Za-z0-9_-]+$/` (`asset-storage-service.ts:56,197`).

## Root cause

Not deployment lag — present at HEAD `d5b789be4`:

- `backend-cluster/backend-v2/src/features/s3/service/asset-storage-service.ts:201-229` (`AssetStorageService.generateUploadUrl`):
  - `:201`: `const ext = extname(params.filename ?? "");` copies the raw suffix verbatim into `objectKey` at `:206` with no character allowlist, control-character check, or length cap.
  - `:208-229`: passes `params.mimeType` directly into `PutObjectCommand({ ContentType: params.mimeType })`, signs `content-type` whenever `params.mimeType` is truthy (`:219`), and echoes it in `uploadHeaders` (`:227`) without checking media-type syntax, whitespace-only values, or CR/LF control characters.
- `backend-cluster/backend-v2/src/features/s3/api/temp-asset-routes.ts:6-11`: `tempAssetUploadInput` defines `filename: z.string().nullish()` and `mimeType: z.string().nullish()` with no field-level validation.

## Fix

In `backend-cluster/backend-v2`:

1. Validate `mimeType` and `filename` in `AssetStorageService.generateUploadUrl` (`src/features/s3/service/asset-storage-service.ts:186-230`) so MCP, REST, and GraphQL enforce the same rule before calling `getSignedUrl`:
   - If `params.mimeType !== undefined && params.mimeType !== ""`: refuse any value with control characters, whitespace-only, or not matching a valid RFC 6838 media type (`type/subtype` with optional valid parameters) with `BadUserInputError(..., "mimeType")`. (Keep `undefined` / `""` omitting `ContentType` and `uploadHeaders`, or document explicitly if `""` should also be refused — verify existing callers in `dashboard/` and `mobile/` first.)
   - If `params.filename !== undefined`: refuse control characters (`[\x00-\x1f\x7f]`) with `BadUserInputError(..., "filename")`, and constrain the derived `ext` appended to `objectKey` (e.g., allow only `^\.[A-Za-z0-9]{1,16}$`, refusing unsafe/overlong extensions or characters like `#`, `?`, spaces, and newlines so `objectKey` is always URL/S3-safe and well under 1,024 bytes). Keep normal extensions (`.pdf`, `.jpg`, `.jpeg`, `.png`, `.csv`, `.xlsx`, `.json`, `.ofx`, `.qfx`, `.txt`, `.webp`, `.gif`, `.heic`) and extension-less filenames working identically.
2. Add unit tests in `src/features/s3/__tests__/asset-storage-service.test.ts` and 3-surface adapter parity tests in `src/features/s3/__tests__/temp-asset-parity.test.ts` covering CRLF/blank/malformed `mimeType` and newline/`#`/`?`/overlong-extension `filename` across MCP `generateTempAssetUploadUrl`, REST `POST /api-gateway/v1/temp-assets/upload-url`, and GraphQL `Mutation.generateTempAssetUploadUrl`.
