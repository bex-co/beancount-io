# `docs/mcp.md`'s only analysis-resource example, `trial-balance?time=2026&interval=month&conversion=USD`, is refused `BAD_USER_INPUT`: w23/159 removed the trial balance's `interval` and left the example

**Minor · backend-v2 docs (`docs/mcp.md`) · 5–10m · A1.** Under "Resources", the paragraph that says analysis resources take `account`, `filter`, `time`, `interval`, `conversion` and `accountName` gives one example URI (`backend-cluster/backend-v2/docs/mcp.md:1455`):

```text
beancount://alice/books/trial-balance?time=2026&interval=month&conversion=USD
```

On production that read is refused. The MCP error is `-32602`: "BAD_USER_INPUT: Unknown or repeated resource parameter: interval". Its hint lists `account`, `filter`, `time`, `conversion`. REST `GET /api-gateway/v1/ledgers/{owner}/{name}/trial-balance?time=2026&interval=month&conversion=USD` answers `400`: "Unrecognized key: \"interval\"". An agent that copies the doc's one example gets an error.

Found by `/loopx w31` routine `mcp-qa` (`/qa-find-bugs-mcp w31 LAND=1`) on 2026-11-26. Target `https://beancount.io` (`beancount-mcp 1.0.0`), unpinned read/write key, read-only against the QA ledger `<qa-owner>/mcp-agent-eval`.

## Cause

w23/159 (`1bef330de`, 2026-10-28) dropped `interval` from the trial balance on every surface, because the report is a hierarchy and ignored it. The template is now `trial-balance{?account,filter,time,conversion}`, and `rest-query-strictness.test.ts` pins the refusal. The doc example was not updated, and `grep` finds no other stale copy in the repository.

## Fix

Change the example to a read that takes all three parameters, for example `beancount://alice/books/interval-totals?time=2026&interval=month&conversion=USD`, or drop `interval` from the trial-balance URI. Keep the sentence above it: `interval` is still accepted by the statements, overview, interval totals and account report.

## Done when

The example URI in `docs/mcp.md` reads successfully on `resources/read` against a ledger. It is the same URI shape the template list publishes.

## Dedupe

Searched `.pm/**`, including `done/`, for `interval=month` and the example URI. w23/159 (done) is the change that left it stale. No open item covers it.
