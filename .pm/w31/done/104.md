# An `addLedgerEntries` preview that would add a routed file's include reports `wrote: [{path: "main.bean"}]`, though a dry run writes nothing; the same preview without the include, and `appendLedgerText`'s, report `wrote: []`

**Minor · backend-v2 (`src/features/ai-agent/api/mcp-tools.ts`) · 10–20m · A1.** `wrote` is "Files (and lines, when known) the write landed in" (`src/features/ai-agent/tools/types.ts:154`). A dry run lands in nothing. The `addLedgerEntries` tool adds `main.bean` to `wrote` whenever the result names an include, whether or not it committed. So an agent that previews a routed entry is told the entry point was written. This is MCP only: REST and GraphQL have no `wrote` field.

Found by `/loopx w31` routine `mcp-qa` (`/qa-find-bugs-mcp w31 LAND=1`) on 2026-11-26, during the w31/103 repro.

- **Target:** `https://beancount.io` (`beancount-mcp 1.0.0`, protocol `2025-11-25`). Local HEAD `fa9af286c` has the same code.
- **Credential:** an unpinned read/write `bcio_` key on the QA account.
- **Ledger:** the designated QA ledger `<qa-owner>/mcp-agent-eval`, with the w31/103 setup. `main.bean` has `2000-01-01 custom "beancountio-option" "transaction_file" "qa-20261126-tol/{year}.bean"`, and `qa-20261126-tol/2026.bean` does not exist. It was restored byte for byte afterwards.

## Repro (live)

1. Call `addLedgerEntries` with `dry_run: true` and one balanced transaction dated `2026-08-30`.
2. It returns "Would add 1 entry; main.bean would include qa-20261126-tol/2026.bean" with `files: []`, `preview` naming `qa-20261126-tol/2026.bean`, and `wrote: [{"path":"main.bean"}]`.
3. Controls:
   - With the routing line removed, the same preview returns `wrote: []`.
   - `appendLedgerText` with the routed text and `dry_run: true` returns `wrote: []`, with both files in its `diff`.

## Cause

`addLedgerEntries`'s `execute` builds `touched` from `files` plus `LEDGER_ENTRY_POINT` whenever `included` is non-empty (`backend-cluster/backend-v2/src/features/ai-agent/api/mcp-tools.ts:541-543`), and `wrote` is `touched` (`:555`). `files` is already `[]` on a dry run (`ledger-entry-service.ts`, `files: dryRun ? [] : distinctFiles`), but the entry point is added on every branch.

## Fix

Add the entry point only when the call committed: `included && !dryRun`, or `wrote: dryRun ? [] : …`, as `appendLedgerText` and the file tools do (`mcp-tools.ts:764`, `:829`, `:886`). A routed commit keeps both the routed file and `main.bean`.
