# `bea -x <currency>` and hosted print a netted-to-zero trial-balance adjustment differently

Source: split from `w31/031` (`9e549301f`), from the `mcp-qa` routine's run 98, 2026-11-19.

- On a ledger whose books net to zero, `bea report trial-balance -x USD --json` prints the valuation adjustment line as `{"USD":"0"}`.
- The hosted trial balance (`w1/291`) prints the same line as `{}` on MCP, REST and GraphQL.
- This is separate from the `at_value` rule question in `w31/031`, which waits on the owner. This one is only how an empty, zero-valued adjustment is shown.

**Done when:** a written rule already in the repository decides which shape is right, `bea` and hosted print the same shape for a zero adjustment, and a test on the side that changed pins it. If no written rule exists, the difference is recorded in `backend-cluster/backend-v2/docs/mcp.md` and `cli/docs/USAGE.md` as deliberate, and the note is closed.

---

**Resolved 2026-11-19** — No written rule decides between the two shapes, so the difference is recorded as deliberate. Each side follows its own documented convention, and both are pinned by tests. `bea` names the requested currency in a headline total: w5/506 sent the balance sheet's adjustment through `_headline`, USAGE spells `net_profit` and quiet interval rows the same way, and w1/287 derived the trial-balance line as the balance sheet's. `cli/tests/test_report_trial_balance_nets.py` pins `{"USD": "0"}`. Hosted balance maps are Fava-shaped and drop a currency that nets to zero, quiet interval rows included (`serialiseInventory`, `valueRecord`). The ledger contract and the GraphQL field say the line is `{}` when the roots already net, and `trial-balance-adjustment.test.ts` ("is empty for books that already net") pins it. No ADR, `DO_NOT_DO.md` rule, w1/291, w1/292, `mcp.md` or USAGE text picks one shape for both sides. Rerun at HEAD with `bea` 0.4.1 from this checkout, on a USD ledger that nets: the default and `-x USD` give `{"USD": "0"}`, `-x at_value` and `-x at_cost` give `{}`, and `-x units` gives `null`. Hosted gives `{}` under every valued conversion, from the code and its tests. Nothing was rerun live. `backend-cluster/backend-v2/docs/mcp.md` (after the `shape=fava` paragraph) and `cli/docs/USAGE.md` (trial balance) now state both spellings and say to read a missing currency as zero. Shipped in the commit carrying this note (`backend-v2` docs, `cli` docs).
