# Four links wrap a `<button>`, so each one takes two Tab presses: Bank Connections "Back to Transactions" and "Manage Banks", the CSV example download, OAuth "Create Ledger"

**Severity:** minor (keyboard and screen reader). **Owner:** dashboard. **Estimate:** 20–30 minutes including a test. **A2:** keyboard users hit each of these controls twice, and screen readers announce a link and then a button with the same name. HTML forbids interactive content inside `<a>`. **Found by:** `/qa-find-bugs-dashboard` on 2026-11-18 against `https://beancount.io` (entry chunk `main-LGv2TZLj.js`), headless Chromium 153 at 1440×1000, English/light, signed in as the QA owner on the synthetic ledger `mcp-agent-eval`. Read-only. Local HEAD `a95dfa7d3`.

## Repro

On `/ledger/<owner>/<ledger>/plaid-connections`, focus **Help and support** and press Tab repeatedly. The stops are Import, User menu, `A "Back to Transactions"`, `BUTTON "Back to Transactions"`, Connect Bank. The accessibility tree shows `link "Back to Transactions"` containing `button "Back to Transactions"`. The rendered DOM is `<a href="…/link"><button data-slot="button">…`.

## Cause

A `<Link>` or `<a>` wrapping `<Button>` without `asChild`:

- `dashboard/src/features/plaid/pages/plaid-connections/index.tsx:117-125`: **Back to Transactions** (observed).
- `dashboard/src/features/plaid/pages/plaid-settings/components/plaid-management-state.tsx:94-102`: **Manage Banks** (by source).
- `dashboard/src/features/importer/components/steps/upload/parse-error-display.tsx:158-167`: **Download CSV example** on the Smart Import parse error (by source).
- `dashboard/src/features/oauth/pages/consent.tsx:137-143`: **Create Ledger** on OAuth consent with no ledgers (by source).

## Fix

Use `<Button asChild><Link …>…</Link></Button>`, as the rest of the dashboard does, so each control renders as one `<a>` with button styling. The `download` attribute and the search params move to the inner element unchanged. Also check **Back to Transactions**: it goes to `/link`, which is headed "Connected Accounts" and shows no transactions while nothing is connected. Name it for where it goes.

## Definition of done

- Each of the four renders a single focusable `<a>` with no nested `<button>`. One Tab reaches it, and Enter follows it.
- A test (rendered, or a source scan like the existing a11y lint tests) fails on a `<Link>` or `<a>` that wraps `<Button>` without `asChild`. Dashboard gates pass.
