# Retarget inferred postings with a comment beside the account token

**Minor · cli · 25–40m · A1 · worker1.** A native-valid inferred posting
`Expenses:Uncategorized; keep counter note` is ignored by an account update.
Account-only apply exits0/written0/noop; adding `--flag '*'` clears the
review flag and reports written1 while leaving10USD Uncategorized. The
batch detail even describes the requested account change. A space before
the semicolon makes the same edit work. No product fix implemented.
