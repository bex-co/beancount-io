# Keep direct parent-account spending when only a child has a budget

**Major · cli · 35–50m · A1/A2 · worker1.** `report budget` silently omits
unbudgeted postings to a parent when a descendant has a budget. JSON, text
and CSV all succeed and show only 30 USD of a valid ledger's 60 USD expense
activity. An exact-parent account filter reports no rows despite its 30 USD
posting. No product fix implemented.

Environment: 2026-11-07, clean main `74a0b8cbe381391a4385e88cf0358a1f7154928f`,
checkout `cli/.venv/bin/bea` 0.3.1, Python 3.12.10, macOS 26.5.1 arm64;
existing managed engine with checkout helper sources. Each command is a fresh
process, 25s timeout, closed stdin/no TTY, offline, explicit absolute ledger,
isolated child `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, notifier disabled,
`BEA_FILE`/`BEA_TOKEN` removed, HOME unchanged.

## Reproduce

Create this synthetic `main.bean` in a fresh disposable directory:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Cash USD
2026-01-01 open Expenses:Food USD
2026-01-01 open Expenses:Food:Dining USD
2026-01-01 open Expenses:Travel USD
2026-01-01 open Equity:Opening USD
2026-01-01 * "Opening"
  Assets:Cash 1000.00 USD
  Equity:Opening -1000.00 USD
2026-01-02 * "Parent food"
  Expenses:Food 30.00 USD
  Assets:Cash -30.00 USD
2026-01-03 * "Dining"
  Expenses:Food:Dining 20.00 USD
  Assets:Cash -20.00 USD
2026-01-04 * "Travel"
  Expenses:Travel 10.00 USD
  Assets:Cash -10.00 USD
2026-01-31 note Assets:Cash "End"
2026-01-01 custom "budget" Expenses:Food:Dining "monthly" 100.00 USD
```

Run from that directory, substituting absolute executable and file paths:

```sh
bea --json --no-input --offline --file /absolute/main.bean check
bea --json --no-input --offline --file /absolute/main.bean report budget --time 2026-01
bea --no-input --offline --file /absolute/main.bean report budget --time 2026-01
bea --no-input --offline --file /absolute/main.bean report budget --time 2026-01 --format csv
bea --json --no-input --offline --file /absolute/main.bean report budget --time 2026-01 --account '^Expenses:Food$'
bea --json --no-input --offline --file /absolute/main.bean query 'SELECT account, sum(number) WHERE account ~ "Expenses" GROUP BY account'
```

All exit 0 with empty stderr and unchanged source hashes. Check is valid.
The unfiltered budget report contains only Dining (actual 20.00, budget
100.00) and unbudgeted Travel (actual 10.00); Food's direct 30.00 is absent.
The exact-parent filter returns `periods[0].rows: []`. BQL independently gives
Food 30.00, Dining 20.00, Travel 10.00 USD. A fresh native Beancount load has
no errors and those same balances. Expected: an additional unbudgeted Food
row with actual 30.00, `budget: null`, `variance: null`; its direct postings
are outside Dining's budget subtree. This follows `cli/docs/USAGE.md`'s Budgets
contract: accounts no budget covers are listed unbudgeted.

Repeated with a new fixture/process. The equivalent Income parent/child
fixture also loses the parent's 30.00 earnings; both exact-parent filters
return no rows. Controls: removing the budget lists all three direct expense
balances; moving it to Food correctly rolls Food and Dining into a 50.00
budgeted actual and leaves Travel 10.00 unbudgeted. Preserve this rollup.

## Cause and repair

`cli/src/bea_engine/report.py:437` suppresses an unbudgeted account whenever
`_related(account, name)` is true for any budget. `_related` (:352–354) tests
both ancestry directions. A child budget therefore suppresses its parent,
although that budget's actual (:419–420) includes only the child and its
descendants. The parent's direct money is represented nowhere.

Make coverage directional: suppress a direct-posting unbudgeted row only
when an applicable budget is on that account or an ancestor. Keep descendants
rolled into their budgeted ancestor, and retain the Income sign convention
and account-filter scope. `_related` has one production caller. Engine
`answer` dispatches to `_budget`; frontend `commands/report.py::budget` and
`report_csv.py::_budget` render the same rows. Both renderers were exercised;
no server/API or dependency change is involved.

Acceptance: the fixture's three expense amounts remain visible, including
Food's unbudgeted 30.00 in JSON/text/CSV and with the exact-parent filter;
the Income equivalent retains positive earned actuals. Preserve no-budget
and parent-budget controls, and add meaningful regression coverage in
`cli/tests/test_report_budget.py`; run `make check-all` inside `cli/`.

Dedupe: searched all 6,445 board Markdown files (done/blocked included) for
budget ancestry, omitted/unbudgeted actuals and `_related`; reviewed all
42 open/blocked milestone scopes and targeted source history. Introduced by
`a501d9341` ([w21/m7](../w21/done/m7/README.md)); its tests cover a budgeted
parent but not unbudgeted direct ancestor postings. Keep that completed
milestone closed; this is a newly exercised residual. No open overlap found.
