# The Journal's Type column prints "Balance", "Price", "Custom" and the "Transaction" tooltip in English in every language

**Severity:** minor (localization). **Found by:** `/qa-find-bugs-dashboard` on 2026-11-15 against `https://beancount.io` (local HEAD `11ff3a84b`; the code below is unchanged at HEAD, so this is not deployment lag), headless Chromium at 1440×1000, isolated profile, signed in as the QA account.

## Repro

1. Open `/ledger/open_ledger/example/journal?lang=fa` (also reproduces with `lang=de` or any other non-English locale).
2. In the type filter row, turn on Balance, Price and Custom. Their buttons read `مانده`, `قیمت`, `سفارشی`, so the labels are translated.
3. Read the first column of the table.

**Actual:** the badge on each non-transaction row is the raw API value: `Balance`, `Price`, `Custom` (and `Open`, `Close`, `Note`, `Document`, `Pad` when shown). Every transaction badge (`*` / `!`) carries the English tooltip `title="Transaction"`. The account page (`/ledger/<owner>/<ledger>/account/<name>`) uses the same table and shows the same English tooltip.

**Expected:** the badge text and its tooltip use the same translated labels as the filter buttons (`journal.balance`, `journal.price`, `journal.custom`, `journal.transaction`, …). The `*` / `!` flag glyph itself stays as it is.

## Root cause

`dashboard/src/features/journal/components/journal-table.tsx:469-471` renders `title={directive.directive_type}` and `{isTransaction ? directive.flag : directive.directive_type}` directly. The filter buttons translate the same types through `labelKey` in `features/journal/components/journal-filter-buttons.ts`. Every type already has a key in `features/journal/locales/*.ts` (`journal.open`, `close`, `transaction`, `balance`, `note`, `document`, `pad`, `price`, `custom`, `commodity`, `event`, `query`).

## Fix

Owned by `dashboard`. Map `directive_type` to its `journal.<type>` key in one place and use the result for both the badge text and its `title`. If a type has no key, fall back to the raw value. Callers are `features/journal/pages/journal-page.tsx` and `features/reports/account/index.tsx`, and both go through `journal-table.tsx`.

## Acceptance

- With `?lang=fa`, the Journal's Balance, Price and Custom rows show `مانده`, `قیمت`, `سفارشی`. A transaction badge's tooltip reads `تراکنش`.
- English rendering is unchanged.
- A `journal-table` test renders a Balance row and a Transaction row under a non-English locale. It asserts the translated badge text and tooltip, and it fails against the current code.
