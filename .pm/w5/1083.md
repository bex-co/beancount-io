# Expand forecast markers in existing multiline narrations

**Minor · cli · 30–45m · A1 · worker1.** Real CLI QA, 2026-10-27,
`bea 0.3.1` on macOS 26.5.1 arm64, frontend Python 3.13.3 and existing
managed Python 3.12.10 / Beancount 3.2.3. Runtime source is pinned to
`0c2c69bd09407962f0a51e17411155acfcca035c`; all 1,741 current CLI files
still match that snapshot. Report only; no product fix implemented.

An existing, native-valid multiline narration ending in a supported
recurrence marker is silently treated as an ordinary single occurrence.
For three monthly 100 USD rents, list, query, income statement and the
export all contain only January: forecast expense is 100 USD instead of
300 USD. Every command exits 0, including `check`.

Create a disposable `main.bean`. The line break inside the quoted
narration below is literal:

```beancount
plugin "fava.plugins.forecast"
option "operating_currency" "USD"
2024-01-01 open Assets:Checking USD
2024-01-01 open Expenses:Rent USD
2024-01-05 # "Rent
apartment [MONTHLY REPEAT 3 TIMES]"
  Expenses:Rent 100.00 USD
  Assets:Checking -100.00 USD
```

With an owned `BEA_CONFIG_DIR` / `XDG_CACHE_HOME`, notifier disabled,
no inherited ledger/token selection, unchanged HOME and closed stdin:

```sh
bea --offline --no-input --file /absolute/main.bean check
bea --json --offline --file /absolute/main.bean list transaction --sort oldest
bea --json --offline --file /absolute/main.bean report income-statement --time 2024
```

Actual: one transaction dated `2024-01-05`, narration still containing
`[MONTHLY REPEAT 3 TIMES]`, and `net_profit: {"USD": "-100.00"}`.
Expected: January 5, February 5 and March 5, with the marker removed and
the multiline narration otherwise preserved; annual net profit −300 USD.
Joining just the existing narration's two lines restores all three
occurrences and the −300 USD total without changing the plugin or marker.

The plugin's own contract expands supported markers on `#` templates
and preserves their other fields. Existing multiline Beancount strings are
valid inputs; USAGE also preserves them during formatting and directive
exports. New writes deliberately normalize pasted line breaks to spaces
([USAGE](../../cli/docs/USAGE.md)); that documented behavior is a working
control and is unchanged by this repair.

native operations; eight affected and sixteen controls**. LF and CRLF,

For a complete standalone replay, save this as `recipe.py`, then run
`python3 recipe.py /absolute/unused/case lf json split`. Use `crlf` for
Windows-style source bytes, `single`, `ordinary`, `no-marker` or `trailing`
for controls, and `human` / `root` for the other output/layout forms.
The recipe uses fixed historical dates and no network or installation.

```python
import hashlib,json,os,subprocess,sys,time
from pathlib import Path
# python3 recipe.py /absolute/unused/case lf|crlf|single|ordinary|no-marker|trailing json|human root|split
case=Path(sys.argv[1]).resolve();mode,surface,layout=sys.argv[2:5];case.mkdir(parents=True,exist_ok=False)
assert mode in ['lf','crlf','single','ordinary','no-marker','trailing'] and surface in ['json','human'] and layout in ['root','split']
books=case/'Books Café';books.mkdir();book=books/'main.bean';journal=books/'2024/activity.bean' if layout=='split' else book;reference=case/'reference.bean';export=case/'export.bean';calls=[];env=os.environ.copy()
for key in ('BEA_FILE','BEA_TOKEN','BEANCOUNT_LOAD_CACHE_FILENAME','BEA_ENGINE_PYTHON','BEA_ENGINE_DIR'):env.pop(key,None)
overrides=dict(BEA_CONFIG_DIR=str(case/'config'),XDG_CACHE_HOME=str(case/'cache'),BEA_NO_UPDATE_NOTIFIER='1');env.update(overrides)
def quote(s):return '"'+s.replace('\\','\\\\').replace('"','\\"')+'"'
plain='Rent apartment' if mode=='single' else 'Rent\napartment';marker=' [MONTHLY REPEAT 3 TIMES]';narration=plain+marker;flag='*' if mode=='ordinary' else '#';dates=['2024-01-05','2024-02-05','2024-03-05']
if mode=='no-marker':narration=plain;dates=dates[:1]
elif mode=='ordinary':dates=dates[:1]
elif mode=='trailing':narration='Rent'+marker+' receipt';plain='Rent'
header='option "operating_currency" "USD"\n2024-01-01 open Assets:Checking USD\n2024-01-01 open Expenses:Rent USD\n'
def entry(day,text):return day+' '+flag+' "Landlord" '+quote(text)+' #housing ^lease-2024\n  reference: "unit-2"\n  Expenses:Rent 100.00 USD\n  Assets:Checking -100.00 USD\n'
root='plugin "fava.plugins.forecast"\n'+header;body=entry('2024-01-05',narration)
if layout=='split':journal.parent.mkdir();book.write_text(root+'include "2024/activity.bean"\n');journal.write_bytes(body.replace('\n','\r\n').encode() if mode=='crlf' else body.encode())
else:book.write_bytes((root+body).replace('\n','\r\n').encode() if mode=='crlf' else (root+body).encode())
reference.write_bytes((header+''.join(entry(day,narration if mode in ['ordinary','no-marker'] else plain) for day in dates)).encode());inputs={p:p.read_bytes() for p in {book,journal,reference}}
def hashes():return {str(p.relative_to(case)):hashlib.sha256(p.read_bytes()).hexdigest() for p in inputs}
def save():(case/'results.json').write_text(json.dumps(dict(mode=mode,surface=surface,layout=layout,book=str(book),journal=str(journal),reference=str(reference),export=str(export),calls=calls),indent=2,ensure_ascii=False))
def run(tag,args,printing=False):

run('check',['check']);run('list',['list','transaction','--sort','oldest','--limit','100']);run('on-disk',['list','transaction','--sort','oldest','--limit','100','--on-disk']);run('query',['query',"SELECT date,narration,number WHERE account = 'Expenses:Rent' ORDER BY date"]);run('income',['report','income-statement','--time','2024','--interval','monthly']);run('PRINT',['query','PRINT','--format','beancount','--output',str(export)],True)
print(json.dumps(dict(mode=mode,surface=surface,layout=layout,exits=[c['exit'] for c in calls])))
```
