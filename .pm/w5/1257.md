# Report charts write their y-axis in English in every language: German Income Statement reads "-3.0k" over a tooltip of "-3.125,74", Japanese "8.0k" where Overview says "8万", Persian Latin "8.0k" beside Persian-digit tooltips (dashboard gap in w21/177)

**Severity:** minor (chart readability in 14 of 15 languages). **Owner:** `dashboard` (`common/lib/chart`, `features/ledger-data/commodities`). **Estimate:** 30–45 minutes including tests. **A2:** a reader who chose German, Japanese or Persian reads the report charts' scale in English notation: a `.` decimal point, `k`/`m`/`b`/`t` suffixes and Latin digits. The same chart's tooltip, the tables under it and the Overview charts on the same ledger all use the reader's language. **Found by:** `/qa-find-bugs-dashboard` (`dashboard-qa` routine) on 2026-11-27 against `https://beancount.io`, production entry chunk `main-BBmi61Hs.js`. QA-owned headless Chromium 158 at 1440×1000, signed out in fresh contexts with the `i18nextLng` cookie set to `de`, `ja` or `fa`, on the public `open_ledger/example` ledger. Read-only. Local HEAD `c654550d1`.

## Repro

Public ledger, no sign-in needed. Set the language to Deutsch (or open with `?lang=de`).

1. Open `/ledger/open_ledger/example/income-statement`. The Nettogewinn chart's y-axis reads **0.0, -1.0k, -2.0k … -7.0k**. Hover the 2015-02 bar: the tooltip reads **USD: -3.125,74**. The Erträge table under it reads **-357.944,58**.
2. Open `/balance-sheet`. The net worth axis reads **7.9k, 20.0k … 100.0k, 117.5k**. Open `/budget`: **0.0, 100.0 … 700.0**. Open `/commodities` and show a price history: the axis reads **150.00 … 300.00** and the tooltip **GLD/USD: 221.08**.
3. Control, same ledger and language: Overview (`/ledger/open_ledger/example?month=2016-08`) labels its net worth axis **20.000 … 80.000** and the point **72.496,4**.
4. In 日本語, `/account/Assets%3AUS%3ABofA%3AChecking` labels its balance axis **166.0, 2.0k … 8.0k, 8.8k**. Overview on the same ledger labels its axis **2万 … 8万** and the point **7.2万**.
5. In فارسی, `/cash-flow` labels its axis **-6.0k … 8.0k** in Latin digits. Hovering 2016-05 gives the tooltip **USD: ‎−۲٬۳۰۰٫۰۴۴** in Persian digits. Overview labels its axis **۲۰ هزار … ۸۰ هزار**.

Each page was repeated from a fresh load. English renders as before (`-1.2k`, `117.5k`).

## Cause

`dashboard/src/common/lib/chart/chart.ts:24-42`: `formatYAxisNumber` calls `numbro(value).format({ average: true, mantissa: 1 })`. numbro is used only here and has no language registered, so it always writes en-US, whatever language the reader chose. Its callers are:

- `common/lib/chart/cartesian-config.ts:37-40`, through `createCommonAxisConfig`: the Income Statement charts (`income-statement/date-balance-chart/single-…` and `stack-date-balance-chart.tsx`), both Cash Flow charts (`cash-flow/cash-flow-charts.tsx:120,296`) and the Budget chart (`budget-chart-card.tsx:217`);
- `features/reports/balance-sheet/line-chart.tsx:188`: Balance Sheet net worth and the account page's Account Balance (`reports/account/index.tsx:38`);
- `features/ledger-data/budget/budget-chart-card.tsx:260`.

Commodities formats its own ticks with `toFixed` / `String(Number(…))` (`ledger-data/commodities/format-commodity-price.ts:47-58`). Its tooltip prints the raw source string (`build-commodity-chart-labels.ts:37-41`, `formatCommodityPriceLabel`).

The working control is Overview. Its net worth axis uses `netWorthTickFormatter(language)`, an `Intl.NumberFormat(language, { notation: "compact" })` (`features/reports/overview/lib/overview-utils.ts:426-434`). Its income/expense axis uses `useFormatNumber` (`overview/components/income-expenses-chart.tsx:233`, w4/216). The report tooltips are already localized.

## Fix

Give every report chart one language-aware tick formatter in `common/lib/chart`. For example, move Overview's `Intl.NumberFormat(language, { notation: "compact", … })` there and pass the reader's language from each caller (they already call `useTranslations`). Keep the rules the current formatter carries:

- one unit per tick at full magnitude (w5/1175);
- fractional and exponential ticks below one stay distinct (w4/117);
- adjacent large ticks stay distinct (w5/1177's `maximumSignificantDigits`);
- the LTR canvas (w4/1018).

For Commodities, format ticks with the language's separators at the decimals `commodityAxisDecimals` picks (w4/1066/1067). Write the tooltip with the reader's separators but every source digit, as `LedgerAmount` does. Do not change the plotted numbers or the Period data tables.

## Definition of done

- In German, the Income Statement, Cash Flow, Balance Sheet, account Balance and Budget axes on `open_ledger/example` use German notation, with the same thousands notation as Overview (`20.000`, not `20.0k`). The Commodities axis reads `300,00` and its tooltip `GLD/USD: 221,08`. English output is unchanged.
- In Japanese, the account Balance axis uses 万 the way Overview does. In Persian, every report axis uses Persian digits and keeps its minus before the digits.
- `common/lib/chart/__tests__/chart.test.ts` (or the new formatter's test) covers en, de, ja and fa, including negative values, zero, a sub-one tick, a million and the w5/1175 boundary values. The de/ja/fa cases fail on the current code. A rendered test for one `createCommonAxisConfig` caller and the commodity labels asserts the German axis. Dashboard gates pass.

## Dedupe

Searched `.pm/**` (open, `done/`, `blocked/`) for `formatYAxisNumber`, numbro, axis together with German, Persian, Japanese or locale, compact notation, `Tsd.` and `万`. The mobile app fixed this: w21/177 for English K/M/B/T, w21/882 and w21/933 for separators and Persian digits. On the dashboard:

- w4/216 (done) localized Overview's tooltip.
- w4/1018 (done) fixed the sign position of Persian ticks and recorded them as `-1.0k`. It did not localize them.
- w5/1175 (done) fixed the unit thresholds, in English only.
- w4/1055 (done) covers the commodity history table's sign, not the chart.

No item localizes the report axes. `main` still has the code cited above, so this is not deployment lag.

**Unverified:** the other 11 languages (same function), the BQL chart (`features/bql/lib/chart-utils.ts`, its own exponent formatter), `render_commas`, and the 390px layout.
