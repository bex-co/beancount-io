# The compact Journal runs a non-transaction entry's words together ("locationNew Metropolis") and cuts its type to "P…"; Commodity rows say "Unknown directive type"

**Severity:** minor. **Owner:** `dashboard`. **Estimate:** 30–45 minutes including tests. **A2:** Compact is the Journal's default layout since the rebuild in `91daf9b46`. Every Event, Custom, Pad and Document row in it reads as one run-on word, and a Pad row's type is cut to one letter on a 1440px screen. **Found by:** `/qa-find-bugs-dashboard` (`dashboard-qa` routine) on 2026-11-20 against `https://beancount.io`, production entry chunk `main-CcF8TRB_.js`, isolated headless Chromium at 1440×1000, English. Public ledgers only; reproduced from fresh loads.

## Repro

1. `/ledger/open_ledger/example/journal?time=2017-06-03`. Open **Entry types** and turn every type off, so the button reads **Entry types: All**. The Event row reads `Event  locationNew Metropolis`. The API returns `{"directive_type":"Event","type":"location","description":"New Metropolis"}`.
2. Same ledger, `?time=2026-10`, with Custom on: `Custom  Expenses:Food:Restaurantmonthly600 USD`. The budget's account, interval and amount have no space between them.
3. `/ledger/open_ledger/blackberry/journal`, Entry types set to Pad only: `P…  Equity:OtherComprehensiveIncomefrom Equity:…`. The type label is cut to `P…`, and the description is cut although the Account and Amount cells of the row are empty.
4. Same view as step 1 with `?time=1980`: each Commodity row reads `Commodity  Unknown directive type`. Its accessible name knows the code (`Open entry 1980-05-12 Commodity IRAUSD (row 1)`), and the API returns `"currency":"IRAUSD"` with a `name` in `meta`.

Control: **Comfortable** keeps each part on its own line (`Event / location / New Metropolis`). Balance rows keep their type label whole.

## Cause

- `dashboard/src/features/journal/components/journal-lines.tsx:265` wraps `JournalDescription` in `[&_div]:inline [&_div]:p-0`. Each description component writes its parts as sibling `<div>`s: `event-description.tsx` (type, description), `custom-description.tsx` (account, then a `flex gap-2` div of interval and amount), `pad-description.tsx` (account, then "from" plus the source account), and `document-description.tsx` (account, filename). Made inline, they lose the block break, and the `flex gap-2` row loses its gap, with nothing to separate them.
- `journal-lines.tsx:213` makes the type button `shrink-0` only for balance rows. Elsewhere it keeps `OPENER`'s `min-w-0 truncate` (`:47`), so a long description shrinks it to `P…`.
- `journal-description/index.tsx:53` has no Commodity branch. A Commodity directive falls through to `journal.unknownDirectiveType`. The type picker offers no Commodity or Event choice, so these rows appear only under **All**.

## Fix

- Compact lines: render each description's parts as inline runs with a visible separator, such as a space or a ` · ` in the muted colour, instead of flattening their `<div>`s. Keep one line, truncating at the end.
- Keep every row's type label whole (`shrink-0`), as balance rows already do.
- Add a Commodity description that shows the code, and its `name` metadata when present (`IRAUSD · US 401k and IRA Contributions`).
- Tests: a rendered compact-lines test for an Event, a budget Custom, a Pad and a Commodity row. It asserts the separated text, the whole type label, and the commodity code. It fails on the current code.

## Blast radius

At `main` (`ebbf43fed`), `journal-lines.tsx` also draws the account page's journal, and the Overview's Recent activity uses the days layout, so the account page gets the same compact rows once it is deployed. Note rows (one div), Open/Close rows (one div) and Price rows (one div) are unaffected. Transactions and balances take their own branches.
