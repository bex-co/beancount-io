# In Persian, every account name on Journal, Overview, account pages, Budget and Accounts reads backwards: "Slate:Liabilities:US:Chase", "Checking:BofA:US:Assets"

**Severity:** minor (Persian locale; misleading on every core page). **Owner:** dashboard. **Estimate:** 30–45 minutes. **A2:** a Persian reader sees `Liabilities:US:Chase:Slate` written as `Slate:Liabilities:US:Chase` in the Journal and `Assets:US:BofA:Checking` as `Checking:BofA:US:Assets` in Accounts. That is not a name in their ledger, not what they type into the Account filter, and not how the same page's heading writes it. **Found by:** `/qa-find-bugs-dashboard` on 2026-11-21 against `https://beancount.io`, production entry chunk `main-CIyNN76T.js` (built from `main` at or after `ebbf43fed`). QA-owned headless Chromium at 1440×1000, light theme, signed in as the QA owner, on the public `open_ledger/example` ledger. Read-only. Local HEAD `08f5f78be`.

## Repro

1. Open `/ledger/open_ledger/example/journal?lang=fa` (the page is `dir="rtl"`). The Account column reads `Slate:Liabilities:US:Chase`, `Restaurant:Expenses:Food`, `Salary:Income:US:Hoogle` and `Checking:Assets:US:BofA`. The bold last segment is drawn first (leftmost), then the colon, then the parent path.
2. Measured on every `AccountName` on the page (the visible part's path span against its leaf span): in Persian the leaf sits left of the path on all 116 names on Journal, all 37 on `/account/Assets:US:BofA:Checking`, all 12 in Overview's account cards, and both on Budget. In English the leaf is right of the path on every one.
3. On `/account/Assets:US:BofA:Checking?lang=fa`, the page heading reads `Assets:US:BofA:Checking` (root first, plain text), while the register under it reads `Checking:Assets:US:BofA` for the same account.
4. Open `/ledger/open_ledger/example/accounts?lang=fa`. Every row is fully mirrored: `Checking:BofA:US:Assets`, `PreTax401k:Federal:US:Assets`, `Slate:Chase:US:Liabilities`.

Repeated from a fresh load. Screen readers are not affected: `AccountName` reads its full name from a visually hidden copy, and each Accounts segment button is named by its prefix.

## Cause

Both renderers split the name into separate boxes inside a flex row, and a flex row in a right-to-left page runs right to left. Beancount account names are written root first; written as plain text in a right-to-left paragraph, a Latin name stays one left-to-right run and reads correctly (the account page heading is plain text).

- `dashboard/src/common/components/account-name.tsx:29` lays the path (`:23`) and `:leaf` (`:24`) out as two flex children of `<span aria-hidden="true" className="flex min-w-0">`, so the leaf ends up left of the path. Introduced with the component in `97c05f2bb` ("one account-name convention"). Callers: `journal-lines.tsx:381,413,422`, `journal-days.tsx:420`, `journal-postings.tsx:68,71`, `account-balances-card.tsx:211`, `money-movement-section.tsx:190`, `budget-summary.tsx:313`, `budget-chart-card.tsx:339`, `cash-account-status-panel.tsx:130`.
- `dashboard/src/features/ledger-data/accounts/account-prefix-navigation.tsx:37-40` renders one button per segment in a `flex flex-wrap` row, so the whole path mirrors. Same commit.

Working controls: amounts already isolate themselves (`common/components/amount.tsx`, `<bdi dir="ltr">`, w3/479), and the narrow Accounts row's parent path (`accounts/index.tsx:416`) is plain text and reads root first. Mobile settled the rule in w21/743 and w21/927 (`isolateAccountPath`, `mobile/src/common/bidi.ts`): an account path reads root first in every app direction.

## Fix

Owned by `dashboard`. Lay both renderers out left to right, isolated from the page: `dir="ltr"` on `AccountName`'s visible flex row and on the Accounts segment row (each with `unicode-bidi: isolate`), still aligned to the reading start of a right-to-left cell. Keep each segment's own text first-strong, so a Persian segment such as `خوراک` reads correctly inside the left-to-right path, as mobile's `isolateAccountPath` does. Keep the truncation rule (the path gives way, the leaf stays whole), the wrap-after-colon rule, the prefix buttons, and the hidden full name.

## Definition of done

- At `?lang=fa`, Journal, the account register, Overview's account cards, Budget and Accounts draw `Liabilities:US:Chase:Slate` root first, left to right, with the leaf last, matching the account page heading. English is unchanged.
- An account with a Persian segment (`Expenses:Qa…:خوراک:رستوران` on a disposable ledger) reads root first in both languages.
- In a right-to-left page the name still starts at the cell's reading edge, and a long path still truncates before the leaf.
- A rendered test of `AccountName` and `AccountPrefixNavigation` under `dir="rtl"` pins the left-to-right isolation. It fails on current `main`. Dashboard gates pass.
