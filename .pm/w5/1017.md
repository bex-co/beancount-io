# Keep generated feed files outside copied plugin package resources

**Major · cli · 45–60m · A1 · worker1.** A fresh `price export` puts its
generated feed inside a local plugin package named `prices`. A plugin that
enumerates its package's ordinary `.beancount` resources then reads an extra
file. The export succeeds, both source and snapshot pass `check`, but the
snapshot changes a derived quote from 900 to 950 USD and net worth from
1,800 to 1,850 USD. Every copied source file retains its original bytes.
No product fix implemented.

Environment: 2026-10-24, clean main `afde374b447e3db7cff7a27723bf1e04fcacc957`;
CLI source is byte-identical to frozen
`ee4b7702516da4535bb3b478e2efe9913b09481b`. Checkout `bea 0.3.1`, frontend
Python 3.13.3, managed Python 3.12.10 / Beancount 3.2.3 / Beanquery 0.2.0,
macOS 26.5.1 arm64. Fresh bounded subprocesses, closed stdin/no TTY, isolated
absolute config/cache paths and notifier disabled. Only inspected local
plugins and synthetic bookkeeping. A validated **synthetic offline cache**
supplies the managed quote; no server or HTTP request is used or evaluated.

## Cause and scoped repair

`cli/src/bea_engine/managed_load.py:1863–1871` allocates the feed directory
and filenames against **only ledger-copy destinations**. Copied plugin
packages are discovered later by `_export_plugin_modules` at `:1885`.
That helper preserves package file locations (`:2246–2258`), using
`_package_files` (`:2268–2309`) to carry their resources.
`_free_feed_directory` (`:2449–2460`) checks only whether a candidate
directory's name equals a reserved file, and `_free_feed_path`
(`:2463–2482`) checks individual file names. Neither reserves an entire
copied package namespace. Thus both independently planned files are
distinct, pass the final name/identity guard at `:1898–1916`, and are
successfully written into the same package. Standard `importlib.resources`
then sees the generated feed as a new package resource.

Plan package destinations before generated feeds and keep generated
artifacts outside every copied package's resource namespace. For a root
package called `prices`, choose an available dedicated directory such as
`prices-managed/` and rewrite managed includes to it. Renaming only the
generated basename inside `prices/` is insufficient: the plugin enumerates
all `.beancount` resources. Preserve deterministic names, case/Unicode
collision handling, source files and existing pre-write refusals. Do not
change the plugin or suppress it to make reports agree. CLI-only repair;
no new dependencies or API surfaces.

Caller search finds one production `export_portable` caller, engine
`price_export` (`cli/src/bea_engine/main.py:856–881`); frontend
`cli/src/cli/commands/price.py:182–242` routes default output, `--output`
and `-o` through it. JSON and human export are exercised. Other helper
aliases, installed plugins, namespace packages and other operating systems
remain unverified.
