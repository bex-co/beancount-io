# Dashboard Activity and profile Recent Activity say "Committed to fedex" in English in every language (dashboard gap in w21/718)

**Severity:** minor (localization). **Owner:** `dashboard`. **Estimate:** 30–40 minutes including tests. **A2/A3:** the `/ledger` home is the first page a signed-in reader sees and a public profile is what a visitor from the gallery sees; in German, Japanese, Persian or Russian every activity row is the one English line on the page. **Found by:** `/qa-find-bugs-dashboard` (`dashboard-qa` routine) on 2026-11-26 against `https://beancount.io`, production entry chunk `main-BBmi61Hs.js`. QA-owned headless Chromium 158, fresh isolated contexts, 1440×1000, language chosen with `?lang=`. Reproduced signed out on the public `open_ledger` profile and signed in on the QA owner's `/ledger` home. Read-only. Local HEAD `d5e0d2bdd`.

## Repro

Signed out, no account needed:

1. Open `/ledger/open_ledger?lang=de`.
2. **Letzte Aktivität** lists `Committed to fedex`, `Committed to h-and-r-block`, `Committed to h-and-r-block`, `Committed to rocket-lab`, `Committed to rocket-lab`, each over a German relative time (`vor 16 Tagen`). With `?lang=ja` the heading is `最近のアクティビティ` and the rows still read `Committed to fedex`; with `?lang=fa` the right-to-left page shows `Committed to fedex` over `۱۶ روز قبل`; with `?lang=ru`, `Committed to fedex` over `16 дней назад`.

Signed in, any account with a ledger commit:

3. Open `/ledger?lang=de`. Each **Aktivität** card is the ledger name, `· <author> · vor 23 Minuten`, then `Committed to mcp-agent-eval`, then `Versionsverlauf` and the commit message. Same in Persian.

Expected: the line is in the page's language, as the mobile app says it since w21/718 (German `Commit in mcp-agent-eval`, `Hauptbuch mcp-agent-eval erstellt`), with the ledger name isolated left-to-right in Persian.

## Cause

- The server writes these lines in English: `backend-cluster/backend-v2/src/features/gitea/feed/service/activity-transformer.ts:84-90` (`titleTemplates`, `getFeed` items' `title`) and `features/gitea/user-profile/service/user-profile-service.ts:538-556` (`generateActivityContent`, the profile's `activities[].content`).
- The dashboard prints them as they come: the Activity card's subtitle `{item.title}` (`dashboard/src/features/ledger-list/components/feed-card.tsx:78`, and `:59` when a row has no ledger destination) and the profile's `{activity.content}` (`features/user-profile/components/profile-activity.tsx:108`, `:111`).
- w21/718 fixed this only in the mobile app, on the client: `mobile/src/screens/home-screen/components/feed-logic.ts:159-183` (`feedRowTitle`) maps `Committed to X` and `Created repository X` to `feedCommittedTo` / `feedCreatedLedger`. The dashboard has no counterpart. The server templates, and the GraphQL, REST and MCP reads that return them, were deliberately left unchanged.

## Fix

- Profile: `profile-activity.tsx` already has the activity's `type` and `repoName` (it uses `type === "create_repo"` for the icon). Render `commit_repo` and `create_repo` from dashboard messages (for example `userProfile.activityCommitted` "Committed to {ledger}" and `userProfile.activityCreatedLedger` "Created ledger {ledger}") with the ledger name in a `<bdi>`; keep the server's `content` for any other type.
- Activity card: the feed item has no type, so map the server's `Committed to X` / `Created repository X` titles to the same kind of messages for `LEDGER_RSS` items, as mobile does, and keep any other title as sent. Do not import from `mobile/`; write the dashboard's own helper.
- Real translations in all 15 catalogs (`yarn i18n:prepare`); English output is unchanged apart from any wording you settle on.
- Tests: the profile list and an Activity card render `Commit in fedex` (German) and keep `Committed to fedex` (English); an unknown title or type is shown unchanged. The German assertions fail on the current code.

## Definition of done

On production, `/ledger/open_ledger?lang=de` lists `Commit in fedex` (or the chosen German wording) under **Letzte Aktivität**, and a signed-in `/ledger?lang=de` shows its Activity cards' subtitle in German; Persian shows the ledger name isolated in a right-to-left sentence. English is unchanged. Dashboard gates pass.

## Blast radius

Two dashboard surfaces: the `/ledger` home's Activity feed and every user profile's Recent Activity (`/ledger/<user>`). What's new (CHANGELOG) items already arrive translated from the CMS and are not affected. The rarer Gitea titles (pull requests, branches, tags, mirror syncs) stay English, as on mobile.

## Dedupe

Searched `.pm/**`, including `done/` and `blocked/`, for `Committed to`, `titleTemplates`, `feedRowTitle` and profile activity. w21/718 (done) is the mobile fix and names the dashboard nowhere; w21/599, w21/715 and w3/460 changed which activities appear and what they carry, not their language. `main` still renders the server text on both dashboard surfaces, so this is not deployment lag.

**Unverified:** the 390px layout; other Gitea activity types (none in the sampled feeds).
