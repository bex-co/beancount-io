## Empty resource directories disappear even when every regular file copies

A controlled local plugin enumerates optional JSON rules with
`importlib.resources.files(__package__).joinpath('rules').iterdir()`.
The directory exists and has no active rules. Source check passes and the
source holds the expected **1000 USD Cash / −1000 USD Equity**. The selected
package is an ordinary local package with `__init__.py`.

`bea price export` reports success and copies the ledger and Python module.
The empty `rules/` directory has no entry in the plan, so it is not created.
Fresh snapshot check exits 1 with `FileNotFoundError` naming that directory.
The source remains valid and its files/directories remain unchanged by CLI
operations. The failure is loadability of the exported package.

The same omission affects a helper package: an entry plugin imports its
`run` function from the package, which enumerates nested `data/rules/`.
Both empty directories disappear. A non-JSON `README.txt` inside the same
directory is the working control: no JSON rule becomes active, but copying
the marker creates the parents and the exported ledger checks successfully
with the source-identical full native directive graph. This isolates absent
directories from dependency discovery or plugin behavior.

## Standalone reproduction and controls

Put checkout `bea` on PATH and use a fresh absolute directory per run.
`helper = True` selects the imported helper package with nested resources.
`marker = True` adds the ignored README; `human_export = True` exercises
human success reporting. The inspected Python code only scans its synthetic
local resource directory and returns the entries unchanged.

The three real CLI calls capture argv/cwd/overrides, separate streams,
exit/duration, source file hashes and directory membership, and the exported
tree. Offline mode prevents any managed-feed fetch. Interpreter bytecode
caches are excluded; source data and directory membership stay fixed.

```python
import hashlib,json,os,pathlib,subprocess,time
case = pathlib.Path('/abs/empty-resource-directory-case')
helper = False  # True: the plugin calls a helper package with nested resources
marker = False  # True: a non-JSON README is the working control
human_export = False
case.mkdir(parents=True,exist_ok=False)
source=case/'source';source.mkdir()
package=source/'qa_rule_config';package.mkdir()
relative='data/rules' if helper else 'rules'
resources=package/relative;resources.mkdir(parents=True)
(package/'__init__.py').write_text('''import json
from importlib.resources import files
__plugins__=('run',)
def run(entries,options):
 rules=files(__package__).joinpath('RESOURCE_DIRECTORY')
 active=[p for p in rules.iterdir() if p.name.endswith('.json')]
 for p in active:json.loads(p.read_text())
 return entries,[]
'''.replace('RESOURCE_DIRECTORY',relative))
if marker:(resources/'README.txt').write_text('No active JSON rules.\n')
if helper:
    (source/'qa_rule_entry.py').write_text('from qa_rule_config import run\n__plugins__=("run",)\n')
main=source/'main.bean'
main.write_text('''option "operating_currency" "USD"
option "insert_pythonpath" "TRUE"
plugin "PLUGIN_NAME"
2024-01-01 open Assets:Cash USD
2024-01-01 open Equity:Opening USD
2024-01-02 * "Capital"
  Assets:Cash 1000.00 USD
  Equity:Opening -1000.00 USD
'''.replace('PLUGIN_NAME','qa_rule_entry' if helper else 'qa_rule_config'))
snapshot=case/'snapshot'
env=os.environ.copy()
for key in ('BEA_FILE','BEA_TOKEN','BEANCOUNT_LOAD_CACHE_FILENAME','BEA_ENGINE_PYTHON','BEA_ENGINE_DIR'):
    env.pop(key,None)
overrides=dict(BEA_CONFIG_DIR=str(case/'config'),XDG_CACHE_HOME=str(case/'cache'),BEA_NO_UPDATE_NOTIFIER='1')
env.update(overrides)
def tree(root):
    return {str(p.relative_to(root)):hashlib.sha256(p.read_bytes()).hexdigest() if p.is_file() else None
        for p in root.rglob('*') if '__pycache__' not in p.parts}
fixed=tree(source)
def run(tag,args,file=main):
    argv=['bea',*([] if tag=='export' and human_export else ['--json']),
        '--no-input','--offline','-f',str(file),*map(str,args)]
    before=dict(source=tree(source),snapshot=tree(snapshot));started=time.monotonic()
    r=subprocess.run(argv,cwd=case,env=env,stdin=subprocess.DEVNULL,capture_output=True,text=True,timeout=25)
    assert tree(source)==fixed and resources.is_dir()
    if tag!='export':assert tree(snapshot)==before['snapshot']
    print(json.dumps(dict(tag=tag,args=argv,cwd=str(case),env=overrides,stdin_mode='DEVNULL',tty=False,
        exit=r.returncode,stdout=r.stdout,stderr=r.stderr,duration=round(time.monotonic()-started,3),
        before=before,after=dict(source=tree(source),snapshot=tree(snapshot)),source_preserved=True)),flush=True)
run('source-check',['check'])
run('export',['price','export','--output',snapshot])
run('snapshot-check',['check'],file=snapshot/'main.bean')
```

## Cause, consumer path, and repair target

`_package_files`, `cli/src/bea_engine/managed_load.py:2290–2309`, walks the
package and inspects its subdirectories, but appends only file names to its
`list[Path]`. A visited directory with no descendant file is never represented.
`_export_plugin_modules` at `:2246–2258` maps those files to the export's
attachment plan. The staging loop at `:2044–2046` creates parents for planned
files through `_stage_export` (`:2494`); no file requires the empty resource
directory as a parent, so the directory is absent from the copy.

This path is shared by selected plugin packages and local helper packages
found by `_sibling_imports`. Both are exercised. The frontend `_export`
(`cli/src/cli/commands/price.py:182`) forwards to the `price-export` helper
(`bea_engine/main.py:856`) and `managed_load.export_portable`; JSON and human
success output expose the same incomplete tree. Independent native check is
the consumer that proves the missing package structure, beyond file counts.

Represent ordinary required package directories in the export plan, including
empty descendants. Integrate their creation with the existing preflight,
collision handling and atomic cleanup. A successful snapshot must load the
same package and preserve its native accounting; if its package tree cannot
travel faithfully, refuse before promising a portable copy. Keep source bytes,
marker/helper controls, existing regular-file resource copying and bytecode
exclusions. No plugin rewrite, new dependency or API change is needed.
The [documented package-copy contract](../../cli/docs/USAGE.md#managed-price-includes)
says the package travels whole so its plugin lines still resolve.

## Original report and shipped resolution (retained)

# price export copies a local plugin package's Python files but drops its required package resources, reporting success for a snapshot that cannot load

**Trivial · cli · 15–25m · A1.** Real CLI QA, 2026-10-18, HEAD `4ef6ab16f`, checkout `bea 0.3.1`, macOS 26.5.1, managed engine Python 3.12. Twice from pristine synthetic books with isolated config/cache, stdin closed and no TTY. The plugin is controlled local code; no network, credentials or installation changes. No product fix implemented.

Create `books/main.bean`:

```beancount
option "operating_currency" "USD"
option "insert_pythonpath" "TRUE"
plugin "pkgplug"
2026-01-01 open Assets:Cash USD
```

Create `books/pkgplug/settings.json` containing `{"label":"Synthetic"}`, and `books/pkgplug/__init__.py`:

```python
import json
from importlib.resources import files

CONFIG = json.loads(files(__package__).joinpath("settings.json").read_text())
__plugins__ = ["run"]

def run(entries, options):
    return entries, []
```

```sh
bea --file /abs/books/main.bean check
bea --json --file /abs/books/main.bean price export -o /abs/snapshot
bea --file /abs/snapshot/main.bean check
```

Actual: the source check exits 0. Export exits 0 and lists exactly `snapshot/main.bean` and `snapshot/pkgplug/__init__.py`. It omits `pkgplug/settings.json`. A fresh check of the snapshot exits 1 with `FileNotFoundError ... snapshot/pkgplug/settings.json`. The original settings file retains its bytes. This is a required resource inside the selected package, not an unrelated file beside the ledger.

Control: inline `CONFIG = {"label":"Synthetic"}` in the same package, leaving the unrelated JSON beside it. Source check, export and fresh snapshot check all exit 0.

Expected: the copied package remains loadable, including its required ordinary package resources, or the export refuses to promise a portable copy. USAGE around `:1907` says a local plugin module or package is copied so the snapshot's plugin lines still resolve. The current Python-only copy leaves a partial package while reporting success.

Cause: `_export_plugin_modules` (`cli/src/bea_engine/managed_load.py:1891`) enumerates a selected package with `package.rglob("*.py")` at `:1911`. Resource files never enter the export plan, so its collision, containment and missing-file checks cannot see them. `_sibling_imports` discovers Python modules, not non-module files read through the package resource API. The same omission affects local helper packages imported by the plugin.

Fix: carry ordinary resources belonging to the selected local package through the existing export plan, preserving containment, collision and permission safeguards and excluding bytecode caches. Reject resources that cannot travel safely instead of silently dropping required package contents. Avoid indiscriminately copying unrelated root-ledger files.

Dedupe: searched all board states for plugin/package resources, data files, `settings.json`, non-Python files and `importlib.resources`; no open coverage. Completed w5/094 added local plugin copies and w5/327 added sibling-module discovery, both Python-module cases. The latter's statement that a package is copied whole is overbroad for resources. This is independent of the planned-name collision in w5/867.

Acceptance: the fixture exports a loadable package with its JSON resource and passes a fresh check; the inlined control stays valid. Include a helper-package resource case and preserve rejection of paths outside the permitted export tree.
