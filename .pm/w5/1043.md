# Skip unresolved-price reductions in partial capital-gains reports

**Minor · cli · 20–30m · A1 · worker1.** One unfinished costed sale whose
price is `@ USD` or `@@ USD` makes `report capital-gains --allow-errors`
crash at exit1. It multiplies a Decimal quantity by Beancount's MISSING
sentinel, instead of returning the already completed sale's25USD gain.
Human output fails too. The source intentionally has one native
InterpolationError; strict refusal is correct. The defect is the explicit
partial-read path, which cannot return otherwise available known gains.
No product fix implemented.
