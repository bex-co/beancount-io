## Objective

Keep the supported Windows installation behavior reproducible through a focused deterministic job.

## Context

- The existing skills workflow runs on Ubuntu; CLI Windows release checks do not exercise the customer-skills installer.
- Paid agent calls belong to explicit rehearsals, not ordinary CI.

## Steps

1. Expose a focused installer/lifecycle test entry point using existing helpers, without running unrelated platform-specific accounting recipes.
2. Add a Windows job exercising documented PowerShell setup, repeated install, source update visibility, verification, conflicts, and uninstall with spaces/Unicode paths.
3. Exercise allowed-link and denied/mid-install failure behavior, keeping the current Ubuntu skills gate and assertions intact.

## Files

## Out of scope
