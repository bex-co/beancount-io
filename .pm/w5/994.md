A native-valid trade has one inferred compound stock cost and a second,
fully specified costed asset posting. The reply and import comparison leave
the inferred part unresolved. Two purchases at different cash prices then
get the same generated ID, and the second is skipped even with
`--duplicates include`. The checked book holds **2 HOOL / 979.50 USD cash**
instead of **4 HOOL / 949.00 USD**. Its other holding is also 1 instead of 2.
Both books' cost net worth is 1000 USD, so a grand total and `check` do not
reveal the omitted trade. A bank-ID correction is falsely skipped too, and
single-add JSON fails unchanged bulk replay.

Expected behavior follows the native booking result: first trade's 20.50 USD
cash pays 10 USD for OTHER and **10.50 USD for 2 HOOL**, effective cost
**5.25 USD each**. The second pays 30.50, so HOOL costs **10.25 each**.
These are different acquisitions, not exact duplicates. The two native
reference ledgers in the script validate those weights independently.

Put the checkout's bea on PATH, replace the directory with a fresh absolute
one, and run twice in pristine directories. Modes and journeys below provide
the working controls, missing-total variant and JSON replay. The inspected
local importer only parses its controlled trade file and optionally adds a
synthetic bank reference; no I/O beyond that source, service, dependency or
feature installation is involved. Children use isolated config/cache, closed
stdin/no TTY, bounded timeouts, separate streams and source/input hashes.
HOME, global CLI state and real ledgers are untouched.

```python
import hashlib,json,os,pathlib,subprocess
case = pathlib.Path('/abs/mixed-inferred-cost-case')
mode = 'cost'  # fee, explicit
part = 'per'  # total
journey = 'generated'  # bank, replay
human_second = False
case.mkdir(parents=True)
base = '''option "operating_currency" "USD"
2024-01-01 open Assets:Broker HOOL
2024-01-01 open Assets:Other OTHER
2024-01-01 open Assets:Cash USD
2024-01-01 open Equity:Opening USD
2024-01-01 open Expenses:Fee USD
2024-01-01 * "Capital"
  Assets:Cash 1000.00 USD
  Equity:Opening -1000.00 USD
'''
ledger,copy = case/'main.bean',case/'copy.bean'
ledger.write_text(base);copy.write_text(base)
def postings(index):
    if mode=='explicit':
        cost = ('{'+str(5 if index==0 else 10)+' # 0.50 USD}' if part=='per' else
                '{5 # '+('0.50' if index==0 else '10.50')+' USD}')
    else:
        cost = '{# 0.50 USD}' if part=='per' else '{5 # USD}'
    other = 'Expenses:Fee 10.00 USD' if mode=='fee' else 'Assets:Other 1 OTHER {10 USD}'
    return ['Assets:Broker 2 HOOL '+cost,other,
            'Assets:Cash '+('-20.50' if index==0 else '-30.50')+' USD']
statements = [case/'a.trade',case/'b.trade']
for i,path in enumerate(statements):
    path.write_text('2024-01-02 * "Trade"\n'+''.join('  '+s+'\n' for s in postings(i)))
(case/'first-reference.bean').write_text(base+statements[0].read_text())
(case/'both-reference.bean').write_text(base+''.join(p.read_text() for p in statements))
config = case/'importer.py'
config.write_text("from pathlib import Path\nfrom beancount.parser import parser\nclass Rows:\n"
    " def identify(self,file):return str(file).endswith('.trade')\n"
    " def account(self,file):return 'Assets:Broker'\n"
    " def extract(self,file,existing_entries=None):\n"
    "  es,errs,_=parser.parse_string(Path(str(file)).read_text());assert not errs,errs\n"
    +("  for e in es:e.meta['bank_id']='trade-001'\n" if journey=='bank' else '')
    +"  return es\nCONFIG=[Rows()]\n")
inputs = {p:p.read_bytes() for p in (*statements,config)}
env = os.environ.copy()
for key in ('BEA_FILE','BEA_TOKEN','BEANCOUNT_LOAD_CACHE_FILENAME'):
    env.pop(key,None)
env.update(BEA_CONFIG_DIR=str(case/'config'),XDG_CACHE_HOME=str(case/'cache'),
           BEA_NO_UPDATE_NOTIFIER='1')
def run(tag,args,file=ledger,human=False):
    before = file.read_bytes()
    cmd = ['bea',*([] if human else ['--json']),'--no-input','-f',str(file),*map(str,args)]
    r = subprocess.run(cmd,cwd=case,env=env,stdin=subprocess.DEVNULL,
                       capture_output=True,text=True,timeout=25)
    print(json.dumps(dict(tag=tag,args=cmd,exit=r.returncode,stdout=r.stdout,stderr=r.stderr,
                          source_preserved=file.read_bytes()==before,
                          before_sha256=hashlib.sha256(before).hexdigest(),
                          after_sha256=hashlib.sha256(file.read_bytes()).hexdigest(),
                          inputs_preserved=all(p.read_bytes()==b for p,b in inputs.items()))),flush=True)
    return r
facts = ['query','SELECT account,sum(number) GROUP BY account ORDER BY account']
run('baseline',['check'])
if journey=='replay':
    args = ['add','transaction','--date','2024-01-02','--narration','Trade']
    for text in postings(0):args+=['--posting',text]
    first = run('single-add',args)
    rows = case/'rows.json'
    rows.write_text(json.dumps([json.loads(first.stdout)['data']['directive']]))
    run('replay',['add','transactions','--from',rows],copy,human_second)
    run('source-holdings',facts)
    run('copy-holdings',facts,copy)
    run('source-check',['check'])
    run('copy-check',['check'],copy)
else:
    run('first',['import',statements[0],'--config',config,'--apply'])
    run('repeat-first',['import',statements[0],'--config',config,'--apply'])
    args = ['import',statements[1],'--config',config]
    run('second-preview',args)
    run('second',args+['--apply']+(['--duplicates','include'] if journey=='generated' else []),human=human_second)
    run('holdings',facts)
    run('check',['check'])
```
