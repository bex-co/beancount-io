# Preserve compact header text when changing a transaction flag

**Major · cli · 20–40m · A1 · worker1.** A flag-only `bea update`
silently deletes the payee/narration immediately adjacent to the old flag.
The valid header `2026-01-02 !"Merchant""Coffee" #written ^receipt`
becomes `2026-01-02 * #written ^receipt`: both strings disappear.
Apply exits **0**, reports **written1**, and the saved ledger still checks
valid. This reproduces through single and JSON-batch updates. The preview
diff does expose the deletion; the request and batch change summary name
only the flag. An agent clearing the review queue must retain the entry's
description. No product fix implemented.
