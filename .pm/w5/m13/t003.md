## Objective

Keep the supported Windows installation behavior reproducible through a focused deterministic job.

## Context

- The existing skills workflow runs on Ubuntu; CLI Windows release checks do not exercise the customer-skills installer.
- Paid agent calls belong to explicit rehearsals, not ordinary CI.
- Found by t001 on a native Windows checkout (`core.symlinks=false`): `ci-check.py` stops at `.claude/skills must be a relative symlink` because the shared link is checked out as a plain file; `check_checkout_paths` reports a spurious `importer-graduation.md:52` failure (backslash vs. slash path set); `test_ci_check.py` has 2 failures and 2 errors on Windows at HEAD (`TestSkillTrees` link checks, plus `TestFindBea`/`TestOracleAndIsolation` needing `bea` on `PATH`); `test_beancount_skills.py` stops in setup without `bea`. The job must provision `bea` and symlink permission, and handle the checked-out link without weakening the Ubuntu assertions.
- Found by t002: the installer test module has 17 pre-existing failures on native Windows across its non-`bea` lifecycle classes (`os.readlink` returns `\\?\`-prefixed paths that `describe_conflict`/`destination_problem` also print to users; expected strings use `/`; `Path.home()` is not redirected for plugin-cache detection; `TestGitUpdatePath` old-layout upgrade exits 49), and `TestBeaRecipes.setUpClass` calls `sys.exit` when `bea` is missing, which stops the whole module. The new `TestLinkFailures` class (8 tests) already passes on Windows; run it with `python -m unittest test_beancount_skills.TestLinkFailures` from `scripts/skills/`.

## Steps

1. Expose a focused installer/lifecycle test entry point using existing helpers, without running unrelated platform-specific accounting recipes.
2. Add a Windows job exercising documented PowerShell setup, repeated install, source update visibility, verification, conflicts, and uninstall with spaces/Unicode paths.
3. Exercise allowed-link and denied/mid-install failure behavior, keeping the current Ubuntu skills gate and assertions intact.

## Out of scope
