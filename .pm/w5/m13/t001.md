## Objective

Establish the actual native Windows installation path and publish exact PowerShell commands with supported symlink prerequisites.

## Context

- docs/skills/installation.md and first-query.md currently state that Windows is not covered.
- The installer creates directory symlinks; non-elevated Windows linking depends on the host's allowed symlink capability.

## Steps

1. Use a native Windows workspace to record Python/Git/shell versions and reproduce the existing install with an isolated destination.
2. Check allowed and denied link creation, and capture the actual outcome without changing system policy.
3. Write the PowerShell clone, install, verify, update, conflict-recovery, and removal steps with correctly quoted paths and explicit prerequisites.

## Files

- `docs/skills/installation.md`
- `docs/skills/first-query.md`
- `docs/skills/windows-rehearsal.md (new evidence)`

## Acceptance criteria

- [ ] The instructions are PowerShell commands verified on a named native Windows environment.
- [ ] Symlink prerequisites and any unsupported configuration are explicit; WSL is not claimed as native evidence.
- [ ] The baseline distinguishes confirmed failures from hypotheses and preserves existing user files.

## Out of scope

- Enabling Developer Mode or administrator privileges automatically, new installation modes, or Linux expansion.
