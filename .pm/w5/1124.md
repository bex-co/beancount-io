# Keep ignored-budget diagnostics on stderr when exporting CSV

**Minor · cli · 20–35m · A1/A2 · worker1.** `report budget --format csv`
silently drops the warning that a malformed-interval budget was ignored.
Text warns and JSON carries `budget_errors`; CSV stdout and file exports
succeed with empty stderr and no error information. Agents consuming that
export cannot distinguish an absent budget from one the CLI rejected.
No product fix implemented.

Environment: 2026-11-07, bea 0.3.1, Python 3.12.10, macOS 26.5.1 arm64;
checkout CLI source unchanged from `74a0b8cbe`, board-only HEAD `81ae1d449`.
Fresh 25s-bounded subprocesses, closed stdin/no TTY, offline, isolated child
config/cache, notifier off, no inherited `BEA_FILE`/`BEA_TOKEN`, HOME unchanged.

## Reproduce

Create a synthetic `main.bean` in a fresh disposable directory:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Cash USD
2026-01-01 open Expenses:Food USD
2026-01-02 * "Food"
  Expenses:Food 10.00 USD
  Assets:Cash -10.00 USD
2026-01-01 custom "budget" Expenses:Food "fortnightly-ish" 100.00 USD
```

Run from that directory with absolute executable/file paths and the isolated
environment above:

```sh
bea --json --no-input --offline --file /absolute/main.bean check
bea --json --no-input --offline --file /absolute/main.bean report budget --time 2026-01
bea --no-input --offline --file /absolute/main.bean report budget --time 2026-01
bea --no-input --offline --file /absolute/main.bean report budget --time 2026-01 --format csv
bea --no-input --offline --file /absolute/main.bean report budget --time 2026-01 --output /absolute/fresh-budget.csv
```

All exit 0. Check is valid. JSON names
`budget_errors: ["Invalid interval for budget entry"]`; text stderr prints
`Budget directive ignored: Invalid interval for budget entry`. Both CSV paths
have **empty stderr** and represent Food as unbudgeted with empty budget and
variance. File output correctly leaves stdout empty. The ledger stays
byte-identical; only the requested CSV export is written.

Expected: CSV keeps its valid table/file and exit behavior, and stderr carries
the same ignored-budget warning. `cli/docs/USAGE.md`'s Budgets contract puts
invalid-interval diagnostics on stderr; Reports as CSV puts advisory notes
there while keeping CSV clean. No warning is needed for a valid budget.

Repeated twice from pristine fixtures, with an additional independent valid
Travel budget: text and JSON retain the diagnostic; both CSV destinations
omit it. The minimal public fixture above was also rerun. This uses a parser
error it already handles, so it does not require [1122](done/1122.md)'s fix.

## Cause and repair

`cli/src/cli/commands/report.py::budget:864–866` returns via `_emit_csv`
before the `budget_errors` warning loop (:873–874). `_emit_csv` (:386–396)
calls `_heading(csv=True)`, whose shared advisories do not include budget
errors. `cli/src/cli/report_csv.py::_budget` serializes only the ordinary
row columns, appropriately leaving diagnostics out of the table.

Emit ignored-budget diagnostics on the CSV rendering path, reusing the
existing warning wording/mechanism. Keep CSV/file stdout clean, warn once
per diagnostic, preserve JSON's `budget_errors` without duplicating raw text
in its streams, and preserve text warnings. Both CSV destinations share
`_emit_csv`; other report commands use that helper too, so avoid assuming
they have a `budget_errors` key. No engine/API/dependency change needed.

Acceptance: invalid-interval text/CSV stdout/CSV file journeys all retain
the stderr warning; JSON retains its structured error; valid budgets produce
no warning. Keep correct rows, exit codes, export file behavior and untouched
ledger bytes. Add meaningful CLI coverage and run `make check-all` in `cli/`.

stderr and diagnostics, and reviewed 42 open/blocked milestone scopes plus
