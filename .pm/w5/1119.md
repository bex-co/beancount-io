# Bound root discovery and refuse incomplete searches

**Major · cli · 45–60m · A1/A2.** Automatic root discovery has two budget
failures. Unrelated files can consume unbounded filesystem work, stalling a
one-row import. When 64 qualifying candidates consume the stated limit,
the scan silently looks complete and can miss the actual root: a successful
leaf write then leaves the whole ledger invalid. Bound the work and signal
incomplete discovery before a write. No product fix implemented; worker1.

Real local CLI QA, 2026-11-01: checkout `bea 0.3.1`, frozen source
`21ae0fb51c2ccc15d4bab3f74e40725921dd0d83` and fresh current-main source
`66508069e946991b492d83392e40e01bba071f40`. macOS 26.5.1 arm64;
current frontend and existing managed engine Python 3.12.10, Beancount 3.2.3,
Beangulp 0.2.0. Later main `cd9d7f3ba` changes setup-module code;
root discovery, importer and launch/protocol files remain byte-identical.
Every child has isolated config/cache, notifier disabled, stdin DEVNULL,
no TTY, separate captured streams and a 25-second ordinary-command limit.
No cloud account, real ledger, dependency change or live Ask was involved.

## Candidate exhaustion accepts a false balance

Fresh current-main reproduction at
`bd8a1c565347ceef9e306627334661100b47357a`, the same existing runtime and
isolated environment above. Eight pristine journeys repeat four conditions
twice; the exact public recipe below was then replayed in four more fresh
workspaces. **Three unsafe writes, nine safe controls.** The scan/root
producer is unchanged from the initial performance finding.

Run this recipe with the tested checkout's `bea` on PATH and a new absolute
`base`. Each workspace is a real Git repository, so discovery cannot reach
other QA files or the caller's actual neighbors. All noise ledgers are valid;
their ordinary `*` transaction flags admit them through the scanner's cheap
glob-character prefilter, although none includes `leaf.bean`. The actual
root sorts after them as `zz-main.bean`. Its fresh Equity open makes it a
defining root rather than a forecast overlay.

```python
import hashlib, json, os, pathlib, subprocess
base = pathlib.Path('/abs/root-budget-exhaustion-repro')
base.mkdir(parents=True)
for neighbors, explicit in ((0, False), (63, False), (64, False), (64, True)):
    case = base / (str(neighbors) + ('-explicit' if explicit else '-auto'))
    case.mkdir()
    subprocess.run(['git', 'init', '--quiet'], cwd=case, check=True,
                   stdin=subprocess.DEVNULL, capture_output=True)
    leaf, root = case/'leaf.bean', case/'zz-main.bean'
    leaf.write_text('option "operating_currency" "USD"\n'
                    '2024-01-01 open Assets:Cash USD\n'
                    '2024-01-01 open Expenses:Food USD\n', encoding='utf-8')
    root.write_text('option "operating_currency" "USD"\n'
                    'include "leaf.bean"\n'
                    '2024-01-01 open Equity:Opening USD\n'
                    '2024-01-02 * "Capital"\n'
                    '  Assets:Cash 100 USD\n'
                    '  Equity:Opening -100 USD\n', encoding='utf-8')
    (case/'noise-common.bean').write_text(
        '2024-01-01 open Assets:Other USD\n'
        '2024-01-01 open Equity:Other USD\n', encoding='utf-8')
    for i in range(neighbors):
        (case/f'000-noise-{i:03d}.bean').write_text(
            'include "noise-common.bean"\n'
            '2024-01-02 * "Noise"\n'
            '  Assets:Other 1 USD\n'
            '  Equity:Other -1 USD\n', encoding='utf-8')
    env = os.environ.copy()
    for key in ('BEA_FILE', 'BEA_TOKEN', 'BEANCOUNT_LOAD_CACHE_FILENAME'):
        env.pop(key, None)
    env.update(BEA_CONFIG_DIR=str(case/'config'),
               XDG_CACHE_HOME=str(case/'cache'), BEA_NO_UPDATE_NOTIFIER='1')
    def run(tag, file, args):
        before = {p.name: hashlib.sha256(p.read_bytes()).hexdigest()
                  for p in (root, leaf)}
        cmd = ['bea', '--json', '--no-input', '--offline', '-f', str(file), *args]
        r = subprocess.run(cmd, cwd=case, env=env, stdin=subprocess.DEVNULL,
                           capture_output=True, text=True, timeout=25)
        print(json.dumps(dict(case=case.name, tag=tag, args=cmd,
                              exit=r.returncode, stdout=r.stdout, stderr=r.stderr,
                              before=before, after={
                                  p.name: hashlib.sha256(p.read_bytes()).hexdigest()
                                  for p in (root, leaf)})), flush=True)
    run('root-before', root, ['check'])
    args = ['add', 'balance', '--date', '2024-02-01', '--account', 'Assets:Cash',
            '--amount', '0 USD']
    if explicit:
        args += ['--into', 'leaf.bean']
    run('add', root if explicit else leaf, args)
    run('root-after', root, ['check'])
    run('leaf-after', leaf, ['check'])
```

The bounded search is documented in `cli/docs/USAGE.md:1233`: it opens at
most 64 candidates and routes a leaf write through its defining root. Keep
that bound. Exhaustion needs a distinct safe outcome; it cannot establish
that the requested file has no root. The zero/63-neighbor cases prove that
this same real root is recognized before the cap, and explicit-root selection
proves that whole-ledger validation correctly refuses the false assertion.

Cause: `_scan_includers` (`cli/src/bea_engine/ledger/write.py:1994`) executes
`return` when `opened >= _INCLUDER_CANDIDATES`. `_nearest_includers` (:2185)
receives an empty list, and `write_through_root` (:2240) treats `not tops`
as a complete standalone-file result. The add validates only the leaf, where
zero is true; its root's 100 USD is absent. The helper `add` entry point
(`src/bea_engine/main.py:286`) accepts that selection before constructing the
validated write. Existing callers listed below share this result; runtime
unsafe-write evidence is `add balance` only.

## Unbounded filesystem work

Run this standalone recipe with `bea` on PATH. Choose a new absolute
`base`; it must not exist. It creates two disposable Git workspaces so the
search cannot escape into the caller's real neighbors. The second has
4,096 unrelated, non-including ledgers; `neighbors` can be increased to
observe scaling. These are ordinary regular files, with no plugins.

```python
import hashlib, json, os, pathlib, subprocess, time
base = pathlib.Path('/abs/root-discovery-width-repro')
base.mkdir(parents=True)
for neighbors in (0, 4096):
    workspace = base / str(neighbors)
    books = workspace / 'books'
    books.mkdir(parents=True)
    subprocess.run(['git', 'init', '--quiet'], cwd=workspace, check=True,
                   stdin=subprocess.DEVNULL, capture_output=True)
    ledger = books / 'main.bean'
    ledger.write_text('option "operating_currency" "USD"\n'
                      '2024-01-01 open Assets:Cash USD\n'
                      '2024-01-01 open Expenses:Food USD\n'
                      '2024-01-01 open Equity:Opening USD\n'
                      '2024-01-02 * "Capital"\n'
                      '  Assets:Cash 100 USD\n'
                      '  Equity:Opening -100 USD\n', encoding='utf-8')
    bank = books / 'bank.csv'
    bank.write_text('Date,Description,Amount,Reference\n'
                    '2024-02-01,Coffee,-4.50,coffee-1\n', encoding='utf-8')
    for i in range(neighbors):
        noise = workspace / f'noise-{i:05d}'
        noise.mkdir()
        (noise / 'book.bean').write_text(
            '2024-01-01 open Assets:Spare USD\n', encoding='utf-8')
    env = os.environ.copy()
    for key in ('BEA_FILE', 'BEA_TOKEN', 'BEANCOUNT_LOAD_CACHE_FILENAME'):
        env.pop(key, None)
    env.update(BEA_CONFIG_DIR=str(books/'config'),
               XDG_CACHE_HOME=str(books/'cache'), BEA_NO_UPDATE_NOTIFIER='1')
    base_args = ['bea', '--json', '--no-input', '--offline', '-f', str(ledger)]
    imp = ['import', str(bank), '--csv',
           'date=Date,narration=Description,amount=Amount,id=Reference',
           '--account', 'Assets:Cash', '--default-account', 'Expenses:Food']
    def run(tag, args):
        before = ledger.read_bytes()
        started = time.monotonic()
        try:
            p = subprocess.run(base_args + args, cwd=books, env=env,
                               stdin=subprocess.DEVNULL, capture_output=True,
                               text=True, timeout=25)
            out = dict(exit=p.returncode, stdout=p.stdout, stderr=p.stderr)
        except subprocess.TimeoutExpired as e:
            out = dict(exit=None, timed_out=True,
                       stdout=str(e.stdout or ''), stderr=str(e.stderr or ''))
        out.update(tag=tag, neighbors=neighbors,
                   seconds=round(time.monotonic()-started, 3),
                   before=hashlib.sha256(before).hexdigest(),
                   after=hashlib.sha256(ledger.read_bytes()).hexdigest())
        print(json.dumps(out), flush=True)
    run('ordinary-preview', imp)
    run('explicit-root-preview', imp + ['--into', 'main.bean'])
    run('explicit-root-apply', imp + ['--into', 'main.bean', '--apply'])
    run('check-after', ['check'])
```

## Cause and repair

`cli/src/bea_engine/ledger/write.py:1963` `_scan_includers` eagerly lists
up to four ancestors and their immediate child directories, then sorts and
examines every directory's entries. It stats and reads each regular ledger
before testing the text for a relevant include. `_INCLUDER_CANDIDATES = 64`
at :1934 is checked before a candidate, but `opened += 1` occurs only
**after** the include/name/glob prefilter. Arbitrarily many non-including
files and non-ledger entries therefore consume unbounded work.
`_nearest_includers` (:2174) consumes the scan to completion.

The frontend import command (`src/cli/commands/import_.py:1085`) calls
helper `root` before reading remembered mappings, and the engine import
uses root routing too. An explicit `--into` skips discovery in both paths,
which explains the control. The helper's `root` result is the ordinary
`{root, into, note}` envelope; the delay precedes that result, with no
prompt or malformed-output issue.

Bound **total** enumeration/stat/read work and avoid repeated unnecessary
scans. If discovery exhausts a budget before it can establish the governing
root safely, return an explicit incomplete-search failure before any write.
For the exercised add/import surfaces, name the root and `--into` as the
working explicit-selection recipe. Do not silently treat an incomplete scan as proof the named file is
a standalone root: that would restore invalid leaf writes. Preserve nearest
defining-root selection, pass-through includes, overlay exclusion, true
independent-root refusal, uppercase suffixes and case/Unicode spellings.
No dependency or backend/API change is needed.

Caller search: engine `add`, `update`, `root`, `append` and `import` in
`src/bea_engine/main.py` (:286, :326, :372, :414, :637), plus
`defining_root`, read hints and `root_ledger_hints`. Runtime slowdown evidence
is CSV preview/apply and helper root; other command slowdowns are source-traced.
Seven fresh real-CLI controls (21 commands, 14 native loads) still pass:
three-level leaf, `../` sibling, case-variant refusal, nearby FIFO, and roots
named `main.BEAN`, `main.Beancount`, `main.BeAn`.
