# Document converting an existing Windows clone to real symlinks

**Minor · repo docs · 15–20m · A3 · worker1.** Found by the adoption pass of
[w5/m13/t005](./m13/done/t005.md), 2026-10-28.

`skills/AGENTS.md` now tells Windows contributors that `ci-check.py` and
`check-agent-guidance.py` need a checkout with real symlinks. It covers
only a fresh `git -c core.symlinks=true clone`. A contributor who already
has a `core.symlinks=false` clone, where `.claude/skills` is a text file,
has no documented way to convert it in place.

**Fix:** document the in-place conversion (set `core.symlinks=true` for the
repo, then check out `.claude/skills` again) after rehearsing it on Windows
with symlink permission. Never commit the text-file form.
