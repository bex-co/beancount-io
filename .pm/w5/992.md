# Use authored price facts across filtered and transformed views

**Minor · cli · 45–60m · A1 · worker1.** Real local CLI QA, 2026-10-22,
checkout `bea 0.3.1` at `c9c3b645504c913a2c60f08c981632dcba2e55c3`, macOS
26.5.1 arm64, frontend Python 3.13.3, managed Python 3.12.10 / Beancount 3.2.3.
Completed 938's `d1b5c6474` is included. No product fix implemented.

Price duplicate/conflict guards read the plugin view instead of the authored
quote facts in the files. A local filter hides an existing EUR 1.25 USD quote:
`add price` then appends that exact quote again, and writes a different
1.30 USD quote without the documented exit-4 conflict or `--force`. Native
import also appends the same existing price on every apply. An inverse-only
view instead falsely skips a new USD 0.80 EUR quote as already authored,
although the file contains only the forward EUR 1.25 USD directive.

[USAGE's price contract](../../cli/docs/USAGE.md#adding-directives) says exact
ledger-authored quotes skip, different same-day quotes require force, only
written prices count, and a generated point is not authored duplicate evidence.
Keep the active plugin view for accounting, and use the actual authored
date/commodity/amount facts for these write decisions.

Run the standalone recipe twice in fresh absolute directories. Try all modes
and operations; `human_add=True` checks ordinary add output. The inspected
plugins perform deterministic in-memory filtering or exact finite inversion
of 1.25/0.80, with no I/O or services. The inspected importer parses only its
controlled statement. Existing optional importer support is already available;
no installation or feature enablement was performed. Children have isolated
config/cache, closed stdin/no TTY, separate streams, bounded timeouts and source
hashes. Global state, HOME and real ledgers are untouched.

```python
import hashlib, json, os, pathlib, subprocess
case = pathlib.Path('/abs/authored-price-case')
mode = 'filter'  # pass, inverse, inverse-control
operation = 'same'  # different, import-same
human_add = False
case.mkdir(parents=True)
module = case/'qa_prices.py'
module.write_text('''from decimal import Decimal
from beancount.core.amount import Amount
from beancount.core.data import Price
__plugins__ = ('view',)
def view(entries, options, config=None):
    out = []
    for e in entries:
        if isinstance(e,Price):
            if MODE=='filter':continue
            if MODE=='inverse':e=e._replace(currency=e.amount.currency,
                amount=Amount(Decimal(1)/e.amount.number,e.currency),meta=e.meta.copy())
        out.append(e)
    return out, []
'''.replace('MODE',repr(mode)),encoding='utf-8')
ledger = case/'main.bean'
ledger.write_text('''option "operating_currency" "USD"
option "insert_pythonpath" "TRUE"
plugin "qa_prices"
2024-01-01 open Assets:Euro EUR
2024-01-01 open Equity:Opening USD
2024-01-02 * "Capital"
  Assets:Euro 100.00 EUR @ 1.25 USD
  Equity:Opening -125.00 USD
2024-01-31 price EUR 1.25 USD
''',encoding='utf-8')
(case/'initial-main.txt').write_bytes(ledger.read_bytes())
original_module = module.read_bytes()
env = os.environ.copy()
for key in ('BEA_FILE','BEA_TOKEN','BEANCOUNT_LOAD_CACHE_FILENAME'):
    env.pop(key,None)
env.update(BEA_CONFIG_DIR=str(case/'config'),XDG_CACHE_HOME=str(case/'cache'),
           BEA_NO_UPDATE_NOTIFIER='1')
def run(tag,args,human=False):
    before = ledger.read_bytes()
    cmd = ['bea',*([] if human else ['--json']),'--no-input','-f',str(ledger),*map(str,args)]
    r = subprocess.run(cmd,cwd=case,env=env,stdin=subprocess.DEVNULL,
                       capture_output=True,text=True,timeout=25)
    print(json.dumps(dict(tag=tag,args=cmd,exit=r.returncode,stdout=r.stdout,stderr=r.stderr,
                          source_preserved=ledger.read_bytes()==before,
                          before_sha256=hashlib.sha256(before).hexdigest(),
                          after_sha256=hashlib.sha256(ledger.read_bytes()).hexdigest(),
                          plugin_preserved=module.read_bytes()==original_module)),flush=True)
run('before-check',['check'])
inverse = mode.startswith('inverse')
commodity = 'USD' if inverse else 'EUR'
amount = (('0.50' if operation=='different' else '0.80')+' EUR' if inverse else
          ('1.30' if operation=='different' else '1.25')+' USD')
if operation=='import-same':
    statement = case/'quote.statement'
    statement.write_text(f'2024-01-31 price {commodity} {amount}\n')
    config = case/'importer.py'
    config.write_text("from beancount.parser import parser\nclass Quotes:\n"
        " def identify(self,file):return str(file).endswith('.statement')\n"
        " def account(self,file):return 'Assets:Euro'\n"
        " def extract(self,file,existing_entries=None):\n"
        "  es,errs,_=parser.parse_file(str(file));assert not errs,errs;return es\n"
        "CONFIG=[Quotes()]\n")
    args = ['import',statement,'--config',config]
    run('preview',args)
    run('apply',args+['--apply'])
    run('repeat',args+['--apply'])
else:
    run('add',['add','price','--date','2024-01-31','--currency',commodity,'--amount',amount],human_add)
run('after-check',['check'])
run('list',['list','price','--limit','100'])
```
