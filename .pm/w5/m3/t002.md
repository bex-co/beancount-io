## Objective

Let users diagnose an incomplete skill installation without having an agent fail midway through a ledger workflow.

## Context

- Reconcile, close, and ask load supporting references; close and migrate compose sibling skills.
- `skills/scripts/ci-check.py` validates the source checkout, which is different from validating a user's installed suite.

## Steps

1. Add a read-only verifier that accepts an explicit installed-suite location and checks the expected customer inventory.
2. Resolve the actual relative supporting files and composed skill requirements used by that installation; avoid treating external links or prose examples as local files.
3. Return actionable missing-item messages and a nonzero exit status on incomplete installations; document the command.

## Files

- `skills/scripts/ (new installed-suite verification helper)`
- `skills/README.md`
- `skills/docs/installation.md (if created)`

## Acceptance criteria

- [ ] A complete installed suite passes without modifying any file.
- [ ] Removing a required reference or composed sibling produces a specific actionable failure.
- [ ] Unrelated installed skills do not cause failure or get included as customer workflows.

## Out of scope

- Executing ledger writes or installing missing tools automatically.
- Duplicating the source-checkout CI suite.
