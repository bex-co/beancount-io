## Objective

Keep repeated benchmark runs bounded and produce a report suitable for public review.

## Context

- External clients can stall, emit partial output, or expose unsupported usage fields.
- All persisted artifacts must remain synthetic and free of credentials.

## Steps

1. Enforce duration and call limits, handle cancellation, and terminate run-owned child processes.
2. Reset or remove only run-owned fixture state and surface cleanup failures instead of obscuring them.
3. Emit reports with server revision, client/model versions, attempt counts, correctness, calls, elapsed time, and supported token/cost metrics; redact credentials and mark unavailable metrics explicitly.

## Files

- `backend-cluster/backend-v2/evals/mcp-agent/ (runner lifecycle and report output)`

## Acceptance criteria

- [ ] Timeout and cancellation leave no run-owned client process running and mark the result incomplete.
- [ ] Cleanup cannot remove an unrelated ledger or fixture directory.
- [ ] Reports contain no credential values; unsupported metrics are unavailable rather than fabricated zeros.

## Out of scope

- Persistent telemetry, production usage tracking, or historical cost recomputation.
