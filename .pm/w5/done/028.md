# MCP tool path returns raw unexpected-error messages; REST masks them (D7 gap)

**Severity:** medium. **Journey:** envelope. **Owner:** backend-v2. Found by the MCP QA auth sweep on 2026-10-03 against production; live at repo HEAD `75819075`. No live board dupe.

Target: `https://beancount.io`, `POST /api-gateway/mcp` (production), observed 2026-10-03.
serverInfo `{"name":"beancount-mcp","version":"1.0.0"}`, protocolVersion `2025-11-25`.
Credential: `bcio_` API key (server kind `apikey`), scopes `ledger.read ledger.write ledger.admin`, ledger pin none (unpinned), no expiry. Value never recorded.
Helper: `node .agents/skills/qa-shared/scripts/qa-mcp.mjs --credentials-file muse.env` from repo root.

## Repro (synthetic coords `qa-owner/qa-book`)

```sh
call appendLedgerText '{"dry_run":true,"text":"2026-13-45 * \"bad\"\n  Expenses:X 1 USD\n  Assets:Y -1 USD"}' (example trigger; any unexpected throw leaks)
```

JSON-RPC sent:

```json
{"jsonrpc":"2.0","method":"tools/call","params":{"name":"appendLedgerText","arguments":{"dry_run":true,"text":"2026-13-45 * ..."}},"id":1}
```

Observed: INTERNAL `Invalid time value` raw RangeError text. Systemic: any non-DomainError leaks verbatim on the MCP tool path.

## Control

REST error-middleware masks unexpected errors in production (:109); GraphQL always masked. MCP boundary has no masking step.

## Cause

- `backend-cluster/backend-v2/src/features/ai-agent/api/mcp-errors.ts`
- `backend-cluster/backend-v2/src/server/api/composition-root.ts`
- `backend-cluster/backend-v2/src/server/rest/error-middleware.ts`

D7 (ADR007) mandates production masking of unexpected errors on all surfaces; `envelopeFromThrown`/`splitToolFailure` in mcp-errors.ts has no mask. Distinct from the bad-date item: that is misclassification of a caller error (fix: validate -> BAD_USER_INPUT); this is the missing transport mask for genuinely unexpected errors.

## Fix (parity: MCP)

Owning package `backend-cluster/backend-v2`; the fix must land on every eligible surface (MCP) in the same change. Add a production masking step at the MCP boundary.

## Evidence

---

**Resolved 2026-10-03** — in production the MCP boundary now replaces the message of an unexpected failure with `Internal server error`, keeping its code and hint, on tool calls, resource reads and prompt fetches. A `DomainError`, an argument refusal and a tool guard's own not-found keep their message, and the full message still goes to the logger. Shipped in `0b1a0af7` (`backend-cluster/backend-v2`, with the status recorded in ADR 0007).

Tests drive a failing tool call and resource read through the real registry in production and development modes; the production case fails with the fix reverted. Two caller-facing guards still throw a plain `Error` and are therefore masked in production until they are given a category: the bank-connection `dry_run` refusal ([034](./034.md)) and the ambiguous `old_string` refusal ([036](./036.md)). Not observed against the hosted endpoint: the mask reaches it with the next deploy.
