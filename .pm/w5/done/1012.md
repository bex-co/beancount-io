# Compare declared tags and links for same-location transaction copies

**Minor · cli · 35–50m · A1 · worker1.** A calculated transaction copy replaces
the source's tag or link but keeps its date, header, flag and posting amounts.
Both rows are called written. `--on-disk --tag derived` and `--link receiptB`
therefore return a row whose annotations the file never declares; unfiltered
on-disk listing and truncation count two declarations where one exists.
This is a read/provenance defect; no financial write failure is claimed.
No product fix implemented.
