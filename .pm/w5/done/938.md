# Exclude generated prices and balances from duplicate and conflict checks

**Major · cli · 45–60m · A1.** A calculated price that inherits another
price directive's source location is correctly marked generated by listing,
but `add price` and native import count it as an authored quote. A forced
correction from 1.20 to 1.30 USD exits successfully without writing, leaving
a 100 GBP holding valued at 120 USD instead of the requested 130 USD.
The balance writer also falsely skips a generated assertion as already
written, including under force, through the same omitted shared-source
context. No product fix implemented.

Real CLI QA, 2026-10-21, HEAD `7790292dd`, checkout `bea 0.3.1`, macOS
26.5.1 arm64, frontend Python 3.13.3, existing managed Python 3.12.10.
Separate subprocesses, closed stdin/no TTY, isolated absolute
`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, `BEA_NO_UPDATE_NOTIFIER=1`, no inherited
`BEA_FILE`/`BEA_TOKEN`. The synthetic calculation plugin uses the real native
loader; no mocked CLI result or external service.

Create disposable `/abs/books/qa_cross.py`:

```python
from decimal import Decimal
from beancount.core.amount import Amount
from beancount.core.data import Price

__plugins__ = ("derive",)

def derive(entries, options):
    out = []
    for entry in entries:
        out.append(entry)
        if isinstance(entry, Price) and entry.currency == "EUR":
            out.append(entry._replace(
                meta=entry.meta.copy(),
                currency="GBP",
                amount=Amount(entry.amount.number * Decimal(13) / Decimal(11), "USD"),
            ))
    return out, []
```

Native import has the same gap. With the already-enabled Beangulp feature,
create `/abs/books/importer.py`:

```python
import datetime
import json
from decimal import Decimal
from beancount.core.amount import Amount
from beancount.core.data import Price, new_metadata

class Quotes:
    def identify(self, file):
        return str(file).endswith("quote.json")
    def account(self, file):
        return "Assets:Cash"
    def extract(self, file, existing=None):
        value = json.loads(open(file).read())
        return [Price(new_metadata(str(file), 1), datetime.date(2024, 2, 1),
                      "GBP", Amount(Decimal(value["amount"]), "USD"))]

CONFIG = [Quotes()]
```

## Generated balances borrowing another account's assertion line

Additional real CLI QA, 2026-10-21, HEAD `5b7a28f43` (initial reproduction
on `f6744d176`, CLI unchanged), confirms the same omission in
`_balance_match` and `_balance_conflict`. The fixture is native-valid: the
generated assertion is for a different account, not a different amount under
the same account/date/currency key.

Create `/abs/books/assertions.py`:

```python
from beancount.core.data import Balance
from beancount.core.amount import Amount
from decimal import Decimal

__plugins__ = ("derive_assertion",)

def derive_assertion(entries, options):
    result = []
    for entry in entries:
        result.append(entry)
        if isinstance(entry, Balance) and entry.account == "Assets:Cash":
            result.append(entry._replace(account="Assets:Savings", amount=Amount(Decimal("8"), "USD")))
    return result, []
```
