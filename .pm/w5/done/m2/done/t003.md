## Objective

Complete the ARIA wiring on the gallery page's ledger-search combobox so keyboard highlighting is exposed to screen readers, and make the clear button keyboard-reachable.

## Context

- `dashboard/src/features/ledger-list/pages/gallery-page/index.tsx`: input has `role="combobox"`, `aria-expanded`, `aria-autocomplete="list"`, options have `role="option"` + `aria-selected`, and ArrowUp/Down/Enter/Escape handling exists — but the dropdown container lacks `role="listbox"`, and there is no `aria-controls`/`aria-activedescendant` wiring, so the highlight is invisible to screen readers. The clear button has `tabIndex={-1}`.
- Existing tests: `pages/gallery-page/__tests__/gallery-page.test.tsx` (178 lines) cover combobox behavior — extend them.

## Steps

1. Add `role="listbox"` to the dropdown container with a stable `id`; point `aria-controls` at it.
2. Wire `aria-activedescendant` to the highlighted option's id (give each option an id).
3. Make the clear button focusable (`tabIndex` removal) with an `aria-label`.
4. Extend the existing gallery tests for the new semantics.
