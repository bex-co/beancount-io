## Objective

The sidebar's home/logo control and logo images get accessible names: an `aria-label` on the button and a localized, descriptive `alt` instead of the generic `"Logo"`.

## Context

- `dashboard-sidebar.tsx` (~line 328): the logo + "Dashboard" header is a plain `<button>` navigating to `/ledger` with no `aria-label`; its `<img>` has `alt="Logo"`.
- `src/common/components/ledger-layout/ledger-switcher.tsx` uses the same generic `alt="Logo"` image.
- Strings must go through `t()`; locales cover 15 languages and `src/test/translations.test.ts` enforces key parity.

## Steps

1. Add an `aria-label` (localized, e.g. "Go to dashboard") to the sidebar home button.
2. Replace `alt="Logo"` with a localized descriptive alt (or `alt=""` if the adjacent text makes it decorative) in both `dashboard-sidebar.tsx` and `ledger-switcher.tsx`.
3. Add the keys to all 15 feature/common locales as appropriate.

## Files

- `dashboard/src/features/ledger-list/pages/dashboard-page/components/dashboard-sidebar.tsx`
- `dashboard/src/common/components/ledger-layout/ledger-switcher.tsx`
- Relevant `locales/*.ts`

## Acceptance criteria

- [ ] Home control announces its purpose to screen readers.
- [ ] No remaining generic `alt="Logo"` on these two surfaces.
- [ ] Translation parity test passes.

## Out of scope

- Auditing alt text across the whole app.
