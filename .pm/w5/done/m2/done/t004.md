## Objective

The delete-ledger confirmation dialog communicates its destructive nature to assistive technology and manages focus safely.

## Context

- `dashboard-sidebar.tsx` delete dialog: destructive intent is currently conveyed only by button styling; no explicit destructive aria handling or focus management beyond the Dialog defaults.

## Steps

1. Ensure the dialog's accessible description states the consequence (permanent deletion of the named ledger); wire `aria-describedby` if the shadcn `Dialog`/`AlertDialog` doesn't already.
2. Consider switching to `AlertDialog` if not already used — it is the correct primitive for destructive confirmations.
3. Verify initial focus lands on the cancel (safe) action, not the destructive button.

## Files

- `dashboard/src/features/ledger-list/pages/dashboard-page/components/dashboard-sidebar.tsx`
