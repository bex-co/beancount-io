# Catalan Holdings, Statistics, Commodities, Documents, Errors and Query pages still show strings written for other keys

**Severity:** major (localization: the wrong words in page headings and empty states). **Owner:** dashboard. **Estimate:** 30–45 minutes. **A3:** a Catalan reader opens Holdings and the heading says "Nom del fitxer" (File name). Statistics is headed "Consulta" (Query), and an empty Documents page says the ledger has no currency price data. **Found by:** `/qa-find-bugs-dashboard` on 2026-11-16 against `https://beancount.io`, headless Chromium, the QA account's synthetic ledger. Read-only. Local HEAD `15173444f` has the same strings.

This is the same defect as w4/m14 and w4/139: a Catalan entry holds the text for a neighbouring key, while the entry's `description` is still correct. Those items repaired the common, Journal, report, account-report, overview and file-editor catalogs. The `ledger-data`, `bql` and `ledger-editor` catalogs below were never audited. Only Catalan is affected: the same keys are correct in the other thirteen locales.

## Repro (live)

Open each page with `?lang=ca` on any ledger, for example `/ledger/open_ledger/example/<page>?lang=ca`:

- `holdings`: H1 and sidebar item read **Nom del fitxer**. The tab title reads `Participacions - …`.
- `statistics`: H1 reads **Consulta**. The tab title reads `Estadístiques`. The Account Last Entries date column header reads **Participacions per compte**.
- `errors` on a clean ledger: the empty state title reads **Dades no disponibles** (No data available) instead of "No s'han trobat errors".
- `documents` on a ledger with no documents: the empty state reads **Aquest llibre encara no té cap dada de preus de monedes.** (This ledger has no currency price data yet.)

## Why the guard missed it

The placeholder-set check that w4/139 widened in `dashboard/src/test/translations.test.ts` only catches a swap that moves a `{placeholder}`. None of these entries contains a placeholder on either side.

## Fix

Translate each listed key from its English message. Keep the wording consistent with the strings beside it: "Participacions" for holdings, "Estadístiques" for statistics, "Resultat de la consulta" for query result. Add a regression test for this class. For example, assert that no two keys in one Catalan catalog share a message when their English messages differ, scoped to these catalogs. w4/139 measured a global duplicate-value gate as too noisy, so keep the check scoped.

- The Errors and Documents empty states describe errors and documents.
- Every key listed above reads as a translation of its English message.
- `yarn test` (translations suite), `yarn lint` and `yarn format:check` pass in `dashboard/`.
