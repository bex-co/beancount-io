## Standalone recipe

Put the checkout `bea` on PATH. Save this as `recipe.py`, then run
`python3 recipe.py /absolute/fresh/book` (the directory must not exist).
Optional arguments select the symbol, currency, `match` or `usd`, amount
mode and `json` or `human`, for example:
`python3 recipe.py /absolute/fresh/kip '₭' LAK usd column human`.
The script records separate streams, exact argv/cwd/child overrides, duration,
exits and before/after hashes in the synthetic case's `results.json`.
`pristine.bean` retains the initial ledger for independent native comparison.

```python
import csv, hashlib, json, os, pathlib, subprocess, sys, time

# Usage: python3 recipe.py /absolute/fresh/book [symbol] [currency] [match|usd]
#        [amount|column|debit|credit|direction|ledger|constant] [json|human]
root = pathlib.Path(sys.argv[1]).resolve()
symbol = sys.argv[2] if len(sys.argv) > 2 else '₿'
currency = sys.argv[3] if len(sys.argv) > 3 else 'BTC'
matching = len(sys.argv) > 4 and sys.argv[4] == 'match'
mode = sys.argv[5] if len(sys.argv) > 5 else 'amount'
human = len(sys.argv) > 6 and sys.argv[6] == 'human'
root.mkdir()
book, bank = root/'main.bean', root/'bank.csv'
book.write_text('option "operating_currency" "USD"\n'
    '2024-01-01 open Assets:Cash USD\n'
    '2024-01-01 open Assets:Local '+currency+'\n'
    '2024-01-01 open Assets:Multi USD,'+currency+'\n'
    '2024-01-01 open Equity:Opening USD,'+currency+'\n'
    '2024-01-01 open Expenses:Food\n'
    '2024-01-01 * "Capital"\n'
    '  Assets:Cash 1000.00 USD\n'
    '  Assets:Local 100.00 '+currency+'\n'
    '  Equity:Opening -1000.00 USD\n'
    '  Equity:Opening -100.00 '+currency+'\n')
(root/'pristine.bean').write_bytes(book.read_bytes())
row = {'Date':'2024-01-02','Description':'Symbol purchase','Reference':'B1'}
mapping = 'date=Date,narration=Description,id=Reference'
if mode in ('debit','credit'):
    row.update(Debit=symbol+'4.50' if mode == 'debit' else '',
               Credit=symbol+'4.50' if mode == 'credit' else '')
    mapping += ',debit=Debit,credit=Credit'
else:
    row['Amount'] = symbol+'4.50' if mode == 'direction' else '-'+symbol+'4.50'
    mapping += ',amount=Amount'
if mode == 'column':
    row['Currency'] = currency if matching else 'USD'
    mapping += ',currency=Currency'
if mode == 'constant':
    mapping += ',currency='+ (currency if matching else 'USD')
if mode == 'direction':
    row['Type'] = 'debit'
    mapping += ',direction=Type'
if mode == 'ledger':
    mapping += ',sign=ledger'
with bank.open('w', newline='') as out:
    writer = csv.DictWriter(out, fieldnames=list(row))
    writer.writeheader(); writer.writerow(row)
original_csv = bank.read_bytes()
env = os.environ.copy()
for key in ('BEA_FILE','BEA_TOKEN','BEANCOUNT_LOAD_CACHE_FILENAME',
            'BEA_ENGINE_PYTHON','BEA_ENGINE_DIR'):
    env.pop(key, None)
env.update(BEA_CONFIG_DIR=str(root/'config'), XDG_CACHE_HOME=str(root/'cache'),
           BEA_NO_UPDATE_NOTIFIER='1')
records = []
def run(tag, args, may_write=False, json_output=True):
    before = book.read_bytes()
    argv = ['bea'] + (['--json'] if json_output else []) + [
        '--no-input','--offline','--file',str(book),*map(str,args)]
    started = time.monotonic()
    result = subprocess.run(argv, cwd=root, env=env, stdin=subprocess.DEVNULL,
                            capture_output=True, text=True, timeout=25)
    record = dict(tag=tag, args=argv, cwd=str(root), stdin_mode='DEVNULL',
        tty=False, duration=round(time.monotonic()-started,3),
        env={k:env[k] for k in ('BEA_CONFIG_DIR','XDG_CACHE_HOME','BEA_NO_UPDATE_NOTIFIER')},
        exit=result.returncode, stdout=result.stdout, stderr=result.stderr,
        ledger_before=hashlib.sha256(before).hexdigest(),
        ledger_after=hashlib.sha256(book.read_bytes()).hexdigest(),
        csv_sha256=hashlib.sha256(bank.read_bytes()).hexdigest())
    records.append(record)
    (root/'results.json').write_text(json.dumps(records,indent=2,ensure_ascii=False))
    assert bank.read_bytes() == original_csv
    assert (may_write and result.returncode == 0) or book.read_bytes() == before
    return result
assert run('baseline',['check']).returncode == 0
account = 'Assets:Multi' if mode in ('column','constant') else (
    'Assets:Local' if matching else 'Assets:Cash')
args = ['import',bank,'--csv',mapping,'--account',account,
        '--default-account','Expenses:Food']
run('preview',args,json_output=not human)
applied = run('apply',args+['--apply'],may_write=True,json_output=not human)
if applied.returncode == 0:
    run('repeat',args+['--apply'])
run('facts',['query','SELECT account,currency,sum(number) GROUP BY account,currency ORDER BY account,currency'])
assert run('check',['check']).returncode == 0
print(json.dumps({'root':str(root),'symbol':symbol,'currency':currency,
                  'matching':matching,'mode':mode,'human':human,
                  'exit_codes':[(r['tag'],r['exit']) for r in records]},ensure_ascii=False))
```

## Root cause and repair scope

`cli/src/bea_engine/csv_mapper.py:_is_currency_symbol` (:114) recognizes any
Unicode `Sc` sign. `_split_amount_sign` (:178–222) removes those edge signs
before numeric parsing. The finite `_SYMBOL_CURRENCIES` (:122–141) omits all
three verified associations, so `_cell_symbol_currencies` (:144–158) returns
no evidence for them. `_check_cell_symbols` (:1685–1716) has nothing to compare
against the resolved currency. `CsvImporter.extract` resolves currency then
calls that guard at :1886 for every amount layout; the resulting balanced
postings use that currency at :1898–1899. This explains clean native checks
over the already relabelled postings.

The frontend `import_entries` delegates through `launch.helper_json`
(`cli/src/cli/commands/import_.py:1532`); `importing.py:309` constructs this
same CsvImporter for the mapped CSV path. No separate frontend symbol guard
was found. Native explicit-commodity postings and Python importers bypass
this symbol-stripping path.

Add these bounded verified associations to the existing contradiction policy,
with meaningful real import coverage for mismatch/match and shared amount
modes. Keep row currency precedence, exact decimal values, bank/ledger signs,
repeat-ID behavior, arbitrary commodity support, `$`/`¥` ambiguity, shared
`£`/`₩` association sets and the scan of every recognized symbol. No dependency,
currency registry restriction, FX, cross-package import or backend/API change
is needed. A1 outcome: agents importing statements cannot silently change the
source unit while receiving success and a clean ledger.
