# Limit Codex eval sessions to the eval server, as Claude Code's are

**Minor · backend-v2 scripts · 45–60m · A1.** Found 2026-10-21 while measuring w5/m5's prompt journeys on Codex ([w4/960](../w4/done/960.md)).

`yarn mcp:agent-eval` gives Claude Code only the eval server (`--strict-mcp-config`, tools allow-listed). Codex gets `--ignore-user-config` and a read-only sandbox. On codex-cli 0.163.0 that still left:

- **The ChatGPT account's apps.** Codex made 93 GitHub connector calls in 23 of 27 attempts on the dedicated ledger. It fetched each prompt's cited playbook from the public repository, and three times fetched `backend-cluster/backend-v2/src/features/ai-agent/api/mcp-prompts.ts`.
- **A shell that reads the whole disk.** Codex ran 63 commands in 27 attempts, some for statement arithmetic. In the hand-run `categorize-imports` sessions, it listed the home directory and read the playbook from the local checkout.
- **Nothing walling off the answers.** No attempt read `evals/`, but nothing stops one. `evals/mcp-agent/journeys.json` holds the expected facts.

The MCP-call metric counts only the eval server, so Codex's effort is not comparable with Claude Code's. Record: [2026-10-21-prompts-codex.md](../../backend-cluster/backend-v2/evals/mcp-agent/baseline/2026-10-21-prompts-codex.md#observations).

Fix, in `codexInvocation` (`scripts/mcp-agent-eval.ts`):

1. **Turn off apps:** pass `--disable apps`, the feature that hosts the connector.
2. **Decide on the shell:** either `--disable shell_tool` for parity with Claude Code, or keep it and document the difference.
3. **Report outside calls:** show connector and shell calls in the report next to MCP calls, from the transcript's existing `otherToolCalls`.
4. **Verify:** add a test of the invocation, then rerun the nine prompt journeys on Codex for a comparable baseline.

Acceptance: a Codex attempt can call no tool outside the eval server, or the report says which outside tools it used and how often.


---

**Resolved 2026-10-22** — fixed in the harness: `clientCommand` (`backend-cluster/backend-v2/scripts/mcp-agent-eval.ts`) now starts Codex, fresh or resumed, with `--disable apps` and `--disable shell_tool` (both are stable features in codex-cli 0.163.0), which leaves it only the eval server as Claude Code's allow-list does; the guide records the shell decision (disabled, for parity). The report gains an *Outside calls* column (`meanOutsideCalls`, the mean of the transcript's `otherToolCalls`), so a client that still reaches outside the server shows how often. Tests pin the two disabled features on both command shapes and the outside-call average; backend-v2 typecheck, eslint, knip, prettier and the full jest suite are green. Not done here: step 4's rerun of the nine prompt journeys on Codex, which is a live, billed run against the hosted endpoint with QA credentials; the existing Codex baseline ran with apps and shell on and is marked not comparable in the guide.
