## Mechanism and retained controls

`cli/src/bea_engine/query.py:204–211`, `_Column`, groups by Python type.
All three cells are `Cost`, so `mixed` is false. `_Orderable._comparable`
(:232–233) therefore returns native Cost values. `__lt__` (:244–250) compares
two dated costs natively but falls back to `str()` only when one date is
`None`. Decimal spellings then decide that pair before dates do.

An actual frozen-helper/native-parser proof records **A < B, B < C and
C < A, all true**, with one Cost type and `mixed=false`. A/B and C/A native
comparisons raise TypeError on `None` versus `datetime.date`; B/C compares
real dates. Python sort needs a transitive relation, so this cycle permits
the source-dependent orders above. The shared ordering hook serves local
and native-source query shells; only local one-shot JSON/text/CSV is directly
exercised for this nullable-cost failure.
