# German Trial Balance uses two names for one report: "Saldenbilanz" in the heading, "Probebilanz" in the tab title, description and related link

**Severity:** minor (localization). **Owner:** dashboard. **Estimate:** 10–15 minutes. **A3:** German readers see the report renamed between the browser tab, the heading and the links that lead to it. **Found by:** `/qa-find-bugs-dashboard` on 2026-11-16 against `https://beancount.io` (local HEAD `3d80f8ba4`, strings unchanged), headless Chromium, `open_ledger/example`. Read-only.

## Repro

Open `/ledger/open_ledger/example/trial-balance?lang=de`.

- The document title reads `Probebilanz - example`.
- The H1 and the table heading read `Saldenbilanz`.
- The description reads `Probebilanzansicht für example. …`.
- Other reports' Related Pages link it as `Probebilanz`.

"Saldenbilanz" is the standard German term. "Probebilanz" is a calque of "trial balance".

## Fix

Use "Saldenbilanz" throughout `dashboard/src/i18n/locales/common/de.ts` (`common.pageDescription.trialBalance`, `common.relatedLinks.trialBalance`) and `dashboard/src/i18n/locales/seo/de.ts` (`seo.ledgerTrialBalance.title`, `seo.ledgerTrialBalance.description`). Keep `common.trialBalance` and `page.trialBalance.overviewTitle`, which already say "Saldenbilanz".

## Acceptance

- `rg Probebilanz dashboard/src` returns nothing.
- On `?lang=de`, the tab title, heading, description and related link all say "Saldenbilanz".
- The dashboard locale checks pass.
