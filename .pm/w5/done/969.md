# Export every imported namespace-package portion

**Minor · cli · 30–45m · A1.** A local Python namespace package can span two
ledger directories that set `insert_pythonpath`. The source plugin reads
both portions successfully, but `price export` copies only the first.
Export exits 0; its fresh snapshot fails on the omitted data file or module.
Moving the same files into one portion makes the export work. This is a
follow-up to completed [880](./done/880.md)'s namespace support, separate
from [968](./968.md)'s cached-input problem. No product fix implemented.

Environment: 2026-10-22 QA, clean main `693b56898` (initial reproduction on
`9e0fefa1b`; implicated source unchanged), checkout `bea 0.3.1`, frontend
Python 3.13.3, managed Python 3.12.10 / Beancount 3.2.3 / Beanquery 0.2.0,
macOS 26.5.1 arm64. Fresh real subprocesses, closed stdin/no TTY, isolated
absolute config/cache paths, notifier disabled, inherited file/token
overrides removed. Inspected local plugin, synthetic ledger/resources only;
no price feeds or optional features.

Run with the checkout's `bea` on PATH, replacing `/abs/case` with a fresh
absolute disposable directory. Neither `qa_bankdata` directory has an
`__init__.py`: Python combines their search locations into one namespace
package. The source is hidden and restored around the snapshot check.

```python
import json, os, subprocess
from pathlib import Path
case = Path('/abs/case')
books = case / 'books'
a, b = books / 'a', books / 'b'
a.mkdir(parents=True)
b.mkdir()
(books / 'main.bean').write_text('''option "operating_currency" "USD"
include "a/settings.bean"
include "b/settings.bean"
plugin "qa_plugin"
2024-01-01 open Assets:Cash USD
2024-01-01 open Income:Services USD
2024-01-02 * "Invoice"
  Assets:Cash 100 USD
  Income:Services -100 USD
''')
for directory in (a, b):
    (directory / 'settings.bean').write_text('option "insert_pythonpath" "TRUE"\n')
    (directory / 'qa_bankdata').mkdir()
(a / 'qa_bankdata' / 'a.json').write_text('{"amount":100}\n')
(b / 'qa_bankdata' / 'b.json').write_text('{"amount":25}\n')
(a / 'qa_plugin.py').write_text('''import json
from importlib.resources import files
__plugins__ = ['read_data']
def read_data(entries, options):
    data = files('qa_bankdata')
    assert json.loads(data.joinpath('a.json').read_text())['amount'] == 100
    assert json.loads(data.joinpath('b.json').read_text())['amount'] == 25
    return entries, []
''')
original = {str(p.relative_to(books)): p.read_bytes() for p in books.rglob('*') if p.is_file()}
env = os.environ.copy()
for key in ('BEA_FILE', 'BEA_TOKEN', 'BEANCOUNT_LOAD_CACHE_FILENAME',
            'BEA_ENGINE_PYTHON', 'BEA_ENGINE_DIR'):
    env.pop(key, None)
env.update(BEA_CONFIG_DIR=str(case / 'config'), XDG_CACHE_HOME=str(case / 'cache'),
           BEA_NO_UPDATE_NOTIFIER='1')
def run(tag, file, args, overrides=None):
    argv = ['bea', '--json', '--no-input', '-f', str(file), *map(str, args)]
    result = subprocess.run(argv, cwd=case, env=env | (overrides or {}),
                            stdin=subprocess.DEVNULL, capture_output=True,
                            text=True, timeout=25)
    print(json.dumps(dict(tag=tag, args=argv, exit=result.returncode,
                         stdout=result.stdout, stderr=result.stderr)), flush=True)
run('source-check', books / 'main.bean', ['check'])
run('source-cash', books / 'main.bean', ['query', "SELECT number WHERE account='Assets:Cash'"])
snapshot = case / 'snapshot'
run('export', books / 'main.bean', ['price', 'export', '--output', snapshot])
hidden = case / 'hidden-books'
books.rename(hidden)
try:
    run('snapshot-check', snapshot / 'main.bean', ['check'],
        {'XDG_CACHE_HOME': str(case / 'snapshot-cache')})
finally:
    hidden.rename(books)
assert all((books / name).read_bytes() == content for name, content in original.items())
```

Actual exits: **0, 0, 0, 1**. Source check is valid and Cash is **100 USD**.
Export reports success with these five files:

```text
main.bean
a/settings.bean
b/settings.bean
a/qa_plugin.py
a/qa_bankdata/a.json
```

`b/qa_bankdata/b.json` is missing. With the original hidden, snapshot check
fails with JSON stderr naming `qa_plugin` and
`FileNotFoundError: …/snapshot/a/qa_bankdata/b.json`. Human export likewise
reports a successful five-file snapshot. Every original ledger/module/data
byte is preserved, and the source directory is restored.

Expected: the snapshot carries both imported portions at their original
relative paths, so the unchanged included `insert_pythonpath` options
resolve the same namespace. USAGE's self-contained export contract at
`cli/docs/USAGE.md:1980–1986` includes local packages and their data files,
not just one directory of a package that actually spans two.

Reproduction and controls:

- Two pristine initial multi-portion fixtures fail, while two otherwise
  identical fixtures with only `b.json` moved beside `a.json` pass snapshot
  check: **12 CLI calls**.
- Eight further fresh cases, twice each: split resources, split Python
  modules, colocated resources and distinct namespace names. **64 CLI calls**
  cover source check/BQL, ordinary and fresh-cache exports/checks, and human
  exports/checks. Source Cash stays 100 USD. All split-resource exports
  omit `b.json` and snapshot checks fail with that exact missing file.
  Replacing the resources with `qa_bankdata.rates` in `a/` and
  `qa_bankdata.taxes` in `b/` omits the latter and fails with `ImportError`
  naming `taxes`. Both working layouts pass independently, including two
  different namespace packages holding same-named `settings.json` files.
- The public script above was replayed twice alongside the colocated
  control, including human export and source-hidden snapshot checks.
  All source graphs and resource bytes remain unchanged.

Cause: `cli/src/bea_engine/managed_load.py:_module_locations:2256–2265`
recognizes every namespace `__path__` location, but `_sibling_imports`
reduces discovery to a set of top-level names at `:2244–2253`.
`_export_plugin_modules:2129–2140` then chooses a **single** `holder = next`
from the ledger's Python directories and copies only that directory's
package tree. The second portion is never planned, even though Python
loaded it and the exporter encountered the namespace. `_package_files`
itself correctly copies a whole chosen directory; it is given too few.

Fix in `cli/`: retain the actual imported namespace-package locations and
copy every in-tree portion to its corresponding relative path. Preserve
Python's first-match behavior for regular modules/packages; indiscriminately
combining every same-named regular package would change import semantics.
Keep existing collision handling and exclude unrelated modules. No dependency
or API change indicated.

Caller scope: the export plan calls `_export_plugin_modules` at
`managed_load.py:1814`; engine `price-export` (`bea_engine/main.py:855`) and
frontend `price._export` (`cli/commands/price.py:182`) expose it. There is one
`_sibling_imports` caller. Both data and module portions were exercised;
normal report/import behavior is outside this export path.

Dedupe: whole-board searches for namespace locations/portions, multi-location

**Resolved 2026-10-23** — fixed: portable export (`_export_plugin_modules` in `cli/src/bea_engine/managed_load.py`) now resolves a plugin or helper name as Python's path finder does: the first module-path directory holding `name.py` or a regular `name/__init__.py` wins, and a directory `name/` without `__init__.py` is one portion of a namespace package, so every portion on the path is copied at its original relative place. A namespace package spread over `a/qa_bankdata` and `b/qa_bankdata` now ships both `a.json` and `b.json`, and the snapshot checks with the source hidden; a regular package found first still keeps later same-named directories out, and the w5/327, w5/868, w5/880 and w5/968 controls pass. Regression tests in `cli/tests/test_price_export_plugin_runtime_imports.py` fail without the fix. Full suite green apart from the known `test_release` smoke timeout, which passes alone. Shipped in this commit (`cli`).
