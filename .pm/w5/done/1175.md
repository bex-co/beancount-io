# Report chart y-axes switch to the next unit at half of it: "0.0, -300.0, -0.6k, -0.9k" and "-300.0b, -0.6t"

**Severity:** minor (chart readability, every report chart). **Owner:** dashboard. **Estimate:** 20–30 minutes including tests. **A2:** the account, Income Statement, Cash Flow, Balance Sheet Net Worth and Budget charts label one axis in two units. Values from 500 to 999 are already written as thousands (`0.5k`–`1.0k`) while 400 is still `400.0`. A $0–$1,000 spending axis reads `0.0, 200.0, 400.0, 0.6k, 0.8k, 1.0k`, and a $200k–$1M net-worth axis reads `200.0k, 400.0k, 0.6m, 0.8m`. Overview's charts on the same ledger label every tick in one consistent unit. **Found by:** `/qa-find-bugs-dashboard` on 2026-11-18 against `https://beancount.io` (entry chunk `main-LGv2TZLj.js`), headless Chromium 153 at 1440×1000 and 390×844, English, isolated profile, signed in as the QA owner. Local HEAD `0087162cd`.

## Repro

1. Open `/ledger/open_ledger/example/account/Assets:US:BofA:Checking?time=2016-08`, the public example ledger, and choose **Changes Over Time**. This is the same reading w4/done/1018 recorded in Persian.
2. **Actual:** the y-axis reads `0.0, -300.0, -0.6k, -0.9k, -1.2k, -1.5k, -1.8k, -2.1k`, so `-300.0` sits directly above `-0.6k`.
3. On a ledger with a balance of about -1.2 trillion USD (a synthetic probe, since removed), the Balance Sheet's Net Worth chart and the account Balance chart read `0.0, -300.0b, -0.6t, -0.9t, -1.2t, -1.4t`. Overview's Net Worth chart on the same ledger reads `500B, 0, -500B, -1T, -1.5T`: one unit per tick.
4. Direct check of the installed dependency (numbro 2.5.0, `format("0.0a")`): 400 → `400.0`, 500 → `0.5k`, 600 → `0.6k`, 999 → `1.0k`. Likewise 400000 → `400.0k`, 600000 → `0.6m`, 300e9 → `300.0b`, 600e9 → `0.6t`.

**Expected:** each tick is abbreviated by its own magnitude. A value below 1,000 of a unit stays in that unit (`600.0`, `600.0k`, `600.0b`). The next unit starts at 1,000, so the axis above reads `0.0, -300.0, -600.0, -900.0, -1.2k, …`. A value that rounds to 1,000.0 at one decimal may move up (999.96 → `1.0k`). The small-value branch from w4/done/117 (ticks below one) is unchanged.

## Cause

- `dashboard/src/common/lib/chart/chart.ts:39`: `formatYAxisNumber` calls `numbro(numberString).format("0.0a")`.
- numbro's `computeAverage` (`node_modules/numbro/dist/numbro.js:4722-4737`) defaults to `lowPrecision = true` and also picks a unit when `Math.round(abs / power) === 1`. Every value from half of a unit upward therefore takes that unit.
- Callers: `common/lib/chart/cartesian-config.ts:39` (used by `income-statement/date-balance-chart/*`, `cash-flow/cash-flow-charts.tsx`, `reports/account/index.tsx` and `ledger-data/budget/budget-chart-card.tsx`), `reports/balance-sheet/line-chart.tsx:187` and `budget-chart-card.tsx:352`.
- Working control: Overview's `month-hero-chart.tsx:285,292` formats ticks with `Intl.NumberFormat` compact notation, which has no half-unit switch.
- `common/lib/chart/__tests__/chart.test.ts` pins the current output in a case titled "should format small numbers without suffix", which expects `formatYAxisNumber(999)` to be `"1.0k"`. The fix changes that expectation.

## Fix

Owned by `dashboard`. In `formatYAxisNumber`, use numbro's object format with `lowPrecision: false`, for example `numbro(v).format({ average: true, mantissa: 1, lowPrecision: false })`, or an equivalent per-magnitude choice. Checked against the installed numbro: −600 → `-600.0`, −1200 → `-1.2k`, 600000 → `600.0k`, 600e9 → `600.0b`, 1.5e12 → `1.5t`. Keep `0.0` for zero, the one-decimal mantissa, and the fractional and exponential branch for |v| < 1. No other caller changes.

## Definition of done

- The example account's Changes Over Time axis reads `0.0, -300.0, -600.0, -900.0, -1.2k, …`. No report chart labels a value between 500 and 999 of a unit in the next unit.
- `chart.test.ts` covers the tick sequences 0/200/400/600/800/1000 and 200k–1M and asserts that each tick is in its own magnitude's unit. It fails on the current code. The existing k/m/b, negative, zero and fractional cases still pass. Dashboard gates pass.
