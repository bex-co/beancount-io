# Settings → Appearance: the theme button is named only "System", and its menu does not mark the current theme

**Severity:** minor (screen reader). **Owner:** dashboard. **Estimate:** 20 minutes including a rendered test. **A2:** a screen-reader user tabbing through Appearance hears "System, button" with no mention of theme. Inside the menu, "Light", "Dark" and "System" are plain menu items, so nothing says which one is in use. The Language control next to it is named "Language" (w4/done/215). **Found by:** `/qa-find-bugs-dashboard` on 2026-11-18 against `https://beancount.io` (entry chunk `main-LGv2TZLj.js`), headless Chromium 153 at 1440×1000, English, signed in as the QA owner. Read-only (the theme lives in local storage). Local HEAD `a95dfa7d3`.

## Repro

On `/settings/general`, the accessibility tree shows `paragraph: Theme`, `paragraph: Select your preferred color theme`, then `button "System"`. Choosing it opens `menu "System"` with `menuitem "Light"`, `menuitem "Dark"` and `menuitem "System"`. None is `checked`. After choosing Dark, the button reads `button "Dark"`, and the menu still marks nothing.

## Cause

`dashboard/src/features/user-settings/pages/general/appearance-section/theme-switch.tsx:48-78`: the `DropdownMenuTrigger` button's only text is the current theme label, and the "Theme" text in `appearance-section/index.tsx` is a sibling paragraph, not a label. The options are `DropdownMenuItem`s rather than a `DropdownMenuRadioGroup` of `DropdownMenuRadioItem`s.

## Fix

Name the trigger "Theme: <current>" (a localized `aria-label`, or `aria-labelledby` the "Theme" text plus the value), as the language picker does. Render the options as a `DropdownMenuRadioGroup` with `value={theme}`, so the current one is exposed as `menuitemradio` `checked` and shows a check mark.

## Definition of done

- The trigger's accessible name includes "Theme" and the current choice in every locale.
- The open menu exposes three `menuitemradio`s, with exactly the current theme `checked`. Choosing one still switches the theme.
- A rendered test asserts both, and fails on the current code. Dashboard gates pass.

## Dedupe

Searched `.pm/**` for `theme-switch`, `ThemeSwitch`, theme menu and dark mode. Earlier theme items cover contrast (w2/done/107, w3/done/153), not the control's name. The file has not changed since the initial import (`af5339de0`).
