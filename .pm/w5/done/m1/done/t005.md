## Objective

Ledger rows whose owner or name truncates show the full text in a tooltip on hover/focus.

## Context

- `LedgerItem` rows truncate owner/name via CSS `truncate` with no way to read the full value.
- Rows become denser after t001 adds the meta line, making truncation more likely.
- The project has Radix-based `Tooltip` in `src/common/components/ui/`.

## Steps

1. Wrap truncated owner/name text in the shared `Tooltip`, rendering full text.
2. Only enable the tooltip when truncation actually occurs (or keep it unconditional if simpler and harmless).
3. Ensure the tooltip is focusable/keyboard-reachable, not hover-only.

## Files

- `dashboard/src/features/ledger-list/pages/dashboard-page/components/dashboard-sidebar.tsx`

## Acceptance criteria

- [ ] Full owner/name readable on hover and keyboard focus when truncated.
- [ ] No layout shift in the sidebar.

## Out of scope

- Tooltips elsewhere in the app.
