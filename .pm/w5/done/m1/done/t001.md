## Objective

Each ledger row in the `/ledger` sidebar shows the ledger's public/private state and a short meta line (description or last-updated), so users can tell ledger state without opening each one.

## Context

- Live UI: `dashboard/src/features/ledger-list/pages/dashboard-page/components/dashboard-sidebar.tsx` — `LedgerItem` (~line 107) currently renders only owner (`text-xs text-muted-foreground`) + name.
- The retired `components/ledger-list.tsx` rendered Status/Owner/Last-Updated columns, proving the GraphQL fields already exist on the ledgers query — no backend change needed (anti-goal check).
- The shared `ledger-switcher.tsx` (`src/common/components/ledger-layout/`) shows the same ledger data; keep badges/ordering consistent between the two surfaces.

## Steps

1. Confirm which fields the `ListLedgers` query returns (visibility/public flag, description, updatedAt); extend the query if a field is missing but available in the schema.
2. Add a small visibility badge (e.g. Globe/Lock icon) and a one-line meta (description, falling back to relative last-updated) to `LedgerItem`.
3. Add any new strings to the feature locales in all 15 languages (`src/i18n/config.ts` lists them; `src/test/translations.test.ts` enforces parity).
4. Mirror the badge in `ledger-switcher.tsx` if the data is already loaded there.
