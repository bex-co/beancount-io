# Insert narration before all native tag/link tokens in a bare header

**Minor · cli · 25–40m · A1 · worker1.** Update cannot add narration to a
native-valid bare transaction header whose first tag or link is adjacent
to the flag. For `2026-01-03 !#review ^receipt`, it puts `"Coffee"` after
`#review`, where Beancount does not permit a string. Single preview exits0
showing that malformed edit; apply correctly refuses1 and preserves the
file. Batch rejects the requested target while writing its separate valid
G1 row. A spaced header works. The missing capability is a valid edit to
a valid entry, not a failure to accept invalid ledger syntax. No product
fix implemented.
