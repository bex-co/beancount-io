# The Query, file and Create File editors are all named "Editor content", in English, in every language

**Severity:** minor (screen reader). **Owner:** dashboard. **Estimate:** 30 minutes including a rendered test. **A2:** a screen-reader user who tabs into the BQL box on Query hears "Editor content, edit text". The file view and Create File give the same name. Nothing says that the box holds a query or which file it holds, and a German, Japanese or Persian reader hears the same English words. **Found by:** `/qa-find-bugs-dashboard` (`dashboard-qa` routine) on 2026-11-21 against `https://beancount.io`, entry chunk `main-CIyNN76T.js`, isolated headless Chromium at 1440×1000, signed in as the QA owner on the designated synthetic ledger. Read-only. Local HEAD `da52c0020`.

## Repro

Inspect the editable element Monaco renders (`.native-edit-context`, `role="textbox"`) on each page:

| Page | `aria-label` | Visible context |
| --- | --- | --- |
| `/ledger/<owner>/<ledger>/query?lang=de` | `Editor content` | heading "Abfrage" |
| `/ledger/<owner>/<ledger>/files/blob/main/main.bean?lang=en` (read-only) | `Editor content` | file name `main.bean` |
| `/ledger/<owner>/<ledger>/files/create?lang=en` | `Editor content` | the file name box above it |

No element sets `aria-labelledby` on them. The Playwright accessibility tree reads `code: textbox "Editor content"` on all three.

## Cause

Monaco's built-in default `ariaLabel` is "Editor content", and it is not translated, because the app loads Monaco without a locale bundle. None of the mounts passes `ariaLabel` in `options`:

- `dashboard/src/features/bql/pages/index.tsx:293` (options at line 368)
- `dashboard/src/features/ledger-editor/file-editor/components/ledger-file-view/text-editor.tsx:251` (`editorOptions`, line 265)
- `dashboard/src/features/ledger-editor/create-file/index.tsx:337` (options at line 349)
- `dashboard/src/features/ledger-data/accounts/delete-account-dialog.tsx:231` and `:268` (the two source previews)

The shared wrapper `dashboard/src/common/components/monaco-editor/index.tsx` passes options through and adds only `domReadOnly`.

## Fix

Have `MonacoEditor` require a localized `ariaLabel` prop and put it in `options`, so a new mount cannot omit it. Name each one after its content: "BQL query" on Query, "Contents of <path>" in the file view and Create File, and "Source of the open directive" / "Source of the close directive" (or similar) in Delete Account. Add the keys to the English catalogs and run `yarn i18n:prepare`. The Entry Context source editor is already covered by w5/1145's fix. Use the same prop there so the two notes do not diverge.

## Definition of done

- On the three pages above, the editor's accessible name says what it holds, in the page's language (for example a German query box is not named "Editor content").
- `MonacoEditor` passes the given `ariaLabel` to Monaco. A rendered test asserts this through the Monaco mock (`src/test/mocks/monaco-editor.ts`), and fails if a mount omits it. Dashboard gates pass, including `yarn i18n:check`.

## Dedupe

Searched `.pm/**` for `Editor content`, `ariaLabel` and Monaco with accessible name. w5/1145 (open) names only the Entry Context snippet editor (`entry-context-panel.tsx`), as part of its Tab-trap fix. w4/m22 (done) exposed `aria-readonly`, not the name. w4/210, w4/224 and w4/250 mention "Editor content" only as the element they drove. No item covers the other mounts.

## Unverified

Real screen-reader speech, and Monaco's accessibility-help hint ("Press Alt+F1…"), which Monaco may append when it detects a screen reader.

---

**Resolved 2026-11-23** — The shared Monaco wrapper requires an accessible name and forwards it to Monaco, including when it changes. Query names the BQL input, file editors name the ledger-relative path, and Create File switches from the unnamed draft label as the reader types the filename. The open and close source previews have distinct names. Entry Context uses the same wrapper prop. Added all 15 localized versions and ran `yarn i18n:prepare` and `yarn i18n:check`. Chromium accessibility trees showed the intended names in English, German, Japanese, and Persian. A rendered Monaco test verifies the options on mount and rename. All 8,674 dashboard tests, format, lint, and build passed. Shipped in `4c6f761ef` (`dashboard`).
