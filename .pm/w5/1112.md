# Give customer skills shell-neutral instructions for native Windows agents

**Minor · skills · 45–60m · A1 · worker1.** Found by the adoption pass of
[w5/m13/t005](./m13/done/t005.md), 2026-10-28, after the native Windows
rehearsal ([docs/skills/windows-rehearsal.md](../../docs/skills/windows-rehearsal.md)).

Several customer skills tell the agent to run POSIX-only commands. Native
Windows agents run Windows PowerShell 5.1, where `&&`, `head`, `command -v`
and `python3` do not work. In the rehearsed journey both agents translated
`beancount-ask`'s `fd -e beancount` and `command -v bea` on their own (Codex
used `Get-Command`). The other skills are unrehearsed on Windows:

- `fd -e … | head -20` in `beancount-import`, `beancount-options` and
  `beancount-reconcile`; `fd` alone in `beancount-add`, `-ask`, `-invoices`,
  `-property` and `-trade`.
- `command -v bea` in `beancount-init/references/bea-cli.md`; `command -v uv`,
  `python3`/`awk` port picking and `make start` in `beancount-init`.
- `mkdir -p … && cp` in `beancount-importer-author`; `make start` in
  `beancount-migrate`.

**Fix:** describe the intent ("find the ledger files", "check bea is on
PATH") or give both a POSIX and a PowerShell form, keeping one instruction
set for Claude Code and Codex. Rehearse at least one affected skill on
Windows.
