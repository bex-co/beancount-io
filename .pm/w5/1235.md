# Account Settings on a phone: every tab label breaks mid-word ("Gen/eral", "Billi/ng"), and SSH Keys scrolls sideways with its Delete button cut off

**Severity:** minor (layout at phone width; WCAG 1.4.10 Reflow at 320px). **Owner:** `dashboard`. **Estimate:** 25–40 minutes including tests. **A2:** a newcomer who opens Settings on a phone to add the SSH key that hosted-to-local workflows require (DO_NOT_DO: no export without SSH setup) meets a tab bar that reads "Gen / eral · Billi / ng", and on SSH Keys a page that pans sideways with the key's Delete button off the screen. **Found by:** `/qa-find-bugs-dashboard` (`dashboard-qa` routine) on 2026-11-27 against `https://beancount.io`, entry chunk `main-BBmi61Hs.js`, isolated headless Chromium 158, light theme, signed in as the QA account (which has one SSH key). Local HEAD `d682554fb`; the implicated files last changed in `d9cc461d6` (w5/1210), which production already serves. Read-only.

## Repro

1. Sign in, open `/settings/general` at 390×844 (any Settings page). The tab bar under **Back** shows **General** as "Gen / eral" and **Billing** as "Billi / ng", each on two lines, with the active underline under the broken word. At 320×844 **General** takes four lines ("Ge / ner / al"), **SSH Keys** ends "Key / s", and **Danger Zone** "Dang / er Zone". In German at 390, "Allgem / ein" and "Abrechn / ung".
2. Open `/settings/ssh-keys` with at least one key whose status badge reads "Last used within the last 3 months". The document is wider than the screen: `scrollWidth` 412 at both 320 and 390 (92px and 22px of sideways pan). At 320 the card's right edge and nearly all of the red **Delete** button (left edge 304, right edge 371) lie off-screen. In German at 390 the page is 508px wide, Delete is entirely off-screen, and the **Gefahrenzone** tab cannot be reached without panning the whole page.
3. At 320, Billing's usage row also breaks "AI Toke / ns".
4. Controls: at 414px and wider nothing breaks or pans; `/settings/general`, `/billing`, `/api-keys` and `/danger-zone` keep `scrollWidth` equal to the viewport (only their tab labels break).

## Cause

- `dashboard/src/features/user-settings/pages/layout.tsx:60-79` (`TopBarNavigation`): the tab links sit in `flex … overflow-x-auto`, but each `Link` keeps the default `flex-shrink: 1` and no `whitespace-nowrap`. The app-wide `[overflow-wrap:anywhere]` on `<body>` (`common/root-route/shell-component.tsx:24`) lets a word break at any character, so a link's min-content width is one character. The links shrink and wrap mid-word instead of the strip scrolling.
- `layout.tsx:94`: `<main className="flex flex-1 flex-col max-w-7xl mx-auto">` is a flex item with the default `min-width: auto`, so it can't be narrower than its content's min-content width. On SSH Keys that floor comes from `ssh-keys/key-card.tsx:68-111`: icon, then the `Badge` (the primitive is `whitespace-nowrap shrink-0`, `common/components/ui/badge.tsx:8`) "Last used within the last 3 months" (211px), then the `shrink-0` Delete button. Together with the card's `p-6`, that is about 380px. `main` grows to 412px and takes the whole page with it.

Injecting only `main { min-width: 0 }` brings the page back to the viewport at 320 and 390 and puts Delete on-screen (right edge 279 at 320). Adding `flex-shrink: 0; white-space: nowrap` to the tab links keeps every label on one line, and the 520px strip scrolls inside its own box as `overflow-x-auto` intends.

## Fix

Owned by `dashboard`; no API change.

- Give `main` (or the content column) `min-w-0` so no Settings page can be widened past the viewport by its content.
- Make the tab links `shrink-0 whitespace-nowrap`, so the strip scrolls rather than breaking words. Bring the active tab into view (`scrollIntoView({ inline: "nearest" })`) so Danger Zone isn't hidden when it is the current page.
- Let the SSH key status badge wrap or fit on a narrow card (for example, drop `whitespace-nowrap` for this badge, or stack Delete under the text below `sm`), so the card fits 320px without overflow.

## Definition of done

- At 320 and 390 (English and German), every Settings tab label renders on one line and the strip scrolls horizontally. Each tab stays reachable by Tab, and the active one is visible on load.
- `/settings/ssh-keys` with a key whose badge says "Last used within the last 3 months" (and its German text) has `document.scrollingElement.scrollWidth === innerWidth` at 320 and 390. The Delete button lies fully inside the viewport.
- Desktop (1440) layout is unchanged.
- A rendered test covers the tab-link classes and `main`'s `min-w-0` (or a geometry check), and fails on the current code. Dashboard gates pass.
