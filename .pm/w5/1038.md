# Match decomposed Unicode source accounts during retargeting

**Minor · cli · 20–35m · A1 · worker1.** `bea update` reads a decomposed
posting account as the normal NFC account, but its source editor compares
the original token without normalization and silently skips that posting.
An account-only update exits **0**, writes **0**, and calls the row unchanged
even though the requested category differs. A combined update changes the
flag/narration and writes **1**, leaving the **9.99 USD** in Café rather
than Dining. Batch output even lists the requested account change among
its successful changes. No amounts, other transactions or total cash are
lost; no product fix implemented.

Environment: 2026-10-25, clean main
`7086e027f9645ec5fbf9df6e36f19d04bf31cce4`, runtime
`71cfd99b1d3bd597659dd6bbccf4d2b9005a9ded` (1,652 frozen tracked CLI files;
the entire CLI tree is identical at that later main). Checkout `bea 0.3.1`,
frontend Python 3.13.3, existing managed Python 3.12.10 / Beancount 3.2.3 /
Beanquery 0.2.0, macOS26.5.1 arm64. Bounded fresh processes, closed stdin/no
TTY, offline, isolated config/cache and notifier disabled. Synthetic books,
no plugins, installs or hosted changes.

The open and requested account are **`Expenses:Café`**, with U+00E9. The
posting spells the same account with **U+0065 U+0301** instead. `bea check`
is valid and `list transaction --on-disk` resolves the posted account as
NFC, so an agent can copy that returned name and still fail to retarget it.
The native control deliberately normalizes a separate copy to NFC, matching
the CLI's documented compatibility loading; raw upstream acceptance of the
authored spelling is not assumed. The original file stays in its authored
normalization.

Save the following as `recipe.py`, put checkout `bea` on PATH, and use an
unused directory:

```sh
python3 recipe.py /absolute/unused/book nfd combined single default /absolute/managed-engine/bin/python
```

Use `account-only` instead of `combined`, `batch` instead of `single`, or
`renamed` instead of `default` for the other affected paths. Use `nfc` for
the matched working control. That parameter describes the posting token;
every case also carries an unrelated decomposed memo whose bytes must be
preserved. The recipe records argv, safe environment, streams, exits,
duration, ledger/mapping hashes and two uncached native NFC-copy loads.

the physical posting line, then rejects it when

comparison uses the incompatible representation. With no planned posting

request the independently planned header edit still makes the write succeed.
Native validation cannot reject the missed intent because the unchanged
category and new header are valid ledger content.
