# Holdings and Commodities pages use up to three different names in one locale: page heading and sidebar, tab title, related-page link

**Severity:** minor (localization). **Owner:** dashboard. **Estimate:** 20–30 minutes. **A3:** in French the Commodities page is "Devises" in the sidebar and heading, "Produits" in the browser tab, and "Marchandises" in the Related Pages links that lead to it. A reader cannot tell these are one page. **Found by:** `/qa-find-bugs-dashboard` on 2026-11-16 against `https://beancount.io`, headless Chromium, the QA account's synthetic ledger. Read-only. Local HEAD `15173444f` has the same strings.

This is the same class as w5/1135 (German Trial Balance "Saldenbilanz"/"Probebilanz"), on two different pages and in many locales.

## Repro

Open `/ledger/open_ledger/example/holdings?lang=fr`. The H1 reads `Avoirs`, the tab title `Participations - example`, and the Related Pages link on other reports `Participations`. Open `/commodities?lang=fr`: the H1 reads `Devises`, the tab title `Produits - example`, and the Holdings page's Related Pages link `Marchandises`.

## Where the names diverge

Each entry lists the heading and sidebar name (`page.commodities.commodities` / `page.holdings.holdings`), then the tab title (`seo.ledgerCommodities.title` / `seo.ledgerHoldings.title`), then the related-page link (`common.relatedLinks.commodities` / `common.relatedLinks.holdings`).

Commodities:

- fr: Devises / Produits / Marchandises
- es: Productos / Productos / Materias primas
- ca: Monedes / Productes / Mercaderies
- de: Währungen / Waren / Waren
- nl: Grondstoffen / Goederen / Goederen

Holdings:

- fr: Avoirs / Participations / Participations
- es: Tenencias / Tenencias / Participaciones
- bg: Активи / Притежания / Притежания
- ru: Активы / Владения / Владения
- uk: Холдинги / Володіння / Володіння
- sk: Portfólio / Držby / Držby
- fa: دارایی‌های نگهداری شده / دارایی‌ها / دارایی‌ها

For Catalan Holdings, see w5/1138: its heading key holds "Nom del fitxer".

en, ja, ko, pt and zh are consistent.

## Fix

Pick one name per locale and per page, and use it for all three keys plus each page's `seo.*.description`. The heading/sidebar key is the one users see most, so treat it as the default. Two exceptions:

- Prefer a term that does not mean "currencies" for Commodities. The page also lists stocks and other assets, so French "Devises" and German "Währungen" are narrower than the page.
- Do not use "Активы" or "Активи" (accounting Assets) for Holdings in ru or bg. Those words collide with the Assets root shown on the same pages.

Files:

- `dashboard/src/features/ledger-data/{commodities,holdings}/locales/<lang>.ts`
- `dashboard/src/i18n/locales/seo/<lang>.ts`
- `dashboard/src/i18n/locales/common/<lang>.ts`

## Acceptance

- For every locale, the Holdings heading, sidebar item, tab title and Related Pages link use the same term, and the same holds for Commodities.
- `yarn test`, `yarn lint` and `yarn format:check` pass in `dashboard/`.
