# Include bank identity in remembered OFX account mappings

**Major · cli · 35–50m · A1 · worker1.** Two banks can issue the same account
number. OFX import remembers only `ACCTID`, so bank B inherits bank A's ledger
account, and explicitly mapping B overwrites A's mapping. A later A statement
then writes to B's ledger account at exit 0. The books remain valid and total
assets still add up; individual bank balances are wrong. No product fix implemented.

Real local CLI QA, 2026-10-25, main/runtime
`64d3a4c09d200f7b1f3d1aa22f5ccb1b8ae87b06`, frozen 1,637 tracked CLI files.
Checkout `bea 0.3.1`, frontend Python 3.13.3, existing managed Python 3.12.10 /
Beancount 3.2.3 / Beanquery 0.2.0 / Beangulp 0.2.0, macOS 26.5.1 arm64.
Bounded fresh subprocesses, closed stdin/no TTY, isolated config/cache,
notifier disabled. Synthetic bank files and ledgers; no service/dependency changes.

In `rebind-bank-collision`:

1. First bank: explicitly choose `Assets:Checking`; preview/apply its 10 USD
   payment. Checking **90**, Savings **200**.
2. Second bank: explicitly choose `Assets:Savings`; preview/apply its 20 USD
   payment. Checking **90**, Savings **180**. Both choices were supplied.
3. First bank's next file: omit `--account`, as the documented remembered
   workflow permits. Preview selects **Assets:Savings**, `ready: 1`; apply
   exits **0**, writes 1, and puts A2's 5 USD payment in Savings.

Native final: **Checking 90 / Savings 175**, instead of **85 / 180**.
Three transactions, amounts and expense **35 USD** are correct, total net
worth **265** is correct, and check passes. The error is the source account
of A2, which independent native loading and BQL both confirm. Human output
also selects Savings and succeeds; there is no mismatched-bank refusal.

The saved record after step 2 has one entry:

```json
{"accounts":[{"acctid":"00012345","account":"Assets:Savings","rules":null,
"default_account":"Expenses:Food","source":"second.ofx"}]}
```

Bank A's explicit binding was replaced. `unbound-bank-collision` shows the
other failure: after mapping only A, a new B statement without `--account`
previews/applies into Checking at exit 0 (Checking **70**, Savings **200**).
Expected: refuse at usage exit **2** and require B's ledger account before
writing; keep the original Checking **90**, Savings **200**. An account number
alone does not establish that B is A. OFX defines bank account identity using
the account aggregate, including its bank identifier and account details.
[OFX Banking 2.3, §§3.1.1 and 11.3.1](https://financialdataexchange.org/wp-content/uploads/2025/12/OFX-Banking-Specification-v2.3.pdf#page=203).
