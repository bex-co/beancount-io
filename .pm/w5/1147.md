# Overview "Open the balance sheet for this period" drops the month the page shows, so it opens today's balances

**Severity:** minor (a drill-down that promises the period shows different numbers). **Owner:** dashboard. **Estimate:** 15–25 minutes. **A2:** a reader looking at July's Financial position who follows "Open the balance sheet for this period" should see July 31 balances, not the latest ones. This regresses `w3/done/568` for the redesigned Overview (`aabf2eced`, 2026-11-16). **Found by:** `/qa-find-bugs-dashboard` on 2026-11-16 against `https://beancount.io`, using headless Chromium at 1440×1000 in English/light. The account was the QA owner, on its designated disposable synthetic ledger. Local HEAD `c040852e8`; production serves the redesign. Read-only.

## Repro

1. Open the ledger Overview with no filters (`/ledger/<owner>/<ledger>`). On the QA ledger, whose last entry is Aug 28, 2026, it opens on **JULY 2026**. Financial position is dated Jul 31, 2026 and lists Checking 4,564.11 USD.
2. The card's footer link reads **Open the balance sheet for this period**, and its `href` is `/ledger/<owner>/<ledger>/balance-sheet` with no `time`.
3. Click it. The Balance Sheet shows Assets 17,251.76 and Checking 6,702.01 USD, the Aug 28 balances, not July's.
4. Same with the stepper: press **Previous** twice to **MAY 2026**. Financial position shows May 31 with Assets 13,184.51 USD; the link still has no `time` and opens the Aug 28 figures. `/balance-sheet?time=2026-05` shows the correct 13,184.51.

Control: with the month in the URL (`/ledger/<owner>/<ledger>?time=2026-07`) the same link is `/balance-sheet?time=2026-07`. Money movement's **View all** links already carry the stepped month (`/income-statement?time=2026-05`).

## Cause

`dashboard/src/features/reports/overview/index.tsx:441` passes the stepped month to the card as `time={pastMonth ? month.timeFilter : …}`. `components/account-balances-card.tsx:280` uses it to pick the "for this period" label and the Balance Sheet target (`:312`), but the `<Link>` at `:375` has no `search`, so it relies on the router keeping the URL's own `time`. The stepped month lives in component state (`hooks/use-overview-month.ts`), not in the URL, so nothing carries it.

## Fix

Give the link `search={{ ...current search, time }}` from the same `time` prop it already reads, so the Balance Sheet opens on the period the card names. Do not change the unfiltered "View all accounts" link.

## Definition of done

- In the repro, on the default July view and after stepping to May, the link's `href` carries `time=2026-07` / `time=2026-05`, and the Balance Sheet it opens lists Checking 4,564.11 / 2,484.51 USD.
- With `?time=2026-07` in the URL the link is unchanged.
- A rendered test of `AccountBalancesCard` with `time="2026-05"` and no URL search asserts the link's `time`. It fails on current `main`.

## Dedupe

Searched `.pm/**`, including `done/`, for `viewPeriodBalanceSheet`, "balance sheet for this period", and Overview month. `w3/done/568` added this link for URL filters. `w5/1143` (focus on the month stepper's self-disabling buttons) and `w5/1144` (badge contrast) touch the same page but not this link. Separate from `w5/1148`, which is about the month not surviving back/reload.
