# Preserve a declared budget's fractional amount when postings use whole units

**Major · cli · 35–50m · A1/A2 · worker1.** A monthly `100.49 USD` budget
becomes `100` in JSON and CSV when the ledger's postings use whole dollars.
The reported variance is -90 rather than -90.49. Merely spelling the same
10-dollar posting `10.00` restores the correct budget. This changes numeric
report data, beyond the documented rounding of human tables. No fix implemented.

Environment: 2026-11-07, checkout bea 0.3.1, Python 3.12.10, macOS 26.5.1
arm64, source `74a0b8cbe381391a4385e88cf0358a1f7154928f` (subsequent
`81ae1d449` changes board files only). Existing managed interpreter executes
checkout helper sources. Fresh subprocesses, 25s timeout, closed stdin/no TTY,
offline, absolute file, isolated child config/cache, notifier off,
`BEA_FILE`/`BEA_TOKEN` removed, HOME unchanged.

## Reproduce

Create this synthetic `main.bean` in a fresh directory:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Cash USD
2026-01-01 open Expenses:Food USD
2026-01-02 * "Food"
  Expenses:Food 10 USD
  Assets:Cash -10 USD
2026-01-31 note Assets:Cash "End"
2026-01-01 custom "budget" Expenses:Food "monthly" 100.49 USD
```

Use isolated environment variables and absolute executable/file paths:

```sh
bea --json --no-input --offline --file /absolute/main.bean check
bea --json --no-input --offline --file /absolute/main.bean list custom
bea --json --no-input --offline --file /absolute/main.bean report budget --time 2026-01
bea --no-input --offline --file /absolute/main.bean report budget --time 2026-01
bea --no-input --offline --file /absolute/main.bean report budget --time 2026-01 --format csv
```

All exit 0 with empty stderr and unchanged ledger bytes. Check is valid;
custom listing preserves `100.49 USD`. Budget JSON returns
`budget: "100", actual: "10", variance: "-90"`; the human table and CSV
agree. Expected full January budget 100.49 and variance 10 - 100.49 = -90.49.
The Budgets section of `cli/docs/USAGE.md` promises that a full month reads
as declared; Reports as CSV promises exact decimal amounts.

Fresh-fixture reproduction agrees. Controls: replace both `10 USD` spellings
with `10.00 USD`, or add `option "display_precision" "USD:0.00"`; the budget
then becomes 100.49 and variance -90.49 without changing economic activity.
With no money postings the same budget also remains 100.49. An eight-decimal
budget `0.12345678 USD` with a zero whole-unit posting becomes an explicit
zero budget. The equivalent Income fixture loses the same .49; an eight-digit
security price does not repair it, correctly remaining separate from money
precision. BQL confirms the original 10-dollar actual.

## Cause and repair

`cli/src/bea_engine/report.py::_budget::prorated:388–391` quantizes the
computed budget using `_display_precision(filtered)`. That shared helper
(:2092 onward) learns only posting units/balance assertions and explicit
display settings; it ignores budget amounts. A whole-dollar posting makes
USD precision zero, so the budget calculation rounds away its declared cents
before either JSON serialization or variance subtraction (:431).

Use the budget amount's meaningful precision when resolving budget-proration
precision, preserving a whole interval's declared value and meaningful small
budgets. Keep the existing day-proration/noise cleanup and deliberate display
settings coherent with the documented contract; do not globally let security
quotes inflate money precision. The shared helper has other report callers,
so scope the new budget-specific evidence carefully. This is independent of
[1121](done/1121.md)'s missing account rows and [1122](./1122.md)'s malformed
amount parsing: this fixture has one valid budget and one expense account.

`answer` dispatches to `_budget`; frontend `commands/report.py::budget` and
`report_csv.py::_budget` use its already rounded values. JSON/text/CSV and
Income were exercised. No server/API or dependency change.

Acceptance: January retains 100.49 budget and -90.49 variance with whole-unit
postings, in JSON and CSV, and a meaningful tiny declared budget does not
become zero. Preserve cents-posting, explicit-precision, empty-actual and
ordinary proration controls. Add meaningful budget regression coverage and
run `make check-all` inside `cli/`.
