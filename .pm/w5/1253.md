# An account's journal leaves the Balance empty on the row that brings the account to zero: paying a card off in full reads "+663.81 USD" with no balance, between "Balance -663.81 USD" and "Balance -41.97 USD"

**Severity:** minor. Nothing is computed wrongly, but the register hides the balance at the moment a reader most wants to see it: the card paid off in full, the cash swept into a fund, the yearly allowance used up. The empty cell reads the same as "not computed", while the balance assertion row in the same table writes its zero as `0 IRAUSD`. **Owner:** `dashboard` (`features/journal`). **Estimate:** 20–30 minutes including tests. **A2:** the account page is where a newcomer checks a card or bank account against its statement, and a zero is the statement figure they are looking for. **Found by:** `/qa-find-bugs-dashboard` (`dashboard-qa` routine) on 2026-11-27 against `https://beancount.io`, entry chunk `main-BBmi61Hs.js`, isolated headless Chromium 158 at 1440×1000, English, browser time zone America/Mexico_City. The run was signed in as the QA account and read the public `open_ledger/example` ledger only. Local HEAD `219e7833f`.

## Repro

1. Open `/ledger/open_ledger/example/account/Liabilities:US:Chase:Slate?time=2015-08`, conversion **At Cost**, layout **Compact**. In the **Account journal** table:
   - 2015-08-08 Jewel of Morroco: `-41.97 USD`, Balance `-41.97 USD`
   - 2015-08-07 Chase:Slate "Paying off credit card": `+663.81 USD`, **Balance cell empty**
   - 2015-08-07 Farmer Fresh: `-44.06 USD`, Balance `-663.81 USD`
2. Choose **Comfortable**. Every other row has a `Balance …` line under its amount. The payment row has none.
3. Open `/ledger/open_ledger/example/account/Assets:US:Federal:PreTax401k`. The 2017-08-10 payroll reads `-500.00 IRAUSD` with no balance. The row below it reads `Balance 500.00 IRAUSD`. The 2017-01-01 balance assertion row in the same table reads `0 IRAUSD`.
4. `Assets:US:Vanguard:Cash` shows the same on its three "Investing 60% of cash in RGAGX" rows (2015-03-30, 2015-06-22, 2016-01-18).

All four repeated from a fresh load.

**API control:** `getLedgerAccountJournal(ledgerId: "open_ledger/example", query: {account: "Liabilities:US:Chase:Slate", limit: 1000})` returns eight transactions whose `balance` is `{}`. The first is 2015-08-07, with `change` `{"USD": "663.81"}`. `Assets:US:Federal:PreTax401k` returns 28 such rows and `Assets:US:Vanguard:Cash` returns 3. The server sends an empty inventory for a zero balance, as Beancount does. The dashboard then shows nothing.

## Cause

`RegisterBalance` (`dashboard/src/features/journal/components/journal-register.tsx:147-177`) returns `null` when `amountsOf(item.balance)` is empty (`:160-162`). That check exists to skip non-transaction rows, but it also catches a transaction whose balance is zero. Both layouts render it: `journal-lines.tsx:522` and `journal-days.tsx:410` and `:500`. The shared journal list came in with `ebbf43fed` (2026-11-20). The column table it replaced also returned `null` for an empty map, so this is long-standing, not a regression.

## Fix

Dashboard only. On a transaction row, every currency that the row's `change` moved and that the balance no longer holds reads `0 <currency>`. When `change` is empty too, as with a `0.00 IRAUSD` posting, use the currencies of the row's derived units instead. Render the zero through `<LedgerAmount>` like the other figures, so it takes the reader's digits (`۰ USD` in Persian). The payment row then reads `Balance 0 USD`. Non-transaction rows keep an empty cell. A balance that still holds other currencies keeps them, with the zeroed currency added.

## Definition of done

- On production, step 1's payment row reads `+663.81 USD` and `Balance 0 USD` in both layouts. On PreTax401k, the 2017-08-10 row reads `Balance 0 IRAUSD`.
- Non-transaction rows (balance assertions, notes, opens) show no balance figure, as before.
- Rendered register tests cover each case and fail on the current code: a transaction with `balance: {}` and a USD change shows `0 USD`; a two-currency account whose USD reaches zero shows `0 USD` beside its EUR balance; a Persian render shows Persian digits. Dashboard gates pass.
