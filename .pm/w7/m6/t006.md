## Objective

Define an app marker that the apps add to every beancount.io page they open; the dashboard keeps it for the session and hides pricing, billing, and upgrade prompts while it is set, as it already does inside a React Native WebView. Login and sign-up started from the app ignore `next=/pricing` and never continue to Checkout (D14).
