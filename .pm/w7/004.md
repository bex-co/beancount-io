# Move the store reads off `IStripeService` once store billing has a service

`grantedStoreTiers` sits on `IStripeService` only because `TierDeps` is `{ stripe }`, and `SubscriptionService` reads the store model directly. Moving it now would add a dependency at seven `getUserTier` call sites for one method. When m3 adds store verification, give it `IStoreBillingService` owning the granted tiers and the renewing-store lookup, make `TierDeps` `{ stripe, stores }`, and return `StripeService` to its `paidCustomer` model. Clients see no change. Found by the w7/m1/t008 review.
