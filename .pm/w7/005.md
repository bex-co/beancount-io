# A `billing`-only `subscriptionStatus` pays for the full Stripe view

Only a document selecting `hasActiveSubscription` alone gets the light path. A document selecting `billing` without `subscriptions` still lists all Stripe subscriptions with expansions, then fetches each product and card, and returns none of it: one list plus a call per product and per subscription.
