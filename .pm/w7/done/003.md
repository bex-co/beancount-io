# MCP tool failures keep plan wording that thrown failures lose

`envelopeFromThrown` runs `withoutPlanWording` on `RESOURCE_LIMIT_REACHED` and `PREMIUM_REQUIRED`, but `splitToolFailure` does not, so the same refusal loses "Upgrade for more" when thrown and keeps it when a tool returns it through `runToolSafely`. Ledger-write tools take that path, which breaks ADR 019. Apply the same rule in `splitToolFailure`. Predates w7; found by the w7/m1/t008 review.

---

**Resolved 2026-11-01** — `splitToolFailure` applies the same rule as `envelopeFromThrown`, with a test that fails without it. Shipped in `ef5626d9c` (`backend-v2`).
