# Skill-suite evidence

This directory holds dated records, not guides. Customers should start from
[`../installation.md`](../installation.md) and the other guides one level up.

Each file records one real run that a roadmap milestone needed before it could
close: a guide followed as written on Claude Code, Codex, or native Windows
(`*-rehearsal.md`), a description change measured against the routing set
(`routing-rehearsal.md`), or a ClawHub or Hermes Agent release check
(`*-controls-*.md`, `clawhub-release-preflight-*.md`,
`hermes-compatibility-*.json`). Guides link here when they claim a procedure
was run end to end; the deterministic checks live in `scripts/skills/`.

Records are history. Add a new dated record rather than rewriting an old one.
